ToBe 浏览器连接（纯标签页 v4）

请在你平时使用、已经登录竞赛平台的 Chrome 或 Edge 中手动加载本目录。
1. 地址栏打开 chrome://extensions 或 edge://extensions。
2. 开启“开发者模式”，选择“加载已解压的扩展程序”，选本目录。
3. 打开新版 ToBe 并登录自己的 ToBe 账号；点击浏览器扩展图标检查“已连接”。
4. ToBe 右上角账号设置中的“浏览器连接”也显示连接状态和随包目录。
若此前加载过旧版连接，请停用旧版，再加载本次完整目录，避免重复连接。
多个浏览器同时连接而无法唯一确认时，请只保留本次使用的一个连接。

无需把登录数据迁入 ToBe 专用 Edge。Cookie、密码和登录会话留在本浏览器内；
本扩展无 cookies、history、debugger 权限，不读取或导出 Cookie。
提交使用网站原生表单、语言菜单及验证码，不跳过网站验证。
后台只静音本次新建的标签页，不影响其它音乐或视频。
需要登录或验证码时才将对应页带到前台。原站正式结果保存、且 ToBe 已经
显示该条结果后才关闭自建页；手动打开的页面保留。
断网或已取得受理编号时，只查询原提交，不重新发送代码。
原站题面读取与 VP 注册同样使用本浏览器，不能悄悄启动另一个登录配置。

请保留旧 ToBe 专用浏览器中仍在查询的页面，直到新版核对原记录完成。
旧记录缺少可靠绑定信息时会保留待核对状态，不猜测账号、题目或结果。
