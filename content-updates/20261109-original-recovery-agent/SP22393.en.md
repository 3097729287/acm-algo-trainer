# KATHTHI - KATHTHI

## Problem Description

Kathiresan is initially locked in cell $(0,0)$ of a highly guarded rectangular prison with $R$ rows and $C$ columns. He must reach the gate at $(R-1,C-1)$ to escape. He can move north, east, west or south to an adjacent cell. A move from $(x_1,y_1)$ to $(x_2,y_2)$ is allowed exactly when $|x_2-x_1|+|y_2-y_1|=1$, $0\le x_2<R$ and $0\le y_2<C$.

Kathiresan manages to obtain the map of the prison. If `map[x1][y1] == map[x2][y2]`, he can make the move without killing any guards. If `map[x1][y1] != map[x2][y2]`, he must kill one guard to make the move.

Given the map, find the minimum number of guards he must kill to escape.

## Input Format

The first line contains $t$, the number of test cases. For each test case, the first line contains $R$ and $C$, followed by $R$ strings describing the prison map.

## Output Format

For each test case, output the minimum number of guards Kathiresan must kill to escape.

## Constraints

- $1\le t\le10$.
- $2\le R\le1000$.
- $2\le C\le1000$.
- Each map character is between `a` and `z`.
