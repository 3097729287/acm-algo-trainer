# KATHTHI - KATHTHI

## 题目描述

Kathiresan 被关在一座戒备森严、共有 $R$ 行和 $C$ 列的矩形监狱中，初始位于格子 $(0,0)$。他必须到达位于 $(R-1,C-1)$ 的大门才能逃脱。他可以向北、东、西或南移动到相邻格子。从 $(x_1,y_1)$ 移动到 $(x_2,y_2)$ 合法，当且仅当 $|x_2-x_1|+|y_2-y_1|=1$、$0\le x_2<R$ 且 $0\le y_2<C$。

Kathiresan 设法得到了监狱地图。如果 `map[x1][y1] == map[x2][y2]`，他无需杀死守卫就能移动过去；如果 `map[x1][y1] != map[x2][y2]`，则必须杀死一名守卫才能移动过去。

给定地图，请求出他逃离监狱最少需要杀死的守卫数量。

## 输入格式

第一行包含测试用例数 $t$。对于每个测试用例，第一行包含 $R$ 和 $C$，随后 $R$ 个字符串描述监狱地图。

## 输出格式

对于每个测试用例，输出 Kathiresan 逃脱所需杀死的最少守卫数量。

## 数据范围

- $1\le t\le10$。
- $2\le R\le1000$。
- $2\le C\le1000$。
- 地图中的每个字符都在 `a` 到 `z` 之间。
