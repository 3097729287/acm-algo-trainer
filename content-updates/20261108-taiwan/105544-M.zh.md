# 任务调度器

时间限制：1 秒。内存限制：1024 兆字节。

## 题目描述

一个简单的任务调度器为嵌入式系统调度任务。每个任务都有任务 ID、优先级数值，以及指向相应回调函数的函数指针。任务 ID 是从 0 到 99 的整数，优先级数值是从 0 到 255 的整数。回调函数负责打印对应的任务 ID。

任务由开发者静态添加。添加完 $N$ 个任务后，调度器开始调度任务。优先级数值最小的任务最先执行。如果多个任务的优先级数值相同，最早添加到系统中的任务最先执行。现在，请确定系统会打印什么。

## 输入格式

第一行包含一个整数 $T$，表示测试数据的组数。接下来的每组测试数据包含三行。

对于每组测试数据，第一行是一个整数 $N\le100$，表示随后两行各自包含的整数个数。第二行包含 $N$ 个整数，每个整数表示一个任务的 ID。整数在第二行中的位置越靠前，对应的任务就越早被添加到系统中。第三行也包含 $N$ 个整数，表示优先级数值。第三行的第 $i$ 个数，是第二行第 $i$ 个数所表示任务的优先级数值。

## 输出格式

对于每组测试数据，输出 $N$ 个整数，用一个空格分隔。这些整数是任务的 ID，打印顺序与任务被调度执行的顺序一致。

## 数据范围

- $1\le T\le10$。
- $1\le N\le100$。
- $0\le taskID\le99$。
- $0\le priority\ value\le255$。
