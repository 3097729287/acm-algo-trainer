# 交付时间估算

时间限制：1 秒。内存限制：1024 兆字节。

## 题目描述

交付时间对于赢得订单至关重要，产品准备过程中的许多因素都会影响交付时间，例如在不同工作区域之间切换工序，以及每道工序的工作量。生产经理收到订单询价时，需要准确估算目标产品的交付时间。请编写程序帮助生产经理完成估算。

一份询价对应的交付时间，是生产这些产品所需的时间，其中包括材料准备、制造、质量检查、运输等多项工作。每个工作岗位有自己的执行时间，而从一道工作转移到下一道工作还需要传输时间。对于每份询价，生产经理掌握以下三类目标产品信息：

- 工作数量和传输数量，分别为 $|T^j|$ 和 $|T^t|$；
- 各项工作的处理时间，其中 $T^j=\{t^j_0,t^j_1,t^j_2,\ldots,t^j_{|T^j|-1}\}$；
- 工作之间的传输时间，其中 $T^t=\{t^t_0,t^t_1,t^t_2,\ldots,t^t_{|T^t|-1}\}$。

流程可能有多个起始工作或结束工作。遇到这种情况，可以插入虚拟的起始工作和结束工作来简化问题。因此，可以假定每份询价的流程都只有一个起始工作和一个结束工作。

## 输入格式

输入分为三部分：(1) 第一行给出工作数量和传输数量，(2) 第二行给出各项工作的处理时间，(3) 其余各行给出传输时间。第一行包含 $|T^j|$ 和 $|T^t|$，用一个空格分隔。第二行给出 $T^j$，其中 $T^j$ 的各个元素之间用逗号分隔。从第三行到第 $(2+|T^t|)$ 行给出传输时间信息。每行包含三项数据：来源工作、目标工作和传输时间。此外，测试数据满足以下限制：

- 任意一对工作之间至多有一项传输时间信息。
- 一个输入文件可能包含多组测试数据。

## 输出格式

输出交付产品所需的总时间，记为 $z$，即所有工作都应在 $z$ 内完成。生产经理还关心具体的制造流程。如果恰好只有一条处理路径决定交付时间，输出该路径上的工作序列；否则输出大写字母 `M`。输出序列中各个元素之间用逗号分隔。换言之，输出形式为 `z,v1,v2,...` 或 `z,M`，其中 $v_1$ 和 $v_2$ 表示工作。

## 数据范围

每份询价的流程恰好有一个入口和一个出口，且至少有一条路径决定交付时间，制造流程中不存在环。各变量的范围如下：

- $2\le|T^j|\le50$。
- $1\le|T^t|\le100$。
- $1\le t^j_x,t^t_y\le50$。

```

```
