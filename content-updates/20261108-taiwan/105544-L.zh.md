# 绝不凑成九

时间限制：3 秒。内存限制：1024 兆字节。

## 题目描述

从前有一位名叫 Tso 的将军，他善于将士兵分成小组，分别执行不同任务。为了提高灵活性，他会尽可能把士兵分成更多的小组。不过，有一个只有极少数人知道的秘密：他年轻时，一位算命先生曾警告他，9 是对他极为不吉利的数字。因此，他每次给士兵分组时，都会确保任选若干小组，其士兵总数都不恰好等于 9。

例如，有 $N=11$ 名士兵时，可以将他们分成三组，人数分别为 3、4、4。任意选择若干组，都不会恰好有 9 名士兵，总人数只可能是 3、4、7、8 或 11。另一种方法是分成四组，人数分别为 1、3、3、4，同样无法通过组合得到恰好 9 名士兵，总人数只可能是 1、3、4、5、6、7、8、10 或 11。后一种方法的组数更多，因此优于前一种方法。

相反，如果将士兵分成十一组，每组一人，虽然组数更多，但选择其中九组就恰好有 9 名士兵，因此将军不能接受这种分法。

作为将军最可靠的助手之一，你的任务是：给定士兵人数 $N$，且 $N\ne9$，帮助将军求出能够分成的最大组数 $K$。

## 输入格式

输入只有一行，包含一个正整数 $N$。

## 输出格式

用 $K$ 表示所求的最大组数。输出只有一行，打印非负整数 $X$，其中 $X$ 是 $K$ 除以 $10^9+7$ 的余数，即 $X\equiv K\pmod{10^9+7}$，且 $0\le X<10^9+7$。

## 数据范围

- $1\le N\le10^{15}$。
- $N\ne9$。
- $0\le X<10^9+7$。

## 样例输入 1

```text
11
```

## 样例输出 1

```text
4
```

## 样例输入 2

```text
8
```

## 样例输出 2

```text
8
```

## 样例输入 3

```text
12345678901234
```

## 样例输出 3

```text
839407413
```
