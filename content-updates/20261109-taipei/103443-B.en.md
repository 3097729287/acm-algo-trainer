# Maximum Sub-Reverse Matching

Time limit: 3 seconds. Memory limit: 1024 megabytes.

## Problem Description

Consider two strings of the same length, such as $s_1=$ `happycoding` and $s_2=$ `onedocument`. Comparing the strings character by character gives 2 matching positions:

```text
happycoding
onedocument
00000100010
```

Reverse the substring from position 4 through position 8 of $s_2$ to obtain $s'_2=$ `onemucodent`. The resulting strings have 4 matching positions:

```text
happycoding
onemucodent
00000111010
```

Given two strings $s_1$ and $s_2$ of the same length, reverse one substring of $s_2$ to maximize the number of positions at which the resulting string matches $s_1$.

## Input Format

The first line contains an integer $T$, the number of test cases. Each test case occupies three lines. The first line contains the length $n\le1000$. The following two lines contain $s_1$ and $s_2$, respectively, each a lowercase string of length $n$.

## Output Format

For each test case, output four space-separated integers $m_{1,2}$, $m_{1,2^*}$, $a$, and $b$. The first is the number of matching positions between the original strings. The second is the maximum possible number of matching positions after reversing a substring of $s_2$. The indices $a\le b$ are numbered starting from 1; reversing positions $a$ through $b$ must achieve that maximum. If several choices work, minimize $b-a$; if there is still a tie, minimize $a$.

## Technical Specification

- $1\le T\le50$.
- $1\le n\le1000$.
- All characters are lowercase letters.
