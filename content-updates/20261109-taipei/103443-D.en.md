# Largest Remainder

Time limit: 1 second. Memory limit: 1024 megabytes.

## Problem Description

Given $D$ digits and an integer $K$, consider every distinct permutation of these digits as a $D$-digit decimal number. Find a permutation $X$ whose remainder on division by $K$, between 0 and $K-1$, is as large as possible. Among permutations giving the same largest remainder, output the largest number.

For example, let $D=3$ and let the digits be 1, 2, and 3.

1. If $K=1$, every permutation has remainder 0, so the answer is 321, the largest permutation.
2. If $K=10$, both 123 and 213 give the largest possible remainder, 3. The answer is 213 because it is larger.
3. If $K=100$, the largest possible remainder is 32, obtained by the permutation 132.

## Input Format

The first line contains two positive integers $D$ and $K$. The next line contains $D$ digits, separated by spaces. Each digit $d$ satisfies $1\le d\le9$.

## Output Format

Output, on one line, the largest permutation giving the largest remainder.

## Technical Specification

- $1\le D\le16$.
- $1\le K\le200$.
- $1\le d\le9$.

### Input

```text
3 1
1 2 3
```

### Output

```text

```
