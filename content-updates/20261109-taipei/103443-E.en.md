# Composition with Large Red Plane, Yellow, Black, Gray, and Blue

Time limit: 1 second. Memory limit: 1024 megabytes.

## Problem Description

Mona is a mosaic designer. Customers ask her to build rectangular frames of specified sizes, with photos embedded in specified layouts. Each frame has a border of thickness $1$ pixel, and a gap of $1$ pixel separates neighboring photos. Photos may be resized while preserving their width-to-height ratios, but both dimensions after resizing must be integers.

Help Mona check whether each customer's request can be fulfilled.

## Input Format

The first line contains two positive integers $W$ and $H$, the requested frame's width and height.

The remaining input describes the layout. A layout consists of H-blocks, V-blocks and photos, each occupying a rectangular region.

An H-block divides its region horizontally into one or more subregions arranged from left to right. Its description begins with a positive integer $S$, the number of subregions. Each subregion is a V-block or a photo, and the descriptions of these subregions follow in order.

A V-block divides its region vertically into one or more subregions arranged from top to bottom. Its description begins with a positive integer $S$, the number of subregions. Each subregion is an H-block or a photo, and the descriptions of these subregions follow in order.

A photo description begins with $0$, distinguishing it from a block description. The next line contains two positive integers $w$ and $h$, the original photo's width and height.

The entire layout is either an H-block or a photo, as determined by its first number.

## Output Format

If the request can be fulfilled, print a preview of the frame consisting of $H$ lines, each containing $W$ characters. Use a space character for each photo pixel and `*` for each border or gap pixel.

If it cannot be fulfilled, print `Impossible` on one line.

## Technical Specification

- $1\le W,H\le1000$.
- $1\le w,h\le1000$ for each photo.
- $N\le2000$, where $N$ is the total number of H-blocks, V-blocks and photos.
