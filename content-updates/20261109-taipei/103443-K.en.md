# Insertion Array

Time limit: 3 seconds. Memory limit: 1024 megabytes.

## Problem Description

You are given two strings $a$ and $b$, of lengths $len_a$ and $len_b$. There are $len_b+1$ ways to insert $a$ into $b$. For $0\le i<len_b$, let $S[i]$ be the string formed by inserting $a$ immediately before the character of $b$ at index $i$, using indices starting from 0. Let $S[len_b]$ be the string formed by placing $a$ after $b$. We call these the inserted strings. For example, if $a=$ `bb` and $b=$ `abc`, the four inserted strings are $S[0]=$ `bbabc`, $S[1]=S[2]=$ `abbbc`, and $S[3]=$ `abcbb`.

The insertion array $Ins$ of $b$ with respect to $a$ is an array indexed starting from 0, of length $len_b+1$, containing a permutation of the integers from 0 through $len_b$. It describes the lexicographical order of the inserted strings. More precisely, it satisfies

$$
i<j\iff S[Ins[i]]<S[Ins[j]]\ \lor\ \bigl(S[Ins[i]]=S[Ins[j]]\ \land\ Ins[i]>Ins[j]\bigr).
$$

Strings in this formula are compared lexicographically. Thus, equal inserted strings are ordered by their insertion indices in decreasing order.

Calculate the insertion array $Ins$. To keep the output small, output only

$$
\left(\sum_{i=0}^{len_b} Ins[i]\times1234567^i\right)\bmod(10^9+7).
$$

## Input Format

The first line contains an integer $T$, the number of test cases. Each test case consists of two lines: the first contains the nonempty string $a$, and the second contains the nonempty string $b$.

## Output Format

For each test case, output an integer between 0 and 1000000006, inclusive, equal to

$$
\left(\sum_{i=0}^{len_b} Ins[i]\times1234567^i\right)\bmod(10^9+7).
$$

## Technical Specification

- $1\le T\le4\times10^4$.
- The sum of $len_a$ over all test cases does not exceed $2\times10^6$.
- The sum of $len_b$ over all test cases does not exceed $2\times10^6$.
- $a$ and $b$ contain only lowercase Latin letters.

## Sample 1

### Input

```text
2
bb
abc
abaa
abab
```

### Output

```text
468235032
667196656
```
