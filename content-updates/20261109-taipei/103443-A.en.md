# Ice Cream

Time limit: 1 second. Memory limit: 1024 megabytes.

## Problem Description

To celebrate the third anniversary of the Ice Cream Professional Company (ICPC), the company is holding an anniversary sale called “Buy $X$ units and get $Y$ units free”. First, you draw a lottery ticket for $X$ and a lottery ticket for $Y$. You can then use this offer: for every $X$ units of ice cream you buy, you receive $Y$ additional units for free.

Each unit of ice cream costs 3 dollars. Write a program to calculate the minimum price you must pay to obtain at least $N$ units of ice cream.

## Input Format

The first line contains an integer $T$, the number of test cases. Each test case consists of one line containing three integers $X$, $Y$, and $N$: the two numbers on your lottery tickets and the minimum number of units of ice cream you want to obtain. Any two consecutive integers are separated by exactly one space.

## Output Format

For each test case, output one integer: the minimum price of your order.

## Technical Specification

- $1\le T\le15$.
- $1\le X,Y\le1000$.
- $1\le N\le15000$.

## Sample 1

### Input

```text
1
1 1 3
```

### Output

```text

```
