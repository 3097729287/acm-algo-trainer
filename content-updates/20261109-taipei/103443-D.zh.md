# 最大余数

时间限制：1 秒。内存限制：1024 兆字节。

## 题目描述

给定 $D$ 个数字和一个整数 $K$，考虑将这些数字排列成一个 $D$ 位十进制数的所有不同方式。请找出一个排列 $X$，使其除以 $K$ 所得的余数尽可能大；余数在 0 到 $K-1$ 之间。如果多个排列得到相同的最大余数，输出其中数值最大的一个。

例如，设 $D=3$，给定的数字依次为 1、2 和 3。

1. 如果 $K=1$，所有排列的余数都是 0，因此答案是数值最大的排列 321。
2. 如果 $K=10$，123 和 213 都能得到最大的余数 3。由于 213 更大，因此答案是 213。
3. 如果 $K=100$，能得到的最大余数为 32，对应的排列为 132。

## 输入格式

第一行包含两个正整数 $D$ 和 $K$。下一行包含 $D$ 个以空格分隔的数字，每个数字 $d$ 都满足 $1\le d\le9$。

## 输出格式

输出一行，表示在得到最大余数的排列中，数值最大的那个排列。

## 数据范围

- $1\le D\le16$。
- $1\le K\le200$。
- $1\le d\le9$。

## 样例 1

### 输入

```text
3 1
1 2 3
```

### 输出

```text
321
```

## 样例 2

### 输入

```text
3 10
1 2 3
```

### 输出

```text
213
```

## 样例 3

### 输入

```text
3 100
1 2 3
```

### 输出

```text
132
```
