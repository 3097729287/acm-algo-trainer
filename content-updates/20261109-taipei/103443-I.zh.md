# 跷跷板

时间限制：1 秒。内存限制：1024 兆字节。

## 题目描述

游乐场里有一个跷跷板，两侧各有 $S$ 个座位，到中心的距离分别为 $1,2,\ldots,S$。体重为 $w$ 的人坐在距离中心 $d$ 的座位上，会在对应一侧产生大小为 $w\times d$ 的力矩。当两侧的总力矩相等时，跷跷板平衡。

最初每个座位上都坐着一个体重为正整数的孩子。左侧所有孩子的体重都是奇数，右侧所有孩子的体重都是偶数。有人提议交换孩子的位置，使跷跷板平衡。但是体重大于 $2$ 的孩子不愿意移动，他们的座位始终不变。请判断能否使跷跷板平衡；如果可以，求最少交换次数。

例如，设 $S=3$，左侧孩子的体重均为 $1$，右侧均为 $2$。交换两侧距离中心 $3$ 的两个孩子后，左侧总力矩为 $1\times1+1\times2+2\times3=9$，右侧为 $2\times1+2\times2+1\times3=9$，一次交换就能使跷跷板平衡。

再例如，设 $S=3$，左侧体重均为 $1$，右侧距离中心 $1,2,3$ 的体重依次为 $4,2,2$。先交换两侧距离中心 $2$ 的孩子，再交换左侧距离中心 $1$ 的孩子与右侧距离中心 $3$ 的孩子。此时左侧总力矩为 $2\times1+2\times2+1\times3=9$，右侧为 $4\times1+1\times2+1\times3=9$。这个例子无法只通过一次交换达到平衡，因此最少需要两次交换。

## 输入格式

第一行包含一个正整数 $T$，表示测试用例数。每个测试用例首先包含一个正整数 $S$，表示每侧的座位数。接下来一行包含 $S$ 个奇数，依次给出左侧从距离中心 $1$ 到 $S$ 的孩子体重。再下一行包含 $S$ 个偶数，以同样从 $1$ 到 $S$ 的距离顺序给出右侧孩子的体重。

## 输出格式

对于每个测试用例，输出使跷跷板平衡所需的最少交换次数；如果不可能，输出 $-1$。每个答案单独一行。

## 数据范围

- $1\le T\le5$。
- $1\le S\le100$。
- 每个体重 $w$ 都是整数，满足 $1\le w\le50000$。

## 样例 1

### 输入

```text
4
3
1 1 3
2 2 2
3
1 1 1
2 2 2
3
1 1 1
4 2 2
3
3 3 3
2 2 2
```

### 输出

```text
0
1
2
-1
```
