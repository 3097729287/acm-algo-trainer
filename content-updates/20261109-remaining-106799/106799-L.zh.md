# 长距离滑行



**本题有附件，可以用来模拟并可视化机器人的移动。**



VegiCat 在无限大的二维网格上有一个机器人。他希望机器人从格子 $$$s=(s_x,s_y)$$$ 移动到格子 $$$t=(t_x,t_y)$$$。所有格子坐标均为整数。$$$s$$$ 和 $$$t$$$ 可以相同。



机器人按字符串 $$$p$$$ 中的指令行动，每个字符为 `L`、`R`、`U` 或 `D`。用 $$$|p|$$$ 表示 $$$p$$$ 的长度。



机器人从 $$$s$$$ 出发。执行任何指令之前，你可以在不同格子中放置至多 $$$|p|$$$ 个障碍物。每个障碍物的坐标 $$$(x,y)$$$ 必须满足 $$$-2\cdot10^9 \le x,y \le 2\cdot10^9$$$。$$$s$$$ 和 $$$t$$$ 都不能放置障碍物。每个障碍物占一个格子，且整个过程中保持不动；其他格子均无障碍物。



机器人依次执行指令 $$$p_1,p_2,\ldots,p_{|p|}$$$。对于每条指令，从当前位置 $$$(x,y)$$$ 开始，它会沿如下格子序列移动：



- `L`：$$$(x,y)\to(x-1,y)\to(x-2,y)\to\cdots$$$；

- `R`：$$$(x,y)\to(x+1,y)\to(x+2,y)\to\cdots$$$；

- `U`：$$$(x,y)\to(x,y+1)\to(x,y+2)\to\cdots$$$；

- `D`：$$$(x,y)\to(x,y-1)\to(x,y-2)\to\cdots$$$。



只要指定方向的下一个格子没有障碍物，机器人就继续前进一步，直到停在该方向第一个障碍物前的格子。如果开始执行指令时，指定方向的相邻格子已有障碍物，机器人保持原位，但这条指令仍算执行完毕。如果该方向前方没有障碍物，机器人会无限移动，此时障碍物放置方案不合法。



机器人可以在执行完全部指令前到达 $$$t$$$，但**仍必须执行全部剩余指令**。请构造任意一种满足上述要求的障碍物放置方案，使机器人执行最后一条指令后停在 $$$t$$$；或者报告不存在这样的方案。



## 输入格式



第一行包含整数 $$$T$$$（$$$1 \le T \le 10^5$$$），表示测试用例数。接下来描述各测试用例。



每个测试用例的第一行包含两个整数 $$$s_x$$$ 和 $$$s_y$$$（$$$-10^9\le s_x,s_y\le10^9$$$），表示起始格子的坐标。



第二行包含两个整数 $$$t_x$$$ 和 $$$t_y$$$（$$$-10^9 \le t_x,t_y \le 10^9$$$），表示目标格子的坐标。



第三行包含指令字符串 $$$p$$$（$$$1 \le |p| \le 10^5$$$），仅由字符 `L`、`R`、`U`、`D` 组成。



保证所有测试用例的 $$$|p|$$$ 之和不超过 $$$10^5$$$。



## 输出格式



按输入顺序输出各测试用例的答案，不同测试用例的障碍物方案相互独立。



如果不存在合法方案，单独输出一行 `NO`。



否则，第一行输出 `YES`，第二行输出整数 $$$k$$$（$$$0\le k\le|p|$$$），表示障碍物数量。



然后输出 $$$k$$$ 行，其中第 $$$i$$$ 行必须包含两个整数 $$$x_i$$$ 和 $$$y_i$$$（$$$-2\cdot10^9 \le x_i,y_i \le 2\cdot10^9$$$），表示格子 $$$(x_i,y_i)$$$ 中有一个障碍物。



全部 $$$k$$$ 对坐标必须互不相同，且都不能等于 $$$s$$$ 或 $$$t$$$。放置方案必须使每条指令都能结束，并使机器人执行最后一条指令后停在 $$$t$$$。如果有多个方案，输出任意一个。



肯定或否定判定不区分大小写。例如 `yEs`、`yes`、`Yes` 和 `YES` 都会被视为肯定回答。
