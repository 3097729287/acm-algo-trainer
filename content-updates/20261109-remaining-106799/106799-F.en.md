# First Word

Time limit: 5 seconds. Memory limit: 1024 megabytes. Standard input and output.

VegiCat has a string $S$ of $n$ lowercase English letters. He wants a dictionary containing $k$ distinct nonempty substrings of $S$ as words. A substring is a contiguous part of a string. Substrings with identical content are the same word even if they occur at different positions in $S$.

Let $\pi$ map the letters `a,b,...,z` to the corresponding letters of a permutation of the $26$ lowercase English letters. For example, `qwertyuiopasdfghjklzxcvbnm` defines this mapping:

```text
c      a b c d e f g h i j k l m n o p q r s t u v w x y z
pi(c)  q w e r t y u i o p a s d f g h j k l z x c v b n m
```

For a string $u=u_1u_2\cdots u_m$, define $\pi(u)=\pi(u_1)\pi(u_2)\cdots\pi(u_m)$. For the mapping above, $\pi(\mathtt{apple})=\mathtt{qhhst}$.

The dictionary must contain a word $w$ such that, for every such mapping $\pi$ applied to all dictionary words, $\pi(w)$ is the lexicographically smallest resulting word. The same word must satisfy this requirement for all mappings.

For each $k=1,2,\ldots,n$, count dictionaries containing $k$ distinct words and satisfying the requirement, modulo $998244353$. Two dictionaries differ exactly when their word sets before any mapping differ.

Recall that string $a$ is lexicographically smaller than string $b$ if $a$ is a proper prefix of $b$ ($a\ne b$), or there is an index $i$ ($1\le i\le\min(|a|,|b|)$) such that $a_i<b_i$ and $a_j=b_j$ for every $j$ ($1\le j<i$).

## Input Format

The first line contains $T$ ($1\le T\le10^4$), the number of test cases. Each test case has $n$ ($1\le n\le10^5$) on the first line and a string $S$ of length $n$, consisting only of lowercase English letters, on the second line. The sum of $n$ over all test cases does not exceed $10^5$.

## Output Format

For each test case, output $n$ integers on one line. The $k$-th integer is the number of valid dictionaries with $k$ distinct words, modulo $998244353$.

## Sample Explanation

Write each dictionary as a set of words. In the first test case, $S=\mathtt{aab}$. The dictionaries for $k=1,2,3$ are:

| $k$ | Valid word sets | Number |
| --- | --- | --- |
| 1 | `{a}`, `{b}`, `{aa}`, `{ab}`, `{aab}` | 5 |
| 2 | `{a, aa}`, `{a, ab}`, `{a, aab}`, `{aa, aab}` | 4 |
| 3 | `{a, aa, ab}`, `{a, aa, aab}`, `{a, ab, aab}` | 3 |
