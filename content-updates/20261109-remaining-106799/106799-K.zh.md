# 保持距离



VegiCat 正在执行扫雷任务。数轴上有 $$$n$$$ 颗地雷，地雷 $$$i$$$ 位于整数坐标 $$$a_i$$$。地雷按坐标顺序编号，因此 $$$a_1\le a_2\le\cdots\le a_n$$$。地雷坐标可以重复。



VegiCat 按 $$$1,2,\ldots,n$$$ 的顺序对每颗地雷各测试一次。对于地雷 $$$i$$$，他选择一个整数坐标 $$$b_i$$$ 作为测试位置，坐标可以为负数或零。这次测试的误差为 $$$|a_i-b_i|$$$。



对于每个 $$$2\le i\le n$$$，给定整数 $$$l_i$$$，表示地雷 $$$i-1$$$ 和 $$$i$$$ 的测试位置之间所需的最小距离。这些位置必须满足 $$$$$$ |b_i-b_{i-1}| \ge l_i. $$$$$$



请帮助 VegiCat 最小化最大的测试误差，即求 $$$$$$ \min_{\substack{ b_1,\ldots,b_n\in\mathbb{Z}\\ |b_i-b_{i-1}|\ge l_i\quad(2\le i\le n) }} \left(\max_{1\le i\le n}|a_i-b_i|\right). $$$$$$



## 输入格式



第一行包含整数 $$$T$$$（$$$1 \le T \le 10^4$$$），表示测试用例数。接下来描述各测试用例。



每个测试用例的第一行包含整数 $$$n$$$（$$$2 \le n \le 10^5$$$），表示地雷数量。



第二行包含 $$$n$$$ 个整数 $$$a_1,a_2,\ldots,a_n$$$（$$$1\le a_i\le10^9$$$），其中 $$$a_i$$$ 为地雷 $$$i$$$ 的坐标。保证 $$$a_1\le a_2\le\cdots\le a_n$$$。



第三行包含 $$$n-1$$$ 个整数 $$$l_2,l_3,\dots,l_n$$$（$$$1 \le l_i \le 10^9$$$），其中 $$$l_i$$$ 是地雷 $$$i-1$$$ 和 $$$i$$$ 的测试位置之间的最小距离。



保证所有测试用例的 $$$n$$$ 之和不超过 $$$10^5$$$。



## 输出格式



对于每个测试用例，输出一个整数，表示最大测试误差的最小可能值。



## 样例说明



第一组样例中，选择 $$$b_1=1$$$ 和 $$$b_2=2$$$，最大误差为 $$$1$$$。若误差为 $$$0$$$，则必须有 $$$b_1=b_2=1$$$，这不满足距离要求。



第二组样例中，一种最优选择为 $$$b=[-4,7,15,10,8,22,13]$$$。所有距离要求均满足，最大误差为 $$$6$$$。
