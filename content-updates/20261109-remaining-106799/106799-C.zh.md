# 数组计数



VegiCat 给你两个整数 $$$n$$$ 和 $$$m$$$。考虑满足以下条件的整数数组 $$$a_1,a_2,\ldots,a_n$$$：



$$$$$$a_1=0,\qquad 0\le a_{i+1}-a_i\le 1\quad(1\le i \lt n).$$$$$$



令 $$$s_i=a_1+a_2+\ldots+a_i$$$ 表示 $$$a$$$ 的前缀和。VegiCat 还告诉你 $$$m$$$ 个位置的前缀和，即给出 $$$m$$$ 条形如 $$$s_{p_j}=v_j$$$（$$$1\le j\le m$$$）的限制。



计算满足全部限制的数组数量，对 $$$998244353$$$ 取模。如果不存在满足全部限制的数组，答案为 $$$0$$$。



## 输入格式



第一行包含整数 $$$T$$$（$$$1\le T\le 10^4$$$），表示测试用例数。接下来描述各测试用例。



每个测试用例的格式如下：



第一行包含两个整数 $$$n$$$ 和 $$$m$$$（$$$1\le n\le100$$$，$$$0\le m\le n$$$），分别表示数组长度和前缀和限制数量。



接下来 $$$m$$$ 行，第 $$$j$$$ 行包含两个整数 $$$p_j$$$ 和 $$$v_j$$$（$$$1\le p_j\le n$$$，$$$0\le v_j\le10^9$$$），表示数组前 $$$p_j$$$ 个元素之和必须等于 $$$v_j$$$。



位置 $$$p_j$$$ 按严格递增顺序给出。



## 输出格式



对于每个测试用例，输出一个整数，表示合法数组数量对 $$$998244353$$$ 取模的结果。



## 样例说明



没有前缀和限制时，恰好有 $$$2^{n-1}$$$ 个这样的数组，因为 $$$n-1$$$ 个相邻元素的差可以独立选择为 $$$0$$$ 或 $$$1$$$。



第二组样例中，满足 $$$s_3=1$$$ 的唯一数组为 $$$(0,0,1)$$$。



第三组样例中，$$$s_2=0$$$ 迫使 $$$a_2=0$$$，此后 $$$a_3$$$ 可以为 $$$0$$$ 或 $$$1$$$。



第四组样例中，合法数组为 $$$(0,1,1,1)$$$ 和 $$$(0,0,1,2)$$$。



第五组样例中，满足 $$$s_5=4$$$ 的数组为 $$$(0,0,1,1,2)$$$ 和 $$$(0,1,1,1,1)$$$。



第六组样例中，$$$s_2=0$$$ 迫使 $$$a_1=a_2=0$$$，因此 $$$s_5\le6$$$。限制 $$$s_5=10$$$ 不可能满足。
