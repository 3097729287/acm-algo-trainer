# 愤怒决斗



VegiCat 和 VegiDog 正在《杀戮尖塔》中进行一场特殊决斗。VegiCat 操纵观者 A，VegiDog 操纵观者 B。A 和 B 的基础攻击力分别为 $$$a$$$ 和 $$$b$$$，初始生命值分别为 $$$h_A$$$ 和 $$$h_B$$$。



每轮开始时，游戏会决定两名观者本轮的姿态。每人可以处于以下两种姿态之一：



- 普通：造成和承受的伤害均不变。

- 愤怒：造成和承受的伤害均翻倍。



每次攻击的初始伤害等于攻击者的基础攻击力。若攻击者处于愤怒姿态，伤害翻倍；若防御者也处于愤怒姿态，伤害再翻倍。因此，每轮伤害如下：



- 若双方均为普通姿态，A 对 B 造成 $$$a$$$ 点伤害，B 对 A 造成 $$$b$$$ 点伤害。

- 若恰好一人处于愤怒姿态，A 对 B 造成 $$$2a$$$ 点伤害，B 对 A 造成 $$$2b$$$ 点伤害。

- 若双方均处于愤怒姿态，A 对 B 造成 $$$4a$$$ 点伤害，B 对 A 造成 $$$4b$$$ 点伤害。



每轮双方同时攻击一次，生命值同时减少。即使本轮中有角色的生命值降到 $$$0$$$ 或以下，双方的攻击也都生效。每轮结束时，生命值小于等于 $$$0$$$ 的角色死亡。只要有角色死亡，战斗就立即结束；否则开始下一轮。基础攻击力始终不变，生命值不会恢复。



每轮姿态由游戏决定，而非由玩家选择。两名角色的姿态在每轮可以是任意组合。



只有 B 死亡而 A 仍然存活时，VegiCat 才获胜。如果双方在同一轮死亡，VegiCat 不算获胜。请判断：**无论双方姿态如何变化**，VegiCat 是否都能获胜。



## 输入格式



第一行包含整数 $$$T$$$（$$$1 \le T \le 10^5$$$），表示测试用例数。接下来描述各测试用例。



每个测试用例占一行，包含四个整数 $$$a$$$、$$$b$$$、$$$h_A$$$ 和 $$$h_B$$$（$$$1 \le a,b,h_A,h_B \le 10^{18}$$$），分别给出双方的基础攻击力和初始生命值。



## 输出格式



对于每个测试用例，如果无论双方姿态如何变化 VegiCat 都能获胜，输出 `YES`；否则输出 `NO`。每个答案单独占一行。



答案不区分大小写。例如 `yEs`、`yes`、`Yes` 和 `YES` 都会被视为肯定回答。



## 样例说明



第一份样例的第一组测试中，B 总会在第一轮死亡。A 在该轮最多承受 $$$4$$$ 点伤害，仍然存活。



第一份样例的第二组测试中，如果第一轮双方均为普通姿态，A 会获胜；如果第一轮双方均为愤怒姿态，两人都会死亡。因此答案为 `NO`。



第二份样例的第二组测试中，如果前 $$$4$$$ 轮双方均为普通姿态，剩余生命值分别为 $$$8$$$ 和 $$$1$$$。如果第 $$$5$$$ 轮双方均进入愤怒姿态，两人都会死亡，所以不能保证获胜。
