# 隐藏的顺序



**这是一道交互题。**



VegiCat 知道一个数组 $$$a_1,a_2,\ldots,a_n$$$，每个元素为 $$$0$$$、$$$1$$$ 或 $$$2$$$。他不愿告诉你具体数值，但允许你提问。每次询问选择两个下标 $$$i$$$ 和 $$$j$$$，VegiCat 会告诉你 $$$a_i \gt a_j$$$ 是否成立。



VegiCat 要求你按对应数组值的非递减顺序输出下标。也就是说，找到 $$$1,2,\ldots,n$$$ 的一个排列 $$$p_1,p_2,\ldots,p_n$$$，满足 $$$$$$ a_{p_1}\le a_{p_2}\le\cdots\le a_{p_n}. $$$$$$



每个测试用例最多允许 $$$2n-3$$$ 次询问。



**交互器具有自适应性。** 这意味着数组不会预先固定。交互器保证，始终至少存在一个元素属于 $$$\{0,1,2\}$$$ 的数组，与目前给出的所有回答一致。你最终输出的排列必须对**所有与全部回答一致的数组**都有效。



## 输入格式



第一行包含整数 $$$T$$$（$$$1\le T\le 250$$$），表示测试用例数。接下来描述各测试用例。



每个测试用例以一个整数 $$$n$$$（$$$2\le n\le 500$$$）开始，表示数组长度。



所有测试用例的 $$$n$$$ 之和不超过 $$$500$$$。



## 交互方式



进行询问时，按以下格式输出一行：



```text

? i j
```



其中 $$$1\le i,j\le n$$$。每次询问后读取一个整数：



- 若 $$$a_i \gt a_j$$$，返回 $$$1$$$；

- 若 $$$a_i\le a_j$$$，返回 $$$0$$$。



允许询问 $$$i=j$$$，也允许重复询问，这些都计入询问次数。



确定顺序后，按以下格式输出一行：



```text

! p_1 p_2 ... p_n
```



从 $$$1$$$ 到 $$$n$$$ 的每个下标都必须恰好出现一次。输出答案不计入询问次数。



如果答案正确，读取下一组的 $$$n$$$ 并继续；如果已经是最后一组，则结束程序。交互器不会在答案之后单独发送确认信息。



每次输出询问或答案后，都要输出换行并刷新输出缓冲区。可以使用：



- C/C++ 中的 `fflush(stdout)` 或 `cout.flush()`；

- Java 和 Kotlin 中的 `System.out.flush()`；

- Python 中的 `sys.stdout.flush()`。



如果询问不合法、超过询问次数上限或答案错误，将得到 **Wrong Answer** 判定。输出格式不符合要求也会得到 **Wrong Answer**。这些情况下，交互器直接结束，不会发送错误响应。



## 样例说明



第一组样例中，询问 ? 1 2 和 ? 2 3 都返回 $$$1$$$，因此 $$$a_1 \gt a_2 \gt a_3$$$，所以 $$$(3,2,1)$$$ 是正确答案。



第二组样例中，询问 ? 1 2 返回 $$$0$$$，因此 $$$a_1\le a_2$$$，所以 $$$(1,2)$$$ 是正确答案。
