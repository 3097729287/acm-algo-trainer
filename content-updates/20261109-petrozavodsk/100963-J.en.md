# Once Upon A Time

Problem J, Summer Camp, Petrozavodsk, 29 Aug 2007.

Original input file: `once.in`. Original output file: `once.out`. Time limit: 5 seconds.

## Problem Description

Once upon a time, an elderly man and an elderly woman lived together. One day, the man went to a mountain to hang glide, while the woman went to a river to shoot rapids in a canoe.

Looking down from the sky, the man saw the woman enjoying the rapids. He called out loudly, and she noticed him. Both enjoy acrobatic feats, so they decided to touch hands.

Because they are busy with their activities, each can stretch out a hand only periodically. The woman first stretches out her hand at time $n$, and then every $m$ time units. The man takes $k$ time units to approach her, and then stretches out his hand every $a$ time units. His first stretch is at time $k+a$.

Find the first time when they can touch hands.

For the sample, the following table shows their actions. They first touch hands at time $8$.

| Time | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Woman | - | - | Stretch | - | - | - | - | Stretch |
| Man | - | Approach | - | Stretch | - | Stretch | - | Stretch |

## Input Format

The input contains multiple test cases. Each consists of one line containing four nonnegative integers $n$, $m$, $a$ and $k$, separated by spaces. A line with $n=m=a=k=0$ terminates the input and must not be processed. All input integers are less than $2^{31}$.

## Output Format

For each test case, output the first time when they can touch hands, if possible. Otherwise output `Impossible`.

## Sample 1

### Input

```text
3 5 2 2
0 0 0 0
```

### Output

```text
8
```
