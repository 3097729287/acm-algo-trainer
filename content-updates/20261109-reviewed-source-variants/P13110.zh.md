# Draupnir

## 题目描述

Odin 有一些能自我复制的魔法戒指。每一枚“X 日戒指”从诞生之日起，每经过 X 天就会再产生一枚 X 日戒指。这些戒指共有六种：1 日戒指、2 日戒指，直到 6 日戒指。

例如，一枚在第 0 天诞生的 3 日戒指，在第 3 天之前不会产生新戒指；到了第 3 天，它会产生另一枚 3 日戒指。然后在第 6 天，这两枚戒指又会各自产生一枚 3 日戒指，以此类推。

你知道 Odin 在第 0 天之前没有戒指。第 0 天，一些戒指出现了。第 0 天结束时，对于每个 $1 \leqslant i \leqslant 6$，Odin 有 $R_i$ 枚 i 日戒指。你知道对所有 $i$ 都有 $0 \leqslant R_i \leqslant 100$，而且至少一个 $R_i$ 为正。

幸运的是，你还能使用神秘的知识之井。每次使用时，你可以得知从第 1 天到第 500 天（含两端）中某一天结束时，Odin 拥有的戒指总数。知识之井会将答案对 $2^{63}$ 取模后告诉你，因为它能容纳的信息也有限！此外，最多只能使用知识之井 W 次。

你的目标是确定第 0 天结束时每种戒指的数量，即求出每一个 $R_i$。

### 交互协议

这是一道交互题。

程序首先应读入一行两个整数 $\mathbf{T}$ 和 $\mathbf{W}$，分别表示测试用例数，以及每个测试用例允许使用知识之井的次数。接下来处理 $\mathbf{T}$ 个测试用例。

每个测试用例中，程序最多与评测器进行 $\mathbf{W} + 1$ 轮交互。其中，你可以进行至多 $\mathbf{W}$ 轮如下形式的交互：

* 程序输出一行，仅包含一个位于 1 到 500 之间（含两端）的整数 $\mathbf{D}$。
* 评测器返回一行一个整数，表示第 $\mathbf{D}$ 天结束时 Odin 拥有的戒指总数对 $2^{63}$ 取模后的值。若你输出的数据非法，例如数字超出范围或行格式错误，评测器会返回 -1。

完成上述 0 到 $\mathbf{W}$ 轮查询后，还必须进行最后一轮如下形式的交互：

* 程序输出一行六个整数 $\mathbf{R}_1$、$\mathbf{R}_2$、$\mathbf{R}_3$、$\mathbf{R}_4$、$\mathbf{R}_5$、$\mathbf{R}_6$，其中 $\mathbf{R}_i$ 表示第 0 天结束时 i 日戒指的数量。
* 评测器返回一行一个整数：若答案正确则返回 1；若答案错误或行格式错误，则返回 -1。

评测器由于非法数据或错误答案向你的输入流发送 -1 后，不会再发送任何内容。若程序收到 -1 后仍继续等待评测器，就会超时并得到 Time Limit Exceeded。你应及时结束程序，使其获得应有的 Wrong Answer，而不是由于等待造成的 Time Limit Exceeded。和通常情况一样，若超过内存限制或发生运行错误，会得到相应的评测结果。

## 提示

**交互示例**

这段交互对应测试集 1。假设在我们不知道的情况下，评测器已经决定 Odin 在第 0 天结束时，六种戒指各有一枚。

```
  t, w = readline_int_list()   // Reads 50 into t and 6 into w
  printline 3 to stdout        // Asks about day 3.
  flush stdout
  n = readline_int()           // Reads 15 into n.
  printline 1 to stdout        // Asks about day 1.
  flush stdout
  n = readline_int()           // Reads 7 into n.
  printline 1 1 1 3 0 0 to stdout
  flush stdout                 // We make a guess even though we could have
                               // queried the well up to four more times.
  verdict = readline_int()     // Reads -1 into verdict (judge has decided our
                               //   solution is incorrect)
  exit                         // Exits to avoid an ambiguous TLE error
```

注意，虽然猜测与已获得的查询信息相容，但它仍然错误，因为我们没有求出真正的各类戒指数量。

你可以使用题目专用测试工具，在本地或原平台测试程序。在本地测试时，需要让测试工具与你的程序并行运行；为此，可以使用原有的 [interactive runner](https://storage.googleapis.com/coding-competitions.appspot.com/interactive_runner.py)。具体用法见该脚本中的注释。

测试工具的使用说明写在工具自身的注释中，也鼓励你添加自己的测试数据。请注意，虽然测试工具旨在模拟评测系统，但它**不是**真正的评测系统，行为可能与实际评测器不同。

**数据范围**

- $1 \leq T \leq 50$。

**测试集 1（10 分，公开评测）**

- $W = 6$。

**测试集 2（21 分，隐藏评测）**
