# 已有题解与原题的知识点复核

本批补齐 35 道题的知识点：30 道来自已通过编译、示例与对照验证的既有题解，5 道来自本轮恢复的台北新竹原题。它们是人工复核的算法归类，不是原站官方标签；不估造官方难度，也不产生通过、经验或学习进度。

`review.json` 记录题目原身份、修改前完整记录摘要、标签和逐项依据。题解证据绑定本库 Markdown 文件的 SHA-256；原题证据绑定已收录 PDF 资源的 SHA-256。`applied.json` 记录实际应用结果。再次执行 `scripts/apply_reviewed_knowledge_20261108.py` 验证 35 项均已应用，不重复追加。

原站 `sourceTags` 继续保留。缺少原站标签时，界面读取现有 `knowledge_topic_review.json` 的复核结果，分类来源明确为 `reviewed-topic`，避免将中文标签误标为官方资料。题目身份、来源、个人状态及日期不变。
