# Nana Likes Polygons

Nana’s electronic pet, MACARON, enjoys moving around in the room. Nana wants to create a bounded area where MACARON can roam within.

The positions in the room can be represented using a two-dimensional coordinate system, and Nana provides a set of vertices on it. Nana likes polygons and wants to select a subset of vertices that can form a convex polygon as its endpoints. However, she also wants to ensure that the selected area is not too big.

Determine the minimum possible area of a convex polygon whose vertices are selected from the given set. If no such convex polygon exists, output $-1$.

## Input

The first line contains a single integer $T$ ($1\le T\le 10$), the number of test cases.

For each test case, the first line contains a single integer $n$ ($1\le n\le 100$), the number of given vertices.

The following $n$ lines each contain two integers. The $i$-th line contains $x_i,y_i$ ($-1000\le x_i,y_i\le 1000$), the coordinates of the $i$-th vertex.

## Output

For each test case, output $-1$ if no such convex polygon exists. Otherwise, output a single real number denoting the minimum possible area.

Let $a$ and $b$ denote the answer and your output, respectively. Your output is accepted if its absolute or relative error does not exceed $10^{-6}$. Formally,

$$
\frac{|a-b|}{\max(1,a)}\le 10^{-6}.
$$

## Note

In the first test case, choose $(2,2)$, $(-3,0)$, and $(0,2)$ as the vertices of a convex polygon with area $2$. This area is minimal.

In the second test case, no convex polygon can be formed by the three vertices.
