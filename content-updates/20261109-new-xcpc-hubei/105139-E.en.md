# Spicy or Grilled?

A regular programming contest lasts five hours, so preparing food for contestants during the contest is a significant task.

![Two burger sets](hubei-105139-E-1.jpg)

At the 20XX International Collegiate Programming Contest in Hubei Province, China, there were $n$ contestants. The host originally planned a Spicy Chicken Burger Set for each contestant, at a price of $a$ dollars per set. Some people, such as Walk Alone, could not tolerate spicy food, so the host prepared Grilled Chicken Burger Sets for them, at $b$ dollars per set. Before the contest, the host collected the number $x$ of contestants who wanted a Grilled Chicken Burger Set.

Walk Alone was too stupid and lazy to work out the total expenditure. Help him calculate it.

## Input

The first line contains an integer $T$ ($1\le T\le 10^4$), the number of test cases.

Each test case consists of four integers $n,x,a,b$ ($1\le n,a,b\le 10^4$, $0\le x\le n$), representing the total number of contestants, the number who want a grilled set, the price of a spicy set, and the price of a grilled set.

## Output

For each test case, output one integer denoting the total expenditure.

## Note

In the first test case, $400$ contestants choose spicy sets and $200$ choose grilled sets. The total is $400\times27+200\times26=16000$ dollars.
