# Points on the Number Axis B

Bob is playing a single-player game on the number axis.

Initially there are $n$ points. At each step, he selects two points, removes them, and adds their midpoint. The game ends when only one point remains. Formally, selecting $x_i,x_j$ adds the point at $\frac{x_i+x_j}{2}$.

Bob always randomly selects two adjacent points. Initially, point $i$ is adjacent to point $i+1$. When Bob adds a new point, it inherits the left neighbor of the selected left point and the right neighbor of the selected right point.

Find the expected position of the final point. The answer can be expressed as $\frac{p}{q}$; output $p\cdot q^{-1}\bmod998244353$.

## Input

The first line contains an integer $n$ ($1\le n\le10^6$).

The second line contains $n$ integers $x_i$ ($0\le x_1\le\cdots\le x_n<998244353$), describing the position of each point.

Two points may occupy the same position.

## Output

Output the answer modulo $998244353$.
