# Enchanted

In Minecraft, enchanting armor and weapons is one way to become stronger. Enchanted books play an important role.

![Enchanted book](hubei-105139-F-1.png)

The most important attribute of an enchanted book is its level: a higher level means a better book. Two books of the same level $l$ can be merged into one new book of level $l+1$. The old books disappear, and the merge costs $2^{l+1}$.

Steve has $n$ books numbered from $1$ to $n$. Initially, book $i$ has level $a_i$. Help him process these operations:

1. Given $l,r$ ($1\le l\le r\le n$), calculate the maximum level achievable by merging books numbered from $l$ through $r$.
2. Given $l,r$ ($1\le l\le r\le n$) and $k$, perform the following three steps for the calculation:
   - Merge the books numbered from $l$ through $r$ until all remaining books have different levels.
   - Add a new book of level $k$ to those remaining books.
   - Merge the books obtained in the preceding step, maximizing the number of merges.
   Output the total cost of the last step modulo $10^9+7$. After the calculation, the sequence is restored: this operation does not actually change it.
3. Given $pos,k$, change the level of the book numbered $pos$ to $k$.
4. Given $t$, restore the sequence to its state after operation $t$. If $t=0$, restore the initial sequence.

## Input

The only line contains five integers $n,m,A,p,q$ ($1\le n\le 10^6$, $1\le m\le 10^6$, $1\le A\le 19260817$, $1\le p\le4$, $1\le q\le30$).

To avoid a large input file, generate the actual input as follows. The function `rnd()` changes the current state and returns its new value:

```text
A ← (7A + 13) mod 19260817
return A
```

First generate $a_1,a_2,\ldots,a_n$ in order, setting $a_i\leftarrow\operatorname{rnd}()\bmod q+1$.

Then generate all operations in order. For each operation, first generate its type $opt\leftarrow\operatorname{rnd}()\bmod p+1$, and then generate its parameters according to its type:

- For operation 1, generate $L\leftarrow\operatorname{rnd}()\bmod n+1$, then $R\leftarrow\operatorname{rnd}()\bmod n+1$, and set $l\leftarrow\min(L,R)$, $r\leftarrow\max(L,R)$.
- For operation 2, generate $L\leftarrow\operatorname{rnd}()\bmod n+1$, then $R\leftarrow\operatorname{rnd}()\bmod n+1$, set $l\leftarrow\min(L,R)$, $r\leftarrow\max(L,R)$, and then generate $k\leftarrow\operatorname{rnd}()\bmod q+1$.
- For operation 3, generate $pos\leftarrow\operatorname{rnd}()\bmod n+1$, then $k\leftarrow\operatorname{rnd}()\bmod q+1$.
- For operation 4, generate $t\leftarrow\operatorname{rnd}()\bmod i$, where $i$ is the index of the current operation.

## Output

For each operation 1 or 2, output one line containing its answer modulo $10^9+7$.

## Note

The functions `max` and `min` return the maximum and minimum of their arguments, respectively.

In the first example, the initial levels are $[1,2,3,1,2,3]$. The ranges of the three operations are $[4,4]$, $[1,3]$, and $[4,5]$.
