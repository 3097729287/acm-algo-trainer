# Lili Likes Polygons

Lili 和 Nana 正在 Lili 家的后院除草。她们反复选取矩形区域，清除其中的全部杂草。

后院可以看作二维网格，每个方格的面积为一个单位。她们共进行了 $n$ 次操作。第 $i$ 次操作选定矩形的左、下、右、上边界 $l_i,b_i,r_i,t_i$，用割草机清除其中所有方格的杂草。这些矩形可以相互重叠。

用 $[l_i,r_i]\times[b_i,t_i]$ 表示包含端点的方格矩形。下图中选取的两个矩形分别为 $[1,5]\times[2,3]$ 和 $[2,3]\times[1,4]$。

![除草后的方格](hubei-105139-C-1.png)

全部操作结束后，裸露区域可能不连通，但边界都水平或竖直。因此，它会形成若干正交多边形，其中可能含有多边形孔洞；某些孔洞内部还可能存在裸露方格。详见样例与示意图。

现在，她们想在裸露方格上种植植物来恢复土地。Lili 喜欢多边形，尤其喜欢矩形。她们想选出若干互不重叠的矩形，恰好覆盖全部裸露方格，并在不同矩形中种植不同植物。

对于前面的示意图，一种可行方案为 $[1,1]\times[2,3]$、$[2,3]\times[1,4]$ 和 $[4,5]\times[2,3]$。

两个女孩玩累了，请求出恰好覆盖全部裸露方格所需的最少不重叠矩形数。

## 输入

第一行包含一个整数 $n$（$1\le n\le 300$），表示除草时选取的矩形数量。

接下来的 $n$ 行，每行包含四个整数 $l_i,b_i,r_i,t_i$（$1\le l_i,b_i,r_i,t_i\le 10^9$，$l_i\le r_i$，$b_i\le t_i$），依次表示第 $i$ 个矩形的左、下、右、上边界。

保证裸露区域边界（包括多边形孔洞）的顶点总数不超过 $2000$。

## 输出

输出一个整数，表示覆盖全部裸露方格所需的最少矩形数。

## 说明

原题第一组样例说明中的坐标区间存在排版错误。样例输入是由八个单位方格组成的环，可用四个不重叠矩形覆盖：左列、右列各一个矩形，再覆盖中间列上、下剩余的两个方格。原始 PDF 中的写法仍原样保留。

第二组样例可以选取 $[1,100]\times[1,100]$ 和 $[1,100]\times[501,600]$。

第三组样例可以选取 $[1,4]\times[1,1]$、$[1,5]\times[4,4]$、$[1,1]\times[2,3]$、$[4,4]\times[2,3]$ 和 $[4,4]\times[5,5]$。
