# LCMs

Walk Alone has a number axis containing only positive integers. Walking from the point at integer $a$ to the point at integer $b$ costs $\operatorname{lcm}(a,b)$, the least common multiple of $a,b$.

Because he hates the integer $1$, Walk Alone forbids anyone from moving to points at integers less than or equal to $1$.

Given $a,b$, calculate the minimum total cost of walking from $a$ to $b$.

## Input

There are $T$ ($1\le T\le1000$) test cases.

Each test case consists of one line containing two integers $a,b$ ($2\le a\le b\le10^7$), the starting and ending positions.

## Output

For each test case, output one integer denoting the minimum cost.

## Note

In the first test case, the path $3\to2\to4$ has cost $\operatorname{lcm}(3,2)+\operatorname{lcm}(2,4)=6+4=10$. This is the minimum possible cost.
