# Operator Precedence

Time limit: $1$ second. Memory limit: $1024$ MiB. Standard input and standard output.

Randias has a primary-school homework problem. Find an integer sequence $a$ of length $2n$, all of whose elements are nonzero, satisfying

$$
\begin{aligned}
&(a_1\times a_2)+(a_3\times a_4)+\cdots+(a_{2n-1}\times a_{2n})\\
&=a_1\times(a_2+a_3)\times(a_4+a_5)\times\cdots\times(a_{2n-2}+a_{2n-1})\times a_{2n}\ne 0.
\end{aligned}
$$

Equivalently,

$$
\sum_{i=1}^{n}a_{2i-1}a_{2i}=a_1a_{2n}\prod_{i=2}^{n}(a_{2i-2}+a_{2i-1})\ne 0.
$$

Randias knows how to solve it, but wants to test you. Can you solve it?

## Input

The first line contains the number of test cases $t$ ($1\leq t\leq 10^5$).

Each test case consists of one line containing an integer $n$ ($2\leq n\leq 10^5$).

The sum of $n$ over all test cases does not exceed $2\cdot 10^5$.

## Output

For each test case, output $2n$ integers $a_1,a_2,\ldots,a_{2n}$ on one line, with $1\leq |a_i|\leq 10^{10}$.

A solution always exists. If there are multiple valid solutions, output any one.
