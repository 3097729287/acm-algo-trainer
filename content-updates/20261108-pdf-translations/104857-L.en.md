# Information Spread

Time limit: $3$ seconds. Memory limit: $512$ MB. Standard input and standard output.

Mr. Ham's class has $n$ students numbered from $1$ to $n$. Initially, student $1$ learns a piece of information. The students then spread it according to a directed graph with $n$ vertices and $m$ edges. Each edge has a real weight $w\in[0,1]$.

The process is exactly the following pseudocode. Outgoing edges are processed in their input order.

```text
aware[1..n] = False
visited[1..n] = False

procedure DFS(u):
    if visited[u]:
        return
    visited[u] = True
    for (u, v, w) in outgoing edges of u, in input order:
        if aware[u] and not aware[v]:
            with probability w:
                aware[v] = True
        DFS(v)

procedure SPREAD():
    aware[1] = True
    DFS(1)
```

For every student $i$ with $1\leq i\leq n$, compute the probability that the student knows the information after this process; that is, the probability that `aware[i]` is `True`.

## Input

The first line contains $n,m$ ($3\leq n\leq10^5$, $n-1\leq m\leq3\cdot10^5$), the number of students and relationships.

Each of the next $m$ lines contains four integers $u_i,v_i,p_i,q_i$ ($1\leq u_i,v_i\leq n$, $0\leq p_i\leq q_i\leq10^5$, $q_i\ne0$), describing a directed edge from $u_i$ to $v_i$ with weight $w_i=p_i/q_i$.

There are no self-loops and at most one edge from any student $i$ to any student $j$. All students are reachable from student $1$ during the traversal.

## Output

Output $n$ lines. Line $i$ contains the probability that student $i$ knows the information, modulo $998244353$.

More precisely, the answer is a rational number $p/q$. Output $pq^{-1}\bmod M$, where $M=998244353$ and $q^{-1}$ satisfies $qq^{-1}\equiv1\pmod M$.

## Note

In the first example, the process visits the edges as follows:

- Student $1$ knows the information initially.
- On edge $(1,2,\frac12)$, student $2$ learns it with probability $\frac12$.
- Edge $(2,3,\frac12)$ is processed.
- On edge $(2,4,\frac12)$, student $4$ learns it with probability $\frac12\times\frac12=\frac14$.
- Edge $(4,3,1)$ is processed.

Student $3$ remains unaware in either of these cases:

- Student $2$ did not learn the information on edge $(1,2,\frac12)$.
- Student $2$ learned it on edge $(1,2,\frac12)$, but student $3$ did not learn it on edge $(2,3,\frac12)$ and student $4$ did not learn it on edge $(2,4,\frac12)$.

Therefore, the probability that student $3$ learns the information is $1-\frac12-\frac12\times\frac12\times\frac12=\frac38$.
