# Information Spread

时间限制：$3$ 秒。内存限制：$512$ MB。使用标准输入和标准输出。

Ham 老师的班上有 $n$ 名学生，从 $1$ 到 $n$ 编号。最初，学生 $1$ 得知了一条消息，随后学生们开始传播消息。学生关系用一张有 $n$ 个顶点、$m$ 条边的有向图表示，每条边的权值都是实数 $w\in[0,1]$。

传播过程严格按照以下伪代码执行。枚举某个顶点的出边时，必须遵循这些边在输入中出现的顺序。

```text
aware[1..n] = False
visited[1..n] = False

procedure DFS(u):
    if visited[u]:
        return
    visited[u] = True
    for (u, v, w) in outgoing edges of u, in input order:
        if aware[u] and not aware[v]:
            with probability w:
                aware[v] = True
        DFS(v)

procedure SPREAD():
    aware[1] = True
    DFS(1)
```

对于每个满足 $1\leq i\leq n$ 的学生 $i$，求过程结束后他得知消息的概率，也就是 `aware[i]` 为 `True` 的概率。

## 输入

第一行包含整数 $n,m$（$3\leq n\leq10^5$、$n-1\leq m\leq3\cdot10^5$），分别表示学生数和关系数。

接下来 $m$ 行，每行包含四个整数 $u_i,v_i,p_i,q_i$（$1\leq u_i,v_i\leq n$、$0\leq p_i\leq q_i\leq10^5$、$q_i\ne0$），表示一条从 $u_i$ 指向 $v_i$、权值为 $w_i=p_i/q_i$ 的有向边。

保证没有自环，任意学生 $i$ 到任意学生 $j$ 至多有一条边，并且遍历过程中能从学生 $1$ 到达所有学生。

## 输出

输出 $n$ 行。第 $i$ 行输出学生 $i$ 最终得知消息的概率，对 $998244353$ 取模。

具体地，答案可以表示为有理数 $p/q$。请输出 $pq^{-1}\bmod M$，其中 $M=998244353$，$q^{-1}$ 满足 $qq^{-1}\equiv1\pmod M$。

## 说明

第一组样例按以下顺序处理各条边：

- 学生 $1$ 最初就知道消息。
- 处理边 $(1,2,\frac12)$，学生 $2$ 以 $\frac12$ 的概率得知消息。
- 处理边 $(2,3,\frac12)$。
- 处理边 $(2,4,\frac12)$，学生 $4$ 得知消息的概率为 $\frac12\times\frac12=\frac14$。
- 处理边 $(4,3,1)$。

学生 $3$ 最终仍不知道消息，可能出现以下两种情况：

- 处理边 $(1,2,\frac12)$ 时，学生 $2$ 没有得知消息。
- 处理边 $(1,2,\frac12)$ 时学生 $2$ 得知了消息，但处理边 $(2,3,\frac12)$ 时学生 $3$ 没有得知消息，并且处理边 $(2,4,\frac12)$ 时学生 $4$ 也没有得知消息。

因此，学生 $3$ 得知消息的概率为 $1-\frac12-\frac12\times\frac12\times\frac12=\frac38$。
