# Python Program

时间限制：$1$ 秒。内存限制：$256$ MB。使用标准输入和标准输出。

请计算一个 Python 程序的输出。为简化问题，程序满足以下限制。

程序恰好有 $5$ 行，第一行为：

```python
ans=0
```

第二行和第三行的形式为：

```python
for i in range(a,b,c):
    for j in range(d,e,f):
```

这里 $i$ 和 $j$ 是两个不同的小写英文字母，分别作为循环变量。$a,b,c,d,e,f$ 中的每一个参数，都可以是不含前导零的整数，或者此前已经引入的循环变量。因此，$d,e,f$ 可以使用外层变量 $i$。步长参数 $c$、$f$ 可以省略其中任意一个，也可以同时省略；省略的步长默认为 $1$。

第四行位于内层循环中，形式为：

```python
        ans+=j
```

这里 $j$ 表示内层循环的变量，它也可以是字母 `j` 之外的其他小写字母。

第五行为：

```python
print(ans)
```

对于 $c\ne0$，Python 中以下循环的含义如下：

```python
for i in range(a,b,c):
```

- 若 $c>0$，$i$ 依次取值 $a,a+c,a+2c,\ldots,a+kc$，其中 $k$ 是满足 $a+kc<b$ 的最大整数。若 $a\geq b$，则循环不执行。
- 若 $c<0$，$i$ 依次取值 $a,a+c,a+2c,\ldots,a+kc$，其中 $k$ 是满足 $a+kc>b$ 的最大整数。若 $a\leq b$，则循环不执行。

## 输入

输入为程序的 $5$ 行代码。保证每行末尾没有多余空格，但输入文件末尾可能有额外换行。每个制表符都用 $4$ 个空格表示。

保证 $1\leq a,b,|c|,d,e,|f|\leq10^6$。

## 输出

输出一个整数，表示该程序的输出。

## 说明

第一组样例中，外层变量依次取值 $1,2$；对于其中每个值，内层变量都依次取值 $5,3$，因此答案为 $2\times(5+3)=16$。

你可以使用 Python 解释器测试这些程序。
