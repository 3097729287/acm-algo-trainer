# Python Program

Time limit: $1$ second. Memory limit: $256$ MB. Standard input and standard output.

Calculate the output of a Python program. To simplify the task, the program satisfies the following constraints.

The program has exactly $5$ lines. Its first line is:

```python
ans=0
```

The second and third lines have the form:

```python
for i in range(a,b,c):
    for j in range(d,e,f):
```

Here $i$ and $j$ are two distinct lowercase English letters used as loop variables. Each of $a,b,c,d,e,f$ is an integer without leading zeroes or a previously introduced loop variable. Thus $d,e,f$ may be $i$. The step argument $c$, $f$, or both may be omitted; an omitted step equals $1$.

The fourth line, inside the inner loop, has the form:

```python
        ans+=j
```

Here $j$ denotes the inner loop's variable, which can be a letter other than `j`.

The fifth line is:

```python
print(ans)
```

For $c\ne0$, Python interprets the following loop as described below:

```python
for i in range(a,b,c):
```

- If $c>0$, $i$ takes the values $a,a+c,a+2c,\ldots,a+kc$, where $k$ is the largest integer satisfying $a+kc<b$. If $a\geq b$, there are no iterations.
- If $c<0$, $i$ takes the values $a,a+c,a+2c,\ldots,a+kc$, where $k$ is the largest integer satisfying $a+kc>b$. If $a\leq b$, there are no iterations.

## Input

The input consists of the $5$ program lines. There are no trailing spaces on any line, but extra newlines may occur at the end of the input. Each tab is represented by $4$ spaces.

It is guaranteed that $1\leq a,b,|c|,d,e,|f|\leq10^6$.

## Output

Output one integer: the program's output.

## Note

In the first example, the outer variable takes values $1,2$. For each of them the inner variable takes values $5,3$, so the answer is $2\times(5+3)=16$.

You may test the programs with a Python interpreter.
