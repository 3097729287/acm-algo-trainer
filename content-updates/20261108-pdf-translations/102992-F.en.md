# Fireworks

Time limit: $1$ second. Memory limit: $256$ MB. Standard input and standard output.

Kotori is practicing making fireworks for the upcoming hanabi taikai [1]. It takes her $n$ minutes to make a single firework. Each firework has a probability of $p\times 10^{-4}$ to be perfect.

After finishing a firework, she can start making the next one, or spend $m$ minutes lighting all remaining fireworks made so far. If at least one of the lit fireworks is perfect, she will be happy and go to rest. Otherwise, she continues practicing. Find the minimum expected practicing time before she rests, assuming an optimal strategy.

Lighting all remaining fireworks always takes $m$ minutes, regardless of their number.

## Input

The first line contains the number of test cases $T$ ($1\leq T\leq 10^4$).

Each test case consists of one line containing three integers $n,m,p$ ($1\leq n,m\leq 10^9$, $1\leq p\leq 10^4$).

## Output

For each test case, output the minimum expected practicing time. The absolute or relative error must not exceed $10^{-4}$.

## Note

[1] Hanabi taikai is the romanization of the Japanese phrase “花火大會”, referring to a fireworks gathering.
