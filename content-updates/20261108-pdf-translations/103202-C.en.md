# Mean Streets of Gadgetzan

Time limit: $4$ seconds. Memory limit: $1024$ MB. Standard input and standard output.

Gadgetzan is a city of opportunity, but gangs rule its streets. Recently, robbers broke through the outer wall of the First Bank of Gadgetzan and stole crates of jade antiques. The bank's owner advertised in the Gadgetzan Gazette, offering arcane dust and unused decks as a reward for capturing the perpetrators.

As a famous detective, you collected witness testimonies such as:

- “Kazakus was not at home on the day of the robbery.”
- “If the courier was at home, then Kazakus was also at home.”
- “If Kazakus and the courier were at home that day, then Kazakus was not the robber.”

Every testimony has one of four forms:

- Unconditional affirmation: a proposition is true.
- Unconditional denial: a proposition is false.
- Conditional affirmation: if all the listed antecedent propositions are true, a specified consequent proposition is true.
- Conditional denial: if all the listed antecedent propositions are true, a specified consequent proposition is false.

Each proposition is either true or false. Determine whether the testimonies conflict. If they do not, assign a truth value to every proposition so that all testimonies hold.

## Input

The first line contains two integers $n,m$ ($1\leq n,m\leq10^6$), the number of testimonies and propositions. Propositions are numbered from $1$ to $m$.

Each of the next $n$ lines contains one testimony, with the following syntax:

- Unconditional affirmation: one integer, the proposition to affirm.
- Unconditional denial: one integer preceded by `!`, the proposition to deny.
- Conditional affirmation: a list of antecedent integers, followed by `->`, then the consequent integer to affirm.
- Conditional denial: a list of antecedent integers, followed by `->`, then the consequent integer preceded by `!`.

There is exactly one space between integers and on either side of `->`. There is no space after `!`.

The antecedents in any conditional testimony are distinct and do not include its consequent. The total number of antecedents in all conditional testimonies does not exceed $10^6$.

## Output

If the testimonies conflict, print `conflict` on one line. Otherwise, print $m$ characters without spaces. Each character is `T` for true or `F` for false, giving a valid assignment in proposition order. If there are multiple valid assignments, print any one.
