# Rubik's Rectangle

## Description

A new puzzle aiming to conquer the game market combines Rubik's Cube and Fifteen. Its board is an $H\times W$ frame with tiles bearing every number from $1$ to $H\cdot W$.

![Original starting board](/upload/images2/rubik1.png)

The only allowed move is to flip one entire row or one entire column. Flipping reverses the order of all elements in that row or column. The following illustration flips the third row:

![Original row-flip illustration](/upload/images2/rubik2.png)

Given a board with its tiles in an arbitrary order, determine a sequence of flips that puts it into the sorted order shown below, if possible.

![Original sorted target board](/upload/images2/rubik3.png)

## Input

The first line contains the number of test cases $T$. Each test case begins with an empty line.

The next line contains two space-separated integers $W,H$ ($1\le W,H\le100$), the width and height of the board, respectively. Each of the next $H$ lines contains $W$ space-separated integers, the numbers on the consecutive tiles.

## Output

Print answers in input order. For each test case, start with `POSSIBLE` or `IMPOSSIBLE`, depending on whether the puzzle can be solved.

If a solution exists, on the same line print the number of moves (possibly $0$), followed by their descriptions. Each description consists of `R` or `C`, indicating a row or column flip, concatenated with the index of that row or column.

Any solution using at most $10\cdot W\cdot H$ moves is accepted. Every test case is either solvable within this limit or impossible to solve at all.

## Limits

Time limit: $6$ seconds. Memory limit: $128$ MB.
