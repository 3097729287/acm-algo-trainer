# Rubik's Rectangle

## 题目描述

一款试图席卷游戏市场的新拼图结合了魔方与十五数码游戏。棋盘是一个 $H\times W$ 的矩形框架，其中放有编号从 $1$ 到 $H\cdot W$ 的所有方块。

![原稿初始棋盘](/upload/images2/rubik1.png)

唯一允许的操作是翻转完整的一行或一列。翻转会将该行或该列的所有元素顺序反转。下图展示了翻转第三行后的结果：

![原稿行翻转示意图](/upload/images2/rubik2.png)

给定一个方块按任意顺序排列的棋盘，请在可能的情况下构造一系列翻转操作，使棋盘变为下图所示的有序状态。

![原稿排序后的目标棋盘](/upload/images2/rubik3.png)

## 输入格式

第一行包含测试用例数 $T$。每个测试用例的描述前有一个空行。

接下来一行包含两个用空格分隔的整数 $W,H$（$1\le W,H\le100$），分别表示棋盘的宽度和高度。接下来 $H$ 行，每行包含 $W$ 个用空格分隔的整数，依次表示该行各方块上的数字。

## 输出格式

按照输入顺序输出各组答案。对于每组测试数据，若有解，先输出 `POSSIBLE`；否则输出 `IMPOSSIBLE`。

若有解，在同一行继续输出操作次数（可以为 $0$），然后依次输出每次操作的描述。每次操作由字符 `R` 或 `C` 与对应行号或列号直接拼接而成，分别表示翻转一行或一列。

任何操作次数不超过 $10\cdot W\cdot H$ 的合法方案都会被接受。对于每组数据，要么能在此次数限制内解决，要么根本无解。

## 限制

时间限制：$6$ 秒。内存限制：$128$ MB。
