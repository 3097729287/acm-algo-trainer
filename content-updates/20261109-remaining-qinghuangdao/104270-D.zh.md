# 魔法乘法



BaoBao 正在魔法书中学习一种作用于两个正整数的新二元运算，用 $$$\otimes$$$ 表示。书上说，运算结果是将两个整数的每一对数位相乘所得的结果依次拼接起来。



形式化地，设第一个整数为 $$$A = a_1a_2 \dots a_n$$$，其中 $$$a_i$$$ 表示 $$$A$$$ 的第 $$$i$$$ 个数位；第二个整数为 $$$B = b_1b_2 \dots b_m$$$，其中 $$$b_i$$$ 表示 $$$B$$$ 的第 $$$i$$$ 个数位。定义 $$$$$$A \otimes B = \sum\limits_{i=1}^n\sum\limits_{j=1}^m a_ib_j = a_1b_1 + a_1b_2 + \dots + a_1b_m + a_2b_1 + \dots + a_nb_m$$$$$$ 请注意，$$$a_ib_j$$$ 的结果被视为**字符串**：如果 $$$a_ib_j \gt 0$$$，没有前导零；如果 $$$a_ib_j = 0$$$，则恰好包含一个字符 '0'。它不是通常意义上的整数。这里的求和表示**字符串拼接**，也不是通常的加法。



例如，23 $$$\otimes$$$ 45 = 8101215，因为 $$$8=2 \times 4$$$、$$$10=2 \times 5$$$、$$$12=3 \times 4$$$，且 $$$15=3 \times 5$$$。



聪明的 BaoBao 很快掌握了 $$$\otimes$$$ 的逆运算。现在，他给出一次 $$$\otimes$$$ 运算的结果以及两个原整数各自的位数。请帮助他还原两个原整数 $$$A$$$ 和 $$$B$$$。



## 输入格式



有多组测试数据。输入第一行包含一个整数 $$$T$$$，表示测试用例数。对于每个测试用例：



第一行包含两个正整数 $$$n$$$ 和 $$$m$$$（$$$1 \le n, m \le 2 \times 10^5$$$），其中 $$$n$$$ 表示 $$$A$$$ 的长度，$$$m$$$ 表示 $$$B$$$ 的长度。整数的长度是将它写成无前导零的十进制字符串后的长度。



第二行只包含一个无前导零的正整数 $$$C$$$，表示 $$$A \otimes B$$$ 的结果。$$$C$$$ 的长度不超过 $$$2 \times 10^5$$$。



保证所有测试用例中 $$$C$$$ 的长度之和不超过 $$$2 \times 10^6$$$。



## 输出格式



对于每个测试用例，输出一行。



如果存在满足 $$$A \otimes B = C$$$ 的 $$$A$$$ 和 $$$B$$$，在一行中输出这两个整数 $$$A$$$ 和 $$$B$$$，用一个空格分隔。注意，$$$A$$$ 和 $$$B$$$ 必须是无前导零的正整数，$$$A$$$ 的长度必须恰好为 $$$n$$$，$$$B$$$ 的长度必须恰好为 $$$m$$$。



如果有多个合法答案，选择 $$$A$$$ 最小的答案；如果仍有多个答案，选择其中 $$$B$$$ 最小的答案。



如果不存在这样的 $$$A$$$ 和 $$$B$$$，单独输出一行 "Impossible"（不含引号）。
