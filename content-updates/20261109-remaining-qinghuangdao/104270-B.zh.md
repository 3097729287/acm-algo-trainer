# Kawa 考试



BaoBao 正在参加一场 Kawa 编程语言的在线考试，考试包含 *n* 道单项选择题。考试并不容易，因为每题都有 10$^{5}$ 个选项，而 BaoBao 必须从中选择唯一正确的选项！不过不用担心，作为著名项目 *open-kdk* 的活跃贡献者，BaoBao 知道所有题目的正确答案。



虽然 BaoBao 精通 Kawa，但考试系统的开发者显然不擅长软件工程。考试系统中有 *m* 个缺陷，第 *i* 个缺陷可以用一对数（*u*$_{i}$，*v*$_{i}$）描述：BaoBao 必须为第 *u*$_{i}$ 题和第 *v*$_{i}$ 题选择相同的选项，即使这个选项是错误的也必须如此！



时间有限，考试还得继续。开发者只来得及修复一个缺陷。现在，对于所有 1 ≤ *i* ≤ *m*，他们想知道：如果修复第 *i* 个缺陷，BaoBao 最多能够答对多少道题？请编写程序解决这个问题，帮助开发者选择要修复的缺陷。



## 输入格式



有多组测试数据。输入第一行包含一个整数 *T*，表示测试用例数。对于每个测试用例：



第一行包含两个整数 *n* 和 *m*（1 ≤ *n* ≤ 10$^{5}$，1 ≤ *m* ≤ 10$^{5}$），分别表示题目数量和缺陷数量。



第二行包含 *n* 个整数 *a*$_{1}$、*a*$_{2}$、...、*a*$_{n}$（1 ≤ *a*$_{i}$ ≤ 10$^{5}$），其中 *a*$_{i}$ 表示第 *i* 题的正确选项。



接下来 *m* 行，第 *i* 行包含两个整数 *u*$_{i}$ 和 *v*$_{i}$（1 ≤ *u*$_{i}$，*v*$_{i}$ ≤ *n*），描述第 *i* 个缺陷。



保证所有测试用例的 *n* 之和与 *m* 之和均不超过 10$^{6}$。



## 输出格式



对于每个测试用例，在一行中输出 *m* 个以空格分隔的整数 *c*$_{1}$、*c*$_{2}$、...、*c*$_{m}$，其中 *c*$_{i}$ 表示修复第 *i* 个缺陷后，BaoBao 最多能够答对的题目数。



请不要在每行末尾输出多余的空格，否则可能被判为错误！



## 样例说明



下表解释了第一组样例。



- “可选方案”列给出 BaoBao 对各题选择的一组可能选项，按照这组方案作答可以使答对的题目数最多；
- “答对题数”列给出采用“可选方案”中的选项时答对的题目数。



| **缺陷编号** | **可选方案** | **答对题数** |
| --- | --- | --- |
| 1 | (1, 2, 1, 2, 1, 1, 1) | 6 |
| 2 | (2, 2, 1, 2, 1, 1, 1) | 5 |
| 3 | (1, 1, 1, 2, 1, 1, 1) | 5 |
| 4 | (1, 1, 1, 1, 1, 2, 1) | 5 |
| 5 | (1, 1, 1, 1, 1, 1, 1) | 4 |



对于第二组样例，无论修复哪个缺陷，BaoBao 都必须为三道题选择相同的选项。由于每道题的正确答案不同，他最多只能答对 1 道题。



对于第三组样例，即使开发者修复第一个缺陷，第二个缺陷仍然生效，所以 BaoBao 仍必须为这两道题选择相同的选项。修复第二个缺陷时也是如此。
