# 空投



PUBG 是一款多人在线大逃杀游戏。游戏中，最多一百名玩家跳伞到一座岛上，搜集武器和装备，在避免自己被击杀的同时击杀其他玩家。空投是游戏中的重要元素，因为它们往往带有强大的武器或大量补给，能够帮助玩家生存。



![](https://espresso.codeforces.com/ebaf063f56f45e8a482a0e55de21436109ff839a.png) *游戏中的空投（？）*



将游戏战场视为二维平面。一个空投刚刚落在点（*x*$_{0}$，*y*$_{0}$），其中 *x*$_{0}$ 和 *y*$_{0}$ 都是整数。战场上的全部 *n* 名玩家开始按以下规则向空投移动，其中（*x*$_{i}$，*y*$_{i}$）表示第 *i* 名玩家的初始位置，*x*$_{i}$ 和 *y*$_{i}$ 都是整数：



- 如果一名存活玩家在当前时间单位开始时不位于（*x*$_{0}$，*y*$_{0}$），他将开始下一次移动。
  - 假设他当前位于点（*x*，*y*），他会考虑四个点：（*x*，*y* - 1）、（*x*，*y* + 1）、（*x* - 1，*y*）和（*x* + 1，*y*）。
  - 他会从中选择到空投（*x*$_{0}$，*y*$_{0}$）的曼哈顿距离最小的点，作为下一次移动的目的地。两点（*x*$_{a}$，*y*$_{a}$）和（*x*$_{b}$，*y*$_{b}$）之间的曼哈顿距离定义为 |*x*$_{a}$ - *x*$_{b}$| + |*y*$_{a}$ - *y*$_{b}$|。
  - 如果有两个或更多候选点到空投的曼哈顿距离相同，则按以下优先级决定：（*x*，*y* - 1）优先级最高，其次是（*x*，*y* + 1），再次是（*x* - 1，*y*），最后是（*x* + 1，*y*）。
  - 在当前时间单位结束时，他到达目的地。
- 如果一名存活玩家在当前时间单位开始时已经位于（*x*$_{0}$，*y*$_{0}$），他会继续收集空投里的补给，留在（*x*$_{0}$，*y*$_{0}$）。



但战斗很残酷，所有玩家都安全到达空投几乎是不可能的。如果两名或更多玩家在空投（*x*$_{0}$，*y*$_{0}$）以外的点（*x*'，*y*'）相遇，且 *x*' 和 *y*' 都是整数，他们就会互相战斗，全部被淘汰，没有人能存活。



BaoBao 是这款游戏的忠实玩家，他对最终成功到达空投的玩家数量很感兴趣，但不知道 *x*$_{0}$ 的值。给定 *y*$_{0}$ 和每名玩家的初始位置，请帮助他计算在所有 ![](https://espresso.codeforces.com/c17a977908181379d33a56edeaa16de87288ae4a.png) 中，成功到达空投的玩家数量的最小值与最大值。其中 ![](https://espresso.codeforces.com/b719c7ce5a7442a3bf64a8fa268fc460dcd2f3a3.png) 表示整数集合；注意 *x*$_{0}$ 可以为正数、零或负数。



## 输入格式



有多组测试数据。输入第一行包含一个整数 *T*，表示测试用例数。对于每个测试用例：



第一行包含两个整数 *n* 和 *y*$_{0}$（1 ≤ *n* ≤ 10$^{5}$，1 ≤ *y*$_{0}$ ≤ 10$^{5}$），分别表示玩家数量和空投的 *y* 坐标。



接下来 *n* 行，第 *i* 行包含两个整数 *x*$_{i}$ 和 *y*$_{i}$（1 ≤ *x*$_{i}$，*y*$_{i}$ ≤ 10$^{5}$），表示第 *i* 名玩家的初始位置。



保证所有测试用例的 *n* 之和不超过 10$^{6}$，并且同一个测试用例中任意两名玩家的初始位置不同。



## 输出格式



对于每个测试用例，在一行中输出两个以单个空格分隔的整数 ![](https://espresso.codeforces.com/40a5c62ab8b19d8cbb78f0318250c2eeb951c253.png) 和 ![](https://espresso.codeforces.com/8b9278571945da66a9a4ccafc20103f266f514ef.png)。![](https://espresso.codeforces.com/40a5c62ab8b19d8cbb78f0318250c2eeb951c253.png) 表示成功到达空投的玩家数量的最小值，![](https://espresso.codeforces.com/8b9278571945da66a9a4ccafc20103f266f514ef.png) 表示最大值。
