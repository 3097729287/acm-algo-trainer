# 植物大战僵尸



BaoBao 和 DreamGrid 正在玩*植物大战僵尸*。游戏中，DreamGrid 种植植物，保护花园免受 BaoBao 的僵尸攻击。



![](https://espresso.codeforces.com/67cb1bf92680e3419c15e3730a37bbb3c42768e5.png) *植物大战僵尸（？）* *（图片来自 pixiv，作品 ID：21790160；画师：socha）*



DreamGrid 的花园里有 $$$n$$$ 棵植物，排成一行。从西向东，植物编号为 1 到 $$$n$$$，第 $$$i$$$ 棵植物位于 DreamGrid 房子以东 $$$i$$$ 米处。第 $$$i$$$ 棵植物的防御值为 $$$d_i$$$，生长速度为 $$$a_i$$$。初始时，对于所有 $$$1 \le i \le n$$$，都有 $$$d_i = 0$$$。



DreamGrid 用机器人给植物浇水。机器人最初位于他的房子里。在每一步浇水操作中，DreamGrid 选择一个方向（东或西），机器人沿该方向恰好移动 1 米。移动后，如果机器人所在位置有第 $$$i$$$ 棵植物，它就给这棵植物浇水，使 $$$d_i$$$ 增加 $$$a_i$$$。由于机器人携带的水有限，最多只能执行 $$$m$$$ 步。



花园的防御值定义为 $$$\min\{d_i | 1 \le i \le n\}$$$。DreamGrid 需要你帮助他最大化花园的防御值，从而赢得游戏。



请注意：



- 机器人每次给植物浇水前都必须先移动；
- 机器人可以向东走到距离房子超过 $$$n$$$ 米的位置，也可以返回房子，甚至可以走到房子以西。



## 输入格式



有多组测试数据。输入第一行包含一个整数 $$$T$$$，表示测试用例数。对于每个测试用例：



第一行包含两个整数 $$$n$$$ 和 $$$m$$$（$$$2 \le n \le 10^5$$$，$$$0 \le m \le 10^{12}$$$），分别表示植物数量和机器人最多能走的步数。



第二行包含 $$$n$$$ 个整数 $$$a_1, a_2, ... , a_n$$$（$$$1 \le a_i \le 10^5$$$），其中 $$$a_i$$$ 表示第 $$$i$$$ 棵植物的生长速度。



保证所有测试用例的 $$$n$$$ 之和不超过 $$$10^6$$$。



## 输出格式



对于每个测试用例，在一行中输出一个整数，表示 DreamGrid 能得到的最大花园防御值。



## 样例说明



以下说明中，'E' 表示机器人从当前位置向东恰好移动 1 米，'W' 表示从当前位置向西恰好移动 1 米。



对于第一组样例，一种可行的方向序列为 {E, E, W, E, E, W, E, E}，浇水后有 $$$d = \{6,6,12,6\}$$$。



对于第二组样例，一种可行的方向序列为 {E, E, E, E, W, E, W, E, W}，浇水后有 $$$d = \{10, 10, 4\}$$$。
