# 函数与函数



如果定义 $$$f(0) = 1, f(1) = 0, f(4) = 1, f(8) = 2, f(16) = 1, \dots$$$，你知道函数 $$$f$$$ 的含义吗？



实际上，$$$f(x)$$$ 计算的是 $$$x$$$ 的各个数位中封闭区域的总数。下表给出了每个数位包含的封闭区域数量：



| **数位** | **封闭区域数** | **数位** | **封闭区域数** |
| --- | --- | --- | --- |
| 0 | 1 | 5 | 0 |
| 1 | 0 | 6 | 1 |
| 2 | 0 | 7 | 0 |
| 3 | 0 | 8 | 2 |
| 4 | 1 | 9 | 1 |



例如，$$$f(1234) = 0 + 0 + 0 + 1 = 1$$$，且 $$$f(5678) = 0 + 1 + 0 + 2 = 3$$$。



现在用以下递推式定义函数 $$$g$$$：$$$$$$\begin{cases} g^0(x) = x \\ g^k(x) = f(g^{k-1}(x)) & \text{if } k \ge 1 \end{cases}$$$$$$



例如，$$$g^2(1234) = f(f(1234)) = f(1) = 0$$$，且 $$$g^2(5678) = f(f(5678)) = f(3) = 0$$$。



给定两个整数 $$$x$$$ 和 $$$k$$$，请计算 $$$g^k(x)$$$。



## 输入格式



有多组测试数据。输入第一行包含一个整数 $$$T$$$（约为 $$$10^5$$$），表示测试用例数。对于每个测试用例：



唯一一行包含两个整数 $$$x$$$ 和 $$$k$$$（$$$0 \le x, k \le 10^9$$$）。正整数没有前导零，零恰好用一个字符 '0' 表示。



## 输出格式



对于每个测试用例，在一行中输出一个整数，表示 $$$g^k(x)$$$ 的值。
