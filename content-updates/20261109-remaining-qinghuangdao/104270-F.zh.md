# 骑士锦标赛



Gridland 的国王 DreamGrid 正在举办骑士锦标赛。共有 $$$n$$$ 名骑士参加，编号为 1 到 $$$n$$$。比赛规则如下：



- 锦标赛包含 $$$k$$$ 轮。每轮包含若干场决斗，每场决斗恰好由两名骑士参加。
- 每名骑士在每轮都必须恰好参加一场决斗。
- 在全部 $$$k$$$ 轮中，任意一对骑士至多交手一次。
- 设 $$$1 \le i, j \le k$$$、$$$i \ne j$$$，且 $$$1 \le a, b, c, d \le n$$$，其中 $$$a, b, c, d$$$ 两两不同。如果
  - 骑士 $$$a$$$ 和骑士 $$$b$$$ 在第 $$$i$$$ 轮交手，并且
  - 骑士 $$$c$$$ 和骑士 $$$d$$$ 在第 $$$i$$$ 轮交手，并且
  - 骑士 $$$a$$$ 和骑士 $$$c$$$ 在第 $$$j$$$ 轮交手，
  那么骑士 $$$b$$$ 必须和骑士 $$$d$$$ 在第 $$$j$$$ 轮交手。



作为 DreamGrid 的将军，你需要编写程序，安排全部 $$$k$$$ 轮中的所有决斗，使安排满足上述规则。



## 输入格式



有多组测试数据。输入第一行包含一个整数 $$$T$$$，表示测试用例数。对于每个测试用例：



唯一一行包含两个整数 $$$n$$$ 和 $$$k$$$（$$$1 \le n, k \le 1000$$$），分别表示参赛骑士数量和比赛轮数。



保证所有测试用例的 $$$n$$$ 之和与 $$$k$$$ 之和均不超过 5000。



## 输出格式



对于每个测试用例：



- 如果存在合法安排，输出 $$$k$$$ 行。在第 $$$i$$$ 行输出 $$$n$$$ 个用单个空格分隔的整数 $$$c_{i, 1}, c_{i, 2}, \dots, c_{i, n}$$$，表示在第 $$$i$$$ 轮，对于所有 $$$1 \le j \le n$$$，骑士 $$$j$$$ 与骑士 $$$c_{i, j}$$$ 交手。
  如果有多个合法答案，请输出字典序最小的答案。



  对于两个答案 $$$A$$$ 和 $$$B$$$，令 $$$a_{i, j}$$$ 表示答案 $$$A$$$ 中第 $$$i$$$ 行的第 $$$j$$$ 个整数，$$$b_{i, j}$$$ 表示答案 $$$B$$$ 中第 $$$i$$$ 行的第 $$$j$$$ 个整数。如果存在整数 $$$p$$$（$$$1 \le p \le k$$$）和 $$$q$$$（$$$1 \le q \le n$$$），满足以下条件，则称答案 $$$A$$$ 的字典序小于答案 $$$B$$$：



  - 对于所有 $$$1 \le i \lt p$$$ 和 $$$1 \le j \le n$$$，都有 $$$a_{i, j} = b_{i, j}$$$；并且
  - 对于所有 $$$1 \le j \lt q$$$，都有 $$$a_{p, j} = b_{p, j}$$$，且 $$$a_{p, q} \lt b_{p, q}$$$。
- 如果不存在合法安排，单独输出一行 "Impossible"（不含引号）。



请不要在每行末尾输出多余的空格，否则可能被判为错误！
