# 子环图



给定一个有 *n*（*n* ≥ 3）个顶点和 *m* 条边的无向简单图，顶点编号为 1 到 *n*。如果可以向图中添加非负条数的边，使整个图恰好成为一个包含 *n* 个顶点的简单环，就称它为“子环图”。



给定两个整数 *n* 和 *m*，请计算有 *n* 个顶点和 *m* 条边的不同子环图数量。答案可能很大，请输出答案对 10$^{9}$ + 7 取模的结果。



相关定义如下：



- 简单图是没有自环和重边的图；
- 包含 *n*（*n* ≥ 3）个顶点的简单环，是一个有 *n* 个顶点、*n* 条边且每个顶点度数均为 2 的连通无向简单图；
- 两个有 *n* 个顶点和 *m* 条边的无向简单图不同，当且仅当它们的边集不同；
- 令 *u* < *v*，用（*u*，*v*）表示连接顶点 *u* 和 *v* 的无向边。如果 *u*$_{1}$ ≠ *u*$_{2}$ 或 *v*$_{1}$ ≠ *v*$_{2}$，则无向边（*u*$_{1}$，*v*$_{1}$）与（*u*$_{2}$，*v*$_{2}$）不同。



## 输入格式



有多组测试数据。输入第一行包含一个整数 *T*（约为 2 × 10$^{4}$），表示测试用例数。对于每个测试用例：



唯一一行包含两个整数 *n* 和 *m*（3 ≤ *n* ≤ 10$^{5}$，![](https://espresso.codeforces.com/8ea7e8d4963d7e2e692b960f3208e1550d376981.png)），分别表示图的顶点数和边数。



保证所有测试用例的 *n* 之和不超过 3 × 10$^{7}$。



## 输出格式



对于每个测试用例，在一行中输出一个整数，表示有 *n* 个顶点和 *m* 条边的不同子环图数量对 10$^{9}$ + 7 取模的结果。
