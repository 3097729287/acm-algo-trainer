# 修复画作



DreamGrid 有一条包含 $$$n$$$ 个连续格子的纸带，他在其中一些格子里画了漂亮的图案。不幸的是，调皮的室友 BaoBao 趁他不在家，在另一些格子里画了其他图案。现在，DreamGrid 必须擦掉 BaoBao 的图案，同时不能破坏自己的图案。



将格子从左到右编号为 1 到 $$$n$$$。每个格子要么有 DreamGrid 的图案，要么有 BaoBao 的图案，要么为空。



每次操作，DreamGrid 可以选择两个整数 $$$l$$$ 和 $$$r$$$（每次选择的整数可以不同），满足：



- $$$1 \le l \le r \le n$$$；并且
- 对于所有 $$$l \le i \le r$$$，第 $$$i$$$ 个格子要么有 BaoBao 的图案，要么为空，



然后对于所有 $$$l \le i \le r$$$，将第 $$$i$$$ 个格子变为空格。



恰好执行 $$$m$$$ 次上述操作后，将所有含有 BaoBao 图案的格子变为空格，共有多少种方案？答案可能很大，请输出答案对 $$$10^9 + 7$$$ 取模的结果。



设 $$$\{(a_1, b_1), (a_2, b_2), \dots (a_m, b_m)\}$$$ 是一个合法的擦除序列（$$$1 \le a_i \le b_i \le n$$$），其中 $$$(a_i, b_i)$$$ 表示 DreamGrid 在第 $$$i$$$ 次操作中选择整数 $$$a_i$$$ 和 $$$b_i$$$。设 $$$\{(c_1, d_1), (c_2, d_2), \dots, (c_m, d_m)\}$$$ 是另一个合法的擦除序列（$$$1 \le c_i \le d_i \le n$$$），其中 $$$(c_i, d_i)$$$ 表示 DreamGrid 在第 $$$i$$$ 次操作中选择整数 $$$c_i$$$ 和 $$$d_i$$$。如果存在整数 $$$k$$$（$$$1 \le k \le m$$$），使 $$$a_k \ne c_k$$$ 或 $$$b_k \ne d_k$$$，则认为两个序列不同。



## 输入格式



有多组测试数据。输入第一行包含一个整数 $$$T$$$（$$$1 \le T \le 1000$$$），表示测试用例数。对于每个测试用例：



第一行包含两个整数 $$$n$$$ 和 $$$m$$$（$$$1 \le n \le 100$$$，$$$1 \le m \le 10^9$$$），分别表示格子数量和操作次数。



第二行包含 $$$n$$$ 个整数 $$$a_i$$$（$$$a_i \in \{0, 1, 2\}$$$）。



- 如果 $$$a_i = 0$$$，则第 $$$i$$$ 个格子为空。
- 如果 $$$a_i = 1$$$，则第 $$$i$$$ 个格子有 DreamGrid 的图案。
- 如果 $$$a_i = 2$$$，则第 $$$i$$$ 个格子有 BaoBao 的图案。



保证至多有 50 个测试用例满足 $$$n \gt 50$$$。



## 输出格式



对于每个测试用例，在一行中输出方案数对 $$$10^9 + 7$$$ 取模的结果。
