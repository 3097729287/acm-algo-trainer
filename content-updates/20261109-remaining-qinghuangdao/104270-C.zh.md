# 翻转序列



DreamGrid 刚刚从虚拟机中找到了两个二进制序列 $$$s_1, s_2, \dots, s_n$$$ 和 $$$t_1, t_2, \dots, t_n$$$（对于所有 $$$1 \le i \le n$$$，均有 $$$s_i, t_i \in \{0, 1\}$$$）！他希望恰好执行两次下述操作，使两次操作后对于所有 $$$1 \le i \le n$$$ 都有 $$$s_i = t_i$$$。



操作如下：选择两个整数 $$$l$$$ 和 $$$r$$$（$$$1 \le l \le r \le n$$$），对于所有 $$$l \le i \le r$$$，将 $$$s_i$$$ 改为 $$$(1 - s_i)$$$。



DreamGrid 想知道有多少种满足要求的操作方案。



我们用以下规则判断两种方案是否不同：



- 设 $$$A = (a_1, a_2, a_3, a_4)$$$，其中 $$$1 \le a_1 \le a_2 \le n, 1 \le a_3 \le a_4 \le n$$$，是一对合法操作，表示 DreamGrid 在第一次操作中选择整数 $$$a_1$$$、$$$a_2$$$，在第二次操作中选择整数 $$$a_3$$$、$$$a_4$$$；
- 设 $$$B = (b_1, b_2, b_3, b_4)$$$，其中 $$$1 \le b_1 \le b_2 \le n, 1 \le b_3 \le b_4 \le n$$$，是另一对合法操作，表示 DreamGrid 在第一次操作中选择整数 $$$b_1$$$、$$$b_2$$$，在第二次操作中选择整数 $$$b_3$$$、$$$b_4$$$。
- 如果存在整数 $$$k$$$（$$$1 \le k \le 4$$$）使 $$$a_k \ne b_k$$$，则认为 $$$A$$$ 与 $$$B$$$ 不同。



## 输入格式



有多组测试数据。输入第一行包含一个整数 $$$T$$$，表示测试用例数。对于每个测试用例：



第一行包含一个整数 $$$n$$$（$$$1 \le n \le 10^6$$$），表示两个二进制序列的长度。



第二行包含长度为 $$$n$$$ 的字符串 $$$s_1s_2\dots s_n$$$（$$$s_i \in \{\text{'0'}, \text{'1'}\}$$$），表示第一个二进制序列。



第三行包含长度为 $$$n$$$ 的字符串 $$$t_1t_2\dots t_n$$$（$$$t_i \in \{\text{'0'}, \text{'1'}\}$$$），表示第二个二进制序列。



保证所有测试用例的 $$$n$$$ 之和不超过 $$$10^7$$$。



## 输出格式



对于每个测试用例，输出一个整数，表示答案。



## 样例说明



对于第二组样例，有两对合法操作：$$$(1, 1, 2, 2)$$$ 和 $$$(2, 2, 1, 1)$$$。



对于第三组样例，有六对合法操作：$$$(2, 3, 5, 5)$$$、$$$(5, 5, 2, 3)$$$、$$$(2, 5, 4, 4)$$$、$$$(4, 4, 2, 5)$$$、$$$(2, 4, 4, 5)$$$ 和 $$$(4, 5, 2, 4)$$$。
