# A Simple Math Problem

## Description

Huanhuan challenges you to a simple math problem.

Define $F(x)$ as the sum of the decimal digits of $x$.

For example: $F(123)=1+2+3=6$, $F(700)=7+0+0=7$.

Huanhuan wants you to calculate the sum of $F(j)$ for every pair $i,j$ that satisfies $1\le j\le i\le n$ and for which $i,j$ are coprime.

More formally, calculate

$$
\sum_{i=1}^{n}\sum_{j=1}^{i}[\gcd(j,i)=1]F(j).
$$

## Input

There is only one test case, containing a single integer $n$ ($1\le n\le10^5$).

## Output

Print one integer, the answer to

$$
\sum_{i=1}^{n}\sum_{j=1}^{i}[\gcd(j,i)=1]F(j).
$$

## Sample

### Input

```text
3
```

### Output

```text
5
```

## Limits

C/C++/Rust/Pascal: $1$ second, $128$ MB. Other languages: $2$ seconds, $256$ MB.
