# 孤星



*倘若千年万载之后，我们的后代已航行于群星之间，他们必将高颂她的名字。*



为了揭开泰拉“虚假天空”的秘密，克丽斯腾建造了一座空间站。



空间站可以用一棵包含 $$$n$$$ 个结点的树表示，结点编号为 $$$1$$$ 到 $$$n$$$。空间站开始发射后，能量逐渐增长。初始时，结点 $$$i$$$ 有 $$$b_i$$$ 单位能量。每天开始时，结点 $$$i$$$ 的能量增加 $$$a_i$$$。



纯净水是生命必需品。作为水精灵，缪尔赛思需要将纯净水输送到空间站的每个结点。



你需要处理 $$$k$$$ 次操作，分为两类：



- 在第 $$$x$$$ 天结束时，空间站改变模式，选择两个**直接相连**的结点 $$$u$$$ 和 $$$v$$$。结点 $$$u$$$ 的每日能量增量 $$$a_u$$$ 减少 $$$w$$$，结点 $$$v$$$ 的每日能量增量 $$$a_v$$$ 增加 $$$w$$$。保证 $$$u$$$ 和 $$$v$$$ 之间有边相连，且操作前 $$$a_u \ge w$$$。

- 在第 $$$x$$$ 天，缪尔赛思需要给每个结点输送纯净水。具体而言，她会选择一个结点 $$$r$$$ 作为水源。从水源向结点 $$$u$$$ 输水需要消耗 $$$dis_{u} \times c_u$$$ 个流形，其中 $$$dis_{u}$$$ 表示结点 $$$u$$$ 到 $$$r$$$ 的路径上的边数，$$$c_u$$$ 表示结点 $$$u$$$ 当前的能量。请帮助她选择合适的水源，使流形消耗总数最少。



保证所有操作中的 $$$x$$$ 严格递增。形式化地，令 $$$x_i$$$ 表示第 $$$i$$$ 次操作中的 $$$x$$$，则对于所有 $$$1\leq i\leq k-1$$$，都有 $$$x_i \lt x_{i+1}$$$。



## 输入格式



第一行包含两个整数 $$$n$$$、$$$k$$$（$$$1 \le n, k \le 10^5$$$），分别表示空间站的结点数和操作数。



第二行包含 $$$n$$$ 个整数 $$$a_1,a_2,\ldots,a_n$$$（$$$0 \leq a_i \leq 1000$$$），其中 $$$a_i$$$ 表示结点 $$$i$$$ 的每日能量增量。



第三行包含 $$$n$$$ 个整数 $$$b_1,b_2,\ldots,b_n$$$（$$$0 \leq b_i \leq 1000$$$），其中 $$$b_i$$$ 表示结点 $$$i$$$ 的初始能量。



接下来 $$$n - 1$$$ 行，每行包含两个整数 $$$u$$$、$$$v$$$（$$$1 \le u, v \le n, u \neq v$$$），描述树的一条边。



接下来 $$$k$$$ 行描述操作。第 $$$i$$$ 次操作为以下两种形式之一：



- “$$$1\ x_i\ u_i\ v_i\ w_i$$$”（$$$1 \leq x_i \leq 10^9$$$，$$$1 \leq u_i, v_i \leq n$$$），含义如上所述。保证 $$$u$$$ 和 $$$v$$$ 之间有边相连，且操作前 $$$a_{u_i} \ge w_i$$$。

- “$$$2\ x_i$$$”（$$$1 \leq x_i \leq 10^9$$$），含义如上所述。



保证所有操作中的 $$$x$$$ 严格递增。



## 输出格式



对于每次类型为 $$$2$$$ 的操作，输出一个整数，表示缪尔赛思最少需要消耗的流形数量。
