# Eminor 数组



Gew 正在寻找满足以下性质的“Eminor”序列 $$$[a_1, a_2, \ldots, a_m]$$$：



- 序列非空（$$$m \geq 1$$$）；

- $$$1 \leq a_i \leq 2^n-1$$$；

- 序列严格递增（对于每个 $$$i\leq m-1$$$，都有 $$$a_i \lt a_{i+1}$$$）；

- 不存在连续三个元素的按位异或等于零（对于每个 $$$i\leq m-2$$$，都有 $$$a_i \oplus a_{i+1} \neq a_{i+2}$$$，其中 $$$\oplus$$$ 表示按位异或运算）。



现在，Gew 想知道有多少个“Eminor”序列。数量可能很大，你只需要输出答案对 $$$998\,244\,353$$$ 取模的结果。



## 输入格式



输入包含一个整数 $$$n$$$（$$$1 \leq n \leq 10^6$$$）。



## 输出格式



输出一个整数，表示“Eminor”序列数量对 $$$998\,244\,353$$$ 取模的结果。



## 样例说明



第二组样例中，有以下 $$$6$$$ 个“Eminor”序列：



- $$$[1]$$$

- $$$[2]$$$

- $$$[3]$$$

- $$$[1,2]$$$

- $$$[1,3]$$$

- $$$[2,3]$$$
