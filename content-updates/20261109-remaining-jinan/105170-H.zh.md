# 广告里的游戏 2：涂色



*厌倦了广告里的虚假游戏？来试试这一款！*



给定一个 $$$n \times n$$$ 的网格。每行和每列各对应一把画刷，共有 $$$2n$$$ 把。使用一把画刷时，它会将对应行或列中的所有格子涂成这把画刷指定的颜色。游戏中有 $$$n$$$ 种颜色，编号为 $$$1$$$ 到 $$$n$$$。各行画刷的指定颜色组成 $$$[1,2,\ldots,n]$$$ 的一个排列；各列画刷的指定颜色也组成 $$$[1,2,\ldots,n]$$$ 的一个排列。



![](https://espresso.codeforces.com/95f9a7b49a10c0ba165a8918bf365c590b6a6040.png) *样例中的画刷与目标图案*



初始网格为空，所有格子都没有颜色。游戏目标是将网格涂成给定图案。



你不满足于仅判断目标是否能够达成。你想知道，如果每把画刷都恰好使用一次，在全部 $$$(2n)!$$$ 种使用顺序中，有多少种能得到目标图案？答案可能很大，请输出答案对 $$$998\,244\,353$$$ 取模的结果。



## 输入格式



第一行包含一个整数 $$$n$$$（$$$1\le n \le 20$$$），表示网格大小。



第二行包含 $$$n$$$ 个整数 $$$p_1,p_2,\cdots,p_n$$$（$$$1 \le p_i \le n$$$），其中 $$$p_i$$$ 表示第 $$$i$$$ 行对应画刷的颜色。保证 $$$p$$$ 是 $$$[1,2,\ldots,n]$$$ 的一个排列。



第三行包含 $$$n$$$ 个整数 $$$q_1,q_2,\cdots,q_n$$$（$$$1 \le q_i \le n$$$），其中 $$$q_i$$$ 表示第 $$$i$$$ 列对应画刷的颜色。保证 $$$q$$$ 是 $$$[1,2,\ldots,n]$$$ 的一个排列。



接下来 $$$n$$$ 行，每行包含 $$$n$$$ 个整数，描述一个 $$$n \times n$$$ 的矩阵 $$$c$$$（$$$1 \le c_{i,j} \le n$$$），其中 $$$c_{i,j}$$$ 表示目标图案第 $$$i$$$ 行、第 $$$j$$$ 列格子的颜色。



## 输出格式



输出一个整数，表示方案数对 $$$998\,244\,353$$$ 取模的结果。



## 样例说明



对于样例，如果先从上到下、再从左到右对 $$$4$$$ 把画刷编号，那么能得到目标图案的 $$$6$$$ 种顺序如下：



- $$$3,2,4,1$$$

- $$$3,4,1,2$$$

- $$$3,4,2,1$$$

- $$$4,1,3,2$$$

- $$$4,3,1,2$$$

- $$$4,3,2,1$$$
