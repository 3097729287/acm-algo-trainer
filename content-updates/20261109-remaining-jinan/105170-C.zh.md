# 斐波那契求和



用 $$$f(i)$$$ 表示著名的斐波那契数列的第 $$$i$$$ 项。形式化定义为：$$$$$$f(i) = \begin{cases} 1 & \text{if } i \leq 2, \\ f(i-1) + f(i-2) & \text{if } i \gt 2. \end{cases} $$$$$$



用 $$$g(x)$$$ 表示数 $$$x$$$ 的二进制表示中 $$$1$$$ 的个数。例如，$$$g(5)=g(101_{(2)})=2$$$，$$$g(15)=g(1111_{(2)})=4$$$。



你的任务是计算以下值：



$$$$$$\sum_{i=1}^n f \left( g(i)\right) \bmod {10^9+7}$$$$$$



## 输入格式



输入包含一个仅由 '`0`' 和 '`1`' 组成的字符串 $$$s$$$（$$$1\le |s|\le 10^7$$$），表示整数 $$$n$$$ 的**二进制形式**。



保证输入不包含前导 $$$0$$$。



## 输出格式



输出一个整数，表示答案对 $$$10^9+7$$$ 取模的结果。



## 样例说明



可以算出，$$$f\left(g(1_{(2)})\right) = 1$$$，$$$f\left(g(10_{(2)})\right) = 1$$$，$$$f\left(g(11_{(2)})\right) = 1$$$。
