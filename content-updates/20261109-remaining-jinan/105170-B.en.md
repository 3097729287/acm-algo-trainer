# Dfs Order 0.5

Time limit: 1 second. Memory limit: 512 megabytes. Standard input and output.

Shuishui has a rooted tree with $n$ vertices numbered from $1$ to $n$. Vertex $1$ is the root, and vertex $i$ has value $a_i$.

Start depth-first search at the root. The children of each vertex can be visited in any order, giving different possible depth-first orders. The value of an order is the sum of the values of vertices at even positions in that order. Find the maximum value among all possible depth-first orders of the tree.

The following pseudocode generates the order. Calling `main()` leaves the depth-first order in `dfs_order`.

```text
procedure dfs(vertex x):
    append x to the end of dfs_order
    for each child y of x in an arbitrary order:
        dfs(y)
procedure main():
    let dfs_order be a global variable
    dfs_order <- empty list
    dfs(1)
```

The following pseudocode calculates the value. The array is indexed from $1$ and has length $n$; `calc(dfs_order)` returns its value.

```text
procedure calc(dfs_order):
    s <- 0
    p <- 2
    while p <= n:
        u <- dfs_order[p]
        s <- s + a[u]
        p <- p + 2
    return s
```

## Input Format

The input contains multiple test cases. The first line contains $t$ ($1\le t\le2\times10^5$), the number of test cases.

For each test case, the first line contains $n$ ($1\le n\le2\times10^5$), the number of vertices. The second line contains $n$ integers $a_1,a_2,\ldots,a_n$ ($1\le a_i\le10^9$), their values. Each of the next $n-1$ lines contains $u_i,v_i$ ($1\le u_i,v_i\le n$, $u_i\ne v_i$), describing a tree edge.

The given edges form a tree. The sum of $n$ over all test cases does not exceed $2\times10^5$.

## Output Format

For each test case, output one integer on a line: the maximum value.

## Sample Explanation

In the first test case, the unique depth-first order is $[1,2]$, with value $a_2=2$. Positions are indexed from $1$. In the second test case, a maximum-value order is $[1,3,2,4]$, with value $a_3+a_4=444$.
