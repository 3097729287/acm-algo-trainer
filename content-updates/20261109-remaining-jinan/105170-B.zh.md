# 深度优先序 0.5

时间限制：1 秒。内存限制：512 MB。使用标准输入和标准输出。

Shuishui 有一棵包含 $n$ 个顶点的有根树，顶点编号为 $1$ 到 $n$。顶点 $1$ 是根，顶点 $i$ 的权值为 $a_i$。

从根开始进行深度优先搜索。每个顶点的子结点可以按任意顺序访问，因此可能产生不同的深度优先序。一个深度优先序的价值，定义为该序列中偶数位置上的顶点权值之和。求这棵树所有可能的深度优先序中的最大价值。

以下伪代码生成深度优先序。调用 `main()` 后，`dfs_order` 中保存的就是该序列。

```text
procedure dfs(vertex x):
    append x to the end of dfs_order
    for each child y of x in an arbitrary order:
        dfs(y)
procedure main():
    let dfs_order be a global variable
    dfs_order <- empty list
    dfs(1)
```

以下伪代码计算序列的价值。数组下标从 $1$ 开始，长度为 $n$；调用 `calc(dfs_order)` 返回其价值。

```text
procedure calc(dfs_order):
    s <- 0
    p <- 2
    while p <= n:
        u <- dfs_order[p]
        s <- s + a[u]
        p <- p + 2
    return s
```

## 输入格式

输入包含多组测试数据。第一行包含测试用例数 $t$（$1\le t\le2\times10^5$）。

对于每个测试用例，第一行包含顶点数量 $n$（$1\le n\le2\times10^5$）。第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$（$1\le a_i\le10^9$），表示各顶点的权值。接下来 $n-1$ 行，每行包含 $u_i,v_i$（$1\le u_i,v_i\le n$，$u_i\ne v_i$），描述树的一条边。

保证给出的边组成一棵树。所有测试用例的 $n$ 之和不超过 $2\times10^5$。

## 输出格式

对于每个测试用例，在一行中输出一个整数，表示最大价值。

## 样例说明

第一组样例只有一种深度优先序 $[1,2]$，价值为 $a_2=2$。序列下标从 $1$ 开始。第二组样例中，一个达到最大价值的深度优先序为 $[1,3,2,4]$，其价值为 $a_3+a_4=444$。


## 样例 1

### 输入

```text
3
2
1 2
1 2
4
1 1 222 222
1 2
1 3
2 4
6
1 5 4 6 1 1
6 1
4 5

```

### 输出

```text
2

15
```
