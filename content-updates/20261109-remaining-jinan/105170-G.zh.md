# 平台游戏



Haha 正在玩一款平台游戏。



游戏的一关中，机器人会在二维地图的各个平台之间下落。将地图视为一个坐标系，地面是 $$$x$$$ 轴。地面上方有 $$$n$$$ 个平台，编号为 $$$1$$$ 到 $$$n$$$。所有平台均与地面平行，第 $$$i$$$ 个平台可视为从 $$$(l_i, y_i)$$$ 延伸到 $$$(r_i, y_i)$$$ 的线段，厚度忽略不计。机器人最初出现在点 $$$(s_x, s_y)$$$，之后按以下规则移动：



- 如果机器人位于某个平台上，就向右移动，直到离开该平台。认为机器人离开平台 $$$i$$$ 时，其 $$$x$$$ 坐标为 $$$r_i$$$，即平台的右端点。

- 如果机器人不位于任何平台上，就保持竖直下落，直到落到某个平台上或最终落到地面。



注意，机器人能落在第 $$$i$$$ 个平台上，当且仅当它的 $$$x$$$ 坐标**严格位于** $$$l_i$$$ 和 $$$r_i$$$ 之间，即 $$$l_i \lt x \lt r_i$$$。



现在，Haha 想知道机器人最终会在地面的什么位置落地。

## 输入格式



输入包含多组测试数据。



第一行包含一个整数 $$$t$$$（$$$1\leq t\leq 2\times 10^5$$$），表示测试用例数。



对于每个测试用例：



第一行包含一个整数 $$$n$$$（$$$1 \leq n \leq 2\times 10^5$$$），表示平台数量。



接下来 $$$n$$$ 行，第 $$$i$$$ 行包含三个整数 $$$l_i$$$、$$$r_i$$$、$$$y_i$$$（$$$1 \leq l_i \lt r_i \leq 10^9$$$，$$$1 \leq y_i \leq 10^9$$$），表示第 $$$i$$$ 个平台的位置。



最后一行包含两个整数 $$$s_x$$$、$$$s_y$$$（$$$1 \leq s_x, s_y \leq 10^9$$$），表示机器人的初始位置。



保证任意两个平台都不重叠。只要两个平台有至少一个公共点，就视为重叠。



保证所有测试用例的 $$$n$$$ 之和不超过 $$$2\times 10^5$$$。



## 输出格式



对于每个测试用例，在一行中输出一个整数，表示答案。
