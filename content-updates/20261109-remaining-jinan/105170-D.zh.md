# 平行线



曾经，二维平面上有 $$$k$$$ 条平行线，以及位于这些直线上的 $$$n$$$ 个点。已知每条直线上都**至少有两个**点。



现在给出这 $$$n$$$ 个点，请找出这 $$$k$$$ 条平行线。



## 输入格式



第一行包含两个整数 $$$n$$$、$$$k$$$（$$$2\le n \le 10^4,1 \le k \le \mathrm{min}(50,\frac{n}{2})$$$），分别表示点数和平行线数量。



接下来 $$$n$$$ 行，第 $$$i$$$ 行包含两个整数 $$$x_i$$$、$$$y_i$$$（$$$1\le x_i, y_i \le 10^9$$$），表示第 $$$i$$$ 个点的坐标。



保证这 $$$n$$$ 个点两两不同，即 $$$\forall 1\le i \lt j \le n$$$，都有 $$$x_i \neq x_j$$$ 或 $$$y_i \neq y_j$$$。



## 输出格式



输出 $$$k$$$ 行。



第 $$$i$$$ 行先输出一个整数 $$$m_i$$$（$$$2 \le m_i \le n$$$），表示第 $$$i$$$ 条平行线上的点数；然后输出 $$$m_i$$$ 个整数 $$$x_1,x_2,\ldots,x_{m_i}$$$，表示第 $$$i$$$ 条直线上的点的编号。



你的输出必须保证每个点恰好出现在一条直线上，且这 $$$k$$$ 条直线互不相同、两两平行。



保证存在将这 $$$n$$$ 个点分配到 $$$k$$$ 条平行线上的合法方案。如果有多个方案，输出任意一个。
