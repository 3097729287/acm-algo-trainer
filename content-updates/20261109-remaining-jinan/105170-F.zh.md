# 最佳选手



第 17 届厨艺对抗专业竞赛（CCPC）已经结束，主办方将选出本次比赛的最佳选手。



共有 $$$n$$$ 名选手参加，编号为 $$$1$$$ 到 $$$n$$$，他们一共进行了 $$$m$$$ 场 1 对 1 的对决：



- 第 $$$i$$$ 场对决由选手 $$$a_i$$$ 和 $$$b_i$$$ 参加；

- 每场对决包含上半场和下半场：

  - 上半场中，选手 $$$a_i$$$ 的得分为 $$$x_i$$$，选手 $$$b_i$$$ 的得分为 $$$y_i$$$；

  - 下半场中，选手 $$$a_i$$$ 和 $$$b_i$$$ 的确切得分目前尚不确定，但两人得分之和为 $$$z_i$$$；

  - 一名选手在一场对决中的得分是上下半场得分之和。也就是说，在第 $$$i$$$ 场对决中，$$$a_i$$$ 和 $$$b_i$$$ 的可能得分分别为 $$$x_i + p_i$$$ 和 $$$y_i + q_i$$$，其中 $$$0 \leq p_i,q_i \leq z_i, p_i + q_i = z_i$$$。



所有得分都是非负整数，每名选手都至少参加过一场对决。



一名选手的最终得分，是他参加的所有对决中的**最高**得分。一名选手能够获得最佳选手奖，当且仅当他的最终得分**严格大于**所有其他选手的最终得分。



由于 $$$m$$$ 场对决下半场的得分尚不确定，最佳选手也可能不同。请找出所有有可能成为最佳选手的人。



## 输入格式



输入包含多组测试数据。



第一行包含一个整数 $$$t$$$（$$$1\leq t\leq 10^5$$$），表示测试用例数。



对于每个测试用例：



第一行包含两个整数 $$$n$$$、$$$m$$$（$$$2 \leq n \leq 2 \times 10^5$$$，$$$1 \leq m \leq 2 \times 10^5$$$），分别表示选手数量和对决数量。



接下来 $$$m$$$ 行，第 $$$i$$$ 行包含 $$$5$$$ 个整数 $$$a_i$$$、$$$b_i$$$、$$$x_i$$$、$$$y_i$$$、$$$z_i$$$（$$$1 \leq a_i, b_i \leq n$$$，$$$a_i \neq b_i$$$，$$$0 \leq x_i, y_i, z_i \leq 10^5$$$），含义如上所述。保证每名选手都至少参加一场对决。



保证所有测试用例的 $$$n$$$ 之和与 $$$m$$$ 之和均不超过 $$$2\times 10^5$$$。



## 输出格式



对于每个测试用例：



第一行输出一个整数 $$$k$$$，表示有可能成为最佳选手的人数。



第二行按**升序**输出 $$$k$$$ 个整数，表示这些选手的编号。特别地，当 $$$k=0$$$ 时，输出或不输出这一空行均可。



## 样例说明



第一组样例中，三名选手都有可能成为最佳选手。选手 $$$1$$$ 只有在以下情况下才能成为最佳选手：



- 第一场对决中，选手 $$$1$$$ 得到 $$$2 + 6 = 8$$$ 分，选手 2 得到 $$$3 + 0 = 3$$$ 分；

- 第二场对决中，选手 $$$2$$$ 得到 $$$6 + 1 = 7$$$ 分，选手 $$$3$$$ 得到 $$$6 + 1 = 7$$$ 分。



此时，选手 $$$1$$$ 的最终得分为 $$$8$$$，选手 $$$2$$$ 的最终得分为 $$$\max(3, 7) = 7$$$，选手 $$$3$$$ 的最终得分为 $$$7$$$，因此选手 $$$1$$$ 是最佳选手。
