# 连通分量



Eminor 大陆上有 $$$n$$$ 个王国，编号为 $$$1$$$ 到 $$$n$$$。每个王国都有两个属性值，分别用 $$$a_i$$$ 和 $$$b_i$$$ 表示。



当 $$$a_i - a_j \leq i - j \leq b_i - b_j$$$ 或 $$$a_j - a_i \leq j - i \leq b_j - b_i$$$ 成立时，王国 $$$i$$$ 和 $$$j$$$（$$$i \lt j$$$）之间有一条无向道路相连。



Gew 想知道这片大陆上共有多少个连通分量。



## 输入格式



第一行包含一个整数 $$$n$$$（$$$1\leq n\leq 10^6$$$）。



接下来 $$$n$$$ 行，第 $$$i$$$ 行包含两个整数 $$$a_i, b_i$$$（$$$-10^9 \leq a_i, b_i \leq 10^9$$$）。



## 输出格式



输出一个整数，表示连通分量数量。
