# 台北 2021 原题恢复

从 [ICPC Archive 的整场原始 PDF](https://icpcarchive.github.io/Asia%20Pacific%20Contests/Taiwan/2021%20Asia%20Taipei%20Regional%20Contest/problems.pdf) 找回已有的 13 题，与 [Gym 103443 原站题单](https://codeforces.com/gym/103443) 的全部题号、题名和限制核对。来源为存档副本，保留这一来源说明，不冒称本次从原站成功下载。

整场共 34 页，逐题拆分后全部经过真实 PDF.js 渲染、原字节摘要及无外部请求检查；样例按实际原页核对。C 的字面输出 `>_<` 保留连续字符；D 补回首页两组样例；E 补齐跨页的第三组输入，并按原页字形位置保留每一个画框空格。E 的三组样例另由独立的有理数布局程序重建，逐字符一致。

`review.json` 保留原册摘要、题目身份、物理页码、限制和完整样例摘要。各题的 `.samples.json` 保存核对后的原始样例。`verify_samples.py` 独立验证 A、B、D 的小样例及 E 的精确字符画，不提交原站。

13 个原 ID、别名及个人数据保持；撤下的公共题目按先前可见性恢复。原英文 PDF 完整可读，中文暂不提供未经核对的数学文字抽取；待逐页补译。实际导入和检查回执为 `docs/verification/taipei-originals-20261108.json`。
