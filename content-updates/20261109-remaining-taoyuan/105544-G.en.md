# A Packing Problem

Time limit: 1 second. Memory limit: 1024 megabytes.

## Problem Description

There are $m$ distinguishable boxes $\mathcal B=\{B_1,\ldots,B_m\}$, each of capacity $T$, and $n$ items $\mathcal I=\{I_1,\ldots,I_n\}$. Item $I_j$ has size $a_j\in\{s_1,s_2\}$. The two possible sizes satisfy $0<s_1,s_2\le T$, and neither lies in the open interval $(T/4,3T/4)$.

Each item $I_j$ may be put only into a box in a specified set $P_j\subseteq\mathcal B$. Let $P_i^{-1}=\{I_j\in\mathcal I:B_i\in P_j\}$ be the set of items allowed in box $B_i$.

A feasible packing is an assignment $\sigma:\mathcal I\to\mathcal B$ such that $\sigma(I_j)\in P_j$ for every item and $\sum_{I_j\in\sigma^{-1}(B_i)}a_j\le T$ for every box. If no such assignment exists, the instance is infeasible.

One way to prove infeasibility is to give nonnegative values $\alpha_1,\ldots,\alpha_n$ for the items and $\beta_1,\ldots,\beta_m$ for the boxes. For capacity $t$, consider these conditions, called LP-$(t)$:

$$\sum_{1\le j\le n}\alpha_j>\sum_{1\le i\le m}\beta_i.$$

For every $1\le i\le m$ and every subset $C\subseteq P_i^{-1}$ satisfying $\sum_{I_j\in C}a_j\le t$, require

$$\sum_{I_j\in C}\alpha_j\le\beta_i.$$

The values can be viewed as estimates of item sizes and box capacities. Every set of items that fits in a box has total estimated size at most that box's estimated capacity, yet the estimated total size of all items exceeds the estimated total capacity of all boxes. Thus LP-$(T)$ proves that the original instance is infeasible.

Mike proposes allowing each box to have capacity $(1+3/4)T$. For every input instance, output either:

- an assignment using these enlarged capacities, with at most one item of size strictly greater than $T/4$ in each box; or
- values satisfying LP-$(T)$, proving infeasibility for the original capacity.

The assignment must still respect every allowed-box set. A proof concerns the original capacity, not the enlarged capacity.

## Input Format

The first line contains $n$ and $m$. Each of the next $n$ lines describes item $I_j$: its size $a_j$, the number $p_j$ of allowed boxes, and then the $p_j$ box indices in $P_j$. Boxes are numbered from $1$ to $m$. The last line contains $T$.

## Output Format

If giving an assignment, output `Assignment` on the first line and the $n$ assigned box indices in item order on the second line. Each item must be assigned to an allowed box. No box may receive total size greater than $(1+3/4)T$ or more than one item strictly larger than $T/4$.

If giving a proof, output `Proof` on the first line, the $n$ values $\alpha_1,\ldots,\alpha_n$ on the second line, and the $m$ values $\beta_1,\ldots,\beta_m$ on the third line. All these values must be integers in $[0,3\times10^5]$ and satisfy LP-$(T)$.

Either kind of valid output is accepted.

## Technical Specification

- $1\le n,m\le100$.
- $1\le T\le10^5$, and $T$ is divisible by $4$.
- $s_1,s_2\in[1,T/4]\cup[3T/4,T]$ and $a_j\in\{s_1,s_2\}$.
