# Slabstones Rearrangement

Time limit: 3 seconds. Memory limit: 1024 megabytes.

## Problem Description

Babara has a rectangular garden containing rectangular slabstones. Every slabstone lies inside the garden, and its sides are parallel to the garden's sides. The slabstones do not overlap. Each of the four sides of the garden is touched by at least one slabstone.

Babara wants to rearrange the slabstones to reduce the area of the garden. A slabstone can only move horizontally: its vertical position cannot change. The slabstones must remain non-overlapping. For any two slabstones whose vertical projections overlap with positive length, their left-to-right order must remain unchanged and their horizontal separation must be at least the given positive minimum spacing. The horizontal edges of slabstones may touch.

Find the maximum area that can be freed by this rearrangement. If no area can be freed, output zero.

## Input Format

The first line contains the number of test cases $T$.

For each test case, the first line contains the number of slabstones $n$ and the required minimum spacing. Each of the next $n$ lines contains four integers $x_1,y_1,x_2,y_2$, the coordinates of the lower-left and upper-right corners of a slabstone, respectively.

## Output Format

For each test case, output the maximum area that can be freed, or zero if the garden's area cannot be reduced.

## Technical Specification

- $1\le T\le32$ and $4\le n\le100$.
- All coordinates are unsigned 32-bit integers.
- The original garden's area does not exceed the maximum unsigned 32-bit integer.
- The width and height of each slabstone and the minimum spacing are positive unsigned 32-bit integers.
