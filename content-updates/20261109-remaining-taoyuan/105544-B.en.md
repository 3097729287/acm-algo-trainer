# Recurring Decimal to Fractions

Time limit: 3 seconds. Memory limit: 1024 megabytes.

## Problem Description

A recurring decimal is a decimal number with a repeating sequence of digits. We describe such a decimal, which is less than one, by two strings: the first contains the non-recurring digits after the decimal point, and the second contains the recurring digits. For example, the strings `1` and `012` describe $0.1\overline{012}$.

Given these two strings, convert the recurring decimal to a fraction $n/d$, where $n$ and $d$ are relatively prime integers.

## Input Format

The first line contains the number of test cases $T$. Each test case consists of three lines. The first line contains two integers $a$ and $b$, the lengths of the non-recurring and recurring strings, respectively. The second line contains the non-recurring string of length $a$. The third line contains the recurring string of length $b$. Leading zeroes in either string must be retained.

## Output Format

For each test case, output the numerator $n$ and denominator $d$ of the reduced fraction, separated by a space.

## Technical Specification

- $1\le T\le40$.
- $1\le a$, $1\le b$, and $1\le a+b\le10$.


## Sample 1

### Input

```text
2
1 3
0
012
3 1
085
3
```

### Output

```text
2 1665
32 375
```
