# Baker's Dilemma

Time limit: 3 seconds. Memory limit: 1024 megabytes.

## Problem Description

A baker has $N$ orders, numbered from $1$ to $N$. He can process only one order at a time. Order $i$ requires $D_i$ consecutive days, and incurs a penalty of $S_i$ for every day it waits before processing begins. Choose an order in which to process all the orders so that the total penalty is minimized.

For example, suppose the four orders have processing times $3,1,2,5$ and daily penalties $4,1000,2,5$, respectively. Processing them in order $1,2,3,4$ incurs a total penalty of $4\times0+1000\times3+2\times4+5\times6=3038$. Processing them in order $2,1,3,4$ incurs $1000\times0+4\times1+2\times4+5\times6=42$.

If more than one processing order has minimum total penalty, output the lexicographically smallest sequence of order numbers.

## Input Format

The first line contains the number of test cases $T$.

For each test case, the first line contains $N$. The next $N$ lines describe the orders in their numbered order, each containing two integers $D_i$ and $S_i$.

## Output Format

For each test case, output the numbers of the orders in an optimal processing order on one line, separated by spaces. Break ties by the lexicographic order of the entire sequence.

## Technical Specification

- $1\le T\le1000$ and $1\le N\le1000$.
- $1\le D_i\le1000$.
- $1\le S_i\le10000$.


## Sample 1

### Input

```text
2
4
3 4
1 1000
2 2
5 5
5
3 4
1 1000
8 8
2 2
5 6
```

### Output

```text

```
