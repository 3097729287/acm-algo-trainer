# 灯火阑珊处

时间限制：3 秒。内存限制：1024 MB。

## 题目描述

元宵节期间，主办方会开关花灯，让游客欣赏不同的灯光效果。每位游客会给当时亮着的每一盏花灯评分：非常满意记三分，满意记一分，失望记负二分。未点亮的花灯不获得分数。有些花灯已经损坏，它们始终不亮，也无法被打开。

共有 $n$ 盏花灯，编号为 $0$ 到 $n-1$。每盏花灯都有初始状态和初始分数。按发生顺序处理以下 $m$ 个事件：

- `W` $l_j$ $r_j$：切换闭区间 $[l_j,r_j]$ 中所有未损坏花灯的开关状态。亮着的变为不亮，不亮的变为亮着；损坏花灯的状态不变。
- `C` $q_j$：一位游客给当前亮着的每盏花灯增加 $q_j$ 分。

求全部事件结束后所有花灯的分数总和。

## 输入格式

第一行包含两个整数 $n$ 和 $m$。

接下来 $n$ 行按编号顺序描述花灯。每行包含一盏花灯的初始状态 $s_i$ 和初始分数 $p_i$：$s_i=1$ 表示亮着，$s_i=0$ 表示不亮，$s_i=-1$ 表示已经损坏。

随后 $m$ 行描述事件。开关事件由 `W` 以及 $l_j$、$r_j$ 组成。游客评分事件由 `C` 以及 $q_j$ 组成。

## 输出格式

输出一个整数，表示全部事件结束后所有花灯的分数总和。初始分数计入答案，损坏花灯的初始分数也计入答案。

## 数据范围

- $1\le n,m\le10^6$。
- $s_i\in\{-1,0,1\}$，且 $-10000\le p_i\le10000$。
- $0\le l_j\le r_j<n$。
- $q_j\in\{-2,1,3\}$。


## 样例 1

### 输入

```text
3 3
0 0
0 0
0 0
W 0 2
W 1 1
C 3
```

### 输出

```text
6
```

## 样例 2

### 输入

```text
5 5
1 5
0 0
-1 2
1 0
0 -2
C 1
W 0 4
C -2
W 1 3
C 3
```

### 输出

```text
9
```
