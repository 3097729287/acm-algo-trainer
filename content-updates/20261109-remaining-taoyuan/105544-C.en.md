# Where the Lantern Lights are Dimming

Time limit: 3 seconds. Memory limit: 1024 megabytes.

## Problem Description

During the Lantern Festival, lanterns are switched on and off to give visitors different impressions. A visitor gives each currently lit lantern three points if very satisfied, one point if satisfied, and minus two points if disappointed. An unlit lantern receives no points. Some lanterns are broken: they remain unlit and cannot be switched on.

There are $n$ lanterns, indexed from $0$ to $n-1$. Each lantern has an initial state and an initial score. Process the following $m$ events in chronological order:

- `W` $l_j$ $r_j$: toggle every working lantern whose index is in the inclusive interval $[l_j,r_j]$. Lit lanterns become unlit and unlit lanterns become lit; broken lanterns remain broken.
- `C` $q_j$: a visitor gives $q_j$ points to each lantern that is currently lit.

Find the sum of the final scores of all lanterns.

## Input Format

The first line contains two integers $n$ and $m$.

The next $n$ lines describe the lanterns in index order. Each line contains the initial state $s_i$ and initial score $p_i$ of a lantern: $s_i=1$ means lit, $s_i=0$ means unlit, and $s_i=-1$ means broken.

The following $m$ lines describe the events. A switching event contains `W` followed by $l_j$ and $r_j$. A visitor event contains `C` followed by $q_j$.

## Output Format

Output one integer: the sum of all lanterns' scores after all events. Their initial scores are part of this sum, including the initial scores of broken lanterns.

## Technical Specification

- $1\le n,m\le10^6$.
- $s_i\in\{-1,0,1\}$ and $-10000\le p_i\le10000$.
- $0\le l_j\le r_j<n$.
- $q_j\in\{-2,1,3\}$.


## Sample 1

### Input

```text
3 3
0 0
0 0
0 0
W 0 2
W 1 1
C 3
```

### Output

```text
6
```
