# 循环小数转分数

时间限制：3 秒。内存限制：1024 MB。

## 题目描述

循环小数的小数部分有一段数字不断重复。本题用两个字符串描述一个小于一的循环小数：第一个字符串表示小数点后的非循环部分，第二个字符串表示循环节。例如，字符串 `1` 和 `012` 表示 $0.1\overline{012}$。

给定这两个字符串，请将该循环小数化为分数 $n/d$，其中 $n$ 和 $d$ 是互质的整数。

## 输入格式

第一行包含测试用例数 $T$。每个测试用例占三行。第一行包含两个整数 $a$ 和 $b$，分别表示非循环部分和循环节的长度。第二行包含长度为 $a$ 的非循环部分字符串。第三行包含长度为 $b$ 的循环节字符串。两个字符串中的前导零都属于小数表示的一部分，不能忽略。

## 输出格式

对于每个测试用例，在一行中输出最简分数的分子 $n$ 和分母 $d$，用一个空格分隔。

## 数据范围

- $1\le T\le40$。
- $1\le a$、$1\le b$，且 $1\le a+b\le10$。


## 样例 1

### 输入

```text
2
1 3
0
012
3 1
085
3
```

### 输出

```text
2 1665
32 375
```
