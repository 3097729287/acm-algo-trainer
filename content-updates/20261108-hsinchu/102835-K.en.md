# Number with Bachelors

Numbers without duplicated digits are considered bachelor numbers. For example, `123` is a bachelor number in the decimal number system, and `9af` is a bachelor number in the hexadecimal number system. Decimal `101` and hexadecimal `aba` are not bachelor numbers because they have duplicated digits.

There are two types of questions. Given an interval $[a,b]$ in a designated number system, decimal or hexadecimal, count the bachelor numbers in the interval, including both endpoints. Alternatively, given an integer $i$ in a designated number system, find the $i$-th bachelor number in that number system.

## Input Format

The first line contains an integer $n$, the number of test cases. Each following line describes one question.

Each question starts with `d` or `h`, indicating the decimal or hexadecimal domain, respectively. In the decimal domain, all following numbers are represented in decimal. In the hexadecimal domain, all following numbers are represented in hexadecimal.

The next digit is `0` or `1`, indicating the question type:

- For type `0`, two integers $a$ and $b$ follow, where $0\le a\le b<2^{64}$. They specify the interval.
- For type `1`, an integer $i$ follows, where $1\le i<2^{64}$. It specifies the order.

## Output Format

Output one integer for each question, in decimal for a decimal-domain question and in hexadecimal for a hexadecimal-domain question. For a type `1` question, if the $i$-th bachelor number does not exist, output `-`.

## Technical Specification

- $1\le n\le 50000$.
- $0\le a\le b<2^{64}$.
- $1\le i<2^{64}$.

## Sample Input 1

```text
6
d 0 10 20
h 0 10 1f
d 1 10
h 1 f
d 1 1000000000
h 1 ffffffffffffffff
```

## Sample Output 1

```text
10
f
9
e
-
-
```
