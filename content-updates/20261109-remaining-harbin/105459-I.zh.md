# 全新的几何问题



你是高维空间中的一名魔法师，最初有一个 $$$n$$$ 维超长方体，各维边长为 $$$a_1, a_2, \dots, a_n$$$。对于一个 $$$d$$$ 维超长方体，本题将边长和定义为 $$$\sum_{i=1}^d a_i$$$，超体积定义为 $$$\prod_{i=1}^d a_i$$$。



你希望得到一个边长和为 $$$S$$$、超体积为 $$$M$$$ 的超长方体。为此，可以对当前的超长方体执行降维和升维操作：



- 降维：删除一个维度。

- 升维：新增一个维度，其边长可以是任意正整数。



两种操作都很耗费精力，因此你希望确定：至少需要多少次操作，才能得到边长和为 $$$S$$$、超体积为 $$$M$$$ 的超长方体。



## 输入格式



第一行包含三个整数 $$$n, S, M$$$（$$$1\le n \le 10^5$$$，$$$1 \le S, M \le 10^{10}$$$）。



第二行包含 $$$n$$$ 个整数，表示超长方体的初始各维边长 $$$a_i$$$（$$$1 \le a_i \le 10^{10}$$$）。



## 输出格式



输出一个整数，表示所需的最少操作次数。如果不可能得到满足要求的超长方体，输出 $$$-1$$$。



## 样例说明



第一组样例的一种方案是：先删除边长为 $$$1$$$ 的维度，再新增一个边长为 $$$3$$$ 的维度。
