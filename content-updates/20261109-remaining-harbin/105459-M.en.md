# Weird Ceiling

Time limit: 1 second. Memory limit: 1024 megabytes. Standard input and output.

While learning about the ceiling function, a student wrote this pseudocode:

```text
function f(a, b):
    i <- b
    while i >= 2:
        if a mod i = 0:
            return a / i
        end if
        i <- i - 1
    end while
    return a
end function
```

You know it is incorrect, but are curious about this student's function $f(a,b)$. Calculate $\sum_{i=1}^{n}f(n,i)$.

## Input Format

The first line contains the number of test cases $T$ ($1\le T\le10^3$). Each test case consists of one line containing an integer $n$ ($1\le n\le10^9$).

## Output Format

For each test case, output one integer on a line: the answer.


## Sample 1

### Input

```text
3
5
451
114514
```

### Output

```text
21
10251
7075858
```
