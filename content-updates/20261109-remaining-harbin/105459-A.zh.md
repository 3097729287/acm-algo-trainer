# 建造计算机



你想建造一台实现特定功能的计算机：给定整数 $$$x$$$，判断 $$$x$$$ 是否位于区间 $$$[L, R]$$$ 内。为此，你设计了一个边权为 $$$0$$$ 或 $$$1$$$ 的有向无环图（DAG），其中有一个入度为 $$$0$$$ 的起点和一个出度为 $$$0$$$ 的终点。从起点沿一条路径走到终点，将依次经过的边权拼接起来，就能得到区间 $$$[L, R]$$$ 内某个整数的无前导零二进制表示。区间 $$$[L, R]$$$ 内的每个整数都必须恰好对应图中的一条唯一的路径。这样，通过检查一个整数的二进制表示能否沿这个 DAG 走出，就可以判断它是否位于区间 $$$[L, R]$$$ 内。



显然，你可以为每个整数分别建立一条链。但当区间较大时，这样的 DAG 需要太多结点，只有 256 MiB 内存的计算机无法存储。因此，你需要压缩这个 DAG，让不同路径共享结点，以减少结点和边的数量。形式化地，你需要构造一个不超过 $$$100$$$ 个结点、每个结点出度不超过 $$$200$$$ 的 DAG。边权只能为 $$$0$$$ 或 $$$1$$$，恰好有一个入度为 $$$0$$$ 的起点和一个出度为 $$$0$$$ 的终点。区间 $$$[L, R]$$$ 内的每个整数必须**恰好**对应一条从起点到终点的唯一路径，且不能存在表示区间 $$$[L, R]$$$ 以外整数的路径。任何路径形成的二进制序列都不能有前导零。两个结点之间可以存在两条边权不同的边。



## 输入格式



一行包含两个正整数 $$$L, R$$$（$$$1 \le L \le R \le 10^6$$$）。



## 输出格式



第一行输出结点数 $$$n$$$（$$$1 \le n \le 100$$$）。



接下来 $$$n$$$ 行，第 $$$i$$$ 行先输出整数 $$$k$$$（$$$0 \le k \le 200$$$），表示结点 $$$i$$$ 的出边数量；然后输出 $$$2 \cdot k$$$ 个整数 $$$a_{i,k}, v_{i,k}$$$（$$$1 \le a_{i,k} \le n$$$，$$$a_{i,k} \neq i$$$，$$$v_{i,k} \in \{0, 1\}$$$），表示结点 $$$i$$$ 有一条指向结点 $$$a_{i,k}$$$、边权为 $$$v_{i,k}$$$ 的有向边。必须保证输出是满足要求的有向无环图。
