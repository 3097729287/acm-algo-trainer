# 在哈尔滨指路



有些地区的人习惯用东南西北指路，例如：向南走到第二个路口，再向东走到第一个路口。但哈尔滨的路网规划较复杂，很多街道并不与正东、正西等方向完全对齐。因此，如果用绝对方向向一个长期住在哈尔滨的人指路，他可能很难理解你想表达的路线。



哈尔滨人更习惯用相对方向指路。对于同一个地点，他可能先让你面朝南，然后说：沿路直走到第二个路口，左转，再直走到第一个路口。



为解决这种差异，你决定编写程序，将使用东南西北的指路方式转换为哈尔滨人习惯的方式。当然，使用真实的哈尔滨地图过于复杂，因此本题假设地图是一个无限大的网格。



## 输入格式



第一行包含整数 $$$T$$$（$$$1 \le T \le 10^4$$$），表示测试用例数。



对于每个测试用例，第一行包含整数 $$$n$$$（$$$1 \le n \le 10$$$），表示指路指令数量。



接下来 $$$n$$$ 行，每行描述一条绝对方向指令，包含字符 $$$d$$$（$$$d\in\{\texttt{N}, \texttt{S}, \texttt{W}, \texttt{E}\}$$$）和整数 $$$x$$$（$$$1 \le x \le 10$$$），表示“沿 $$$d$$$ 方向走到第 $$$x$$$ 个路口”。其中 $$$\texttt{N}$$$ 表示北，$$$\texttt{S}$$$ 表示南，$$$\texttt{W}$$$ 表示西，$$$\texttt{E}$$$ 表示东。



保证相邻两条指令的方向既不相同，也不相反；南与北相反，东与西相反。



## 输出格式



对于每个测试用例，第一行输出整数 $$$m$$$（$$$1 \le m \le 20$$$）和字符 $$$f$$$（$$$f \in \{\texttt{N}, \texttt{S}, \texttt{W}, \texttt{E}\}$$$），分别表示哈尔滨式指令数量和初始朝向。方向字符的含义与输入相同。



接下来输出 $$$m$$$ 行。每行以字符 $$$g \in \{\texttt{Z}, \texttt{L}, \texttt{R}\}$$$ 开头，其中 $$$\texttt{Z}$$$ 表示直走，$$$\texttt{L}$$$ 表示左转，$$$\texttt{R}$$$ 表示右转。如果字符为 $$$\texttt{Z}$$$，本行还必须包含整数 $$$y$$$（$$$1 \le y \le 100$$$），表示直走到第 $$$y$$$ 个路口。输出的第一条指令必须以 $$$\texttt{Z}$$$ 开头。相邻指令的字符 $$$g$$$ 不能相同，且 $$$\texttt{L}$$$ 与 $$$\texttt{R}$$$ 指令不能相邻。



本题不要求最小化 $$$m$$$。如果有多种方式能到达同一个终点，输出任意合法方案即可。
