# 农场管理



你放弃了编程，来到三江平原种田。在田间劳作期间，你养成了规律的作息，现在每天**恰好**工作 $$$m$$$ 个时间单位。收获季到了，你需要收割并处理 $$$n$$$ 种作物。对于第 $$$i$$$ 种作物，每处理一个时间单位可获得 $$$w_i$$$ 的收益。为了让每天的工作不那么单调，你每天处理第 $$$i$$$ 种作物的时间必须是区间 $$$[l_i, r_i]$$$ 内的整数，包括两端点。



某天，天气预报说明天会有大雨，无法工作，所以你需要调整安排，在今天尽快收获作物。具体地，你可以选择至多一种作物，取消它每天的处理时间范围限制，使处理它的时间可以是 $$$[0, m]$$$ 内的任意整数。其他作物的时间限制保持不变。你仍然必须**恰好**工作 $$$m$$$ 个时间单位。



请确定今天最多能获得多少收益。



## 输入格式



第一行包含两个整数 $$$n$$$ 和 $$$m$$$（$$$1 \le n \le 10^5$$$，$$$1 \le m \le 10^{11}$$$），分别表示作物种类数和每天的工作时长。



接下来 $$$n$$$ 行，每行包含三个整数 $$$w_i$$$、$$$l_i$$$ 和 $$$r_i$$$（$$$1 \le w_i \le 10^6$$$，$$$1 \le l_i \le r_i \le 10^6$$$），表示作物的收益和时间限制。



保证 $$$\sum_{i=1}^n l_i \le m \le \sum_{i=1}^n r_i$$$。



## 输出格式



输出一个整数，表示今天能够获得的最大收益。
