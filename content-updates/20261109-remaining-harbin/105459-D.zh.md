# 一个简单的字符串问题



给定一个 $$$2$$$ 行、$$$n$$$ 列的字符网格，每个格子中都有一个小写字母。你可以从任意格子出发，移动若干步，每步只能向右或向下，并在任意格子停止。将按顺序经过的格子中的字符拼接起来，就得到一个字符串。



字符串 $$$S$$$ 被称为双倍字符串，当且仅当存在一个非空字符串 $$$T$$$，使 $$$S = TT$$$。例如，$$$\texttt{aa}$$$ 和 $$$\texttt{xyzxyz}$$$ 是双倍字符串，而 $$$\texttt{a}$$$ 和 $$$\texttt{xyzyz}$$$ 不是。



给定字符网格，请求出能够得到的最长双倍字符串的长度。



## 输入格式



第一行包含整数 $$$n$$$（$$$1 \le n \le 2 \times 10^5$$$），表示字符网格的列数。



接下来两行各包含一个长度为 $$$n$$$、仅由小写英文字母组成的字符串，表示字符网格。



## 输出格式



输出一个整数，表示能够得到的最长双倍字符串的长度。



## 样例说明



第一组样例中，可以按以下方式得到一个最长双倍字符串，方案不唯一：



$$$$$$ \begin{aligned} \underline{\texttt{abc}}\texttt{ab}\\ \texttt{ac}\underline{\texttt{abc}} \end{aligned} $$$$$$
