# 奇怪的向上取整

时间限制：1 秒。内存限制：1024 MB。使用标准输入和标准输出。

一名学生在学习向上取整函数时，写下了以下伪代码：

```text
function f(a, b):
    i <- b
    while i >= 2:
        if a mod i = 0:
            return a / i
        end if
        i <- i - 1
    end while
    return a
end function
```

你知道这段代码实现得不正确，但对这名学生定义的函数 $f(a,b)$ 的性质很好奇。请计算 $\sum_{i=1}^{n}f(n,i)$。

## 输入格式

第一行包含测试用例数 $T$（$1\le T\le10^3$）。每个测试用例占一行，包含一个整数 $n$（$1\le n\le10^9$）。

## 输出格式

对于每个测试用例，在一行中输出一个整数，表示答案。


## 样例 1

### 输入

```text
3
5
451
114514
```

### 输出

```text
21
10251
7075858
```
