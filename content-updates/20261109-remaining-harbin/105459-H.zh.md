# 子序列计数



给定长度为 $$$m$$$ 的序列 $$$\{t\}$$$，以及长度为 $$$L$$$ 的序列 $$$\{s\}$$$。序列 $$$\{s\}$$$ 从左到右由 $$$n$$$ 个连续段组成，其中第 $$$i$$$ 段包含 $$$l_i$$$ 个相同元素，每个元素的值均为 $$$v_i$$$。



序列 $$$\{s'\}$$$ 由 $$$\{s\}$$$ 按一定规则打乱得到。具体地，$$$\{s'\}$$$ 满足 $$$s'_{i \cdot k \bmod L} = s_i$$$，下标从 $$$0$$$ 开始。其中 $$$k$$$ 是给定的正整数常量，保证 $$$\gcd(k, L) = 1$$$。



求 $$$\{t\}$$$ 作为子序列在 $$$\{s'\}$$$ 中出现的次数。形式化地，若存在严格递增的下标序列 $$$0 \le i_1 \lt i_2 \lt \dots \lt i_m \lt L$$$，使每个 $$$j = 1, 2, \dots, m$$$ 都满足 $$$t_j = s'_{i_j}$$$，则认为 $$$\{t\}$$$ 在这些下标处构成 $$$\{s'\}$$$ 的一个子序列。你需要计算满足条件的不同下标组数。答案可能很大，请输出结果对 $$$998244353$$$ 取模的值。



## 输入格式



第一行包含四个整数 $$$n, m, k, L$$$（$$$1 \le n \le 2 \times 10^3$$$，$$$1 \le m \le 10$$$，$$$1 \le k \lt L \le 10^9$$$，$$$\gcd(k, L) = 1$$$）。



第二行包含 $$$m$$$ 个整数，描述序列 $$$\{t\}$$$（$$$1 \le t_i \le 10^3$$$）。



接下来 $$$n$$$ 行描述序列 $$$\{s\}$$$，每行包含两个整数 $$$l_i, v_i$$$（$$$1 \le l_i \le 10^9$$$，$$$1 \le v_i \le 10^3$$$）。保证 $$$\sum_{i=1}^n l_i = L$$$。



## 输出格式



输出一个整数，表示结果对 $$$998244353$$$ 取模的值。
