# 一维星系



在一个神奇的一维空间中，有 $$$n$$$ 颗行星，编号为 $$$1$$$ 到 $$$n$$$。初始时（$$$t=0$$$），编号为 $$$i$$$ 的行星位于 $$$x_i$$$，质量为 $$$w_i$$$，质量可以为负数。现实世界中行星受引力作用而运动，这个一维星系中的行星也受到吸引而移动，但其运动并不遵守通常的物理定律。具体来说，对于任意一颗行星，如果其左侧所有行星的质量之和大于右侧所有行星的质量之和，它会在下一时刻向左移动一个单位；如果右侧质量之和更大，则向右移动一个单位；如果两侧相等，则保持原位。可以认为行星不会发生物理碰撞，它们能够相互穿过。



形式化地，令编号为 $$$i$$$ 的行星在时刻 $$$t$$$（$$$t = 0, 1, 2, \ldots$$$）的位置为 $$$x_{i,t}$$$。此时它左侧行星的总质量为 $$$w_{i,t}^l = \sum_{j\ :\ x_{j,t} \lt x_{i,t}} w_j$$$，右侧行星的总质量为 $$$w_{i,t}^r = \sum_{j\ :\ x_{j,t} \gt x_{i,t}} w_j$$$。下一时刻的位置 $$$x_{i, t+1}$$$ 为：



$$$$$$ x_{i, t+1} = \begin{cases} x_{i,t} - 1, & w_{i,t}^l \gt w_{i,t}^r \\ x_{i,t} + 1, & w_{i,t}^l \lt w_{i,t}^r \\ x_{i,t}, & w_{i,t}^l = w_{i,t}^r \end{cases} $$$$$$



有 $$$q$$$ 次询问，每次询问编号为 $$$i$$$ 的行星在指定时刻 $$$t$$$ 的位置。请回答这些询问。



## 输入格式



第一行包含两个整数 $$$n$$$ 和 $$$q$$$（$$$1 \le n, q \le 10^5$$$），分别表示行星数量和询问数量。



接下来 $$$n$$$ 行，第 $$$i$$$ 行包含两个整数 $$$x_i, w_i$$$（$$$-10^9 \le x_i, w_i \le 10^9$$$），表示编号为 $$$i$$$ 的行星的初始位置和质量。



随后 $$$q$$$ 行，每行包含两个整数 $$$t$$$ 和 $$$i$$$（$$$0 \le t \le 10^9$$$，$$$1 \le i \le n$$$），描述一次询问。



## 输出格式



输出 $$$q$$$ 行，依次回答相应的询问。
