# TB · 训练工作台

TB 将题库、图文题解、C++ / Python 编辑、本地评测和训练记录放在同一个工作台，支持 Codeforces、AtCoder、牛客和洛谷。本机 SQLite 保存代码与待同步记录，账号服务支持跨电脑恢复。

## 安装与更新

Windows 10/11 x64。[用户版安装包](https://47.82.84.74/updates/assets/1.4.1/TB-Setup-1.4.1-win64.exe)包含 C++ 编译器、Python 3 运行时和离线 WebView2；[便携版](https://github.com/3097729287/acm-algo-trainer/releases/download/v1.4.1/TB-1.4.1-win64.zip)需要完整解压。GitHub 仅公开用户版；管理员程序仅供维护者本机自用。发布页提供校验清单及从 1.4.0 升级的增量包；更旧版本可使用完整 Setup。管理员只保留维护者本机程序和快捷方式。

保存草稿并退出 TB 后安装到原目录，个人数据库、代码和导入内容保留。自动更新会先保存草稿、在线备份 SQLite、验证 SHA-256，再替换程序。跨电脑使用同一账号时，各电脑应升级到同一版本。原站登录保存在 TB 专用浏览器中，无需扩展。

- 算法实验室进入沉浸式教学，正文适度放大，翻页、目录与退出集中到顶部；短暂离开恢复位置，离开满三分钟回课程入口，输入与草稿保留。

- 设置二级页、更新按钮、恐龙与行星环动画统一调整；猫猫头教主单列特别鸣谢。账号恢复先显示独立加载页，修复 Setup 检查旧记录时的内部错误弹窗。
- 管理员仅生成本机程序与快捷方式，无管理员 Setup 或便携包。612 项后端、完整前端 CI、原生窗口、新装/卸载、1.4.0 升级及实际增量验证通过。[CI](https://github.com/3097729287/acm-algo-trainer/actions/runs/39919816597)。

## 1.3.4 的变化

- 相同原题去重并保留旧编号、草稿及提交；下一题无缝切换，题解重复点击收起，首次打开保持宽度。筛选改为文件夹浏览，统一表格、顶栏与浮层对齐。

## 题库与成长

公共种子保留 **5824 条原始题目、2427 份题面、1307 份默认题解、1307 份详细题解、443 篇讲义**；界面按原题去重，旧编号、内容和作答关联保留。未缓存的题面仍需联网读取。新增题解只限题目难度小于等于 2200（含 2200），未知难度先核验。[题解政策](docs/editorial-policy.md)。

经验等级和能力段位分别成长。5 级解锁段位，至少 5 道已验证独立首次官方 AC 后，取最高 5 题难度的中位数作为能力分。门槛依次为 **0、800、1000、1200、1600、1800、2000、2100、2200**，对应黑铁至王者。这是题库训练尺度上的参考值，非直接使用原站账号 rating。[完整规则](docs/progression.md)。

原站 AC 才计入通过成绩；运行公开样例不会冒充 AC。1.3.2 全部计时训练通过原站浏览器提交，本地仍可运行样例；历史本地评测记录保留其真实范围。排行榜显示等级与能力段位，支持每日一次爱心和私密留言。
