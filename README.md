ToBe public statement resources

Immutable original PDFs and images, addressed by SHA-256. These exact public resources are already part of the public source library. This branch contains no accounts, keys, private state or administrator packages. Original content retains its source licenses and attribution; see https://github.com/3097729287/acm-algo-trainer/tree/main/data/library and the statement source/resource manifests there. New NC53264 diagrams are faithful regions of the official JOISC 2014 day 4 PDF, credited in the statement.

This branch serves resources only, not an application release. Desktop clients verify every declared size and digest and cache successful downloads for offline reading.
