# TB · 训练工作台

TB 将题库、图文题解、C++ / Python 编辑、本地评测和训练记录放在同一个工作台，支持 Codeforces、AtCoder、牛客和洛谷。本机 SQLite 保存代码与待同步记录，账号服务支持跨电脑恢复。

## 安装与更新

Windows 10/11 x64。[安装包](https://github.com/3097729287/acm-algo-trainer/releases/download/v1.3.0/TB-Setup-1.3.0-win64.exe)包含 C++ 编译器、Python 3 运行时和离线 WebView2；[便携版](https://github.com/3097729287/acm-algo-trainer/releases/download/v1.3.0/TB-1.3.0-win64.zip)需要完整解压。发布页提供校验清单和对应版本的增量包。

保存草稿并退出 TB 后安装到原目录，个人数据库、代码和导入内容保留。自动更新会先保存草稿、在线备份 SQLite、验证 SHA-256，再替换程序。跨电脑使用同一账号时，各电脑应升级到同一版本。原站登录保存在 TB 专用浏览器中，无需扩展。

## 1.3.0 的变化

- **统一工作台：** 去除侧栏、顶底栏分割线与状态图标边框，表头随页面透明度变化，数值与控件对齐。题库和我的训练只保留题目列表，比赛使用分类目录；目录中的具体比赛直接显示题号、难度与开始按钮。
- **集中筛选：** 比赛分类、知识点、难度、提交结果和常用筛选收进筛选按钮，知识点使用二级菜单。平台简写为 CF、AC 等；ACM 赛事只归入 ACM，不因托管在其他平台而重复归类。列表和比赛均可切换正序、倒序。
- **连续练习：** 顶栏火焰显示连续练习天数，每天至少一次正式提交；样例运行、浏览和只存草稿不计入。按北京时间结算，今天未练习时保留截至昨天的连续记录。火焰在 **1 / 2 / 4 / 7 / 15 / 30 / 60 天**分七档成长，60 天后大小保持不变。
- **知识雷达与题单：** 成长页可点击专题进入二级雷达，再点具体知识点筛题。仅纳入基础至常见图论层次的知识，难度为估计值。题单先提供思想、模板、交互、练习、迁移五阶段框架及双指针交互示例；正式精选与逐题分析仍待填充，不把候选题当成已完成课程。
- **四种训练：** 综合、专项、随机单题、重现赛共用紧凑配置；简单、普通、困难分别使用绿、黄、红，默认范围 0–10000。专项知识点和重现场次在筛选中选择；重现赛难度筛选整场中位难度，保留原题序与全部题目。
- **设置与勋章：** 设置首页采用拼图布局，含咖啡变冷、气球、小恐龙、灯泡、云等动画；账号与身份、鸣谢各有独立入口。鸣谢新增 jiahao27，每人一行。支持 GIF / 动态 WebP / PNG 背景和本机定时播放列表；题解透明度可单独调节。段位和不同成就称号采用不同勋章；同步中显示旋转图标，完成后短暂提示。
- **Python 3：** 编辑器可切换 C++17 与 Python 3，保存草稿及提交语言；本地运行沿用 Windows Job 时间、内存和输出限制。随包提供独立 CPython 3.13.16，无需另装 Python；原站从实际语言控件选择 Python 3 / PyPy 3。
- **独立管理员入口：** 使用 `TB新版.exe --admin` 或“TB 管理员工作台”快捷方式。等级、段位可自行修改，全部成就与称号可解锁。数据和浏览器位于独立 `admin-workspace/`，不登录用户云账号或上传公共排行。
- **提交窗口：** 原站提交打开专用浏览器窗口；最终回执保存并在 TB 显示后，自动关闭本次窗口。登录、验证、错误和结果不确定时保留窗口；其他页面不受影响。新手指引同步更新。

## 题库与成长

公共种子包含 **5819 题（5646 可见、173 隐藏）、2422 份题面、1302 份默认题解、1302 份详细题解、376 篇讲义**。未缓存的题面仍需联网读取；所有已有内容保留。新增题解只限难度严格低于 2200，未知难度先核验。[题解政策](docs/editorial-policy.md)。

经验等级和能力段位分别成长。5 级解锁段位，至少 5 道已验证独立首次官方 AC 后，取最高 5 题难度的中位数作为能力分。门槛依次为 **0、800、1000、1200、1400、1600、1800、2000、2100、2200**，对应黑铁至王者。这是题库训练尺度上的参考值，非直接使用原站账号 rating。[完整规则](docs/progression.md)。

原站 AC 才计入通过成绩；运行公开样例不会冒充 AC。重现赛通过原站表单提交，盲组题训练使用其标注的本地评测范围。排行榜显示等级与能力段位，支持每日一次爱心和私密留言。

## 数据与开发

账号同步包括训练、完整提交代码、草稿、目标、经验、收藏和偏好；冲突草稿另存。原站 Cookie 与翻译密钥不进入公共题库，翻译密钥使用 Windows DPAPI 保护。设置中的数据导出为 JSON，不含密码、Cookie 或 API 密钥。

```powershell
python backend/backend.py --offline

cd frontend

```
