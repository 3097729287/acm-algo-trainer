# TB · 训练工作台

TB 将题库、图文题解、C++ / Python 编辑、本地评测和训练记录放在同一个工作台，支持 Codeforces、AtCoder、牛客和洛谷。本机 SQLite 保存代码与待同步记录，账号服务支持跨电脑恢复。

## 安装与更新

Windows 10/11 x64。[安装包](https://github.com/3097729287/acm-algo-trainer/releases/download/v1.3.1/TB-Setup-1.3.1-win64.exe)包含 C++ 编译器、Python 3 运行时和离线 WebView2；[便携版](https://github.com/3097729287/acm-algo-trainer/releases/download/v1.3.1/TB-1.3.1-win64.zip)需要完整解压。发布页提供校验清单和对应版本的增量包。

保存草稿并退出 TB 后安装到原目录，个人数据库、代码和导入内容保留。自动更新会先保存草稿、在线备份 SQLite、验证 SHA-256，再替换程序。跨电脑使用同一账号时，各电脑应升级到同一版本。原站登录保存在 TB 专用浏览器中，无需扩展。

## 1.3.1 的变化

- 顶部统一搜索与筛选，移除重复提示；收藏、排序和方向收进筛选。比赛默认列表，可在筛选中开启文件夹浏览。
- AC 显示为“今日之前的累计 + 今日 AC”，如 `AC:82`、`AC:82+2`。火焰改为静态手绘，段位使用装饰头像框，成长页整合大型账号统计与知识雷达详情。
- 四种模拟赛共用生成和开始流程，专项知识点及重现场次直接选择。难度预设为 1000–1400、1300–1700、1600–2000、1900–2200；修复浮层下拉选择失效。
- 设置新增可修改、冲突检查和重置的快捷键；导航名称、分组与顺序合为一个编辑器。二级设置由顶栏面包屑标明，Esc 返回首页。
- 修复列表被强制全透明，统一各页与题面、编辑器、题解的透明度。进入题目后铺满整个客户区，隐藏菜单与外框，返回箭头或 Esc 退出。
- 排行榜铺满内容区，奖牌移到最前；本人爱心有颜色且无留言按钮。爱心动态始终保留栏目，仅显示北京时间当天记录；删除使用就近确认浮层。
- 设置拼图自适应填满页面；恐龙往返、云二维漂移、灯泡柔和发光，新增地球建造与爆裂循环。鸣谢居中放大，通知移除题库更新设置。
- 账号设置先显示已登录的本机身份，补充状态后台读取。窗口最小化不再修改主 WebView 的可见性；渲染进程退出后限次恢复，持续失败显示恢复入口，草稿保留。

## 题库与成长

公共种子包含 **5819 题（5646 可见、173 隐藏）、2422 份题面、1302 份默认题解、1302 份详细题解、376 篇讲义**。未缓存的题面仍需联网读取；所有已有内容保留。新增题解只限难度严格低于 2200，未知难度先核验。[题解政策](docs/editorial-policy.md)。

经验等级和能力段位分别成长。5 级解锁段位，至少 5 道已验证独立首次官方 AC 后，取最高 5 题难度的中位数作为能力分。门槛依次为 **0、800、1000、1200、1400、1600、1800、2000、2100、2200**，对应黑铁至王者。这是题库训练尺度上的参考值，非直接使用原站账号 rating。[完整规则](docs/progression.md)。

原站 AC 才计入通过成绩；运行公开样例不会冒充 AC。重现赛通过原站表单提交，盲组题训练使用其标注的本地评测范围。排行榜显示等级与能力段位，支持每日一次爱心和私密留言。

## 数据与开发

账号同步包括训练、完整提交代码、草稿、目标、经验、收藏和偏好；冲突草稿另存。原站 Cookie 与翻译密钥不进入公共题库，翻译密钥使用 Windows DPAPI 保护。设置中的数据导出为 JSON，不含密码、Cookie 或 API 密钥。

```powershell
python backend/backend.py --offline
# 另一个终端
cd frontend
npm ci
npm run dev
```
