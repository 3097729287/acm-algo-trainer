# 模板与算法实验室整理

2026-10-30，本机 1.4.30 教学修订。公开正式版仍为 1.4.29，本次不公开发布、不部署服务。正常程序直接加载打包后的前端与公共模板资源；EXE 和后台运行模块沿用已安装版本，源码归属分别记录在 BUILD-INFO。

用户要求：多种操作配套的算法、数据结构要同时有讲解和可复用模板，并放入实验室；不再混入独立“从零讲”目录。本次核对现有 467 份讲义，将下表 15 份通用操作讲解接入 7 个已有算法专题，另增线性基。24 份原模板的两版代码、最小示例与原练习编号逐字段保留；补上 4 份完整模板后共 28 份。

| 专题 | 迁移讲解数 | 主要内容 |
| --- | ---: | --- |
| 并查集 | 1 | 查根、合并、连通性、集合大小 |
| 树状数组 | 5 | 单点加、前缀和、区间和、逆序对、第 k 个频次 |
| 懒标记线段树 | 2 | 建树、区间加、区间和、下传与回收 |
| 字典树 | 2 | 插入、整词计数、前缀计数、删除一份 |
| 倍增 | 3 | 函数图后继、二进制步长拼接、64 位步数 |
| 最大流与最小割 | 1 | 加边、正反残量、增广、割的源侧 |
| Li Chao 树 | 1 | 登记离散坐标、插入整条直线、点查询最小值 |
| 线性基 | 新增 | 插入、表示性、最大／最小异或、合并、第 k 小、最小非零值 |

原 SQLite 讲义及题解中的相应引用没有删除；只调整独立目录的展示归属。模板讲解保存原文和原图，实验室可继续阅读，旧独立讲义入口进入对应模板。语言、标准库工具、基础概念以及依赖某道题特有条件的应用段落没有被按关键词搬走。未把哈希表容器操作或 vector 的多种接口误判成算法模板。

模板的讲解版并列显示问题、不变量、各操作的输入／输出／前提、边界和 C++ 代码；竞赛版保留精简实现与约定。两版均可复制或另存，主应用提供模板与实验室的双向入口。原代码插入规则与账号私有模板存储沿用。

八个专题各有七节操作课程。实验展示实际父指针、覆盖区间、sum/lazy、经过／结束计数、倍增表、正反残量、直线取值或主元二进制；除最大流的固定残量推演外，允许追加操作与重新尝试。线性基允许修改原数、逐位消元、输入查询、按序取值和合并另一组。所有状态是确定性演算，不执行读者输入的源代码。

并查集继续保留已有五道真实原题的跟做指导；其余七个专题各有五个原创课堂练习，分别覆盖直接操作、条件变化与最小反例，标明课堂性质，不附加虚构比赛评级，不把自检当作 AC。正式练习继续通过既有工作台；课程草稿、解释、提示与自检存入对应专题的私有偏好，保留其它专题及既有记录。

## 验证

- `node tests/algorithm-operations-model.mjs`：独立枚举全部小规模异或值，对照秩、查询、第 k 小；随机数组、集合、字符串和函数图另用朴素模型核对，最大流对照所有割。核对 15 份原文／图及 24 份旧模板代码逐字段保留。
- `python scripts/check_algorithm_operations.py --compiler <g++> --report <临时报告>`：实际编译新增四份模板的两版实现及两版最小示例，2,302 组独立对照，含满秩 64、第 63 位、空结构、平行边、自环、反向改路、大坐标乘法和函数图。
- `node tests/algorithm-operations-ui.mjs`：56 节章节渲染、35 道新课堂题的错答／改答、提示和草稿恢复，旧入口跳转、模板两版、追加操作及非法输入；1366／1024／390 宽度、深浅主题。没有原站账号提交。

前端构建、完整后端检查、全部模板示例编译，以及正常冻结程序的新状态／升级副本验证，结果写入本机 `.backups/algorithm-learning-20261030/`。实际本机安装、当前提交和备份位置以项目根目录《当前更新.md》为准，不把隔离验证当作已安装。

## 维护

内容来源是 `scripts/organize_algorithm_learning.py` 中逐条审核的专题与讲义清单，新四份 C++ 以 `backend/resources/algorithm-templates/` 为源。运行生成器同步 `code-templates.json` 与 `algorithm-learning.json`，再运行模型、C++ 和 UI 验证。该脚本不改个人数据库，也不改题库种子，避免覆盖同时进行的题解更新。

树状数组和线段树的新操作实验与公开模板均采用外部 0 下标、左闭右开区间；原讲义中独立推导使用的其它编号约定，在展开原文时单独交代，不能与当前调用混算。线性基 kth 从 0 编号，包含空集的 0，返回不同结果而非下标方案。最大流的残量小实验演示增广与撤回，完整 Dinic 代码再讲分层及当前弧，不能称为运行用户 C++。
