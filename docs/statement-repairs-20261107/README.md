# 2026-11-07 公共题面修订

原公共种子包含 13,417 道题、13,287 条题面记录，其中 371 道题面的原文或资源未通过完整性审计。本轮按明确的原题编号、镜像对应关系和全部既有样例查找来源，恢复 219 道；其余 152 道保持原身份并禁用入口。

修订后的公共种子包含 13,363 条题面记录。新增的 76 条与替换的 143 条均沿用原题 ID。恢复清单、原站身份及审核结果见 [recovery.json](recovery.json)。资源按 SHA-256 保存，原有资源仍保留。

第一批导出 776 条中文补写／替换，换源后再导出 80 条；《Mining a》另作逐页核对。换源导致旧译文不再对应原稿时，旧内容归档，只有重新绑定和通过校验的译文进入当前显示。最终可见内容中的附带中文译文数量以全库验收统计为准，不把归档译文重复计入。

13 份新恢复 PDF 的提取文本未通过校验，保留原件并暂时关闭中文切换，见 [pdf-originals.json](pdf-originals.json)。这些题目的原始 PDF 完整可读，不阻止比赛开始。原稿缺失的条目与“原稿存在、中文暂不可用”分开处理。

审核数据：

- [declarations.json](declarations.json)：原稿可证明的变量名称／长度关系修正。
- [source-format.json](source-format.json)：嵌套公式分隔符修正，不改动变量、约束和文字含义。
- [display-repairs.json](display-repairs.json)：货币美元符号、分段递推排版，以及以已渲染通过的既有中文保留可读题面。
- [mining-pdf.json](mining-pdf.json)：原始 PDF 的两页核对摘要与哈希。

复查使用明确指定的公共 SQLite，拒绝个人数据库。`scripts/audit_statement_render.py` 导出可见原文／中文，`frontend/tests/statement-corpus.mjs` 使用程序实际的 Markdown、公式插件进行离线渲染。`scripts/check.py` 验证关系、资源哈希及后端行为。翻译保护校验并不等同于全库人工语义复核。

所有补丁均绑定先前题面内容哈希；输入变更时拒绝覆盖。恢复和显示修复脚本使用新的输出路径，已导出的补丁需先保留并针对前序种子重新准备，禁止叠加覆盖。
