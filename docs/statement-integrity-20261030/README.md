## 教学及个人数据保护

以 SQLite 在线备份获取最新版公开种子，包括已提交 WAL。提交前重新核对安装版内容提交及全部公共表。完整保留安装版的 1,674 份默认题解、1,674 份详细题解、467 份讲义、7,214 条讲义关联、294 条方法记录和 564 个公共题单；与基线逐行比较，而不是仅比较数量。相对开发父提交新增的教学内容来自已交付种子，本分支没有创作这些内容。

原有 2,898 份中文逐份保留；6 份仅经过项目既有确定性清理，与清理后的原对象逐字比较通过，原始文本仍在基础种子。`prepared-summary.json` 中旧阶段的 `translations_archived: 6` 是清理前后对象比较产生的旧统计标签，不能解释为 6 份译文丢失。最新原文与译文所绑定的原文快照分别保存，没有伪造新翻译或把旧译文哈希改成新原文哈希。

实际旧版公共种子升级在独立库中验证：合并新公共内容后，8 类合成私人事实、私有导入、用户修改的题面与中文均与升级前在线备份一致。真实个人库读取数为 0。公共题单返回值会过滤隐藏题，持久化题单保持原样；历史按原 ID 可读。

## 合并方式与限制

代码、前端、公共文本源、`statement-patches` 和 `statement-assets` 必须一起合并。库 schema 为 7；旧版程序不能通过 schema 1 内容热更新读取 `tb-asset:` 资源。本分支主动拒绝在这类热更新包中分发资源引用，主会话应统一构建程序后再执行既有 SQLite 合并升级流程。不要以公共 SQLite 文件替换个人库。

修复分片校验逐题旧内容 SHA-256。如另一内容会话已经改动同题，重建会明确报冲突，需先结合最新公开种子合并；不要去掉校验或把旧种子覆盖到新种子。教学 JSON 的更新是对已交付安装版的保全，主会话仍须合入更晚交付的内容。

358 题目前未达到完整离线阅读标准，原因包含正文未核实、资源或嵌入媒体缺口、镜像占位输入输出、公式渲染限制等。退休状态是可恢复的公开目录标记；后续取得经过核验的完整题面后，仅自动恢复本审计保存的先前可见性，不清除既有范围策略。

后台重新抓到正文不会自行认定审计通过，也不会用未经复核的响应替换已保存的中文。恢复需由新公共种子完成全量核验，或提供与当前正文相符的审计校验值；同一私人快照上的编辑仍可保存。这防止安装后后台重试冲掉公式、资源和旧中文的核验结果。

复现脚本见 `scripts/statement_corpus/README.md`；所有原始捕获、不可变下载缓存及验证日志留在本会话隔离目录。公共文件不含原始页面、Cookie、令牌、个人记录或本机绝对路径。最终命令与结果、资源和数据文件校验清单随交接材料交付。
