# 动态复习

首次官方 AC 的下一北京时间日期安排首次复习。之后每天根据题目相对能力分的难度、复习中的官方通过、失败次数和是否依赖题解分配任务，不设固定周日、七天或月末清单。未完成的到期题继续保留，跨日不重复创建同一轮任务。

每轮复习使用独立草稿。首次打开给出对应语言的空模板；重新进入未完成的同一轮会恢复本轮代码。原作答、旧复习代码和提交历史都保留。“运行样例”不会完成复习，必须有这轮打开之后、绑定这轮上下文的官方 AC。仅在昨天看过题解不影响今天独立重写；本轮再次查看题解则按辅助完成处理，次日再练。

有至少五道已知难度的独立首次官方 AC 才采用实际能力分，口径与能力段位一致。题目难度不高于能力分减 200 时，完成一次无错误、未看题解的复习后，免去后续长期重写；之后出现新的官方错误会重新安排。未知难度或尚在定级时不套用简单题豁免。

间隔采用逐题稳定度：独立通过后按相对难度和错误次数乘以约 1.2–3.2 的系数，最短一天、最长九十天；辅助通过重置为次日。到期任务按遗忘风险、难度、失败记录以及是否已经开始排序。它是用于编程练习的调度启发式，不是经过测量的个人记忆概率，也不改变掌握度、能力分或已有经验。

每日预算复用目标中填写的可用分钟数，没有目标时参考 90 分钟。单题估计 5–40 分钟，每天通常至多八题，已打开的任务保留；已完成任务也占当天预算，刷新不会无止境补题。积压或复习占据大部分预算时减少新题，必要时成为复习日。手动清空或移除训练当天不会被目标计划自动加回，代码与目标记录仍保留。

复习状态、会话与回执关联保存在已有私有偏好日志，草稿使用已有表的独立上下文，随当前账号同步。没有新增共享服务协议或表，也不删除旧代码。升级时依据旧的真实官方 AC 接入计划，历史积压按每日预算逐步消化。

调度思路参考 [Murre 与 Dros 对艾宾浩斯遗忘曲线的复现](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0120644)。论文使用特定记忆材料与实验条件；本软件的题目难度、间隔和每日预算参数属于工程设计。
