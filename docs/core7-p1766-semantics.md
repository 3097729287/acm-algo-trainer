# P1766《液体滴落》的语义核对

2026-10-30 复核[洛谷原题](https://www.luogu.com.cn/problem/P1766)。本题仍待补充规则，不计入已写题解数。

原题允许线段相交，端点不属于轨道；一旦沿某条轨道下滑，中途的其它交点不会改变它的运动。后一点已有说明，不是当前疑问。尚未规定的是竖直下落第一次同时碰到两条轨道内部时选哪一条。

例如下面的输入满足原题公开的数量和坐标范围，两条线段均不水平、不竖直：

```text
2 0
-1 2 1 0
-1 0 1 2
```

液滴从 x=0 上方落下，首先同时碰到两条轨道在 (0,1) 的内部交点。选择第一条便沿它到 (1,0)，随后在 x=1 落出；选择第二条则到 (-1,0)，最终 x=-1。两条路径都遵守下滑期间不受交点影响、端点不计的条件，最后答案却不同。题面没有依据让我们任选一个答案并称为完整解法。

另一个边界与上述歧义不同：离开当前轨道的下端点后，可以立即碰到另一条轨道同高的内部，不能只搜索严格更低的轨道。例如：

```text
2 2
1 4 3 2
2 1 4 3
```

液滴先在 (2,3) 碰到第一条轨道，滑到 (3,2)。这个点不属于第一条轨道，却在第二条轨道内部，因此还要沿第二条滑到 (2,1)，最终横坐标为 2。把下一次命中限制成严格更低，会错误地直接输出 3。

`scripts/core7_review_p1766.py` 用有理数比较实际线段交点，列出所有同时命中的分支，核验这两个具体输入。它只是语义反例检查，没有验证完整算法、最大规模性能或原站通过。

水平轨道没有唯一较低端点，竖直轨道也需要另行明确。它们不影响上述非退化反例。已经向用户询问补充规则，其余题解继续；不从二手程序猜测未公开保证，不改写公共原题。
