# 紧凑更新验收

当前为 1.6.8 候选，尚未发布。目标按真实客户端从检查更新、下载、保全数据、安装到重新可用计时；一分钟目标不能用服务器本机下载或提前修改百分比冒充。

1.6.6 旧更新器只认识完整安装 EXE 或旧文件 ZIP，无法直接解释二进制差分。兼容入口使用小型安装引导器，识别并校验原有解释器、版本与程序基线，下载对应版本的紧凑包；未识别的安装和新用户走固定 SHA-256 的完整安装包。旧版不能误选新格式 ZIP。

1.6.8 起可直接识别 `ToBe-Compact-Update-<旧版>-to-<新版>-win64.zip`，复制验证过的冻结运行器，等待主程序正常退出后重建与替换文件。下载中每块更新实际字节；中断保留与 URL、大小、摘要绑定的部分文件，有限重试并验证 HTTP 范围，完整 SHA-256 通过后才允许安装。

`binary_delta.py` 解码有输出及解压上限的 BSDIFF40 分块，逐块绑定源偏移、长度和摘要，再核验完整目标。生成器单独使用 [bsdiff4 1.4.2](https://pypi.org/project/bsdiff4/1.4.2/)，不向应用加入该扩展；本机独立工具的 wheel 已按 PyPI 摘要校验。标准库解码通过八组独立原生实现生成的向量及完整文件校验；不能用同一编码器自测代替安装验收。

`compact_update.py` 只允许程序、工具链与公共题库路径；账号、草稿、提交、浏览器配置和自建数据不进入载荷。先重建并核验全部变更文件、保存原文件和恢复日志，再替换；版本最后写入。运行器单独固定摘要；生成器证明各基线均未改变的文件不在用户更新时重新扫描或复制，完整升级演练另行核对全目录。替换失败回滚，异常退出的日志可在下次安装时恢复，单实例锁禁止并行替换。仅回收校验一致的旧恢复副本，保留最近两代和所有未知文件。

题库合并批量读取已知记录，内容未变时不重复写入。更新器已有完整备份时，逐页比较源与副本，只忽略 SQLite 在线备份会重写的头部计数，所有表结构、未知记录及正文页仍参与比较；有 WAL／热日志或任何内容变化时继续创建在线备份。真实用户题库的隔离副本中，备份 13.857 秒、合并 14.747 秒；旧题解逐项未变，未再创建第二份题库恢复点。这仍不是完整网络更新的计时。

公共题库从当前完整源码构建，再与已核验的旧公共种子对照，保留原有不可变资源页。新增资源按 SHA-256 在国内端提供，首次读取时校验并缓存；所有题目、题面、题解、讲义及题单正文与完整源码逐项相同。当前候选保留 3,191 份普通和 2,306 份详细题解。仅供本地测试的 Rust 版继续保留全部本地资源。

阶段事实：已用本机旧种子成功生成 **970,274 字节**的题库差分，重建结果与 434,143,232 字节目标逐字节一致。它仅证明这一种子差分；安装引导器、各版本载荷、新装／升级与真实网络整链计时尚待完成。

早期 Inno 引导器约 2.1 MB，保留作兼容验证。新的 Windows 引导器约 73 KB，使用系统 PowerShell／TLS 和固定摘要的随附 Python；四段并行下载验证 HTTP 范围、完整大小及 SHA-256，不接受用户提供的 URL。已完成含中文、空格目录的实际网络安装，1.6.6 的 1,964,412 字节载荷下载 14.722 秒、引导器安装共 36.781 秒，5,093 个文件逐项一致；该记录未包含完整真实用户数据库备份。

1.6.7 的公开种子采用另一种物理布局。布局变体的十二张公共表及全部 6,166 项资源与完整公开内容逐项等价，程序与正文一致。新增题解中的公开插图若已经存在本机题库，只允许读取两张题解表的固定 `images` 字段，问题 ID 作为 SQL 参数，匹配固定完整摘要才可复用；草稿、提交、账号与凭据不参与。缺失时从国内不可变资源下载并验证压缩与解压后的双重摘要，所有插图补入新文件后仍须核验整个种子的固定 SHA-256。

插图物理位置由 SQLite 官方[文件格式](https://sqlite.org/fileformat2.html)解析，并与 SQLite 自身解码的字段逐段交叉核对；原文件不会修改。包含页溢出和多层树的 512、4,096、65,536 字节页面测试均通过。真实变体已完成字节精确往返，插图复用可将约 4.93 MB 的种子差分降至 844,859 字节。应用本体与独立更新引导器分别记录实际源码提交，完整安装包的应用源码仍固定为 `94111846`，不改写已验证的完整包。
