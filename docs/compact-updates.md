# 紧凑更新验收

当前为 1.6.8 候选，尚未发布。目标按真实客户端从检查更新、下载、保全数据、安装到重新可用计时；一分钟目标不能用服务器本机下载或提前修改百分比冒充。

1.6.6 旧更新器只认识完整安装 EXE 或旧文件 ZIP，无法直接解释二进制差分。兼容入口使用小型安装引导器，识别并校验原有解释器、版本与程序基线，下载对应版本的紧凑包；未识别的安装和新用户走固定 SHA-256 的完整安装包。旧版不能误选新格式 ZIP。

1.6.8 起可直接识别 `ToBe-Compact-Update-<旧版>-to-<新版>-win64.zip`，复制验证过的冻结运行器，等待主程序正常退出后重建与替换文件。下载中每块更新实际字节；中断保留与 URL、大小、摘要绑定的部分文件，有限重试并验证 HTTP 范围，完整 SHA-256 通过后才允许安装。

`binary_delta.py` 解码有输出及解压上限的 BSDIFF40 分块，逐块绑定源偏移、长度和摘要，再核验完整目标。生成器单独使用 [bsdiff4 1.4.2](https://pypi.org/project/bsdiff4/1.4.2/)，不向应用加入该扩展；本机独立工具的 wheel 已按 PyPI 摘要校验。标准库解码通过八组独立原生实现生成的向量及完整文件校验；不能用同一编码器自测代替安装验收。

`compact_update.py` 只允许程序、工具链与公共题库路径；账号、草稿、提交、浏览器配置和自建数据不进入载荷。先重建并核验全部新文件、保存原文件和恢复日志，再替换；版本最后写入。替换失败回滚，异常退出的日志可在下次安装时恢复，单实例锁禁止并行替换。

公共题库从当前完整源码构建，再与已核验的旧公共种子对照，保留原有不可变资源页。新增资源按 SHA-256 在国内端提供，首次读取时校验并缓存；所有题目、题面、题解、讲义及题单正文与完整源码逐项相同。当前候选保留 3,191 份普通和 2,306 份详细题解。仅供本地测试的 Rust 版继续保留全部本地资源。

阶段事实：已用本机旧种子成功生成 **970,274 字节**的题库差分，重建结果与 434,143,232 字节目标逐字节一致。它仅证明这一种子差分；安装引导器、各版本载荷、新装／升级与真实网络整链计时尚待完成。

引导器使用 Inno Setup 的 [DownloadTemporaryFile](https://jrsoftware.org/ishelp/topic_isxfunc_downloadtemporaryfile.htm) 验证固定 SHA-256，并用 [GetSHA256OfFile](https://jrsoftware.org/ishelp/topic_isxfunc_getsha256offile.htm) 核验已有工具；不下载或执行用户提供的 URL。
