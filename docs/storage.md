# 数据与代码整理

1.4.0 延用 SQLite 持久化及账号状态协议 1，不新增个人数据库表，也不删除历史迁移。共享服务保持原版本与表结构。

| 边界 | 内容 | 维护方式 |
| --- | --- | --- |
| 公共题库 `data/library.sqlite3` | 题目、题面、两版题解、讲义、图片、精确关联 | 从已提交的 `data/library` 重建；打包前检查完整性、外键、统计和无个人记录 |
| 账号个人 SQLite | 训练、草稿、完整提交代码、比赛、目标、经验、偏好 | 每账号独立；既有增量迁移保留，升级前用 SQLite 在线备份保全 WAL |
| 本机文档 SQLite | 目录缓存、联网记录、更新设置、DPAPI 密文 | 按原存储接口读写；会话不进入公共种子或云端学习快照 |
| 浏览器存储 | 设备界面设置、草稿恢复、背景、专用原站配置 | 安装升级保留；原站一方登录记忆只在本机加密 |
| 共享服务数据库 | 账号、同步状态、公开成绩、互动 | 本轮不部署服务或变更 schema |

前端删除了过时的全局浏览器准备弹窗、对应样式、事件分发和独立 UI fixture，保留登录检测兼容测试。课程/讲解/比赛分别使用现有组件及目录控件；没有建立重复状态系统。

后端将工作区构建与读取缓存分开，成长统计在加载题库前检查失效键。缓存只保存派生视图，不删除或替换提交、代码与题库；消费者得到独立副本。写入、外部 SQLite 提交、内容摘要、知识分析、北京时间日期与比赛到期参与失效。保留原建表与迁移入口，使旧安装仍可升级。

运行目录不作为源码和公共数据的来源；公共发行仅用户版。管理员包、个人备份和运行数据库不进入 GitHub 资产及校验索引。
