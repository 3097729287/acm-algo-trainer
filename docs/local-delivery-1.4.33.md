# ToBe 1.4.33 本机交付

普通用户版已通过实际安装器的新装和 1.4.32 覆盖升级，并完成本机更新。私有管理员程序独立打包、核对并更新，仅保留在维护者本机。尚未发布 1.4.33 公共资产或标签，公开稳定版继续为 1.4.32。

## 功能

设置 → 外观 → 代码主题提供 22 种配色与跟随界面选项，左侧滚动选择、右侧代码预览。Woodfish 风格效果由 CodeMirror 实现，使用的 MIT 色板附许可证，未注入外部 VS Code 扩展。编辑光标、括号、选区、透明度、模板选择、已学会标记、题面图片和工具栏一并调整。

成就改为手动领取，保留旧奖励与完成时间；难度从 1500 递进至 2300 并提供勋章，增加时段、单日提交／AC／WA、复习和互动成就。日常与任务分组，移除多余状态行。清空训练保留草稿和复习计划；普通单题首次实际修改代码后加入训练；模板题全部通过后移出继续练习。正在进行的原站比赛按官方结束时间倒计时，原站提供的详细错误信息保留显示。

题单缓存、预取及账号下的位置恢复已接入。代码模板和主题进入账号同步；隔离客户端和服务协议通过，未用两台实体电脑逐项验收。

## 性能和服务边界

原生加载窗口提前到 WebView 和数据库初始化之前。独立窗口组件创建耗时、题单模型热缓存耗时不能当作完整冷启动耗时。本次正常启动至账号及工作区核对完成约 22.4 秒，加载窗口首次可见时刻未在该次启动中捕获，因此不宣称整机冷启动秒开。

共享服务生产仍为 1.2.9。1.3.0 的 HTTP、隔离 MySQL 验证与更新包已准备，但未部署。三类榜单的连续第一星星／皇冠／天数徽章及公开译文共享需要该服务；013/014 只增加新表，部署前需独立授权、在线备份及旧表指纹核对。既有模板与账号同步不依赖这次服务更新。

清理只使用 Windows 回收站，不清空、不修改容量；不足以安全容纳旧候选时保留原文件。移动到回收站不等于释放磁盘空间。
