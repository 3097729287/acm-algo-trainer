启动侧栏从当前账号缓存读取已确认等级；没有记录时等待真实等级，避免把尚未读取误当成一级。缓存按账号隔离，真实一级仍只开放原有入口，隐藏和组合偏好继续生效。未知等级期间不改写恢复页面。

公开头像按账号、用户及摘要共享订阅。后端返回的已校验当前头像可以更新旧榜单摘要的映射；不同周期复用相同图片，临时请求失败自动退避并在恢复联网时重试。头像删除和账号切换丢弃旧请求。切换周期读取期间保留可见身份，榜单周期不匹配时停用互动操作。公开缓存继续限制24条／2MiB，不清理私有草稿。

比赛访问状态保存在App的当前访问对象中，包括场次、筛选、页码、文件夹和滚动位置。进入单题后返回同一详情；题目顺序限于当前比赛。知识点使用独立原生按钮跳转题库并清除旧筛选，整行点击与键盘练习仍有效，考场锁定不显示或开放隐藏知识。CatalogName统一题库／比赛／题单目录、名称与路径中的拉丁字符字宽，中文字体与文本保持原样。
