# 题解补写范围

2026-10-22 用户最新要求：**新增或补写题解的题目难度 ≤ 2200，包含 2200；已有的全部保留。** 本次明确替代 2026-10-19 的“严格小于 2200”边界。

- 后续只补写难度小于等于 2200 的题，适用于所有平台和系列，包括 XCPC 与蓝桥杯。恰好 2200 可新增默认版或详细版；高于 2200 不再新增或补写。
- 已有默认版、详细版、图片和归档全部保留，原有阅读、打包及升级保留逻辑继续有效。高于上限且只有一种版本的题目，也不再补写另一种版本。
- 题目、题面、提交及个人训练记录继续保留。此规则仅约束后续题解补写范围。
- 使用 TB 现有可信难度或已注明的估分；未知难度先核验，不擅自认定符合上限。已完成题解不会因后续重新评级而被移除。

此前“全部完成”、蓝桥杯不设上限及不允许 2200 的计划，后续均以本规则为准。完成记录中的历史统计保留，不据此删除已完成内容。
