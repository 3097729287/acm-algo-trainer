## 在线对战

共享服务候选 1.4.0 增加 gameplay 协议 1 与增量迁移 015。两个不同账号、不同 Codeforces handle 匹配后，由服务创建唯一比赛 ID、共同题目、开赛时间和 30 分钟截止时间。题池为原站 API 核实的 800–1500 题目，与随包可读题目取交集。无本地替身对手。

取消绑定匹配 ticket；过期取消不取消新队列，匹配已发生时返回实际比赛。队列心跳过期退出，比赛掉线不重置计时，重连读取同一比赛。原站结果由服务只读请求 `user.status`，核对 handle、原题、提交 ID、受理时间及最终 verdict；客户端不能上传成绩、时间或代码。保留原生登录、CSRF 和用户显式提交机制。公开读取按 [Codeforces API](https://codeforces.com/apiHelp) 两秒一次的限制调度，有界排队，不自动重发提交。测试成绩来自隔离 verifier，不冒充真实参赛提交；另单独验证了官方只读 adapter。

使用既有 ToBe 账号会话；桌面从原账号绑定读取 handle。该协议不声称提供独立的 Codeforces 账号所有权认证或反作弊认证。服务不可达时不生成比赛、对手或成绩。

## 贴纸

成长右侧的六项统计与下方内容区分开；内容区提供目标／贴纸图标。贴纸模式使用虚线轮廓，头像和段位只保留占位轮廓。库存按传说、史诗、稀有、普通排序，显示未放置数量；选择框支持横向滚轮和左右按钮。点击处放置，拖动、旋转后按 Enter 或对勾固定；Esc 取消草稿或退出模式。右键通过 popconfirm 回收。

每张贴纸有独立服务端实例 ID。发奖、位置更新、回收和请求去重在账号事务内提交；单位 revision 处理并发修改。回收将同一实例归还库存，不新增副本。发奖按账号／日期／任务唯一标识去重，旧学习快照不能恢复出额外库存。任务领取与本机待同步记录在同一 SQLite 事务完成，跨日、离线和响应丢失保留待发奖励；服务确认后才标记完成同步。

按已持久化任务的难度和 XP 确定品质，在该品质内随机选择贴纸。四种任务整卡背景、文字和边框分别采用蓝、橙、紫、多彩宝石。传奇整卡参考用户 2026-11-02 提供的皇室战争图片：上部浅绿、中间乳白浅金、下部粉紫及银灰外框。其余品质也应用整卡配色。[官方品质参考](https://support.supercell.com/clash-royale/en/articles/cards-and-decks-6.html)。产品使用自行绘制的矢量贴纸和 CSS，不分发游戏原图。
