# ToBe 1.4.25

Windows 10 / 11 x64 用户版，GitHub 与国内自动更新使用同一构建和校验值。

- 当前页码可输入并按回车跳转；输入越界自动调整，支持题库、题单、比赛/文件夹和活动明细。
- 完善 ICPC/CCPC 与省赛、邀请赛的系列和类型入口，按现有记录自动显示年份，补齐 2026 年目录。
- 24 份模板各有注释讲解版与短变量竞赛版，配 48 道可在软件内完整评测的操作练习；模板页固定布局、调用示例常驻，目录右键确认复制。
- 自定义初始代码模板和工作台选择器，昵称入口的紧凑账号管理；正式 WA 才安排次日复习，符合条件的复习自动奖励 20 XP；每日 AC、复习和学习时长任务领取后递进。
- 题面清理明确来源/仓库说明，保留题意和图文样例；日历按格子方向移动、日期进度突出，提交操作列贴右。
- 分块增量同步、失败续传和旧代码按需读取，已有本机提交和草稿保留。服务 1.2.7 已上线；迁移到 v2 的账号在其他设备也需升级。
- 公共目录按要求排除 XCPC 决赛、网络赛及中国以外的场次；题单移出 >2500 分题，赛事真题另移出 900 分题。既有个人学习事实、代码和私人题单原文保留。难度复核与知识点补齐仍停止。

种子为 12,231 题、9,243 份题面、1,379 组双版题解、447 篇讲义和 563 个题单目录；实际可叠加在线数据及本机导入。

后端 783 项、服务 HTTP/SQLite 41 项与隔离 MySQL 43 项、真实 App、原生窗口、编译器和 Python、新装/覆盖升级及原 1.4.17、1.4.24 EXE 增量验证通过。测试未向真实原站账号提交程序。

安装包与便携包只包含用户版。管理员版不公开上传。BUILD-INFO.json、源码标签 v1.4.25 和 SHA256SUMS.txt 可核对构建身份及文件哈希。

GitHub CI 当前未全绿：通用 UI fixture 缺少新增赛程接口，Windows runner 的两项静态资源 fixture 返回 404。本机完整后端、分页/分类专项、实际冻结 App 与安装升级验证通过；不能将这些本机结果称为整套远端 CI 通过。
