# ToBe 1.4.25

用户已授权 GitHub 与国内更新源同步发布。1.4.25 发行准备中，验证完成前正式下载仍为 1.4.17；本机安装、两处发行和校验结果另记。

- 当前页码可输入并按回车跳转，越界自动调整；空值、Escape 或失焦恢复实际页码，输入框方向键不触发翻页。应用于题库、题单、比赛/文件夹和活动明细的已知页数。
- 补全 ICPC/CCPC 系列的省赛、邀请赛入口，保留原类型入口；年份从现有元数据和赛事名/日期自动生成。CCPC 2026 黑龙江、福建、秦皇岛和南昌赛事可在对应系列中浏览，筛选和重现赛目录同步。
- 公共题库、题解、个人数据和服务协议不变，继续保留此前的题库范围及题单评分规则，难度复核与知识点补齐仍停止。种子仍为 12,231 题、9,243 份题面、1,379 组双版题解、447 篇讲义及 563 个题单目录。

源码验证覆盖已有 643 场比赛、5,565 条分类路径，页码真实 API/UI 与比赛阅读回归。冻结包、新装/升级及实际数据保全结果另记，没有向真实原站提交测试代码。

本次公开发行将同时包含此前 1.4.18—1.4.24 的本机更新：初始代码模板与账号弹窗、24 份双版本模板及 48 道本地操作练习、WA 次日复习和奖励、递进每日任务、题面来源清理、分块增量与历史代码按需读取，以及公共 XCPC/题单范围调整。配套服务 1.2.7 已上线，分块迁移后的其他设备也须升级；已有本机代码和草稿保留。源码同步已上线服务的数据指纹修正，不在本轮重部署服务。

比赛详情可用滚轮或键盘完整读取；已核对 Windows 支持的最小 1050 像素宽度及 1440 像素宽度、两种主题。服务 HTTP/SQLite 41 项和隔离 MySQL 43 项通过，维护源码与已上线的审计修正一致，本轮不重部署 API 或数据库。
