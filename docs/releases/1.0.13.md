# TB v1.0.13

- 每日任务可领取时，成长与能力入口显示提示点。
- 活动记录恢复独立导航。知识掌握与缺口默认收起，支持搜索。
- 目标计划合并到成长页底部；保存后收起编辑表单；用比赛分类题量代替长期日期列表和说明小字。
- 每日目标题目自动加入我的训练，按目标与北京时间日期持久化，刷新与重启不会重复加入，也不会撤销当天的手动移除。
- 取消强制独立重写队列，保留代码、题解查看证据、提交历史和正常的间隔复习。
- 捕获的比赛题目自动分类为 ABC/ARC/AGC、Div.3、牛客周赛、洛谷基础赛/入门赛/月赛。后台读取公开题面和官方标签，识别知识点并保存分析；证据不足时继续等待补充。
- 从本版本起自动更新使用经过 SHA-256 校验的文件增量包，仅替换变化的 DLL、程序、前端、扩展等文件，不重复下载编译器或 WebView2。漏装版本沿已发布增量包逐步更新；更新错误恢复原程序文件，个人 state/cache 不属于替换范围。

## 发布资产

提供安装版、便携版、从 v1.0.12 到 v1.0.13 的增量包、程序文件清单与 SHA-256 清单。旧客户端首次升级仍使用它原有的安装器；升级到 v1.0.13 后使用新的增量更新逻辑。

后续发布先构建安装版和便携版，再使用 scripts/build_update_patch.py 对上一正式版的 RELEASE-MANIFEST.json 生成 TB-Update-旧版本-to-新版本-win64.zip，并将两者一并上传 Release。新版客户端会在需要时选择中间版本，禁止缺少增量包时静默退回全量安装包。
