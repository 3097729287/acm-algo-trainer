# ToBe 1.5.3 思维对决

本版在对战页顶部加入排位／思维对决切换。思维对决提供独立匹配、3 秒开局、15 分钟文字作答、自动保存、提交锁定、AI 六维评分、独立 Elo 结算和对局记录。断线重连恢复服务端进度；判分失败按平局处理且不扣分。

桌面功能通过 `/api/pk/v1` 中转至独立的共享服务模块，既有排位判题、账号协议和公共题库保持兼容。服务候选为 1.4.3，迁移 017 仅新增 `pk_` 表；默认两个功能开关均关闭，密钥仅保存在服务端。32 道初始题来自已有公开题库，原题、约束、样例与可信参考均保留。

当前为本机交付候选，尚未公开发布；公开桌面下载仍为 1.4.34。生产思维对决服务未部署，真实模型未配置时不能加入队列。实际本机安装、提交和验证结果以本机交付回执为准。[使用、接口、数据与回退说明](../thought-duel.md)。
