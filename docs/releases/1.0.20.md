## 账号数据与单设备会话

服务端 MySQL 成为账号学习数据的权威版本，与排行榜使用同服务器数据库；本机 SQLite 保留耐久工作副本和未上传记录。同步覆盖训练、草稿、完整提交源码和原站回执、模拟赛、目标与固定每日题单、首通经验、每日领取、成就奖励、排位解锁及排行榜奖励账本。CF/AtCoder 公开账号及已同步资料、收藏、保存筛选和导航等账号偏好也随账号恢复。

登录完成前先读取、合并与确认账号版本，失败留在登录页，不临时展示新号空数据。首次合并前进行 SQLite 在线备份；后续以逐行基线识别编辑和删除，冲突草稿版本留存。奖励按稳定领取键去重，跨电脑不会把同一成就或每日奖励再加一次 XP。

后台聚合上传，不在普通 GET 中等待远程网络。界面明确显示待同步与失败，正常退出账号或更新前等待保存。新设备登录在服务端账号事务内撤销旧会话；旧设备联网时约 3 秒心跳收到失效响应后离开工作台。慢上传不阻塞心跳，迟到旧请求再次校验会话，不能覆盖新数据。断网无法即时收到撤销，本机未上传修改保留到下次登录合并。

个人题目事实只包含当前账号实际引用的题目：轻量元数据、链接、已缓存题面与样例，必要时附本机导入题的两版题解与图片。另一电脑缺少公共题目 ID 时可继续显示已有题目和代码，不复制整套公共题库或其他账号的导入内容。

## 隐私与安全迁移

个人代码和草稿会上传 TB 账号服务；旧版“服务器只收成绩摘要、不收代码”的整体描述不再适用。计分接口仍只收通过摘要。Cookie、浏览器会话、翻译密钥、DPAPI 密文、机器路径和设备专用设置不上传。HTTPS 保护传输，快照压缩不是端到端加密，数据库和备份需按个人数据保护。

快照使用有 SHA-256 校验的 gzip/base64 封装，最大 4 MiB 线上内容、64 MiB 解压内容；超限不截断数据假报成功。共享服务对大 JSON 在解析前限制结构与深度，大快照限并发，不阻塞独立心跳。账号状态用 revision CAS，旧客户端在账号已有云端状态后收到 426 升级提示；门槛在登录事务内复验。

部署使用 `005_account_state.sql` 增量建表，不重建或删除已有数据卷。准备脚本先在线备份 MySQL、停 API、执行幂等迁移并收拢旧会话，再切换运行时；健康检查必须显示 `accountStateProtocol: 1`。失败恢复旧运行时，数据库备份和新增表保留。不要在生产创建测试用户。[完整部署与回滚步骤](../../server/leaderboard/README.md#1020-同步上线)。

## 加载与内存

- 题库紧凑 UTF-8 响应约 12.68 → 7.98 MB，热缓存复用已序列化字节；hub 删除重复目标数据。
- 首屏 JavaScript 约 1.419 → 0.863 MB，约 560 KB 编辑器模块按需加载。
- 历史统计和官方奖励重放改为按记录与已解题目线性处理，避免每道题重复扫描全历史。
- 原站题面获取移出个人数据锁，使用有限并发后台任务；失败缓存 60 秒，已有题面优先读取。
- 浏览器扩展空闲轮询间隔 30 秒；切换账号释放旧训练服务、后台任务和缓存。

以上体积是源码响应与构建测量，不能直接换算为所有电脑的打开耗时。公网原站 403 或验证仍可能使题面不可读，界面保留状态、重试和原题入口。本轮保留 Python 本机后端与 Node.js 共享服务，没有改写 Go；本机样本约 70% 私有内存属于 WebView，后端语言无法直接消除该部分占用。
