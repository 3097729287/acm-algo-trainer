# TB 1.4.5：洛谷题单与分层训练

本机版本，未公开发布；正式下载仍为 [1.4.1](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.4.1)。源码分支 `feature/luogu-training`，基于已交付的 1.4.3，保留原课程、题解和个人数据。实际构建提交由随包 `BUILD-INFO.json` 记录。

新增侧栏「题单」，与原界面共享搜索、文件夹、筛选、分页、难度和状态样式。支持按算法或原站分类逐层进入题单、章节、关联子题单；题号/题名搜索、已通过筛选、训练下一题与返回位置恢复。题单题目同步收录题库，精确复用已有题目身份和通过状态。

## 收录范围

来源：[洛谷题单目录](https://www.luogu.com.cn/training/list)，2026-10-24 公开读取快照。13 个分类共 469 个目录题单，另发现 94 个关联子题单，合计 563 个目录条目。420 个题单可读取，143 个暂不可读取（抽查原站返回需登录），不宣称全量已完成。7 个失效/不可读题号保留未解析状态：P5898、P4680、P2384、CF802O、P7388、P7332、T501207。

已解析引用对应 7343 道不同题目，复用 54 道原有题，新增 7289 道，公共种子共 13123 条原始题目。原有 5834 条记录原样保留；2437 份题面、1317 份默认题解、1317 份详细题解、445 篇讲义、5395 条讲义关联均保留。新增题为原站标题/题号/难度档及标签元数据，不新增或重写题解；未知难度保持未知，未核实知识点保留待分类。首次读取未缓存题面仍需联网。

## 存储与验证

题单保存在 SQLite 新表 `training_lists`，schema 5 升级执行在线备份，并按分发摘要保护用户修改及本机导入。个人训练、身份、草稿、提交记录继续使用原数据库。新专题集合不会伪装成整场比赛进入赛事与重现赛。

专项检查覆盖旧种子兼容、schema 迁移备份、合并保全、重复导入、规范 URL 与别名去重、API 来源规则、嵌套/环目录、章节、筛选、下一题与返回、手机/桌面明暗布局。真实公共种子的隔离 API 检查新增题在题库只出现一次，草稿保存与返回有效。完整后端、冻结程序和安装升级结果记录在本机当前更新中；全部验证使用临时个人状态，真实原站提交数为 0。

用户安装器名为 `TB-Setup-1.4.5-win64.exe`。管理员仅供维护者本机使用，不生成管理员安装器或 ZIP，不发布新 Release、服务或公开资产。
