# TB 1.1.3 · 统一目标任务与透明界面

2026-10-19。正在验证与打包，尚未正式发布；当前正式下载为 [v1.1.2](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.1.2)。

## 界面与题单

时间移到顶部。今日目标题目进入训练列表的新栏目，并在每日任务中作为“目标题目”显示；有未完成题目时保留提示点。目标管理缩为新建、调整一行，在弹窗完成编辑与归档。新收录的 Div.3、ABC、牛客周赛及洛谷基础赛/月赛按活跃目标要求补充任务，已确认 AC 显示完成。

比赛、模拟赛、目标管理和其他面板共用透明调色，背景显示更充分；减少装饰分隔线。删除成长页独立“下一个里程碑”卡并平衡列高；移除题解收件箱入口、运行 API 和后台轮询。已有题解继续可读。题库、训练整行可进入练习，收藏、标签和移除保留各自行为。按名称排序时数字轮次从新到旧。

## 历史 AC 核对

成长页可绑定牛客、洛谷数字用户 ID 用于记录匹配，评分仍仅展示 CF 和 AtCoder。读取实际账号与提交编号、原题 URL、最终结果和原时间；去重回填到已有提交表。周日通过、周一才收录的题不会计成周一 AC。比赛题单冻结选择，重启保持；清空或移除训练不会被轮询重新加回。

同步有界：CF 最近 1000 次提交；AtCoder 近 30 天最多 3000 条；牛客题库最近 8 场比赛；洛谷最近 3 页公开记录。站点访问受阻或无匹配回执时不伪造 AC，稍后重试。牛客公开榜单落盘前仅保留本人记录；网络请求不持有个人写锁，回填前复核账号上下文。原站提交和登录保持沿用专用可见浏览器，无需扩展。

题库缓存增加固定大小 SQLite/WAL 头校验，修复 Windows 同尺寸更新后仍显示旧列表的情况。

## 验证与升级

回归使用临时状态及隔离页面，不向真实 OJ 提交代码。覆盖历史日期与去重、账号切换、未知题延迟回填、目标四类比赛、重启/清空、缓存隔离、整行操作、提示点、数字排序及不同宽度的透明界面。公开牛客数据格式已只读核验；其他站点成功路径以 fixture 验证，实际访问受原站限制。

完整后端检查及前端构建、工作台、重现赛、排行榜、透明面板与按需加载检查覆盖本次改动。在 5795 题的临时离线数据中，重启服务 421 ms、题库首读 213 ms、工作区 86 ms；这些数字不包含网络登录，不代表所有设备。安装及增量验证随最终构建执行。

牛客/洛谷的数字 ID 随账号私有偏好同步，登录没有绑定的新账号会清空旧值，返回原账号再恢复；解绑也会跨设备生效。共享服务的 CF/AtCoder 公开资料结构保持兼容，不新增服务器迁移。

包内固定公共库存为 5795 题、2215 份题面、960 组默认与详细题解、376 篇讲义。另行续写内容不混入本次构建。共享服务继续使用 1.1.2、账号与公开成长协议 1，无新增数据库迁移。升级到原目录并保留个人数据。
