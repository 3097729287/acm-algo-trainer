# ToBe 1.4.24

源码尚未公开发行；正式下载仍为 1.4.17。此批已统一完成本机更新，[实际安装和数据保全结果](../local-delivery-1.4.24.md)已核对。

- 模板目录移除可见复制按钮，右键卡片显示确认；确认后复制竞赛版，取消不写入，失败可重试。整卡左键进入保留。
- 详情标题、讲解/竞赛版、练习与操作合并一行；页面固定，代码单独滚动，最小调用示例完整显示。模板与算法实验室目录对齐。
- 收藏入口显示“我的收藏”；提交记录代码/结果贴右，存在耗时和缺少耗时的行共用列位置。
- 日历方向键按屏幕格子移动并在边缘停住；所选日期行高亮，进度条占满剩余宽度。
- 公共题库继续移除 XCPC 总决赛、亚洲/东区决赛及网络赛，新增退役 359 题，普通国内区域赛及非 XCPC 保留。种子为 12,231 题、9,243 份题面、1,379 组双版题解、447 篇讲义和 563 个题单。旧个人代码/草稿/训练记录保留。
- 所有题单移出 >2500 分题，2500 保留；赛事真题另移出恰好 900 分题。原题库及私人题单持久化原文保留，未知分数不猜填。

本轮没有改动同步协议或部署服务。难度复核与知识点补齐继续停止，没有向真实原站提交测试代码。

源码验证已通过：后端完整 783 项、题单范围边界与别名检查、前端构建、实际 App 的 144 组模板布局和相关交互。固定提交冻结程序、新装/升级与更新器验证及实际本机安装均已完成，见交付记录。
