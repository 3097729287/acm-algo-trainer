# ToBe 1.6.13

本版整合单题工作台、原站浏览器连接、三人训练及在线状态修订。国内发布仍按完整升级链验收；版本号或候选安装包本身不表示验收通过。

- 修复 Alt＋2 只看代码时的左上角遮挡，保留题名、返回和上一项，语言与模板正常排列。
- 单题左栏可切换内嵌 DeepSeek，右侧代码保留；按 ToBe 账号保存专用网页登录状态。
- 应用已注册的快捷键在题面、代码、输入框、按钮与内嵌网页中执行同一动作。
- 原站提交复用常用 Chrome／Edge 的已登录会话。首次需从“账号设置 → 浏览器连接”打开扩展目录，在常用浏览器手动加载随包扩展；连接后无需另建原站登录。
- 自动创建的提交页在后台静音运行，登录和验证码需要人工操作时前置。正式结果保存并在 ToBe 当前可见结果区显示后再关页；手动页面保留。
- 牛客结果绑定原题型、编号、题目和账号。已受理记录重查原编号，不因超时、重连或草稿变化重复提交。
- 间隔复习正式 AC 后恢复最新实际通过的代码和语言，保留后续未提交修改及各轮上下文记录。
- 应用开着但五分钟无真实输入显示红色离线，关闭后显示灰色离线；快速重开和账号切换不会被旧窗口晚到的通知覆盖。
- 排位匹配时间并入原有匹配按钮，移除右上角重复显示。
- 三人训练支持共享代码、真实原站提交、三端计分与断线恢复；已完成一次真实 AC 和服务重启后的恢复验证。
- 思维对决以双方提交、正式裁判结果和持久化结算记录为准；无有效裁判结果时不伪造胜负或发放分数。

国内更新采用固定摘要的小型增量与真实字节进度，一分钟是完整升级的目标。验收同时检查旧版检查更新、新安装程序窗口、实际 React 界面可操作，以及原有记录和全部受管程序文件；不能只用下载速度或提前出现的窗口代替完成。先前 1.6.7 → 1.6.12 的 **72.477 秒**失败记录保留。
