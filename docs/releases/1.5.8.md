# ToBe 1.5.8 更新说明

本次安装包包含本轮 1.5.7 的全部修复，并追加显示速度与退出保存优化。

- 头像段位框、段位勋章改为随界面内置原始图片数据，显示时不再等待独立图片请求。九段位共 18 张原图的字节与原素材一致。
- 对战排行榜和公开对战记录保留已确认内容，后台刷新不再先清空。按账号、模式、日期和有效期隔离缓存，复用同一次读取；登录后预取排位榜单。缓存中的在线状态标记为上次确认状态，不作为当前匹配、排队或奖励的授权依据。
- 模板、从零讲和维基目录在空闲时预取，并合并重复读取。已缓存目录先显示、后台核对最新内容；私有模板代码仅在本次进程内复用，不新存入浏览器持久缓存。
- 维基正文独立于目录加载，打开正文无需等较慢的目录请求；取消首次打开目录的固定等待。学习目录各类内容独立显示，较慢的一类不再阻塞其它类别。
- 学习目录的题库索引与内容目录分开复用；搜索预编译匹配规则并缓存规范化结果。13,417 道题的本次检查中，建索引约 14 毫秒，首次搜索约 58 毫秒，之后四次搜索合计约 28 毫秒。
- 修复从未载入、尚未编辑的空题目标签阻挡正常退出的问题。真正有修改且保存失败的草稿仍会阻止退出，保留原有草稿保护。

本轮同时包含：

- 牛客八个编号学习阶段和统一的多层题单目录，保留原 72 个来源题单与 1,083 道不同原题的身份、代码、进度。
- 学习标签页新增“我的训练”，按首页规则标注今日目标、待攻克、间隔复习及已 AC 等状态，原“题目”目录保留。
- 新版新手指引加入 11 个实操步骤；修复打开学习标签页后不能操作指引、不能识别练习题的问题。
- Ctrl+S 明确标为格式化代码，草稿继续自动保存；保留 C++、Python 格式化和原考场规则。
- 放大顶部头像框，常规宽度头像为 36 像素；经验环恢复从底部顺时针增长。对战中间的成就徽章暂时隐藏，外侧展示卡去掉边框和底色，保留头像段位框与段位勋章。
- 地球高速旋转触发原版爆炸，长满房屋后的等待爆炸和拔除、延迟补建逻辑保留。
- 修复牛客“涂小天与他的画”的字符图排版，已缓存旧题面可离线纠正。
- 共享译文上传失败后有限重试、再次打开可补传；其他账号无需配置翻译 API 即可复用同一版题面的共享译文。英文仍默认显示英文。

本版不新增题解，不恢复剩余全库批量翻译。PDF 继续按需读取，保留旧安装包资源退役与个人数据恢复机制。首次尚未取得的联网内容依据真实返回显示，已确认内容不因刷新而空白等待。

验证使用隔离账号和延迟网络夹具：缓存榜单首屏约 6 毫秒、段位图片独立 HTTP 请求为零；模板先于重新读取显示，维基正文先于慢目录显示；账号切换不显示上一账号快照；未编辑空标签可退出，真实保存失败仍拦截退出。完整包、增量与正常启动的最终结果以交付回执为准。
