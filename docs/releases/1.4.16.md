# ToBe 1.4.16 · 性能优化与界面对齐

本机更新，尚未公开发布；公开下载仍为 TB 1.4.1。

- 知识点文字紧邻雷达顶点，取消引线，密集标签分行并避让。
- 比赛详情统一显示 AC、WA、CE、TLE、MLE、RE、OLE 等实际判题结果，样例通过保持独立标记。
- 移除顶栏主题按钮，深浅主题仅在设置中切换。
- 连续练习、AC、爱心和通知图标采用一致的高度、字号与垂直中心。

性能改动保持现有展示和搜索语义：查询只编译一次，收藏与题目范围使用集合，比赛排序和目录路径复用本次计算结果；启动不再为判断题库是否为空而反复解码整张表。相同题库响应复用序列化与有界压缩结果，静态资源支持 ETag 和带内容哈希资源的浏览器缓存；题面清理采用有界文本缓存。会话令牌、日期、内容更新仍即时参与失效判断，动态 API 保持不落浏览器缓存。

新增公开题库性能基线与缓存失效、内容一致性、并发和容量检查。真实原站网络耗时未纳入离线提速结论，首次题面开销仍单独记录。

个人记录、账号、代码、草稿、偏好与教学内容继续保留；管理员程序仅供本机使用。
