# ToBe 1.4.23

本版源码尚未公开发布。公开稳定下载保持 1.4.17，实际本机安装、服务迁移和验证记录见交付记录；管理员产物仅保留本机。

- 24 个内置模板各提供变量/状态/边界注释讲解版和短变量无注释竞赛版；模板与算法实验室共用整卡入口，图标与名称同行，详情占满界面。模板可自建、保存、复制和插入。
- 每模板两道原创操作练习，共 48 题、1,152 组完整用例，只有白名单模板练习允许软件内完整判题，不计原站正式 AC 或首通经验。实验室图论、序列与背包代码补上变量和算法理由注释。
- 自定义初始代码按语言保存，保留原起步程序为“默认”。工作台语言旁打开带预览的选择器；明确载入可撤销，旧草稿和空草稿优先。设置原账号卡片改为初始代码入口。
- 点击右上角昵称管理昵称、密码及四站绑定，布局紧凑，保留必要标题。启动按顺序检查并打开缺失的原站登录，本人身份只自动填入空绑定，不覆盖已有不同账号。登录、验证码与原站提交事件保留。
- 只有正式 WA 触发次日复习，一遍通过不新增次日任务；有效次日复习完成一次自动奖励 20 XP。每日上排改为 AC、复习、前台学习时长递进领取；复习到当日上限后接续随机任务，下排三项领取后保持已完成。
- 提交记录代码按钮与结果固定分列对齐；同步提示独立占用顶部一行，主界面按剩余高度排布，不遮住分页或底栏。
- 客户端与服务 1.2.7 配合分块增量同步、失败续传及完整根 CAS；30 天前提交代码按月归档，新设备按需取回，已有本机代码、草稿、冲突与旧云快照保留。已迁移账号阻止旧客户端写入，其他设备需一起升级。服务部署须核对在线 SQL 备份与原表/分块指纹，不以 fixture 代替生产验证。
- 题面截图自动清理明确来源/仓库说明和对齐语法，保护真实背景、公式、图片和样例。公共目录移除全球总决赛及中国以外的 XCPC 题目，旧个人历史保留。新增 2025 CCPC 济南、郑州、重庆各 13 题，原版 PDF 分页可放大，57 组样例可复制；只走正常 QOJ 原站提交。

公共文本种子为 **12,590 题、9,566 份题面、1,379 组双版题解、447 篇讲义和 563 个题单目录**。目录仍按原题身份去重，存档数不代表所有题面均完整。用户要求已停止难度复核及知识点补齐，已完成的证据保留；新增 QOJ 未知值不猜填。

两年容量模拟采用纯合成数据，730 天每天 10 道新题、每题 3 次提交及每题约 4 KiB 高熵资料；初次对象约 30.71 MiB，50 份在随后 30 天的全对象缓存约 2.10 GiB，不含 SQL 索引、日志、系统和备份。不是服务器 RAM 需求，也不是 50 个大账号同时压测。按该规模建议评估 2 核 / 4 GB 内存 / 60 GB SSD 及异机备份，尚未购买服务器升级。

源码验证包括后端 782 项、服务 SQLite/HTTP 41 项和隔离 MySQL 42 项检查，以及模板独立预期结果、边界/非唯一答案检查、真实 HTTP 双客户端合成历史恢复、隔离页面原生表单与真实 App UI。没有向真实原站账号提交测试程序，生产安装和部署状态另记。
