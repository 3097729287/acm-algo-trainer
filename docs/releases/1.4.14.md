# ToBe 1.4.14 · 更名与视觉调整

本机交付，尚未公开发布；公开下载仍为 TB 1.4.1。普通版和私有管理员版来自同一固定源码，构建提交由 `BUILD-INFO.json` 记录。

- 软件更名为 ToBe：窗口、侧栏、启动和登录页、安装器、EXE、快捷方式与程序属性统一；Windows 图标加入 ToBe 字母，兼顾小尺寸显示。
- 恐龙主体减淡并使用主题色，题单目录栏与题库表头深度一致。
- 提交结果筛选保留按钮，只移除“排队中”“评测中”选项；仍正常记录评测状态。
- 从零讲的学习层次标签与标题居中对齐，长标题换行时仍位于同一标题区。

安装身份、个人数据库、浏览器存储与共享协议沿用原值。公共题库仍为 13,184 题、9,652 份题面、1,378 组两版题解，既有课程与内容均保留。没有公开发布、重新部署服务或执行官方测试提交；实际验证和安装结果见指定本机当前更新记录。
