## 界面与使用流程

设置采用一级分类首页和二级详细设置，记住分类与滚动位置。头像通过点击右上角头像弹窗修改，翻译 API 移入设置，鸣谢显示在首页下方。全局和每页透明度支持 0–100%，选项始终展开，提供重置所有透明度。修复旧的 25% 保存校验，以及风格被统一面板规则覆盖的问题。

题库和比赛共用深层文件夹。普通比赛按平台、系列、场次浏览；XCPC 独立，ACM 下区分省赛、邀请赛、CCPC、ICPC、网络预选赛等，再按年份、赛站、热身赛与正赛分组。使用已收录元数据，不虚构未知年份。文件夹数量按题目/场次数各自计算，面包屑返回保留正确层级。

知识点默认收起，展开时导航滑出，知识树占用侧栏。侧栏缩窄、导航间距增大，知识点计数同行显示。未提交题仅灰点；提交记录移除每天的重复统计和来源格式文字。模拟赛缩短输入框、精简说明并修复选项截断；排行榜以切换周期、排名、用户和数量为主，规则与管理按钮改用提示。

顶部显示今日 AC 和今日获得的爱心，头像段位框放大并靠右。每日任务、成就、时钟按顺序位于右下方状态行，时钟开关继续生效。做题时自动隐藏顶部和底部。移除键盘快捷操作的显式入口；保留实际键盘操作。成长页删除重复头像框，账号置于前方。

新手指引逐步高亮实际区域，等待打开练习题和点击返回，再介绍记录、模拟赛、能力建议和设置。可以结束并从数据与帮助重新开始，不会自动提交代码或开始比赛。
