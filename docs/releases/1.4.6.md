# TB 1.4.6 · 四个月日历与掌握基准修正

合并交付候选，正在验证，未公开发布。公开下载仍为 1.4.1。基于已交付 1.4.5，保留 13123 题、563 个题单目录（420 个可读取）、2437 题面、1317 组两版题解、445 讲义、5395 关联及三个算法课程。管理员仅维护者本机程序，无管理员 Setup/ZIP。

- 日历同时显示所选月份及前三个月，格子最大边长 48px（原大格面积约四分之一），窄窗口改为两行。搜索、跨月选择、方向键和下方明细联动。
- 双端点拖动改为相对位移，6px 死区后每档至少 32px，100 分一档；键盘 100 分、Alt 微调 10 分，数值输入保留。
- 掌握指数以 CF2300 为 100% 参照，子项独立估计后加权，未练主题不计已掌握贡献；保守分位数防止少量简单题虚高。[公式与权威资料](../knowledge-mastery.md)。
- 审计全库难度尺度，将 6426 条半百数值归为整百（含题单新增 5764 条），来源和原值保留。点生蚝复核为 1000、区间 800–1200 的非官方估计；其 O(N) 贪心与穷举对照验证。未声称逐题人工重评全库，未知难度不补造。
- 提交行转到题目，状态左侧代码按钮打开原历史提交弹窗；历史代码和当前草稿独立。
- 蓝桥杯省赛/国赛直接列比赛，其他单分支冗余目录自动展开，保存的原始分类路径仍兼容。
- 题面“原文 / 中文 / 原题”保持横排，小面板自动换工具栏行；恐龙改圆润线条，气球使用高竖栏，星球表面自转且保留环与卫星。

来源尺度和估算依据见 `backend/resources/difficulty-audit-1.4.6.json`。原站题面：[海鲜大排档点生蚝](https://codeforces.com/gym/106695/problem/J)。不修改共享服务或原站提交机制，不进行真实试交。构建、安装和个人数据核验以实际验证记录及 BUILD-INFO 为准。

合并前的界面分支检查：619 项后端测试、66 组前后端掌握计算对照、日期/目录/掌握模型检查及浏览器主流程通过。浏览器检查包含真实鼠标小幅拖动不变、跨档加 100、提交代码入口与题目跳转、日期格式、四个月方格和多窗口布局。程序安装验证另行记录，不以源码检查替代。

合并版本还保留 1.4.5 的搜索、题单文件夹、通过筛选、草稿与返回位置，以及 schema 5 的 SQLite 合并保护。143 个题单不可公开读取、7 个题号待解析的限制不变。难度来源与整百尺度检查覆盖合并后 13123 题；保留来源、原始分值和未知状态，后续题单导入与 API 编码边界沿用统一规则。
