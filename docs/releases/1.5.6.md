# ToBe 1.5.6 更新说明

- 修复全屏状态下按 Win+D 显示桌面，再打开其他窗口时 ToBe 自动露出的问题。现在会真正最小化，主动切回后保持全屏；退出全屏后恢复普通窗口边框。
- 按提供的参考图替换九个段位的勋章、头像框、展示卡边框，使用对应的原始段位图，保留用户自己的头像、经验进度、等级及原排位分规则。
- 修复翻译因段落版式标记缺失而重复失败的问题：按完整段落重试，保留公式、代码、链接和数字的校验。为教育赛 196 B「Rhythmic String」补入与原文摘要绑定的完整离线中文译文；英文题面仍默认显示英文。
- 顶部重现赛倒计时移除边框和底色，与相邻统计项居中对齐，保留点击返回比赛。
- 每版随程序附带独立 Markdown 更新说明。更新后的正常启动会将说明存入桌面「ToBe更新记录」，重复启动不重复创建，旧记录保持原内容；同版补充另存文件。

本次不新增题解，也不恢复全库批量翻译。原有的 1,994 条内置译文保留，本次只额外修复反馈中的一题。共享账号服务继续使用 1.4.7，不修改服务端数据与当前公开更新源。

验证：全屏原生回归包含真实 Win+D 按键、打开其他窗口、主动恢复及退出全屏；译文专项使用离线题面与隔离翻译服务，不调用外部翻译 API。九段位显示、素材加载、窄屏和深浅主题计时对齐均在隔离浏览器中验证。完整安装、增量与本机账号保全结果以随交付保存的验收回执为准。

技术依据：[Windows 对 Win+D 与最小化样式的说明](https://devblogs.microsoft.com/oldnewthing/20241021-00/?p=110393)。段位原始素材与摘要记录随包保留。
