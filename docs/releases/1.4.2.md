# TB 1.4.2 · 本机主程序更新

交付正常桌面程序和用户 Setup，公开正式下载仍为 1.4.1。本轮不发布 GitHub Release、不更新公开下载源、不部署共享服务。维护者管理员版仅更新本机程序与原快捷方式，不制作管理员安装器或便携包。

算法实验室新增前缀和与差分、双指针，两专题各七节互动课、五道跟做题。前缀与差分解释互逆、起点、独立使用及二维边界；双指针解释相向、滑窗、快慢指针的移动依据、总步数与负数反例。十道精选题均核对官方评级、题目条件和样例，并配两版题解和本题图。

背包 DP 增加拿与不拿比较、旧方案可被新组合替换的动画；第二课随当前范围和容量更新，未答格仍保留问号；第三课数据流与原推演同帧，正序重复使用时显示错误来源。支持播放、暂停、单步、调速与减少动态效果。

旧背包进度、全部题库记录、两版题解、代码与图片保留。课程与跟做继续沿用私有偏好，模拟赛同题及别名锁定指导；课堂核对不产生 AC、经验或掌握度。公共库为 5834 题、2437 题面、1317 组两版题解、445 讲义、5395 关联。

本轮固定源码分支 `release/1.4.2-lab`，具体提交与资源 SHA-256 记录在随包 `BUILD-INFO.json` 和 `SOURCE-MANIFEST.json`。原 `feature/algorithm-lab-sequences` 工作副本及其中另行开发的界面需求继续保留；本次构建仅包含已完成的课程及必要导航。

已有专项验证包括 1200 组模型数据、67375 次断言、18 份 C++ 程序 494 次运行、新课 96 个页面组合、20 篇题解的 60 个阅读页面、动图 2847 次断言及旧进度恢复。主程序打包额外进行冻结程序、全新安装/卸载、1.4.1 隔离升级、管理员隔离与本机个人库在线备份核对。实际安装结果以本机当前更新记录为准，不将打包前的源码验证冒充安装成功。

按用户 2026-10-24 的持续交付要求，后续功能与教学更新通过验证后直接打包进主程序，不再默认交付独立体验版；教学交互实验继续保留。
