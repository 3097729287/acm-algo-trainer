# ToBe 1.4.31

正在合并与验证，尚未安装或公开发布。本机已验证版本为 1.4.30；GitHub 与国内公开正式版仍为 1.4.29，现有下载链接继续指向该正式版。

本补丁收口用户实测界面问题，并把已有 QOJ 适配接入各平台入口；最终变更与验证结果将在交付前据实记录。公共种子保留本机 1.4.30 已交付的英文默认、离线中文和前七阶段题解内容，共 12,271 题、9,436 份题面、1,674 组双版题解和 467 篇讲义。本次合并不追加新的内容创作或内容热更新；题面补全已交由独立会话，性能检查在本次交付后继续，新题解、翻译与课程创作暂缓。

- 推荐区移除展开箭头、边框和底色；主项与下拉任务的图标、文字对齐，任务快速依次淡入，鼠标离开约 80 毫秒收起，保留键盘与触屏操作。已通过的完整基础单元不再作为未完成任务推荐；后续选择仍核验真实先修证据、题面与题解，并受当日复习预算约束。
- 单题英文原题采用“英／中”单按钮切换，中文原题不显示语言按钮；删除桌面多余布局按钮和样例下方说明，模板、题解、下一题整组靠右。保留拖动分隔线与布局快捷键，返回按钮热区扩展到标题栏左上边缘。
- 模板详情首次绘制直接使用最终全界面尺寸，不再先显示带侧栏的中间帧。实验室每次进入教学从第一页开始，保留已完成记录、代码与跟做进度；目录只显示简述，数字与文字分列左对齐。
- 侧栏改为“我的训练、题库、题单、比赛、模拟赛、成长、提交记录、活动记录、排行榜、实验室、模板、从零讲”。已发行旧默认顺序迁移到新顺序，其它自定义排序保留；恢复默认立即生效。导航设置缩短名称和分组输入框，左右对齐，中间留白，三个操作按钮不再重叠。成长统计的火焰保持最大形状，颜色与其它统计图标一致。
- 消息窗口合并社交与更新的已读操作，爱心、留言及计数同一行，移除账号同步块和空消息说明。消息少时腾出高度给更新，增多后社交区最多占一半；两区分别滚动，窗口整体固定。
- 各页筛选共用紧凑样式，文本与下拉箭头按内容排布，难度标签与数字同行，滑块紧接下一行；面板按触发按钮定位并随窗口变化。清空训练移到筛选图标右侧，须经过 PopConfirm 确认；取消单题训练只在“我的训练”提供。
- 题单按真实来源分为“洛谷”和“牛客”，保留原课程与题目身份、自建题单、收藏及历史事实；去掉题单卡片的爱心控件，标题与完成环对齐。已在题单页点击推荐也直接切换目标，保留未保存的自建编辑草稿。
- 模拟赛三类训练入口缩短并居中，专项知识点和重现赛选择在对应按钮下方展开；重组与开始按钮统一加宽。实验室、模板的分组标题以及从零讲的正文标题居中，从零讲来源并入工具栏，移除重复说明；题面补全状态改为 tooltip。
- W/A/S/D 分别复用上、左、下、右方向键导航。输入、代码编辑、组合键和输入法组合期间保留原键盘行为。推荐还依据已确认的配套操作通过记录接续练习，返回课程首页不会把已完成操作退回成未学课程；先修和复习预算门禁保持有效。
- QOJ 成为独立来源平台，贯通题库、训练、比赛、重现赛、提交记录及浏览器登录；XCPC 仍是赛事分类，同一场可同时从 QOJ 和 XCPC 进入。五个平台的显示、来源别名和徽标共用配置，未来未知来源可独立浏览筛选，尚无提交适配时不提供原站提交。提交记录在统计与分页前按真实来源过滤，保留别名、退休题的历史事实，轻量列表不读取代码正文。
- QOJ 使用独立专用浏览器配置，按需登录；缓存、刷新和退出遵循现有会话白名单、nonce 和加密存储，不加入普通启动的强制登录或没有依据的公开账号绑定。新 Cookie 快照尚待原站确认时不再显示旧快照的登录标记，确认后保存同一状态供重启恢复；保持异步检查。原题身份沿用 QOJ 全局题号，不猜测比赛字母。
- 日夜切换回到顶栏，移除外观页重复主题行；外层边距与图标轴线统一。同步完成只显示对勾。设置插图保留原场景并统一线宽；地球房屋逐间低空落下、延后建满并加快爆炸，服从减少动态效果。
- 新版通过验证并完成本机更新后，自动清理过期程序、安装器及废弃构建，无需再次确认；个人数据、唯一源码和当前仍使用的依赖与恢复证据保留。本轮磁盘清理和上线状态分别按实际记录核验。

共享服务 1.2.9 已独立部署并保留 SQL 备份和数据指纹。只有当前服务端源码与原部署提交完全一致，且原部署、备份、运行时和健康证据全部有效时，才允许复用；本补丁不再次部署服务、不迁移 SQL。

计划验证本机 1.4.30 → 1.4.31 增量及完整安装；公开的 1.4.29 和已验证的 1.4.1 等旧版使用完整 1.4.31 安装器。普通版更新保留当前账号、草稿、提交、私有题单及浏览器登录；升级时重新取得最新个人数据快照，不回填旧恢复资料。管理员程序仅供本机使用，不公开上传。

当前没有本版完整回归、冻结程序、安装升级或远端 CI 的成功结论；这些结果必须绑定最终同一源码提交，全部完成后才更新发布状态。
