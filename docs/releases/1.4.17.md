# ToBe 1.4.17

2026-10-26。用户版通过国内自动更新源交付；管理员程序仅供维护者本机使用。

## 本次变化

- 目录生成按行读取公开数据，在一次计算内复用知识字典；长期缓存改存压缩快照。单题打开只读取必要的题目和别名字段。账号切换、外部导入和 SQLite WAL 提交仍使旧缓存失效；题目等价关系与模拟赛锁定保留。
- 活动明细每个星期增加 AC 汇总。周一至周日为一周，每年第一个星期一为第 1 周；此前几天归上一年的末周。当前未满一周也显示汇总，跨月仍计算整周，每段进度条代表 35 道题。
- 题单支持浏览、搜索、组合筛选标签和编辑自定义标签。标签跟随账号偏好同步，使用“题单 ID—标签”的双向索引；不改动题目、提交或已有目录分类。离开题单页释放其大列表数据。
- 只有标题和原题链接的占位内容不再冒充完整题面。存在完整原站中文译文时优先恢复正文，明确标记的样例输入/输出可恢复为样例。只有日文且无中英文正文的题面暂不可用；题目编号、历史作答、草稿和现存源文保留。
- 排行榜增加本级经验条，头像短暂加载失败会重试。其他用户必须使用新版同步公开资料；未上传头像仍显示默认头像，缺少经验数据明确显示“经验待同步”。不估算他人的经验。
- 算法课程返回按钮、标题、页码靠最左，目录和翻页靠最右；按钮去边框，键盘焦点提示保留。

## 题面检查

对全部 13,184 条公共题目逐项检查：9,652 份存档中，读取时可用 9,564 份（其中 255 份使用已有原站中文译文）；77 份只有占位内容，11 份只有日文。另有 3,532 道题未保存题面，打开时按原有规则向原站读取。没有删除题目或改写个人库。

这是结构、语言和样例完整性检查，不代表所有题目的数学内容都经人工核对；无结构化样例不一定表示题目错误。未批量访问原站、提交测试代码、绕过验证或修改原站限流。原始教育内容继续保留。

## 验证与交付

离线后端检查、周边界/跨月/分页模型、标签读写与跨账号隔离、外部修改失效、公开头像重试、经验进度和三种窗口宽度的导航布局。随后验证实际冻结桌面、编译器、新装及旧版升级。具体结果随发布更新；时间和内存对比使用相同公开种子与隔离状态，不能当作冷开机或真实原站网络测速。

新版保留账号、草稿、提交代码、设置和本机导入。更新前保存并正常关闭旧程序，用 SQLite 在线备份保全 WAL，再进行原目录升级。管理员 EXE、清单和数据不上传公共更新源。

## 性能测量

同机、同种子、独立临时状态各三次，未使用分析器的中位数：首次题面 257.91 → 161.90 ms；首次目录 3929.26 → 2142.11 ms；再次目录（未压缩响应）548.94 → 42.76 ms。题目内容和完整目录语义摘要逐项相同。后台多轮操作后的私有内存 202.3 → 112.4 MiB，三份常驻目录缓存约 55.2 → 3.9 MiB，额外压缩缓存不再持有整个原文作为键。

真实 WebView2 桌面进程组单次对照：首页私有提交内存 502.9 → 425.4 MiB；多页切换后 639.4 → 584.2 MiB，其中 Python 主进程 227.0 → 162.7 MiB。浏览器、渲染与 GPU 等子进程仍占内存，因此尚未达到总计 50–150 MB。这不是任务管理器同一列的读数，不能直接与用户截图的 435 MB 比较；冷开机、真实账号和外网题面仍需单独测量。
