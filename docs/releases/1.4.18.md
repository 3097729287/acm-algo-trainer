# ToBe 1.4.18

本机更新准备中，尚未公开发布。正式下载仍为 1.4.17；管理员程序仅在维护者本机交付。

- 比赛日历只显示今天、明天、后天或 X 天后，同日比赛使用相同底色。当天未读比赛显示提示点与高亮，指针移入或键盘聚焦后记为已读，按账号和日期保存。
- 题单末层使用卡片，保留进度、知识标签；题单内标签并入路径栏。题目显示原有知识点和 AC / WA / TLE / MLE 等判题结果。支持新建、编辑个人题单、选题与排序，随账号同步。
- 公共题单点赞沿用排行榜动效与北京时间每天一次规则，计数由共享服务保存。客户端与服务 1.2.4 一同准备；生产迁移需单独授权，旧服务不伪造计数。私人题单不自动公开。
- 掌握指数保留题单题目的官方作答证据，修复旧编号与同题别名的知识点漏计；同题去重，样例通过与编译错误不作为官方 AC。
- 修复官方 AC 后仍显示在“待攻克”的问题：返回列表保留题目顺序，但分组按照最新结果更新。
- 排行榜只在头像段位框内显示经验进度；顶部爱心改为历史累计 + 今日新增。留言图标使用自身颜色。
- 浏览器回执通过持续 DevTools 事件接收并推送到工作台，保存完成后显示最终结果；本地运行同样推送状态，保留轮询容错。移除回执后的固定等待，沿用原站登录、CSRF 与原生提交。
- 提前读取题面、复用题单内容，减少重复目录解码与背景统计复制；修复题面缓存与个人状态锁的反向等待。本地样例只读取本地题面，不等待原站请求。
- 更新不再被云端离线同步无限阻塞；草稿保存在本机，安装前备份 SQLite。提交、样例运行和模拟赛未结束时不安装，新工作与安装共享互斥检查。

公开种子内容不变：13,184 条题目、9,652 份题面存档、1,378 组默认/详细题解、445 篇讲义、563 个公共题单。已有未完成题面与题解审阅不在本版宣称全部完成。

验证与性能记录在本机 `.backups/local-1418`，最终安装来源写入 `BUILD-INFO.json` 与项目当前更新记录。测试回执不等同于真实原站提交；原站加载和判题本身仍有网络延迟。50–150 MB 是整组进程的优化目标，当前尚未验证达到，不能用仅后端或清空工作集的数字代替整组占用。

源码检查：681 项后端测试、35 项共享服务 SQLite 检查、隔离 MySQL 共享点赞检查通过。前端相对日期/已读、事件回执、题单卡片与新建编辑、标签/头像经验、AC 后分组和顶部爱心回归通过。四站浏览器夹具确认原生提交恰好一次；未发送真实账号提交。

个人数据库在线副本离线测量，20 次连续操作中位数（旧源码 → 本次源码）：进入训练 1358.77 → 106.31 ms，题面读取 405.13 → 41.42 ms，草稿保存 2470.68 → 17.24 ms，提交启动 1294.46 → 18.97 ms，读取完成记录 1456.86 → 0.33 ms。旧版接口包含同步工作台计算，本版把统计刷新移到后续执行；不能把这些数字解释为原站判题速度。Python 后端私有内存从 156.99 MiB 降到 137.38 MiB（20 次后）；此数不含 WebView。
