# ToBe 1.6.14

修正每日任务计数、正式提交完成后的忙态，并降低原生输入监听对系统输入的影响。

- 右下角按实际解锁的挑战计数：三个固定挑战已完成、复习尚未结清时显示 **3/3**；随机任务出现后显示 **3/4**。下一项尚未发出时不提前增加分母。
- 同一次正式提交的 CE、WA、AC 等结果已保存后及时结束转圈，允许继续提交。临时保存失败只重试保存原结果；晚到状态和旧结果不影响新提交，不重复发送代码。
- 已启用连接的常用浏览器可在提交时自动静默启动，沿用同一份原站登录，无需每次预先打开浏览器。没有普通窗口时创建最小化的专用提交窗口，只有登录或验证码需要操作时前置；确认结果显示后只关闭自建页。
- 原生键鼠回调移到独立托管线程，保持应用内快捷键与真实活动判断，避免系统输入等待 Python 锁。随包预编译辅助程序集并核对摘要；隐藏内置网页时停止相应检查定时器。

首次启用常用浏览器连接仍需浏览器自己的扩展授权；程序不复制常用浏览器的 Cookie、密码或浏览历史，不创建另一份牛客登录来替代共享会话。

保留账号、草稿、原提交编号、历史、复习与奖励记录。本版不增加题库内容，不切换 Rust 架构。
