# 1.4.37 知识点学习与连续推荐

这是源码候选说明。实际运行版由程序「设置 → 更新」读取，公开版本由国内 stable 清单读取；本文件不代表安装或发布已经完成。

- 从 1 级开放题库、实验室、模板、从零讲；成长/比赛与模拟赛/活动记录/排行榜依次在 2/3/4/5 级开放。旧账号不失去旧政策下已有入口，隐藏偏好及老手挑战保留。
- 开始知识点需确认，暂停需 PopConfirm，草稿、章节及学习进度保留。先修、实验、跟做、实现、陌生应用及跨日检验随实际已有证据接续，不固定要求每种形式都做一遍。
- 每日学习量按知识难度、学习单元与已有复习安排估计，约 8–25 分钟为初始工程配置，可分多日。它不是已验证的个人认知能力测量，也不限制用户主动继续。今日完成项移到末行，首位切换其它任务。
- 多道不同原题的真实独立作答与不少于 24 小时的跨日陌生题检验支持掌握；跟做题、样例、章节位置、已读及经验不能替代。未知难度的原站作答可用于学习事实，不生成能力分。
- 继续等待或任务耗尽时仍有下一步；保留开始、取消、说明与刷新。读取中保留推荐位置与爱心图标，账号变更丢弃旧结果。
- 更新旧文件只进 Windows 系统回收站；容量不足、不支持或失败则保留并停止新增，保留已核验恢复点。回收不等于实际磁盘释放。
