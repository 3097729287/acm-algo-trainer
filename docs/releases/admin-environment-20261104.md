# 管理员本机补改

基于 1.5.2，仅更新维护者私有管理员程序。公开用户版仍为 1.5.2；本次不发布管理员程序或变更共享服务代码。

管理员工作区使用普通用户的经验增长、等级门槛、初始侧栏及新手流程。新工作区从 1 级开始，不默认预览全部成就。手动调级仍只影响隔离工作区，不生成普通用户的过题、经验或领奖事实。已有个人记录和显式设置保留。

管理员调回 1 级后只显示当前规则的初始板块；旧导航策略保留的入口不越过模拟等级。调到 2 级触发原有等级提升动画，展示维基、实验室等实际新解锁入口；可反复降级、升级预览，普通账号的单调通知确认不变。

公共排行榜及账号维护无需输入管理员账号或密码。私有机器凭据使用当前 Windows 用户的 DPAPI 加密，绑定服务地址，由后台取得和恢复服务端确认的管理会话；凭据和会话不交给前端，不进入公共安装包、同步或公开资产。断网、缺少配置或撤权时显示连接失败并保留重试，不能凭前端标记取得权限。

设置中的账号维护始终可见。按完整登录号或公开 ID 查找，确认后可重置密码或删除普通账号；继续保护管理员账号。重置值及会话撤销规则见[账号说明](../accounts.md)。不使用生产普通账号执行测试重置或删除。

隔离检查覆盖免登录的两项维护操作、保护目标、取消、窄屏明暗主题、1→2 动画、降级后的侧栏、重复升级、新手测试工作区与原草稿保留。原生打包、升级与正常入口的实际结果另记本机交付回执。
