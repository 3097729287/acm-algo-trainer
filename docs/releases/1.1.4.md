# TB 1.1.4 · 本地运行、界面与数据导出

2026-10-20：源码已准备，正在验证与打包，尚未发布。当前正式下载仍为 [v1.1.3](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.1.3)。

## 编译与原站提交

修复干净 Windows 环境下随附 GCC 返回空诊断 CE 的问题。编译器及生成程序现在使用包含工具链运行库的子进程 PATH，清除继承的冻结运行时 DLL 搜索目录并恢复宿主设置；不要求用户安装 MSYS 或配置环境变量。编译失败自动显示诊断，环境故障不再一律误报代码 CE。

相同代码与同一编译器可复用成功编译的可执行字节，缓存仅在内存、至多 8 项 / 16 MiB。每次仍在新的临时目录运行输入并比较全部样例，保留 Job 时间、内存、输出与子进程限制。代码或编译器改变会重新编译，不缓存运行答案。

洛谷无 name/id 的原生语言下拉框通过实际语言选项识别；支持已选 C++17，不再因缺少属性而要求重复切换。四站可见浏览器每个文档只预装一次适配脚本，导航后重新安装，首次表单就绪检查间隔缩短。登录、CSRF、验证码、提交前确认及单次意图保护继续保留。

## 界面与内容

设置标签栏、面板及风格卡共用不透明度。线框为圆角实线，蓝图为虚线与网格；清简和极光分别保留自己的外观。设置行更紧凑、两列均衡，导航编辑移到工作台风格下且默认收起；支持减少动态效果。

「显示比赛平台」控制题库/训练图标与比赛来源。成长页删除 ID，比赛卡移除标题下冗余统计。单题难度不再显示约等于，比赛题显示 `A: 1100`；估算来源与区间仍保留在悬停说明和数据中。顶部状态数字居中对齐。

公开题面转换保留公式、列表、代码、图片与表格；样例从结构化官方数据展示，保留换行并提供复制。旧牛客缓存后台更新到新格式，保留草稿、题目身份与历史。原题未能读取时继续显示已缓存内容并允许重试，不猜测丢失的输入换行。

每日任务提示点仅在有已完成且未领取 XP 的任务时显示；未完成目标题继续留在题单，使用空心状态而非勾选。领取成功即更新任务状态，完整成长统计在后台刷新。

## JSON 与新手指引

偏好设置新增「数据与帮助」：下载当前账号训练、提交代码、草稿、比赛、目标、经验账本及偏好的 `.json`。格式为 `tb-learning-export`，`formatVersion: 1`，包含导出时间与软件版本。导出只读，不包含排名鉴权、密码、浏览器 Cookie 或翻译 API 密钥；暂不提供界面导入。

新注册账号首次登录展示四步指引，完成状态随账号偏好同步；老账号不强制弹出。可随时在同处重新打开，支持键盘、Esc 与小窗口。

## 响应与验证

成长、排行、记录等次要页面按需载入；短期共享重复统计，以个人数据、账号、日期及公共库变化失效。前端主入口从上版约 424 KB 降至约 346 KB；编辑器和数学阅读仍按需加载。这不包含远端登录、验证码及站点加载时间。

在不含外部 GCC 的 PATH 和中文临时目录中，四站实际公共题面的全部样例均通过：Codeforces、AtCoder、牛客、洛谷。一次隔离测量中，首次编译运行 0.77–2.30 秒，相同代码再次执行 0.047–0.108 秒；不代表所有设备或题目。四站原生表单和回执路径另用受控页面验证，没有向真实 OJ 账号发送测试代码。
