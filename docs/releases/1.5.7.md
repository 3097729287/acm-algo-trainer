# ToBe 1.5.7 更新说明

- 牛客题单按学习顺序整理为八个编号阶段，依次进入阶段、专题、练习和题目；统一目录行与章节名称，补全空章节名。原有 72 个来源题单和 1,083 道不同原题的身份、代码与进度关联保留。
- 学习标签页新增“我的训练”文件夹，与首页共用训练清单，标注今日目标、待攻克、待验证、间隔复习、巩固抽检、继续练习及已 AC；原“题目”文件夹继续保留。
- 更新新手指引，加入 11 个实操步骤，包括实际搜索、进入目录、Ctrl+S 格式化、打开我的训练、保存及切换场景预设。需要成功保存或格式化的步骤等待成功回执；修复学习标签页打开后指引不能操作、不能识别已打开题目的问题。提前退出不计为完成入门。
- Ctrl+S 的快捷键说明改为“格式化代码”，单题工作台保留自动保存、单次撤销、C++ 与 Python 本地格式化，以及原有考场限制。
- 放大右上角头像和段位框，头像恢复为 36 像素；保持昵称居中及窄窗口对齐。经验环恢复为从底部开始顺时针增长，顶栏与对战头像一致。
- 对战中间暂时隐藏成就徽章，保留段位勋章；移除外侧展示卡边框与底色，保留头像段位框。排位和思维对决使用一致的展示规则。
- 地球旋转超过速度阈值时直接使用原版爆炸动画；房屋长满后的等待爆炸、拔掉房屋取消等待以及延迟补建继续保留。
- 修复牛客“涂小天与他的画”的字符菱形被解析成列表和横线、缩进丢失的问题。已缓存旧题面可离线纠正；后续读取保留同类字符图。
- 补齐共享译文上传失败后的后台重试与再次打开补传。一个账号用 API 完成并上传公开题面译文后，其他账号无需配置自己的翻译 API，即可复用同一道、同一版原文的译文；后续本机缓存可直接读取。英文题面仍默认显示英文，不共享密钥、草稿或提交代码。

本版不新增题解，不启动剩余全库批量翻译。PDF 继续按需从服务器读取，安装包不重新打入历史 PDF 大资源；保留从旧安装升级时的资源删除清单与个人数据恢复机制。每版 Markdown 更新说明仍自动归档到桌面“ ToBe更新记录 ”文件夹并保留旧版记录。

验证包括题面、共享翻译及本地格式化专项；真实双账号隔离共享；牛客完整题单身份比对和逐层浏览；学习标签、实操指引、贴纸预设、地球互动、九段位经验环和 14 种顶栏布局组合。新安装包与增量包、正常启动及账号保全结果另随本次交付回执保存。
