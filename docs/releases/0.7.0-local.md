# TB 0.7.0 本地更新

本版本用于本机交付，未公开发布、未推送或合并。源码仍在原工作树 `v0.6.1-local/源码`，保留交接时的未提交修复并继续完成。

翻译校验完整英文正文，保护公式、代码、样例和格式；输出截断时拆块重试，旧的不完整缓存不复用。官方 DeepSeek 默认模型为 `deepseek-flash`，自定义模型名称保留。已用现有自定义接口完成 ABC 478 D 的实际全文翻译。其他供应商个人账号未在线实测；接入方式与官方资料见使用说明。

牛客识别真实语言输入框中的 C++（clang++18）。CF 通过页面与同源 API 核对当前账号、题号和提交前基线，桌面宿主独立轮询，可靠回执写入训练与提交历史；重复回执不会重复记题。首次本地通过后取得官方通过，也会正确标为官方确认。

新增窗口位置、正常尺寸与最大化记忆。修复高 DPI 下重复启动造成尺寸放大的问题；显示器改变时将窗口放回可见工作区。

模拟赛创建界面增加重现赛，保留已收录比赛的题序、已解题和全部难度。已知题单不完整或题面、样例缺失时给出具体提示；无法核对完整原卷时如实标注。XCPC 预设 300 分钟、20 分钟错误罚时、编译错误不罚时，均可调整。收录默认包含签到题与未定级题，中文 ICPC / CCPC 赛名同样不受难度过滤限制。入门题提供简明阅读与完整原题解展开。

训练一键清空有确认，并保留草稿、代码、历史、身份和目标。目标计划按具体截止日期、起点和时间容量提供每周题量与独立的每日任务，显示进度落后、时间不足和期限过紧提醒。仅计创建后可靠首次新题通过，不把样例通过或重复 AC 计作新题，不额外发放经验；题量不保证评级或奖项。

蓝桥杯默认 C/C++大学B组：收录 162 道洛谷公开原题，覆盖 2013—2026 年初赛与决赛，提供年份、赛段筛选。早年公开内容并非完整原卷，填空题有合并；题数和题序以原卷为准，题解尚未补全。

“我的训练 / 今日待办”合入“训练与待办”，“活动记录 / 目标计划”合入“成长与能力”。侧栏知识工具标题、搜索、展开收起工具区移除，知识树保留；自定义名称、顺序、书签和快捷键保留。1050×700、18 号字下上方菜单完整显示。

验证使用一次性状态。后端 187 项通过，Worker 5 项通过；前端构建、界面流程、编译器选择、工作台、搜索模型、数学渲染与真实 API 流程通过；连续三次原生窗口启动验证位置、尺寸和最大化恢复。原生提交测试截获全部官方请求：证明编译器选择、表单提交和回执处理，不代表使用真实 OJ 账号提交。牛客 fixture 只确认表单发出，未伪造 AC。

打包及升级使用独立安装标识和临时目录，验证全新启动、本地 C++ 实际编译评测、0.6.0 草稿 / 代码 / 身份 / 经验 / 模拟赛保留和卸载保留数据。迁移工具对全部 SQLite 使用在线 backup，对数据库逻辑内容与普通文件逐一校验，保留旧程序及其数据；个人状态和浏览器资料只进入本机新程序，不进入公共 ZIP。
