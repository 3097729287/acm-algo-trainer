# TB 1.1.1 · 可见浏览器提交与工作台样式

2026-10-18。已正式发布。正式安装包、便携版和 v1.1.0 增量包可从 [GitHub Release](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.1.1) 下载。

## 提交

取消默认静默后台提交和扩展 Cookie 同步。点击提交后打开可见 Edge/Chrome 的原站表单，填代码并按本次用户意图提交一次，随后跟踪相同受理编号的最终结果。首次使用需在 TB 独立浏览器配置中登录原站；验证码和登录由用户完成。配置仅留本机，旧版扩展可停用，新包不再包含扩展。

四个平台的隔离浏览器回归均通过原生表单点击取得 AC 回执，每个平台只发一次 fixture POST，没有访问真实账号。登录、原站异常及调试连接中断仍需按可见页面提示处理，不将页面变化隐藏为无限等待。

## 加载与布局

恢复保存的会话直接由已认证的云端状态请求验证，省去串行 `/accounts/me`；初次登录、跨机合并和会话撤销保护保留。无变化的个人表不再每次启动备份并全量重写，公开账号绑定仍在切换时正确还原。前端登录刷新单飞，慢请求不再每三秒被新代次覆盖。

删除偏好设置中的重复账号入口；版本显示使用软件更新器结果，不使用过期题库同步缓存。排行榜增加摘要卡、边框行卡、紧凑列与姓名行右侧 ID，零题没有奖牌占位。活动数字统一基线；成长页右侧加入真实今日榜单速览。

## 外观

新增清简、线框、极光、蓝图面板风格；纯色、极光、网格、落日和本机背景图。新增可关闭的训练时钟与山景挂件。背景图片由客户端缩小并只保存在本机，不进入账号快照。静态背景不引入持续动画，减少动态效果设置继续生效。

## 内容、更新与验证

打包会从当前公共 JSON 源重新生成题库；目前为 5795 题、2215 份题面、960 份默认题解、960 份详细题解和 376 篇讲义，最终以 `BUILD-INFO.json` 为准。程序版本、源码提交和校验清单一同交付。个人 SQLite、草稿、完整代码、账号身份、快捷方式及浏览器配置在升级时保留。

源码全套 466 项检查、四平台原生表单回执、慢登录单飞、版本显示、外观和三种分辨率回归均已通过。全新安装、完整升级、自动更新器重启和 v1.1.0 增量实际应用均已通过。

同机隔离离线测量：首次服务启动 1037.71 ms、重启 422.89 ms，重启后首次题库读取 212.72 ms，工作区约 90 ms；这些分项不包含云端往返和 WebView 启动，不代表其他设备的整次启动时间。真实账号未被用于自动试提交；隔离结果不构成所有设备启动耗时的承诺。
