# TB 1.4.0

本轮首个正式交付目标，沿用现有版本序列。当前处于发布验证阶段，尚未正式发布；公开稳定版暂为 1.3.5，本机为 1.3.6。发布完成后本页会更新实际构建、验证与下载状态。

- 算法实验室正文加宽，翻页和目录移到右侧；标题正常滚动，不遮挡内容。移除学习中的跟做捷径，末课进入五题跟做，已有进度保留。新按钮与目录使用本页不透明度。
- 比赛分类和讲解分类使用文件夹浏览，父目录包含子项，保留年份、训练情况和排序筛选。
- 顶栏 AC 统一字号、字重与基线；快捷键重置与返回分开。爱心与留言标题补“和”字并居中对齐，主要页面、设置与工作台检查溢出和控件对齐。
- 删除原站提交准备弹窗。未登录时在弹出的浏览器登录，识别成功后自动回本题填码，继续该次未发送的提交；原站验证保留人工完成，发送或拒绝后不自动重发。修复可见浏览器启动环境及登录首页重定向恢复，保留加密登录记忆。
- 登录恢复期间及时读取后台认证结果；工作区和成长统计先检查缓存，避免重复解析整库。大 JSON 协商压缩，账号隔离、来源、令牌和数据迁移守卫保留。
- 清理无引用的浏览器准备组件、样式与事件，整理[数据存储说明](../storage.md)，不删除个人记录、已有题解或历史迁移。

公共种子：5824 条题目记录、2427 份题面、1307 份默认题解、1307 份详细题解、443 篇讲义、5371 条精确关联。全库逐篇精修在另一工作副本独立进行，本版不将其宣称为全部完成；新增题解范围继续为题目难度 ≤2200，全部已有内容保留。

验证使用临时数据库及拦截的原站表单，不向真实账号试交。正式发布前检查完整后端、前端构建和交互、可见浏览器/登录记忆、原生窗口、全新安装与升级、实际增量更新及个人数据保全。管理员程序只供维护者本机使用，不公开上传。共享服务不部署、不迁移。
