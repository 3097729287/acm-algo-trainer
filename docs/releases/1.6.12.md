# ToBe 1.6.12

本次集中完善更新、三人团队训练与思维对决，保留已有账号、草稿、提交及学习记录。

- 国内增量更新优先从两个固定、经过校验的来源获取小更新包，失败后继续使用国内下载入口。显示实际下载与安装进度，独立运行小更新程序后可重新打开 ToBe。
- 修复题库已经达到目标版本时仍重复合并、重复备份的问题。更新的完整耗时以下载、备份、安装、重启并恢复可操作界面的实测为准。
- 三人团队训练恢复提交时同时核对题目、代码与语言，避免把另一种语言的回执误计为本次提交。继续保存共享代码、编辑权、待确认提交及团队成绩。
- 思维对决保留已交答卷，裁判中断、暂时不可用或额度不足时等待恢复。重复交卷只结算一次；真实裁判有调用超时、每场及每日额度限制。
- 切换账号、共享服务或历史对局时拒绝迟到响应，保留当前对局和所属账号的数据。
- 复习通过后立即刷新下一步推荐，旧的已完成复习入口安全返回，避免重复进入和重复结算。
- 单题全屏隐藏右下角卡包入口，保留主界面和阅读界面的原有入口。
- 优化排行榜中首个正式通过记录与排除记录的索引查询，并限制单次查询的执行时间，避免超时请求持续占用服务。

正式桌面版继续使用 React + Python。本次不新增其它题库内容或切换 Rust 架构；思维匹配以共享服务实际开放状态为准。
