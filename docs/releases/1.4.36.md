# 1.4.36 修复候选

状态：前一候选已完成本机安装，最终补改正在重新打包验收，尚未公开发布；国内正式版仍为 1.4.34。

- 修复旧版安装准备失败后仍为 ready，触发重复自动安装并不断创建完整数据库备份的问题。相同快照复用，显式重试不会绕过去重及数量、字节和剩余空间限制。
- 更新备份使用 SQLite 在线备份，保留已提交 WAL；元数据位于独立目录，不覆盖账号文档数据库。已验证的受管恢复点保留两个，旧副本直接删除失败才在容量允许时回收；未知旧副本、损坏/未完成副本、额外手工文件及链接不自动删除。无法清理则停止新增。
- 软件更新恢复目录上限 8 GiB，与原有迁移/手工恢复点分别计量。辅助运行时与程序回滚目录也按校验过的内容复用，保留两个受管恢复点并限制总量；下载缓存另有总量上限，旧版本已知安装包自动退休。各路径持续检查磁盘余量，空间不足立即暂停。旧版异常备份需要先退出旧程序，使用完整安装包修复，不能只依赖新清单改变仍在运行的旧逻辑。
- 单题工具栏左右连接为同一行，分界线仅从正文开始，保持 1px。居中捕获距离增至 32px、释放距离 52px，左右拖动一致。
- 字号数字靠近 px；语言触发器和菜单字号、行高及文字起点对齐。模板点击直接打开下拉，选择后保留撤销载入入口。
- 初始代码模板移除行内名称输入与永久对勾；新建和重命名弹出名称输入。重命名保留同一模板身份及代码，保存后在右侧操作按钮前短暂显示“代码已保存”。
- 设置分类详情不重复显示分类标题；右上返回及 Esc 逐级返回。代码主题预览字号移到标题旁，去掉边框并显示 px。

完整后端运行 999 项测试，2 项跳过。浏览器检查覆盖实际 App 返回及草稿保留、工具栏几何与显隐、双向吸附、模板新建/重命名/撤销、语言对齐和设置逐级返回。原生窗口与安装验收正在进行，不能据此声称本机已修复或已经上线。

公共题库延续 1.4.35 的已验证种子：12,294 题，12,195 份题面，1,686 组双版题解，467 份讲义，7,238 条讲义关联，564 个题单，306 种解法。个人身份、代码、训练和草稿不进入公开发行物。共享服务保持 1.2.9，不部署 1.3.0 或迁移服务数据库。

本次完整安装包建立增量更新基线。此前客户端的允许文件清单缺少 ToBeLoader.exe，本版补齐并验证随程序升级及失败回滚；固定工具链的加载器构建取消 PE 时间戳，避免未改源码仍产生不同文件。旧客户端进入本基线采用完整安装包，后续默认使用校验过的增量包。历史客户端不能使用本版新增文件规则生成的迁移增量，此类包仅用于隔离协议验证，不进入公开资产。


最终补改：

- pywebview 的普通窗口阴影强制启用了 DWM 非客户区；进入全屏后改为遵循无边框窗口样式并清零扩展边距，退出全屏恢复普通窗口策略。仅 CSS 去圆角不能消除原生边框。
- 能力评估采用保存的当前账号原站回执：即使原站不暴露源码，若明确未看题解且提交处于已核实的原站赛时或唯一匹配的已保存模拟赛区间，也作为独立作答证据。普通公开历史仍不能凭一个调用方标志取得独立性。样例和 CE 不计，辅助 AC 不计为独立成功，同一原题仍只计首次学习。未知难度显示待核实及实际参与，不伪造评分，也不挤掉已知难度的 60 题窗口。
- 按精确题目 ID 与提交时刻恢复缺失的历史模拟赛关联，重复同步不重复导入或发奖；区间有歧义时不猜测。原始代码、结果及时间不变。
- 比赛优先按首次加入时间倒序；已保存 addedAt/firstAdded 原样保留，后续补齐题面不会移动原场次。三个旧校队训练入口缺少字段，以首次纳入源码的记录补齐，保留其来源提交；名称中的数字和个人练习时间不作为加入时间。
- 推荐任务移除原生悬停说明框，九类任务使用各自图标；设置 → 新手指引列出图标含义。顶栏推荐内容做 1px 视觉居中调整，缩小展开首项间隔，使其与下方行间距接近。

本机文件清理执行 2026-11-02 用户更新的回收站规则；回收失败或容量不足保留原文件，不永久删除、不清空或挤掉既有回收项。回收本身不等于释放实际磁盘空间。

- 每日难度挑战按能力参考 +100/+200/+300 分区分三个层级；选择任务时按实际完成条件去重，最高难度封顶时选择其他任务。随机复习替代任务也避免与固定任务同义，已领取定义及奖励保持原样。
- 周榜明确以北京时间周一 00:00（周日 24:00）切换。服务仅对生产 1.2.9 的时间边界和待结算周期进行针对性补丁，保留旧奖励，跳过与旧周期重叠的过渡片段；不部署 1.3.0 或新建 013/014 表。
- 模拟赛成绩分子与分母统一字号，代码主题标题旁显示“字号大小: XX px”并对齐。

- 交互设置中的导航编辑区仅保留板块显示开关；左侧导航长按 360ms 后拖动排序，邻项让位，释放回位后保存。短按仍进入板块，Esc 取消，隐藏板块顺序保留，减少动态效果时不晃动。强调色去掉选中对勾，仅保留边框；鸣谢新增金色 Rei。

- 设置插画中，指南针点击可累加转速并衰减恢复，云和恐龙可在卡片内拖动，点击气球球体短暂爆炸；空白区域继续进入设置，其他插画保持原逻辑。插画地球位置向右上微调。学习算法标题后放目录与 X/Y 进度，移除“课程”前缀及“打开对应模板”按钮。
