# TB 1.3.3

2026-10-22：[1.3.3 已正式发布](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.3.3)，管理员专用资产已撤下，公开附件仅提供用户版。标签与 `BUILD-INFO.json` 的构建提交均为 [`84fa8d5830f0ee79abbe4356447a900c6f3e62ca`](https://github.com/3097729287/acm-algo-trainer/commit/84fa8d5830f0ee79abbe4356447a900c6f3e62ca)。后续测试和文档提交不改变已发布二进制的来源身份。

## 变化

- 1262 份现有英文题面默认中文：1260 份新预置译文和 2 份保留的原站中文，可离线切换原文。预置译文绑定原文 SHA-256，保留公式、代码、样例与限制。
- 雷达、题库与筛选共用知识点名称和分类；枚举改入思维与策略，二级雷达 Esc 返回。掌握度 v3 加入题量与难度折减，大类要求各子项具备足够不同题目证据。
- 比赛文件夹与重现赛同目录最新在上，补齐 ARC、AGC、CCPC、网络预选赛等目录；空分类明确未收录，蓝桥杯 B 组独立。重现赛移除顶栏搜索，不被单题难度预设隐藏。
- 列表底部合为一行，每页题数移至交互设置；恢复胶囊开关，统计图标放大并使用 tooltip，等级/经验条与排行爱心对齐。删除重复白色 TB，标识与侧栏图标共轴。
- 修复叶子知识点被识别为空文件夹，点击叶子可直接选中，父知识点继续支持整类选择。
- 新账号首次进入自动打开入门总览，设置内集中提供各页指引，覆盖头像、雷达、段位、成就、目标和工作台；页面不新增冗余按钮。鸣谢新增 NiuXyn。
- 用户版拒绝榜单管理接口；维护者的本机管理工具不公开分发，公共管理由服务端验证角色，本地实验不上传成绩。
- 我的训练、题库、比赛、提交记录与讲义搜索栏统一按“搜索、正倒序、筛选”排列；方向按钮默认颜色与筛选一致，切换方向不再触发筛选提示点。
- 工作区四边统一保留 12px 间距，删除大屏将底部设为 0 的重复覆盖。
- 删除设置组件残留的 24px 底部留白与间距覆盖；首页拼图、鸣谢和翻译面板使用可用高度，不再裁去翻译面板底部边框。做题窗口仍铺满客户区。

## 验证与数据

553 项后端检查通过。前端构建、主界面、真实隔离 API 端到端流程、工作台、账号隔离与首次指引、知识模型、界面回归和五种窗口模拟赛通过。旧端到端断言按新版规范分类和重现赛控件更新后再次通过，测试修正单独提交，不改变运行代码。

最终打包验证包括：原生窗口与 C++/Python、两版全新安装和卸载、用户版完整升级、独立管理员身份与接口隔离、更新助手，以及 1.3.1 / 1.3.2 两条实际增量应用。撤下 3 个管理员专用资产后，GitHub 保留 8 个用户版与公共校验资产；用户二进制大小、SHA-256 及原标签保持，公开校验索引已更新。本机用户版 4587 个分发文件核验，8 个个人 SQLite 库的表、行记录和 schema 保持完整。两版 Setup 和启动快捷方式已复制到桌面。

测试不发送真实原站代码，管理员公共鉴权使用本地服务替身，不声称已测试生产密码登录。生产共享服务版本保持 1.2.1、协议 1，无服务端迁移。

公共种子保持 5819 题、2422 份题面、1302 份默认题解、1302 份详细题解及 376 篇讲义。共享服务保持 1.2.1，个人记录继续保留。
