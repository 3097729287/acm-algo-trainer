# TB v0.10.1

2026-10-11 发布。[正式发布页](https://github.com/3097729287/acm-algo-trainer/releases/tag/v0.10.1) · [对应源码](https://github.com/3097729287/acm-algo-trainer/tree/v0.10.1)。

## 安装与升级

Windows 10/11 x64 推荐 `TB-Setup-0.10.1-win64.exe`，包含 Python、C++ 编译器和离线 WebView2 安装组件。`TB-0.10.1-win64.zip` 是便携版，须完整解压且系统已有 WebView2。发布资产另含 `SHA256SUMS.txt` 与 `BUILD-INFO.json`。

已有版本可在“偏好设置 → 更新 → 软件版本更新”下载后选择“保存并安装更新”，或退出 TB 后手动安装到原目录。个人训练、身份、草稿、提交、设置和导入内容保留。自动安装先保存草稿、执行 SQLite 在线备份并核对 SHA-256，安装后重新打开；进行中的官方提交或模拟赛会阻止安装。

## 本版与已包含的改进

- v0.10.1 修复系统代理共享 GitHub API 查询额度耗尽时的更新检查失败，此时自动尝试一次直接 HTTPS 查询。
- 延续 v0.10.0 的官方 AC 排行榜：历史官方回执自动补传、原题去重、北京时间日榜/周榜/总榜；仅上传身份与成绩摘要，样例通过不计入。当前没有独立的原站防作弊认证。
- 延续启动时与运行期间每日的正式版检查、下载进度、SHA-256 校验、保存并安装更新及安装后重开。
- 包含四个平台的后台官方提交、浏览器会话连接与重复提交保护，结果显示在 TB 内。
- 包含 958 道题和题面、796 份图文题解、376 篇基础讲义；离线配图、点击放大、精简训练与模拟赛布局，以及独立 14–32px 题面字号。
