# TB 1.0.17

2026-10-15。源码、程序、前端与浏览器扩展统一为 1.0.17。正式发布状态以 [GitHub Release](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.0.17) 为准；资产公开前本版本尚未正式发布。

## 比赛与题库

比赛与题库共用顶部分类，顺序为全部比赛、牛客、洛谷、Codeforces、AtCoder、XCPC 历年、蓝桥杯 B 组历年。删除平台下拉框，题库难度与结果筛选直接展开，排序选项为“比赛时间”。搜索、收藏、保存筛选及键盘操作继续可用。

比赛名称统一系列、年份和地点，按数字自然顺序排列；同年日本、台湾、印度等网络赛保留各自地点，同一赛事的不同 Gym 镜像以 Gym 编号区分。题目 ID 不变。

从 [Codeforces Gym 公共列表](https://codeforces.com/api/contest.list?gym=true)发现 500 个名称匹配，排除 29 场仅采用 ICPC 赛制的校内训练、混合训练或选拔测试，核对其中 455 场在线题单，新增 5328 道题。另有 16 场未取得可核对的在线题单，不填造题号、题名或题数。具体来源及未取得场次见[覆盖报告](../../backend/resources/cf-xcpc-coverage.json)。

新库共 **7530 道题、760 场比赛**；保留 **2202 份内置题面、796 份默认题解、1 份详细题解、376 篇讲义**。新增 Gym 题面在打开时联网读取并缓存；原站不可用时可重试或打开原题，不保证新增题面全部离线可读。修复内置 `remote:` 题目没有同步状态时无法读取和缓存题面的情况。

## 难度复核

原有 2202 道题使用 832 份公开来源重新核对，本次来源请求全部成功，调整 1003 道题的数值。CF 优先使用官方 rating，AtCoder 采用最新 AtCoder Problems 模型及已有 CF-EQ 训练换算，洛谷采用当前官方档位及区间换算。牛客没有官方 CF rating，保留明确标注的估算区间。

牛客周赛 165 E 的同色块合并与带权节点对统计估算约 1900，F 的二分答案和前后缀可行区间估算约 2100，替换原来的 2600/3100。统计估算压缩长尾并平滑少量通过样本；不足十次通过、缺少足够同场证据时保持未定级。不再按题面对象默认填 1700，或把零通过直接当作超高难题。

估算显示“≈”，悬停可看来源、区间和依据；本次有难度的 1781 道中，291 道为官方 rating、1490 道为模型或区间估算，其余 5749 道未定级。新增 Gym 未提供官方 rating，保持未定级。升级时替换旧版难度缓存，避免界面继续显示旧估算。[原库复核统计](../../backend/resources/difficulty-audit.json)。

## 活动记录

日历、选中日期与明细表只显示原站通过题数，删除提交数和首次本地通过数。同一道题同一天只计一次，跨日再次通过分别计数；样例通过和失败提交不增加通过数，已同步的题库外公开通过也计入。日期按北京时间划分。

0、1、2–3、4–6、7+ 题分别使用五档颜色与数字样式，最长连续按所选年份内连续有通过的日期计算。

## 升级

保存草稿并退出 TB 后升级到原目录；个人数据库、身份、设置、草稿、提交代码与导入内容保留。新安装提供完整安装版、便携版和同版浏览器扩展；1.0.16 用户提供增量包。更早版本可沿既有增量链升级或使用完整安装包。

346 项后端检查、前端构建、分类与活动样式、工作台和端到端检查通过，原生 WebView2 隔离检查通过。发布资产须通过新安装、升级、个人数据保留和真实增量替换检查；结果记在随包 BUILD-INFO。标签和 BUILD-INFO 指向同一构建提交。测试没有向真实账号发送代码。
