# TB 1.3.0

状态：2026-10-21 已[正式发布](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.3.0)，并完成本机升级。标签、`BUILD-INFO.json` 和资产均固定为已推送的干净提交 `8922ffbc144402adf01b6367a9f68775e1461b77`；后续文档更新不改变构建身份。

## 1.3.0 的变化

- **统一工作台：** 去除侧栏、顶底栏分割线与状态图标边框，表头随页面透明度变化，数值与控件对齐。题库和我的训练只保留题目列表，比赛使用分类目录；目录中的具体比赛直接显示题号、难度与开始按钮。
- **集中筛选：** 比赛分类、知识点、难度、提交结果和常用筛选收进筛选按钮，知识点使用二级菜单。平台简写为 CF、AC 等；ACM 赛事只归入 ACM，不因托管在其他平台而重复归类。列表和比赛均可切换正序、倒序。
- **连续练习：** 顶栏火焰显示连续练习天数，每天至少一次正式提交；样例运行、浏览和只存草稿不计入。按北京时间结算，今天未练习时保留截至昨天的连续记录。火焰在 **1 / 2 / 4 / 7 / 15 / 30 / 60 天**分七档成长，60 天后大小保持不变。
- **知识雷达与题单：** 成长页可点击专题进入二级雷达，再点具体知识点筛题。仅纳入基础至常见图论层次的知识，难度为估计值。题单先提供思想、模板、交互、练习、迁移五阶段框架及双指针交互示例；正式精选与逐题分析仍待填充，不把候选题当成已完成课程。
- **四种训练：** 综合、专项、随机单题、重现赛共用紧凑配置；简单、普通、困难分别使用绿、黄、红，默认范围 0–10000。专项知识点和重现场次在筛选中选择；重现赛难度筛选整场中位难度，保留原题序与全部题目。
- **设置与勋章：** 设置首页采用拼图布局，含咖啡变冷、气球、小恐龙、灯泡、云等动画；账号与身份、鸣谢各有独立入口。鸣谢新增 jiahao27，每人一行。支持 GIF / 动态 WebP / PNG 背景和本机定时播放列表；题解透明度可单独调节。段位和不同成就称号采用不同勋章；同步中显示旋转图标，完成后短暂提示。
- **Python 3：** 编辑器可切换 C++17 与 Python 3，保存草稿及提交语言；本地运行沿用 Windows Job 时间、内存和输出限制。随包提供独立 CPython 3.13.16，无需另装 Python；原站从实际语言控件选择 Python 3 / PyPy 3。
- **独立管理员入口：** 使用 `TB新版.exe --admin` 或“TB 管理员工作台”快捷方式。等级、段位可自行修改，全部成就与称号可解锁。数据和浏览器位于独立 `admin-workspace/`，不登录用户云账号或上传公共排行。
- **提交窗口：** 原站提交打开专用浏览器窗口；最终回执保存并在 TB 显示后，自动关闭本次窗口。登录、验证、错误和结果不确定时保留窗口；其他页面不受影响。新手指引同步更新。
