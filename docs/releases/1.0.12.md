# TB v1.0.12

2026-10-13。[正式发布页](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.0.12) · [对应源码](https://github.com/3097729287/acm-algo-trainer/tree/v1.0.12)。

Windows 10/11 x64 推荐安装 `TB-Setup-1.0.12-win64.exe`，包含程序运行时、C++ 编译器和离线 WebView2 安装组件。便携包 `TB-1.0.12-win64.zip` 须完整解压，系统需已安装 WebView2。程序、前端、安装器和浏览器扩展版本统一为 1.0.12。

已有用户可通过“偏好设置 → 更新 → 软件版本更新”检查、下载并安装，或退出 TB 后安装到原目录。升级保留训练、草稿、提交代码、身份、设置和导入内容；安装前保存草稿并完成正在进行的提交。浏览器扩展随包提供，旧扩展需要重新加载新版。

本版包含四站浏览器会话同步修复：读取非 Secure 和第一方分区 Cookie，识别已登录的 AtCoder 会话，持久化登录状态并在提交前刷新。登录同步不依赖原站标签页；缓存可复用时浏览器无需保持运行，需要刷新时可无窗口启动已安装扩展的浏览器。实际提交仍经过原站的登录、CSRF 和验证流程。

“我的训练”显示当天练习与到期任务，按紧迫程度排列，并内置 7 天复习和 30 天抽检。提交记录按日期分组，保留每次尝试与代码；工作台和列表统一显示评测缩写及颜色。默认题解和可选详细题解继续独立保存。

发布包完成前端构建、打包 API、C++ 编译器、原生 WebView2、新装/卸载、升级保留数据和四站扩展回归。四站测试覆盖无原站标签页、非 Secure Cookie、第一方分区 Cookie、既有 AtCoder 会话、TB 重启、零窗口浏览器冷启动及退出登录更新；使用隔离测试数据，没有用真实账号试提交。安装器和便携包已核对 GitHub SHA-256。
