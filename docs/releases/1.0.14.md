# TB v1.0.14

2026-10-14 正式发布：[下载与发布记录](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.0.14)。对应源码为 [`0d4b6ff`](https://github.com/3097729287/acm-algo-trainer/commit/0d4b6ffd1fa909ac39576caee56c733d89b12d88)。

- 每日目标的当天题单独立保存、独立计数并自动加入“我的训练”，完成另一目标不再清空当前任务。升级时补回旧版错误清空的题单。
- 每日经验按当天 AC 的不同原题计算，旧题当天重新 AC 可计入；历史首次 AC 奖励不重复发放。可领取任务在导航中显示提示点。
- 四站提交验证与账号登录分开处理，复用现有浏览器会话和本次提交页。修复洛谷旧回执阻塞下一次提交、明确拒绝后无法重试的问题。原站验证由用户完成，受理不明的代码不自动重发。
- 修复空样例输入导致题面缺失；加载失败可重试并保留草稿。洛谷优先显示原站已公开的中文题面，补充缺失的公开知识点元数据。
- 随包提供 958 道题和题面、796 份默认题解、1 份详细题解、376 篇基础讲义。

发布资产包含安装版、便携版、1.0.13 → 1.0.14 增量包、程序文件清单、构建信息和 SHA-256 清单。该增量包为 6,610,183 字节、14 个变化文件，保留个人数据，不重复下载编译器与 WebView2。

当次发布记录确认 320 项后端检查、前端构建、界面与工作台、独立 API、四站适配、原生隐藏 WebView、新安装与升级及实际增量替换通过。自动提交验证使用隔离接口，未向真实原站账号提交测试代码。
