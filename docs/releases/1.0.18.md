# TB 1.0.18

2026-10-15。源码、程序、前端与浏览器扩展统一为 1.0.18。发布状态见 [GitHub Release](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.0.18)；资产公开前尚未正式发布。

## 界面与计划

我的训练删除今日训练分组和平台分类栏，仍按当天任务与复习紧迫度组织题目。题库保留平台分类，难度、提交结果和搜索框同排；窄窗口换行。保存的旧筛选在我的训练不再叠加隐藏的平台/分组条件。

每日任务移入顶部按钮打开的独立弹窗，显示领取数和可领取提示；成长页移除重复区块。领取后焦点落到已禁用按钮时，Esc 仍可关闭弹窗。更新通知增加“一键已读”，已读状态持久保存，通知和题目链接保留。

等级称号调整为编程入门、基础研习、算法实践、结构分析、状态建模、构造与证明、复杂度掌控、算法设计、竞赛研究、算法专家；经验曲线、首通记账与段位积分规则保留。活动统计移除高亮色块框，使用数字、单位与细条，保留五档颜色，年度合计注明题次。

多目标的每周比赛题量只显示一份。同类赛事取最高周题量和最高练习范围，建议题目排除已通过和退出公共选题范围的条目；各目标的每日题单、归档与进度仍独立保存。合并周题量不重复相加。

批量分配每日建议题时复用本次请求的题库快照，避免每激活一道题都重复加载整库；下次请求仍读取新数据。

## 比赛范围、名称与时间

自动新增牛客、洛谷、AtCoder 已结束比赛。CF 普通比赛仅补已指定题解的 31 场；另按公开 Gym 题单补新 XCPC。历史 XCPC 从 2017 年起收录，不把单纯采用 ICPC 赛制的校内训练当正式 XCPC。

160 场、1748 道旧自动收录条目退出公共选题，保留原有题目 ID。升级不删除私有库中的旧题、个人训练、代码、草稿、经验或回执，旧题仍可继续历史训练与复习；新安装不再包含这些旧 Gym 条目。

赛事名称改为统一中文格式，保留国家/城市、资格赛/区域赛/决赛、热身赛、轮次、组别与不同 Gym 镜像。AtCoder 与普通 CF 场次也采用中文显示名，题目 ID 和规范原题 URL 不变。

核对 63 场原赛时间。2019 银川赛按原赛榜单与公开题面核对为 2019-10-20，修复被 2026 年镜像重现日期覆盖的显示。Gym 上传时间单独保留，不作为原赛日期；未核实具体日期时只显示年份，并按年份参与时间排序。[赛事审计](../../backend/resources/contest-audit-1.0.18.json)。

## 难度与知识证据

公共库为 **5782 题、600 场**，含 **295 场、3580 道 CF Gym XCPC 题**；内置题面 2202 份、默认题解 796 份、详细题解 1 份、讲义 376 篇保留。

284 场 Gym 提供的整场难度按 1–5 级显示，明确区别于单题 CF rating。其他赛事按已评级题目给出参考，覆盖不足时显示已评级题数。模拟赛期间不泄露整场难度或知识点。

新增 439 道有依据的单题估分。已核对镜像采用完整题单对应及本题唯一原题名；原始榜单估算用已有复核题校准，保留验证误差与宽区间。另采用作者发布的 XCPC Sight 聚合模型数据，明确标注非官方估算，少于十支队伍通过的题不向高分外推。当前 291 题为官方评级、1929 题为估算、3562 题证据不足而未定级。[评级审计](../../backend/resources/xcpc-rating-audit.json)。

新增 172 道具体知识标签，来自可核对的同题镜像及对应公开题解的明确技术词。文档先按完整题单识别，再按题名/题号识别页面；未识别扫描页、否定技术描述与无明确题目归属的页面不猜测。自动标签注明未复验算法，宽分类不冒充具体算法。[知识审计](../../backend/resources/xcpc-knowledge-audit.json)。

## 升级与验证

每次启动立即强制检查正式版，登录前也可以更新；发现新版自动下载、SHA-256 校验并安装，无需确认。原每日检查设置仅控制运行期间的额外检查。安装前自动保存草稿，在线备份所有本机账号数据库及 WAL；提交或模拟赛进行中则等待结束后自动重试。网络失败保留当前程序并后台重试。隔离测试覆盖以上过程，不执行真实账号提交。

保存草稿并退出后安装到原目录。1.0.17 用户使用对应增量包；更早版本可沿已有增量链或使用完整安装包。个人状态目录保留，旧通知可一键标为已读。

后端、前端与原生检查覆盖目录退役、原赛日期、白名单发现、合并周计划、建议题目去重、批量已读、弹窗键盘、窄窗口与个人记录保留。发布资产须完成新安装、升级、卸载保留数据和真实增量替换验证，最终结果及构建提交记入 BUILD-INFO。测试不向真实账号发送代码。
