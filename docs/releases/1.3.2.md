# TB 1.3.2

2026-10-22：源码和文档已同步准备，尚未正式发布。正式下载暂保留 1.3.1；本版完成隔离构建、安装与增量验证后发布。

## 变化

- 删除全局页面面包屑与多余边距；大写 TB 切换侧栏，底部对齐，设置入口不随同步状态移动。设置二级页统一右上返回箭头与 Esc，冗余说明移入 tooltip，翻译配置使用整块面板；鸣谢标题放大、昵称配色。
- 今日目标左对齐，每日目标题目并入我的训练；线框主题每题有边框，圆角内容正确裁剪；清理难度约等号、历史提交占位和箭头。
- 比赛与重现赛按目录逐层查找；专项知识点恢复多级菜单并支持大类选择，顶栏显示可取消的知识筛选，各有序搜索提供升降序按钮。
- 模拟赛历史下移并按新到旧排列，四模式添加边框；默认时间随题型、难度和题量变化，单题从 30 分钟起，重现赛使用原时长，手动设置保留。
- 模拟赛“提交”打开原站浏览器，保留考场回执与计分；选题菜单不被裁剪，计时和结束按钮移到右上角。移除代码导入、手动保存按钮与编辑器焦点外框，自动保存保留。
- 掌握度改为个人有效作答的解决率、独立性、稳定性与难度加权，少于 5 道不同有效题或少于 3 道有难度题显示 `?%`；同题跨标签不重复计样本，题库扩容不降低得分。
- 紧凑排行榜，恢复 AC 颜色、放大 AC 与爱心数量，爱心默认实心，火焰统一图标；头像框与轴对称段位勋章重绘，经验从底部顺时针增长，成就按含义配图，目标按钮移入账号统计卡。
- 设置的八块分别使用恐龙往返、建筑地球、气球、横向云、咖啡、轨道、柔和灯泡和星座。按横向/竖向所需空间安排并居中对齐；恐龙细化、触壁转向，气球与云延长漂移，地球建筑各不相同，爆炸包含碎片、冲击波与渐变重建。

## 数据与验证

公共种子维持 5819 题、2422 份题面、1302 份默认题解、1302 份详细题解、376 篇讲义。共享服务保持 1.2.1，账号、公开成长与互动协议均为 1，无需服务迁移。个人训练、代码、回执、身份和偏好不重写。

功能回归使用临时状态与合成回执，不向真实原站试交代码。完整后端 532 项及前端构建、主界面、真实隔离 API E2E、目录、筛选、设置、透明度、排名、成长、掌握度、自动保存和模拟赛五种窗口尺寸已通过。代码与界面复查还修复了 tooltip 的 Esc 被设置页全局返回提前捕获的问题。原生窗口、随包编译器、新安装、完整升级、更新助手及 1.3.0 / 1.3.1 实际增量应用均已通过，最终构建提交与资产校验随正式发布记录补充。
