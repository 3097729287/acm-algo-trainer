# Shared service 1.4.3

发布准备：四档卡包、五连开包事务、逐包品质保底、每日最多三个任务卡包及旧未开箱策略兼容；已开结果与幂等账本保留。无 SQL 模式迁移，所有已有账号、记录、点赞、社交、私有快照和奖励事实继续使用原表。

公开下载只转发本地明确索引的用户资产，固定 GitHub 仓库和版本路径，不接收任意上游地址、不转发用户凭据、不把大型文件缓存到账号服务器。最多两个有背压的下载流，大小及 SHA-256 校验完成前不发送最后的有界片段。既有 Caddy 文件仍优先本地读取；未知文件和管理员资产不代理。

部署前须在线事务备份到本机私有目录并校验，停写后核对所有原表完整数据摘要，代码切换后再次核对；原 MySQL／Redis／Caddy 配置与卷保留。上线状态和准确源码提交以后续交付证据为准。
