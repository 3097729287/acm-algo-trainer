# TB 1.3.5

本次修复以 1.3.4 正式版为基础，用户版公开发行，管理员工具仅保留本机。

- 登录状态立即返回，保存会话在后台恢复；网络失败显示错误和重试，认证和云端状态合并保持原要求。
- 默认从现有阿里云 HTTPS 服务读取更新清单并下载安装包，客户端无需连接 GitHub。校验 SHA-256，备份 SQLite，等待草稿与待处理提交保存，再安装并自动重开。
- 新版正常登录后识别旧版官方程序，先备份个人目录；仅清理已核实的程序文件并修正旧快捷方式。运行中、管理员、自行修改和未知文件保留。
- 每日任务领取复用已验证证据，在本机事务提交后反馈；云同步通知和成长统计在后台完成，重复请求不重复发经验。
- 专用浏览器在登录后预热，自动提交目标在后台创建，不抢占 TB。需要原站登录或验证码时显示本次页面；原生表单、CSRF 和回执核对保留。
- 删除工作台顶部重复评测条，评测结果集中在下方；必要的验证入口也在结果区。
- 公共库保留 5819 条题目、2422 份题面、1302 组两版题解，讲义更新为 443 篇，包含 43 篇独立基础课。《小月的长廊》保留图文推导、边界二分与 lambda 讲解。

全库逐篇精修与阅读复核仍在进行，不将基础补齐当作全部人工教学验收。实验室联合更新继续单独验证。

验证使用隔离数据库、浏览器配置和安装目录，覆盖登录恢复、账号隔离、奖励幂等、原站适配、新装与升级、实际更新助手及文件校验。没有用真实账号试交代码。账号服务版本及协议不变，Caddy 仅增加公开更新文件路由。

首次使用国内更新渠道，需要安装本版一次；之后由本版自动下载安装后续版本。保存草稿并正常退出旧 TB 后，安装到原目录可沿用全部本机数据。
