## 称号与成就

累计 AC 保留 1、10、25、50、100、200、300、500、750、1000、1500、2000 共 12 档。500 题起改奖永久称号：解题能手、解题精英、千题大师、解题宗师、双千传奇。连续训练 30、90、180、365、730 天改奖持之以恒、百炼不怠、半载精进、全年坚守、双年不辍；730 天即两年，替代旧 1000 天目标。

删除累计 AC 3000/5000/10000 和独立 AC 3000/10000 的展示及新奖励。所有已发经验继续保留，不因改奖称号或目标退役而降低等级。成就仍按稳定 ID 一次记账，跨电脑恢复不重复奖励；旧 1000 天记录可证明两年称号。

自动佩戴最高 AC 与最高连续训练称号各一枚，顶部和排行榜显示勋章，成长页展示全部已获得称号与用户名、公开 ID。新达成的成就卡片带边框和“新达成”，仅鼠标经过或键盘聚焦该卡片后清除；打开或关闭弹窗不会批量清除。已读状态跨电脑合并，迟到保存不恢复已读提示。

点击顶部段位经验框直接打开训练概览。最高已达成 AC 成就加边框与奖杯，下方只展示下一个目标；“仅样例通过”和“今日待办”不占概览栏位。我的训练导航显示当天未完成提示，每日任务提示只在顶部任务入口显示。

## 账号、排行榜与操作

成长页集中展示账号管理、CF/AtCoder 公开绑定、翻译 API 和获得称号。删除牛客、洛谷空评分行，四站题库、登录和提交支持继续保留。偏好设置合并训练、键盘与快捷操作，Ctrl+K 入口继续可用。

排行榜显示称号、等级、段位和排位分；公开 ID 与登录号分离。没有排位时显示未解锁，旧客户端未上传摘要时不虚构资料。当天登录零题也入榜，零题不参与名次奖励。公共成长摘要通过认证会话独立上传，排行读取无需解压个人源码快照；目前仍没有独立原站防作弊认证。

比赛列表增加“开始比赛”，校验后启动对应重现赛，继续遵守进行中比赛、完整题单和题面限制。推荐题整行进入单题，删除重复练习按钮。

## 响应与加载

- 比赛列表每页 40 场，搜索或排序变化后回到第一页。
- 无变化的工作区响应复用已有对象，减少后台刷新导致的重渲染。
- 窗口隐藏时暂停常规界面数据和目标轮询，恢复可见时刷新；后台会话检查、上传、任务执行与软件自动更新继续，自动安装流程不受隐藏状态影响。
- 延续紧凑题库响应、缓存序列化字节、编辑器按需加载、限量后台获取题面和缩短数据锁。

数学标题、Markdown 与讲义阅读器按需加载后，生产构建主入口 JavaScript 从 871.12 KB 降至 423.61 KB，另有 8.90 KB 的首屏共享 JSX runtime；这不代表页面全部 JavaScript 只有 423.61 KB，编辑器仍为约 560 KB 的按需模块。

原生 WebView 使用活跃时 Normal、最小化时 Low 的内存目标；主窗口取消不需要的请求头订阅。三轮同一隔离 fixture（400 次、每次 64 KiB 回环响应，统计六个进程）中位数如下：

| 隔离基准 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 请求阶段耗时 | 347.4 ms | 212.7 ms |
| CPU 时间 | 1.078 秒 | 0.531 秒 |
| 前台私有内存 | 318.18 MiB | 248.32 MiB |
| 最小化私有内存 | 317.71 MiB | 234.66 MiB |
| 最小化工作集 | 497.96 MiB | 363.63 MiB |

该 fixture 中，最小化后 52 KB 草稿 POST 与 JavaScript 定时器仍可运行，恢复后回到可见/Normal；没有使用 WebView Suspend。真实 Windows WebView 的官方及静默流程隔离回归也已通过，全部请求由本机 fixture 拦截，没有向真实原站提交。最终安装包验证仍待完成，以上基准不能作为其他电脑的内存或耗时承诺。

这些是减少渲染、请求和重复计算的具体措施，不等于对所有机器的耗时承诺。此前 1.0.19/1.0.20 的隔离历史数据对比见[原测量记录](1.0.20.md#加载与内存)，不能作为本版新构建的测试结果。Python 本机服务和 Node.js 共享服务继续使用，没有改写 Go。

## 同步、迁移与验证边界

账号、排行榜和数据库使用原服务器和原 MySQL 卷。`005_account_state.sql` 的账号同步协议 1 已部署，`006_public_progress.sql` 于 2026-10-16 13:51（北京时间）完成生产迁移。公网 HTTPS 健康响应确认 `version: 1.1.0`、`accountStateProtocol: 1`、`singleSession: true`、`publicProgressProtocol: 1`。此次迁移前后 143 个身份、3 个账号、164107 条官方 AC 记录及其指纹、4 笔共 400 XP 的奖励和 3 个会话完全一致；账号快照与登录日期各 1 条，同账号多会话为 0。原卷及 compose 覆盖配置未改动，在线备份已在受控位置核验；没有用真实账号试提交。

账号快照覆盖训练、完整源码、草稿、模拟赛、目标、每日题单、经验、奖励和偏好；首次合并在线备份，三方冲突保留恢复版本。新设备登录撤销旧设备会话，联网旧设备约三秒内检测失效；断网未上传记录仍保留。Cookie、翻译密钥、DPAPI 密文和设备配置不上传。详见[账号与同步](../accounts.md)。

为兼容旧版增量更新器，1.1.0 的构建信息与来源清单通过原有 `resources/` 白名单路径交付，旧版增量清单不声明两个根目录元数据文件。新版冻结程序启动时先检查版本、40 位提交号、来源清单 SHA-256、文件大小及链接路径，再原子恢复根目录副本；失败回滚并写日志，不修改个人状态。新版更新器为后续升级增加这两个精确文件白名单，没有放开个人文件路径。
