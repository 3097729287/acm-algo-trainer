# TB 1.0.16

2026-10-15。源码、程序、前端、浏览器扩展同版。标签和 BUILD-INFO 指向构建提交；发布状态与下载资产以 GitHub 发布页为准。

修复 CF 异步 `problemLock`：原站取得题目锁前会禁用提交按钮，现在等待原生控件启用，最多 30 秒；不强制启用，不修改原站验证。已选中的题目和语言不重复触发切换，避免重启题目锁。支持默认类型按钮、CF 原生 `.submit` 控件和外部表单关联。后台连接超时不再错误弹出登录准备，也不因普通适配错误强制手动提交。实际原站验证仍由用户完成；45 秒没有受理编号继续核对，不重发已经发送的代码。

等级限定为 1—10，每级所需 XP 逐级增加，累计 9000 XP 解锁 TB 排位。黑铁、青铜、白银、黄金、铂金、翡翠、钻石、大师、宗师、王者有不同图标和颜色。经验原值、个人记录和已达成成就保留；原等级按新曲线重新计算。

排位从首次解锁时刻开始，历史过题不会重新奖励。独立首次官方 AC 满足当前段位难度后加 20—200 分，同题只奖励一次。所需难度随段位由 800 提高到 3000；翡翠起每天需独立 AC 一道达标题，已结束的缺勤日扣 10—30 分，重复 AC 可用于维持。王者每 500 分增加一星。当前分数决定当前称号，可因缺勤降低。此为本机训练排位，未改动共享排行榜服务。

新增 2400、2700、3000、3300、3600 难度成就；独立过题称号延伸至万题；连续训练延伸至 1000 天。等级栏显示本级 XP 或排位分，今日 AC 单独显示，移除旧弹出统计方块。昵称、密码与退出操作默认放在“管理账号”折叠区。取消牛客、洛谷公开统计绑定，不影响四站原站会话及提交。

公共题库 2202 道题及题面，796 份默认题解、1 份详细题解、376 篇讲义。所有题目有知识分类和难度，762 道为 TB 估算，保留 LOW 可信度及估算区间。统计估算采用同一比赛公开通过数；其他估算采用题面模型与技术复杂度，不是原站官方 rating。部分分类只覆盖题面模型，算法代码未复验。公开题库不含个人进度、凭据或 Cookie。

XCPC 名称统一为系列、年份、地点与赛种，省赛去除赞助商及届次冗余，热身赛仍单独标识。周赛、小白月赛、练习赛使用已有短名模板，之后添加时自动规范化。ICPC/CCPC 等重复题名前缀被去除，原始标题和题目 ID 保留，个人提交仍按原题 URL 匹配。

升级：保存草稿、退出旧程序后完整安装，或使用 1.0.14 → 1.0.16 增量包。安装不覆盖个人数据库；本地 1.0.15 也可完整安装。升级后重新加载浏览器连接扩展。官方账号 POST 测试全部在隔离接口执行，不把测试回执作为真实账号提交成功。
