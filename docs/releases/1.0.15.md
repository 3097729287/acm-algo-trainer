# TB v1.0.15 源码更新

**状态：源码已同步，已完成本地构建与验证，尚未发布 GitHub Release。** 最新正式版仍为 [v1.0.14](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.0.14)。本页描述当前源码，不提供尚未发布的安装包链接。

## 官网提交与回执

Codeforces 按已配置账号定期读取官方提交记录；浏览器扩展读取 Codeforces、AtCoder 本人记录，并观察牛客、洛谷的原站提交与评测响应。即使没有由 TB 发起的提交任务，也可同步能匹配当前题库原题的回执。记录按平台和提交编号去重，保留原始提交时间；没有取得源码时明确标记，不用草稿代替已提交代码。

提交准备超时或原站要求验证时，打开本次浏览器提交页并尝试预填代码，由用户完成原站验证和提交，TB 继续检测结果。不重复发送受理不明的代码；原站不可访问时保留等待与重试，无法保证立即取得结果。

## 训练、比赛与题库

- 顶部显示按北京时间统计的今日 AC；成长页显示总做题数，包含已配置公开账号在题库外的已知通过记录。
- 全局提交历史只显示正式提交；运行与样例记录保留在工作台。
- 比赛名称统一并按自然顺序排列，重现赛选择可搜索，修复长题号与预览标题排版。
- 已结束模拟赛支持单条或全部删除，保留草稿、提交代码与 AC；进行中的比赛须先结束。
- 随源码提供 1,982 道题和题面，比 1.0.14 增加 1,024 道；保留 796 份默认题解、1 份详细题解和 376 篇基础讲义。新增内容包括公开 XCPC 赛题、蓝桥杯 B 组共用题与已有比赛题单。
- 内置题单升级替换可见题号时，每日目标通过原题 URL 继续识别原有任务和提交，不清零已完成目标。

部分比赛题单仍待核验：Codeforces problemset API 未必覆盖 Div.1/Div.2 共用题，部分洛谷入门赛完整题单尚未全部核实。实际覆盖与缺失原因保存在 `backend/resources/*-coverage.json`；不将已收录题数表述为所有比赛都已完整。

本地交付记录包含 330 项后端检查、前端构建、界面与工作台、四站适配、手动提交接续、独立官网回执、新安装与升级、编译器及原生桌面验证。适配器主动提交测试均使用隔离接口，不向真实账号提交测试代码。

正式发布时须重新核对构建提交、版本、文档、安装包和增量包，并按[发布同步检查](../development.md#发布同步检查)同步 GitHub。
