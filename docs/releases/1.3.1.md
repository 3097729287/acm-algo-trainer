# TB 1.3.1

2026-10-22：[1.3.1 已正式发布](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.3.1)，本机已更新。构建提交与标签均为 `7ab050ae0add7356a5f3b63d2b6a9e8f498b3a0c`；后续发布状态文档单独提交，程序来源保持不变。

## 变化

- 顶部统一搜索与筛选，移除重复提示；收藏、排序和方向收进筛选。比赛默认列表，可在筛选中开启文件夹浏览。
- AC 显示为“今日之前的累计 + 今日 AC”，如 `AC:82`、`AC:82+2`。火焰改为静态手绘，段位使用装饰头像框，成长页整合大型账号统计与知识雷达详情。
- 四种模拟赛共用生成和开始流程，专项知识点及重现场次直接选择。难度预设为 1000–1400、1300–1700、1600–2000、1900–2200；修复浮层下拉选择失效。
- 设置新增可修改、冲突检查和重置的快捷键；导航名称、分组与顺序合为一个编辑器。二级设置由顶栏面包屑标明，Esc 返回首页。
- 修复列表被强制全透明，统一各页与题面、编辑器、题解的透明度。进入题目后铺满整个客户区，隐藏菜单与外框，返回箭头或 Esc 退出。
- 排行榜铺满内容区，奖牌移到最前；本人爱心有颜色且无留言按钮。爱心动态始终保留栏目，仅显示北京时间当天记录；删除使用就近确认浮层。
- 设置拼图自适应填满页面；恐龙往返、云二维漂移、灯泡柔和发光，新增地球建造与爆裂循环。鸣谢居中放大，通知移除题库更新设置。
- 账号设置先显示已登录的本机身份，补充状态后台读取。窗口最小化不再修改主 WebView 的可见性；渲染进程退出后限次恢复，持续失败显示恢复入口，草稿保留。

## 验证

前端构建、统一搜索/筛选、透明度 0/50/100、可修改快捷键、四种训练生成与开始、排行榜当天动态、账号立即显示及全窗口练习已通过隔离验证。原生 WebView 模拟渲染进程退出后自动恢复，52,000 字符测试草稿保留；最小化、原站覆盖层和旧 SDK 回退通过。全部验证仅用隔离状态和合成回执，没有真实原站试交。后端完整检查通过（525 项，包含偏好持久化、北京时间 AC 基线与原生恢复逻辑）；旧版 UI 回归已按新入口更新。随包 C++ / Python 样例、管理员隔离、原生窗口、全新安装/卸载、完整升级、更新助手正常关窗与重启，以及 1.2.1 / 1.3.0 两条实际增量应用均通过。

公共种子保持 5819 题、2422 份题面、1302 份默认题解、1302 份详细题解和 376 篇讲义。共享服务保持 1.2.1，状态与互动协议保持 1，无需服务迁移。

[GitHub CI](https://github.com/3097729287/acm-algo-trainer/actions/runs/39650917032) 的前端与共享服务已通过；后端工作流汇总状态以链接为准。本机后端完整 525 项已通过。

本机升级前在线备份 8 个 SQLite 数据库；升级后个人表和 schema 指纹不变，4583 个分发文件的 SHA-256 与清单一致，原 3 个普通快捷方式保持。当前工作区未自动启动，未合并公共种子覆盖个人内容。
