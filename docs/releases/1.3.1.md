# TB 1.3.1

状态：源码已更新，发布资产与本机升级正在验证。正式下载暂保留 v1.3.0；完成安装和增量验证后更新。

## 变化

- 顶部统一搜索与筛选，移除重复提示；收藏、排序和方向收进筛选。比赛默认列表，可在筛选中开启文件夹浏览。
- AC 显示为“今日之前的累计 + 今日 AC”，如 `AC:82`、`AC:82+2`。火焰改为静态手绘，段位使用装饰头像框，成长页整合大型账号统计与知识雷达详情。
- 四种模拟赛共用生成和开始流程，专项知识点及重现场次直接选择。难度预设为 1000–1400、1300–1700、1600–2000、1900–2200；修复浮层下拉选择失效。
- 设置新增可修改、冲突检查和重置的快捷键；导航名称、分组与顺序合为一个编辑器。二级设置由顶栏面包屑标明，Esc 返回首页。
- 修复列表被强制全透明，统一各页与题面、编辑器、题解的透明度。进入题目后铺满整个客户区，隐藏菜单与外框，返回箭头或 Esc 退出。
- 排行榜铺满内容区，奖牌移到最前；本人爱心有颜色且无留言按钮。爱心动态始终保留栏目，仅显示北京时间当天记录；删除使用就近确认浮层。
- 设置拼图自适应填满页面；恐龙往返、云二维漂移、灯泡柔和发光，新增地球建造与爆裂循环。鸣谢居中放大，通知移除题库更新设置。
- 账号设置先显示已登录的本机身份，补充状态后台读取。窗口最小化不再修改主 WebView 的可见性；渲染进程退出后限次恢复，持续失败显示恢复入口，草稿保留。

## 验证

前端构建、统一搜索/筛选、透明度 0/50/100、可修改快捷键、四种训练生成与开始、排行榜当天动态、账号立即显示及全窗口练习已通过隔离验证。原生 WebView 模拟渲染进程退出后自动恢复，52,000 字符测试草稿保留；最小化、原站覆盖层和旧 SDK 回退通过。全部验证仅用隔离状态和合成回执，没有真实原站试交。后端完整检查通过（525 项，包含偏好持久化、北京时间 AC 基线与原生恢复逻辑）；旧版 UI 回归已按新入口更新。发布包检查完成后补充结果。
