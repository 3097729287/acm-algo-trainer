# ToBe 1.4.33

本机候选，尚未正式发布。当前安装为 1.4.32；公开下载保持已发布版本。共享服务生产仍为 1.2.9，1.3.0 源码候选未部署。

## 编辑与外观

- 外观增加独立代码主题板块：22 种配色及跟随界面，左侧滚动列表，右侧 C++ 预览，支持键盘选择与账号同步。
- 参考两个视频与 Woodfish 7.0 官方示例，加入原生 CodeMirror 渐变、微光、彩色光标和弹出菜单玻璃效果。使用 MIT 色板并附许可证；未打包外部扩展或 Bearded 主题。视频描述与官方源码／预览已核对，视频播放受 HTTP 412 限制。
- 光标保持可见并停用闪烁，关闭代码连字；括号柔和高亮，夜间选区降低亮度。题面隐藏滚动条并保留滚动。
- 透明度采用分类目录，任务、成就、初始模板、模板菜单、比赛选题、模拟赛及普通单题各自适配。
- 已学会知识点使用实心方块和整行浅绿背景，讲义工具栏去边框；模板详情去重复标题和多余圆角，工具栏贴齐两端。
- 比赛列表去表头，排行榜刷新去边框、互动列间距统一；题面图片保持自然比例并限制显示大小，下拉菜单适配实际文字宽度，密码眼睛状态纠正。
- 单题工具栏默认锁定，编辑器左侧切换锁定；解锁后顶部悬停或键盘聚焦显示。草稿提示位于右上角。

## 成长、训练与同步

- 成就需要手动领取；日期与名称同行，删除已达成及领取后 XP 状态行。旧奖励与首次完成事实保留，重复领取不重复加 XP。
- 八档难度为 1500、1600、1700、1800、1900、2000、2150、2300，奖励相应勋章，旧 ID 和已发奖励不变。
- 新增早晨／夜晚／周末、单日提交／AC／WA、多轮间隔复习先错后对、给不同用户点赞、对今日第一留言及霸榜天数成就。仅使用真实正式提交、复习任务和服务确认的互动事实；测试未向真实用户发送留言或爱心。
- 日常与额外任务分组，未完成项不显示“进行中”。清空训练保留复习计划，次日继续显示逾期复习；普通单题实际修改代码后加入训练。
- 模板完整练习通过后退出继续练习，不冒充原站通过或官方经验。真实比赛按官方结束时间倒计时。
- 代码模板和已选模板修改后唤醒后台同步；聚焦刷新保留未保存内容。代码主题与题单位置纳入私有账号同步偏好。
- 原站返回详细诊断时保留并显示；CF 仅按真实测试集和通过数量生成失败测试编号，旧回执可补充详情而不重计提交。

## 加载与共享服务候选

题单目录和索引按实际内容／进度缓存，登录后空闲预载；恢复目录、筛选、页码和滚动。公共种子校验及合并按流和逐资源读取。Python 入口先显示轻量原生加载窗口，总启动时间以最终打包实测为准。

服务 1.3.0 增量 013/014 分别增加每日观察的三类榜首记录与公开译文缓存。星星每三颗合为皇冠，九天起为天数徽章，紧贴奖牌下方。共享译文按源文摘要绑定，个人 API 翻译先保存再异步共享，不上传密钥、私人代码或身份。生产部署尚未执行，旧服务继续可用。
