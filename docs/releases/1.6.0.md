# ToBe 1.6.0：学习进度与周计划

以 2026-11-05 确认的《教学内容进度总结功能设计》为本版主线，整合此前优化建议中的每日反馈、学习接续、阅读恢复和交付校验。包含 1.5.9 的既有修复。

- 顶栏新增“学习进度与周计划”，位于书本入口左侧；单题工具栏也可打开，默认快捷键 Ctrl+Shift+P，可在原快捷键设置中调整。
- 用完整文章说明当前阶段、最近进步、主要缺口、本周安排、下一项任务、下一阶段与检验方法；提供简略／详细和语气设置，可查看整体或当前专题。
- 先设置工作日、周末时间和休息日，再形成整周方案。支持一个总目标和多条共享预算的主线；新方向、并行主线和阶段切换须采纳后执行。同阶段跨周续排，未完成内容按预算接续。
- 周计划与顶部推荐共用已采纳任务；整周安排显示在“我的训练”和学习目录中。可以进入真实课程、模板练习、原题、复习和综合检验，支持换题与推迟。
- 已读、原理检查、跟做、独立实现、独立原题、延迟保持及综合应用分别记录。复用正式回执和原有能力模型，不用阅读、样例或时长代替掌握；公开历史独立性未知时保留待验证状态。
- 提供困难选项与短原理检查；明显停滞时提示先说明情况，不自动替换训练方向。限时训练期间保留已有规划，交卷后再分析与调整。
- 有效学习时间只记录真实交互之间不足五分钟的学习区间。连续五分钟无操作的整个区间不计入；键盘、鼠标、滚动和触控均支持，重复回执和并发页面按时间并集合并。
- 支持全屏和可拖动、缩放、置顶、收起的 ToBe 内浮窗，保存阅读方式、位置、尺寸、滚动和展开状态；更新按段提示，悬停或键盘查看后清除对应提示。
- 周结束、阶段检验完成及采纳调整保存历史快照；删除快照保留实际代码、提交与学习记录。使用原账号 SQLite 和同步机制，无需在线 AI；断网可显示已保存规划。
- 对计划所需的缺失题面优先使用原有后台补全渠道，继续保留原题身份、真实来源和校验；未准备好的资料不伪装成完成。
- 去掉先修知识、下一篇、题解关联讲义等阅读链接的细边框，保留文字、箭头、点击与键盘焦点。

本次不新增批量题解，不恢复剩余全库翻译，不启用真实 AI 思维对决或三账号组队。阶段说明属于训练规划；获奖目标仍需真实比赛结果确认，证据不足时不生成获奖日期或保证。

验证与安装状态以本机交付回执为准；源码、隔离检查、本机安装和公开发布分别记录。
