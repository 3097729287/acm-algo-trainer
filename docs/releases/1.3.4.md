# TB 1.3.4

源码准备完成，安装包尚未正式发布。当前正式下载为 [1.3.3](https://github.com/3097729287/acm-algo-trainer/releases/tag/v1.3.3)。

- 官方 AC 次日使用独立草稿复习，之后按相对难度、独立通过与失败表现动态调整间隔；简单题可免长期重写，积压时减少新题，不固定周日或月末。原代码与所有历史保留。[调度规则](../adaptive-reviews.md)。
- 底栏比赛日历以弹窗显示四个平台的基础赛程，按北京时间排列。匿名读取官方公开赛程，后台更新、失败保留缓存，启动时不等待赛程网络。
- 雷达统一知识点索引并缓存一级、二级汇总，避免切换时重复扫描全库；成长卡不再被长雷达撑高。按唯一原题展示题目与比赛题号，保留别名编号、草稿和提交。
- 下一题等待保存后直接切换题面，保存失败留在当前编辑器；题解按钮再次点击收起，首次加载保持阅读面板尺寸。成功翻译提示条移除，错误和重试保留。
- 筛选以文件夹浏览赛事与知识点，父目录可以直接选择。最新比赛在上的顺序标为正序。训练配置和排行榜周期栏居中，活动表左右对齐、大字号与斑马纹；顶栏、头像、通知、确认浮层同步校准。
- 列表底部只保留“共 X 题”和必要页码，移除保存字样及圆点。头像弹窗居中，通知使用彩色实心爱心及图标标题。TB 标识的侧栏操作并入新手指引，页面不再显示该悬停文字。
- 结束比赛使用按钮旁确认浮层，并提供取消比赛；取消不生成完赛记录或补题，保留已写代码与真实原站提交。模拟赛记录删除确认内容居中。
- 从新题解中整理 24 篇基础讲解及配图与精确关联，现有内容完整保留。公共文本源与 SQLite 同步为 5819 题、2422 份题面、1302 组默认与详细题解、400 篇讲义。
- 算法实验室包含背包 DP 入门互动课：装包实验、状态推导、逐步执行与回退、模板构造、找错和迁移自测，复用既有课程状态与真实练习入口。

用户版和管理员版继续独立安装、独立数据，管理员账号为 `admin`，公共管理仍由服务端验证角色。学习快照和共享成长协议仍为 1，无服务器迁移。

隔离验证包括完整后端检查、前端构建及交互回归、6000 题雷达性能、首次题解宽度、下一题保存屏障、日历时区和缓存、复习草稿与重启，以及全新安装、升级、增量器和用户/管理员隔离。验证期间不提交真实原站代码；实际安装验证结果在发布后补充。
