# 概率与期望：按事件或按贡献计算

概率描述某事件发生的机会；等可能的有限样本空间里，概率为合法结果数除总结果数。先写清哪些结果等可能，不能把不同生成路径自然当作等可能。

随机变量给每个结果一个数值，期望是按概率加权的平均。公平骰子的点数期望为 $(1+2+3+4+5+6)/6=3.5$，不要求期望本身是可出现的整数结果。

## 指示变量把总量拆成贡献

若总分为每次成功加一，令 $I_i$ 在第 $i$ 次成功时为一，否则零，则总分 $X=\sum I_i$。每项期望就是成功概率，故 $E[X]=\sum P(I_i=1)$。期望的线性性不要求各项独立；但计算联合成功概率时，直接相乘需要独立或正确使用条件概率。

例如三项成功概率分别为二分之一、三分之一、四分之一，总成功数期望为十二分之十三，即使三件事有关联，这个和仍成立。若问“至少成功一次”的概率，则不能只把三项概率相加，事件可能重叠。

## 期望递推要包含当前消耗

若每轮以概率 $p$ 完成，否则回到原状态，每轮都消耗一步，则 $E=1+(1-p)E$，得到 $E=1/p$。这里的一来自本轮无论成败都执行的一步；$p=0$ 时永远不能完成，不能除零得有限值。

一般期望 DP 应说明状态、转移概率和每步即时费用。含自环时要把同状态项移到等式一边，不能按普通无环 DP 直接读取尚未确定的自己。模意义的概率还要求分母可逆；输出浮点期望则要按误差要求选择类型，不可把普通实数平均与模逆计算混用。
