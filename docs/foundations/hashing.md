# 哈希：用摘要快速筛选相同对象

哈希把较大的对象映射成较小的摘要，适合快速定位和比较。哈希相同不保证原对象相同，这种不同对象映射到同一摘要叫碰撞；相同对象必须得到相同摘要。

字符串滚动哈希可用 $H_{i+1}=H_i B+\operatorname{code}(s_i)$ 并对模数取余。保存 $B$ 的幂后，半开子串 $[l,r)$ 的哈希为

$$H_r-H_lB^{r-l}\pmod M.$$

前 $l$ 个字符的权值多乘了 $B^{r-l}$，相减恰好消除；长度也必须参与比较，不能把不同长度自动当同串。预处理 $O(n)$，每次取子串摘要 $O(1)$，空间 $O(n)$。

使用两个独立摘要能降低偶然碰撞概率，但不把随机正确性变成确定性保证。需要严格相等时，可在哈希命中后比较原对象，或使用能确定比较的字符串结构。选取模数、基数和字符编码时要保证乘法范围、负余数归一及空子串含义。

`unordered_map` 的哈希用来分桶，随后还会比较键的相等性，通常不会仅因碰撞就把不同键当成同一个键；碰撞主要会恶化性能。只存一个字符串指纹并把相同指纹直接当相等，则承担了额外的正确性风险。二者不要混为一谈。
