# 字典序排列与 next_permutation

比较两个等长序列时，从左往右找第一处不同，该处数字较小的序列在前。这就是字典序。例如 [1,3,2] 排在 [2,1,3] 前面，不能用各项之和比较。对于不同长度的序列，若一个是另一个的前缀，较短者在前。

## 下一个排列怎样得到

从右向左找到第一个满足 $a[i]<a[i+1]$ 的位置。它右边已经非递增，是这些数字的最大排列；若保持前面所有位置不变，右侧已经无法再增大。因此必须增大位置 $i$。选右侧严格大于 $a[i]$ 的最小数字与它交换，再把右侧变成升序，就同时保证了“比原来大”和“增加得最少”。

例如 [1,3,2] 中位置零的 1 是要增大的项，右侧最小的更大数字为 2。交换后得到 [2,3,1]，把后缀反转为升序，结果是 [2,1,3]。找不到这样的 $i$，说明整个序列已经非递增，当前就是最后一种排列。

## C++ 标准库的接口

`<algorithm>` 提供 `next_permutation(first,last)`，处理左闭右开范围，直接改变原容器。找到下一个排列时返回 true；当前已是最后一种时，把范围恢复成升序并返回 false。因此枚举全部排列前必须先排序，且用 do-while 先处理当前排列。

```cpp
vector<int> a{1, 2, 3};
int count = 0;
do {
    ++count;  // 此处可以访问当前排列
} while (next_permutation(a.begin(), a.end()));
// count == 6，a 已恢复为 {1,2,3}
```

一次操作最坏 $O(n)$ 时间，$O(1)$ 额外空间；输出不同元素的全部排列要 $O(n \cdot n!)$ 时间。若输入有重复值，从排序后的序列出发仍会生成每种不同值序列一次，不会按重复元素的身份产生重复行。`reverse` 只反转范围，$O(n)$ 时间；它用于上述非递增后缀时才能把后缀变成升序，不能反转任意无序范围来代替排序。
