# nth_element：只把第 k 个位置及两侧分好

若只需最小的 k 项之和，把全部元素完整排序往往做了多余工作。`nth_element` 只确定某个排序位置的值，并把它之前、之后的两组分开，两组内部不保证有序。

接口 `nth_element(first,nth,last)` 操作左闭右开范围 [first,last)，默认从小到大。nth 指向希望放置其最终排序位置的那个迭代器；算法结束后，nth 的值等于完整排序后该位置的值，前面元素不大于它，后面元素不小于它。返回值为 void，原容器被重新排列。

```cpp
vector<int> values = {8, 2, 5, 1, 9, 3};
int k = 3;
// 位置 k 是第四个位置；它前面恰有 k 项。
nth_element(values.begin(), values.begin()+k, values.end());
int smallest_sum = 0;
for (int i = 0; i < k; ++i) smallest_sum += values[i];
```

上例最小三项为一、二、三，总和六；前三项可能是三、一、二，不应要求它们已经排序。若要最大的 k 项，可用第四个参数 `greater<int>()`，让比较方向改为从大到小，之后仍只读取前 k 项。重复值各自算一个元素，等于分界值的项可以分布在两边，不影响取 k 项。

k 是项数时，使用位置 begin()+k 来分出前 k 项；若单独问从一计数的“第 k 小”，应使用 begin()+k−1 并读取它，二者不要混淆。k=0 时无需选择；k 等于长度时直接使用全体元素，避免把 end 当作可解引用的位置。所有迭代器必须来自同一有效范围。

标准库要求平均线性比较次数，因此平均时间 O(n)，额外空间取决于实现；不能把它写成所有实现、所有输入均保证线性，也不能把左右两组当成可二分的有序数组。它适合只用分界值、前 k 项总和等场景；若还需要有序输出，仍须另外排序所需部分。

有序查找的 `lower_bound` 与这里目标不同：前者在已有序范围内找边界，不会重排；后者对未排序范围做选择并重排。代码使用 `<algorithm>`；`greater<T>` 是标准比较对象，`greater<int>()(a,b)` 的含义为 a>b，不捕获外部变量。
