# 十进制高精度加法：从个位逐位进位

当结果可能有几百位时，机器整数装不下，可以用十进制字符串表示非负整数，例如 `"998"`。字符串保存的是字符，不会自动参与数值计算；`a+b` 拼接两个字符串，并不等于整数相加。

竖式加法从个位开始。998+27：个位 8+7=15，写五进一；十位 9+2+1=12，写二进一；百位 9+0+1=10，写零进一；最后进位一仍要写出，得到 1025。位数较短的一方缺失数字视为零。

字符 `'7'` 减 `'0'` 才得到整数七，整数七加 `'0'` 再转 char 得到字符 `'7'`。每轮的和最大为十九，因此进位只可能为零或一。

```cpp
string decimal_add(const string &a, const string &b) {
    int i = (int)a.size() - 1, j = (int)b.size() - 1, carry = 0;
    string result;
    while (i >= 0 || j >= 0 || carry != 0) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        result.push_back(char('0' + sum % 10));
        carry = sum / 10;
    }
    reverse(result.begin(), result.end());
    return result;
}
```

参数约定为非空、无多余前导零的非负整数字符串，返回同样格式的和；零用 `"0"` 表示。因为先算低位，逐次追加得到的顺序也是低位到高位，最后必须 `reverse` 反转。循环条件包含 carry，才不会丢掉最高位新产生的一。

该函数不处理负号、小数点和减法。长度至多 L 时，时间和结果空间均为 O(L)。`const string &` 只读引用避免复制输入，返回的 result 是独立字符串，不引用即将消失的局部缓冲区。若逐项递推，只保存前两项即可节省不再使用的大整数。
