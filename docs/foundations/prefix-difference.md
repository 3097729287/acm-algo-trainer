# 前缀和与差分：累计量与变化量

只需知道数组、加减与循环。给数组 `[3,1,4]`，反复询问某个连续区间的和。每次从头加到尾，会重复计算相同部分。

从 1 开始编号，定义 `P[i]` 为前 i 个数之和，`P[0]=0` 是空前缀。这个例子得到 `[0,3,4,8]`。第 2～3 项之和为 `P[3]−P[1]=8−3=5`：前 3 项减去前 1 项，恰好留下目标。一般闭区间 `[l,r]` 的和为 `P[r]−P[l−1]`。建表 O(n)，每次查询 O(1)；负数不影响加减相消。数组修改后，旧前缀需要维护或重建。

差分换一个问题：每格比前一格变了多少？约定 `a[0]=0`，令 `d[i]=a[i]−a[i−1]`，例子是 `[3,−2,3]`。从左累计得到 `[3,1,4]`。内部的相邻项一正一负抵消，所以对差分求前缀能还原原数组；对前缀相邻相减，也能还原原数组。必须保留起点，只有内部相邻差时，无法区分整体平移的数组。

若所有修改都是区间统一加、最后才需要结果，可以令增量事件 `delta` 初始全 0。`[l,r]` 加 k 只记 `delta[l]+=k`、`delta[r+1]−=k`。累计事件时，l 前是 0，l～r 为 k，r 之后又变回 0；最后将累计增量加回原值。n+1 哨兵存储末尾区间的停止事件。每次记事件 O(1)，最后还原 O(n)，总 O(n+m)。

```cpp
vector<long long> delta(n + 2, 0);
// 对每次闭区间 [l,r] 加 k：
delta[l] += k;
delta[r + 1] -= k;
// 全部操作结束后：
long long add = 0;
for (int i = 1; i <= n; ++i) {
    add += delta[i];
    a[i] += add;
}
```

也可以先对原数组建差分，在它上面修改，最后累计直接得到最终值。此时不再加回原值；不能混用两种表示。前缀可独立回答静态区间和，差分可独立描述相邻变化；批量区间加才将边界记录与累计还原组合起来。

二维前缀 `P[x][y]` 是左上角前 x 行、前 y 列的矩形和。查询先取右下角大矩形，减上方、减左方，再加回它们被减两次的交集。二维差分则在左上、右下之外两个边界与其交点写四个正负事件，沿两个方向累计。算法实验室提供实际矩形与四角的交互图。

相消依赖可逆的加减，不能把前缀最小值直接相减来求区间最小。交替修改与立刻查询时，也不能只记简单差分就宣称每次都 O(1)。累计和、覆盖加权与计数应按范围选择 64 位整数。
