# 旧题解代码格式统一

本次是 1.6.6 的本机内容与前端修订，未发布公共更新，不更换原生程序。

扫描现有 1,939 份默认题解、1,938 份详细题解、562 组多解及 480 份讲解。实际调整 1,922 份默认题解、1,921 份详细题解、16 组多解和 63 份讲解；其余条目已经符合标准或没有对应代码。去重正文中共检查 25,186 个代码块、2,122 种代码片段。

旧的 `cxx`、`cc` 和带标准版本的 C++ 标记现在沿用同一语法配色。存量内容同时统一为 `cpp` 代码围栏和四空格缩进，整理空格、长行、分支及注释对齐；整数循环的独立递增使用 `i++`。字符串、注释内容、迭代器、条件和调用中使用递增结果的表达式保留。Python 代码使用原有离线工具统一排版，文本和样例代码块不当作程序改写。

迁移只改变教育内容的 Markdown 代码区域，保留正文、公式、图片、题目身份、多解信息和原验证记录。SQLite 更新按行进行，不替换个人数据库；种子归属摘要同步保留，供后续升级继续识别原有内容。原文件和包含已提交 WAL 的数据库备份保存在本机修订恢复目录。

验证包含全部 C++ 片段的词法标记比较、Python AST 与字符串/注释比较、全部正文 Markdown 结构比较，以及重复执行零变化。四份用户/管理员种子与运行题库的隔离迁移通过完整性和外键检查；从文本源重建题库通过。14 项题库、两版题解与多解升级测试通过。12 个界面场景检查深浅主题、宽窄栏、ISBN 默认/详细切换、离线显示、旧 `cxx` 导入和精确复制；ISBN 程序实际编译并通过正确、纠错和校验字符 X 三例。

维护工具为 `scripts/standardize_editorial_code.py` 和 `frontend/scripts/standardize-editorial-code.mjs`：先 prepare 收集文本及数据库正文，再用经过摘要校验的本机格式化工具生成结果；确认报告没有失败后 apply。格式化达到稳定结果后才写入，未通过代码或结构核对时停止。检查报告见 `docs/verification/editorial-code-format-20261108.json`。
