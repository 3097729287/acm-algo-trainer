# 下一步学习任务的依据

推荐按现有学习记录选择一个可执行的主任务，最多展示六项同阶段任务供选择，包含主任务、到期复习和满足前置的备选，不要求同时完成。经验、等级和勋章用于反馈与入口开放，不参与知识或能力达标判断。目标是逐步形成独立实现、保持和综合应用能力；没有统一人群标定或奖项预测模型。

顶栏和下拉默认只显示任务名称与既有图标；任务类别、优先顺序和完整理由通过悬停 tooltip 及无障碍描述读取。下拉中的主任务和备选都可以直接进入。基础阶段可在当前同一单元的题单与最多三道不同原题中选择；后续课程和模板备选同样检查先修、实际内容与完成记录，不为凑足六项跳过前置。

## 实际证据

模型读取 `assessment` 或 `growth.ranked` 中方法标识 `model.method` 为 `rasch-practice-evidence-v2` 的逐题证据。它们来自服务端已结束的正式原站提交，按同一原题首次学习事件去重，保留独立成功、有效失败、重试、难度权重和时间。模板操作、本地样例、普通通过总数、公开同步但独立性未知的 AC、已保存章节和经验不能替代这些证据。

前端仅使用最近 90 天的有效证据，不接受未来时间、无效时间、零权重或明确非独立的条目。同一原题的 URL 形式和别名合并；同一时刻存在不确定成功时取失败事实。服务端仅返回最近 60 道难度已知且权重有效的原题，因此窗口外历史不被解释成“从未学过”。

全局解题证据与专题证据分开。`knowledgeReviewRequired` 为真、缺少可信具体知识点或只标注数学/图论/数据结构等粗大类的题，可以保留全局作答事实，不能证明某项具体先修技术；具体知识点也可来自 `knowledgeCategories` 的叶节点。题目标签只证明练过带该标签的题，不能证明无提示识别出方法。

## 保守的工程门槛

专题巩固要求至少三道不同原题独立成功，成功分布在至少两天且时间跨度达到 24 小时，成功证据权重总和至少 0.75，尚未独立完成的比例不超过三分之一，至少一半独立成功题在通过前没有失败。先修诊断使用至少两道独立成功，其余日期、权重和未完成比例要求相同。权重是多道题的合计，不要求跨平台单题达到 0.75。

这些阈值是公开的训练策略，不是经群体研究证明的掌握或获奖分界。知识掌握指数以 CF2300 为参照，不能用固定百分比直接判定基础语法是否达标；推荐直接核对当前任务所需的原题证据。

编程基础按实际题单顺序选择未支持的节点，无需清空每个题单。来自其它来源的同主题代表性独立证据可支持节点；至少五道稳定独立成功、已有有效能力估计且至少两个基础主题有先修支持时，也可跳过重复的基础题单。已通过的题不重新作为新题推荐。

## 任务顺序

正在进行的比赛独占优先。其后保留服务端当天已经选中的到期复习，使用 `reviewTask.due`，优先继续已打开的作业；日期按 UTC+8 处理。复习不要求题目难度已知，但要求题面完整且未锁定。`workspace.reviews.reviewOnly` 为真或 `newMinutes` 不足十五分钟时，不另排新内容；缺少预算数据时不猜测空闲时间，也不把全部积压重新塞进当天队列。

新内容先补当前需要的前置，再继续真实存在的课程。保存的章节仅决定从哪里继续；到实现或跟做位置后，可做明确关联的模板操作或真实题诊断，不把翻到末页视为学会。模板的 `practicePassed[index]` 是对应操作题全案例通过记录，已通过的操作题会跳过。操作题完成后转向未通过的官方题，检验独立实现与边界应用。

没有对应互动课程的模板不创建虚假课程入口；它仍可在先修具备时作为适用条件与实现的学习材料。遇到无法支持的高级书签，会回退到其它已具备前置的学习任务。

只有至少五道近期稳定独立成功和可信的保守能力参考时，才考虑上方不超过 200 分的拔高题。每个已标注的具体技术都必须有相应支持，不能因为“数组”已练过就自动跳到同时标注网络流的题。题面不全、未知/待核难度、待核知识点、隐藏或锁定内容不会作为新的拔高目标；无可靠候选时少推荐或不推荐。

已有至少八道稳定独立成功、至少三个有支持的具体技术时，可以先进行熟悉难度的混合限时训练。候选必须是实际题库中的完整试卷：有原站题单标记、相同平台/比赛 ID/场次/来源、明确公布题数且至少三题、同原题去重后题数相符，且题号不重复或缺项；不熟悉的题号编排暂不自动推荐。全部题面和难度来源完整、所有题都未通过、每个具体技术都有支持，不包含交互或通信题。单题最高难度不超过保守参考上方 100 分，试卷最高难度不低于参考下方 200 分、平均难度不低于参考下方 400 分。任何先修或当前专题巩固任务仍优先于混合训练。推荐只进入模拟赛配置页面，并提供真实试卷名，不自动创建或启动比赛，不编造组别、用时或获奖结论。

等级开放、用户隐藏、关联入口均继续过滤。不会自动开赛，不创建生产评测提交，也不根据收藏、浏览或导航状态伪造课程完成时间。

## 可推导的验收案例

| 输入事实 | 应有结果 |
| --- | --- |
| Lv.11，但没有合格独立证据，只有辅助 AC | 不因等级推荐高级课或挑战；先给可用基础或诊断任务 |
| 同一原题有三个别名、十次提交 | 只计一份原题事件，不能凑够三题门槛 |
| 三道独立成功集中在一天；或跨午夜但只隔两分钟 | 尚不满足跨日保留条件，不能据此进入进阶 |
| 某专题三道独立成功，分布两日、跨度 25 小时，权重和为 0.9，无失败，至少两题首次通过 | 该专题满足当前稳定门槛；不意味着其他专题也稳定 |
| 用户只保存了背包课的章节，但缺数组或递推证据 | 不把书签当完成；先补前置，而非直接宣布适合拔高 |
| 数组稳定，但候选还标有尚未支持的网络流 | 不能因为共享数组标签而推荐为进阶挑战 |
| 模板配套题完整通过，但没有独立官方变式 | 实现练习已完成；下一步检验独立应用，不宣布已掌握 |
| 已打开到期复习，`reviewOnly=true` 或只剩 10 分钟新任务预算 | 优先继续该复习，不另外开新课或比赛 |
| 正在模拟赛中 | 只继续当前比赛，不暴露新算法建议干扰当前试卷 |

## 教育依据与后续验证

- [IES/WWC 官方实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)把间隔学习、例题与独立解题交替列为中等证据建议；用测验反复练习关键内容为强证据建议。用测验诊断待学内容的证据等级较低，不能借此证明本系统的数值门槛。
- [Karpicke 与 Roediger，2008](https://doi.org/10.1126/science.1152408)的词汇实验支持首次答对后继续检索有助于延迟回忆；没有验证编程竞赛表现。
- [Cepeda 等，2008，学会官方摘要](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2008.02209.x/)支持复习间隔与目标保留时长有关，不支持所有算法统一采用某个固定天数。
- [Atkinson、Renkl 与 Merrill，2003，作者机构条目](https://asu.elsevierpure.com/en/publications/transitioning-from-studying-examples-to-solving-problems-effects-/)支持逐步撤去例题步骤并加入原理解释提示；不能把复制代码等同于迁移。

这些研究支持训练设计原则，没有校准 TB 的能力分、门槛、难度映射或获奖预测。后续应核对真实的隔日独立重写、未见变式迁移、无标签混合限时作答与赛后复盘结果，记录推荐是否可执行、是否造成重复基础任务或前置死路，再修正规则。没有实际对照和验证之前，不生成获奖概率，也不以浏览量、等级或 XP 替代学习效果。
