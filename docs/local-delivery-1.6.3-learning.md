# 1.6.3 · 2026-11-07 学习界面与任务修订

未开赛的日历赛事继续列在“接下来”，当前位置显示现在可开始的学习、复习任务，到赛事实际开始时才切换为比赛。修复只有日历赛事、尚未采纳学习计划时误显示“等待比赛”的问题：主线有真实讲解时直接提供“开始学习”，否则提供安排学习入口；不自动生成、采纳计划或增加完成记录。将来的学习任务和未到间隔的复习也不提前作为当前任务。

从零讲的主页、添加、目录搜索与右侧阅读工具栏接成连续的同一行，统一高度与边界。目录和正文在该行下方分别滚动，文字不再穿过顶栏。保留目录内搜索、阅读位置、任务上下项与分区缩放；窄窗继续使用抽屉目录。

已学会的目录行显示柔和的绿色通过底色，主目录与阅读侧栏一致，深浅主题均适配。状态沿用账号实际学习标记，刷新保留，取消后恢复；不会因为打开文章而自动标为学会。

王者头像框两侧上翼按标注弧线收尖，尖端略向外、向下衔接原羽翼；保留原图颜色、纹理与下方主体，顶栏小头像和对战大头像使用同一轮廓。

本次为本机前端追加修订，原生程序、后端与数据格式不变。此前雨湖动效与交互修复继续保留；公开国服及 GitHub 正式 1.6.3 下载资产未被覆盖。
