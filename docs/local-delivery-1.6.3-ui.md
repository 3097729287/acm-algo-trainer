# 1.6.3 本机交互与比赛修订 · 2026-11-07

本次修订同时更新本机用户版与管理员版的界面和 Python 后端，保留 Open Water 雨湖质感修订。GitHub／国服的正式 1.6.3 安装包和增量包保留原发布内容，本次不覆盖正式发行资产。

- 普通左右方向键翻列表页；Alt＋左右方向键按拖动后的实际书签顺序切换并循环，搜索输入不丢失。目录上层改用 Alt＋上方向键，输入与代码内的普通方向键、日期格、树与滑块保持原有语义。
- 修复相邻 Codeforces 公式误吞英文正文，旧不完整译文不能继续充当中文；截图中 C1 提供完整离线中文，公式、代码、数字与原文不变。比赛菜单按状态配色，WA 带红色叉。主界面计时文字跟随正文色，顶栏扩大间距并保持整窗搜索居中。
- 默认初始代码按账号、语言可修改保存，保留版本冲突检查及已有草稿。设置中两个选择控件无边框；单题语言、模板和下拉项去掉多余右留白。
- 全屏单题、比赛、讲解、维基 iframe、模板、题解和实验室支持 Ctrl＋滚轮分区缩放。各内容与账号隔离保存；正文、返回工具行和书签行分别缩放。关闭、重新打开与刷新恢复。
- 从零讲展开目录后补充目录搜索；主页／添加按钮不再盖住基础学习标题。
- 火花与训练日历统一使用首次正式 AC 日期，重复 AC 不填补空白日，按北京时间断签与重新累计。
- 比赛开始和只读题面不加入训练，实际保存代码（包括改空）或提交才加入；结束时不补入未动过的题。旧条目仅在比赛归属、加入时间及无任何草稿／提交／实际记录能共同证明为自动加入时撤下，记录本身仍保留。

验证包含真实拖动与键盘、各全屏区域和 iframe 缩放、账号与刷新恢复、目录搜索对齐、默认代码原样保存、状态颜色、宽窄窗口、后端全量覆盖与受影响回归、原生冻结程序启动及隔离代码保留。具体构建与本机安装回执由当前更新记录给出。
