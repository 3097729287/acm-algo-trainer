# TB 账号

从 0.10.4 起，整个软件要求登录。启动后先注册账号，填写昵称、登录号和密码，再使用登录号和密码登录。登录号为 4–32 位字母、数字或下划线，大小写视为相同；密码为 8–128 个字符。排行榜显示昵称。设置 → 账号与身份可以修改昵称、验证原密码后修改密码和退出账号。不提供忘记密码、短信或邮箱找回。

账号存放在共享服务。密码使用带随机盐的 scrypt（N=16384、r=8、p=5）摘要；并发密码计算最多两个，等待队列最多十六个。登录按来源 IP 和登录号限流。服务器只保存随机会话令牌的 SHA-256 摘要，会话有效期三十天；修改密码撤销全部旧会话，并为当前设备签发新会话。服务不记录密码、提交代码或站点 Cookie。

本机 HTTP 接口默认要求登录，包括题库、训练、提交、设置和浏览器连接接口。登录页只使用 `/api/account` 的启动信息与注册、登录接口；所有写操作仍要求本机会话令牌和同源校验。中央登录会话不返回给前端，由 Windows 用户绑定的 DPAPI 加密后存入个人 SQLite 设置库。重启时向共享服务验证保存的会话；网络不可用或会话过期时显示登录页。

旧安装第一次注册时，客户端向服务证明持有原安装凭据，在服务器事务内将原身份关联到注册账号。原成绩、奖励和管理员角色继续归属同一个内部 ID，原安装凭据随即失效，不能仅凭 ID 使用服务。未注册的旧身份和记录保留在数据库中，暂不参与新排行榜和后续奖励结算。

本机原个人数据库保留。首次注册关联的账号继续使用原数据库；其他账号的数据分别放在 `state/accounts/<内部 ID>/tb-personal.sqlite3`。原工作区关联只保存一次，切换账号不会复制别人的训练、草稿或提交。浏览器草稿按账号分开保存，原浏览器草稿只能由原个人数据库所属账号恢复。退出前等待草稿保存；进行中的评测、原站提交或模拟赛会阻止退出与切换。回执固定写入发起提交的工作区。

旧测试可以通过代码参数 `require_account=False` 显式测试底层 API；默认值始终为 `True`，`TB_OFFLINE` 不会绕过登录。发布探针只接受显式临时状态目录；`--serve-account-check` 另外要求指定本机测试账号服务，用于验证打包程序的实际登录边界。
