# TB 账号

本文对应准备发布的 [v1.1.0](releases/1.1.0.md)。账号同步协议 1 与公开成长资料的 `006` 增量迁移已于 2026-10-16 在原排行榜服务器部署，继续使用原 MySQL；公网 HTTPS 已确认服务 1.1.0、单设备会话及公开成长协议 1。客户端安装与升级验证仍待完成，当前正式下载仍为 v1.0.18。每台电脑应升级到同一新版。

## 登录与数据恢复

整个软件要求登录。启动后先注册账号，填写昵称、登录号和密码，再使用登录号和密码登录。登录号为 4–32 位字母、数字或下划线，大小写视为相同；密码为 8–128 个字符。排行榜显示昵称和独立的公开 ID，不公开登录号。成长与能力 → 账号与身份 → 管理账号可修改昵称、验证原密码后修改密码和退出账号；公开绑定和翻译 API 位于同一区域。不提供忘记密码、短信或邮箱找回。

1.0.20 登录先验证账号、读取服务端学习数据、安全合并本机尚未同步的记录，再打开工作台。恢复失败停留在登录界面并显示原因，不先显示空账号再慢慢补回。服务端 MySQL 是账号数据的权威版本，与排行榜使用同一服务器的数据库；本机 SQLite 继续负责及时保存、离线工作副本和待同步记录。

## 同步范围与隐私

| 随账号同步 | 保留在本机 |
| --- | --- |
| 训练、自动保存草稿、完整提交源码与原站回执、样例运行记录、模拟赛 | 原站 Cookie、浏览器登录会话与 DPAPI 密文 |
| 目标、固定每日题单、首通经验、每日奖励、成就领取、排位解锁与排行榜奖励账本 | 翻译 API Key、设备路径、编译器和安装配置 |
| CF/AtCoder 公开用户名、已同步公开资料与正式通过证据 | 全屏等设备专用偏好、整套公共题库 |
| 收藏、保存筛选、主题、字号、导航和逐项成就已读状态 | 未被当前账号引用的其他本机导入内容 |

账号快照含代码和草稿，会经 HTTPS 上传至 TB 服务端。榜单计分接口只接收身份和原站 AC 摘要，1.1.0 的公开资料接口另接收等级、段位、排位分和自动佩戴称号。快照使用有校验的压缩封装，传输上限 4 MiB、解压后上限 64 MiB；超限或网络错误保留本机数据并显示待同步，不会截断源码后假报成功。压缩不等于端到端加密，服务端数据库与备份应按个人数据保护。

个人快照还包含本账号练习、草稿、提交、模拟赛或目标题单引用的题目资料：标题、原题链接、轻量元数据和已缓存题面、样例；本机导入题可携带两版题解和图片。另一电脑缺少同一题目 ID 时可继续显示题目、代码与已有内容。没有缓存的原站题面仍需联网读取，公共题库不会整库上传。

## 待同步、合并与单设备登录

写入先落本机 SQLite，再由后台聚合上传；读取题库或工作台不等待远程同步请求。界面显示同步中、待同步、失败或最后成功时间。正常退出账号和安装更新前等待保存；网络失败时保留未同步数据及提示。换电脑前应确认同步完成，不能把“本机已保存”当成“另一台已经收到”。

首次迁移在应用远端数据前执行 SQLite 在线备份。原本机数据按记录主键合并，首通、每日、成就和排行榜奖励沿各自领取键去重，不相加重复发放。后续同步使用服务端版本号和逐行基线，保留本机未上传的编辑与删除；双方修改同一草稿时，未采用的版本保存在个人库 `account_sync_conflicts`，可结合在线备份恢复。同步不会复制其他 TB 账号的工作区。

每次登录只保留一个有效服务端会话，新设备登录会撤销旧设备会话。客户端约每 3 秒独立检查一次会话，联网时收到失效响应即退出工作台；慢上传不阻塞心跳。断网设备无法实时知道另一台已登录，未上传的本机记录继续保留，重新登录后参与合并。迟到的旧设备请求会被服务端事务再次校验，不能覆盖新设备数据。

窗口隐藏时暂停常规界面数据和目标轮询，重新可见后立即刷新。后台账号心跳、数据上传、原站任务和软件自动更新继续运行，隐藏窗口不会暂停会话失效检测或自动安装流程。

账号已有云端学习数据后，不支持同步协议的旧客户端返回 426 升级提示。请在另一台电脑使用 1.1.0 安装包升级原目录，再登录同一个账号。换电脑前先确认当前设备显示同步完成；不要通过降级客户端绕过恢复流程，也不要把另一台电脑的个人 SQLite 直接覆盖到当前工作区。

## 密码、会话与工作区

账号存放在共享服务。密码使用带随机盐的 scrypt（N=16384、r=8、p=5）摘要；并发密码计算最多两个，等待队列最多十六个。登录按来源 IP 和登录号限流。服务器只保存随机会话令牌的 SHA-256 摘要，会话有效期三十天；修改密码撤销全部旧会话，并为当前设备签发新会话。服务不保存明文密码或站点 Cookie。

本机 HTTP 接口默认要求登录，包括题库、训练、提交、设置和浏览器连接接口。登录页只使用 `/api/account` 的启动信息与注册、登录接口；所有写操作仍要求本机会话令牌和同源校验。中央登录会话不返回给前端，由 Windows 用户绑定的 DPAPI 加密后存入个人 SQLite 设置库。重启时向共享服务验证保存的会话；网络不可用或会话过期时显示登录页。

0.10.5 修复系统代理干扰账号连接的问题：内置账号与排行榜服务，以及本机测试服务，使用直接连接；自定义共享服务继续使用系统代理。HTTPS 证书校验和禁止重定向的保护保留，注册、登录和修改密码请求不会自动重发。`--account-network-check <报告路径>` 可在显式指定临时 `TB_STATE_DIR` 后检查内置 HTTPS 服务及空注册输入的拒绝响应；不输入或保存密码，不创建测试账号。

0.10.6 修复慢排行榜响应超过旧 5 秒超时的问题。后台请求允许 10 秒，各周期成功读取后立即显示；另一个周期或奖励刷新失败时保留已读取的结果，显示重试提示。首次连接失败可直接点击“重试连接”。

旧安装第一次注册时，客户端向服务证明持有原安装凭据，在服务器事务内将原身份关联到注册账号。原成绩、奖励和管理员角色继续归属同一个内部 ID，原安装凭据随即失效，不能仅凭 ID 使用服务。未注册的旧身份和记录保留在数据库中，暂不参与新排行榜和后续奖励结算。

本机原个人数据库保留。首次注册关联的账号继续使用原数据库；其他账号的数据分别放在 `state/accounts/<内部 ID>/tb-personal.sqlite3`。原工作区关联只保存一次，切换账号不会复制别人的训练、草稿或提交。浏览器草稿按账号分开保存，原浏览器草稿只能由原个人数据库所属账号恢复。退出前等待草稿保存；进行中的评测、原站提交或模拟赛会阻止退出与切换。回执固定写入发起提交的工作区。

## 排行榜与设备设置

1.0.20 记录北京时间当天的有效登录与会话恢复。当天登录的注册用户进入排行榜，无通过记录显示 0；已有周期成绩的用户继续显示。零题登录不产生名次奖励，原计分、身份及奖励规则保留。独立原站防作弊认证仍未提供。

1.1.0 通过认证会话上传小型 `publicProgress` 摘要，排行榜直接读取，无需解压个人代码快照。显示等级、成长段位、已解锁排位分和最多两枚自动佩戴称号；未提供的旧版资料显示未知。摘要不包含登录号、密码、代码或翻译凭据，也不改变官方 AC 排名和结算规则。

称号由个人成就领取账本永久记录。更改奖励或删除高档目标不追扣旧经验；同一领取键跨设备合并后不会重新发放。成就已读记录取并集，另一设备迟到的偏好保存不会将已查看的成就重新变成未读。

旧测试可以通过代码参数 `require_account=False` 显式测试底层 API；默认值始终为 `True`，`TB_OFFLINE` 不会绕过登录。发布探针只接受显式临时状态目录；`--serve-account-check` 另外要求指定本机测试账号服务，用于验证打包程序的实际登录边界。

1.0.16 账号编辑默认收起。公开统计账号绑定仅支持 CF 与 AtCoder；原有牛客、洛谷绑定会解除，不删除个人训练、导入内容或原站浏览器登录。

公开账号绑定在 1.0.20 随 TB 账号同步，不再要求每台电脑分别填写。原站浏览器登录与翻译密钥仍须在每台电脑配置；DPAPI 密文不能跨 Windows 用户搬运。[共享服务部署](../server/leaderboard/README.md)。
