# TB 账号与个人数据

本说明对应同目录 `VERSION` 所标识的客户端。正式下载、历史变化与发行验证见 [GitHub 发布记录](https://github.com/3097729287/acm-algo-trainer/releases)；开发源码是否已发布以仓库首页为准。

## 登录、注册与恢复

首次注册、密码登录及新设备恢复须联网。注册填写昵称、登录号和密码；登录号为 4–32 位字母、数字或下划线，大小写视为相同，密码为 8–128 个字符。昵称归一化后不得重复。排行榜显示昵称和独立公开 ID，不公开登录号。不提供短信、邮箱或忘记密码找回。

登录先验证账号、读取服务端学习数据并安全合并本机未同步记录，再进入工作区。新老账号首次使用当前指引时自动显示入门内容；指引完成版本按账号保存，手动重看在“设置 → 新手指引”。等级决定可用页面，已看指引或升级弹窗的状态不决定权限。

后台恢复与账号切换均有等待上限，旧请求迟到不会激活旧账号。网络不确定时不会自动重放注册或密码登录；已确认凭据的首次同步可继续恢复，进入工作区前仍须完成安全合并。普通同步故障自动重试，需要处理的冲突、重新登录或升级信息进入消息中心。

维护者私有管理员程序可按完整登录号或公开 ID 查找账号，确认后删除普通账号或将密码重置为 `123456`；不能查看原密码或摘要，也不能修改自己或其它管理员账号。重置撤销目标全部会话并保留其学习数据；目标使用临时密码登录后可修改密码，新密码仍须满足 8–128 个字符。普通用户程序没有这些管理入口，管理员程序不公开分发。

登录页可以检查和安装程序更新，无需先完成账号登录。已经迁移到分块协议 2 的账号，其他设备也应升级到支持该协议的版本；收到升级提示时安装到原目录。不要用另一台电脑的个人 SQLite 覆盖当前工作区。[安装与更新](usage.md)。

## 已验证账号的离线学习

本机已经成功登录并同步、保存的 Windows DPAPI 凭据未过期，且工作区所属账号和服务地址匹配时，临时断网或账号服务连接故障可恢复原离线工作区。缓存题面与题解、草稿、本地样例继续可用；未缓存内容和原站正式提交仍需联网。

从未验证的账号、过期或已知撤销的会话、升级拒绝及损坏的云端响应不会获得离线访问资格。断网时无法获知其他设备刚登录或服务端撤销；重新联网会再次验证，明确失效时关闭账号访问，本机资料仍保留。

离线修改先落本机 SQLite。重新联网先校验会话、读取最新云端根并按原基线合并，然后使用版本比较上传。界面中的本机保存、待同步和同步成功分别表示不同状态；换电脑前确认同步完成。正常退出先保存本机草稿，不为网络上传无限等待，下次进入继续同步。

## 同步范围与隐私

| 随账号同步 | 保留在本机 |
| --- | --- |
| 训练、自动保存草稿、提交源码与原站回执、样例运行记录、模拟赛 | 原站 Cookie、浏览器登录会话及 DPAPI 密文 |
| 目标、每日题单、已领取经验、成就与奖励账本 | 翻译 API Key、设备路径、编译器与安装配置 |
| 公开平台绑定、已同步公开资料与正式作答证据 | 全屏等设备专用偏好、整套公共题库 |
| 收藏、主题、字号、导航、课程进度、成就与升级提示已读状态 | 未被当前账号引用的其他本机导入内容 |

账号资料和代码经 HTTPS 上传至 TB 服务，压缩不等于端到端加密。公开榜单只接收身份、原站 AC 及公开成长摘要，不包含登录号、密码、代码或翻译凭据。原站 Cookie 不随学习记录上传。[原站浏览器与提交](browser-preparation.md)。

学习数据使用有界压缩对象分块：先上传缺失依赖，最后以版本比较切换完整根。失败保留本机记录并重试，不发布半份资料。历史代码可按月归档，新设备查看某条提交时才下载对应源码；原设备已有代码继续保留。旧协议快照仍受 4 MiB 信封与 64 MiB 展开限制，迁移后不回退到旧协议覆盖资料。

个人同步还携带本账号记录引用的题目标题、原题链接、轻量元数据和已缓存题面、样例；导入题可包含两版题解及图片。另一设备缺少相同题目 ID 时仍能显示已有内容，公共题库不整库上传。

## 合并、切换账号与会话

学习记录按主键合并，首通、每日及成就奖励按领取键去重，不重复发放。后续同步使用服务端版本与逐行基线，保留本机编辑和删除；同一草稿发生冲突时，未采用内容留在私有 `account_sync_conflicts` 以便恢复。升级提示已读等级取较大值，迟到的旧偏好不会重置已看内容。

每次登录只保留一个有效服务端会话，新设备登录撤销旧设备会话。联网时客户端独立检查失效，慢上传不会阻塞心跳；迟到请求也受服务器事务校验。窗口隐藏会暂停普通界面轮询，账号心跳、待同步上传和进行中的原站任务继续运行。

首次关联的账号继续使用原个人库，其他账号分别保存在 `state/accounts/<内部 ID>/tb-personal.sqlite3`。浏览器草稿按账号隔离；回执固定写入发起操作的工作区。切换账号不会复制另一账号数据。进行中的评测、原站提交或模拟赛先完成，退出前确认草稿保存。

右上角昵称打开账号管理，可修改昵称、验证原密码后改密码、绑定公开平台账号或退出。改密码撤销旧会话，为当前设备签发新会话。CF/AtCoder 公开用户名、牛客/洛谷数字用户 ID 用于匹配本人公开记录；检测到原站本人登录只填入空绑定，不覆盖已有不同账号。没有评分来源的平台不制造评分。

## 本机恢复点与容量

例行完整备份间隔为一小时；迁移和云端替换前仍立即在线备份，包含已提交 WAL。每份自动恢复点先核对 SQLite 完整性、关键表记录数、SHA-256 和重新打开结果。自动保留最近三份、近七天每天一份、近四周每周一份，每个数据库最多十四份；同一数据库目标预算 256 MiB，备份根目标预算 1 GiB。

至少两份可验证恢复点优先于容量目标，两份本身超预算时不删除最后恢复能力。自动清理只识别本版带清单的恢复点；手动、旧版、未知文件和符号链接不自动淘汰。历史积累需单独核对，`recovery_backups.preview()` 可先预览计划。个人数据库、代码、草稿不属于可淘汰备份。

## 安全边界与本机工具

密码使用随机盐 scrypt 摘要；登录及密码计算有速率与并发限制。服务端只保存随机会话令牌摘要，会话有效期三十天。本机会话通过 Windows 用户绑定的 DPAPI 加密，不向前端返回中央会话令牌。内置 HTTPS 服务直接连接并验证证书、禁止重定向；修改密码等写入不自动重发。

本机 HTTP 接口默认要求已验证账号，所有写请求须有本机会话令牌并通过同源检查。`TB_OFFLINE=1` 本身不会绕过账号保护。发布探针只接受显式临时状态目录；`--account-network-check` 只验证服务健康及空输入拒绝，不创建测试账号或提交代码。

维护者管理员工具仅在本机独立目录使用，不公开分发，不复用用户身份或训练资料。用户版拒绝管理员接口，公共权限由服务器验证。共享服务协议与部署另见[服务说明](../server/leaderboard/README.md)。
