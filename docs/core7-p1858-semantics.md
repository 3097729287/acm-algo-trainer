# P1858《多人背包》的可行性边界

2026-10-31核对[洛谷原题](https://www.luogu.com.cn/problem/P1858)缓存全文。每包必须恰好装满，K个人的物品清单必须两两不同；不同清单即使价值相同，也属于不同方案。题面给出K、V、N的上限，但没有写保证存在至少K种装满方案，也没有规定方案不足时输出什么。

例如：

```text
2 1 1
1 1
```

只有一个物品，容量一的清单只有“取这个物品”一种，无法分给两个人且保持清单不同。输出一表示只安排了一个包；输出二则重复用了同一个清单，都不满足原文。题面也没有给出负一或其它无解标记，不能自行添加。

另一个输入用于区分“方案不同”与“价值不同”：

```text
2 1 2
1 5
1 5
```

两个物品编号不同，取第一件与取第二件是不同清单，都有价值五，因此两包合计十。前K优列表必须保留相同价值的多次出现，不能去重。

`scripts/core7_review_p1858.py`直接枚举物品子集，核对上述两个事实。已向用户询问是否补充“测试数据保证至少有K种合法装满方案”；在补充规则确定前，本题暂不计入完成数，其余背包题继续编写。原题文本不改动，没有猜测无解输出，也没有向原站提交。
