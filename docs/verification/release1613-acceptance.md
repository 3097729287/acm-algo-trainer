## 发布验收条件

1. 原版 1.6.7 的更新服务与桌面 prepare/install 闭包保持原字节/源码绑定，只有候选源指向本版国内 feed。
2. 原生桥和七个 1.6.6—1.6.12 增量各有固定 SHA；35 种公共安装布局使用实际产品 applier 后核对全部受管程序文件、物理公共库组合和未知文件/行保留。公共 fixture 不能冒充真实个人记录。
3. 每个 CDN 资源用正常证书与主机名校验完整 GET，再核对长度与 SHA；Git blob/tree/commit 精确回读，旧 CDN 引用不改。
4. 从第一次旧版更新检查起，同时记录 API 可用、真实原生窗口及实际 React 工作区可操作三个终点，以最大值判断是否不超过 60 秒。保留真实下载字节及原生桥可见进度。
5. 隔离真实状态副本中的 15 个数据库、22 张个人表、其它严格表、每个根文档与不解释的会话有效载荷都须保持，当前程序目录与普通浏览器不参与测试。
6. 新的完整安装包独立检查全部分发文件与新装/升级/卸载中的个人数据保留；实际产物由 BUILD-INFO、完整 source map、native input map 和 RELEASE-MANIFEST 分别绑定。

本次完整升级验证目录在 C 盘，普通安装和先前 72.477 秒失败样本在 E 盘，分别属于不同磁盘。C 盘隔离结果不能声称 E 盘或所有网络/硬件都具有相同耗时。真实状态来源是先前从各数据库在线备份的从未启动样本，不是跨数据库原子快照。

## 真实裁判
