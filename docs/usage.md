# 使用 TB

## 练习

在题库或知识目录选择题目，加入“训练与待办”。题面与 C++ 编辑器并排显示，支持切换布局，草稿自动保存。“运行样例”编译并对比公开样例；选择自定义输入后可运行自己的测试数据。样例通过不计入官方 AC。内存超限、启动失败等运行错误只在运行结果中显示，不弹出 Windows 错误对话框。

“提交”（Ctrl+Enter）使用你日常浏览器已登录的 Codeforces、AtCoder、牛客或洛谷账号，由 TB 的隐藏后台组件完成提交，评测结果直接显示在应用内。登录同步后可以关闭浏览器；需要刷新登录时自动无窗口唤醒连接组件，不打开浏览器窗口或原站标签页，也不需要在 TB 内登录。

首次使用时，点击“连接浏览器”查看设置步骤：在 Edge 的 `edge://extensions`（Chrome 为 `chrome://extensions`）开启开发人员模式，加载连接页所显示的 `browser-extension` 文件夹。此次升级后对“TB 浏览器连接”点击一次“重新加载”，允许四个平台的登录同步。扩展只同步这四个平台的会话 Cookie，不读取密码；登录数据通过回环接口交给 TB，用当前 Windows 用户的 DPAPI 加密保存在本机，不发送到 TB 云端。正常使用无须手动打开浏览器。

登录失效或需要验证码时，点击“在浏览器查看”，在原站处理后回 TB 提交。登录本身不会发送代码。界面先显示“等待原站受理”，拿到本次提交编号后显示“评测中”，确认结果后保存记录并更新进度。准备接口超过 40 秒会明确报错；发送后 45 秒仍未确认时继续查询，迟到回执仍会更新到 TB，不自动重复发送代码，等待最长 15 分钟。结束后释放隐藏组件。模拟赛期间使用受比赛规则保护的“赛内提交”。

点击题解查看内置内容，基础讲解可以按章节展开；从零讲页面可搜索概念。新抓取的公开题若尚未导入题解，会显示尚未收录。内置题解不需要配置 AI API。

模拟赛可选综合、专项或随机单题，比赛期间隐藏考点并限制题解查看；结束后在模拟赛页面复盘。提交记录保存每次提交的代码及结果。

## 翻译

设置 → 翻译 API，选择 DeepSeek 或自定义服务。官方 DeepSeek 使用 `deepseek-chat`；自定义服务填写服务商提供的 Base URL 和模型，支持根地址、`/v1` 或完整 `/chat/completions` 地址。按服务要求填写 API Key；本机无需认证的服务可留空。

保存后点击“测试连接”，成功会显示验证状态。密钥无效、余额不足、模型不存在或服务输出截断会分别给出原因。测试会使用该接口的正常用量。翻译中保留代码、公式和样例；失败时仍可直接看原文。换 Windows 用户或电脑后，原有 DPAPI 密钥需要重新配置。

## 排行榜

软件默认连接已部署的 TB 排行榜。设置 → 账号与身份可以改昵称、查看唯一 ID、修改或断开服务地址。初次连接完成后，界面自动刷新。已保存的原站确认 AC 会自动上传；同一道原题只计第一次，运行和样例通过不计入。历史官方回执会补传，公开账号汇总中没有完整回执的条目不自动补成今日成绩。

日榜和周榜使用北京时间。断网时训练记录继续保存在本机，稍后同步。服务接收昵称、身份与通过摘要，不接收代码或翻译密钥。

## 外观与数据

设置可调整主题、字号、导航顺序、名称、页面组合。知识清单的分组、缩进与连接线表示层级，数字分别反映可用题目和个人覆盖。

设置 → 更新 → 软件版本更新可以检查新版本。默认启动时检查，运行期间每天检查一次；发现新版本会提示。点击“下载更新”，完成后点击“保存并安装更新”，程序保存草稿、备份个人数据库并重启完成安装。正在官方评测或模拟赛中时先完成当前任务。也可从 GitHub 下载完整安装程序，退出 TB 后手动安装到原目录。个人记录保存在程序目录 `state/`；不要将使用后的整个目录当作公共安装包分享。手动备份时先退出程序，再复制完整 `state/`；程序提供的数据库备份使用 SQLite 在线备份。

## 图文题解与从零讲

题库包含已归档比赛的签到题。题解、从零讲和折叠讲义中的图片可点击放大，按 Esc 或“关闭”返回；内置配图离线可读。

导入图文 Markdown 时，请将配图文件夹一起放入收件箱，保留文中的相对路径。支持 SVG、PNG、JPG/JPEG、GIF、WebP、AVIF 和 BMP；单图不超过 8 MB，每篇配图合计不超过 32 MB。导入完成后可离开原文件夹阅读。网络图片仍需联网加载。
