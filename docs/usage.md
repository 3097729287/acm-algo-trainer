# 使用 TB

## 练习

在题库或知识清单选择题目，加入“我的训练”。题面与 C++ 编辑器并排显示，支持切换布局。草稿自动保存。底部的运行、本地提交和官方提交分别检查样例、使用已有评测数据、打开原站提交面板。题目只有样例时会明确标注，样例通过不增加审核通过排行榜。

点击题解查看内置内容，基础讲解可以按章节展开；从零讲页面可搜索概念。入门题默认提供思路提要与完整代码，详细题解可展开。新抓取的公开题若尚未导入题解，会显示尚未收录。内置题解不需要配置 AI API。

“训练与待办”包含我的训练和今日待办。一键清空须确认，只移出当前训练与待办，保留草稿、代码和提交记录；进行中的比赛和未完成评测会阻止清空。

模拟赛可选综合、专项、随机单题或重现赛。重现赛在创建训练界面选择已收录比赛，保留全部已收录题序，包括已通过题和未定级题；已知题单不完整或缺题面、样例会提示补齐。原站完整题数未知时明确标注。XCPC 默认 300 分钟、20 分钟错误罚时、编译错误不罚时，可按具体赛事调整。比赛期间隐藏考点并限制题解查看；结束后在模拟赛页面复盘。提交记录保存每次提交的代码及结果。

默认收录全部难度，包括签到题；CCPC/ICPC 收录不受难度筛选限制。比赛 → 蓝桥杯 B 组历年，按年份和初赛 / 决赛查看 C/C++大学B组公开原题。当前收录 162 道，覆盖 2013—2026 年；早年部分原卷未完整公开，填空题可能在 OJ 中合并，题单不代表完整原卷题数与题序。

成长与能力包含活动记录和目标计划。填写具体目标、截止日期、当前能力和每日时间后，生成每周题量与独立的目标每日任务；目标创建后的首次可靠通过计入进度，样例通过不计。时间不足、落后和期限偏紧会提醒。题量由明确的工作量假设计算，评级或奖项须按原站 / 赛事结果核验。目标每日任务不额外发放经验。

牛客支持页面实际提供的 C++（clang++18）选项。CF 官方回执核对账号、题号和提交前记录，仅保存本次新提交结果；返回 TB 后可在训练与提交记录中查看“官方 AC”。本地完整评测和样例结果仍分别标记。

## 翻译

设置 → 翻译 API，选择 DeepSeek、火山方舟或自定义服务。官方 DeepSeek 默认使用 `deepseek-flash`，旧官方模型别名自动迁移；自定义模型名称按供应商要求保留。当前 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)支持 `deepseek-flash` 与 `deepseek-v4-pro`，TB 对翻译关闭思考模式。

自定义服务填写服务商提供的 Base URL 和模型，支持根地址、`/v1` 或完整 `/chat/completions` 地址。按服务要求填写对应 API Key；本机无需认证的服务可留空。Chat Completions 兼容服务可接入，例如[阿里云百炼](https://help.aliyun.com/zh/model-studio/what-is-model-studio)；地域、业务空间和模型以控制台为准。[火山方舟 Agent Plan](https://docs.volcengine.com/docs/ark/agent-plan-enterprise-opencode?lang=zh)预设使用 `/api/plan/v3`，须配对应套餐的密钥与模型。

本次已用现有自定义接口实际翻译完整 ABC 478 D 题面。官方 DeepSeek、火山方舟和百炼的当前个人账号权限、余额尚未在线实测；协议兼容不等于该账号已可用。可在各自配置下“测试连接”，再翻译完整题面。不要把一个供应商的密钥填到另一个供应商的地址。

保存后点击“测试连接”，成功会显示验证状态。密钥无效、余额不足、模型不存在或服务输出截断会分别给出原因。测试会使用该接口的正常用量。翻译中保留代码、公式和样例；失败时仍可直接看原文。换 Windows 用户或电脑后，原有 DPAPI 密钥需要重新配置。

## 排行榜

软件默认连接已部署的 TB 排行榜。设置 → 账号与身份可以改昵称、查看唯一 ID、修改或断开服务地址。初次连接完成后，界面自动刷新。没有首次本地审核通过的记录时，已连接的榜单可以为空；运行和仅样例通过均不计入。

日榜和周榜使用北京时间。断网时训练记录继续保存在本机，稍后同步。服务接收昵称、身份与通过摘要，不接收代码或翻译密钥。

## 外观与数据

设置可调整主题、字号、导航顺序、名称、页面组合和书签。侧栏顶部知识工具区已移除，下面的知识树保留；全部上方菜单完整显示，书签可展开。窗口关闭时记住位置、正常大小和最大化状态；显示器变化后调整到可见工作区。

升级前退出 TB，再运行安装程序。个人记录保存在程序目录 `state/`；不要将使用后的整个目录当作公共安装包分享。手动备份时先退出程序，再复制完整 `state/`；程序提供的数据库备份使用 SQLite 在线备份。
