# 使用 TB

## 1.3.2 界面更新

本节对应 1.3.2，包含工作台、训练、设置与成长界面的更新。

左上大写 TB 收起或展开侧栏，设置入口固定在左下角；同步中、失败和完成图标使用同一位置。页面面包屑已移除，设置二级页右上箭头或 Esc 返回设置首页，首页 Esc 返回原工作区。必要说明通过问号旁的提示图标查看；翻译配置与其他设置一致使用整块面板。

搜索右侧的上下箭头切换排序方向。比赛标题区域的文件夹按钮打开赛事层级，重现赛也按平台、系列、年份、场次逐层选择。专项知识点可进入子菜单，也可在目录内选择整个大类。选定知识点会在顶栏显示筛选标签，点击 X 只清除该知识点条件。

每日目标题目在“我的训练”的“今日目标”区，包括已通过的目标题；每日任务弹窗只保留经验任务。成长页目标按钮位于账号统计下方。掌握度根据作答证据估计，少于 5 道不同有效题或少于 3 道有难度题显示 `?%`；悬停数值可查看原因。雷达不把缺证据画成 0。

模拟赛记录在配置下方，新记录在上。默认时间如下，筛选中仍可手动修改：

| 难度 | 单题 | 专项 4 题 | 综合 4 题 |
| --- | ---: | ---: | ---: |
| 简单 | 30 分钟 | 90 分钟 | 120 分钟 |
| 普通 | 45 分钟 | 120 分钟 | 150 分钟 |
| 困难 | 60 分钟 | 150 分钟 | 180 分钟 |
| 极难 | 75 分钟 | 180 分钟 | 210 分钟 |

多题按题数比例以 15 分钟取整，默认范围 30–480 分钟；重现赛保留原赛时长。所有计时训练的“提交”均打开浏览器原站流程，运行样例仍在本地。倒计时和“结束比赛”位于右上角。编辑器自动保存，也可 Ctrl+S；不再显示导入和手动保存按钮。头像经验环从底部开始，顺时针增长。

## 1.3.1 工作台（历史基线）

搜索框位于顶栏，右边只有筛选按钮；收藏、排序、提交结果和分类都在筛选中。比赛默认显示列表，筛选内可开启文件夹浏览。右上 `AC:82` 表示今日之前累计 82 道，今天通过两道显示 `AC:82+2`；爱心仍为北京时间当天收到的数量。

成长页左侧是可下钻的知识雷达与掌握详情，右侧是账号、经验和段位统计。段位用装饰头像框表示，经验仍显示在头像环提示中；等级和能力段位独立成长。题单标为“待开发”，保留五阶段学习框架与已有双指针示例。

模拟赛选择综合、专项、随机单题或重现赛后，都点击“生成试卷”，检查预览后点击“开始训练”。专项直接选知识点，重现赛直接选比赛，搜索位于顶栏。简单 1000–1400、普通 1300–1700、困难 1600–2000、极难 1900–2200；筛选中可输入其他范围。重现赛按整场中位难度筛选，不裁掉原赛题目。未定级场次只在完整 0–10000 范围展示。

进入题目后，题面和编辑器填满客户区；左上返回箭头或 Esc 回到原列表。题解和下一题位于编辑器工具栏右侧。C++17 / Python 3 的语言与草稿一起保存；随包 CPython 3.13.16 不附带第三方包。样例通过不等于官方 AC。

设置首页使用自适应拼图；“设置 → 快捷键”显示当前绑定，点击绑定后按新组合键即可修改，冲突会保留原值。Delete/Backspace 取消该绑定，可恢复全部默认值。Esc 返回、方向键选题及编辑器 Tab 行为保持固定；二级设置的 Esc 返回首页。导航名称、分组和顺序在“交互与导航”中统一修改。

不透明度 100% 为实色、0% 为透明；每页可覆盖统一值，题面、编辑器和题解独立设置。“重置所有透明度”恢复 76% 并清除覆盖。背景播放列表支持 GIF / 动态 WebP / PNG，每张最多 12 MB、最多 20 张，5–3600 秒轮换，原始字节只保存在本机 IndexedDB。

排行榜使用可用内容宽度，爱心动态栏目始终存在，仅列出北京时间当天活动。每人每天可点一次爱心，自己的心形显示收到的数量，不提供给自己留言。消息通知只保留互动与更新通知；版本和题库检查配置在设置中。删除模拟赛或榜单成绩须在对应按钮旁确认。

窗口恢复不再切换主 WebView 可见性；渲染进程退出后限次恢复，连续异常显示恢复按钮，底层进程退出则提示重开 TB。草稿每次编辑都在本机留有恢复记录。若还有异常，请保留程序目录日志以便定位。

管理员通过开始菜单“TB 管理员工作台”或 `TB新版.exe --admin` 启动，使用独立 `admin-workspace/`，不上传用户排行。原站最终回执保存并显示后，只关闭本次提交窗口，登录、验证和结果未确认时保留。

## 账号与跨电脑同步

1.0.20 登录会先恢复服务端账号数据，再进入工作台；恢复失败会留在登录页说明原因，不先显示空账号。训练、草稿、完整提交代码与官网回执、模拟赛、目标与每日题单、XP 和奖励、CF/AtCoder 公开绑定，以及收藏、保存筛选和导航偏好随账号同步。与排行榜共用的服务端 MySQL 保存账号权威版本，本机 SQLite 保留工作副本和未上传记录。

界面出现“待同步”或错误时，本机保存仍在，换电脑前先确认同步完成。正常退出账号和更新程序会等待保存；首次合并前在线备份本机库，冲突代码版本另外留存。同一账号在另一台电脑登录会撤销当前会话，联网时约 3 秒检查后返回登录页。断网期间无法即时知道另一台已登录，本机改动保留到重新登录合并。详见[账号与冲突恢复说明](accounts.md)。

个人代码会上传到 TB 账号服务。原站 Cookie、翻译密钥与设备配置保留在当前电脑，换电脑需重新完成原站浏览器登录及密钥配置。已练习或保存代码的题目会携带轻量资料、已缓存题面和样例；从未缓存的原站题面仍需联网。

## 练习

1.0.18 的比赛、题库顶部均可直接选择牛客、洛谷、Codeforces、AtCoder、XCPC 历年和蓝桥杯 B 组历年，最后两项依次在右侧。我的训练不再显示分组与平台栏。题库的最低难度、最高难度与提交结果与搜索框同一行，不需要展开。点击“重置”可恢复全部条件，仍可保存常用筛选。

难度前的“≈”表示估算，悬停可看来源、参考区间与依据；“未定级”表示缺少足够证据。新增 Gym 题目可加入训练，题面打开时需要联网读取并缓存；原站暂不可读时可重试或在原站查看。

1.0.20 优先显示已有题面；缺少题面时在后台获取并显示状态，不阻塞草稿或其他页面。原站返回 403、要求验证或暂时不可用时仍保留代码，并提供重试与原题入口；失败后短时间内不会连续重复抓取。

已获得的首通经验保存在个人库，难度调整后继续保留。新首通使用当前难度；未定级题目暂不发首通经验，后续有评级时补发一次。

活动记录只显示通过题数，按北京时间与原站 AC 去重，同题同日计一次，跨日再次通过各计一次。日历和数字使用五档样式：0、1、2–3、4–6、7+；运行样例和失败提交不会增加通过数。

“我的训练”每天按北京时间刷新，显示今天加入或练习过的题、各目标当天题单，以及待补题和到期复习。各目标分别保存、分别计数，完成另一目标不会清空当前题单。任务按紧迫程度安排；v1.2.0 从练习返回时保留进入前的列表位置，不因刚完成 AC 重新排到最下方。AC 后 7 天安排复习，复习通过后 30 天安排巩固抽检；不再强制安排独立重写。历史训练和代码仍保留。

“提交记录”按日期分组。1.0.15 起全局列表只展示正式提交，运行与样例记录仍可在工作台查看。点击记录可查看当次代码，官网补回但没有取得源码的记录会明确标记。顶部 AC 按“今日之前累计 + 今日”显示；本级 XP 在头像经验环提示，段位用头像框表示。成长页总做题数包含已配置公开账号在题库外的已知通过记录。WA 为红色答案错误，RE 为紫色运行错误，CE 为蓝色编译错误，TLE/MLE/OLE 为橙色资源超限，AC 为绿色通过。

在题库或知识目录选择题目，加入“我的训练”。题面与 C++ 编辑器并排显示，支持切换布局，草稿自动保存。“运行样例”编译并对比公开样例；选择自定义输入后可运行自己的测试数据。样例通过不计入官方 AC。内存超限、启动失败等运行错误只在运行结果中显示，不弹出 Windows 错误对话框。

“提交”（Ctrl+Enter）使用你日常浏览器已登录的 Codeforces、AtCoder、牛客或洛谷账号，在后台提交并把评测结果显示在应用内。浏览器已有窗口时优先复用登录会话和后台页面；关闭浏览器后可使用已同步的有效会话，必要时唤醒连接组件刷新。原站验证仍需本人处理。AtCoder 支持在没有历史提交的比赛中直接提交。

0.10.8 起，工作台内置“浏览器提交准备”。未安装或启用扩展、未同步原站登录或登录失效时，界面显示准备提示；点击“查看准备说明”按安装扩展、登录原站、重新检测三个步骤完成。说明可以打开扩展管理、扩展文件夹和 Codeforces（CF）、AtCoder、牛客、洛谷的登录页，并显示各平台状态。TB 的登录和原站登录分别进行，扩展与原站账号须在同一个浏览器用户配置中，不使用无痕窗口。详见[完整准备说明](browser-preparation.md)。

扩展只同步这四个平台的会话 Cookie，不读取密码；登录数据通过回环接口交给 TB，用当前 Windows 用户的 DPAPI 加密保存在本机，不发送到 TB 云端。0.10.9 起，浏览器登录变化会自动刷新到 TB；CF 的空会话缓存不会覆盖当前原站页面的登录状态或提前拦住提交。原站不可访问或要求验证时显示待确认状态，请在原站处理并重新检测；检测和登录不会自动发送代码。

1.0.18 延续后台提交：CF 等待原站题目锁自然放行，普通准备错误可重试；原站验证或未确认回执保留人工处理路径。已有代码草稿会保留，预填和登录本身不发送代码。拿到提交编号后显示“评测中”；发送后 45 秒仍未确认时继续查询，最多等待 15 分钟，不自动重复发送。模拟赛使用受比赛规则保护的“赛内提交”。

在公开账号设置中配置正确的原站账号后，1.0.15 会定期同步 Codeforces 官方提交；浏览器扩展也会读取本人记录、接收其他支持平台的回执。官网手动提交不要求事先在 TB 创建提交任务；能匹配当前题库原题的结果按提交编号去重，保留原始时间。原站暂时不可访问时等待重试；未取得源码的回执不会拿当前草稿代替。

点击题解查看内置内容，基础讲解可以按章节展开；从零讲页面可搜索概念。新抓取的公开题若尚未导入题解，会显示尚未收录。内置题解不需要配置 AI API。

题解顶部可选择“默认题解 / 详细题解”。每次打开先显示原有默认版；详细版用具体例子逐步解释概念、推导、正确性和代码。当前公共库包含 1302 份默认题解与 1302 份详细题解。此前的 809 组全部保留，牛客周赛 162–165 的 26 题均有两版，包含签到题；本次 XCPC 与蓝桥杯累计新增 453 组，覆盖 408 道不同题目。已核定且低于 2200 分的范围已补齐，已有高分题解保留；未评级条目待核验，见[完成与待核验清单](editorial-content-20261016.md)。

2026-10-19 已为截图中的新比赛补写 29 组两版题解，并让 11 个新收录条目也能读取已有题解；补回 24 份题面。范围继续按低于 2200 执行，练习赛 158 F 暂待可信评级。[本次清单](recent-contest-editorials-20261019.md)。

模拟赛可选综合、专项、随机单题或重现赛，比赛期间隐藏考点并限制题解查看；结束后在模拟赛页面复盘。1.0.15 的比赛名称按自然顺序排列，重现赛可搜索；已结束的比赛记录可以单条或全部删除，代码、草稿和个人 AC 保留，进行中的比赛须先交卷。部分公开比赛题单尚未核验完整，创建前查看预览和缺失提示。

1.1.0 的比赛列表每页 40 场。点击比赛行右侧“开始比赛”会校验题单并启动对应重现赛；进行中的比赛或缺少必要题面会给出明确提示。成长页“下一步练什么”点击整行进入单题，右侧不再另放练习按钮。界面隐藏时暂停刷新界面的轮询，后台上传与会话检查继续。

## 翻译

设置 → 翻译 API，选择 DeepSeek、火山方舟 Agent Plan 或自定义服务。官方 DeepSeek 使用 `deepseek-chat`；自定义服务填写服务商提供的 Base URL 和模型，支持根地址、`/v1` 或完整 `/chat/completions` 地址。火山方舟填写当前套餐可用的模型或接入点 ID。按服务要求填写 API Key；本机无需认证的服务可留空。

保存后点击“测试连接”，成功会显示验证状态。密钥无效、余额不足、模型不存在或服务输出截断会分别给出原因。测试会使用该接口的正常用量。翻译中保留代码、公式和样例；失败时仍可直接看原文。换 Windows 用户或电脑后，原有 DPAPI 密钥需要重新配置。

## 排行榜

打开软件必须先登录。首次注册填写昵称、登录号和密码，再登录进入工作台；成长与能力 → 账号与身份 → 管理账号可以修改昵称、验证原密码后修改密码和退出账号。没有忘记密码或短信找回功能。排行榜显示昵称、等级和能力段位，不显示内部账号 ID；旧安装首次注册时关联原成绩，账号切换分别保存训练和草稿。详见[账号说明](accounts.md)。

软件默认连接已部署的 TB 排行榜。已保存的原站确认 AC 会自动上传；同一道原题只计第一次，运行和样例通过不计入。历史官方回执会补传，公开账号汇总中没有完整回执的条目不自动补成今日成绩。

日榜和周榜使用北京时间。1.0.20 将当天登录的用户列入榜单，无通过记录显示 0，已有周期成绩照常保留；零题登录不会领取名次奖励。断网时训练记录继续保存在本机，稍后同步。计分接口接收昵称、身份与通过摘要；账号快照另同步完整代码和草稿，Cookie 与翻译密钥始终留在本机。默认服务地址为 `https://47.82.84.74`；目前依赖客户端保存的官方回执，尚无独立原站防作弊认证。

1.1.0 排行榜在昵称旁显示称号勋章、等级、段位和排位分。尚未解锁排位时显示未解锁，不能把 XP 当成排位分；旧客户端尚未上传的成长资料保留空缺。摘要由客户端从真实训练账本派生并通过已认证会话上传，与排行计分分别存储。

## 外观与数据

设置可调整主题、字号、导航顺序、名称、页面组合。1.0.20 的收藏、保存筛选和上述账号偏好随账号恢复；全屏等设备设置留在本机。题面可独立设为 14–32px，原文、中文、公式与样例一起缩放，代码字号保持独立。“我的训练”集中展示每日目标、待办、待攻克和间隔复习；目标管理位于成长页，活动记录有独立导航。知识清单支持搜索，分组、缩进与连接线表示层级，数字分别反映可用题目和个人覆盖。

账号管理和 CF/AtCoder 公开绑定位于成长页，翻译 API 在设置中。Ctrl+K 可打开快捷操作，界面上的键盘快捷入口已移除。公开评分只展示 CF 和 AtCoder，牛客、洛谷原站登录及提交能力不受影响。

1.0.18 起每次打开软件都立即检查正式版，登录前也可更新。发现新版后自动下载、校验并安装，无需点击确认。安装前等待草稿成功保存，执行包括其他本机账号在内的 SQLite 在线备份，再校验 SHA-256，正常退出后替换变化文件并重开；替换失败恢复原程序文件。正在官方评测或模拟赛中时等待当前任务结束，每五秒检查是否可安全安装，随后自动继续。断网或下载失败保留当前程序并后台重试。

设置 → 更新 → 软件版本更新可查看进度、手动重查。“运行期间每天额外检查一次”仅控制运行期间的每日检查，关闭后每次启动仍必须检查和自动更新。漏装版本沿已有增量包逐步更新，不重复下载编译器与 WebView2；旧客户端首次升级仍使用原有安装器。

也可从 GitHub 下载正式版完整安装程序，退出 TB 后手动安装到原目录。尚未发布的源码版本不会作为正式更新推送。个人记录保存在程序目录 `state/`；不要将使用后的整个目录当作公共安装包分享。手动备份时先退出程序，再复制完整 `state/`；程序提供的数据库备份使用 SQLite 在线备份。

## 等级与能力段位

v1.2.1 中，等级按累计经验增长，每级需要 `200 × 当前等级` XP，最高 100 级；5 级、累计 2,000 XP 解锁能力段位。至少 5 道不同原题具有已知难度和独立首次官方 AC 后，以最高 5 题的难度中位数定级。能力分与经验独立，没有缺勤扣分；样例通过不参与。原经验、称号、提交、代码和解锁时间保留。此规则替代旧版 10 级后积累排位分的方式；[详细规则及十段门槛](progression.md)。

点击右上角段位经验框直接查看训练概览，最高已达成的 AC 成就带边框与奖杯，下面只列下一个未达成目标。1.1.0 累计 AC 共 12 档：1、10、25、50、100、200、300、500、750、1000、1500、2000；500 题起奖励永久称号。连续训练 30、90、180、365、730 天也奖励称号，最高为两年。删除更高 AC 目标和旧 1000 天目标后，已发经验仍保留；达成或跨电脑恢复不会重复奖励。

称号自动佩戴最高 AC 与最高连续训练两枚，在顶部和排行榜展示；成长页可查看全部已获得称号与公开身份。新达成成就打开弹窗后带边框和“新达成”，仅在鼠标经过或键盘聚焦该卡片后消除，关闭或打开弹窗不会一次性全部标为已读。已读状态随账号同步。

“我的账号”默认只显示身份，点击“管理账号”后修改昵称、密码或退出。公开统计只绑定 CF 和 AtCoder；牛客、洛谷原站登录、题库与提交继续支持。有证据的题目显示分类与难度，估算以“≈”标识并保留来源、区间及可信度；不足以定级时显示“未定级”。模型分类只说明题面对象，不表示已验证解法。
