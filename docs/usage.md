# 使用 ToBe

英文题面默认显示英文。点击题面工具栏的现有语言按钮切换到中文，再次点击返回英文。ABC、Codeforces Div.2/3/4 的现有 361 题已附预置中文，切换不调用翻译服务；其他已有译文继续保留。

本说明随安装包分发，版本以同目录 `VERSION` 和“设置 → 更新”为准。历史变化、已发布版本及检查结果见 [GitHub 发布记录](https://github.com/3097729287/acm-algo-trainer/releases)。

## 安装、登录与退出

从 [GitHub 最新正式版](https://github.com/3097729287/acm-algo-trainer/releases/latest)或[国内下载与更新](https://47.82.84.74/updates/stable/index.html)取得用户版安装包，安装到原目录即可升级。`ToBe.exe` 是正常启动入口；管理员工具仅供维护者本机使用，不在公开下载中提供。

登录页也能检查和安装软件更新，不必先完成登录。安装前保存草稿并检查正在进行的评测、原站提交和模拟赛；学习记录与专用浏览器配置保留。客户端升级与公共内容更新分别处理：支持热更新的程序可在线合并题面、题解、难度和题单，无需退出学习；旧客户端仍须先完成支持该能力的一次程序升级。以实际更新结果为准。

首次注册、新设备登录和密码登录需要联网。已在本机成功验证并同步的账号，在保存的凭据未过期且工作区所属账号匹配时，可以在暂时断网期间读取缓存题面与题解、修改草稿、运行本地样例。没有缓存的内容和原站正式提交仍需联网。

重新联网后先校验会话、读取最新云端状态并合并，再上传待同步修改；代码冲突保留恢复记录。普通网络故障和同步版本冲突自动退避重试，不显示常驻顶部横条；需要处理的账号信息进入消息中心。未验证、过期或已知撤销的会话不会绕过登录。换电脑前确认同步完成，本机已保存不等于另一台已收到。[账号与同步说明](accounts.md)。正常退出先保存本机代码，不为云端上传无限等待；下次进入继续处理待同步记录。

## 从哪里开始

“我的训练”组织今日目标、到期复习和继续练习。顶部搜索区域与经验、AC 信息之间显示下一项推荐任务；点击任务直接进入对应题目或板块，鼠标移入或点击展开按钮可查看其它选择，含主任务最多六项，下拉不重复主任务；任务类别与推荐依据在悬停 tooltip 中，也支持键盘和触屏。新手停在最早未掌握的基础单元，缺少合格练习时提供基础学习入口，不越过先修。

推荐先处理正在进行的比赛和到期复习，再核对基础、先修知识、课程位置、模板操作及独立巩固。近期不同原题的独立作答、跨日保持和技术广度达到门槛后，才提供拔高或完整试卷的混合限时训练；点击比赛建议不会自动开赛。等级、经验、勋章、阅读章节和模板操作通过都不替代独立掌握证据。详见[推荐规则与依据](learning-recommendations.md)。

新手指引只显示已经开放的板块。等级提升后，新增板块提示与指引随实际解锁出现；已注册用户按当前等级进入，不重新从一级限制。

| 等级 | 新开放的板块 |
| --- | --- |
| 1 | 我的训练、题单 |
| 2 | 题库、排行榜 |
| 3 | 比赛、模拟赛 |
| 4 | 算法实验室、模板、从零讲 |
| 5 | 成长与能力、活动记录 |

提交记录和设置始终可用。在“设置 → 交互与导航 → 导航与页面组合”可隐藏允许隐藏的板块；必要入口不能隐藏。关联工具按钮和推荐入口一起隐藏，不删除该板块数据。重新显示后可继续使用。

## 选题、代码与提交

搜索支持题名、来源和知识点，排序、筛选、文件夹浏览集中在顶栏。分页支持直接输入页码，每页行数随可用空间调整。成长页的知识点按当前题库中关联的不同原题数降序排列，高频知识点优先出现在前页；雷达与下方表格共用同一顺序，同数量保留原顺序。题单通过数量按规范原题去重，自建与公共题单分别管理。

打开题目后在工作台阅读并编写代码，已保存草稿优先于初始代码；载入模板不自动覆盖已有内容。本地运行、自定义输入、样例通过与原站正式提交分别处理，样例通过不代表官方 AC。

题面默认显示原文；语言按钮切换中文，原站中文题仍保留原始正文。复制按钮复制当前题面与全部样例。题面和代码默认各半，可拖动中线调整，布局按钮切换全代码视图。样例默认展开，题解按钮再次点击收起。代码在本机自动保存，成功时短暂提示，保存失败会明确显示。

点击提交后，程序使用专用 Edge 或 Chrome 进入该原题的原生提交页，核对真实语言控件、填入代码并取得对应回执。未登录或需验证码时在该窗口完成；明确被拒绝的请求不会自动重发。[浏览器登录与提交](browser-preparation.md)。已登录的平台不会在普通启动时为检查状态弹出首页，无法确认时保持未知。

牛客比赛题与全局题号使用各自原始地址；全局题号不转换成猜测的比赛身份。提交仍通过原站正常按钮，只有核对原题、本人和本次新提交后才记录正式结果；原站改版导致无法确认时会停止并要求核对。

提交记录先显示轻量元数据，点击代码图标读取当次源码。新设备的历史代码可首次查看时加载，原设备已有源码保留。Cookie 保存在本机专用配置，不复制日常浏览器配置，也不随学习记录上传。

## 比赛、模拟赛与日历

比赛目录按实际来源、类型和年份生成，XCPC 区域赛、省赛、邀请赛分别归类，空文件夹不展示。只有已核对完整题单、题面及样例的场次才用于整场重现，不把一两道残缺题目包装成完整比赛。

模拟赛支持综合、专项与重现赛，开始前查看题数和时长。取消不生成完赛或补题记录，真实回执及代码仍保留；结束确认只在主动点击时出现。XCPC 难度按对应原场完成状态显示，正赛与热身赛分别计算，进行中的考场继续保护难度及指导信息。

比赛日历显示未来与进行中的赛事，开赛时主动检查题库和比赛内容。整场导入就绪后可从日历进入；晚加入沿用原开赛及结束时间，不重新获得完整时长。状态以实际“进行中”和导入结果为准。

## 教学、模板与复习

算法实验室通过交互推演、预测和核对解释算法，再以精选题交接独立实现；再次进入恢复上次课程和章节。课堂操作、勾选或本地测试不产生正式 AC，课程与草稿按账号保存。模板默认详细版，按钮切换竞赛版；题内单击模板卡片插入头文件和宏定义之后、主函数之前，去重头文件，内置 C++ 模板统一使用 `using ll = long long;`。模板也可复制或另存；初始代码模板在设置中按语言单独管理。

从零讲支持关联基础讲解、逐篇返回和恢复阅读位置。全屏按钮进入独立阅读布局，Esc 退出，已学会标记可撤销。复习依据实际作答安排，打开任务后取得符合要求的独立正式回执才计入对应奖励。

## 成长与证据

经验等级记录已获得的经验，能力分描述作答证据，两者分别计算。能力分与知识点掌握度共用保守 Rasch 模型，使用不同原题的独立正式作答、有效失败、难度来源和重试强度，不再取最高几题难度的中位数。查看估计区间、支持上限和近期证据，不把参考分当成官方 Codeforces 等级分。[能力分算法](ability-assessment.md)。

知识雷达不展示零题子项，一两题的小知识点合并为同大类“杂项”，多标签共享原题仍去重。圆点进入子项，过多子项分页，图表同步。掌握指数以 CF2300 参考卷归一化，未练部分保持未知，少量证据对应较宽范围。[掌握度计算](knowledge-mastery.md)。

前五级累计门槛为 0、100、200、350、500 XP，已有经验不改写。每日任务按完成证据领取，难度挑战参考近期能力，不要求收藏或修改外观。底栏从 `0/3` 开始，完成三项后显示 `3/4`，后续随机任务依次累加，完成十项显示勾号；已有奖励不会因能力算法修改而扣回。活动页可直接用方向键在日期格子间移动，明细自动跳到对应日期所在页与行；输入文字或打开弹窗时遵循对应控件操作。

## 设置与个人数据

外观可调整主题、强调色、字号、背景和各页透明度，难度的数字与文字直接选择。减少动态效果时保留静态状态。仅外观页记住最近位置，其他设置板块再次进入显示正常入口；小窗口使用响应式布局并保留必要点击范围。

翻译 API 只发送公开题面，不发送草稿；密钥由本机 Windows DPAPI 保护，换设备需重新配置。失败保留原文，原站中文和机器译文按来源区分。

导出可能包含个人代码，请妥善保存。自动 SQLite 备份分层保留最近、每日和每周恢复点，并限制数量与容量；清理前保留已验证恢复点，手动备份单独保护。备份淘汰不删除在用数据库、代码及草稿。[账号数据与备份](accounts.md)。
