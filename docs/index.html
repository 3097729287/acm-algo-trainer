内容随软件提供

1.0.17 内置 7530 道题、2202 份题面、796 份默认题解、1 份详细题解和 376 篇基础讲义，SQLite 存储。有证据的难度保留来源，估算显示“≈”，不足以定级时显示“未定级”。新增 Gym 题面按需联网缓存；内置配图离线可读、点击放大。

按实际训练积累

自动保存草稿、提交代码与结果。每日目标独立计数并汇入“我的训练”，支持独立题面字号、每日经验、知识覆盖与复习。样例通过不计入官方 AC。

组织自己的训练

单题练习、专项与综合模拟赛。比赛期间隐藏知识点与题解，结束后结合记录复盘。

联网能力，按需使用

同步原站公开账号，通过 DeepSeek、火山方舟或自定义兼容 API 翻译题面。官方 AC 自动补传并按原题去重，提供北京时间日榜、周榜和总榜；仅同步身份与成绩摘要，不上传代码或 Cookie，暂无独立防作弊认证。
