# ToBe 1.6.2 整体验收

本次先重新运行原 CI 的 88 项界面命令，保留失败记录，并定位修复对战页两处空状态访问、共享服务慢响应被 3 秒连接预算截断、快速反复修改偏好时旧写入覆盖新值的问题。

后端重新运行 1,218 项，2 项按环境条件跳过，其余通过。共享服务 107 项中 106 项通过，1 项跳过。原生 WebView 检查使用隔离题站表单、授权与回执，未向真实题站提交。雨滴、落点和波纹使用 CheapWater 同一透视相机，单次碰撞多圈扩散，5 秒后仍有可见波纹；静止、卸载、无网络资源和闪电状态恢复均有检查。

安装与增量验收使用独立目录和独立 AppId。公开 1.5.2 安装包从国服取回后核对原发布 SHA-256，再解出原程序进行逐文件比对；本机个人安装仅作为只读升级基线。编译器 4,067 个文件与公开 1.5.2 完全一致。新版本用户包、管理员本机包和实际安装逐文件核对；账号、代码、草稿、题库导入与训练记录单独备份和比对。

国服现有磁盘空间有限，更新沿用现有公开文件转发：只允许核准的 GitHub 发布文件，校验字节数与 SHA-256，并在校验最后一块后完成响应。账号服务不缓存大型更新包，既有版本和个人数据库保留。公开用户安装包与增量先验证后发布，更新清单最后切换。

此项为软件行为与交付检查，不表示重新人工精读每道题解，也不以隔离表单冒充真实账号提交。最终构建、安装、增量、国服和 GitHub 校验回执在项目版本恢复目录留存。
