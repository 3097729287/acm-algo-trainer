本次为现有 27 道题的默认、详细题解补入 27 份独立动图，共 166 个关键状态。选择的是需要同时看操作顺序、数据版本或关系变化的推导：队列两端删除、先查询后插入、相邻交换、整列移动与偏移补偿、同步倍增、扩展图状态、括号前缀镜像、删除传播等。原来的正文、公式、静态图和参考代码保留。

选题前扫描了 1,939 份默认题解与对应详细内容，排除重复的从零讲段落再查找动态机制。827 份词汇命中只作为候选，不代表这些题都需要动画，也不等于逐题人工审阅。实际增补的 27 题逐份阅读了题意、推导和实现，清单、理解卡点和例子记录在 `data/editorial-motions.json`。

动图紧邻对应推导，不统一堆到文末。绝大部分沿用原文已有例子；需要补充的较小例子明确标注，例如 LCA 图固定以一号为根，与原文四号根的例子分开。Full Tank 只展示一条最优行程，不把它冒充完整的堆弹出过程。mex 某层尚未结束时不提前计贡献，区间以外也不标成已修改。

正文中的动图可暂停、上一步、下一步、拖动步骤与重播。首次进入可见区域时播放一遍，在最后状态停住；窗口隐藏、切走或滚出可见区域时停止计时。程序或系统减少动态效果时保持静止，仍可手动逐步查看。放大窗口里保留同一套步骤操作，键盘焦点和关闭恢复沿用图片阅读器。

每份资源是可独立打开的 SVG，包含离线动画和被动的逐帧 SVG 图像；元数据只供播放器读取，不执行代码。图片始终通过 `img` 显示，不向正文注入 SVG/HTML，模型不接受网络或 JavaScript 帧地址。导出 SVG 在系统减少动态效果时也显示静态首帧。
