# 浏览器登录与原站提交

本说明对应随包程序，版本见同目录 `VERSION`。本地运行、样例与官方提交保留真实边界；测试记录不代表已向真实原站提交成功。

## 首次使用与登录记忆

安装 Microsoft Edge 或 Google Chrome。ToBe 默认优先使用 Edge，并记住选择。需要登录时，在 **ToBe 打开的专用浏览器窗口** 登录对应平台；它与日常浏览器分别保存，无需安装扩展。

普通启动先在后台检查专用配置中的本人登录。已登录站点不会为检查状态打开可见首页；网络失败、验证页或无法确认时保持未知，不猜测已退出。明确需要登录时才显示原站，关闭当前登录页会停止继续弹出其他站点。

Codeforces、AtCoder、牛客和洛谷的公开账号绑定在右上角账号弹窗管理。QOJ 题目在原站按需登录，不增加没有公开资料依据的账号绑定字段。

QOJ 与上述四站共用登录状态管理和原站提交流程，专用配置相互独立。账号弹窗可按需打开 QOJ 登录；未使用 QOJ 不会阻塞原四站的就绪状态，也不会在普通启动时强制弹出 QOJ 首页。其它新来源可显示和筛选，只有已实现并核验的适配器才提供原站提交。

## 一次提交的流程

1. 在工作台保存代码，点击提交。
2. 程序连接专用浏览器，进入该原题的原生提交页，核对题目和真实可用语言。
3. 需要登录或验证码时在原站完成；尚未发送的本次操作可以继续，明确被拒绝的请求不自动重发。
4. 适配层填写代码并触发原生控件事件，保留原站 CSRF、语言菜单及验证流程。
5. 取得受理编号后只跟踪对应提交，显示并保存最终结果后，才关闭本次可安全关闭的提交窗口。登录、验证码和未确认结果保持可见。

样例通过不计官方 AC。受理前失败没有最终判定；网络中断、关页或超时可留下待核对记录，不能用样例结果代替。

## 语言与题面

C++17、C++20、C++23、Python 3 均以原站真实语言控件为准；无兼容项则停止，不从题面文字推测编译器。编辑器晚于页面数据加载时，等待可操作后再填写。

QOJ 网页保留公式、图片和样例；PDF 保留原页面图并独立核对样例。原题及提交使用已核对的全局题号，不根据相邻编号推测比赛字母。题目积分不是难度，原文、原站中文和机器译文按实际来源区分。

## 隐私、退出与故障

专用配置保存在本机。允许缓存的第一方会话以 Windows DPAPI 密文存入本机 SQLite，仍受原站过期、撤销和保留期限制；已退出后不会把旧会话当作永久有效。配置与 Cookie 不上传到账号同步服务、不随安装包分发，也不读取日常浏览器历史或其他账号。

退出先保存本机代码，待同步修改下次继续处理。重开程序不会仅为恢复已登录的 Codeforces 会话而弹出首页。正在操作的验证页与未确认提交按实际状态处理，不关闭无关的日常浏览器。

无法提交时，先核对可见原站页面的登录、验证码、语言和受理状态，再按相应重试操作处理，不反复点击制造重复请求。站点维护、网络和页面变更仍可能影响流程；适配不能保证任意网络中的原站验证成功。

专用配置使用本机回环调试连接，程序核对进程、配置目录和端点。Chrome 对远程调试使用非默认目录的要求见 [Chrome 官方说明](https://developer.chrome.com/blog/remote-debugging-port)。[使用说明](usage.md) · [账号与同步](accounts.md)。
