# 浏览器登录与原站提交

本说明对应随包程序，版本见同目录 `VERSION`。本地运行、样例与官方提交保留真实边界；测试记录不代表已向真实原站提交成功。

## 首次使用与登录记忆

使用你平时已登录竞赛平台的 Chrome 或 Edge。在 ToBe 右上角账号设置中展开“浏览器连接”，打开随包扩展目录。在这个常用浏览器地址栏打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，加载完整目录。

打开 ToBe 并登录自己的 ToBe 账号后，账号设置及扩展图标的连接页会显示“已连接”。已登录的原站继续使用这个浏览器的现有会话，无需另开专用 Edge 登录；普通启动不会打开登录首页。加载本地扩展需要浏览器用户手动操作，程序不修改浏览器策略或替你启用扩展。若此前加载过旧版连接，请停用旧版，加载本次完整目录。

Codeforces、AtCoder、牛客和洛谷的公开账号绑定在右上角账号弹窗管理。QOJ 题目在原站按需登录，不增加没有公开资料依据的账号绑定字段。

QOJ 与上述四站使用同一常用浏览器通道，按需登录；未使用 QOJ 不会阻塞其它站点。多个浏览器同时连接且无法唯一确定本次账号时，请只保留本次要用的一个连接，再继续。一个任务固定到同一浏览器连接，断线不会改用另一个浏览器重交。

## 一次提交的流程

1. 在工作台保存代码，点击提交。
2. 扩展在已连接的常用浏览器内创建一个后台标签页，进入该原题的原生提交页，核对题目、原站账号和真实可用语言。只静音这个自建标签页，不影响其它音乐或视频。
3. 需要登录或验证码时在原站完成；尚未发送的本次操作可以继续，明确被拒绝的请求不自动重发。
4. 适配层填写代码并触发原生控件事件，保留原站 CSRF、语言菜单及验证流程。
5. 取得受理编号后只跟踪对应提交。正式结果真正保存、且 ToBe 在当前可见结果区显示该条结果后，才关闭自建标签页；查看别题、隐藏窗口或选中其它历史记录都不算显示。手动打开的页面保留，查询失败保留原编号。

样例通过不计官方 AC。受理前失败没有最终判定；网络中断、关页或超时可留下待核对记录，不能用样例结果代替。

## 语言与题面

C++17、C++20、C++23、Python 3 均以原站真实语言控件为准；无兼容项则停止，不从题面文字推测编译器。编辑器晚于页面数据加载时，等待可操作后再填写。

QOJ 网页保留公式、图片和样例；PDF 保留原页面图并独立核对样例。原题及提交使用已核对的全局题号，不根据相邻编号推测比赛字母。题目积分不是难度，原文、原站中文和机器译文按实际来源区分。

## 隐私、退出与故障

Cookie、密码和登录会话留在常用浏览器内。新版扩展不申请 cookies、history 或 debugger 权限，不读取、复制或导出 Cookie；旧的会话导出接口已停用。题面读取与 VP 注册也使用这个浏览器的页面，不启动另一个登录配置。原站自己的会话过期与账号限制仍按原站规则处理，不猜测固定设备数量。

退出先保存本机代码，待同步修改下次继续处理。升级后，在原 ToBe 账号恢复时只读重查已保存的原编号；旧记录缺少绑定字段时，仅从仍在运行的旧 ToBe 专用页面核对原会话、原始源码摘要和语言，再在常用浏览器确认同一原站账号。请保留这些旧页面直到恢复完成；证据不足时保留待核对状态，不推测结果或重新提交。

无法提交时，先核对可见原站页面的登录、验证码、语言和受理状态，再按相应重试操作处理，不反复点击制造重复请求。站点维护、网络和页面变更仍可能影响流程；适配不能保证任意网络中的原站验证成功。
