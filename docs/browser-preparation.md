# 浏览器提交准备

本文对应 TB 1.1.0 与同版浏览器扩展。升级后请重新加载随包扩展，保持程序与扩展版本一致；账号与翻译设置已集中到成长页，原站浏览器登录仍分别进行。

TB 账号和竞赛平台账号分别登录。原站提交需要在同一个 Edge 或 Chrome 用户配置中安装“TB 浏览器连接”，并登录要使用的平台。不要使用无痕窗口。工作台缺少准备条件时会显示提示；点“查看准备说明”即可打开同一份内置指引。四个平台准备完成后，这条提示自动隐藏。

## 1. 安装并启用扩展

在内置说明选择浏览器，点击“打开扩展管理”。也可以在 Edge 地址栏输入 `edge://extensions`，Chrome 输入 `chrome://extensions`。开启开发人员/开发者模式，点击“加载解压缩的扩展程序”，选择 TB 显示的扩展文件夹。可以点击“打开扩展文件夹”或复制路径；选择包含 `manifest.json` 的目录。

确认“TB 浏览器连接”已启用。安装过旧版本时，点击它的“重新加载”。0.10.12 补齐这四个原站域名的 Cookie 访问范围；若浏览器显示权限更新提示，确认后启用即可。无需重新登录原站。步骤参考 [Microsoft Edge 官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)、[Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

## 2. 登录原站

使用内置说明的登录按钮，可在所选浏览器打开原站。先登录要提交的平台即可。

| 平台 | 登录入口 |
| --- | --- |
| Codeforces（CF） | https://codeforces.com/enter |
| AtCoder | https://atcoder.jp/login |
| 牛客 | https://ac.nowcoder.com/login |
| 洛谷 | https://www.luogu.com.cn/auth/login |

在原站完成密码、验证码和安全验证。TB 不填写原站密码。“登录状态待确认”表示当前信息不足；它不等同于退出登录。遇到提交页验证时，在题目工作台点“在浏览器查看”，完成验证后再回 TB。

## 3. 回到 TB 检测

安装扩展并在浏览器登录后，可直接回到题目点击“提交”。四个平台会自动同步，无需打开原站标签页，也无需重复登录；可以点击“重新检测浏览器准备”立即刷新。检测和登录不会自动发送代码。

四个平台都支持关闭浏览器后使用已同步的有效会话，必要时 TB 会无窗口唤醒已安装扩展的浏览器。重启 TB 后保留已确认的登录状态；提交前会刷新实际会话。浏览器已有窗口时，CF、AtCoder 优先复用已登录配置中的后台页面。旧状态、空缓存或网络暂时不可用不会直接要求重新登录。

AtCoder 同一道题已经打开且没有代码草稿的提交页可直接复用，已完成的验证也会保留。1.0.16 只有原站实际要求验证时，会打开本次提交使用的浏览器页并尝试预填代码，由你在原站完成验证和提交，TB 继续等待回执。浏览器提交页中已有的代码草稿不会被覆盖，预填代码不会自动提交。

配置原站公开账号后，1.0.15 还可同步不由 TB 发起的官网提交。扩展只同步本人记录，结果按平台和提交编号去重，并保留原始提交时间；没有取得源码时会明确说明。Codeforces 也通过公开接口定期读取已配置账号的记录。只同步能与当前题库原题匹配的回执；原站暂时不可访问时等待后续重试。

原站确认会话失效或要求人工验证时仍需按提示处理。网站验证码、账号权限和原站故障不会被当作已成功提交；取得本次受理编号后才记录受理，发送过的代码不会自动重发。

正常后台准备不因 12 秒等待误报未登录，普通控件解析失败只显示可重试错误。已发送请求未收到回执时继续核对，不自动重复发送；确实无法取得结果时可使用“在浏览器查看”核对并处理。
