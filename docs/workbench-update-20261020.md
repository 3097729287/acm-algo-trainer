# 2026-10-20 工作台更新 · v1.2.0 发布准备

本批功能纳入 v1.2.0 发布准备，尚未正式发布；公开下载仍为 v1.1.5。本文记录源码功能与隔离验证，实际打包、安装升级、本机替换和服务部署结果见[v1.2.0 说明](releases/1.2.0.md)，完成前不宣称已经交付。

## 界面与选题

- 题库、训练支持「平台 → 比赛 → 题目」层级浏览，可逐级返回，或在任一层查看全部题目；搜索与筛选沿用当前范围。
- 进入练习前保存列表顺序、分组、页码和滚动位置；退出时恢复原视觉位置，不保留选中高亮或竖线，也不因为 AC 将题目移到底部。鼠标静止滚动时，指向行同步更新。
- 吸顶表头、设置栏和提交记录日期栏使用可遮挡滚动内容的表面，避免透明文字重叠。最近练习时间随字号调整，最低 13px。
- 比赛列表移除平台前缀；未定级题只显示字母，数字与字母保持同一基线。「显示比赛平台」只控制单题图标。
- 通用 `ThemedSelect` 保留表单语义和原生 change 事件，使用统一弹层；`BoundedNumber` 支持键入和边界校验；`Tooltip` 提供鼠标悬浮和键盘焦点提示。
- 设置拆成外观、头像、交互、导航、更新、训练与快捷操作、数据与帮助和高级设置。外观只有视觉选项，自定义顺序只在高级设置出现。说明收进提示，背景以横向图标选择，风格预览缩小；每个界面、题面及编辑器可分别配置不透明度。
- 侧栏待补角标改为灰色，悬停后高亮；知识树默认收起。浅色正文提高对比度，线框用中性细边框和小圆角。段位使用固定专属色，独立于主题强调色。
- 模拟赛按难度层次、历史试卷和近期抽题次数选择题目，规范 URL 去重；不再偏向少量本地评测题。新题不足时说明复用情况，重启后保留历史试卷的避重依据。
- 鸣谢新增「她不爱吃酸」。

## 头像、等级与实力段位

头像内的经验环展示本级经验，等级放在头像下角；经验文字只在悬浮提示中出现。旁边的独立段位图标、边框和背景使用固定段位色。头像设置支持 PNG/JPEG/WebP，本机自动缩小至 96px 内，私有同步数据不超过 48 KiB。

等级延续每级 `200 × 当前等级` XP 的曲线，最高 100 级；累计 2,000 XP 达到 5 级，解锁能力段位。至少有 5 道不同原题、已知难度、独立首次官方 AC 后定级，能力分取最高 5 题难度的中位数。十段门槛依次为 0、800、1100、1400、1700、2000、2300、2600、2900、3200；训练概览的「段位要求」可展开查看。旧 XP、解锁时间、提交和代码保留，旧积分算法仅在私有 `legacyPoints` 中提供只读重放。完整规则见[等级与段位说明](progression.md)。

## 爱心、留言与数据兼容

`mysql/008_social.sql` 只增建 `social_likes` 和 `social_notifications`，不替换既有库或账号快照。升级生产库前须按既有流程备份，再对同一数据库执行该增量并更新服务代码；可以重复执行。此处未对生产库执行迁移。

爱心按发送者、接收者、北京时间日期唯一，每天可给同一人点一次，当日不能取消；重复请求和并发请求不增加计数。留言为 1–500 字，使用请求 UUID 防止重试重复；正文只进入接收者的通知，不进入公开动态。爱心动态显示谁给谁点赞。写入在账号锁内重新验证会话，不能通过过期设备修改。

通知返回最近 100 条，「全部已读」在服务端按当前收件人处理所有未读，包含更早记录；公开动态不包含消息正文或已读状态。只有社交通知读取采用 1 MiB 有界响应，其余共享服务读取仍为 256 KiB。

前端点击爱心使用约 600ms 动效：0.8 → 1.2 → 1，灰色转红，8 个彩色粒子飞散并淡出，数字向上滚动。连接失败回滚，减少动态效果时关闭动画。主页顶部显示累计收到的爱心。

`social-store.mjs` 是存储薄层，负责 SQL 列名；`social.mjs` 映射稳定的 API 字段。核心账号和状态写入改为显式列名，新增有默认值的列不会错位。字段改名应在存储薄层映射或迁移，不能假定任意未知重命名自动兼容。旧服务没有新接口或新表时只停用互动，登录、快照和排行榜仍可用。

账号学习快照继续使用协议 1；用户代码、身份、设置、历史 XP、提交和本地导入不由公共库覆盖。头像与页面外观存入账号偏好，不读取其他账号或浏览器数据。

- 共享服务：SQLite/API/HTTP 33 项、隔离 MySQL 33 项通过。
- 前端构建通过；app、workbench、catalog-activity、workspace-decorations、issues 五组回归通过。
- 新增 UI 回归通过：返回位置、滚动悬停、表头、爱心动效与失败回滚、每日锁定、超过 100 条全部已读、头像与经验环、固定段位色、设置隔离、层级浏览及九页布局。
- 真实本地 API E2E 通过：1302 组题解、讲解关联、实际草稿保存、目标与任务、响应布局；不代表真实原站提交验证。
