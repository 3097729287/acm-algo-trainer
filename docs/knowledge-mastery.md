# 掌握指数 v4：Rasch 估计与证据范围

旧算法要求每个子项都有五题、其中三题有难度，才显示父项。少题量、偏难的子项会永久阻塞整个领域。v4 取消这项门槛：有一道已定级题的有效作答即可估计，同时给出宽的模型区间；没有有效难度证据仍显示 `?%`，不填成零。

## 采用的公式和资料

使用一参数逻辑斯蒂题目反应模型（1PL / Rasch）：

\[
P(Y_i=1\mid\theta,b_i)=\sigma(\theta-b_i),\qquad
\sigma(x)=\frac{1}{1+e^{-x}}.
\]

模型把人的能力与题目难度放在同一尺度，以两者之差描述题目反应。[Stan 官方用户指南](https://mc-stan.org/docs/2_30/stan-users-guide/item-response-models.html)给出模型、缺失作答的处理以及先验设定的限制；[Bürkner，JSS，2021](https://doi.org/10.18637/jss.v100.i05)讨论贝叶斯 IRT 的拟合、后验和模型检验。

以正态先验和不同题目的作答证据形成后验：

\[
\pi(\theta\mid D)\propto
 e^{-\theta^2/(2s^2)}
 \prod_i\left[
 \sigma(\theta-b_i)^{y_i}
 (1-\sigma(\theta-b_i))^{1-y_i}
 \right]^{r_i}.
\]

后验均值与分位区间用确定性数值积分计算，遵循 [Linacre：Expected A Posteriori Measures](https://www.rasch.org/rmt/rmt163i.htm)中先验、似然、归一化和积分的 EAP 方法。TB 在 `[-8,8]` 上以 `0.05` 步长计算；用 log-sum-exp 避免连乘下溢。前后端执行相同积分。

## TB 的具体约定

这里没有经过群体答题数据标定的题目参数，不能把平台评级直接宣称为 Rasch 标定值。以下是**公开的工程假设**，不是文献给定或经过验证的参数：

\[
b_i=(d_i-1600)/400,\quad s=1.5,\quad
M=100\,E_{\pi}[\sigma(\theta)].
\]

`M` 是统一参照难度 1600 的练习指数，显示为百分数。所有主题使用同一参照，便于对比；它不是官方等级分、课程完成率、已练题量占比或经过校准的考试通过概率。UI 同时展示该变换的 2.5% 与 97.5% 后验分位数。模型区间只表示当前参数假设下的证据不确定性，不包含模型选择、评级换算和用户自选题目的误差。样本少时区间通常很宽。

同一规范原题只形成一条证据，题目别名、多标签和反复提交不会增加独立样本。只用结束的原站正式 AC 或 WA/TLE/MLE/RE/OLE；CE、样例、运行、排队中、基础设施错误不进入似然。公开核验的 AC 可以证明通过，但不能证明独立编写。

`y=1` 表示该原题已有核验 AC，`y=0` 表示有有效正式失败且尚未 AC。对于成功证据，独立编写为 `a=1`、无源码的核验记录为 `0.65`、看过题解为 `0.25`；首次 AC 前有 `f` 次有效失败时：

\[
r_i=a_i/\sqrt{1+\min(f_i,8)}.
\]

尚未 AC 的有效失败取 `r=1`。这是 TB 为辅助完成和试错设计的幂似然折扣，**属于模型改编**；文献没有为这些常数背书。它不把一次失败永久等同于整项技能为零，也不会把看题解的 AC 当成完全独立完成。未知/无效难度不补造 `b_i`，但保留在作答数量中。

## 父项、子项和出现频率

父项对该领域已有的不同原题合并估计，不平均子项百分比，也不等待所有子项达标。同一题同时属于三个子项，父项的似然仍只使用一次。父项是假定该领域有共同能力维度的粗略摘要；它不能证明每个未练子项都已掌握，必须结合二级雷达查看。

另外报告证据覆盖范围：以当前题库中规范原题的出现频率计算子项权重。设题目 `j` 同时属于 `k_j` 个子项，则在每个子项各分配 `1/k_j` 份题量：

\[
m_c=\sum_{j\in c}1/k_j,\qquad
w_c=m_c/\sum_hm_h.
\]

只要父项有已收录的子题，所有子项权重之和为 100%。无题子项权重为零，不编造题量；缺证据的子项单列为未覆盖，**不当作答错来拉低指数**。这样罕见的高难主题不会阻塞常见主题的展示，题库扩容也不会凭空改变用户的能力证据。频率权重用于覆盖说明，不冒充教育重要性或客观考试频率。

本算法只派生显示值，不修改历史提交、XP、段位、复习任务或个人数据库。后续有足够匿名、经授权的群体作答数据后，才能检验单维与局部独立假设、拟合难度换算、验证校准误差并重新选择参数。
