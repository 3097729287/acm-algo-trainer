## 排位积分规则

- 排位增加的是独立的排位积分，不直接改能力段位、等级或 XP。排行榜按服务端确认的排位积分排序，结算必须在同一事务中持久记录。
- 胜负双方通常加减同一数值；根据赛前双方积分计算，击败高分对手收益更高，输给明显低分对手损失更高。胜者的有效胜局应有正收益，不能因舍入变成零分。
- 败者积分最低为 0。零分保护只限制败者扣分，不能同步削减胜者应得积分：例如应转移 20 分、败者原有 7 分，则败者变为 0、胜者仍加 20；败者原有 0 分时胜者也正常加分。因此，**除零分保护产生的差额外为零和**。
- 平局、取消、未成立对局和系统判分失败不制造胜负积分。断线依照已成立对局的真实服务状态处理，不能绕过原有截止时间。
- 思维组件已改用独立胜者收益和败者扣分，保持 K=40；极端分差仍保证胜者至少加 1 分。已验证双方低分、双方零分、强弱悬殊、重复回执、并发结算及重启恢复。该规则目前只接入思维组件，原站代码排位的积分账本和榜单仍待接入。
- 排位与思维的匹配、评分和结果证据各自明确，不能把原站正式 AC、文字作答评分和能力评估混为一个事实。具体积分参数与历史迁移在实现时记录，不追改旧胜负、学习或奖励事实。

## 实用教学标准

目标是高效、不枯燥、可持续地训练到区域赛拿牌。每一份内容都应帮助读者识别题型、建立正确状态、解释关键选择、写出可改的实现并验证边界；不能仅把标准代码放进一个更花哨的页面。

模板不写死：讲清什么能改、为什么能改、改后哪些条件需要重新证明，用真实题目展示迁移。实验室保持生动且不拘泥于形式，按算法选择操作实验、可回退推演、反例、调参或练习；重复点击、看动画不能代替理解或学习完成证据。题解保留题目特有的推理，把可复用基础工具关联到相应讲义。

维基是知识参照，不是内容上限。维基没有覆盖但竞赛实用的内容也要提供，线性基明确保留；多操作的数据结构与算法归入模板的讲解版／竞赛版及实验室，不恢复成独立“从零讲”目录。语言和标准库基础、原文、原图、身份、题解引用和历史进度继续保留。关联应帮助从题目找到知识、从知识找到实现和练习，不能增加来回跳转负担。
