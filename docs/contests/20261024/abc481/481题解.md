## A. Digits of A+B

### 题意

给定 $1\le A,B\le9$，输出 $A+B$ 的十进制位数。

### 从零讲：条件表达式

`int answer = condition ? first : second;` 是条件表达式的用法：条件成立，把 first 赋给 answer，否则赋 second。例如 `int answer = 5 >= 3 ? 10 : 20;` 会得到 10。大于等于比较包含相等的情况。

### 思路

两数之和最小为 2，最大为 18，因此答案只有 1 和 2。和达到 10 时输出 2，否则输出 1。时间和额外空间均为 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    // 和在 2 到 18 之间，只需判断是否达到 10。
    cout << (a + b >= 10 ? 2 : 1) << '\n';
}
```

### 易错点

和恰好等于 10 时已经是两位数。


## B. Polyline

### 题意

依次连接 $(i,A_i)$ 得到一条折线。相邻两点高度不同，求它与水平直线 $y=K$ 有多少个不同交点。

### 从零讲：动态数组

`std::vector<int> a(n)` 创建含 $n$ 个整数的数组，合法下标为 0 到 $n-1$，访问 `a[i]` 为常数时间。`for (int &v : a) cin >> v` 依次读入每个元素；这里采用引用遍历，输入直接写回原数组元素。连续数组适合按下标比较相邻位置，空间为 $O(n)$。

### 思路

把交点分为折点和线段内部两种，就能避免重复计数。

![水平线经过中间折点，两条相邻线段共享同一个交点](images/b-vertex.svg)

先统计所有 $A_i=K$ 的折点。再遍历相邻两点：只有一个严格低于 K、另一个严格高于 K，线段内部才产生一个新交点。上图中间折点计一次；两段的端点都等于 K，因此都不满足“严格跨越”，不会再加。

每段横坐标区间的内部互不相交，所以不同线段内部的交点不同；这些点也不可能是已统计的折点。两类既无重计也无遗漏。时间 $O(N)$，存数组的空间 $O(N)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    int answer = 0;
    for (int &v : a) {
        cin >> v;
        if (v == k) ++answer;  // 折点单独计数，避免相邻线段重复算它。
    }
    for (int i = 0; i + 1 < n; ++i) {
        // 两端严格分居水平线两侧，才有一个内部交点。
        if (min(a[i], a[i + 1]) < k && k < max(a[i], a[i + 1]))
            ++answer;
    }
    cout << answer << '\n';
}
```

### 易错点

线段内部的判断必须使用严格不等号。相邻高度不同，题目不会出现整段重合而交点无穷多的情况。


## C. Bank Accounts

### 题意

依次处理账户名。首次出现的名字获得下一个从 1 开始的编号，已经出现的名字继续使用原编号。输出每次处理得到的编号。

### 从零讲：map 查找名字

`std::map<string,int>` 保存“字符串键 → 整数值”的对应关系。`id.find(name);` 返回迭代器；等于 `end()` 表示没找到，找到时 `it->second` 是对应的值。`id[name]=number` 插入或更新条目。map 按键排序，但可以自行决定保存的编号；一次查找或插入至多比较 $O(\log N)$ 次字符串。相比每次扫描旧名字，查找更快。

### 思路

维护名字到编号的 map，以及下一个可分配编号 `next_id`。例如依次读到 `"z", "a", "z", "b", "a"`，输出应为 $1,2,1,3,2$。

查到名字就输出原值；查不到才保存新编号并递增 `next_id`。这样第一个新名字取得 1，此后每个新名字只让计数器加一次，重复名字不会占用编号，恰好符合规则。

若名字最大长度为 L，时间 $O(NL\log N)$，空间 $O(NL)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    map<string, int> id;
    int next_id = 1;
    while (q--) {
        string s;
        cin >> s;
        // 账户从不删除，已用编号始终是从 1 开始的连续一段。
        auto it = id.find(s);
        if (it == id.end()) {
            id[s] = next_id;
            cout << next_id << '\n';
            ++next_id;
        } else {
            cout << it->second << '\n';
        }
    }
}
```

### 易错点

编号按首次出现的顺序分配，与 map 内部按名字排序无关。只有新名字才递增计数器。


## D. Autopilot

### 题意

有向图中，从一个点走向它能直接到达的编号最小的点不耗油，走其他出边耗油 1。求从 S 到 T 的最小耗油量，不可达输出 $-1$。

### 从零讲：邻接表与双端队列

`vector<vector<int>> graph(n+1)` 为每个点保存出边终点，读到边 $u \to v$ 就在 `graph[u]` 中加入 $v$。总空间为 $O(N+M)$，扫描一个点只访问它的出边。

`std::deque<int>` 是两端都能增删的队列。`push_front` 加到头部，`push_back` 加到尾部，`todo.front();` 读取头部，`pop_front` 删除头部。这些单次操作均为 $O(1)$；读取或删除前先确认非空。普通 FIFO 队列只有一端插入，不能把优先处理的元素补到头部。

### 思路

先对每个点求出出边终点的最小编号，把通往它的边视为权重 0，其余边视为权重 1。

![免费边可能成环，需要使用一次付费边离开](images/d-zero-one.svg)

图中 1→2→1 都免费，沿免费边一直走会绕圈；走 1→3 付费一次，再免费到 4，答案为 1。因此要比较整条路径的总费用。

用 `distance[u]` 保存目前到达 $u$ 的最小费用。每次从双端队列头部取 $u$，尝试用 `distance[u]+cost` 改善相邻点 $v$。若确实变小，0 权边把 $v$ 放队首，1 权边放队尾。这就是 0-1 BFS：零费用仍在当前费用层，一费用排到下一层，点第一次出队时已取得最小费用。用 `fixed[u]` 跳过后来重复的队列项。

所有点的出边各扫描一次，总时间、空间均为 $O(N+M)$。T 的距离仍为无穷大时输出 $-1$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, s, t;
    cin >> n >> m >> s >> t;
    vector<vector<int>> graph(n + 1);
    vector<int> smallest(n + 1, n + 1);
    while (m--) {
        int a, b;
        cin >> a >> b;
        graph[a].push_back(b);
        smallest[a] = min(smallest[a], b);
    }
    const int INF = 1000000000;
    vector<int> distance(n + 1, INF);
    vector<bool> fixed(n + 1, false);
    deque<int> todo;
    distance[s] = 0;
    todo.push_front(s);
    while (!todo.empty()) {
        int u = todo.front();
        todo.pop_front();
        if (fixed[u]) continue;
        fixed[u] = true;
        for (int v : graph[u]) {
            int cost = (v == smallest[u] ? 0 : 1);
            if (distance[v] > distance[u] + cost) {
                distance[v] = distance[u] + cost;
                // 零费用留在当前层，费用为一的路线进入下一层。
                if (cost == 0) todo.push_front(v);
                else todo.push_back(v);
            }
        }
    }
    cout << (distance[t] == INF ? -1 : distance[t]) << '\n';
}
```

### 易错点

最小编号只比较当前点的直接出边。不能把首次入队当成最终确定，因为稍后可能通过 0 权边改进距离。


## E. Most Brilliant Starry Sky

### 题意

平面上有 N 颗星。选一条经过原点且不经过任何星的直线，取其中一侧，最多能包含多少颗星？任意两颗星与原点不共线。

### 从零讲：极角排序与叉积

把原点指向点的向量看成一根射线，它相对正 $x$ 轴逆时针旋转的角度称为极角。向量 $a$、$b$ 的叉积为 $a_xb_y-a_yb_x$。叉积大于零，表示 $b$ 位于 $a$ 逆时针不足半圈的一侧；小于零表示另一侧；等于零表示共线。

整圈不能只按叉积排序，例如三个分散的方向会形成比较环。先将上半平面（含正 $x$ 轴）排在下半平面之前，再在同半平面内比较叉积，才能得到从小到大的角度顺序。`std::sort(begin,end,cmp)` 排序左闭右开范围，cmp 必须只在第一个元素应严格排在前面时返回真；复杂度 $O(N\log N)$。结构体 `Point p;` 把 $x$、$y$ 保存为一个元素，`std::vector<Point>` 连续保存这些点。

### 思路

直线一侧对应一段角度长度为半圈的开区间。选中的星必须能放进一个跨度严格小于 $\pi$ 的角度窗口。

![跨越正 x 轴的三个点也能被同一个半平面包含](images/e-half-plane.svg)

极角排序后复制一份数组接在末尾，跨越排序起点的窗口就变成普通连续区间。枚举窗口第一个点 left，用 right 指向第一个不满足 `cross(p[left],p[right])>0` 的位置，候选星数是 `right-left`，包括起点自己。

虽然检查时暂用起点射线作为边界，但最终可把边界顺时针转动一个足够小的角度，把起点也包含进去。题目保证没有共线点，所以不会碰到恰好相反方向的星，也能选到不穿过任何星的直线。

left 向后移动时，窗口的角度终点也向后移动，right 无需回退。排序 $O(N\log N)$，扫描 $O(N)$，空间 $O(N)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
struct Point { long long x, y; };
int half(Point p) {
    return (p.y > 0 || (p.y == 0 && p.x > 0)) ? 0 : 1;
}
long long cross(Point a, Point b) {
    return a.x * b.y - a.y * b.x;
}
bool angle_less(Point a, Point b) {
    if (half(a) != half(b)) return half(a) < half(b);
    return cross(a, b) > 0;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        vector<Point> p(n);
        for (Point &v : p) cin >> v.x >> v.y;
        sort(p.begin(), p.end(), angle_less);
        for (int i = 0; i < n; ++i) p.push_back(p[i]);
        int answer = 1, right = 0;
        for (int left = 0; left < n; ++left) {
            right = max(right, left + 1);
            // 从起点逆时针转动不足半圈，叉积严格为正。
            while (right < left + n && cross(p[left], p[right]) > 0) ++right;
            answer = max(answer, right - left);
        }
        cout << answer << '\n';
    }
}
```

### 易错点

叉积用 `long long`，坐标乘积不能在 32 位整数中计算。right 不能走到 `left + N;` 之后，否则会重复统计同一颗星。


## F. Evil Shortest Path

### 题意

有向边上写着 1 到 9 的数字。路径得分是按顺序拼接边上数字形成的整数。求从 1 到每个其他点的最小得分，对 998244353 取模。

### 从零讲：BFS 队列与分组

普通 BFS 用 FIFO 队列逐层扩展，每走一条边就进入下一层，因而先找到边数较少的路径。`std::queue` 的 `push` 入队、`todo.front();` 读队首、`todo.pop();` 删除队首都是 $O(1)$；读删前确认非空。

这里队列的元素为 `std::vector<int>`，一个动态数组保存一组点。邻接表中的 `std::pair<int,int>` 保存终点和数字，`auto [v,digit]` 把这对值取出来。`std::move` 允许容器转移已有存储，减少整组复制；移动后的原容器仍可销毁或重新赋值，但不再依赖其原内容。本程序先把队首移动到局部变量，再弹出队首。

### 思路

没有前导零时，整数先比较位数，位数相同再比较字典序。因此按 BFS 层数处理，再让同层的路径字符串按字典序处理。

关键是把最优字符串相同的点放在同一组，统一收集它们的出边，再按数字 1 到 9 分桶。

![相同前缀的两个点必须一起收集出边，才能先发现 12](images/f-groups.svg)

图中点 2、3 的最优字符串都是 1。若先展开 2 并直接确定点 4，会错误得到 19；整组一起收集后先处理数字 2，就能得到 12。

队列初始只有组 {1}，对应空字符串。取出一组后先扫描全部出边，再按末位递增产生新组；在分桶出队时标记首次到达，忽略已确定的点。FIFO 保证位数递增，同层旧前缀已经有序，每个前缀的子组也按末位有序，所以第一次确定的字符串就是最小值。

一组内的实际字符串相同，可共用 `answer[current[0]]` 的余数，追加数字 $d$ 后更新为 $(answer\times10+d)\bmod998244353$。余数只用于输出，不用于决定顺序。每个点展开一次、每条边扫描一次，时间和空间均为 $O(N+M)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
const long long MOD = 998244353;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, int>>> graph(n + 1);
    while (m--) {
        int a, b, c;
        cin >> a >> b >> c;
        graph[a].push_back({b, c});
    }
    vector<bool> seen(n + 1, false);
    vector<long long> answer(n + 1, 0);
    queue<vector<int>> groups;
    groups.push({1});
    seen[1] = true;
    while (!groups.empty()) {
        vector<int> current = move(groups.front());
        groups.pop();
        vector<int> bucket[10];
        for (int u : current)
            for (auto [v, digit] : graph[u])
                if (!seen[v]) bucket[digit].push_back(v);
        for (int digit = 1; digit <= 9; ++digit) {
            vector<int> next;
            for (int v : bucket[digit]) {
                if (seen[v]) continue;
                // 必须在整组按末位排序后确认首次到达，不能按父顶点顺序抢占。
                seen[v] = true;
                answer[v] = (answer[current[0]] * 10 + digit) % MOD;
                next.push_back(v);
            }
            if (!next.empty()) groups.push(move(next));
        }
    }
    for (int v = 2; v <= n; ++v) cout << answer[v] << '\n';
}
```

### 易错点

必须收集完整组以后再按数字确认 `seen[v]`，不能扫描父顶点时就抢先标记。不同字符串即使取模相同，也不能合并成一组。
