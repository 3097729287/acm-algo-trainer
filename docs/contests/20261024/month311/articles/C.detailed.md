### 题意

需要找 $n$ 个非负整数，使它们的按位与为 $x$、按位或为 $y$、按位异或为 $z$。在全部合法方案中最大化乘积，最后才对 **998244853** 取模。$n$ 最大为 $10^{18}$，不能逐个创建这些数。

### 从零讲：按位约束和实现工具

二进制中，每一位权重为 1、2、4、8……。`a & b;` 对应“所有数都为 1”，`a | b;` 对应“至少一个数为 1”，多个数的 `a ^ b;` 对应“1 的个数为奇数”。不同位的这些约束可以分别检查；乘积则仍要根据构造出的完整整数计算。

`(value>>k)&1` 先右移再取末位，得到第 $k$ 位；`1ULL<<k` 使用 64 位无符号整数构造权重，避免从 32 位的字面量 1 开始移位。无符号数不会保存负数，本题只有确认该位为 1 的数才减去它的权重。

快速幂利用 $a^{2t}=(a^t)^2$。将指数从低位到高位读取，每轮底数平方；当前指数位为 1 就把底数乘进答案，再右移指数。只需 $O(\log n)$ 次模乘。模乘中的两个因子先约到模数以内，它们的乘积可由 64 位整数保存。

lambda 是可以保存在变量中的局部函数，例如 `auto f = [&](ull v) { product = product*v%MOD; };`。参数 $v$ 是值副本，捕获符 `[&](){ return product; }` 让函数引用外层 product，调用会修改原变量；`[=](){ return product; }` 会保存外层值的副本。按引用捕获时，外层对象必须在调用期间仍存活，因此不能返回一个引用已销毁局部变量的 lambda。本程序定义后立即在同一轮测试中使用，不把它保存到外部。

`std::sort(top,top+kept,std::greater<ull>())` 用降序比较器排序左闭右开范围，最多三个元素。`std::fread` 一次把最多一块字节读入缓冲区并返回实际读取数，读指针用完才补下一块，避免对上百万整数逐字符请求系统输入。快读类在文件结束时返回空字符，测试输入由题目保证完整。

### 思路

#### 固定位先判断，活动位只关心零的数量

$y$ 的某位为 0，说明全部数的这一位都必须为 0，所以 $x$、$z$ 也必须为 0。$x$ 的某位为 1，说明全部 $n$ 个数这一位都为 1，异或结果必须等于 $n$ 的奇偶性。

剩余的是 $y$ 为 1、$x$ 为 0 的可变位。让这一位有 $q$ 个 0，则既要有 0 也要有 1，故 $1\le q<n$；并要求 $(n-q)\bmod2=z_k$。

为了乘积大，可以尽量多放 1。若一个合法方案在这位有至少三个 0，把其中两个改成 1：仍至少保留一个 0，仍存在 1，1 的个数增加 2 不改变异或。两个整数变大、其他整数不变，乘积不会减小。因此只需选最小合法 $q$：$n$ 与 $z_k$ 奇偶不同取 1，相同取 2。

当 $n=1$ 时只能有 $x=y=z$；当 $n=2$ 时可变位必须恰好一个 1，故它在 $z$ 中也必须为 1。$n \ge 3$ 时 $q=1$、2 都不会达到 $n$，所有逐位条件也就充分。

#### 清零分给谁：减少当前较大的数

先让所有数等于 $y$，再按权重从大到小处理可变位。每位需要清零 $q$ 个不同的数，选择当前最大的 $q$ 个。

![样例的清零过程与每一步的实际整数](images/c-bits.svg)

样例 $n=3$、$x=2$、$y=7$、$z=6$：权重 2 的位由 $x$ 固定为 1；权重 4 的位需要两个 0，权重 1 的位需要一个 0。于是 $[7,7,7]\to[7,3,3]\to[6,3,3]$，乘积为 54。

证明时看一个相反安排：高位前缀较大的 A 保留本位 $w$，高位前缀较小的 B 清掉 $w$。二者高位部分至少相差 2w，低位最多抵消 $w-1$，再计入这一位的差，仍有 $A-B>w$。交换本位的 0 和 1 后，A 变成 $A-w$，B 变成 $B+w$，而

$$
(A-w)(B+w)-AB=w(A-B-w)>0.
$$

其他数非负，整体乘积不会下降。交换不会改变这一位中 1 的数量，也不改变其他位的约束。因此可以把每一位的 0 都挪给高位前缀最大的 $q$ 个数；高位前缀相同的数可交换身份，任选其中几个。由高到低依次确定，就得到最优构造。

#### 压缩到三个修改过的数

最多 60 个可变位，每位只改一两个数，但 $n$ 可能巨大。首先用计数 rest 保存从未被改动的 $y$，不展开它们。只要 rest 足够，当前这位就直接选其中 $q$ 个，得到 $q$ 个新值 $y-w$。

对修改过的数，观察它第一次清零的那一位。第一次清零权重较大的数，在更高位已经落后，未来低位怎么变化都追不上第一次清零权重较小的数。每一位最多首次改动两个数，因此每个“首次清零位”组最多两个成员，组之间的大小次序永久固定。

未来最多同时选两个修改过的数。如果最大的组有两人，它已经够选；如果最大的组只有一人，就还需要第二组，第二组至多两人。总共保留三个数便足够，排在它们之后的数再也不会被选。

不能再压成两个：$n=3$、$x=0$、$y=7$、$z=7$ 时，每个位都要清两个数。中间会出现 $[5,3,1]$，继续正确选择得到 $[4,2,1]$；若过早把一个与候选并列的数冻结，后续会选错人。因此代码保留前三名，每次更改后重排；被挤出前三名的数才乘入 product。

#### 三种更新与最后的乘积

rest 至少为 $q$ 时，取 $q$ 个 $y$，各减 $w$ 后插入候选；rest=1 且 $q=2$ 时，取最后一个 $y$ 与候选中的最大值；rest=0 时，直接减候选中的前 $q$ 个数。每位中的选择要同时基于修改前的排名。

最终答案是已冻结数的乘积、候选数的乘积与 $y^{rest}$ 的乘积，运算时不断取模。最大化已由贪心完成，取模只在最后的数值累积中使用。每位操作常数个候选，加上快速幂，总时间 $O(60+\log n)$，额外空间 $O(1)$。

### 易错点

模数末三位是 853。不要以余数大小判断哪种构造乘积更大；不要在同一位减少第一个数后立即重排，再选第二个，那可能把同一个数选两次。
