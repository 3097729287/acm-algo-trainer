# 原站适配层

## 1.1.3 只读记录补齐

`site_receipts.py` 在配置账号范围内核对实际回执；牛客使用原站页面采用的公开 `rank/submit-list`，落盘前过滤成本人记录。AtCoder 使用 AtCoder Problems 的用户提交接口；洛谷只读取公开记录页，拒绝访问时保留已有证据。读取窗口和失败行为见 [使用说明](usage.md#113-使用变化)。原站提交仍走可见原生表单，没有新增代交通道。

v1.1.1 将提交执行集中到本机可见浏览器连接 `desktop/external_browser.py`。工作台与后端只传递用户主动创建的题目、代码和一次提交意图，适配层负责打开原站表单、选择语言、填代码、等待原站允许的按钮并跟踪回执。平台脚本位于 `official_page.js`、`official_languages.js`、`official_nowcoder.js`、`official_luogu.js`。

这是一层本机适配接口：共享服务器不代理原站提交、不保存原站 Cookie。当前交付支持 Codeforces、AtCoder、牛客、洛谷，未实现任意在线插件市场或自动下载执行第三方插件。后续接入平台应增加显式域名与题目地址校验、登录和验证状态、原生表单选择器、仅绑定本次提交的结果解析，以及完全隔离的浏览器回归；不靠通用“提交”按钮扫描接入任意站点。

浏览器输送与页面解析分开维护，平台页面变化只需调整相应适配脚本。网站登录、CSRF、验证码及原生提交行为继续由网站管理。中间层能减少重复维护和服务端持有凭据的范围，不能自动消除 ToS 或题面、图片和题解的版权约束。程序代码许可与各来源内容的权利分别看待；不要把代码的 MIT 许可解释为原站内容授权。
