## P11231 决斗

原题：[P11231](https://www.luogu.com.cn/problem/P11231)

### 从问题到算法

每个怪兽最多打倒一个更弱者，因此成功攻击构成若干互不相交的链，沿链攻击力严格递增，最终每条链至少留一个怪兽。相同攻击力的怪兽不能出现在同一条严格递增链上，所以若某值出现 c 次，最终至少需要 c 条链。

把所有怪兽按攻击力排序，设最大频数为 C。对每一种攻击力，把它的各个副本分配给不同的 C 条链；同一条链只会拿到同值的一个副本，不同批次值递增，因此链均严格递增。这样确实能用 C 条链覆盖全部怪兽。

每条链从小到大安排攻击：最小者先作一次无效攻击，之后每个更强者打倒前一个，最后只剩最大者。由下界与构造，上述最大频数就是最优答案。实现只需计数，无需输出攻击顺序。

### 复杂度

时间 O(n+A)，空间 O(A)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> count(100001);
    int ans = 0;
    while (n--) {
        int x;
        cin >> x;
        ans = max(ans, ++count[x]);
    }
    cout << ans << '\n';

    return 0;
}
```

### 实现提醒

攻击必须严格更强才能击败；统计频数最大值即可。
