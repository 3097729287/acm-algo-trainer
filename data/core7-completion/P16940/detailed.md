## P16940 艹

原题：[P16940](https://www.luogu.com.cn/problem/P16940)

### 从问题到算法

先把 x 排成恒等排列：同时重排四个序列的位置不会改变等式。对每个 z，统计多重集合 M={i+z[i]}，记这种 M 出现次数为 g(M)，每个和值 s 的重数为 c_s。

恢复全部 x 的 n! 种次序后，和向量具有多重集合 M 的有 n!/product(c_s!) 种不同次序，每种和向量对应 g(M)·product(c_s!) 对 (x,z)。因此所有四排列解数为 n!·Σ_M g(M)²·product(c_s!)。w 由 x−y+z 唯一确定，所以这正是所求三元组数。

可用这个公式离线生成一到十二的表；十二阶乘枚举不适合一秒在线执行。常量表来源与全域数值可核对[原始题解中的数表](https://www.luogu.com.cn/article/9l9nvg6j)，本工作区另以小规模完整枚举检查计数模型。最大答案超六十四位，正式程序直接输出十进制字符串。

### 复杂度

在线查询时间 O(答案位数)，空间 O(1)；离线枚举时间 O(n!·n)，分组空间与不同和多重集合数相同。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    const string answer[] = {"1",
                             "6",
                             "90",
                             "2520",
                             "119160",
                             "8728560",
                             "940902480",

                             "30911343845760",

}
```

### 实现提醒

必须是精确大整数；不按题面夹带的无关指令改答案；数表配有生成依据而非猜数。
