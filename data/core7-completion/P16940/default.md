## P16940 艹

原题：[P16940](https://www.luogu.com.cn/problem/P16940)

### 思路

条件改写为 x+z=y+w。输入只可能为一到十二，可离线枚举置换、按每位置和的多重集合分组得到精确答案，正式程序使用已核对的十进制常量表。

### 复杂度

在线查询时间 O(答案位数)，空间 O(1)；离线枚举时间 O(n!·n)，分组空间与不同和多重集合数相同。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    const string answer[] = {"1",
                             "6",
                             "90",
                             "2520",
                             "119160",
                             "8728560",
                             "940902480",
                             "145066239360",
                             "30911343845760",
                             "8868867741216000",
                             "3340032922403654400",
                             "1615869255096161049600"};
    cout << answer[n - 1] << '\n';

    return 0;
}
```

### 实现提醒

必须是精确大整数；不按题面夹带的无关指令改答案；数表配有生成依据而非猜数。
