## 智乃酱的cube

### 题意

立方体各边初始一，支持某维度区间增加，并查询体积总和。

### 思路

只维护 xyz 不够，因为给 x 加 a 时，体积增加 a*yz。于是对每个节点保存八种乘积的和：1、x、y、xy、z、xz、yz、xyz，其中一的和就是区间长度。用三位掩码表示是否含 x、y、z。给某维 d 增加 a 时，每个包含 d 的乘积 sum[mask] 增加 a*sum[mask 去掉 d]，不含 d 的量保持不变。右边的量本次没有被修改，所以可直接逐项更新。

三个懒标记分别累计三个维度的增加量，推给儿子时依次应用即可；不同时段修改的交叉项会随着 xy、xz、yz 的维护自然产生。初始化所有边为一，所以八项和最初都等于节点长度。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct CubeTree {
    static const long long mod = 1000000007;
    struct Node {
        array<long long, 8> sum{};
        array<long long, 3> lazy{};
    };
    int n;
    vector<Node> tree;
    explicit CubeTree(int count) : n(count), tree(4 * count + 4) { build(1, 1, n); }
    void build(int p, int l, int r) {
        tree[p].sum.fill(r - l + 1);
        if (l == r)
            return;
        int mid = (l + r) / 2;
        build(p * 2, l, mid);
        build(p * 2 + 1, mid + 1, r);
    }
    void apply(int p, int axis, long long value) {
        for (int mask = 1; mask < 8; mask++)
            if (mask >> axis & 1)
                tree[p].sum[mask] =
                    (tree[p].sum[mask] + value * tree[p].sum[mask ^ (1 << axis)]) % mod;
        tree[p].lazy[axis] = (tree[p].lazy[axis] + value) % mod;
    }
    void push(int p) {
        for (int axis = 0; axis < 3; axis++)
            if (tree[p].lazy[axis]) {
                apply(p * 2, axis, tree[p].lazy[axis]);
                apply(p * 2 + 1, axis, tree[p].lazy[axis]);
                tree[p].lazy[axis] = 0;
            }
    }
    void change(int p, int l, int r, int ql, int qr, int axis, long long value) {
        if (ql <= l && r <= qr) {
            apply(p, axis, value);
            return;
        }
        push(p);
        int mid = (l + r) / 2;
        if (ql <= mid)
            change(p * 2, l, mid, ql, qr, axis, value);
        if (qr > mid)
            change(p * 2 + 1, mid + 1, r, ql, qr, axis, value);
        for (int mask = 0; mask < 8; mask++)
            tree[p].sum[mask] = (tree[p * 2].sum[mask] + tree[p * 2 + 1].sum[mask]) % mod;
    }
    long long query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr)
            return tree[p].sum[7];
        push(p);
        int mid = (l + r) / 2;
        long long answer = 0;
        if (ql <= mid)
            answer += query(p * 2, l, mid, ql, qr);
        if (qr > mid)
            answer += query(p * 2 + 1, mid + 1, r, ql, qr);
        return answer % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    CubeTree tree(n);
    while (m--) {
        char op;
        int l, r;
        cin >> op >> l >> r;
        if (op == 'q')
            cout << tree.query(1, 1, n, l, r) << '\n';
        else {
            long long value;
            cin >> value;
            int axis = op == 'x' ? 0 : op == 'y' ? 1 : 2;
            tree.change(1, 1, n, l, r, axis, value % CubeTree::mod);
        }
    }
    return 0;
}
```

### 复杂度

每个操作 $O(8\log n)$，空间 $O(8n)$。

### 易错点

区间长度是 sum[0]，不是零。连续修改不同维度时必须维护低阶乘积，否则会漏掉交叉项。
