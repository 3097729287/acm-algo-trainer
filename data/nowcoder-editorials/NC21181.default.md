## 重返小学

### 题意

按指定优先级与同级从左到右规则，计算带阶乘和乘方的表达式，每一步采用 C++ 的模六万五千五百三十六余数。

### 思路

把后缀阶乘在读到数字时立刻计算，再用数值栈与运算符栈处理二元运算。读到新运算符时，先弹出所有优先级不低于它的旧运算符，保证乘方在本题也左结合。每次运算立即取模；除数为零则本组输出 ArithmeticException。阶乘的参数达到十八时，结果含至少十六个因子二，模 65536 为零，可直接返回零，避免重复阶乘产生长循环。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 65536;
    int t;
    cin >> t;
    auto precedence = [](char op) {
        if (op == '+' || op == '-')
            return 1;
        if (op == '*' || op == '/')
            return 2;
        return 3;
    };
    auto power = [&](long long a, long long b) {
        long long result = 1;
        while (b > 0) {
            if (b & 1)
                result = result * a % mod;
            a = a * a % mod;
            b >>= 1;
        }
        return result;
    };
    auto factorial = [&](long long x) {
        if (x >= 18)
            return 0LL;
        long long result = 1;
        for (long long i = 2; i <= x; i++)
            result = result * i % mod;
        return result;
    };
    while (t--) {
        string s;
        cin >> s;
        vector<long long> values;
        vector<char> operators;
        bool bad = false;
        auto apply = [&]() {
            long long b = values.back();
            values.pop_back();
            long long a = values.back();
            values.pop_back();
            char op = operators.back();
            operators.pop_back();
            long long result = 0;
            if (!bad) {
                if (op == '+')
                    result = a + b;
                else if (op == '-')
                    result = a - b;
                else if (op == '*')
                    result = a * b;
                else if (op == '/') {
                    if (b == 0)
                        bad = true;
                    else
                        result = a / b;
                } else
                    result = power(a, b);
            }
            values.push_back(result % mod);
        };
        for (size_t i = 0; i < s.size();) {
            if (isdigit(static_cast<unsigned char>(s[i]))) {
                long long value = s[i++] - '0';
                while (i < s.size() && s[i] == '!') {
                    value = factorial(value);
                    i++;
                }
                values.push_back(value);
            } else {
                char op = s[i++];
                while (!operators.empty() && precedence(operators.back()) >= precedence(op))
                    apply();
                operators.push_back(op);
            }
        }
        while (!operators.empty())
            apply();
        if (bad)
            cout << "ArithmeticException\n";
        else
            cout << values.back() << '\n';
    }
    return 0;
}
```

### 复杂度

表达式长为 $L$，栈操作总量 $O(L)$；每次乘方最多十六次位循环，故固定模数下总时间 $O(L)$，空间 $O(L)$。

### 易错点

本题明确规定乘方同级从左往右，与某些语言的幂运算规则不同。负余数保留 C++ 语义，不要擅自加模数转正；零的零次方为一。
