## 新建 Microsoft Office Word 文档

### 题意

新建时取最小空闲正编号；删除时判断文件是否存在。

### 思路

将1到n都放入小根堆，表示空闲编号；至多n次新建，故这些编号足够。新建取堆顶并标记存在；成功删除时取消标记并将编号放回堆。删除不存在的文件不能放回编号，否则会重复分配。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    priority_queue<int, vector<int>, greater<int>> available;
    vector<bool> exists(n + 1);
    for (int i = 1; i <= n; i++)
        available.push(i);
    while (n--) {
        string op;
        cin >> op;
        if (op == "New") {
            int id = available.top();
            available.pop();
            exists[id] = true;
            cout << id << '\n';
        } else {
            int id;
            cin >> id;
            if (id > 0 && id < (int)exists.size() && exists[id]) {
                exists[id] = false;
                available.push(id);
                cout << "Successful\n";
            } else
                cout << "Failed\n";
        }
    }
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

删除编号可能超过实际创建过的最大编号，需要先检查数组范围。只有成功删除才回收。
