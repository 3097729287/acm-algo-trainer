## [SDOI2008]仪仗队

### 题意

从方阵左下角观察，求不被同一直线上前方同学挡住的人数。

### 思路

以观察角为(0,0)，其余坐标0到N−1。正坐标点(x,y)可见当且仅当gcd(x,y)=1；否则沿同一射线先看到约去gcd后的格点。对x>y≥1按x分组，数量为phi(x)，关于对角线对称乘二；再加(1,1)及两个坐标轴上的首点。等价写成1+2*Σ(i=1..N−1)phi(i)。N=1没有其他人，答案0。用筛法初始化phi[i]=i，每个素数p对其倍数更新phi=phi/p*(p−1)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    if (n == 1) {
        cout << 0;
        return 0;
    }
    vector<int> phi(n);
    iota(phi.begin(), phi.end(), 0);
    for (int p = 2; p < n; p++)
        if (phi[p] == p)
            for (int x = p; x < n; x += p)
                phi[x] = phi[x] / p * (p - 1);
    long long answer = 1;
    for (int i = 1; i < n; i++)
        answer += 2LL * phi[i];
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(N\log\log N)$，空间 $O(N)$。

### 易错点

实际坐标最大是N−1，不能把phi[N]也累加。phi[1]=1，已经把两条坐标轴的首个可见点计入公式。
