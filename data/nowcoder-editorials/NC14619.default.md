## 栗酱的异或和

### 题意

第一步必须从第k堆取，是否存在必胜取法。

### 思路

总异或X非0时，获胜首步必须把总异或变0。若改第k堆a，则新值唯一为a xor X；它必须严格小于a，才可通过取走正数实现。只检查这个不等式，不是问整个局面是否先手胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, k;
        cin >> n >> k;
        int total = 0, chosen = 0;
        for (int i = 1; i <= n; i++) {
            int a;
            cin >> a;
            total ^= a;
            if (i == k)
                chosen = a;
        }
        cout << ((chosen ^ total) < chosen ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n)$，空间 $O(1)$。

### 易错点

X=0时新值等于原值，不允许不取，所以输出No。
