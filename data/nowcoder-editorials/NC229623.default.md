## Mike and Foam

### 题意

动态切换啤酒是否在架，统计互素无序对数。

### 思路

维护count[d]为架上a的d倍数个数。加入x时新增互素对数=Σ(d|x)mu(d)*count[d]，再把这些count[d]加1；移除时先减1，再减去相同表达式，避免把自身计入。只枚举x的不同质因子子集，得到所有无平方因子约数和mu符号；a≤500000最多6种不同质因子，每次至多64项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    const int limit = 500000;
    vector<int> smallest(limit + 1);
    for (int p = 2; p <= limit; p++)
        if (!smallest[p])
            for (int x = p; x <= limit; x += p)
                if (!smallest[x])
                    smallest[x] = p;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    vector<bool> active(n);
    vector<int> count(limit + 1);
    long long answer = 0;
    while (q--) {
        int id;
        cin >> id;
        id--;
        int x = a[id];
        vector<int> primes;
        while (x > 1) {
            int p = smallest[x];
            primes.push_back(p);
            while (x % p == 0)
                x /= p;
        }
        vector<pair<int, int>> divisor = {{1, 1}};
        for (int p : primes) {
            int size = divisor.size();
            for (int i = 0; i < size; i++)
                divisor.push_back({divisor[i].first * p, -divisor[i].second});
        }
        if (active[id])
            for (auto [d, mu] : divisor)
                count[d]--;
        long long change = 0;
        for (auto [d, mu] : divisor)
            change += 1LL * mu * count[d];
        if (active[id])
            answer -= change;
        else {
            answer += change;
            for (auto [d, mu] : divisor)
                count[d]++;
        }
        active[id] = !active[id];
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(U\log\log U)$，每次 $O(\log U+2^{\omega(x)})$，空间 $O(U+n)$。

### 易错点

切换按啤酒编号而非泡沫值；同值不同啤酒仍是不同元素。x=1只有约数1，可与所有已有元素配对。
