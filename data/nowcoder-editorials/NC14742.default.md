## 栗酱和火柴

### 题意

按题面七段数码图，分别统计每个数字的水平与竖直火柴数。

### 思路

图中只有七种固定段位，逐个数字核对后保存两张表：水平数为 2,0,3,3,1,3,3,1,3,3；竖直数为 4,2,2,2,3,2,3,2,4,3。查询时直接按数字下标取两项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int horizontal[] = {2, 0, 3, 3, 1, 3, 3, 1, 3, 3};
    int vertical[] = {4, 2, 2, 2, 3, 2, 3, 2, 4, 3};
    int t;
    cin >> t;
    while (t--) {
        char c;
        cin >> c;
        int x = c - '0';
        cout << horizontal[x] << ' ' << vertical[x] << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间与额外空间均为 $O(1)$。

### 易错点

零的上下各一根水平火柴、左右各两根竖直火柴。按原图计算，不按手写字体猜测。
