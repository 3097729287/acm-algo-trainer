## 明七暗七

### 题意

求严格大于m的第n个7倍数或含7的数字。

### 思路

用数位DP统计F(x)：值模7、此前是否出现7，结束满足余数0或出现7。整数0也满足倍数判定，但F(x)−F(m)会抵消。答案最小x使F(x)−F(m)≥n。以m+7n为二分上界，因为这段至少含n个7倍数；每次只需前缀计数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long memo[20][7][2];
    memset(memo, -1, sizeof(memo));
    auto count = [&](long long bound) {
        string s = to_string(bound);
        auto dfs = [&](auto &&self, int p, int remainder, bool has7, bool tight) -> long long {
            if (p == (int)s.size())
                return remainder == 0 || has7;
            long long &cache = memo[s.size() - p][remainder][has7];
            if (!tight && cache != -1)
                return cache;
            int maximum = tight ? s[p] - '0' : 9;
            long long result = 0;
            for (int d = 0; d <= maximum; d++)
                result += self(self, p + 1, (remainder * 10 + d) % 7, has7 || d == 7,
                               tight && d == maximum);
            if (!tight)
                cache = result;
            return result;
        };
        return dfs(dfs, 0, 0, false, true);
    };
    long long m, n;
    cin >> m >> n;
    long long before = count(m), low = m + 1, high = m + 7 * n;
    while (low < high) {
        long long mid = low + (high - low) / 2;
        if (count(mid) - before >= n)
            high = mid;
        else
            low = mid + 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

缓存 $O(D\cdot14\cdot10)$；二分 $O(D\log n)$ 次常数规模数位分支，空间 $O(14D)$。

### 易错点

“m以后”严格排除m。倍数与含7取并集，不能重复计数。
