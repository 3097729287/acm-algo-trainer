## 得不到的爱情

### 题意

N、M 互素，求不能表示为两个数的非负整数倍之和的最大整数。

### 思路

答案为 NM-N-M。先证它不能表示：若 NM-N-M=aN+bM，则 NM=(a+1)N+(b+1)M。模 M 可知 a+1 是 M 的正倍数，右侧便严格大于 NM，矛盾。再看任意 x>NM-N-M：在 0,M,…,(N-1)M 中恰有一个与 x 模 N 同余，记作 bM。于是 x-bM 是 N 的倍数且大于 -N，只能非负，故可以表示。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, m;
    cin >> n >> m;
    cout << n * m - n - m;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

互素是结论成立的前提；允许某种食材使用零个。乘积最高二十五亿，要使用 long long。
