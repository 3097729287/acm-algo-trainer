## 分数游戏

### 题意

双方每轮各加[-k,k]整数，统计t轮后先手分数更高的游戏数。

### 思路

L的每次增量取负后仍均匀遍历[-k,k]，所以M减L的总增量可视为2t个独立[-k,k]整数之和。每个数加k变成[0,2k]，若和为s，最终差为a−b+s−2kt，要求s>b−a+2kt。

DP统计2t个[0,2k]整数的和。每层新dp[s]为旧dp[s−2k..s]之和，用滑动窗口O(1)更新每个s。最后把满足严格不等式的和状态相加。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, k, t;
    cin >> a >> b >> k >> t;
    const int mod = 1000000007;
    vector<int> dp(1, 1);
    for (int step = 0; step < 2 * t; step++) {
        int old = dp.size() - 1;
        vector<int> next(old + 2 * k + 1);
        long long sum = 0;
        for (int s = 0; s < (int)next.size(); s++) {
            if (s <= old)
                sum += dp[s];
            int remove = s - 2 * k - 1;
            if (remove >= 0 && remove <= old)
                sum -= dp[remove];
            sum = (sum % mod + mod) % mod;
            next[s] = sum;
        }
        dp.swap(next);
    }
    int threshold = b - a + 2 * k * t;
    long long answer = 0;
    for (int s = max(0, threshold + 1); s < (int)dp.size(); s++)
        answer = (answer + dp[s]) % mod;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(kt^2)$，空间 $O(kt)$。

### 易错点

胜利要求严格大于，平分不能计入。每一轮每个人的取值独立，转换后仍需2t个变量。
