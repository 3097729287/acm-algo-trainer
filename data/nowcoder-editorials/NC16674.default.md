## [NOIP2003]乒乓球

### 题意

对同一份逐球记录，分别计算十一分制和二十一分制比分。

### 思路

先读取到 E 为止并保存 W、L。对每种目标分重放一次：加分后若最高分已达到目标且双方相差至少二，就输出本局并清零。重放结束后仍要输出当前局，即使刚好清零也输出 0:0。两种计分之间空一行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string record;
    char ch;
    while (cin >> ch && ch != 'E')
        record += ch;
    auto score = [&](int target) {
        int a = 0, b = 0;
        for (char c : record) {
            if (c == 'W')
                a++;
            else
                b++;
            if (max(a, b) >= target && abs(a - b) >= 2) {
                cout << a << ':' << b << '\n';
                a = b = 0;
            }
        }
        cout << a << ':' << b << '\n';
    };
    score(11);
    cout << '\n';
    score(21);
    return 0;
}
```

### 复杂度

时间与记录空间均为 $O(L)$。

### 易错点

达到十一或二十一不一定结束，平分后必须净胜两分。忽略 E 后面的全部内容。
