## 智乃酱的平方数列

### 题意

区间依次加一、四、九等平方数，并查询区间和模 10^9+7。

### 思路

一次 [l,r] 修改给位置 i 加 (i-l+1)²，展开为 Ai²+Bi+C，其中 A=1、B=2(1-l)、C=(1-l)²。令 F(t)=A*t(t+1)(2t+1)/6+B*t(t+1)/2+C*t，则更新对前缀和的贡献在 l<=x<=r 时为 F(x)-F(l-1)，x>r 时为常数 F(r)-F(l-1)。

用四棵树状数组维护前缀函数的四个系数：在 l 加 (A,B,C,-F(l-1))，在 r+1 加 (-A,-B,-C,F(r))。查询 x 时取四个系数前缀和，代入平方和、自然数和、x、常数一，即得整个数组的前缀和；相减得到区间和。模数为固定奇素数，可使用二和六的逆元。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 1000000007;
    int n, m;
    cin >> n >> m;
    vector<array<long long, 4>> tree(n + 1);
    auto first = [&](long long x) { return x * (x + 1) % mod * 500000004 % mod; };
    auto second = [&](long long x) {
        return x * (x + 1) % mod * (2 * x + 1) % mod * 166666668 % mod;
    };
    auto mark = [&](int p, array<long long, 4> values) {
        for (int i = p; i <= n; i += i & -i)
            for (int k = 0; k < 4; k++) {
                tree[i][k] += values[k];
                if (tree[i][k] >= mod)
                    tree[i][k] -= mod;
            }
    };
    auto prefix = [&](int p) {
        array<long long, 4> coefficient{};
        for (int i = p; i > 0; i -= i & -i)
            for (int k = 0; k < 4; k++) {
                coefficient[k] += tree[i][k];
                if (coefficient[k] >= mod)
                    coefficient[k] -= mod;
            }
        return (coefficient[0] * second(p) + coefficient[1] * first(p) + coefficient[2] * p +
                coefficient[3]) %
               mod;
    };
    while (m--) {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 2)
            cout << (prefix(r) - prefix(l - 1) + mod) % mod << '\n';
        else {
            long long b = (2LL * (1 - l) % mod + mod) % mod, c = (1LL - l) * (1LL - l) % mod;
            auto f = [&](int x) { return (second(x) + b * first(x) + c * x) % mod; };
            mark(l, {1, b, c, (mod - f(l - 1)) % mod});
            mark(r + 1, {mod - 1, (mod - b) % mod, (mod - c) % mod, f(r)});
        }
    }
    return 0;
}
```

### 复杂度

每个操作 $O(\log n)$，空间 $O(n)$。

### 易错点

平方从修改左端重新计为一，不是直接给位置 i 加 i²。右端取消标记在 r+1。所有负系数先规范到模数范围。
