## 统计颜色

### 题意

区间每桶加入某色球，询问范围内不同颜色数。

### 思路

颜色0..60用64位掩码。加入颜色c相当于区间每桶掩码OR上1ULL<<c，节点统计整段颜色并集也OR该位，懒标记用OR合并。部分访问时下传标记，查询将所有命中段的并集OR起来，popcount得到颜色数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    while (cin >> n >> m) {
        vector<unsigned long long> value(4 * n + 4), tag(4 * n + 4);
        auto apply = [&](int u, unsigned long long mask) {
            value[u] |= mask;
            tag[u] |= mask;
        };
        auto push = [&](int u) {
            if (tag[u]) {
                apply(u * 2, tag[u]);
                apply(u * 2 + 1, tag[u]);
                tag[u] = 0;
            }
        };
        auto update = [&](auto &&self, int u, int l, int r, int ql, int qr,
                          unsigned long long mask) -> void {
            if (ql <= l && r <= qr) {
                apply(u, mask);
                return;
            }
            push(u);
            int mid = (l + r) / 2;
            if (ql <= mid)
                self(self, u * 2, l, mid, ql, qr, mask);
            if (qr > mid)
                self(self, u * 2 + 1, mid + 1, r, ql, qr, mask);
            value[u] = value[u * 2] | value[u * 2 + 1];
        };
        auto query = [&](auto &&self, int u, int l, int r, int ql, int qr) -> unsigned long long {
            if (ql <= l && r <= qr)
                return value[u];
            push(u);
            int mid = (l + r) / 2;
            unsigned long long answer = 0;
            if (ql <= mid)
                answer |= self(self, u * 2, l, mid, ql, qr);
            if (qr > mid)
                answer |= self(self, u * 2 + 1, mid + 1, r, ql, qr);
            return answer;
        };
        while (m--) {
            int op, l, r;
            cin >> op >> l >> r;
            if (op == 1) {
                int c;
                cin >> c;
                update(update, 1, 1, n, l, r, 1ULL << c);
            } else
                cout << __builtin_popcountll(query(query, 1, 1, n, l, r)) << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每组时间 $O(m\log n)$，空间 $O(n)$。

### 易错点

操作是增加颜色，不是覆盖桶的旧颜色；懒标记应OR累积。颜色0用第0位。
