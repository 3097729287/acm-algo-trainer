## [NOIP2008]传球游戏

### 题意

圆圈里每次传给左或右邻居，恰传m次回到起点的方案数。

### 思路

dp[t][p]表示传t次后在p的方案数，每一步从左右邻居的上一步方案相加。初始dp[0][0]=1。位置用模n处理，两数组滚动，做满m轮后输出起点。n至少3，左右邻居不同。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> dp(n), next(n);
    dp[0] = 1;
    for (int t = 0; t < m; t++) {
        for (int p = 0; p < n; p++)
            next[p] = dp[(p + n - 1) % n] + dp[(p + 1) % n];
        dp.swap(next);
    }
    cout << dp[0];
    return 0;
}
```

### 复杂度

时间 $O(nm)$，空间 $O(n)$。

### 易错点

每轮从上一轮同时转移，不可直接原地更新。恰好传m次，不能把提前回到起点的方案单独累加。
