## Christmas Game

### 题意

每次向k级祖先移动任意多石子，对全部树根判胜负。

### 思路

固定根时，把深度按长度k分块。仅奇数块（floor(depth/k)为奇数）的石子堆参与Nim异或：每次上移k层恰在奇偶块之间转移，0异或局面任何移动都会改变一个被计入堆；非0时可从某奇块堆减到令异或为0的大小，再把取出的石子移入偶块，因此判定成立。

只需知道距离模2k，令down[u][r]为u子树中距离u模2k等于r的a异或。后序将儿子余数整体+1合并。换根到儿子v时，先从u的全树余数表中异或去v子树贡献，再把其余部分距离+1并入v。每个根取余数k..2k−1的异或。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct EulerTree {
    int n;
    vector<vector<int>> edge;
    vector<int> parent, depth, in, out, order;
    EulerTree(int n) : n(n), edge(n + 1), parent(n + 1), depth(n + 1), in(n + 1), out(n + 1) {}
    void add(int u, int v) {
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    void root(int start) {
        vector<int> stack = {start};
        parent[start] = 0;
        order.clear();
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            in[u] = order.size() + 1;
            order.push_back(u);
            for (int v : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    depth[v] = depth[u] + 1;
                    stack.push_back(v);
                }
        }
        vector<int> size(n + 1, 1);
        for (int i = (int)order.size() - 1; i >= 0; i--) {
            int u = order[i];
            out[u] = in[u] + size[u] - 1;
            if (parent[u])
                size[parent[u]] += size[u];
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    EulerTree tree(n);
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        tree.add(u, v);
    }
    int period = 2 * k;
    vector<vector<int>> dp(n + 1, vector<int>(period));
    for (int u = 1; u <= n; u++)
        cin >> dp[u][0];
    tree.root(1);
    for (int i = n - 1; i > 0; i--) {
        int u = tree.order[i], p = tree.parent[u];
        for (int r = 0; r < period; r++)
            dp[p][(r + 1) % period] ^= dp[u][r];
    }
    vector<int> answer(n + 1);
    for (int u : tree.order) {
        int value = 0;
        for (int r = k; r < period; r++)
            value ^= dp[u][r];
        answer[u] = value != 0;
        for (int v : tree.edge[u])
            if (tree.parent[v] == u) {
                auto old = dp[v];
                for (int r = 0; r < period; r++)
                    dp[v][r] =
                        old[r] ^ dp[u][(r - 1 + period) % period] ^ old[(r - 2 + period) % period];
            }
    }
    for (int u = 1; u <= n; u++)
        cout << answer[u] << (u == n ? '\n' : ' ');
    return 0;
}
```

### 复杂度

时间、空间均 $O(nk)$。

### 易错点

参与的是距离模2k落在后半段，不是距离模k。换根计算需保存儿子旧子树表，不能边覆盖边读取。
