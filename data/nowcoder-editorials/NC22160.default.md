## 牛牛学数列5

### 题意

求首两项为一的斐波那契数列第 n 项。

### 思路

用 a、b 保存相邻两项，从第三项起令 next=a+b，再同步前移。n=1 或二时循环不执行，输出一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long a = 1, b = 1;
    for (int i = 3; i <= n; i++) {
        long long next = a + b;
        a = b;
        b = next;
    }
    cout << b;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

更新 b 前先保存两项的和，否则容易误用已经更新的 a。
