## 队伍配置

### 题意

最多选五名从者，礼装数量不能超过从者数量，总cost受限，最大化总攻击。

### 思路

从者和礼装之间没有指定兼容性，只要求一名从者最多配一礼装，故分别做“选择数量、恰好cost”的01背包。两边数量都只需0到5。最后枚举从者数s、礼装数e≤s及两边cost，总cost≤d时合并攻击值取最大。礼装能任意分给所选从者，因此数量约束已经充分，不必记录实际配对。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, budget;
    cin >> n >> m >> budget;
    const int neg = -1000000000;
    auto build = [&](int items) {
        vector<vector<int>> dp(6, vector<int>(budget + 1, neg));
        dp[0][0] = 0;
        while (items--) {
            int attack, cost;
            cin >> attack >> cost;
            for (int count = 5; count >= 1; count--)
                for (int b = budget; b >= cost; b--)
                    if (dp[count - 1][b - cost] != neg)
                        dp[count][b] = max(dp[count][b], dp[count - 1][b - cost] + attack);
        }
        return dp;
    };
    auto servant = build(n), equipment = build(m);
    int answer = 0;
    for (int s = 1; s <= 5; s++)
        for (int e = 0; e <= s; e++)
            for (int a = 0; a <= budget; a++)
                if (servant[s][a] != neg)
                    for (int b = 0; a + b <= budget; b++)
                        if (equipment[e][b] != neg)
                            answer = max(answer, servant[s][a] + equipment[e][b]);
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(5(n+m)d+25d^2)$，空间 $O(5d)$。

### 易错点

不可单独上礼装，也不要求每个从者都穿礼装。数量和预算两维均倒序，保证物品各用一次。
