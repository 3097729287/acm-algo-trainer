## 点名：easy

### 题意

一到 n 中恰有一个学生缺席，找出他的学号。

### 思路

完整学号总和为 n(n+1)/2。逐个减去到场的 n-1 个不同学号，最后剩下的就是缺席学号。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    long long answer = n * (n + 1) / 2;
    for (int i = 0; i < n - 1; i++) {
        int x;
        cin >> x;
        answer -= x;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

总和超过 int，用 long long 计算乘法。n=1 时没有到场学号，直接输出一。
