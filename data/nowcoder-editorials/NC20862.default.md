## 救救企鹅

### 题意

从左到右把原文本中的A替换为B，替换结果不再参与匹配。

### 思路

对A求前缀函数，在原S上做KMP。每当匹配出完整A，输出上一次已处理末尾到本次匹配开头的原文，再输出B；将已处理位置移到此次匹配末尾之后，并把当前匹配长度清0。清0确保重叠在刚消耗A内部的出现不再使用。全部扫描完后输出剩余尾部。新输出的B从未送入匹配过程，所以不会递归替换。输出分段流式写，避免把可能远长于输入的结果整体放入内存。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

template <class Sequence> vector<int> prefixFunction(const Sequence &s) {
    int n = s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])
            j = pi[j - 1];
        if (s[i] == s[j])
            j++;
        pi[i] = j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s, a, b;
    cin >> s >> a >> b;
    auto pi = prefixFunction(a);
    int matched = 0;
    size_t written = 0;
    for (size_t i = 0; i < s.size(); i++) {
        while (matched && s[i] != a[matched])
            matched = pi[matched - 1];
        if (s[i] == a[matched])
            matched++;
        if (matched == (int)a.size()) {
            size_t begin = i + 1 - a.size();
            cout.write(s.data() + written, begin - written);
            cout << b;
            written = i + 1;
            matched = 0;
        }
    }
    cout.write(s.data() + written, s.size() - written);
    return 0;
}
```

### 复杂度

输入总长 $L$、输出长 $R$，时间 $O(L+R)$，空间 $O(L)$。

### 易错点

按左到右不重叠替换，不能把产生的新字符再扫入KMP。若B很长，实际输出时间必须计入复杂度。
