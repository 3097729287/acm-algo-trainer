## Happy Running

### 题意

从随机起点顺时针依次打两个随机点，求总路程至少k的概率。

### 思路

以起点为0，两个打卡点距离为独立均匀变量u、v∈(0,x)。若u<v，路程为v；否则先走到u再绕圈到v，路程为x+v。在正方形(u,v)中按v积分：k≤x时，不达标区域面积为k²/2，概率1−k²/(2x²)；x<k<2x时，达标区域面积为(2x−k)²/2，概率为该面积除x²；k≥2x为0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    cout << fixed << setprecision(2);
    while (tests--) {
        long double k, x;
        cin >> k >> x;
        long double answer;
        if (k <= x)
            answer = 1 - k * k / (2 * x * x);
        else if (k < 2 * x)
            answer = (2 * x - k) * (2 * x - k) / (2 * x * x);
        else
            answer = 0;
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均 $O(1)$。

### 易错点

经过第二点不算完成第二次打卡，必须先到第一点。计算平方前转浮点，最后按题意保留两位。
