## 卡拉兹函数

### 题意

对 n 只计算一次卡拉兹函数。

### 思路

用 n%2 判断奇偶，奇数输出 3n+1，偶数输出 n/2。题目要求单次函数值，不要求重复迭代到一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << (n % 2 ? 3 * n + 1 : n / 2);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

输入一时答案是四，不能因为熟悉其他 Collatz 题而直接停止。
