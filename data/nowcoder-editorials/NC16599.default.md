## 数字统计

### 题意

统计闭区间 L 到 R 的所有整数中数字二的出现总次数。

### 思路

区间上界只有一万，直接逐数检查。每次取最低十进制位，等于二就计数，再整除十移去这位。一个数中的多个二分别贡献。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int l, r;
    cin >> l >> r;
    int ans = 0;
    for (int x = l; x <= r; x++)
        for (int n = x; n > 0; n /= 10)
            if (n % 10 == 2)
                ans++;
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O((R-L+1)\log R)$，额外空间 $O(1)$。

### 易错点

二十二贡献两次，不是只判断每个数是否含二。
