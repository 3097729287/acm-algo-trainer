## Cut

### 题意

允许先重排序列，随后逐次切开，最大化每次被切序列的总和之和。

### 思路

逆向看，切分就是把所有单元素合并，每次代价为新合并的总和，目标是最大化总代价。最优合并树中，越大的数应放在越深的位置，因为它参与的合并次数更多；最深处必有一对兄弟叶子，可以把最大的两个数交换到这里而不减答案。合并这两个最大数后，问题缩小。各数非负，合并结果仍最大，所以后续总是把当前大块与下一个较大数合并。正向就是升序排列，每次单独切掉最左的最小数。累加长度 n、n-1、……、2 的后缀和。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    long long sum = 0, answer = 0;
    for (auto &x : a) {
        cin >> x;
        sum += x;
    }
    sort(a.begin(), a.end());
    for (int i = 0; i + 1 < n; i++) {
        answer += sum;
        sum -= a[i];
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

求最大代价，应让大数被反复计入。长度一不再切分，不能再加最后一个数。总和与答案都用 long long。
