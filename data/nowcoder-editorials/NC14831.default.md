## 无限长正整数排列字符串

### 题意

将正整数依次拼接，查询第 n 个字符。

### 思路

n 最大一千，直接从一开始把 to_string(x) 追加到字符串，直到长度至少为 n。字符位置是一开始编号，访问下标 n-1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    string s;
    for (int x = 1; (int)s.size() < n; x++)
        s += to_string(x);
    cout << s[n - 1];
    return 0;
}
```

### 复杂度

生成字符数为 $O(n)$，时间与空间均为 $O(n)$。

### 易错点

第十位是一十中的一，第十一位是零，跨过九之后每个整数贡献两位。
