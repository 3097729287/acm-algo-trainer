## 牛牛数数

### 题意

输出一到 n 中既不含数字四、又不是四的倍数的数。

### 思路

从小到大枚举。先检查余数不为零，再把数字转换为字符串，检查其中找不到字符四。只有两个条件都成立才输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int x = 1; x <= n; x++)
        if (x % 4 != 0 && to_string(x).find('4') == string::npos)
            cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，数位临时空间 $O(\log n)$。

### 易错点

不是四的倍数也可能含四，例如四十一仍应被排除。
