## Frogs

### 题意

多只青蛙从0按各自固定步长绕环，求所有可到石头编号之和。

### 思路

步长a的青蛙能到的恰是gcd(a,m)的倍数。所有这些g都整除m，先去重。对于任意石头x，令d=gcd(x,m)，它被覆盖当且仅当某个g整除d。因此可以按m的因数d分组，只需检查因数之间的整除。

当d<m时，gcd(x,m)=d的非零石头有phi(m/d)个，这是把x除以d后的互质剩余类。累加所有被覆盖组的人数count。覆盖集合在x与m−x之间成对对称，每对编号和为m，所以编号总和为m*count/2；0不影响总和，单独排除d=m即可。m/2若是自对称点，m一定为偶数，公式仍是整数。分解m一次就能算各组欧拉函数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    for (int tc = 1; tc <= tests; tc++) {
        int n;
        long long m;
        cin >> n >> m;
        set<long long> groups;
        for (int i = 0; i < n; i++) {
            long long a;
            cin >> a;
            groups.insert(gcd(a, m));
        }
        vector<long long> divisors, primes;
        for (long long d = 1; d * d <= m; d++)
            if (m % d == 0) {
                divisors.push_back(d);
                if (d * d != m)
                    divisors.push_back(m / d);
            }
        long long remaining = m;
        for (long long p = 2; p * p <= remaining; p++)
            if (remaining % p == 0) {
                primes.push_back(p);
                while (remaining % p == 0)
                    remaining /= p;
            }
        if (remaining > 1)
            primes.push_back(remaining);
        long long count = 0;
        for (long long d : divisors)
            if (d < m) {
                bool covered = false;
                for (long long g : groups)
                    if (d % g == 0) {
                        covered = true;
                        break;
                    }
                if (!covered)
                    continue;
                long long q = m / d, phi = q;
                for (long long p : primes)
                    if (q % p == 0)
                        phi = phi / p * (p - 1);
                count += phi;
            }
        cout << "Case #" << tc << ": " << m * count / 2 << '\n';
    }
    return 0;
}
```

### 复杂度

因数数 $D$、不同gcd数 $G\le D$，时间 $O(n\log m+\sqrt m+DG+D\omega(m))$，空间 $O(D+G)$。

### 易错点

不是把所有步长一起取一个gcd：不同青蛙的可达集合取并集，不是允许在途中任意切换步长。编号范围是0到m−1，不含m。答案和乘积使用64位。
