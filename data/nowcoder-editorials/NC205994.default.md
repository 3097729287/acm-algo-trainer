## 卷积

### 题意

对递推数列的生成函数F，求F+F²+...的n次系数。

### 思路

原递推给出F(x)=x/(1−ax−bx²)。由于F常数项为0，形式幂级数的几何和为G=F/(1−F)=x/(1−(a+1)x−bx²)。因此所求系数直接满足g[0]=0、g[1]=1、g[n]=(a+1)g[n−1]+b*g[n−2]，线性滚动即可，无需实际卷积。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long a, b;
    cin >> n >> a >> b;
    const long long mod = 998244353;
    long long previous = 0, current = 1;
    for (int i = 2; i <= n; i++) {
        long long next = ((a + 1) * current + b * previous) % mod;
        previous = current;
        current = next;
    }
    cout << current;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

和从F¹开始，不包含常数1；新递推第一系数是a+1。
