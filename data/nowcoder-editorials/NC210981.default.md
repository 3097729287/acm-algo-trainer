## mixup2 混乱的奶牛

### 题意

安排全部奶牛，任意相邻编号差严格大于K，统计完整队列方案。

### 思路

dp[mask][last]记录已放mask中的奶牛、最后一头为last的方案数。任一单头都可作起点，初值1。追加未用奶牛next时，只需检查它与last的编号差>K，满足就累加到新状态。最终对全体集合的所有末尾求和。编号不同但只按身份位标记，不按数值大小改变原索引。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    vector<vector<long long>> dp(1 << n, vector<long long>(n));
    for (int i = 0; i < n; i++)
        dp[1 << i][i] = 1;
    for (int mask = 1; mask < (1 << n); mask++)
        for (int last = 0; last < n; last++)
            if (dp[mask][last])
                for (int next = 0; next < n; next++)
                    if (!(mask >> next & 1) && abs(a[last] - a[next]) > k)
                        dp[mask | (1 << next)][next] += dp[mask][last];
    cout << accumulate(dp.back().begin(), dp.back().end(), 0LL);
    return 0;
}
```

### 复杂度

时间 $O(n^2 2^n)$，空间 $O(n2^n)$。

### 易错点

差恰等于K不合法。反向排列是不同队伍，答案不除二。题目保证在64位范围内。
