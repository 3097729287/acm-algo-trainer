## 牛妹数

### 题意

判断整数是否为大于五十的偶数。

### 思路

两个条件要同时满足：n>50 且 n%2==0。用逻辑与连接，成立输出小写 yes，否则输出小写 no。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << (n > 50 && n % 2 == 0 ? "yes" : "no");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

五十虽然是偶数，但不满足严格大于五十。
