## 树上子链

### 题意

点权可正可负，求非空简单路径上的最大点权和。

### 思路

down[u]表示从u向某个后代延伸的最大路径和。孩子中只取最大的正贡献加入u；以u为最高点的完整路径最多连接两个不同孩子，故取最大的两个非负down贡献，再加u权值更新全局答案。全局初值为负无穷，保证全负时仍选一个最大权点，而非空路径。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> weight(n), down(n);
    for (auto &x : weight)
        cin >> x;
    Tree tree(n);
    for (int i = 1; i < n; i++) {
        int a, b;
        cin >> a >> b;
        tree.add(a - 1, b - 1);
    }
    tree.root(0);
    long long answer = -(1LL << 60);
    for (int i = n - 1; i >= 0; i--) {
        int u = tree.order[i];
        long long first = 0, second = 0;
        for (auto [v, w] : tree.edge[u])
            if (v != tree.parent[u]) {
                long long value = down[v];
                if (value > first) {
                    second = first;
                    first = value;
                } else if (value > second)
                    second = value;
            }
        down[u] = weight[u] + first;
        answer = max(answer, weight[u] + first + second);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

不是树边权直径，负权下不能用两次找最远点。每个点至多用一次，两条向下支路必须来自不同孩子。
