## [ZJOI2007]棋盘制作

### 题意

在01矩阵中分别找最大黑白相间正方形和矩形，输出面积。

### 思路

把每格颜色异或(行号+列号)的奇偶，原本相邻异色就变为相同色，所以棋盘等价于新矩阵全0或全1子矩形。分别对两种颜色维护以当前行结束的连续同色高度。每一行作为底边，单调栈枚举每个高度能够覆盖的最大宽度width，矩形面积为height*width，可容纳的最大正方形边长为min(height,width)。对所有行、两种颜色取最大。输入逐行处理，只需两组高度。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols;
    cin >> rows >> cols;
    vector<vector<int>> height(2, vector<int>(cols + 1));
    long long bestSquare = 0, bestRectangle = 0;
    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < cols; c++) {
            int color;
            cin >> color;
            color ^= (r + c) & 1;
            for (int value = 0; value < 2; value++)
                height[value][c] = color == value ? height[value][c] + 1 : 0;
        }
        for (int value = 0; value < 2; value++) {
            vector<int> stack;
            for (int c = 0; c <= cols; c++) {
                while (!stack.empty() && height[value][stack.back()] > height[value][c]) {
                    int h = height[value][stack.back()];
                    stack.pop_back();
                    int width = c - (stack.empty() ? -1 : stack.back()) - 1;
                    bestRectangle = max(bestRectangle, 1LL * h * width);
                    long long side = min(h, width);
                    bestSquare = max(bestSquare, side * side);
                }
                stack.push_back(c);
            }
        }
    }
    cout << bestSquare << '\n' << bestRectangle;
    return 0;
}
```

### 复杂度

时间 $O(NM)$，额外空间 $O(M)$。

### 易错点

必须同时考虑全0和全1两种变换后颜色。正方形要输出面积，不能输出边长。高度数组末尾额外的0用作冲刷栈。
