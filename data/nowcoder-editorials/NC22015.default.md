## 最大最小值

### 题意

找出三个数的最大与最小值，并附上指定英文标签。

### 思路

分别用 max、min 对三个数取极值，按最大值在前、最小值在后的顺序输出。冒号左右的空格也是格式的一部分。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, c;
    cin >> a >> b >> c;
    cout << "The maximum number is : " << max({a, b, c}) << '\n';
    cout << "The minimum number is : " << min({a, b, c});
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

第二行是 minimum，不能只改数字而忘记改标签。
