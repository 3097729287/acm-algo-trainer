## 游戏

### 题意

每次从某堆取其当前石子数的一个约数，统计先手获胜首步数。

### 思路

一堆m的SG值为v₂(m)+1，空堆为0。证明按m归纳：令r=v₂(m)。取约数d时，若v₂(d)<r，剩余数的二进赋值恰为v₂(d)，产生SG值1..r；取d=m得到0。若v₂(d)=r且未取空，剩余数赋值大于r，SG值大于r+1。因此0..r都可达，r+1不可达，mex正好是r+1。

所有堆的SG异或为X。枚举每种堆大小m的每个约数d，如果X xor SG(m) xor SG(m−d)=0，这一取法获胜，贡献该大小堆的出现次数。按d的倍数枚举m就能遍历全部约数对。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    const int limit = 100000;
    vector<int> frequency(limit + 1), sg(limit + 1);
    for (int m = 1; m <= limit; m++)
        sg[m] = __builtin_ctz((unsigned)m) + 1;
    int total = 0, maximum = 0;
    while (n--) {
        int x;
        cin >> x;
        frequency[x]++;
        total ^= sg[x];
        maximum = max(maximum, x);
    }
    long long answer = 0;
    for (int d = 1; d <= maximum; d++)
        for (int m = d; m <= maximum; m += d)
            if (frequency[m] && (total ^ sg[m] ^ sg[m - d]) == 0)
                answer += frequency[m];
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(U\log U+n)$，空间 $O(U)$。

### 易错点

不同堆即使大小相同也算不同首步，所以乘出现次数。不能对0调用ctz，sg[0]单独保留0。
