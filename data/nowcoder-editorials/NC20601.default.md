## [ZJOI2007]仓库建设

### 题意

工厂产品只能往更大编号运，建仓库和运输均收费，求最低总成本。

### 思路

令P[i]=Σp，W[i]=Σp*x。若上一仓库在j、下一仓库在i，把(j,i]产品运到i的费用为x[i]*(P[i]−P[j])−(W[i]−W[j])。所以dp[i]=c[i]+x[i]P[i]−W[i]+min(dp[j]+W[j]−x[i]P[j])。这是斜率−P[j]、截距dp[j]+W[j]、查询横坐标x[i]的直线最小值。工厂顺序向山下距离增加，P非减，符合单调凸壳。

直线斜率按非增顺序加入，查询横坐标非减。维护下凸壳：新线使末尾两线的交点顺序逆转时，删除中间线，交点顺序用交叉乘积精确比较。斜率相同时只保留截距更小者。查询时若第二条线不劣于第一条，就弹掉第一条；随着横坐标变大，它也不会重新更优。每条线至多进出队一次。代码用128位处理中间乘积，避免平方及交点比较溢出。

若后面工厂产品全为0，并不必须在那里再建仓库。因此答案取所有P[i]已等于总产品数的dp[i]最小；全无产品可不建仓，费用0。这样也覆盖零产品的边界情况。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using Wide = __int128;
struct MonotoneHull {
    struct Line {
        Wide slope, intercept;
        Wide at(Wide x) const { return slope * x + intercept; }
    };
    deque<Line> lines;
    void add(Wide slope, Wide intercept) {
        Line line{slope, intercept};
        while (!lines.empty() && lines.back().slope == slope) {
            if (lines.back().intercept <= intercept)
                return;
            lines.pop_back();
        }
        while (lines.size() >= 2) {
            auto a = lines[lines.size() - 2], b = lines.back();
            if ((b.intercept - a.intercept) * (b.slope - line.slope) <
                (line.intercept - b.intercept) * (a.slope - b.slope))
                break;
            lines.pop_back();
        }
        lines.push_back(line);
    }
    Wide minimum(Wide x) {
        while (lines.size() >= 2 && lines[1].at(x) <= lines[0].at(x))
            lines.pop_front();
        return lines.front().at(x);
    }
};
void printWide(Wide value) {
    if (value < 0) {
        cout << '-';
        value = -value;
    }
    string digits;
    do {
        digits += char('0' + value % 10);
        value /= 10;
    } while (value);
    reverse(digits.begin(), digits.end());
    cout << digits;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Factory {
        long long x, p, c;
    };
    vector<Factory> a(n);
    Wide total = 0;
    for (auto &f : a) {
        cin >> f.x >> f.p >> f.c;
        total += f.p;
    }
    if (total == 0) {
        cout << 0;
        return 0;
    }
    MonotoneHull hull;
    hull.add(0, 0);
    Wide quantity = 0, weighted = 0, answer = Wide(1) << 120;
    for (auto f : a) {
        quantity += f.p;
        weighted += Wide(f.p) * f.x;
        Wide value = f.c + Wide(f.x) * quantity - weighted + hull.minimum(f.x);
        if (quantity == total)
            answer = min(answer, value);
        hull.add(-quantity, value + weighted);
    }
    printWide(answer);
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(n)$。

### 易错点

不能把产品向上运，分组末端必须是所建仓库位置。产品数为0时出现相同斜率，保留截距较小者即可。
