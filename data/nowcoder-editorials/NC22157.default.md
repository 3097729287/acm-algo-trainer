## 牛牛学数列2

### 题意

计算调和数列前 n 项和。

### 思路

枚举分母 i，将 1.0/i 累加到 double 变量。输出足够的小数位以满足十万分之一误差。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    double ans = 0;
    for (int i = 1; i <= n; i++)
        ans += 1.0 / i;
    cout << fixed << setprecision(9) << ans;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

写成 1/i 会执行整数除法，第二项起都变零。
