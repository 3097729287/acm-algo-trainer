## 学姐的"Hello world!"

### 题意

输出题目明确指定的字符串 Helo word!。

### 思路

本题特意要求保留少写的字母。直接输出目标字符串，不进行拼写纠正。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout << "Helo word!";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

大小写、空格和感叹号均按题面保留，双引号不输出。
