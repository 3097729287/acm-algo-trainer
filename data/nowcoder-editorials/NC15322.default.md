## 强迫症的序列

### 题意

每步给恰好 n-1 个元素加一，用最少步数使所有值相等，并求最终值。

### 思路

每步相当于所有元素一起加一，再把未选中的那一个减一。忽略公共平移，就成了每步把一个元素减一，至少需要 sum(a[i]-minimum) 步才能都降到原最小值。依次降低各元素可实现此下界。还原公共平移后，最终值为 minimum+steps。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        long long sum = 0, minimum = LLONG_MAX;
        for (int i = 0; i < n; i++) {
            long long x;
            cin >> x;
            sum += x;
            minimum = min(minimum, x);
        }
        long long steps = sum - minimum * n;
        cout << steps << ' ' << minimum + steps << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n)$，额外空间 $O(1)$。

### 易错点

求操作次数时基准是原数组最小值。n=1 时每步改变零个元素，本来已相等，答案零步。
