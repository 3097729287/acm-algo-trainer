## 箱子归位

### 题意

在五乘五的空广场，把唯一箱子推到中心，求最少单位步数。

### 思路

扫描矩阵找到箱子所在行列。横向至少要走到第三列，纵向至少要走到第三行，两方向互不影响，所以答案是 |row-3|+|column-3|。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int ans = 0;
    for (int i = 1; i <= 5; i++)
        for (int j = 1; j <= 5; j++) {
            int x;
            cin >> x;
            if (x == 1)
                ans = abs(i - 3) + abs(j - 3);
        }
    cout << ans;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

这里没有墙或其他障碍，不需要搜索。按零下标写时中心下标应为二。
