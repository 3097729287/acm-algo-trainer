## 送外卖

### 题意

可正负跳跃，到达末点的选择串按a小于b取字典序最小；无最小有限串时输出Infinity。

### 思路

对每个合法跳跃建边，反向搜索求能到末点的集合。若0不在其中，输出No solution!。否则从0开始，每一步优先选择仍能到终点的a边，没有才选b；这是字典序的首次不同字符原则。到终点立刻停止，因为空后缀最小。

若在到终点之前重复来到某点，贪心选择将永远重复这一圈。虽然每个点都能绕路到终点，但每次选择退出环的有限串，都能通过再绕一圈得到更小的串，因此没有最小有限答案，输出Infinity!。访问标记可在线检测。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<int, 2>> edge(n);
    vector<vector<int>> reverse(n);
    for (int type = 0; type < 2; type++)
        for (int i = 0; i < n; i++) {
            int step;
            cin >> step;
            int v = i + step;
            edge[i][type] = (v >= 0 && v < n) ? v : -1;
            if (edge[i][type] != -1)
                reverse[v].push_back(i);
        }
    vector<bool> reachable(n), seen(n);
    vector<int> queue{n - 1};
    reachable[n - 1] = true;
    for (size_t h = 0; h < queue.size(); h++)
        for (int v : reverse[queue[h]])
            if (!reachable[v]) {
                reachable[v] = true;
                queue.push_back(v);
            }
    if (!reachable[0]) {
        cout << "No solution!";
        return 0;
    }
    int u = 0;
    string answer;
    while (u != n - 1) {
        if (seen[u]) {
            cout << "Infinity!";
            return 0;
        }
        seen[u] = true;
        int a = edge[u][0];
        int type = (a != -1 && reachable[a]) ? 0 : 1;
        answer += char('a' + type);
        u = edge[u][type];
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

不是求最短选择串；a自环即使有b出口，也可能导致字典序没有有限最小值。n=1时答案是空串。
