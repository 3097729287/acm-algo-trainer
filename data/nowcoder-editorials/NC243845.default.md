## [Violet]天使玩偶/SJY摆棋子

### 题意

在线序列只有插入点与查询最近曼哈顿距离，离线求每次答案。

### 思路

先只考虑候选点$(x,y)$在询问$(X,Y)$左下方，即$x\le X,y\le Y$，距离是$X+Y-(x+y)$。按时间做CDQ，左半插入只能影响右半询问；左右按x归并扫描，用y上的树状数组维护左半插入的最大x+y，右半询问查y前缀即可。这样同时满足时间、x、y三维约束。

分别将所有坐标乘上(+,+)、(+,-)、(-,+)、(-,-)四种符号，每次都求左下方候选，最后取四个方向距离最小。初始点作为早于所有操作的插入事件。CDQ递归返回时数组按x排序，但所属时间区间始终由归并前的划分固定。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Event {
    long long x, y;
    int kind, id, rank;
};
vector<Event> event, buffer;
vector<long long> bit, answer;
const long long NEG = -(1LL << 60);
void add(int p, long long value) {
    for (; p < (int)bit.size(); p += p & -p)
        bit[p] = max(bit[p], value);
}
long long maximum(int p) {
    long long value = NEG;
    for (; p; p -= p & -p)
        value = max(value, bit[p]);
    return value;
}
void cdq(int l, int r) {
    if (r - l <= 1)
        return;
    int mid = (l + r) / 2;
    cdq(l, mid);
    cdq(mid, r);
    int i = l;
    for (int j = mid; j < r; j++) {
        while (i < mid && event[i].x <= event[j].x) {
            if (event[i].kind == 1)
                add(event[i].rank, event[i].x + event[i].y);
            i++;
        }
        if (event[j].kind == 2) {
            long long best = maximum(event[j].rank);
            if (best != NEG)
                answer[event[j].id] = min(answer[event[j].id], event[j].x + event[j].y - best);
        }
    }
    for (int j = l; j < i; j++)
        if (event[j].kind == 1)
            for (int p = event[j].rank; p < (int)bit.size(); p += p & -p)
                bit[p] = NEG;
    merge(event.begin() + l, event.begin() + mid, event.begin() + mid, event.begin() + r,
          buffer.begin() + l, [](const Event &a, const Event &b) { return a.x < b.x; });
    copy(buffer.begin() + l, buffer.begin() + r, event.begin() + l);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<Event> base;
    for (int i = 0; i < n; i++) {
        long long x, y;
        cin >> x >> y;
        base.push_back({x, y, 1, -1, 0});
    }
    int queries = 0;
    for (int i = 0; i < m; i++) {
        int kind;
        long long x, y;
        cin >> kind >> x >> y;
        base.push_back({x, y, kind, kind == 2 ? queries++ : -1, 0});
    }
    answer.assign(queries, LLONG_MAX);
    for (int sx : {-1, 1})
        for (int sy : {-1, 1}) {
            event = base;
            vector<long long> coordinate;
            for (auto &q : event) {
                q.x *= sx;
                q.y *= sy;
                coordinate.push_back(q.y);
            }
            sort(coordinate.begin(), coordinate.end());
            coordinate.erase(unique(coordinate.begin(), coordinate.end()), coordinate.end());
            for (auto &q : event)
                q.rank =
                    lower_bound(coordinate.begin(), coordinate.end(), q.y) - coordinate.begin() + 1;
            bit.assign(coordinate.size() + 1, NEG);
            buffer.resize(event.size());
            cdq(0, event.size());
        }
    for (auto value : answer)
        cout << value << '\n';
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log^2(n+m))$，空间 $O(n+m)$。

### 易错点

树状数组维护最大值不能用减法回滚；每次归并完成后，将本轮更新经过的节点恢复负无穷。各递归层不同时保留树状数组状态，所以清空有效。
