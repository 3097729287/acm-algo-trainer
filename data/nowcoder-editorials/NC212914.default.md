## 牛牛与后缀表达式

### 题意

计算由数字、结束符 # 及加减乘构成的合法后缀表达式。原站要求实现 `Solution::legalExp(string str)` 并返回 long long。

### 思路

从左到右扫描，数字持续读到 # 为止，把完整数值压栈。遇到运算符，就依次弹出右操作数 b、左操作数 a，计算 a op b 后重新压栈。每个栈元素始终代表一个已经算好的完整子表达式；合法后缀串结束后，栈内只剩整个表达式的值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
class Solution {
  public:
    long long legalExp(string str) {
        vector<long long> values;
        for (size_t i = 0; i < str.size();) {
            if (isdigit(static_cast<unsigned char>(str[i]))) {
                long long value = 0;
                while (i < str.size() && isdigit(static_cast<unsigned char>(str[i]))) {
                    value = value * 10 + str[i] - '0';
                    i++;
                }
                values.push_back(value);
                i++;
            } else {
                char op = str[i++];
                long long b = values.back();
                values.pop_back();
                long long a = values.back();
                values.pop_back();
                values.push_back(op == '+' ? a + b : op == '-' ? a - b : a * b);
            }
        }
        return values.back();
    }
};
```

### 复杂度

每个字符与栈元素均只处理常数次，时间与栈空间上界均为 $O(|str|)$。

### 易错点

先弹出的是右操作数，减法必须写 a-b。参数可能有多位，不能把每个数字字符都单独压栈。样例外层引号表示字符串参数，不属于传入函数的内容。所有数值使用 long long，原题保证中间结果绝对值不超过十的十八次方。
