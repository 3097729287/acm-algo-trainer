## 二进制？十进制！

### 题意

把两数的二进制数码当成十进制数字串，再按十进制加法相加。

### 思路

逐位取原数的二进制位，但使用十进制位权一、十、一百等累加，得到对应的十进制整数。对两项分别转换后直接相加。原数最多十六个二进制位，因此转换值可由 long long 容纳。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    auto convert = [](int x) {
        long long value = 0, place = 1;
        while (x) {
            value += (x & 1) * place;
            place *= 10;
            x >>= 1;
        }
        return value;
    };
    cout << convert(a) + convert(b);
    return 0;
}
```

### 复杂度

时间 $O(\log\max(A,B))$，额外空间 $O(1)$。

### 易错点

不能直接计算 a+b 再转二进制。结果中出现数字二是正常的，不按二进制进位。
