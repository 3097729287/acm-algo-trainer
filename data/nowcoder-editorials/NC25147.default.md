## 金币馅饼

### 题意

从左上走到右下，每步必须到下一列，行号变动至多1，最大化经过的金币和。

### 思路

按列推进。dp[r]为上一列停在r行的最大金币和，下一列r可由上一列r−1、r、r+1转移。初始仅左上格可达，其他为负无穷，最后必须取右下而非末列任意行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols;
    cin >> rows >> cols;
    vector<vector<int>> a(rows, vector<int>(cols));
    for (auto &row : a)
        for (int &x : row)
            cin >> x;
    const int neg = -1000000000;
    vector<int> dp(rows, neg), next(rows);
    dp[0] = a[0][0];
    for (int c = 1; c < cols; c++) {
        fill(next.begin(), next.end(), neg);
        for (int r = 0; r < rows; r++)
            for (int previous = max(0, r - 1); previous <= min(rows - 1, r + 1); previous++)
                if (dp[previous] != neg)
                    next[r] = max(next[r], dp[previous] + a[r][c]);
        dp.swap(next);
    }
    cout << dp[rows - 1];
    return 0;
}
```

### 复杂度

时间 $O(RC)$，存输入 $O(RC)$、额外DP空间 $O(R)$。

### 易错点

每次列号加一，不能在同一列上下移动。起点只有(1,1)，不能把第一列全部初始化为对应金币。
