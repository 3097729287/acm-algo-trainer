## Running

### 题意

跑一分钟疲劳加一，停下后必须休息到零才能再跑，结束时疲劳零，最大化跑步距离。

### 思路

把一次完整活动看成“连续跑k分钟，再连续休息k分钟”，1≤k≤M；块开始和结束疲劳都为0。dp[t]表示前t分钟已回到疲劳0的最大距离。可以再休息一分钟继承dp[t−1]；也可用一个长度2k的完整块结束在t，此块跑的是t−2k+1到t−k，距离用前缀和求，转自dp[t−2k]。所有合法计划都可按归零时刻拆成这些块，故没有漏解。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> prefix(n + 1), dp(n + 1);
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
    }
    for (int t = 1; t <= n; t++) {
        dp[t] = dp[t - 1];
        for (int run = 1; run <= m && 2 * run <= t; run++)
            dp[t] = max(dp[t], dp[t - 2 * run] + prefix[t - run] - prefix[t - 2 * run]);
    }
    cout << dp[n];
    return 0;
}
```

### 复杂度

时间 $O(nM)$，空间 $O(n)$。

### 易错点

休息中途不能恢复跑步。末尾剩余疲劳不合法，所以只维护完整归零块，不取所有疲劳状态的最大值。
