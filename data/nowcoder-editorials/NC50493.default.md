## 石子合并

### 题意

环上只能合并相邻石堆，求全部合并的最小和最大总代价。

### 思路

复制一遍石堆，把环的断点转成长度n的连续区间。dp[l][r]枚举最后一次合并的分界k，代价是左右子区间代价之和，再加整个[l,r]的石子总数。分别维护最小与最大值，从长度2到n计算。最后在全部n个长度n区间中分别取最小和最大。单堆无需合并，初值0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(2 * n), prefix(2 * n + 1);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        a[i + n] = a[i];
    }
    for (int i = 0; i < 2 * n; i++)
        prefix[i + 1] = prefix[i] + a[i];
    vector<vector<long long>> low(2 * n, vector<long long>(2 * n)), high = low;
    for (int length = 2; length <= n; length++)
        for (int l = 0; l + length <= 2 * n; l++) {
            int r = l + length - 1;
            low[l][r] = 1LL << 60;
            high[l][r] = -(1LL << 60);
            long long sum = prefix[r + 1] - prefix[l];
            for (int k = l; k < r; k++) {
                low[l][r] = min(low[l][r], low[l][k] + low[k + 1][r] + sum);
                high[l][r] = max(high[l][r], high[l][k] + high[k + 1][r] + sum);
            }
        }
    long long minimum = 1LL << 60, maximum = -(1LL << 60);
    for (int l = 0; l < n; l++) {
        minimum = min(minimum, low[l][l + n - 1]);
        maximum = max(maximum, high[l][l + n - 1]);
    }
    cout << minimum << '\n' << maximum;
    return 0;
}
```

### 复杂度

时间 $O(n^3)$，空间 $O(n^2)$。

### 易错点

合并必须相邻，不能用任取两堆的Huffman贪心。只计算长度至n的区间，并依题目输出先最小、后最大。
