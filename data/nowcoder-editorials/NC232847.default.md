## 美丽数

### 题意

统计能被所有非零数码整除的数。

### 思路

所有非零数码的最小公倍数L一定是2520的约数，共48种。数字只需保存模2520余数，因为最终判定r%L=0即可。加入非零d时L更新为lcm(L,d)，加入0时不变。预先列出2520全部约数及其转移，用(剩余位数,L编号,余数)缓存非贴界状态。前导0不改变L或余数，内部整数0也满足判定，但原区间l≥1，两个前缀相减会抵消它。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    vector<int> divisor;
    for (int d = 1; d <= 2520; d++)
        if (2520 % d == 0)
            divisor.push_back(d);
    vector<int> index(2521);
    for (int i = 0; i < (int)divisor.size(); i++)
        index[divisor[i]] = i;
    vector<array<int, 10>> next(divisor.size());
    for (int i = 0; i < (int)divisor.size(); i++)
        for (int d = 0; d <= 9; d++)
            next[i][d] = index[d ? lcm(divisor[i], d) : divisor[i]];
    int states = divisor.size();
    vector<long long> memo(20 * states * 2520, -1);
    auto count = [&](long long bound) {
        if (bound < 0)
            return 0LL;
        string s = to_string(bound);
        auto dfs = [&](auto &&self, int p, int state, int remainder, bool tight) -> long long {
            if (p == (int)s.size())
                return remainder % divisor[state] == 0;
            long long &cache = memo[((s.size() - p) * states + state) * 2520 + remainder];
            if (!tight && cache != -1)
                return cache;
            int maximum = tight ? s[p] - '0' : 9;
            long long result = 0;
            for (int d = 0; d <= maximum; d++)
                result += self(self, p + 1, next[state][d], (remainder * 10 + d) % 2520,
                               tight && d == maximum);
            if (!tight)
                cache = result;
            return result;
        };
        return dfs(dfs, 0, index[1], 0, true);
    };
    int tests;
    cin >> tests;
    while (tests--) {
        long long l, r;
        cin >> l >> r;
        cout << count(r) - count(l - 1) << '\n';
    }
    return 0;
}
```

### 复杂度

缓存至多 $O(D\cdot48\cdot2520)$ 个状态，每状态10条转移；单边界另 $O(10D)$，空间同状态数。

### 易错点

0数码应忽略，不能令L变成0。余数必须模2520，不能随L变化后丢掉必要信息。
