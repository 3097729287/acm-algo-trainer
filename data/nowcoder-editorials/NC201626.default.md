## 字符串分类

### 题意

统计输入字符串中有多少种不同内容。

### 思路

将每个完整字符串插入 set。集合会合并相同键，全部插入后集合大小即为不同字符串数。相同字母组成但顺序不同的字符串仍是不同内容。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    set<string> values;
    while (n--) {
        string s;
        cin >> s;
        values.insert(s);
    }
    cout << values.size();
    return 0;
}
```

### 复杂度

最长串长为 $L$ 时，时间 $O(nL\log n)$，字符串存储空间 $O(nL)$。

### 易错点

不能排序字符串内部字符；aaa 与 aa 也必须区分。
