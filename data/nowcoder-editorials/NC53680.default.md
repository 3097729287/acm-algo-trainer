## 「金」点石成金

### 题意

每块石头二选一，财富或魔法低于0就归零，最大化最后乘积。

### 思路

n最多15，直接DFS枚举每块石头的两种选择。转移时马上把被减少的量截到0，不能把负数留到最后。到第n块后计算乘积取最大。搜索深度只有15，不需要记忆化。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<long long, 4>> a(n);
    for (auto &x : a)
        for (auto &v : x)
            cin >> v;
    long long answer = 0;
    auto dfs = [&](auto &&self, int i, long long wealth, long long magic) -> void {
        if (i == n) {
            answer = max(answer, wealth * magic);
            return;
        }
        auto [gain, cost, recover, loss] = a[i];
        self(self, i + 1, wealth + gain, max(0LL, magic - cost));
        self(self, i + 1, max(0LL, wealth - loss), magic + recover);
    };
    dfs(dfs, 0, 0, 0);
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(2^n)$，额外空间 $O(n)$。

### 易错点

每步都归零，不能把减少量当欠债。两个累计量可达一千五百万，乘积用64位。
