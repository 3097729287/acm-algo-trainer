## 你能活多少秒

### 题意

按每年 31560000 秒，把年龄换算成秒数。

### 思路

题目已经指定一年近似的秒数，不必另算天数或闰年。年龄乘 31560000LL，最大结果超过 32 位有符号整数范围。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long age;
    cin >> age;
    cout << age * 31560000LL;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

二百岁对应 6312000000 秒，必须使用 long long。
