## CSL分苹果

### 题意

苹果不可切开，分两堆尽量等重，重的一堆给tokitsukaze。

### 思路

总重量为S，较轻堆重量不超过S/2。用01背包求可达到且不超过S/2的最大重量x，另外一堆就是S−x，差值随x增大而减小。每个苹果倒序更新可达重量，保证只取一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    int sum = 0;
    for (int &x : a) {
        cin >> x;
        sum += x;
    }
    int capacity = sum / 2;
    vector<bool> can(capacity + 1);
    can[0] = true;
    for (int x : a)
        for (int s = capacity; s >= x; s--)
            can[s] = can[s] || can[s - x];
    int x = capacity;
    while (!can[x])
        x--;
    cout << x << ' ' << sum - x;
    return 0;
}
```

### 复杂度

时间 $O(nS)$，空间 $O(S)$，$S\le10000$。

### 易错点

输出先轻后重，不要求两个人的苹果个数相同。容量倒序，不能把同一苹果重复使用。
