## Count the Arrays

### 题意

严格先增后减数组，恰有一对相等，求数量。

### 思路

n=2无法严格单峰且重复，答案0。n≥3时选n−1种不同值C(m,n−1)，最大值作为唯一峰值；重复值只能从其余n−2种选择，并在峰左右各放一次。剩下n−3个值各自任选放左或右，之后两侧顺序被严格单调性唯一确定。因此答案C(m,n−1)*(n−2)*2^(n−3)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 998244353;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}
struct Combinations {
    vector<long long> factorial, inverse;
    Combinations(int n) : factorial(n + 1, 1), inverse(n + 1) {
        for (int i = 1; i <= n; i++)
            factorial[i] = factorial[i - 1] * i % mod;
        inverse[n] = power(factorial[n], mod - 2);
        for (int i = n; i >= 1; i--)
            inverse[i - 1] = inverse[i] * i % mod;
    }
    long long choose(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return factorial[n] * inverse[k] % mod * inverse[n - k] % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    if (n == 2) {
        cout << 0;
        return 0;
    }
    Combinations comb(m);
    cout << comb.choose(m, n - 1) * (n - 2) % mod * power(2, n - 3) % mod;
    return 0;
}
```

### 复杂度

时间 $O(m+\log P+\log n)$，空间 $O(m)$。

### 易错点

最大值不能重复，否则无法满足峰两侧的严格不等。相等的那一对分居峰两边。
