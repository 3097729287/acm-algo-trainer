## 八数码

### 题意

三乘三滑块，把x与四邻格交换，输出到标准排列的移动串或unsolvable。

### 思路

每个九字符排列是一个状态，交换一次是边。BFS按步数递增访问，记录每个新状态的父状态编号和到达它的移动字符，到目标后沿父链倒序恢复。最多9!种状态，全部存储足够。若可达状态遍历完仍无目标，则无解。相同状态只入队一次，避免在滑块来回交换中循环。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string start;
    char c;
    while (cin >> c)
        start += c;
    const string target = "12345678x";
    vector<string> states{start};
    vector<int> parent{-1};
    vector<char> move{'?'};
    unordered_map<string, int> id;
    id.reserve(200000);
    id[start] = 0;
    int found = -1;
    int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
    string names = "udlr";
    for (size_t h = 0; h < states.size(); h++) {
        string current = states[h];
        if (current == target) {
            found = h;
            break;
        }
        int p = current.find('x'), r = p / 3, col = p % 3;
        for (int d = 0; d < 4; d++) {
            int rr = r + dr[d], cc = col + dc[d];
            if (rr < 0 || rr >= 3 || cc < 0 || cc >= 3)
                continue;
            string next = current;
            swap(next[p], next[rr * 3 + cc]);
            if (!id.count(next)) {
                int index = states.size();
                id[next] = index;
                states.push_back(next);
                parent.push_back(h);
                move.push_back(names[d]);
            }
        }
    }
    if (found == -1)
        cout << "unsolvable";
    else {
        string answer;
        for (int u = found; parent[u] != -1; u = parent[u])
            answer += move[u];
        reverse(answer.begin(), answer.end());
        cout << answer;
    }
    return 0;
}
```

### 复杂度

记状态数 $S\le9!$，每状态最多四条边、字符串长9，期望时间 $O(9S)$，空间 $O(9S)$。

### 易错点

字符表示空格x的移动方向。样例可能给出另一条合法路径，本地校验会逐步执行整条输出并检查最终排列。
