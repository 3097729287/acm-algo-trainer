## Big Water Problem

### 题意

单点加、区间和。

### 思路

树状数组维护原数组值。单点加沿下标不断增加lowbit，前缀和沿下标减少lowbit。区间[l,r]用prefix(r)−prefix(l−1)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    Fenwick bit(n);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        bit.add(i, x);
    }
    while (m--) {
        int op, x;
        long long y;
        cin >> op >> x >> y;
        if (op == 1)
            bit.add(x, y);
        else
            cout << bit.sum((int)y) - bit.sum(x - 1) << '\n';
    }
    return 0;
}
```

### 复杂度

初始化 $O(n\log n)$，操作 $O(\log n)$，空间 $O(n)$。

### 易错点

位置从1开始。区间和可能超过32位，Fenwick节点用64位。
