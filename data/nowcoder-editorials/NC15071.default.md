## 数一数

### 题意

对每个输入字符串，计算它在所有输入字符串中出现次数的乘积。

### 思路

只要某个被乘的出现次数为零，答案就为零。设最短字符串长度为 L，所有比 L 长的候选在最短串中都不可能出现，答案必为零；长度为 L 的候选若要在最短串中出现，就只能与它完全相同。因此若多个最短串并不相同，全部答案都是零；否则只需把唯一的最短串当模式，对所有串跑一次 KMP，并将出现次数相乘。最终只有这些最短串的位置输出该乘积，其余输出零。

前缀函数 pi[i] 记录前缀 s[0..i] 的最长相同真前后缀长度。失配时令已匹配长度 j=pi[j-1]，保留仍可能匹配的后缀；成功时 j 增一。每次回退都会减少 j，增长总数只与串长成正比，因此预处理和扫描均为线性。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

template <class Sequence> vector<int> prefixFunction(const Sequence &s) {
    int n = s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])
            j = pi[j - 1];
        if (s[i] == s[j])
            j++;
        pi[i] = j;
    }
    return pi;
}

template <class Sequence>
long long occurrences(const Sequence &text, const Sequence &pattern, const vector<int> &pi) {
    if (pattern.empty())
        return text.size() + 1;
    int matched = 0;
    long long answer = 0;
    for (const auto &value : text) {
        while (matched > 0 && value != pattern[matched])
            matched = pi[matched - 1];
        if (value == pattern[matched])
            matched++;
        if (matched == (int)pattern.size()) {
            answer++;
            matched = pi[matched - 1];
        }
    }
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 998244353;
    int n;
    cin >> n;
    vector<string> strings(n);
    int shortest = 0;
    for (int i = 0; i < n; i++) {
        cin >> strings[i];
        if (strings[i].size() < strings[shortest].size())
            shortest = i;
    }
    const string &pattern = strings[shortest];
    bool valid = true;
    for (const auto &s : strings)
        if (s.size() == pattern.size() && s != pattern)
            valid = false;
    long long answer = valid ? 1 : 0;
    if (valid) {
        auto pi = prefixFunction(pattern);
        for (const auto &s : strings) {
            answer = answer * occurrences(s, pattern, pi) % mod;
            if (answer == 0)
                break;
        }
    }
    for (const auto &s : strings)
        cout << (s.size() == pattern.size() ? answer : 0) << '\n';
    return 0;
}
```

### 复杂度

设总字符数为 $N$，时间 $O(N+n)$，保存全部输入空间 $O(N+n)$。

### 易错点

出现可重叠，且大小写敏感。不能对每个字符串各跑一遍全体匹配，会退化成输入串数乘总长。
