## 笨小猴

> 原题：[P1125](https://www.luogu.com.cn/problem/P1125)
> 解法：频数差的质数判定 · C++17

### 题意

统计小写单词中出现最多与最少的字母次数差；差为质数则输出 Lucky Word 和该差，否则输出 No Answer 和零。



### 思路

只在实际出现的字母中找最小频数，求差后用试除法判质数。零和一都不是质数。

单词长度为 L，时间 $O(L+\sqrt L)$，额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int count[26] = {};
    for (char c : s)
        ++count[c - 'a'];
    int low = s.size(), high = 0;
    for (int c : count)
        if (c) {
            low = min(low, c);
            high = max(high, c);
        }
    int d = high - low;
    bool prime = d >= 2;
    for (int x = 2; x * x <= d; x++)
        if (d % x == 0)
            prime = false;
    if (prime)
        cout << "Lucky Word\n" << d << '\n';
    else
        cout << "No Answer\n0\n";
    return 0;
}
```

### 易错点

最小次数只取出现过的字母；零、一都不是质数。
