## 装进肚子

### 题意

恰好 K 个巧克力早上吃，其余晚上吃，最大化总甜蜜值。

### 思路

先假设全部晚上吃，得到基准 sum(B)。把第 i 个改到早上，收益只改变 A[i]-B[i]。因此选差值最大的 K 个，累加这些增量即可。即使增量为负，恰好 K 个的要求也仍需选择。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<long long> a(n), delta(n);
    for (auto &x : a)
        cin >> x;
    long long answer = 0;
    for (int i = 0; i < n; i++) {
        long long b;
        cin >> b;
        answer += b;
        delta[i] = a[i] - b;
    }
    sort(delta.rbegin(), delta.rend());
    for (int i = 0; i < k; i++)
        answer += delta[i];
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，数组空间 $O(n)$。

### 易错点

不能只按早上甜蜜值排序，选到早上意味着同时失去晚上甜蜜值。总和可达百亿，要用 long long。
