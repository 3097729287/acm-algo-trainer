## Most Powerful

### 题意

两原子碰撞指定一方消失，最大化直到只剩一个原子的总能量。

### 思路

状态mask记录还存在的原子，dp[mask]为到达该集合的最大已获能量。初始全部存在为0。枚举仍存在的两个不同原子i、j，让i消灭j，获得power[i][j]，清掉j位。每次集合缩小，按mask递减处理即可保证前驱已求。最后在所有单元素集合中取最大。全为正值，合并到只剩一个一定最优。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n && n) {
        vector<vector<int>> power(n, vector<int>(n));
        for (auto &row : power)
            for (int &x : row)
                cin >> x;
        vector<int> dp(1 << n, -1000000000);
        dp.back() = 0;
        for (int mask = (1 << n) - 1; mask > 0; mask--)
            if (dp[mask] >= 0)
                for (int i = 0; i < n; i++)
                    if (mask >> i & 1)
                        for (int j = 0; j < n; j++)
                            if (i != j && (mask >> j & 1))
                                dp[mask ^ (1 << j)] =
                                    max(dp[mask ^ (1 << j)], dp[mask] + power[i][j]);
        int answer = 0;
        for (int i = 0; i < n; i++)
            answer = max(answer, dp[1 << i]);
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2 2^n)$，空间 $O(2^n+n^2)$。

### 易错点

矩阵第i行第j列表示j消失、i保留，不能反用。原子身份在后续碰撞中不变，无需额外记录能量。
