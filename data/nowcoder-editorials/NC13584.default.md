## 日历中的数字

### 题意

按四位年份、两位月份、两位日期的形式，统计指定月份所有日期中目标数字的次数。

### 思路

先按公历闰年规则求该月天数。枚举每一天，用 setw 和补零写成 YYYY-MM-DD，再统计目标数字字符。连字符不会等于任何数字，直接忽略即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int y, m, digit;
    while (cin >> y >> m >> digit) {
        int days[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        if (y % 400 == 0 || (y % 4 == 0 && y % 100 != 0))
            days[2] = 29;
        int ans = 0;
        for (int d = 1; d <= days[m]; d++) {
            ostringstream out;
            out << setfill('0') << setw(4) << y << '-' << setw(2) << m << '-' << setw(2) << d;
            string s = out.str();
            ans += count(s.begin(), s.end(), char('0' + digit));
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 复杂度

每组最多三十一条八数字日期，时间与额外空间均为常数。

### 易错点

年份和月份每天都会重新出现一次，不能只统计日期部分。补出的零也要计数。
