## Partitions

### 题意

分成k个非空无序集合，权为每块大小乘块内权和，求全部划分权值和。

### 思路

固定一个元素i，其权w[i]在每个划分中乘所在块大小。块大小可写成1+Σ(j≠i)[j与i同块]。全部划分的第一项计S(n,k)次；对固定j，把i、j合并为一个元素，同块划分数为S(n−1,k)。故每个w的系数相同，为S(n,k)+(n−1)S(n−1,k)，乘总权值即可。

使用S(N,k)=Σ(i=0..k)(−1)^(k−i)*i^N/(i!*(k−i)!)，两式合并成Σ符号*i^(n−1)*(i+n−1)/(i!*(k−i)!)，预处理逆阶乘，每项一次快速幂。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000007;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}
struct Combinations {
    vector<long long> factorial, inverse;
    Combinations(int n) : factorial(n + 1, 1), inverse(n + 1) {
        for (int i = 1; i <= n; i++)
            factorial[i] = factorial[i - 1] * i % mod;
        inverse[n] = power(factorial[n], mod - 2);
        for (int i = n; i >= 1; i--)
            inverse[i - 1] = inverse[i] * i % mod;
    }
    long long choose(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return factorial[n] * inverse[k] % mod * inverse[n - k] % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        sum = (sum + x) % mod;
    }
    Combinations comb(k);
    long long coefficient = 0;
    for (int i = 0; i <= k; i++) {
        long long term =
            power(i, n - 1) * (i + n - 1) % mod * comb.inverse[i] % mod * comb.inverse[k - i] % mod;
        if ((k - i) & 1)
            coefficient = (coefficient - term + mod) % mod;
        else
            coefficient = (coefficient + term) % mod;
    }
    cout << coefficient * sum % mod;
    return 0;
}
```

### 复杂度

时间 $O(n+k\log n+\log P)$，空间 $O(k)$。

### 易错点

集合块无编号，因此用第二类Stirling数，不能额外乘k!。n=1时0次幂按1，公式仍成立。
