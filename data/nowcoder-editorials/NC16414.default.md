## [NOIP2017]小凯的疑惑

### 题意

互素面值a、b，求非负组合无法表示的最大金额。

### 思路

答案ab−a−b。若它能写成ax+by，移项得a(x+1)=b(a−y−1)，互素迫使x+1为b倍数，从而ax≥a(b−1)>ab−a−b，矛盾。

对任意N>ab−a−b，由于b在模a下可逆，存在y∈[0,a−1]使by≡N(mod a)。令x=(N−by)/a，它是整数；又N−by>ab−a−b−b(a−1)=−a，所以x>−1，必有x≥0。于是所有更大金额可表示。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long a, b;
    cin >> a >> b;
    cout << a * b - a - b;
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

互素是公式前提，原题保证；乘积需64位。若面值1存在则没有无法支付金额，原题的存在性保证已排除。
