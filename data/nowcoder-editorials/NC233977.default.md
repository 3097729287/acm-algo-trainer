## [CERC2018]The ABCD Murderer

### 题意

用字典单词覆盖目标串，允许匹配部分重叠，最少单词数。

### 思路

AC自动机每个状态保存自身及fail链上的最长模式长度。扫描目标串，第i位得到的最长匹配区间[i−len+1,i]包含同终点的全部较短匹配，所以只保留它。对每个左端记录最远右端。

之后贪心覆盖：当前已覆盖[0,covered)，把左端≤covered的区间都纳入候选，选择能把右端推得最远的一个。若无法前进就无解。交换论证：任何可行下一块必须与当前覆盖衔接，选最远不会增加之后所需块数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Aho {
    struct Node {
        array<int, 26> next = {};
        int fail = 0, parent = 0, letter = 0, longest = 0;
    };
    vector<Node> node;
    vector<int> order;
    int alphabet;
    char base;
    Aho(int alphabet, char base, size_t capacity) : alphabet(alphabet), base(base) {
        node.reserve(capacity);
        node.emplace_back();
    }
    int insert(const string &s) {
        int u = 0;
        for (char ch : s) {
            int c = ch - base;
            if (!node[u].next[c]) {
                int v = node.size();
                node[u].next[c] = v;
                node.emplace_back();
                node[v].parent = u;
                node[v].letter = c;
            }
            u = node[u].next[c];
        }
        node[u].longest = max(node[u].longest, (int)s.size());
        return u;
    }
    void build() {
        order = {0};
        for (int c = 0; c < alphabet; c++)
            if (node[0].next[c])
                order.push_back(node[0].next[c]);
        for (size_t i = 1; i < order.size(); i++) {
            int u = order[i], f = node[u].fail;
            node[u].longest = max(node[u].longest, node[f].longest);
            for (int c = 0; c < alphabet; c++) {
                int v = node[u].next[c];
                if (v) {
                    node[v].fail = node[f].next[c];
                    order.push_back(v);
                } else
                    node[u].next[c] = node[f].next[c];
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string text;
    cin >> n >> text;
    vector<string> pattern(n);
    size_t total = 1;
    for (auto &s : pattern) {
        cin >> s;
        total += s.size();
    }
    Aho ac(26, 'a', total);
    for (auto &s : pattern)
        ac.insert(s);
    ac.build();
    vector<int> farthest(text.size(), -1);
    int u = 0;
    for (int i = 0; i < (int)text.size(); i++) {
        u = ac.node[u].next[text[i] - 'a'];
        int length = ac.node[u].longest;
        if (length) {
            int start = i - length + 1;
            farthest[start] = max(farthest[start], i + 1);
        }
    }
    int covered = 0, scan = 0, best = 0, answer = 0;
    while (covered < (int)text.size()) {
        while (scan <= (int)covered && scan < (int)text.size())
            best = max(best, farthest[scan++]);
        if (best <= covered) {
            cout << -1;
            return 0;
        }
        covered = best;
        answer++;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(26L+N)$，空间 $O(26L+N)$。

### 易错点

允许重叠，所以不能用只允许首尾相接的分词DP。只使用完整单词的匹配区间，不任意裁剪单词。
