## 3和5和7

### 题意

按递增顺序输出一到 n 中对三、五、七取余分别为二、三、二的数。

### 思路

n 不超过十万，逐个枚举并同时检查三个余数条件，满足就输出。三个条件需要全部成立。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int x = 1; x <= n; x++)
        if (x % 3 == 2 && x % 5 == 3 && x % 7 == 2)
            cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

应使用逻辑与，不能任意满足一个条件就输出。
