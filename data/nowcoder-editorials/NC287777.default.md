## 音符

### 题意

按各音符持续拍数，查询零起算时刻正在播放哪个音符。

### 思路

prefix[i] 为前 i 个音符的总拍数，第 i 个音符占据 [prefix[i-1],prefix[i])。给定 t，找第一个严格大于 t 的结束时间，它的下标就是答案。严格比较恰好把切换时刻归到下一个音符。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    vector<long long> prefix(n + 1);
    for (int i = 1; i <= n; i++) {
        int duration;
        cin >> duration;
        prefix[i] = prefix[i - 1] + duration;
    }
    while (q--) {
        long long t;
        cin >> t;
        cout << upper_bound(prefix.begin() + 1, prefix.end(), t) - prefix.begin() << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(n)$，每次查询 $O(\log n)$，空间 $O(n)$。

### 易错点

t 从零开始，音符编号从一开始。不能在 t 恰等于 prefix[i] 时继续返回第 i 个音符。
