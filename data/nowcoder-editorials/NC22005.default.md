## 计算机内存

### 题意

计算 n MB 内存最多存放多少个四字节整数。

### 思路

先用两次乘 1024 将 MB 换为字节，再除四，所以每 MB 可存 262144 个整数。只需乘这个常数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << n * 262144;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

本题采用 1024 进位，不能按十进制的一千换算。
