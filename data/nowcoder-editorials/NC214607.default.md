## 前天是哪天

### 题意

求一个合法公历日期的前两天，并保持补零格式。

### 思路

连续执行两次“退一天”：日减一，若变零就退到上一个月，再令日为该月的天数；一月之前还要回到上一年的十二月。二月的天数按退回后的实际年份判断。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int y, m, d;
    char sep;
    cin >> y >> sep >> m >> sep >> d;
    for (int step = 0; step < 2; step++) {
        d--;
        if (d == 0) {
            m--;
            if (m == 0) {
                y--;
                m = 12;
            }
            int days[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
            if (y % 400 == 0 || (y % 4 == 0 && y % 100 != 0))
                days[2] = 29;
            d = days[m];
        }
    }
    cout << setfill('0') << setw(4) << y << '-' << setw(2) << m << '-' << setw(2) << d;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

年初可能退到输入年份范围以外，仍应正常输出；月份与日期不足两位都要补零。
