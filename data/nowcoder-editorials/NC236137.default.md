## Palindrome Game (hard version)

### 题意

翻0付1，非回文且前步非反转时可免费反转，费用少者胜。

### 思路

统计总0数z和不相等的对称对数d。若d=0，免费反转暂不能用：z=1时先手必须承担最后一次修改而输；z为偶数时后手用镜像回应也赢；z为奇数且>1时先手先改中心，再利用后手打破对称后的免费反转取得优势。z=0时双方费用都是0，平局。

若d>0，先手可先免费反转，把必须付费的责任交给后手。除一种边界外先手胜：恰有一个不对称对、总共两个0、中心也是0时，双方可以各付1，结果平局。此时一个0来自不对称对，另一个来自中心；其他非回文状态先手均可保持免费操作优势。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        string s;
        cin >> n >> s;
        int zeros = count(s.begin(), s.end(), '0'), different = 0;
        for (int i = 0; i < n / 2; i++)
            different += s[i] != s[n - 1 - i];
        if (!zeros)
            cout << "DRAW\n";
        else if (!different)
            cout << ((zeros > 1 && zeros % 2) ? "ALICE\n" : "BOB\n");
        else if (different == 1 && zeros == 2 && n % 2 && s[n / 2] == '0')
            cout << "DRAW\n";
        else
            cout << "ALICE\n";
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n)$，空间 $O(n)$ 存串。

### 易错点

非回文时也不能连续两步反转，这正是费用策略成立的条件。全1串无需操作，应平局。
