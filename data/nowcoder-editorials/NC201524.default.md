## KiKi学程序设计基础

### 题意

把题面给出的两行 C 与 C++ 输出语句原样输出。

### 思路

题目让我们输出代码文字。用原始字符串保存引号、反斜杠和分号，其中反斜杠 n 必须作为两个字符出现。两条语句之间才是真实换行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout << R"code(printf("Hello world!\n");
cout << "Hello world!" << endl;)code";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不能真的执行题面中的两条语句，否则只会输出两次 Hello world。
