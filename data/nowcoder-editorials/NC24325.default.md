## [USACO 2012 Mar S]Flowerpot

### 题意

选最窄的水平花盆区间，使接到的雨滴最高与最低落地时间差至少 D。

### 思路

落地速度为一，时间差就是窗口内 y 的最大值减最小值。按 x 排序后，维护窗口的最大 y、最小 y 两条单调队列。每次扩张右端，只要高度差已至少 D，就记录 x[right]-x[left] 并移出左端，继续尝试更窄区间；不再满足时再扩张右端。两队列各自按下标移除过期项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, d;
    cin >> n >> d;
    vector<pair<int, int>> drops(n);
    for (auto &[x, y] : drops)
        cin >> x >> y;
    sort(drops.begin(), drops.end());
    deque<int> maximum, minimum;
    int left = 0, answer = INT_MAX;
    for (int right = 0; right < n; right++) {
        while (!maximum.empty() && drops[maximum.back()].second <= drops[right].second)
            maximum.pop_back();
        while (!minimum.empty() && drops[minimum.back()].second >= drops[right].second)
            minimum.pop_back();
        maximum.push_back(right);
        minimum.push_back(right);
        while (!maximum.empty() &&
               drops[maximum.front()].second - drops[minimum.front()].second >= d) {
            answer = min(answer, drops[right].first - drops[left].first);
            if (maximum.front() == left)
                maximum.pop_front();
            if (minimum.front() == left)
                minimum.pop_front();
            left++;
        }
    }
    cout << (answer == INT_MAX ? -1 : answer);
    return 0;
}
```

### 复杂度

排序 $O(n\log n)$，滑动窗口 $O(n)$，空间 $O(n)$。

### 易错点

雨滴落在盆边也算命中，所以宽度就是端点坐标之差，不加一。同一 x 可有不同高度的雨滴，最小宽度可能为零。
