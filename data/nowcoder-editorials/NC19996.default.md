## [HAOI2015]树上染色

### 题意

恰染K个黑点，最大化黑黑距离和加白白距离和。

### 思路

按边计贡献。孩子子树大小s、其中黑点j时，经过父子边的同色点对数为 j*(K−j)+(s−j)*(N−K−s+j)，乘边长就是这条边对全局距离和的贡献。

树上背包dp[u][j]维护u子树恰有j黑点的最大内部边贡献，合并孩子时枚举其黑点数，把孩子dp及这条边的贡献加进来。子树计数还不能超过全局白点总数，非法状态设负无穷。黑白对称，先将K替成min(K,N−K)可缩小状态。点只初始化成黑或白，边的贡献在合并其下方子树时恰算一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    k = min(k, n - k);
    Tree tree(n);
    for (int i = 1; i < n; i++) {
        int a, b;
        long long w;
        cin >> a >> b >> w;
        tree.add(a - 1, b - 1, w);
    }
    tree.root(0);
    const long long neg = -(1LL << 60);
    vector<int> size(n, 1);
    vector<vector<long long>> dp(n);
    for (int index = n - 1; index >= 0; index--) {
        int u = tree.order[index];
        dp[u].assign(min(k, 1) + 1, 0);
        for (auto [v, w] : tree.edge[u])
            if (v != tree.parent[u]) {
                int cap = min(k, size[u] + size[v]);
                vector<long long> next(cap + 1, neg);
                for (int a = 0; a < (int)dp[u].size(); a++)
                    if (dp[u][a] != neg)
                        for (int b = 0; b < (int)dp[v].size() && a + b <= cap; b++)
                            if (dp[v][b] != neg && size[u] + size[v] - a - b <= n - k) {
                                long long white = size[v] - b;
                                long long contribution =
                                    (1LL * b * (k - b) + white * (n - k - white)) * w;
                                next[a + b] = max(next[a + b], dp[u][a] + dp[v][b] + contribution);
                            }
                size[u] += size[v];
                dp[u].swap(next);
            }
    }
    cout << dp[0][k];
    return 0;
}
```

### 复杂度

按实际子树大小做卷积，全部分叉规模乘积合计 $O(n^2)$，时间 $O(n^2)$，空间上界 $O(nK)$。

### 易错点

只统计同色无序点对，不能把黑白点对算入。贡献公式用全局K与N−K，不能用当前已合并部分代替。
