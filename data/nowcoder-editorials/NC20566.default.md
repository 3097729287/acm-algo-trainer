## [SCOI2010]游戏

### 题意

每件装备有两个可选属性，只能用一次，求能连续覆盖从1开始的多少种属性。

### 思路

把属性值看成点，每件装备是一条连接两个属性的边，选某属性相当于把一条未用边分配给端点。一个连通块若有环，可以沿环循环分配，树枝各分配父边，因此所有点都能覆盖；若无环，则是树，边数比点数少一，至多覆盖少一个点。反之只要指定某个不覆盖的点为根，其他点各用父边，就能全部覆盖。

因此一个树形连通块中不能把所有属性都包含在目标前缀里；它最大的属性编号必须留在前缀之外，故答案至多该块最大编号减一。所有树块取这个界的最小值，带环块不限制。用并查集维护块大小、最大编号、装备边数即可，孤立属性同样是零边树，会自然截断缺失编号。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int values = 10000;
    int n;
    cin >> n;
    DSU dsu(values);
    vector<int> edgeCount(values + 1), maximum(values + 1);
    iota(maximum.begin(), maximum.end(), 0);
    while (n--) {
        int a, b;
        cin >> a >> b;
        a = dsu.find(a);
        b = dsu.find(b);
        if (a == b)
            edgeCount[a]++;
        else {
            if (dsu.size[a] < dsu.size[b])
                swap(a, b);
            dsu.parent[b] = a;
            dsu.size[a] += dsu.size[b];
            edgeCount[a] += edgeCount[b] + 1;
            maximum[a] = max(maximum[a], maximum[b]);
        }
    }
    int answer = values;
    for (int v = 1; v <= values; v++)
        if (dsu.find(v) == v && edgeCount[v] < dsu.size[v])
            answer = min(answer, maximum[v] - 1);
    cout << answer;
    return 0;
}
```

### 复杂度

属性上限 $A=10000$，时间 $O((n+A)\alpha(A))$，空间 $O(A)$。

### 易错点

同一属性对出现多次是多条独立装备边，可以形成环。两个属性相同形成自环，也能覆盖该属性。
