## [NOIP2004]津津的储蓄计划

### 题意

逐月收三百元、支付预算、把整百存给妈妈；首次不足输出负月份，否则年末存款返还两成利息。

### 思路

维护手头 cash 与累计存款 saved。每月加三百再扣预算，若为负则立即输出负的月份；否则把 cash/100 个整百存入，手头只留 cash%100。年末输出 cash+saved*120/100，存款本来是整百，整数计算精确。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int cash = 0, saved = 0;
    for (int month = 1; month <= 12; month++) {
        int expense;
        cin >> expense;
        cash += 300 - expense;
        if (cash < 0) {
            cout << -month;
            return 0;
        }
        saved += cash / 100 * 100;
        cash %= 100;
    }
    cout << cash + saved * 120 / 100;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

存给妈妈的钱年内不能取出应急；利息只加到存款上，手头零钱不计息。
