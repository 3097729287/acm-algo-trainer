## 矩阵消除游戏

### 题意

矩阵k次选择行或列清零，最大得分。

### 思路

所有权值为正，重复清零不会再加分，结果只由选中的行、列集合决定。枚举行子集，先取得这些行全部权值；每列只计算未被选中行的剩余和，再选最大的k−行数列。k≥min(n,m)可直接清空所有行或所有列，答案为全矩阵和。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    vector<vector<long long>> a(n, vector<long long>(m));
    long long total = 0;
    for (auto &row : a)
        for (auto &x : row) {
            cin >> x;
            total += x;
        }
    if (k >= min(n, m)) {
        cout << total;
        return 0;
    }
    long long answer = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        int rows = __builtin_popcount((unsigned)mask);
        if (rows > k)
            continue;
        vector<long long> column(m);
        long long score = 0;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++) {
                if (mask >> i & 1)
                    score += a[i][j];
                else
                    column[j] += a[i][j];
            }
        sort(column.rbegin(), column.rend());
        for (int j = 0; j < k - rows && j < m; j++)
            score += column[j];
        answer = max(answer, score);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(2^n(nm+m\log m))$，空间 $O(nm)$。

### 易错点

行列交点只计一次，选列时必须用删去所选行后的剩余列和。多余回合可重复清零，不会降低分数。
