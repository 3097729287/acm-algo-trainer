## 整数个数

### 题意

统计给出的整数中一、五、十分别出现多少次。

### 思路

用下标零到十的频次数组，每读到一个数就增加对应位置。最后按一、五、十的顺序输出三个计数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int k;
    cin >> k;
    int count[11] = {};
    for (int i = 0; i < k; i++) {
        int x;
        cin >> x;
        count[x]++;
    }
    cout << count[1] << ' ' << count[5] << ' ' << count[10];
    return 0;
}
```

### 复杂度

时间 $O(k)$，额外空间 $O(1)$。

### 易错点

题目正文规定只有一组输入，不要把 k 当作测试组数。
