## 指纹锁

### 题意

维护指纹集合：与已有值差不超过 k 时忽略新增，区间删除，区间存在性查询。

### 思路

用 set 按数值存储指纹。任一操作只关心 [x-k,x+k]：lower_bound(x-k) 找到可能的第一个元素，若它不大于右端点就说明存在匹配。添加时按此条件决定是否插入；删除时从这个迭代器开始逐个删除直到越过右端点。每个被删除元素都源自此前一次成功插入，所有删除的总量不超过操作数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, k;
    cin >> m >> k;
    set<int> values;
    for (int i = 0; i < m; i++) {
        string op;
        int x;
        cin >> op >> x;
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
        auto it = values.lower_bound(x - k);
        bool exists = it != values.end() && *it <= x + k;
        if (op == "add") {
            if (!exists)
                values.insert(x);
        } else if (op == "query")
            cout << (exists ? "Yes" : "No") << '\n';
        else {
            while (it != values.end() && *it <= x + k)
                it = values.erase(it);
        }
    }
    return 0;
}
```

### 复杂度

总时间 $O(m\log m)$，集合空间 $O(m)$。删除的元素总数受成功添加次数限制。

### 易错点

删除会移除区间里全部指纹，不要求集合里恰好存在 x。样例行末有解释性注释，读取指令和值后忽略该行余下内容。
