## 模拟战役

### 题意

攻击引发八邻域连锁爆炸，双方轮流攻击，求清空敌军后最多剩余己方炮数。

### 思路

每张4行地图中，八邻接的大炮连通块会被一次攻击全部摧毁。设敌军有 k 块，则必须攻击 k 次，前 k−1 次后敌军会反击并摧毁我方当前开炮所在块，最后一次敌军清空，不会反击。故我方至少需要 k 块；为损失最少，前 k−1 次依次牺牲最小的块，最后用任意剩余块开炮。若敌军本来为空无需攻击；我方块数不足则不可能。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m;
    cin >> m;
    auto components = [&]() {
        vector<string> grid(4);
        for (auto &row : grid)
            cin >> row;
        vector<int> sizes;
        for (int r = 0; r < 4; r++)
            for (int c = 0; c < m; c++)
                if (grid[r][c] == '*') {
                    vector<pair<int, int>> queue{{r, c}};
                    grid[r][c] = '.';
                    for (size_t head = 0; head < queue.size(); head++) {
                        auto [x, y] = queue[head];
                        for (int dx = -1; dx <= 1; dx++)
                            for (int dy = -1; dy <= 1; dy++) {
                                int xx = x + dx, yy = y + dy;
                                if (xx >= 0 && xx < 4 && yy >= 0 && yy < m && grid[xx][yy] == '*') {
                                    grid[xx][yy] = '.';
                                    queue.push_back({xx, yy});
                                }
                            }
                    }
                    sizes.push_back(queue.size());
                }
        return sizes;
    };
    auto enemy = components();
    auto ours = components();
    int k = enemy.size(), answer = accumulate(ours.begin(), ours.end(), 0);
    if (k > (int)ours.size())
        cout << -1;
    else {
        sort(ours.begin(), ours.end());
        for (int i = 0; i < k - 1; i++)
            answer -= ours[i];
        cout << answer;
    }
    return 0;
}
```

### 复杂度

时间 $O(m\log m)$，空间 $O(m)$。

### 易错点

输入前四行是司机，后四行才是齐齐。连锁按八方向相邻，最后一击后没有反击。
