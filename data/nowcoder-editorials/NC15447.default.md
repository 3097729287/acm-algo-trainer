## wyh的问题

### 题意

从指定灯开始，沿直线关掉所有路灯，移动期间未关灯都耗电，最小化总能耗。

### 思路

经过一盏灯时关掉不会花时间，也不会使后续更差，所以已关灯一定是包含起点的连续区间。dp[l][r][0/1]记录已关[l,r]、人站左/右端的最少耗能。继续去l−1或r+1时，移动耗时为距离，耗能等于距离乘“此次出发前所有未关灯的功率和”。区间功率用前缀和计算。起点灯立即关掉，初态区间仅起点且代价0。按区间长度递增，向两侧扩展。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        int start;
        cin >> start;
        start--;
        vector<long long> position(n), power(n), prefix(n + 1);
        for (int i = 0; i < n; i++) {
            cin >> position[i] >> power[i];
            prefix[i + 1] = prefix[i] + power[i];
        }
        const long long inf = 1LL << 60;
        vector<vector<array<long long, 2>>> dp(n, vector<array<long long, 2>>(n, {inf, inf}));
        dp[start][start] = {0, 0};
        for (int length = 1; length <= n; length++)
            for (int l = max(0, start - length + 1); l <= start && l + length <= n; l++) {
                int r = l + length - 1;
                if (r < start)
                    continue;
                long long remaining = prefix[n] - (prefix[r + 1] - prefix[l]);
                for (int side = 0; side < 2; side++)
                    if (dp[l][r][side] != inf) {
                        int p = side ? r : l;
                        if (l > 0)
                            dp[l - 1][r][0] =
                                min(dp[l - 1][r][0],
                                    dp[l][r][side] + (position[p] - position[l - 1]) * remaining);
                        if (r + 1 < n)
                            dp[l][r + 1][1] =
                                min(dp[l][r + 1][1],
                                    dp[l][r][side] + (position[r + 1] - position[p]) * remaining);
                    }
            }
        cout << min(dp[0][n - 1][0], dp[0][n - 1][1]) << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n^2)$。

### 易错点

移动到下一盏灯的途中，它仍然亮着，剩余功率要在扩展区间前计算。输入灯已按位置排序，多组读至EOF。
