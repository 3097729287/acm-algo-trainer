## Cow Contest

> 原题：[P2419](https://www.luogu.com.cn/problem/P2419)
> 解法：传递闭包确定谁比谁强，再检查与所有人的关系 · C++17

### 题意

胜负始终由不同的真实实力决定，资料没有矛盾。根据部分比赛结果，统计具体名次已经可以唯一确定的奶牛数量。



### 思路

用 $reach[u][v]$ 表示已知 $u$ 强于 $v$。对每个中转点 $k$，若 $u$ 能到 $k$、$k$ 能到 $v$，就补上 $u$ 能到 $v$。完成 Floyd 传递闭包后，若对一头牛 $u$，其余每头牛 $v$ 都满足 $reach[u][v]$ 或 $reach[v][u]$，则 $u$ 的名次确定。只数直接比赛会漏掉间接胜负。

时间 $O(n^3)$，空间 $O(n^2)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<bool>> reach(n + 1, vector<bool>(n + 1));
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        reach[u][v] = true;
    }
    for (int k = 1; k <= n; k++)
        for (int u = 1; u <= n; u++)
            if (reach[u][k])
                for (int v = 1; v <= n; v++)
                    reach[u][v] = reach[u][v] || reach[k][v];
    int answer = 0;
    for (int u = 1; u <= n; u++) {
        bool fixed = true;
        for (int v = 1; v <= n; v++)
            if (v != u && !reach[u][v] && !reach[v][u])
                fixed = false;
        if (fixed)
            ++answer;
    }
    cout << answer << '\n';
    return 0;
}
```

### 易错点

Floyd 的中转点循环放最外层；统计可推导的全部关系；一个人的名次确定不要求全体排名唯一。
