## BFS

### 题意

忽略大小写找 Bob 第一次出现的零起始位置，没有则输出负一。

### 思路

先把整串转成小写，再用 find 查找固定子串 bob。find 返回的第一个位置就是答案，找不到时返回 string::npos，需要显式改成负一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    for (char &c : s)
        c = tolower(static_cast<unsigned char>(c));
    auto p = s.find("bob");
    if (p == string::npos)
        cout << -1;
    else
        cout << p;
    return 0;
}
```

### 复杂度

固定模式长度为三，时间 $O(|S|)$，字符串空间 $O(|S|)$。

### 易错点

题名里的 BFS 是题目自定义名称，这里是字符串匹配，不需要图搜索。
