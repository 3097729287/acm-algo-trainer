## 选择颜色

### 题意

n 个有顺序的人围成环，相邻颜色不同，使用 c 种颜色计数。

### 思路

环的染色数为 (c-1)^n+(-1)^n(c-1)。可用递推证明：把 n 点环最后一条边先去掉，路径有 c(c-1)^(n-1) 种染法；其中首尾同色者把首尾合并后对应 n-1 点环，所以 C[n]=c(c-1)^(n-1)-C[n-1]。从 C[2]=c(c-1) 开始代入即可归纳得到公式。用快速幂算第一项，再按 n 奇偶加减 c-1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 10007;
    long long n, c;
    cin >> n >> c;
    long long base = c - 1, exponent = n, answer = 1;
    while (exponent) {
        if (exponent & 1)
            answer = answer * base % mod;
        base = base * base % mod;
        exponent >>= 1;
    }
    answer += n % 2 ? -(c - 1) : c - 1;
    cout << (answer % mod + mod) % mod;
    return 0;
}
```

### 复杂度

时间 $O(\log n)$，额外空间 $O(1)$。

### 易错点

人有固定顺序，旋转后的着色仍算不同，不要再除以 n。奇数环减法后应规范到非负模值。
