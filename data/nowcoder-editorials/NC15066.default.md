## 小牛再战

### 题意

从一堆取正数后可把其余部分分给其他非空堆，判断胜负。

### 思路

将非空堆排序。必败态恰是每种堆大小出现偶数次，也就是排序后两两相等。

这类局面不能一步到另一类必败态：若选中堆从a降到b，任意阈值t∈(b,a]上，达到t的堆数少1。要恢复所有阈值的偶数性，其他堆至少共增加a−b颗；但本步还取走了正数，可分配总数严格小于a−b，矛盾。

反过来，奇数堆时，选最大堆，把其余排序后每一对较小堆补到较大堆，所需总补数小于最大堆，取走余下正数并清空该堆，就到必败态。偶数堆且不两两相等时，仍选最大堆，将它降到最小堆大小，补齐中间相邻配对；能取走的数正好是原排序每对差之和，严格为正。故所有其他局面都能一步到必败态。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n && n) {
        vector<int> a;
        for (int i = 0; i < n; i++) {
            int x;
            cin >> x;
            if (x)
                a.push_back(x);
        }
        sort(a.begin(), a.end());
        bool lose = a.size() % 2 == 0;
        for (int i = 0; i + 1 < (int)a.size(); i += 2)
            if (a[i] != a[i + 1])
                lose = false;
        cout << (lose ? "Lose\n" : "Win\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

不能按普通Nim异或判断，取后转移石子会改变其必败集合。空堆不能接收新石子，因此先忽略已有空堆。
