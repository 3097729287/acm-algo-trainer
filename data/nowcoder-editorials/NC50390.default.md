## 布局 Layout

### 题意

按编号不下降排队，朋友距离有上限、敌人距离有下限，求首尾最大间距或矛盾、无界。

### 思路

设位置x1≤…≤xN。统一写成x[v]≤x[u]+w：顺序给i+1→i权0；朋友A<B要求x[B]−x[A]≤D，连A→B权D；敌人要求x[B]−x[A]≥D，连B→A权−D。原输入描述把差值顺序写反，按“距离”和样例中的正间距理解为后者减前者。

先把所有点距离置0，Bellman-Ford检查全图负环，有则无任何合法位置，输出−1。可行后，从1重新求最短路；每条1到N的路径都给首尾差一个上界，最紧者是最短距离，并可由差分约束势函数达到。若N不可达，则没有有限上界，输出−2；否则输出最短距离。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, close, far;
    cin >> n >> close >> far;
    struct Edge {
        int a, b;
        long long w;
    };
    vector<Edge> edges;
    for (int i = 1; i < n; i++)
        edges.push_back({i, i - 1, 0});
    while (close--) {
        int a, b;
        long long d;
        cin >> a >> b >> d;
        edges.push_back({a - 1, b - 1, d});
    }
    while (far--) {
        int a, b;
        long long d;
        cin >> a >> b >> d;
        edges.push_back({b - 1, a - 1, -d});
    }
    vector<long long> d(n);
    for (int round = 1; round <= n; round++) {
        bool changed = false;
        for (auto e : edges)
            if (d[e.b] > d[e.a] + e.w) {
                d[e.b] = d[e.a] + e.w;
                changed = true;
            }
        if (!changed)
            break;
        if (round == n) {
            cout << -1;
            return 0;
        }
    }
    const long long inf = 1LL << 60;
    fill(d.begin(), d.end(), inf);
    d[0] = 0;
    for (int round = 1; round < n; round++) {
        bool changed = false;
        for (auto e : edges)
            if (d[e.a] != inf && d[e.b] > d[e.a] + e.w) {
                d[e.b] = d[e.a] + e.w;
                changed = true;
            }
        if (!changed)
            break;
    }
    cout << (d[n - 1] == inf ? -2 : d[n - 1]);
    return 0;
}
```

### 复杂度

时间 $O(N(N+M_L+M_D))$，空间 $O(N+M_L+M_D)$。

### 易错点

必须先全图判可行性，不能只判从1可达的负环。目标虽是最大距离，差分约束的上界模型用最短路。
