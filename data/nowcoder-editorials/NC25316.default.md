## 统计数据正负个数

### 题意

统计十个整数中正数和负数各有几个。

### 思路

读入十次，大于零时增加正数计数，小于零时增加负数计数。零不属于两类，因此两个计数之和可以小于十。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int positive = 0, negative = 0;
    for (int i = 0; i < 10; i++) {
        int x;
        cin >> x;
        if (x > 0)
            positive++;
        if (x < 0)
            negative++;
    }
    cout << "positive:" << positive << '\n' << "negative:" << negative;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

标签与冒号按样例输出，零不能算成正数。
