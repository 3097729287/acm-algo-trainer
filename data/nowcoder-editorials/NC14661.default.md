## 简单的数据结构

### 题意

支持双端插删、整体反转、输出与少量排序操作。

### 思路

用 deque 保存物理顺序，再用 reversed 标志表示逻辑方向。反转只切换标志；逻辑头尾的插删依标志映射到物理头尾。输出按逻辑方向遍历。排序次数最多十次，可以直接把 deque 升序排序并把 reversed 清零，令逻辑顺序确为从小到大。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    deque<int> a;
    bool reversed = false;
    while (m--) {
        int op;
        cin >> op;
        if (op == 1 || op == 3) {
            int x;
            cin >> x;
            bool front = (op == 1) != reversed;
            if (front)
                a.push_front(x);
            else
                a.push_back(x);
        } else if (op == 2 || op == 4) {
            bool front = (op == 2) != reversed;
            if (front)
                a.pop_front();
            else
                a.pop_back();
        } else if (op == 5)
            reversed = !reversed;
        else if (op == 6) {
            cout << a.size() << '\n';
            for (int i = 0; i < (int)a.size(); i++) {
                if (i)
                    cout << ' ';
                cout << a[reversed ? a.size() - 1 - i : i];
            }
            cout << '\n';
        } else {
            sort(a.begin(), a.end());
            reversed = false;
        }
    }
    return 0;
}
```

### 复杂度

普通操作 $O(1)$，每次输出 $O(n)$，每次排序 $O(n\log n)$；输出、排序合计至多十次，空间 $O(n)$。

### 易错点

整体反转后，头插和尾插的物理位置也必须随之反转。排序应清除反转标志。输出末尾不留空格。
