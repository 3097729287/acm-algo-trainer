## 凸多边形的划分

### 题意

凸多边形三角剖分，最小化各三角形三顶点权值乘积之和。

### 思路

固定区间端点l、r所连的边，最后与这条边相邻的三角形第三点必为某个k，左右剩余多边形独立。转移dp[l][r]=min(dp[l][k]+dp[k][r]+a[l]*a[k]*a[r])，k严格在l、r之间；少于三个点代价0。N≤50、每权小于十亿，总值小于48*10^27，超过64位但在128位范围内，使用unsigned __int128保存并手动十进制输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<unsigned long long> a(n);
    for (auto &x : a)
        cin >> x;
    using Big = unsigned __int128;
    vector<vector<Big>> dp(n, vector<Big>(n));
    for (int length = 3; length <= n; length++)
        for (int l = 0; l + length <= n; l++) {
            int r = l + length - 1;
            dp[l][r] = ~Big(0);
            for (int k = l + 1; k < r; k++)
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k][r] + Big(a[l]) * a[k] * a[r]);
        }
    Big value = dp[0][n - 1];
    string result;
    do {
        result += char('0' + value % 10);
        value /= 10;
    } while (value);
    reverse(result.begin(), result.end());
    cout << result;
    return 0;
}
```

### 复杂度

时间 $O(n^3)$，空间 $O(n^2)$。

### 易错点

乘法前先转128位，否则中间乘积已溢出。这里分界点k同时属于两子多边形，不能误写成互不共享端点的石子合并转移。
