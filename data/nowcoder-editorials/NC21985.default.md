## 【模板】牛牛学说话之-整数

### 题意

读入一个整数并输出它。

### 思路

用 int 接收输入，再将该变量交给 cout。题目允许负数，范围一万以内不需要特殊的大整数类型。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << n << '\n';
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

输出读到的数值，不输出变量名字或额外提示。
