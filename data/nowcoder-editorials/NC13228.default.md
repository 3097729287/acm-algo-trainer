## 倒水

### 题意

把水缸中的部分水加入各杯，使各杯最终温度相同，求能达到的最高温度。

### 思路

记各杯总水量为 V、总的温度乘体积为 H，初始最低和最高温度为 low、high。混水只能让每杯温度向水缸温度 T 靠近，不能有限次越过或恰好到达 T（除非原来就是 T）。若 T>high，最高共同温度是用完 C 升后的 (H+TC)/(V+C)，且它必须至少为 high；这也充分，因为每杯所需加入量 c[i](X-t[i])/(T-X) 都非负，合计恰为 C。若 T<low，共同温度不能高于 low；取 X=low 最省冷水，所需总量为 (H-low V)/(low-T)，不超过 C 就可行。若 T 夹在温度范围内，只有所有杯原来都等于 T 才可行。用整数交叉相乘判断可行性，最后才做除法输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long t, capacity;
    cin >> n >> t >> capacity;
    long long volume = 0, heat = 0, low = 10001, high = 0;
    for (int i = 0; i < n; i++) {
        long long temperature, c;
        cin >> temperature >> c;
        volume += c;
        heat += temperature * c;
        low = min(low, temperature);
        high = max(high, temperature);
    }
    bool possible = false;
    long double answer = 0;
    if (t > high) {
        possible = heat + t * capacity >= high * (volume + capacity);
        answer = (heat + (long double)t * capacity) / (volume + capacity);
    } else if (t < low) {
        possible = heat - low * volume <= capacity * (low - t);
        answer = low;
    } else if (low == high) {
        possible = true;
        answer = low;
    }
    if (!possible)
        cout << "Impossible\n";
    else
        cout << "Possible\n" << fixed << setprecision(4) << answer << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n)$，只保存汇总量，额外空间 $O(1)$。

### 易错点

不要求倒光水缸。降温时多倒水反而降低共同温度，样例也只用了 1.5 升而非全部两升。杯间不能互相倒水。
