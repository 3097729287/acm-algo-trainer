## 子串查询

### 题意

按原题的明确定义，判断每个查询串是否可从 s 中按顺序选出，允许不连续。

### 思路

原题把允许不连续选择的子序列称为子串，例子中 abc 的 ac 也算，故按这个定义处理。预处理 next[i][c]，表示从位置 i 起第一个字符 c 的位置，不存在记 n。从右向左复制下一行并覆盖当前字母即可。查询从位置零开始，每取到一个字母，就跳到它的位置之后；不存在则失败。每次取最早位置，给后面保留的选择最多，因此贪心判定正确。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    string s;
    cin >> n >> q >> s;
    vector<array<int, 26>> next(n + 1);
    next[n].fill(n);
    for (int i = n - 1; i >= 0; i--) {
        next[i] = next[i + 1];
        next[i][s[i] - 'a'] = i;
    }
    while (q--) {
        string t;
        cin >> t;
        int position = 0;
        bool valid = true;
        for (char c : t) {
            int found = next[position][c - 'a'];
            if (found == n) {
                valid = false;
                break;
            }
            position = found + 1;
        }
        cout << (valid ? "YES\n" : "NO\n");
    }
    return 0;
}
```

### 复杂度

预处理 $O(26n)$，全部查询 $O(\sum|t|)$，空间 $O(26n)$。

### 易错点

必须使用不同且递增的下标，匹配后跳到 found+1。不能按通常的连续子串匹配来解释此题。
