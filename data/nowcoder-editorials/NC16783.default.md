## 拼数

### 题意

排列整数的连接顺序，使拼成的十进制字符串最大。

### 思路

比较两个串 a、b 时，应比较 a+b 与 b+a，而不是比较单独数值或字典序。若 a+b 更大，就让 a 在前；相邻交换论证说明每一对都满足该顺序后，总串不能再改进。保存字符串后按这个比较器排序并连接输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> a(n);
    for (string &s : a)
        cin >> s;
    sort(a.begin(), a.end(), [](const string &a, const string &b) { return a + b > b + a; });
    for (string s : a)
        cout << s;
    return 0;
}
```

### 复杂度

最大串长为 $L$ 时，时间 $O(nL\log n)$，字符串空间 $O(nL)$。

### 易错点

前缀关系最容易出错，例如九和九十一应比较 991 与 919，而不是看长串更长。整个答案可能很长，不转成整数。
