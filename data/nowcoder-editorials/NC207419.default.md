## 李在赣神魔

### 题意

把字符方阵顺时针旋转九十度后输出。

### 思路

旋转后第 i 行来自原矩阵第 i 列，且原行号从 n-1 递减到零。因此输出 b[i][j]=a[n-1-j][i]，无需另建结果矩阵。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> a(n);
    for (string &s : a)
        cin >> s;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++)
            cout << a[n - 1 - j][i];
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间与棋盘空间均为 $O(n^2)$。

### 易错点

顺时针旋转不等于转置，原矩阵左下角应成为输出左上角。
