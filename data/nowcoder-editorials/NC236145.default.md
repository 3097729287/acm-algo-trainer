## Northcott Game

### 题意

每行黑白棋子可移动不可越过，黑方先走。

### 思路

把每行两棋子之间的空格数g=abs(T−J)−1看作Nim堆。朝对方移动会减小g，恰是取石子。背离对方移动虽会增大g，但对方可沿同方向跟进同样格数，恢复原间隔；这种无效退让只能有限进行，无法破坏Nim必胜策略。因此全部间隔异或非0先手胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    while (cin >> n >> m) {
        int total = 0;
        for (int i = 0; i < n; i++) {
            int a, b;
            cin >> a >> b;
            total ^= abs(a - b) - 1;
        }
        cout << (total ? "I WIN!\n" : "BAD LUCK!\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n)$，空间 $O(1)$。

### 易错点

看的是两子之间空格数，距离要减1。题目允许棋子左右顺序任意，取绝对值。
