## gpa

### 题意

最多删 k 门课，最大化按学分加权的平均分。

### 思路

总能删满 k 门而不变差：保留多于 n-k 门时，其中至少有一门分数不高于当前加权均值，删去它不会降低均值。因此固定保留 keep=n-k 门。二分均分 x，每门打分 s[i]*(c[i]-x)，选最大的 keep 项；若和非负就能达到 x。和总学分始终为正，移项判定等价。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    int keep = n - k;
    vector<long double> credits(n), score(n), transformed(n);
    for (auto &x : credits)
        cin >> x;
    long double high = 0;
    for (auto &x : score) {
        cin >> x;
        high = max(high, x);
    }
    long double low = 0;
    for (int iteration = 0; iteration < 65; iteration++) {
        long double mid = (low + high) / 2;
        for (int i = 0; i < n; i++)
            transformed[i] = credits[i] * (score[i] - mid);
        if (keep < n)
            nth_element(transformed.begin(), transformed.begin() + keep, transformed.end(),
                        greater<long double>());
        if (accumulate(transformed.begin(), transformed.begin() + keep, 0.0L) >= 0)
            low = mid;
        else
            high = mid;
    }
    cout << fixed << setprecision(12) << low;
    return 0;
}
```

### 复杂度

固定 $K=65$ 轮，平均时间 $O(Kn)$，空间 $O(n)$。

### 易错点

学分不同，不能简单删分数最低的 k 门或按未加权平均处理。k=0 时仍应保留全部课程。
