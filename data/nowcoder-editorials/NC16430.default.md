## [NOIP2016]蚯蚓

### 题意

每秒切最长蚯蚓，只有未新生的蚯蚓增长 q，按步数和最终排名抽样输出。

### 思路

用全局增量 offset 表示所有已有蚯蚓的统一增长，保存长度减 offset 后的基准值。当前最大实际长度是最大基准值加 offset。切分后先把 offset 增加 q，再把两个新段减去新的 offset 存入，保证它们本秒不增长。

初始蚯蚓排序后是一条递减队列，两种切分结果也分别按生成顺序递减：相邻两次被切的实际长度 x、y 满足 y<=x+q，而 floor(py)-floor(px)<=q，所以扣除每秒增长后，第一种新段不会变大；第二种同理。于是只需三条队列，每次比较三个队首取最大，不用数百万次堆操作。切完后按同样三路归并取最终降序排名。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, growth, u, v, interval;
    cin >> n >> m >> growth >> u >> v >> interval;
    vector<int> queues[3];
    queues[0].resize(n);
    queues[1].reserve(m);
    queues[2].reserve(m);
    for (int &x : queues[0])
        cin >> x;
    sort(queues[0].begin(), queues[0].end(), greater<int>());
    size_t head[3] = {};
    long long offset = 0;
    auto take = [&]() {
        int selected = -1;
        for (int j = 0; j < 3; j++)
            if (head[j] < queues[j].size() &&
                (selected == -1 || queues[j][head[j]] > queues[selected][head[selected]]))
                selected = j;
        return queues[selected][head[selected]++];
    };
    bool first = true;
    auto output = [&](long long x) {
        if (!first)
            cout << ' ';
        first = false;
        cout << x;
    };
    for (int second = 1; second <= m; second++) {
        long long length = take() + offset;
        if (second % interval == 0)
            output(length);
        long long left = length * u / v, right = length - left;
        offset += growth;
        queues[1].push_back((int)(left - offset));
        queues[2].push_back((int)(right - offset));
    }
    cout << '\n';
    first = true;
    for (int rank = 1; rank <= n + m; rank++) {
        long long length = take() + offset;
        if (rank % interval == 0)
            output(length);
    }
    cout << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n+n+m)$，空间 $O(n+m)$。

### 易错点

切段乘 u 前先用 long long，不能浮点乘 p 再取整。新段扣的是增长后的 offset。本题基准值范围约在 -14亿至1亿，可用 int 节省队列空间；实际长度和乘法仍用 long long。
