## 组队

### 题意

选尽量多的人，使任意两人的能力差不超过 k。

### 思路

排序后，一个团队合法等价于最大值减最小值不超过 k。若选了两个端点，中间的人也可全部加入而不破坏条件，所以只需找最长合法连续段。枚举右端点，不断右移左端点直到极差不超过 k，再更新长度；左端点只会向右移动。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        long long k;
        cin >> n >> k;
        vector<long long> a(n);
        for (auto &x : a)
            cin >> x;
        sort(a.begin(), a.end());
        int left = 0, answer = 0;
        for (int right = 0; right < n; right++) {
            while (a[right] - a[left] > k)
                left++;
            answer = max(answer, right - left + 1);
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

排序 $O(n\log n)$，双指针 $O(n)$，空间 $O(n)$。

### 易错点

限制是任意两人，不能仅检查排序后相邻两人的差；链式相近不保证首尾相近。
