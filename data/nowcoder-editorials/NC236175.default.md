## 任务安排

### 题意

依赖任务并行执行，求最短总工期内可以拖延的任务。

### 思路

拓扑排序计算最早开始early[v]=max(early[u]+time[u])，所有任务最早完成时间最大值即总工期T。若拓扑点数不足n，存在环而无法完成。

再逆拓扑计算最迟开始：所有任务初始latest[u]=T−time[u]，对每条u→v用latest[v]−time[u]缩小latest[u]。early[u]<latest[u]说明存在正松弛，可以拖延；相等则位于某条关键路径。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> duration(n), early(n), latest(n);
    for (auto &x : duration)
        cin >> x;
    vector<vector<int>> edge(n);
    vector<int> indegree(n);
    while (m--) {
        int u, v;
        cin >> u >> v;
        u--;
        v--;
        edge[u].push_back(v);
        indegree[v]++;
    }
    queue<int> queue;
    for (int u = 0; u < n; u++)
        if (!indegree[u])
            queue.push(u);
    vector<int> order;
    long long total = 0;
    while (!queue.empty()) {
        int u = queue.front();
        queue.pop();
        order.push_back(u);
        total = max(total, early[u] + duration[u]);
        for (int v : edge[u]) {
            early[v] = max(early[v], early[u] + duration[u]);
            if (--indegree[v] == 0)
                queue.push(v);
        }
    }
    if ((int)order.size() != n) {
        cout << -1;
        return 0;
    }
    for (int u = 0; u < n; u++)
        latest[u] = total - duration[u];
    for (int i = n - 1; i >= 0; i--) {
        int u = order[i];
        for (int v : edge[u])
            latest[u] = min(latest[u], latest[v] - duration[u]);
    }
    vector<int> answer;
    for (int u = 0; u < n; u++)
        if (early[u] < latest[u])
            answer.push_back(u + 1);
    cout << answer.size() << '\n';
    for (int i = 0; i < (int)answer.size(); i++)
        cout << answer[i] << (i + 1 == (int)answer.size() ? '\n' : ' ');
    if (answer.empty())
        cout << '\n';
    return 0;
}
```

### 复杂度

时间、空间均 $O(n+m)$。

### 易错点

多个终点都受同一个总工期约束，不能只从任意一个终点反推。
