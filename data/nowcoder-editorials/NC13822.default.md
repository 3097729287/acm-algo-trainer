## Keep In Line

### 题意

已知每人进出队时刻且从队首出队，统计从未插队的人。

### 思路

按进队次序给每人一个递增编号。某人出队时，若还有比他更早进队的人尚未出队，他必然曾插到别人前面；反之他没有越过仍在队里的早到者，就是正常排队。维护最早尚未离开的编号 front，出队时标记删除，再让 front 跳过所有已离开的编号。每个编号只被跳过一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        unordered_map<string, int> id;
        vector<bool> removed(n + 2);
        int total = 0, front = 1, answer = 0;
        for (int i = 0; i < n; i++) {
            string op, name;
            cin >> op >> name;
            if (op == "in")
                id[name] = ++total;
            else {
                int current = id[name];
                if (current == front)
                    answer++;
                removed[current] = true;
                while (front <= total && removed[front])
                    front++;
            }
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

哈希查名期望 $O(n)$，编号扫描总计 $O(n)$，空间 $O(n)$。

### 易错点

新入队者不一定站在队尾，不能把实际队伍简单当普通 FIFO 队列重放；这里保存的是到达顺序，并用实际出队信息惰性删除。
