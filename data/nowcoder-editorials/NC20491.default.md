## [ZJOI2010]COUNT 数字计数

### 题意

求[a,b]内每个十进制数码出现总次数。

### 思路

对数字d枚举位权place。非零d：完整高位周期贡献high*place；当前位>d再加place，等于d加low+1，小于则不加。d=0时须排除前导零：high>0才有贡献，先加(high−1)*place，再根据当前位补充。分别计算1..b和1..a−1后相减。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long countDigit(long long n, int digit) {
    if (n <= 0)
        return 0;
    long long answer = 0;
    for (long long place = 1; place <= n;) {
        long long high = n / place / 10, current = n / place % 10, low = n % place;
        if (digit) {
            answer += high * place;
            if (current > digit)
                answer += place;
            else if (current == digit)
                answer += low + 1;
        } else if (high) {
            answer += (high - 1) * place;
            answer += current == 0 ? low + 1 : place;
        }
        if (place > n / 10)
            break;
        place *= 10;
    }
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long a, b;
    cin >> a >> b;
    for (int d = 0; d < 10; d++)
        cout << countDigit(b, d) - countDigit(a - 1, d) << (d == 9 ? '\n' : ' ');
    return 0;
}
```

### 复杂度

时间 $O(10\log b)$，空间 $O(1)$。

### 易错点

原题区间全为正数，数字0自身不加入。输出次数用64位。
