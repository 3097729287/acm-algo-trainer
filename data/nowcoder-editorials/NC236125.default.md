## Rake It In

### 题意

4×4棋盘交替选择2×2加总分再旋转，最多6步，求最优总分。

### 思路

只有9个可选2×2区域，深度2k≤6，直接极小极大搜索。Alice层取最大、Bob层取最小；每步先记四格和，再逆时针旋转，递归返回剩余最优分后加本步和。退出分支时恢复四格。

用Alpha-Beta界剪掉不可能影响祖先决策的分支。因递归值是“此后额外得分”，传入子节点的上下界都减去当前gain。Alice优先尝试高gain、Bob优先低gain，只改变搜索顺序，不改变结果。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int k;
        cin >> k;
        array<int, 16> board;
        for (int &x : board)
            cin >> x;
        auto search = [&](auto &&self, int remaining, bool maximize, int alpha, int beta) -> int {
            if (!remaining)
                return 0;
            vector<pair<int, int>> moves;
            for (int r = 0; r < 3; r++)
                for (int c = 0; c < 3; c++) {
                    int p = r * 4 + c;
                    int gain = board[p] + board[p + 1] + board[p + 4] + board[p + 5];
                    moves.push_back({gain, p});
                }
            sort(moves.begin(), moves.end());
            if (maximize)
                reverse(moves.begin(), moves.end());
            int best = maximize ? INT_MIN : INT_MAX;
            for (auto [gain, p] : moves) {
                array<int, 4> old = {board[p], board[p + 1], board[p + 5], board[p + 4]};
                board[p] = old[1];
                board[p + 1] = old[2];
                board[p + 5] = old[3];
                board[p + 4] = old[0];
                int value = gain + self(self, remaining - 1, !maximize, alpha - gain, beta - gain);
                board[p] = old[0];
                board[p + 1] = old[1];
                board[p + 5] = old[2];
                board[p + 4] = old[3];
                if (maximize) {
                    best = max(best, value);
                    alpha = max(alpha, best);
                } else {
                    best = min(best, value);
                    beta = min(beta, best);
                }
                if (alpha >= beta)
                    break;
            }
            return best;
        };
        cout << search(search, 2 * k, true, -1000000000, 1000000000) << '\n';
    }
    return 0;
}
```

### 复杂度

最坏 $O(9^{2k})$，排序9种动作视常数；递归空间 $O(k)$。

### 易错点

双方每步都向同一个总分加分，Bob也不是减去本步得分。旋转是逆时针，恢复棋盘必须与旋转前完全一致。
