## [SHOI2017]期末考试

### 题意

通过调拨或增派老师提前成绩公告，连同学生等待费用，最小化总不愉快度。

### 思路

枚举所有课程最迟在第 D 天公布。晚于 D 的课程共需 need=Σmax(b[i]-D,0) 单位提前量；早于 D 的课程允许被推迟 room=Σmax(D-b[i],0) 单位，仍不超过 D。若调拨单价 A 比增派 B 便宜，就优先用 min(need,room) 单位调拨，其余增派；否则全用增派。学生等待费用为 C*Σmax(D-t[i],0)。

日期最大只有十万，可对 b 和 t 分别建立人数与日期和前缀，O(1) 求 need、room、等待天数，直接枚举 D=1 到 max(b)。超过原最迟日不会减少任何调整量，等待又只会增加，因此不需要。每个固定 D 的调整都能逐单位配对实现，取所有 D 的最小总费用就是答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long transfer, hire, wait;
    int n, m;
    cin >> transfer >> hire >> wait >> n >> m;
    const int limit = 100000;
    vector<long long> students(limit + 1), studentSum(limit + 1), courses(limit + 1),
        courseSum(limit + 1);
    for (int i = 0; i < n; i++) {
        int t;
        cin >> t;
        students[t]++;
        studentSum[t] += t;
    }
    int latest = 0;
    long long total = 0;
    for (int i = 0; i < m; i++) {
        int day;
        cin >> day;
        courses[day]++;
        courseSum[day] += day;
        total += day;
        latest = max(latest, day);
    }
    for (int day = 1; day <= limit; day++) {
        students[day] += students[day - 1];
        studentSum[day] += studentSum[day - 1];
        courses[day] += courses[day - 1];
        courseSum[day] += courseSum[day - 1];
    }
    long long answer = LLONG_MAX;
    for (long long day = 1; day <= latest; day++) {
        long long need = total - courseSum[day] - day * (m - courses[day]),
                  room = day * courses[day] - courseSum[day];
        long long moved = transfer < hire ? min(need, room) : 0;
        long long cost = moved * transfer + (need - moved) * hire +
                         (day * students[day] - studentSum[day]) * wait;
        answer = min(answer, cost);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

日期上限 $V=10^5$，时间 $O(n+m+V)$，空间 $O(V)$。

### 易错点

学生等待的是所有课程中的最晚公布日，不能按每门课分别计等待。调拨只能利用提前课程距离 D 的空余天数；把 A 与 B 比较后再决定是否值得调拨。
