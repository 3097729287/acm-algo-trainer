## 迷宫游戏

### 题意

树上随机游走、传回根或出口，求离开前走边次数期望。

### 思路

设E[u]为从u出发的剩余期望边数，k、e为传送和出口概率，q=1−k−e，t=q/degree。方程E[u]=kE[root]+q+t*ΣE[v]，传送不算走边。

以1为根消元，把非根子树表示成E[u]=A[u]E[parent]+B[u]E[root]+C[u]。代入儿子表达式，den=1−t*ΣA[child]，A=t/den、B=(k+tΣB)/den、C=(q+tΣC)/den。根没有父项，最终E[root]=C[root]/(1−B[root])。用后序一次完成树形消元。

先标出实际可达节点：只有q>0的节点能继续走向儿子。若可达节点没有任何正出口概率，必定无法离开，输出impossible；不可达子树不参与消元，避免无关方程的奇异性。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct EulerTree {
    int n;
    vector<vector<int>> edge;
    vector<int> parent, depth, in, out, order;
    EulerTree(int n) : n(n), edge(n + 1), parent(n + 1), depth(n + 1), in(n + 1), out(n + 1) {}
    void add(int u, int v) {
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    void root(int start) {
        vector<int> stack = {start};
        parent[start] = 0;
        order.clear();
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            in[u] = order.size() + 1;
            order.push_back(u);
            for (int v : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    depth[v] = depth[u] + 1;
                    stack.push_back(v);
                }
        }
        vector<int> size(n + 1, 1);
        for (int i = (int)order.size() - 1; i >= 0; i--) {
            int u = order[i];
            out[u] = in[u] + size[u] - 1;
            if (parent[u])
                size[parent[u]] += size[u];
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    EulerTree tree(n);
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        tree.add(u, v);
    }
    vector<long double> teleport(n + 1), exit(n + 1), walk(n + 1);
    for (int i = 1; i <= n; i++) {
        long double k, e;
        cin >> k >> e;
        teleport[i] = k / 100;
        exit[i] = e / 100;
        walk[i] = (100 - k - e) / 100;
    }
    tree.root(1);
    vector<bool> active(n + 1);
    active[1] = true;
    bool possible = false;
    for (int u : tree.order)
        if (active[u]) {
            possible = possible || exit[u] > 0;
            if (walk[u] > 0)
                for (int v : tree.edge[u])
                    if (tree.parent[v] == u)
                        active[v] = true;
        }
    if (!possible) {
        cout << "impossible";
        return 0;
    }
    vector<long double> a(n + 1), b(n + 1), c(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = tree.order[i];
        if (!active[u])
            continue;
        long double sa = 0, sb = 0, sc = 0, t = walk[u] / tree.edge[u].size();
        for (int v : tree.edge[u])
            if (tree.parent[v] == u && active[v]) {
                sa += a[v];
                sb += b[v];
                sc += c[v];
            }
        long double denominator = 1 - t * sa;
        a[u] = u == 1 ? 0 : t / denominator;
        b[u] = (teleport[u] + t * sb) / denominator;
        c[u] = (walk[u] + t * sc) / denominator;
    }
    cout << fixed << setprecision(12) << c[1] / (1 - b[1]);
    return 0;
}
```

### 复杂度

时间、空间均 $O(n)$。

### 易错点

出口和传送不增加边数，只有实际走边事件贡献q。树边是双向，必须保留父项再消元。
