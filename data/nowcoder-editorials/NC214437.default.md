## 拯救小a

### 题意

读入多行小写文本，直到单独的句点，统计字符 a 的总数。

### 思路

题目保证普通行只有小写字母，可以逐段用 cin 读取。遇到字符串等于句点时结束，否则累加这一段中 a 的出现次数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    long long ans = 0;
    while (cin >> s && s != ".")
        for (char c : s)
            if (c == 'a')
                ans++;
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(L)$，临时空间为最长行长度，$L$ 为总字符数。

### 易错点

不是只统计最后一行，也不把结束标记计入文本。
