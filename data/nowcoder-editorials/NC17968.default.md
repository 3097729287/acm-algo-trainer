## xor序列

### 题意

任意多次异或给定数，判断x能否变为y。

### 思路

重复异或相同元素两次抵消，所以问题等价于x xor y能否表示为给定数的子集异或。构造按最高位排列的二进制线性基；插入数时用已有同最高位向量消去，首次空位保存。查询也同样从高到低消去，最后归0则可表示。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    array<unsigned, 32> basis = {};
    for (int i = 0; i < n; i++) {
        unsigned x;
        cin >> x;
        for (int bit = 31; bit >= 0 && x; bit--)
            if (x >> bit & 1U) {
                if (basis[bit])
                    x ^= basis[bit];
                else {
                    basis[bit] = x;
                    break;
                }
            }
    }
    int q;
    cin >> q;
    while (q--) {
        unsigned x, y;
        cin >> x >> y;
        x ^= y;
        for (int bit = 31; bit >= 0 && x; bit--)
            if (x >> bit & 1U)
                x ^= basis[bit];
        cout << (!x ? "YES\n" : "NO\n");
    }
    return 0;
}
```

### 复杂度

时间 $O(32(n+q))$，空间 $O(32)$。

### 易错点

值相同可以不做任何操作。unsigned保存位模式并安全处理第31位。
