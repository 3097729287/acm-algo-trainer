## 牛牛的Link Power I

### 题意

所有标记1位置之间的无序距离和。

### 思路

从左向右遇到位置i为1时，它与之前所有1的距离和为count*i−sumPosition。将此值加入答案后，更新count与位置和。每对恰在右端点处理一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string s;
    cin >> n >> s;
    const long long mod = 1000000007;
    long long count = 0, position = 0, answer = 0;
    for (int i = 0; i < n; i++)
        if (s[i] == '1') {
            answer = (answer + count * i - position) % mod;
            count++;
            position += i;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(n)$ 存输入。

### 易错点

无序对只统计一次，不乘2。使用64位保存计数与位置乘积。
