## 长方体

### 题意

已知长方体在一个顶点相交的三个面的面积，求十二条棱长之和。

### 思路

设三条棱长为 x、y、z，三个面积分别为 xy、xz、yz。将前两个面积相乘再除第三个，得到 x 的平方；另两条棱同理。所求为四倍的三棱之和。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long double a, b, c;
    cin >> a >> b >> c;
    long double x = sqrtl(a * b / c), y = sqrtl(a * c / b), z = sqrtl(b * c / a);
    cout << llroundl(4 * (x + y + z));
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

输入的是面积而不是棱长；先用浮点计算，最后按题目的整数结果取整，避免浮点表示造成截断。
