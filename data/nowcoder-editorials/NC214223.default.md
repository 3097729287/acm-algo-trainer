## 整除判断

### 题意

判断 m 能否被 n 整除。

### 思路

若 m%n 等于零，整数商没有余数，输出 YES；否则输出 NO。输入均为正数，无须处理除零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, n;
    cin >> m >> n;
    cout << (m % n == 0 ? "YES" : "NO");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

整除的方向是 m 除以 n，不能颠倒。
