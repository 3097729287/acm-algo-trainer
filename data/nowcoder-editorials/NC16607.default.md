## 托米历险记

### 题意

按队伍顺序收取二十五元票款，判断能否从零零钱开始完成所有找零。

### 思路

维护二十五与五十元钞票数量。收五十元时消耗一张二十五；收一百元时优先用一张五十和一张二十五，否则用三张二十五。优先消耗五十元能保留用途更广的二十五元，不会使后续找零更差。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int c25 = 0, c50 = 0;
    bool ok = true;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (!ok)
            continue;
        if (x == 25)
            c25++;
        else if (x == 50) {
            if (c25 == 0)
                ok = false;
            else {
                c25--;
                c50++;
            }
        } else if (c50 > 0 && c25 > 0) {
            c50--;
            c25--;
        } else if (c25 >= 3)
            c25 -= 3;
        else
            ok = false;
    }
    cout << (ok ? "YES" : "NO");
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

不能改变排队顺序，也不能用当前这一张一百元给自己找零。
