## Lost Cows

### 题意

已知每个位置前面更小编号数，恢复1到n的排列。

### 思路

从最后一个位置倒推。此时尚未分配的编号恰好属于当前及其前面，若前面有c个更小编号，当前编号就是剩余编号中的第c+1小。树状数组记录每个编号是否未使用，二进制提升查第k个1，找到后删除。第一个位置默认c=0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> smaller(n + 1), answer(n + 1);
    for (int i = 2; i <= n; i++)
        cin >> smaller[i];
    Fenwick bit(n);
    for (int i = 1; i <= n; i++)
        bit.add(i, 1);
    for (int i = n; i >= 1; i--) {
        int p = 0, k = smaller[i] + 1, step = 1;
        while (step <= n / 2)
            step <<= 1;
        for (; step; step >>= 1)
            if (p + step <= n && bit.tree[p + step] < k) {
                p += step;
                k -= bit.tree[p];
            }
        answer[i] = p + 1;
        bit.add(p + 1, -1);
    }
    for (int i = 1; i <= n; i++)
        cout << answer[i] << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

必须倒序恢复，正序时尚不清楚哪些更小编号会出现在后方。
