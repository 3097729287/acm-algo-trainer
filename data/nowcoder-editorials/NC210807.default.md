## 刷野

### 题意

按顺序删除怪物，每次受自身攻击及当时两邻增益伤害，求最小总伤害。

### 思路

设dp[l][r]为删除区间[l,r]且两侧l−1、r+1暂不删除的最小伤害。枚举区间内最后删除的k，之前左右两段独立删除，最后k只受固定边界增益b[l−1]+b[r+1]及自身a[k]。转移dp[l][r]=min_k(dp[l][k−1]+dp[k+1][r]+a[k]+b[l−1]+b[r+1])。两端增设0增益哨兵，按长度递增计算。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n + 2), b(n + 2);
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    for (int i = 1; i <= n; i++)
        cin >> b[i];
    vector<vector<long long>> dp(n + 2, vector<long long>(n + 2));
    for (int len = 1; len <= n; len++)
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;
            dp[l][r] = LLONG_MAX / 4;
            for (int k = l; k <= r; k++)
                dp[l][r] = min(dp[l][r], dp[l][k - 1] + dp[k + 1][r] + a[k] + b[l - 1] + b[r + 1]);
        }
    cout << dp[1][n];
    return 0;
}
```

### 复杂度

时间 $O(n^3)$，空间 $O(n^2)$。

### 易错点

枚举最后删除者，边界才固定；枚举第一个删除者不能把剩余两边直接独立相加。
