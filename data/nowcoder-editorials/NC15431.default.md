## 比较月亮大小

### 题意

给定若干天的月亮大小，判断下一天变大还是变小，无法判断则输出负一。

### 思路

最后一天为零时一定开始变大，为十五时一定开始变小。其余位置若至少记录两天，就沿用最后两天的增减趋势；若只记录一天且不在端点，两个方向都可能，输出负一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    if (a.back() == 0)
        cout << "UP";
    else if (a.back() == 15)
        cout << "DOWN";
    else if (n == 1)
        cout << -1;
    else
        cout << (a[n - 1] > a[n - 2] ? "UP" : "DOWN");
    return 0;
}
```

### 复杂度

时间与数组空间均为 $O(n)$。

### 易错点

记录只有一天时也可能可以判断，零与十五这两个端点应先处理。
