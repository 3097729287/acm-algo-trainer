## [CQOI2013]新数独

### 题意

只有相邻格大小关系的数独，要求每行、列、宫均为1到9排列，输出唯一解。

### 思路

每格保存九位候选集，初始为1到9。将全部大小关系统一为a<b。传播两类约束：已确定格的数字从同行、同列、同宫的其他格删除；每个排列单位内，某数字若只剩一个可放位置就强制放入。对a<b，删除a中不小于b最大候选的值，并删除b中不大于a最小候选的值。反复传播直到没有变化，任何候选集为空或某单位某数字无处可放就判矛盾。

若仍未填完，选候选数最少且多于一个的格，逐一固定候选后递归。每个分支复制候选数组，回退无需逐项撤销。传播仅删除已经不可能的值，分支枚举其余全部值，因此保持完备性。输入按每个宫带的五行读取：横、竖、横、竖、横。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    vector<array<int, 9>> units;
    for (int r = 0; r < 9; r++) {
        array<int, 9> row{}, column{}, block{};
        for (int j = 0; j < 9; j++) {
            row[j] = r * 9 + j;
            column[j] = j * 9 + r;
            block[j] = (r / 3 * 3 + j / 3) * 9 + r % 3 * 3 + j % 3;
        }
        units.push_back(row);
        units.push_back(column);
        units.push_back(block);
    }
    vector<pair<int, int>> less;
    for (int band = 0; band < 3; band++)
        for (int local = 0; local < 3; local++) {
            int r = band * 3 + local;
            for (int box = 0; box < 3; box++)
                for (int j = 0; j < 2; j++) {
                    char sign;
                    cin >> sign;
                    int a = r * 9 + box * 3 + j, b = a + 1;
                    less.push_back(sign == '<' ? make_pair(a, b) : make_pair(b, a));
                }
            if (local < 2)
                for (int c = 0; c < 9; c++) {
                    char sign;
                    cin >> sign;
                    int a = r * 9 + c, b = a + 9;
                    less.push_back(sign == '^' ? make_pair(a, b) : make_pair(b, a));
                }
        }
    auto propagate = [&](array<int, 81> &domain) {
        bool changed = true;
        while (changed) {
            changed = false;
            for (auto &unit : units) {
                for (int p : unit) {
                    int mask = domain[p];
                    if (!mask)
                        return false;
                    if ((mask & (mask - 1)) == 0)
                        for (int q : unit)
                            if (p != q && (domain[q] & mask)) {
                                domain[q] &= ~mask;
                                if (!domain[q])
                                    return false;
                                changed = true;
                            }
                }
                for (int digit = 0; digit < 9; digit++) {
                    int position = -1, count = 0;
                    for (int p : unit)
                        if (domain[p] >> digit & 1) {
                            position = p;
                            count++;
                        }
                    if (!count)
                        return false;
                    if (count == 1 && domain[position] != (1 << digit)) {
                        domain[position] = 1 << digit;
                        changed = true;
                    }
                }
            }
            for (auto [a, b] : less) {
                if (!domain[a] || !domain[b])
                    return false;
                int maxB = 31 - __builtin_clz((unsigned)domain[b]);
                int nextA = domain[a] & ((1 << maxB) - 1);
                if (!nextA)
                    return false;
                if (nextA != domain[a]) {
                    domain[a] = nextA;
                    changed = true;
                }
                int minA = __builtin_ctz((unsigned)domain[a]);
                int nextB = domain[b] & ~((1 << (minA + 1)) - 1);
                if (!nextB)
                    return false;
                if (nextB != domain[b]) {
                    domain[b] = nextB;
                    changed = true;
                }
            }
        }
        return true;
    };
    array<int, 81> answer{};
    auto dfs = [&](auto &&self, array<int, 81> domain) -> bool {
        if (!propagate(domain))
            return false;
        int selected = -1, fewest = 10;
        for (int p = 0; p < 81; p++) {
            int count = __builtin_popcount((unsigned)domain[p]);
            if (count > 1 && count < fewest) {
                selected = p;
                fewest = count;
            }
        }
        if (selected == -1) {
            answer = domain;
            return true;
        }
        int options = domain[selected];
        while (options) {
            int bit = options & -options;
            options ^= bit;
            domain[selected] = bit;
            if (self(self, domain))
                return true;
        }
        return false;
    };
    array<int, 81> initial;
    initial.fill(511);
    dfs(dfs, initial);
    for (int r = 0; r < 9; r++)
        for (int c = 0; c < 9; c++)
            cout << (__builtin_ctz((unsigned)answer[r * 9 + c]) + 1) << (c == 8 ? '\n' : ' ');
    return 0;
}
```

### 复杂度

固定81格，最坏仍为指数搜索。每次传播至少删除一个候选，共至多729次删除，单次扫描至多 $O(27\cdot9^2+108)$；递归栈保存至多81个候选数组。

### 易错点

v表示上格大于下格，^表示上格小于下格；只给每宫内部的相邻关系，不存在跨宫的额外符号。候选集用0到8位代表数字1到9。
