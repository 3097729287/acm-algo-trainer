## Atlantis

### 题意

多个实数坐标矩形求并面积，多组0结束，严格按两位小数报告。

### 思路

n仅100，可把全部矩形左右边界排序去重，按相邻x坐标切成竖条。每条内部没有矩形边界，覆盖情况恒定：收集完全穿过这条竖条的矩形y区间，排序并合并得到总覆盖高度，乘条宽加入面积。各竖条互不重叠，所有矩形并集恰好被覆盖。无需对坐标取整，也无需开平面网格。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, tc = 0;
    while (cin >> n && n) {
        struct Rectangle {
            long double x1, y1, x2, y2;
        };
        vector<Rectangle> a(n);
        vector<long double> xs;
        for (auto &r : a) {
            cin >> r.x1 >> r.y1 >> r.x2 >> r.y2;
            xs.push_back(r.x1);
            xs.push_back(r.x2);
        }
        sort(xs.begin(), xs.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        long double area = 0;
        for (size_t i = 1; i < xs.size(); i++) {
            vector<pair<long double, long double>> intervals;
            for (auto r : a)
                if (r.x1 <= xs[i - 1] && r.x2 >= xs[i])
                    intervals.push_back({r.y1, r.y2});
            sort(intervals.begin(), intervals.end());
            long double covered = 0, left = 0, right = 0;
            bool active = false;
            for (auto [l, r] : intervals) {
                if (!active) {
                    left = l;
                    right = r;
                    active = true;
                } else if (l > right) {
                    covered += right - left;
                    left = l;
                    right = r;
                } else
                    right = max(right, r);
            }
            if (active)
                covered += right - left;
            area += (xs[i] - xs[i - 1]) * covered;
        }
        cout << "Test case #" << ++tc << '\n'
             << "Total explored area: " << fixed << setprecision(2) << area << "\n\n";
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2\log n)$，空间 $O(n)$。

### 易错点

坐标不是整数，不能离散化后把下标差当实际长度。每组报告后输出空行，Test case #后没有冒号。
