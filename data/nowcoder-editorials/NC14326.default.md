## Rails

### 题意

列车按一到 N 进入单端车站，判断多组目标出站排列是否可行。

### 思路

维护下一节尚未进站的车厢编号。对于目标 x，若栈顶还不是 x，就把后续车厢依次压入，直到栈顶为 x 或全部已进站。栈顶匹配就弹出；无法匹配则当前目标不可能实现。每个目标排列都要重新开始。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n && n != 0) {
        while (true) {
            vector<int> target(n);
            cin >> target[0];
            if (target[0] == 0)
                break;
            for (int i = 1; i < n; i++)
                cin >> target[i];
            vector<int> st;
            int next = 1;
            bool ok = true;
            for (int x : target) {
                while ((st.empty() || st.back() != x) && next <= n)
                    st.push_back(next++);
                if (!st.empty() && st.back() == x)
                    st.pop_back();
                else {
                    ok = false;
                    break;
                }
            }
            cout << (ok ? "Yes" : "No") << '\n';
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

每个目标排列时间与栈空间均为 $O(N)$。

### 易错点

输入有两层结束标记：块内单独零结束当前 N 的排列，外层 N 为零结束全部输入。每块结果之后还需空行。
