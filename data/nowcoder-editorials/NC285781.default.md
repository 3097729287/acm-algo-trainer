## 【模板】二叉树遍历Ⅰ-A ‖ 深度优先：DFS

### 题意

根据左右儿子关系找到不固定的根，输出前、中、后序遍历。

### 思路

给每个儿子标记有父亲，唯一未被标记的点就是根。用显式栈模拟递归的三个阶段：阶段零先记录前序，再访问左子树；阶段一记录中序，再访问右子树；阶段二记录后序。栈里的阶段表示从相应子树返回后应继续做什么，因此顺序与递归一致。输入允许二十万结点长链，显式栈避免系统调用栈溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<int, 2>> child(n + 1);
    vector<bool> hasParent(n + 1);
    for (int i = 1; i < n; i++) {
        int u, v, side;
        cin >> u >> v >> side;
        child[u][side] = v;
        hasParent[v] = true;
    }
    int root = 1;
    while (hasParent[root])
        root++;
    vector<int> orders[3];
    vector<pair<int, int>> stack{{root, 0}};
    while (!stack.empty()) {
        auto [u, stage] = stack.back();
        stack.pop_back();
        orders[stage].push_back(u);
        if (stage < 2) {
            stack.push_back({u, stage + 1});
            int v = child[u][stage];
            if (v)
                stack.push_back({v, 0});
        }
    }
    for (const auto &order : orders) {
        for (int i = 0; i < n; i++) {
            if (i)
                cout << ' ';
            cout << order[i];
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

根不一定是一，不能按无向邻接表随意确定左右儿子。输入 o=0 为左、o=1 为右。
