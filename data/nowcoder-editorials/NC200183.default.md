## 牛妹和01串

### 题意

把整个零一串切为最多段，每段都至少有一个零和一个一。

### 思路

从左到右累积当前段出现过的数字，一旦零和一都出现，就立刻切一段并清空标记。任何合法第一段的终点都不会比这个最早位置更早，提前结束第一段会给后续留下更多字符，因此不会减少后面可切段数。末尾若只剩一种数字，把它并入上一段，不改变段数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int mask = 0, answer = 0;
    for (char c : s) {
        mask |= 1 << (c - '0');
        if (mask == 3) {
            answer++;
            mask = 0;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(|s|)$，额外空间 $O(1)$。

### 易错点

必须覆盖全串，末尾剩余字符要并入已有最后一段。题目保证全串同时含零和一，所以至少可形成一段。
