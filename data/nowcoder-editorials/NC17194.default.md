## 送分题

### 题意

在不改三个数顺序的前提下加入加号、乘号和括号，求最大结果。

### 思路

两个运算位置共有四种加乘组合，括号只有先算左边和先算右边两种结构。去掉重复结果后，只需检查全加、全乘、两种先乘后加及两种括号乘法，共六个表达式。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, c;
    cin >> a >> b >> c;
    cout << max({a + b + c, a * b * c, a * b + c, a + b * c, (a + b) * c, a * (b + c)});
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不能交换输入顺序。出现一时，加法后再乘可能比全部相乘更大。
