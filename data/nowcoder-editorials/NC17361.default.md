## 鹏

### 题意

只把上升、可选的平顶、下降组成的完整山峰计为一次翻越。

### 思路

比较相邻高度，忽略相等的边，把剩余变化记为上升或下降。每当最近一次非零变化是上升，而当前变化是下降，就完整经过一个山峰。边界上的单纯上升或下降都不计数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long previous;
    cin >> previous;
    int direction = 0, ans = 0;
    for (int i = 1; i < n; i++) {
        long long x;
        cin >> x;
        int next = (x > previous) - (x < previous);
        if (next != 0) {
            if (direction == 1 && next == -1)
                ans++;
            direction = next;
        }
        previous = x;
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

平台可以有任意长度，同高度不应清除前一次上升方向。
