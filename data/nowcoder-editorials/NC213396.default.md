## B 是不是太迟了

### 题意

判断二〇二〇年的日期是否严格早于十月二十九日。

### 思路

输入的年、月、日都有固定宽度且补零，因此字符串字典序与日期先后顺序一致。与 2020/10/29 比较，小于才仍可训练。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    cout << (s < "2020/10/29" ? "No. It's not too late." : "QAQ");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

十月二十九日本身已经太迟，比较应为严格小于。
