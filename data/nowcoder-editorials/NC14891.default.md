## 旅游观光

### 题意

公交边价为 (i+j) mod (n+1)，买票后可重复使用，求游遍所有地点的最小票价。

### 思路

零价边只连接 i 与 n+1-i，形成 ceil(n/2) 个连通块。要连接它们至少需要块数减一条正价边，每条至少一元。按 1,n,2,n-1,3,n-2,… 行走，边价交替为零、一，恰花 floor((n-1)/2)，达到下界。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    cout << (n - 1) / 2;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

n 为奇数时中点独成一个零价连通块，n=1 时本来已经游遍，费用是零。
