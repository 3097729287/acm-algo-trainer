## The XOR Largest Pair

### 题意

从非负31位整数中选两数，最大化异或值。

### 思路

把每个整数从第30位到第0位插入二进制 Trie。查询 x 时，从高位到低位优先走与 x 当前位相反的分支，使结果这一位为一；不存在才走相同分支。高位一的收益超过所有低位之和，因此每步贪心成立。对所有 x 取查询结果的最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    vector<array<int, 2>> trie(1);
    trie.reserve(1 + 31 * n);
    for (int &x : a) {
        cin >> x;
        int node = 0;
        for (int b = 30; b >= 0; b--) {
            int bit = x >> b & 1;
            if (!trie[node][bit]) {
                trie[node][bit] = trie.size();
                trie.push_back({0, 0});
            }
            node = trie[node][bit];
        }
    }
    int answer = 0;
    for (int x : a) {
        int node = 0, value = 0;
        for (int b = 30; b >= 0; b--) {
            int bit = x >> b & 1;
            if (trie[node][bit ^ 1]) {
                value |= 1 << b;
                node = trie[node][bit ^ 1];
            } else
                node = trie[node][bit];
        }
        answer = max(answer, value);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(31n)$，最坏空间 $O(31n)$。

### 易错点

最高允许位是第30位，共31位。这里输出异或值，不是组成该值的两个原整数；重复数也可插入。
