## 收益

### 题意

客户独立决定是否投资，筹足L才赚M并支付分红，求期望净利润模P。

### 思路

将筹资金额压到0..L，L代表已筹足。f[j]是金额状态概率，g[j]是该状态下“分红总额乘概率”的和。客户投资概率p、分红c=m*r时，不投转移(f,g)*(1−p)，投资转移到min(L,j+m)，增加(p*f,p*(g+c*f))。每人使用新数组，避免同一客户重复选择。

最后只有L状态产生收益，期望为M*f[L]−g[L]。概率和利率都用整数乘100的模逆元表示，不用浮点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, l;
    long long profit;
    cin >> n >> l >> profit;
    constexpr long long mod = 1000000007, inv100 = 570000004;
    vector<long long> probability(l + 1), payout(l + 1);
    probability[0] = 1;
    while (n--) {
        int money, rate, percent;
        cin >> money >> rate >> percent;
        long long p = percent * inv100 % mod, q = (1 - p + mod) % mod,
                  cost = 1LL * money * rate % mod * inv100 % mod;
        vector<long long> nextProbability(l + 1), nextPayout(l + 1);
        for (int j = 0; j <= l; j++) {
            int to = min(l, j + money);
            nextProbability[j] = (nextProbability[j] + probability[j] * q) % mod;
            nextPayout[j] = (nextPayout[j] + payout[j] * q) % mod;
            nextProbability[to] = (nextProbability[to] + probability[j] * p) % mod;
            nextPayout[to] =
                (nextPayout[to] + (payout[j] + cost * probability[j] % mod) % mod * p) % mod;
        }
        probability.swap(nextProbability);
        payout.swap(nextPayout);
    }
    cout << (profit * probability[l] % mod - payout[l] + mod) % mod;
    return 0;
}
```

### 复杂度

时间 $O(nL)$，空间 $O(L)$。

### 易错点

筹资超额仍应支付全部投资者分红，所以只能压缩金额，不能截断分红。失败筹资不产生题目指定的成功分红。
