## Lucky Numbers

### 题意

统计至多n位、每位7或8的数。

### 思路

恰k位有2^k种，k从1到n相加为2^(n+1)−2。n≤55，64位整数足够。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << (1ULL << (n + 1)) - 2;
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

不包含空数字，所以减2；移位常数使用64位。
