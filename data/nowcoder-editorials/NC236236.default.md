## 分蛋糕

### 题意

随机圆周方位点能被一块等分扇形包含的概率。

### 思路

随机点落在圆盘内，其极角独立均匀。有r个点、分成p等份（p>2）时，若它们能被一个角宽2π/p的扇形包含，则覆盖扇形顺时针的首个点唯一；指定该点后，其余r−1点均落在它后方1/p圆周，概率(1/p)^(r−1)。r种首点情形互斥，答案r/p^(r−1)，用最大公约数约分。

当前页面把输入n、m的角色写反：若按“n草莓、m份”理解，样例3 4应为3/16；实际样例是4/27，对应3份、4草莓。参考代码按两组样例及来源模型采用第一个数为份数p、第二个数为草莓数r，并明确记录此题面矛盾。

### 参考代码

```python
import math
import sys

parts, points = map(int, sys.stdin.buffer.read().split())
numerator = points
denominator = parts ** (points - 1)
g = math.gcd(numerator, denominator)
print(f'{numerator // g}/{denominator // g}')
```

### 复杂度

大整数幂与gcd时间依位数而定，结果位数 $O(r\log p)$，空间同结果位数。

### 易错点

大整数分母可超过64位，不用浮点约分。若平台修正输入含义，应对应交换parts和points。
