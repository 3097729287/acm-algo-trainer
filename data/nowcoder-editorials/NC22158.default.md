## 牛牛学数列3

### 题意

累加分母为奇数交错前缀和的倒数，并保留三位小数。

### 思路

分母依次为 1、1-3、1-3+5 等。循环维护当前分母，奇数步加 2i-1，偶数步减 2i-1，再把其浮点倒数加入答案。分母实际交替为正 i 和负 i，始终不会为零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long denominator = 0;
    long double ans = 0;
    for (int i = 1; i <= n; i++) {
        denominator += (i % 2 ? 2LL * i - 1 : -(2LL * i - 1));
        ans += 1.0L / denominator;
    }
    cout << fixed << setprecision(3) << ans;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

倒数的分母是当前整段交错和，而不是新加入的单个奇数。
