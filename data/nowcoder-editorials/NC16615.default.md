## [NOIP2008]传纸条

### 题意

往返纸条的两条单调路径，内部同学只能帮一次，最大化参与者好感总和。

### 思路

把返回路径反向，两条路径都从左上到右下，每步向右或向下。同一步的行列和相同，记为step，因此只需状态(step,r1,r2)，列号分别为step−r1、step−r2。每条路上一时刻的行号要么不变（向右），要么少1（向下），共四种转移。

除公共起终点外，不允许两人本步在同一格；而任意一个格只会在固定的行列和时刻出现，所以仅这一检查就排除了整条路径的重复内部点。两路本步增量相加，公共端点只算一次，输入中端点为0。按step滚动存二维表。单行或单列的退化输入不存在可往返的内部中继，按0处理。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long twoPaths(const vector<vector<int>> &a, bool disjoint) {
    int rows = a.size(), cols = a[0].size();
    if (disjoint && (rows == 1 || cols == 1))
        return 0;
    const long long neg = -(1LL << 60);
    vector<vector<long long>> dp(rows, vector<long long>(rows, neg)), next = dp;
    dp[0][0] = a[0][0];
    for (int step = 1; step <= rows + cols - 2; step++) {
        for (auto &row : next)
            fill(row.begin(), row.end(), neg);
        int low = max(0, step - cols + 1), high = min(rows - 1, step);
        for (int r1 = low; r1 <= high; r1++)
            for (int r2 = low; r2 <= high; r2++) {
                if (disjoint && r1 == r2 && step != rows + cols - 2)
                    continue;
                long long previous = neg;
                for (int d1 = 0; d1 <= 1; d1++)
                    for (int d2 = 0; d2 <= 1; d2++)
                        if (r1 >= d1 && r2 >= d2)
                            previous = max(previous, dp[r1 - d1][r2 - d2]);
                if (previous == neg)
                    continue;
                long long gain = a[r1][step - r1];
                if (r1 != r2)
                    gain += a[r2][step - r2];
                next[r1][r2] = previous + gain;
            }
        dp.swap(next);
    }
    return dp[rows - 1][rows - 1];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols;
    cin >> rows >> cols;
    vector<vector<int>> a(rows, vector<int>(cols));
    for (auto &row : a)
        for (int &x : row)
            cin >> x;
    cout << twoPaths(a, true);
    return 0;
}
```

### 复杂度

时间 $O((m+n)m^2)$，空间 $O(m^2+mn)$。

### 易错点

不能先求一条最优路再删点求第二条，两条路径必须联合优化。只允许在起终点重合。
