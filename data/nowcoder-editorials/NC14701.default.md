## 取数游戏2

### 题意

每次从A的两端取一数，第i次乘B[i]，求全部取完的最大总值。

### 思路

dp[l][r]表示尚余A[l..r]时，从现在直到取完能获得的最大值。剩余长度len时，已经取了n−len个，所以当前乘数是B[n−len]。选择左端转到dp[l+1][r]，选择右端转到dp[l][r−1]，二者取最大。从长度1到n计算。滚动为dp[l]时，每一长度下l从小到大更新，dp[l]和dp[l+1]都仍是上一长度的值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        vector<long long> a(n), b(n), dp(n + 1);
        for (auto &x : a)
            cin >> x;
        for (auto &x : b)
            cin >> x;
        for (int length = 1; length <= n; length++)
            for (int l = 0; l + length <= n; l++) {
                int r = l + length - 1;
                long long multiplier = b[n - length];
                dp[l] = max(a[l] * multiplier + dp[l + 1], a[r] * multiplier + dp[l]);
            }
        cout << dp[0] << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2)$，空间 $O(n)$。

### 易错点

乘数取决于已取数量，不是剩余区间的左端点。滚动更新必须从小到大，反过来会读到本轮新状态。
