## 因数个数和

### 题意

多次求1..x的约数个数和。

### 思路

交换求和，每个约数d贡献它在1..x中的倍数个数floor(x/d)。相同商q=floor(x/l)持续到r=floor(x/q)，整段贡献q*(r−l+1)。每次跳到r+1，只有O(sqrt x)段。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    while (q--) {
        long long x;
        cin >> x;
        long long answer = 0;
        for (long long l = 1, r; l <= x; l = r + 1) {
            long long quotient = x / l;
            r = x / quotient;
            answer += quotient * (r - l + 1);
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每问时间 $O(\sqrt x)$，空间 $O(1)$。

### 易错点

这是约数个数和，不是约数值之和。答案使用64位。
