## 好串

### 题意

判断能否从空串反复插入 ab 得到目标串。

### 思路

把 a 当左括号、b 当右括号。插入 ab 不会使任何前缀中的 b 多于 a，也不改变总数相等。反过来，任何满足前缀余额非负且最终为零的非空串，都有一对相邻 ab；删去它后条件仍成立，递归即可回到空串。因此扫描维护 a 数减 b 数，并拒绝其他字母。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int balance = 0;
    bool ok = true;
    for (char c : s) {
        if (c == 'a')
            balance++;
        else if (c == 'b')
            balance--;
        else
            ok = false;
        if (balance < 0)
            ok = false;
    }
    cout << (ok && balance == 0 ? "Good" : "Bad");
    return 0;
}
```

### 复杂度

时间 $O(|S|)$，额外空间 $O(1)$。

### 易错点

只检查 a、b 总数相等不够，ba 的总数相等但首个前缀已经不合法。其他小写字母也不能由操作生成。
