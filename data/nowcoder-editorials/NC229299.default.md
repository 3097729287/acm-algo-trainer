## Subpermutation

### 题意

把n的全部排列按字典序连接，统计恰为1..m排列的连续窗口。

### 思路

窗口要么完全在一行n排列内，要么跨相邻两行的边界。行内把m个小数视为一个块，可任意排列m!，连同其余n−m个数共n−m+1个对象，所以行内数为m!*(n−m+1)!。

边界先枚举来自上一行尾部的小数个数k，1≤k<m。理想形态是上一行“前部小数A、中部大数B、尾部小数C”，所有≤m的数刚好占据A和C；每个k有m!*(n−m)!种。若BC严格递减，next_permutation的进位会改动A，使对应边界失败。固定C长度k时，BC的次序已被降序唯一确定，A可从m个小数中选择并排列，坏情况为C(m,k)*(m−k)!=m!/k!。其余形态可按保持不变的A对应到唯一边界窗口。

合计为m!*((n−m+1)!+(m−1)*(n−m)!−Σ(k=1..m−1)1/k!)，阶乘、逆阶乘及逆阶乘前缀和预处理后每问常数时间。

推导核对：[CCPC 2021网络重赛官方题解，Subpermutation](https://codeforces.com/gym/103492/attachments/download/15254/CCPC2021%E7%BD%91%E7%BB%9C%E8%B5%9B%E9%87%8D%E8%B5%9B%20%E9%A2%98%E8%A7%A3.pdf)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000007;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}
struct Combinations {
    vector<long long> factorial, inverse;
    Combinations(int n) : factorial(n + 1, 1), inverse(n + 1) {
        for (int i = 1; i <= n; i++)
            factorial[i] = factorial[i - 1] * i % mod;
        inverse[n] = power(factorial[n], mod - 2);
        for (int i = n; i >= 1; i--)
            inverse[i - 1] = inverse[i] * i % mod;
    }
    long long choose(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return factorial[n] * inverse[k] % mod * inverse[n - k] % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int limit = 1000000;
    Combinations comb(limit);
    vector<long long> prefix(limit + 1);
    for (int i = 1; i <= limit; i++)
        prefix[i] = (prefix[i - 1] + comb.inverse[i]) % mod;
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        long long inside = comb.factorial[n - m + 1],
                  boundary = (m - 1) * comb.factorial[n - m] % mod;
        long long value = (inside + boundary - prefix[m - 1] + mod) % mod;
        cout << comb.factorial[m] * value % mod << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(U+\log P)$，每问 $O(1)$，空间 $O(U)$。

### 易错点

m=1时没有跨行窗口，逆阶乘前缀和取0。不能把最后排列和第一排列再首尾相接。
