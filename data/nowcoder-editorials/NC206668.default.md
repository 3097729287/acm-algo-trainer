## 开学？

### 题意

星期 x 推迟 n 天后，求新的星期编号。

### 思路

先将一到七转换成零到六，经过 n 天后对七取余，再转换回一到七，答案为 (x-1+n)%7+1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int x, n;
    cin >> x >> n;
    cout << (x - 1 + n) % 7 + 1;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

对七取余前先减一，否则星期日会被输出为零。
