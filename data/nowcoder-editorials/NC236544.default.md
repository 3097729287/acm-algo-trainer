## [国家集训队]拉拉队排练

### 题意

所有奇数长度回文子串按长度降序，求前 K 个长度的乘积。

### 思路

用 Manacher 得到每个中心的最长奇回文长度。若某中心最长为 L，它就恰好给 L、L-2、……、1 各贡献一次。因此先按最长长度计数，再沿奇数长度从大到小累加后缀，得到每个长度的实际出现次数。每个长度取 min(剩余K,出现次数) 项，用快速幂把这一长度的重复乘法一次完成。全部用尽仍不足 K 则输出 -1。

Manacher 的 odd[i] 表示以 i 为中心、包含中心的最大奇回文半径，长度为 2odd[i]-1；even[i] 表示中心在 i-1 与 i 之间的最大偶回文半径，长度为 2even[i]。维护已知最靠右的回文区间，利用镜像位置的半径初始化，再只向未知部分扩展。右边界只会前进，全部扩展次数为线性。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct PalindromeRadii {
    vector<int> odd, even;
    explicit PalindromeRadii(const string &s) {
        int n = s.size();
        odd.resize(n);
        even.resize(n);
        int left = 0, right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 1 : min(odd[left + right - i], right - i + 1);
            while (i - k >= 0 && i + k < n && s[i - k] == s[i + k])
                k++;
            odd[i] = k;
            if (i + k - 1 > right) {
                left = i - k + 1;
                right = i + k - 1;
            }
        }
        left = 0;
        right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 0 : min(even[left + right - i + 1], right - i + 1);
            while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k])
                k++;
            even[i] = k;
            if (i + k - 1 > right) {
                left = i - k;
                right = i + k - 1;
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long k;
    string s;
    cin >> n >> k >> s;
    PalindromeRadii radius(s);
    vector<long long> count(n + 3);
    for (int r : radius.odd)
        count[2 * r - 1]++;
    const long long mod = 19930726;
    auto power = [&](long long a, long long exponent) {
        long long result = 1;
        while (exponent) {
            if (exponent & 1)
                result = result * a % mod;
            a = a * a % mod;
            exponent >>= 1;
        }
        return result;
    };
    long long answer = 1;
    for (int length = n % 2 ? n : n - 1; length >= 1 && k > 0; length -= 2) {
        count[length] += count[length + 2];
        long long take = min(k, count[length]);
        answer = answer * power(length, take) % mod;
        k -= take;
    }
    cout << (k ? -1 : answer);
    return 0;
}
```

### 复杂度

预处理 $O(n)$，选取阶段 $O(n\log(K+1))$ 的上界，空间 $O(n)$。

### 易错点

位置不同的相同回文也分别计数。只考虑奇数长度，K 最大万亿，不能逐项枚举。模数不必为素数，普通快速幂仍可用。
