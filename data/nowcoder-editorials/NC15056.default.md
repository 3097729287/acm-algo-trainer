## 竞赛技巧

### 题意

将多个时、分、秒三元组按时间递增排列。

### 思路

把每条时间保存为 tuple。tuple 的默认比较按第一项、第二项、第三项依次比较，正好等于按时、分、秒排序。输出仍使用三个整数，不改成带冒号的格式。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<tuple<int, int, int>> a(n);
    for (auto &[h, m, s] : a)
        cin >> h >> m >> s;
    sort(a.begin(), a.end());
    for (auto [h, m, s] : a)
        cout << h << ' ' << m << ' ' << s << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，数组空间 $O(n)$。

### 易错点

题目举例有冒号，但实际输入输出要求都是空格分隔的三个整数。
