## 标题统计

> 原题：[P5015](https://www.luogu.com.cn/problem/P5015)
> 解法：整行读取并跳过空白 · C++17

### 题意

标题由字母、数字和空格组成，统计其中非空格字符的个数。



### 思路

标题里的空格用于分隔词语，题目只计字母与数字。例如 `a b3` 有四个字符位置，但非空格只有 $a$、$b$、3，答案三。`cin >> s` 会在空格处停止，因此必须读完整一行。题面保证其它字符类型不会出现，逐个跳过空格即可；空标题或全空格标题的计数自然为零。

标题长为 L，时间 $O(L)$、空间 $O(L)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    getline(cin, s);
    int count = 0;
    for (char c : s)
        if (c != ' ')
            ++count;
    cout << count << '\n';
    return 0;
}
```

### 易错点

不能用字符串长度直接作为答案，也不能只读第一个词。
