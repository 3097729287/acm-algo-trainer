## [HEOI2012]采花

### 题意

查询区间中至少出现两次的颜色种数，单独一朵的颜色不采。

### 思路

查询按右端点排序，扫描前缀时，每种颜色只在它倒数第二次出现的位置放一个一；更早的标记清除。一个颜色在 [L,R] 至少出现两次，当且仅当它在前缀 R 中倒数第二次的位置不小于 L。所以树状数组的 [L,R] 区间和即答案。每次新颜色到来，先删旧的倒数第二位置，再把原最后位置升级为新的倒数第二位置。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

class FastInput {
    static const int size = 1 << 16;
    char buffer[size];
    int position = 0, available = 0;
    int get() {
        if (position == available) {
            available = fread(buffer, 1, size, stdin);
            position = 0;
            if (!available)
                return EOF;
        }
        return buffer[position++];
    }

  public:
    int next() {
        int c = get(), sign = 1;
        while (c != '-' && (c < '0' || c > '9'))
            c = get();
        if (c == '-') {
            sign = -1;
            c = get();
        }
        long long x = 0;
        while (c >= '0' && c <= '9') {
            x = x * 10 + c - '0';
            c = get();
        }
        return (int)(x * sign);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    FastInput input;
    int n = input.next(), colors = input.next(), m = input.next();
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++)
        a[i] = input.next();
    struct Query {
        int l, r, id;
    };
    vector<Query> queries(m);
    for (int i = 0; i < m; i++)
        queries[i] = {input.next(), input.next(), i};
    sort(queries.begin(), queries.end(), [](auto x, auto y) { return x.r < y.r; });
    vector<int> tree(n + 1), last(colors + 1), second(colors + 1), answers(m);
    auto change = [&](int p, int v) {
        for (int i = p; i <= n; i += i & -i)
            tree[i] += v;
    };
    auto sum = [&](int p) {
        int answer = 0;
        for (int i = p; i > 0; i -= i & -i)
            answer += tree[i];
        return answer;
    };
    int right = 0;
    for (auto q : queries) {
        while (right < q.r) {
            int color = a[++right];
            if (second[color])
                change(second[color], -1);
            second[color] = last[color];
            if (second[color])
                change(second[color], 1);
            last[color] = right;
        }
        answers[q.id] = sum(q.r) - sum(q.l - 1);
    }
    for (int x : answers)
        cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O(m\log m+(n+m)\log n)$，空间 $O(n+m+c)$，支持备注中的二百万规模。

### 易错点

问的是颜色数，不是花朵总数。不能使用“每种颜色最后一次出现”的标记，那会把只出现一次的颜色也算进来。
