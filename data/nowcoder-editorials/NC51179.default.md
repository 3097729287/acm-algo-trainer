## 选课

### 题意

恰选M门课程，有先修依赖，每课最多一个直接先修，最大化学分。

### 思路

将没有先修课的课程接到虚拟根0，虚拟根学分0。dp[u][j]表示选u且在其子树共选j门的最大分，初始dp[u][1]=本课学分。逐孩子做数量背包，可选孩子子树0门，或者选择一个包含孩子根的合法状态。中途不能从“不选u”状态接孩子，保证先修必选。处理完后给dp[u][0]=0，供父亲表示整棵不选。目标是dp[0][M+1]，多出的一个是虚拟根。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> children(n + 1);
    vector<int> credit(n + 1);
    for (int u = 1; u <= n; u++) {
        int p;
        cin >> p >> credit[u];
        children[p].push_back(u);
    }
    vector<int> order{0};
    for (size_t i = 0; i < order.size(); i++)
        for (int v : children[order[i]])
            order.push_back(v);
    const int neg = -1000000000;
    int target = m + 1;
    vector<vector<int>> dp(n + 1);
    for (int index = n; index >= 0; index--) {
        int u = order[index];
        dp[u] = {0, credit[u]};
        for (int v : children[u]) {
            int cap = min(target, (int)dp[u].size() + (int)dp[v].size() - 2);
            vector<int> next(cap + 1, neg);
            next[0] = 0;
            for (int i = 1; i < (int)dp[u].size(); i++)
                for (int j = 0; j < (int)dp[v].size() && i + j <= cap; j++)
                    if (dp[u][i] != neg && dp[v][j] != neg)
                        next[i + j] = max(next[i + j], dp[u][i] + dp[v][j]);
            dp[u].swap(next);
        }
    }
    cout << dp[0][target];
    return 0;
}
```

### 复杂度

保守时间 $O(nM^2)$，使用实际子树规模限制卷积；空间 $O(nM)$。

### 易错点

必须恰好M门，不能直接取至多M的最大值。虚拟根必须算进选课计数后，再把目标改为M+1。
