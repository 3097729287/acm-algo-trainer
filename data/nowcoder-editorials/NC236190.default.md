## 分糖果

### 题意

合并糖果余数，最小正解保证小于2^31。

### 思路

按扩展CRT合并x≡R(mod M)，每次解M*t≡r−R(mod p)。但这里只保证解小，未保证所有模数最小公倍数小。利用解界B=2^31：一旦合并周期M≥B，区间[1,B)里至多剩一个候选R，后续只检查它是否满足每条同余，无需继续扩大周期。

进入冻结前M<B且p≤10^9，一步新周期至约2×10^18，64位可存，乘法中间用128位。若最终R=0且M<B，最小正解应取M；若冻结后R=0，界内无正解。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long extendedGcd(long long a, long long b, long long &x, long long &y) {
    if (!b) {
        x = 1;
        y = 0;
        return a;
    }
    long long previousX, previousY;
    long long g = extendedGcd(b, a % b, previousX, previousY);
    x = previousY;
    y = previousX - (a / b) * previousY;
    return g;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    const long long bound = 1LL << 31;
    long long remainder = 0, period = 1;
    bool possible = true, frozen = false;
    while (n--) {
        long long p, r;
        cin >> p >> r;
        if (!possible)
            continue;
        if (frozen) {
            if (remainder % p != r)
                possible = false;
            continue;
        }
        long long u, v, g = extendedGcd(period, p, u, v), delta = r - remainder;
        if (delta % g) {
            possible = false;
            continue;
        }
        long long reduced = p / g,
                  step = (long long)(((__int128)(delta / g) * u % reduced + reduced) % reduced),
                  nextPeriod = period * reduced;
        remainder = (long long)(((__int128)remainder + (__int128)period * step) % nextPeriod);
        period = nextPeriod;
        if (period >= bound) {
            frozen = true;
            if (remainder == 0 || remainder >= bound)
                possible = false;
        }
    }
    long long answer = remainder ? remainder : period;
    if (answer >= bound)
        possible = false;
    cout << (possible ? answer : -1);
    return 0;
}
```

### 复杂度

时间 $O(n\log U)$，空间 $O(\log U)$。

### 易错点

原题要求糖果数是正数，零余数系统的最小正解是周期，不是0。小解不意味着模数乘积小。
