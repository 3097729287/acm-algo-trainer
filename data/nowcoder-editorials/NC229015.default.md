## Notepad

### 题意

b进制所有n位正整数装页，每页c个，求最后一页个数，b和n可有百万位。

### 思路

总数T=(b−1)*b^(n−1)，只需T mod c；余数为0时最后一页装满，应输出c。无需欧拉降幂，直接按十进制指数快速幂：若已有指数前缀e，再读一位d，则b^(10e+d)=(b^e)^10*b^d mod c。

先将大字符串b逐位求模，将n字符串手工减1，预计算b^0..b^9，再扫描指数。每位仅常数次模乘，对合数c、b与c不互素都成立。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string b, n;
    long long c;
    cin >> b >> n >> c;
    if (c == 1) {
        cout << 1;
        return 0;
    }
    long long base = 0;
    for (char d : b)
        base = (base * 10 + d - '0') % c;
    int p = n.size() - 1;
    while (n[p] == '0') {
        n[p] = '9';
        p--;
    }
    n[p]--;
    long long small[10];
    small[0] = 1 % c;
    for (int i = 1; i < 10; i++)
        small[i] = small[i - 1] * base % c;
    long long result = 1 % c;
    for (char digit : n) {
        long long square = result * result % c, fourth = square * square % c,
                  eighth = fourth * fourth % c;
        result = eighth * square % c * small[digit - '0'] % c;
    }
    result = result * ((base - 1 + c) % c) % c;
    cout << (result ? result : c);
    return 0;
}
```

### 复杂度

时间 $O(|b|+|n|)$，空间 $O(|b|+|n|)$。

### 易错点

指数是n−1，不能直接用n。c可能为合数，按位幂避免了不满足互素条件的降幂错误。
