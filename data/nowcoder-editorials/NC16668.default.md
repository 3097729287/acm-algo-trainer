## 数列

### 题意

把互不相同的 k 的幂的非空和从小到大排序，求第 N 个。

### 思路

每个幂只可选零次或一次，所以合法数的 k 进制只含零一。对 k≥三，最高不同位决定大小，合法数的顺序与二进制正整数的顺序完全一致。因此把 N 的二进制位依次当成 k 进制位求值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long k, n;
    cin >> k >> n;
    long long power = 1, ans = 0;
    while (n) {
        if (n & 1)
            ans += power;
        n >>= 1;
        power *= k;
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(\log N)$，额外空间 $O(1)$。

### 易错点

第一项对应 N=1，而不是 N=0；无需真的生成前 N 项再排序。
