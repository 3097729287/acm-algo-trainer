## [网络流24题]飞行员配对方案问题

### 题意

外籍与英国飞行员配对，求最大飞机数。

### 思路

把外籍编号1..m作为左侧，英国编号m+1..n作为右侧，给出的可配合关系连边。每人最多参与一次，所以最大匹配即最大可起飞飞机数。输入只要求输出数量，无需输出配对。

参考代码使用Hopcroft–Karp：从所有未匹配左点BFS标记最短增广路层数，再DFS沿这些层同时增广。每条增广路将匹配边与非匹配边交替翻转，匹配数增加1；不存在增广路时已达最大匹配。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Matching {
    int left, right, shortest;
    vector<vector<int>> edge;
    vector<int> mateLeft, mateRight, distance;
    Matching(int left, int right)
        : left(left), right(right), edge(left), mateLeft(left, -1), mateRight(right, -1),
          distance(left) {}
    bool bfs() {
        queue<int> queue;
        fill(distance.begin(), distance.end(), -1);
        for (int u = 0; u < left; u++)
            if (mateLeft[u] < 0) {
                distance[u] = 0;
                queue.push(u);
            }
        shortest = INT_MAX;
        while (!queue.empty()) {
            int u = queue.front();
            queue.pop();
            if (distance[u] + 1 > shortest)
                continue;
            for (int v : edge[u])
                if (mateRight[v] < 0)
                    shortest = min(shortest, distance[u] + 1);
                else if (distance[mateRight[v]] < 0) {
                    distance[mateRight[v]] = distance[u] + 1;
                    queue.push(mateRight[v]);
                }
        }
        return shortest < INT_MAX;
    }
    bool dfs(int u) {
        for (int v : edge[u])
            if ((mateRight[v] < 0 && distance[u] + 1 == shortest) ||
                (mateRight[v] >= 0 && distance[mateRight[v]] == distance[u] + 1 &&
                 dfs(mateRight[v]))) {
                mateLeft[u] = v;
                mateRight[v] = u;
                return true;
            }
        distance[u] = -1;
        return false;
    }
    int maximum() {
        int result = 0;
        while (bfs())
            for (int u = 0; u < left; u++)
                if (mateLeft[u] < 0 && dfs(u))
                    result++;
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    Matching match(m, n - m);
    int u, v;
    while (cin >> u >> v && u > 0 && v > 0)
        match.edge[u - 1].push_back(v - m - 1);
    cout << match.maximum();
    return 0;
}
```

### 复杂度

时间 $O(E\sqrt n)$，空间 $O(n+E)$。

### 易错点

当前题第一行先总人数n、后外籍数m，与某些原题版本顺序不同；按此页样例10 5读取。
