## Highway

### 题意

完全图的边权为原树两点距离，求最大生成树的总权。

### 思路

求原树直径端点A、B。树的非负边权保证任一点v的最远点可在A、B中取，所以偏心距ecc[v]=max(distA[v],distB[v])。先连A、B，其余每点连到较远端点，得到一棵树，总权为Σecc[v]−直径长度。

上界也恰为此值：任意生成树以A为根，每个v≠A的父边至多ecc[v]，所以总权≤Σ(v≠A)ecc[v]=Σecc[v]−dist(A,B)。上述构造达到上界，因此最优。三次迭代树遍历先找A，再求distA并找B，最后求distB。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        Tree tree(n);
        for (int i = 1; i < n; i++) {
            int a, b;
            long long w;
            cin >> a >> b >> w;
            tree.add(a - 1, b - 1, w);
        }
        auto distances = [&](int source) {
            vector<long long> d(n, -1);
            vector<int> queue{source};
            d[source] = 0;
            for (size_t h = 0; h < queue.size(); h++) {
                int u = queue[h];
                for (auto [v, w] : tree.edge[u])
                    if (d[v] == -1) {
                        d[v] = d[u] + w;
                        queue.push_back(v);
                    }
            }
            return d;
        };
        auto first = distances(0);
        int a = max_element(first.begin(), first.end()) - first.begin();
        auto da = distances(a);
        int b = max_element(da.begin(), da.end()) - da.begin();
        auto db = distances(b);
        long long answer = -da[b];
        for (int u = 0; u < n; u++)
            answer += max(da[u], db[u]);
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n)$。

### 易错点

求的是最大生成树，不能直接把原树边权相加。原树路径唯一，用普通遍历累加距离即可，无须Dijkstra。
