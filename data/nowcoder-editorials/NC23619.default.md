## 小A的柱状图

### 题意

每根柱宽不同，求下端对齐柱状图内最大矩形面积。

### 思路

仍用高度不下降的单调栈，遇到更矮的第 i 柱时弹出 j。此时以 h[j] 为高度，范围为弹栈后栈顶 left 之后，到 i-1 为止。这里宽度不能用柱数，而应使用宽度前缀和 width[i-1]-width[left]。末尾补零高柱清栈，取所有结算面积最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> width(n + 2), height(n + 2);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        width[i] = width[i - 1] + x;
    }
    for (int i = 1; i <= n; i++)
        cin >> height[i];
    vector<int> stack;
    long long answer = 0;
    for (int i = 1; i <= n + 1; i++) {
        while (!stack.empty() && height[stack.back()] > height[i]) {
            int j = stack.back();
            stack.pop_back();
            int left = stack.empty() ? 0 : stack.back();
            answer = max(answer, height[j] * (width[i - 1] - width[left]));
        }
        stack.push_back(i);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

总宽可达一亿，高度可达十亿，面积可达 10^17，必须使用 long long。柱宽只影响区间长度，不改变按高度找边界的规则。
