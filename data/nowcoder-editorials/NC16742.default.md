## [NOIP2002]字串变换

### 题意

按给定子串替换规则，求A到B不超过10步的最少变换数。

### 思路

任何长度至多10的变换路径，都有一个中间串，距A和B各不超过5步。分别从A按正规则、从B按反规则做深度最多5的BFS，每次枚举每条规则在当前串中的所有出现位置，包括重叠位置。将两边所有共同状态的距离和取最小，即得到完整的10步内最短距离。没有交点就输出NO ANSWER!。边必须按方向反转，不能仅交换搜索起点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string a, b;
    cin >> a >> b;
    vector<pair<string, string>> rules;
    string from, to;
    while (cin >> from >> to)
        rules.push_back({from, to});
    auto search = [&](const string &start, bool backward) {
        unordered_map<string, int> distance;
        vector<string> queue{start};
        distance[start] = 0;
        for (size_t h = 0; h < queue.size(); h++) {
            string current = queue[h];
            int depth = distance.at(current);
            if (depth == 5)
                continue;
            for (const auto &rule : rules) {
                const string &x = backward ? rule.second : rule.first,
                             &y = backward ? rule.first : rule.second;
                for (size_t p = current.find(x); p != string::npos; p = current.find(x, p + 1)) {
                    string next = current.substr(0, p) + y + current.substr(p + x.size());
                    if (!distance.count(next)) {
                        distance[next] = depth + 1;
                        queue.push_back(next);
                    }
                }
            }
        }
        return distance;
    };
    auto left = search(a, false), right = search(b, true);
    int answer = 11;
    for (auto &[s, d] : left) {
        auto it = right.find(s);
        if (it != right.end())
            answer = min(answer, d + it->second);
    }
    if (answer <= 10)
        cout << answer;
    else
        cout << "NO ANSWER!";
    return 0;
}
```

### 复杂度

若两侧各生成 $S$ 个状态、最大中间长度 $L$、规则数 $R\le6$，保守时间 $O(SRL^2)$，空间 $O(SL)$；搜索层数各不超过5。

### 易错点

不能人为把中间串长度截在输入长度20，变换过程中可以暂时增长。A等于B时答案0。
