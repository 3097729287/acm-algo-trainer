## 迷宫

### 题意

四方向迷宫，有钥匙后才可经过门，求最少步数。

### 思路

状态必须包含位置和是否持有钥匙，不能只标记格子。每个格子拆成无钥匙、有钥匙两个状态，经过K后钥匙位变成1，进入D要求钥匙位已经为1，其余合法移动花费1。BFS第一次到达终点的距离即最少步数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    int start = 0;
    for (int r = 0; r < n; r++) {
        cin >> grid[r];
        for (int c = 0; c < m; c++)
            if (grid[r][c] == 'S')
                start = (r * m + c) * 2;
    }
    vector<int> distance(2 * n * m, -1), queue{start};
    distance[start] = 0;
    int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
    int answer = -1;
    for (size_t h = 0; h < queue.size(); h++) {
        int u = queue[h], key = u % 2, r = u / 2 / m, c = u / 2 % m;
        if (grid[r][c] == 'E') {
            answer = distance[u];
            break;
        }
        for (int d = 0; d < 4; d++) {
            int rr = r + dr[d], cc = c + dc[d];
            if (rr < 0 || rr >= n || cc < 0 || cc >= m)
                continue;
            char cell = grid[rr][cc];
            if (cell == 'W' || (cell == 'D' && !key))
                continue;
            int v = (rr * m + cc) * 2 + (key || cell == 'K');
            if (distance[v] == -1) {
                distance[v] = distance[u] + 1;
                queue.push_back(v);
            }
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(nm)$。

### 易错点

取得钥匙后可以回到以前走过的格子，这是另一状态。门是D，墙是W。
