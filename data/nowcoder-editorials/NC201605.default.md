## Bits

### 题意

按盘数奇偶确定目标柱，逐帧输出普通汉诺塔从初态到终态的完整过程。

### 思路

用三个栈保存各柱盘子，从底到顶记录。递归搬 n 个盘：先搬上面 n-1 个到辅助柱，再搬最大盘到目标，最后把 n-1 个搬到目标。初始状态和每一次实际移动后各输出一幅图，得到 2^n 幅。绘图按固定柱中心对齐，直径为 2d+1 的星号段表示 d 号盘，所有盘均从底部堆起。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> pole(3);
    for (int d = n; d >= 1; d--)
        pole[0].push_back(d);
    int width = 3 * (2 * n + 1) + 4;
    bool first = true;
    auto draw = [&]() {
        if (!first)
            cout << string(width, '-') << '\n';
        first = false;
        for (int row = 0; row < n + 2; row++) {
            string line(width, '.');
            if (row > 0)
                for (int p = 0; p < 3; p++) {
                    int center = n + 1 + p * (2 * n + 2), index = n + 1 - row;
                    if (index < (int)pole[p].size()) {
                        int disk = pole[p][index];
                        for (int x = center - disk; x <= center + disk; x++)
                            line[x] = '*';
                    } else
                        line[center] = '|';
                }
            cout << line << '\n';
        }
    };
    function<void(int, int, int)> move = [&](int count, int from, int to) {
        if (count == 0)
            return;
        int auxiliary = 3 - from - to;
        move(count - 1, from, auxiliary);
        int disk = pole[from].back();
        pole[from].pop_back();
        pole[to].push_back(disk);
        draw();
        move(count - 1, auxiliary, to);
    };
    draw();
    move(n, 0, n % 2 == 0 ? 2 : 1);
    return 0;
}
```

### 复杂度

图幅数为 $2^n$，每幅输出 $O(n^2)$ 个字符，时间 $O(n^2 2^n)$，栈与递归空间 $O(n)$。

### 易错点

这里允许左右柱直接搬盘，与只准相邻移动的题不同。分隔线只在两幅图之间，最后不再输出一条分隔线。空白必须是句点。
