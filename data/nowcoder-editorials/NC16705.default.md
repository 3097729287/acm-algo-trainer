## 级数求和

> 原题：[P1035](https://www.luogu.com.cn/problem/P1035)
> 解法：逐项累加到首次越界 · C++17

### 题意

求最小的 $n$，使调和和 $1+1/2+\cdots+1/n$ 严格大于给定 $k$。



### 思路

从零项、零和开始。只要当前和还不大于 $k$，就把项数加一，并加入新的一项 $1/n$。第一次超过 $k$ 时停止。

若答案为 $n$，时间 $O(n)$、额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int k;
    cin >> k;
    int n = 0;
    double sum = 0;
    while (sum <= k) {
        ++n;
        sum += 1.0 / n;
    }
    cout << n << '\n';
    return 0;
}
```

### 易错点

条件是严格大于 $k$，等于时必须继续；先增加 $n$，再计算新项。
