## 排列式

### 题意

找出乘数、乘积合起来恰好使用一次数字一到九的所有乘法式，交换乘数只算一次。

### 思路

乘积一定是四位数：若乘数总位数至多四，乘积至多四位，总位数不足九；若总位数至少六，乘积至少五位，总位数超过九。因此只枚举一位乘四位、两位乘三位。拼接两个乘数和乘积，检查长度为九、没有零且每个数位只出现一次。最后按乘积、较小乘数排序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    vector<tuple<int, int, int>> ans;
    auto check = [&](int a, int b) {
        int c = a * b;
        string s = to_string(a) + to_string(b) + to_string(c);
        if (s.size() != 9)
            return;
        int mask = 0;
        for (char ch : s) {
            int d = ch - '0';
            if (d == 0 || (mask & (1 << d)))
                return;
            mask |= 1 << d;
        }
        if (mask == 1022)
            ans.emplace_back(c, a, b);
    };
    for (int a = 1; a <= 9; a++)
        for (int b = 1234; b <= 9876 && a * b <= 9876; b++)
            check(a, b);
    for (int a = 12; a <= 98; a++)
        for (int b = 123; b <= 987 && a * b <= 9876; b++)
            check(a, b);
    sort(ans.begin(), ans.end());
    for (auto [c, a, b] : ans)
        cout << c << " = " << a << " x " << b << '\n';
    return 0;
}
```

### 复杂度

数位上限固定，枚举与排序的总开销为常数；保存九条结果。

### 易错点

同一个乘积可以对应不同乘数，不能只对乘积去重。两种枚举都令较小乘数在前。
