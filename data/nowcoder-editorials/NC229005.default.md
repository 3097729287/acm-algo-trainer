## 【模板】同余方程

### 题意

多组求a模b的乘法逆元，不存在时输出负一。

### 思路

扩展欧几里得给出a*x+b*y=g。只有g=1时才能模b得到a*x=1；否则任何a*x+b*y都是g的倍数，无法等于1。存在时将x归一化到[0,b)，输出最小正解。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long extendedGcd(long long a, long long b, long long &x, long long &y) {
    if (!b) {
        x = 1;
        y = 0;
        return a;
    }
    long long previousX, previousY;
    long long g = extendedGcd(b, a % b, previousX, previousY);
    x = previousY;
    y = previousX - (a / b) * previousY;
    return g;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        long long a, b, x, y;
        cin >> a >> b;
        long long g = extendedGcd(a, b, x, y);
        if (g != 1)
            cout << "-1\n";
        else
            cout << (x % b + b) % b << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、递归栈空间均为 $O(\log\min(a,b))$。

### 易错点

本题没有互质保证，必须检查gcd，不能照搬只保证有解的单组版本。
