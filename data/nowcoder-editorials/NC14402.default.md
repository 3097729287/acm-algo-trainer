## 求最大值

### 题意

单点修改后求任意两点斜率(a[j]−a[i])/(j−i)的最大值。

### 思路

任意两点斜率等于它们之间相邻差分的平均数，不超过其中最大差分；最大相邻差分本身也对应合法两点。因此答案就是max(a[i+1]−a[i])。用multiset保存全部差分，修改a[p]时只删除并重算p−1、p两项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cout << fixed << setprecision(2);
    while (cin >> n) {
        vector<long long> a(n);
        for (auto &x : a)
            cin >> x;
        multiset<long long> difference;
        for (int i = 1; i < n; i++)
            difference.insert(a[i] - a[i - 1]);
        int q;
        cin >> q;
        while (q--) {
            int p;
            long long y;
            cin >> p >> y;
            p--;
            if (p)
                difference.erase(difference.find(a[p] - a[p - 1]));
            if (p + 1 < n)
                difference.erase(difference.find(a[p + 1] - a[p]));
            a[p] = y;
            if (p)
                difference.insert(a[p] - a[p - 1]);
            if (p + 1 < n)
                difference.insert(a[p + 1] - a[p]);
            cout << (long double)*difference.rbegin() << '\n';
        }
    }
    return 0;
}
```

### 复杂度

构建 $O(n\log n)$，每次修改 $O(\log n)$，空间 $O(n)$。

### 易错点

最大值可以为负。multiset删除要用迭代器删除一份，不能把相同差分全部删掉。
