## 最短路

### 题意

任意两城可按异或值乘C直达，另有单向快捷边，求最短时间。

### 思路

把一次异或跳跃拆成若干次单比特翻转，第b位翻转费用2^b*C，翻转不同位的费用和恰为(u xor v)*C。为使任何两个真实城市都能这样连接，把编号扩到包含N的完整二进制立方体0到2^B−1，扩展编号仅作中间点，不新增快捷边。

扩展不会凭空变便宜：任何纯翻位路径在每个差异位至少付一次，所以其费用不低于两端原有直达边；一段经过虚拟点的路径可替换成对应真实城市间直达。因此最优值保持。Dijkstra中按需生成B条翻位邻边，再处理当前真实城市的快捷边，无需显式建立完全图。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    long long c;
    cin >> n >> m >> c;
    int size = 1;
    while (size <= n)
        size <<= 1;
    vector<vector<pair<int, long long>>> quick(size);
    while (m--) {
        int a, b;
        long long w;
        cin >> a >> b >> w;
        quick[a].push_back({b, w});
    }
    int start, target;
    cin >> start >> target;
    const long long inf = 1LL << 60;
    vector<long long> distance(size, inf);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                   greater<pair<long long, int>>>
        heap;
    distance[start] = 0;
    heap.push({0, start});
    while (!heap.empty()) {
        auto [cost, u] = heap.top();
        heap.pop();
        if (cost != distance[u])
            continue;
        if (u == target)
            break;
        auto relax = [&](int v, long long w) {
            if (distance[v] > cost + w) {
                distance[v] = cost + w;
                heap.push({distance[v], v});
            }
        };
        for (int bit = 1; bit < size; bit <<= 1)
            relax(u ^ bit, bit * c);
        for (auto [v, w] : quick[u])
            relax(v, w);
    }
    cout << distance[target];
    return 0;
}
```

### 复杂度

$V=2^{\lceil\log_2(N+1)\rceil}<2(N+1)$，时间 $O((V\log V+M)\log V)$，空间 $O(V+M)$。

### 易错点

虚拟编号0和大于N的编号要保留，否则某些异或直达无法拆成等价路径。快捷通道只按给定方向添加。
