## 铺地毯

### 题意

查询一个点被最后铺下的哪张轴对齐矩形地毯覆盖。

### 思路

保存每张地毯的左下与右上坐标，从编号最大的一张反向检查。点位于闭矩形内就立即输出，该地毯之后再没有更晚的覆盖；全部未命中则输出 -1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Carpet {
        int x, y, right, top;
    };
    vector<Carpet> a(n);
    for (auto &c : a) {
        int w, h;
        cin >> c.x >> c.y >> w >> h;
        c.right = c.x + w;
        c.top = c.y + h;
    }
    int x, y;
    cin >> x >> y;
    for (int i = n - 1; i >= 0; i--)
        if (a[i].x <= x && x <= a[i].right && a[i].y <= y && y <= a[i].top) {
            cout << i + 1;
            return 0;
        }
    cout << -1;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(n)$。

### 易错点

边界和顶点都算覆盖，比较必须包含等号。宽、高不是右上角坐标。
