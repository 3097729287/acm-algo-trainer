## 可持久化动态图上树状数组维护01背包

### 题意

删除当前位置 i 的元素付出 a[i]i，后面的下标减一，求总费用最小值。

### 思路

原来第 i 个元素删除时的位置一定在一到 i 之间。正数的最小贡献不小于 a[i]，负数的最小贡献不小于 i*a[i]。这组逐项下界能同时实现：先从右往左删所有负数，它们前面的原元素全都还在，下标正好是原 i；再从左往右删非负数，每次下标都是一。因此把负数乘原下标、非负数原值直接求和即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long answer = 0;
    for (long long i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        answer += x < 0 ? x * i : x;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

负数希望在更大的下标删除，不能把所有元素都从左到右删。标题中列出的数据结构并非解题所需。
