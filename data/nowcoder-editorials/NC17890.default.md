## 方格填色

### 题意

m行n列黑白填色，左右不能同白，相邻两列不能同时全黑，n至十的十八次方。

### 思路

列mask的1表示白格。相邻两列a、b要求a&b=0，防止同一行左右均白；同时(a|b)≠0，防止两列全黑。每列内部上下没有限制。最多2^m≤32种状态，把合法相邻关系组成转移矩阵，第一列每种状态都有1种方案。求转移矩阵的n−1次幂，所有元素之和即最终总方案数；n=1时单位矩阵元素和为2^m。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m;
    unsigned long long n;
    cin >> m >> n;
    int states = 1 << m;
    const long long mod = 1000000007;
    using Matrix = vector<vector<long long>>;
    Matrix base(states, vector<long long>(states)), result = base;
    for (int a = 0; a < states; a++) {
        result[a][a] = 1;
        for (int b = 0; b < states; b++)
            base[a][b] = !(a & b) && (a | b);
    }
    auto multiply = [&](const Matrix &a, const Matrix &b) {
        Matrix c(states, vector<long long>(states));
        for (int i = 0; i < states; i++)
            for (int k = 0; k < states; k++)
                if (a[i][k])
                    for (int j = 0; j < states; j++)
                        c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % mod;
        return c;
    };
    for (n--; n; n >>= 1) {
        if (n & 1)
            result = multiply(result, base);
        base = multiply(base, base);
    }
    long long answer = 0;
    for (auto &row : result)
        for (long long x : row)
            answer = (answer + x) % mod;
    cout << answer;
    return 0;
}
```

### 复杂度

状态数 $S=2^m\le32$，时间 $O(S^3\log n)$，空间 $O(S^2)$。

### 易错点

约束针对左右及相邻两列，并不限制同一列上下白格。指数为n−1，n=1不能多做一次转移。
