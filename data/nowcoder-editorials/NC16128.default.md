## 小名的回答

### 题意

从原点沿四个方向每次一步，是否能恰走 n 步到达 (a,b)。

### 思路

最少需要 d=|a|+|b| 步。每走一步，横纵坐标和的奇偶性都会翻转，所以 n-d 必须是非负偶数。条件满足时先在原点来回走 (n-d)/2 次，再走最短路线，便能恰好走完。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, n;
    cin >> a >> b >> n;
    int d = abs(a) + abs(b);
    cout << (n >= d && (n - d) % 2 == 0 ? "YES" : "NO");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

只检查步数足够不充分，还要检查多余步数的奇偶性。
