## 小C的周末

### 题意

按顺序连线，对每种游戏求全部玩家首次同处一个连通块的时刻。

### 思路

每个并查集根维护一个“游戏编号→本块人数”的映射，另统计各游戏总人数。合并两块时把较小块的计数加进较大块；某个游戏的块内人数达到总数，就在此时首次连通，记录当前线号。每种游戏只需首次记录。小块并入大块时，每个被搬运玩家所在块大小至少翻倍，因此所有搬运总量 O(n log n)，映射用平衡树再乘一个对数。只有一个玩家（或没有玩家）的游戏在时刻0就无须连线；始终分散者输出−1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, q;
    while (cin >> n >> m >> q) {
        vector<int> game(n + 1), total(m + 1), answer(m + 1, -1);
        vector<map<int, int>> count(n + 1);
        DSU dsu(n);
        for (int i = 1; i <= n; i++) {
            cin >> game[i];
            total[game[i]]++;
            count[i][game[i]] = 1;
        }
        for (int g = 1; g <= m; g++)
            if (total[g] <= 1)
                answer[g] = 0;
        for (int time = 1; time <= q; time++) {
            int a, b;
            cin >> a >> b;
            a = dsu.find(a);
            b = dsu.find(b);
            if (a == b)
                continue;
            if (dsu.size[a] < dsu.size[b])
                swap(a, b);
            dsu.parent[b] = a;
            dsu.size[a] += dsu.size[b];
            for (auto [g, c] : count[b]) {
                int value = (count[a][g] += c);
                if (value == total[g] && answer[g] == -1)
                    answer[g] = time;
            }
            count[b].clear();
        }
        for (int g = 1; g <= m; g++)
            cout << answer[g] << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O((n+q)\alpha(n)+n\log^2 n)$，空间 $O(n+m)$。

### 易错点

联通的是整条路径，不要求同一游戏的玩家直接相连；可以借助玩其他游戏的中间人。重复连接同块不改变计数。
