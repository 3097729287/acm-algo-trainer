## Check In

### 题意

统计参赛账号所属学校恰好为 bnu 的队伍数。

### 思路

账号格式已经固定，只需检查是否以 bnu16- 开头。不能只查找中间是否出现 bnu，以免误计更长学校缩写。每组独立累加。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        int ans = 0;
        while (n--) {
            string s;
            cin >> s;
            if (s.rfind("bnu16-", 0) == 0)
                ans++;
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 复杂度

时间为账号字符总数，空间为最长账号长度。

### 易错点

队伍编号可能相同但学校不同，不能按编号计数或去重。
