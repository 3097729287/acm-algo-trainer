## 棋盘覆盖

### 题意

有禁格棋盘最多放多少1×2骨牌。

### 思路

按(r+c)奇偶把可用格分为两侧，相邻格总异色，每块骨牌对应一条相邻边。骨牌不重叠恰好是匹配约束，因此最大匹配数就是最大骨牌数。题目输出文字“覆盖格数”有歧义，但8×8样例输出32，显然按骨牌块数，不乘2。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Matching {
    int left, right, shortest;
    vector<vector<int>> edge;
    vector<int> mateLeft, mateRight, distance;
    Matching(int left, int right)
        : left(left), right(right), edge(left), mateLeft(left, -1), mateRight(right, -1),
          distance(left) {}
    bool bfs() {
        queue<int> queue;
        fill(distance.begin(), distance.end(), -1);
        for (int u = 0; u < left; u++)
            if (mateLeft[u] < 0) {
                distance[u] = 0;
                queue.push(u);
            }
        shortest = INT_MAX;
        while (!queue.empty()) {
            int u = queue.front();
            queue.pop();
            if (distance[u] + 1 > shortest)
                continue;
            for (int v : edge[u])
                if (mateRight[v] < 0)
                    shortest = min(shortest, distance[u] + 1);
                else if (distance[mateRight[v]] < 0) {
                    distance[mateRight[v]] = distance[u] + 1;
                    queue.push(mateRight[v]);
                }
        }
        return shortest < INT_MAX;
    }
    bool dfs(int u) {
        for (int v : edge[u])
            if ((mateRight[v] < 0 && distance[u] + 1 == shortest) ||
                (mateRight[v] >= 0 && distance[mateRight[v]] == distance[u] + 1 &&
                 dfs(mateRight[v]))) {
                mateLeft[u] = v;
                mateRight[v] = u;
                return true;
            }
        distance[u] = -1;
        return false;
    }
    int maximum() {
        int result = 0;
        while (bfs())
            for (int u = 0; u < left; u++)
                if (mateLeft[u] < 0 && dfs(u))
                    result++;
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<bool> blocked(n * n);
    while (m--) {
        int x, y;
        cin >> x >> y;
        blocked[(x - 1) * n + y - 1] = true;
    }
    Matching match(n * n, n * n);
    const int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
    for (int r = 0; r < n; r++)
        for (int c = 0; c < n; c++)
            if ((r + c) % 2 == 0 && !blocked[r * n + c])
                for (int d = 0; d < 4; d++) {
                    int rr = r + dr[d], cc = c + dc[d];
                    if (rr >= 0 && rr < n && cc >= 0 && cc < n && !blocked[rr * n + cc])
                        match.edge[r * n + c].push_back(rr * n + cc);
                }
    cout << match.maximum();
    return 0;
}
```

### 复杂度

令V=n²，时间 $O(V\sqrt V)$，空间 $O(V)$。

### 易错点

只从一种格子颜色向另一种建边，避免把每格既当左点又当右点而重复使用。
