## 石子游戏

### 题意

奇堆可分成两堆，偶堆两堆可合并，不能操作者输。

### 思路

奇数分裂后恰有一奇一偶，奇堆的总数不变；每次分裂新增一个偶堆，每次合并减少一个偶堆。终局所有奇堆都是1，偶堆至多一个。若最初至少有偶堆，或存在大于1的奇堆，过程中必出现偶堆，终局恰剩一个。

设初始偶堆E，分裂S次，则合并E+S−1次，总步数2S+E−1，奇偶仅由E决定。E为偶数时总步数奇，先手胜；E为奇数时后手胜。若所有堆都是1，则没有任何操作，直接后手胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int even = 0;
    bool activeOdd = false;
    while (n--) {
        int x;
        cin >> x;
        if (x % 2 == 0)
            even++;
        else if (x > 1)
            activeOdd = true;
    }
    cout << ((even % 2 == 0 && (even > 0 || activeOdd)) ? "Alice" : "Bob");
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

分裂次数可以不同，但总步数奇偶固定。全是1时不能套用终局存在一个偶堆的公式。
