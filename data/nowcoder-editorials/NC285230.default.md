## 最大的半径

### 题意

三点作等半径圆，圆可相切但不相交，最大半径。

### 思路

固定三点，半径最多是三条距离最小值的一半。将所有点对按距离平方降序加入无向图。首次出现三角形时，这个三角形最短边就是当前阈值，而此前更大的阈值无三角形，所以得到全局最优。

加入边(u,v)前，只需检查u、v此前的邻接集合是否有交集；用64位位集逐字AND，非零即存在第三点。距离平方为整数，可精确比较；仅最后做sqrt/2。3000点边数约450万，端点用16位存储减少排序内存。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<int, int>> point(n);
    for (auto &[x, y] : point)
        cin >> x >> y;
    struct Edge {
        int distance;
        uint16_t u, v;
    };
    vector<Edge> edge;
    edge.reserve((size_t)n * (n - 1) / 2);
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            long long dx = point[i].first - point[j].first, dy = point[i].second - point[j].second;
            edge.push_back({(int)(dx * dx + dy * dy), (uint16_t)i, (uint16_t)j});
        }
    sort(edge.begin(), edge.end(), [](auto a, auto b) { return a.distance > b.distance; });
    int words = (n + 63) / 64;
    vector<vector<unsigned long long>> neighbor(n, vector<unsigned long long>(words));
    for (auto e : edge) {
        bool triangle = false;
        for (int w = 0; w < words; w++)
            if (neighbor[e.u][w] & neighbor[e.v][w]) {
                triangle = true;
                break;
            }
        if (triangle) {
            cout << fixed << setprecision(12) << sqrtl(e.distance) / 2;
            return 0;
        }
        neighbor[e.u][e.v / 64] |= 1ULL << (e.v % 64);
        neighbor[e.v][e.u / 64] |= 1ULL << (e.u % 64);
    }
    return 0;
}
```

### 复杂度

时间 $O(n^2\log n+n^3/64)$，空间 $O(n^2)$，每条边8字节。

### 易错点

目标是最大化三边中的最小边，不是最大直径或外接圆。等长边按任意顺序加入，首次成三角形的阈值仍正确。
