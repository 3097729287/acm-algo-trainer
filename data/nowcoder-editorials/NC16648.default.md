## [NOIP2005]陶陶摘苹果

### 题意

有三十厘米板凳，统计十个苹果中高度不超过伸手高度加三十的数量。

### 思路

先保存十个高度，再读取伸手高度。能碰到就能摘下，所以对每个苹果检查 height≤reach+30，累加满足条件的个数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a[10];
    for (int &x : a)
        cin >> x;
    int reach;
    cin >> reach;
    int ans = 0;
    for (int x : a)
        if (x <= reach + 30)
            ans++;
    cout << ans;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

恰好能碰到的苹果也算可摘，比较符号要包含等号。
