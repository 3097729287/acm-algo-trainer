## 计算三角形的周长和面积

### 题意

由三边计算三角形周长与面积，并按指定标签输出。

### 思路

令半周长 p=(a+b+c)/2，海伦公式给出面积 sqrt(p(p-a)(p-b)(p-c))。输入保证能构成三角形。使用 long double 计算，固定两位小数，并保留 circumference= 与 area= 两个标签。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long double a, b, c;
    cin >> a >> b >> c;
    long double p = (a + b + c) / 2;
    long double area = sqrtl(max((long double)0, p * (p - a) * (p - b) * (p - c)));
    cout << fixed << setprecision(2) << "circumference=" << a + b + c << " area=" << area;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

面积不能用两条边直接相乘除二，因为题目没有给出对应的直角。
