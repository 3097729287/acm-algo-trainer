## 最大正方形

### 题意

在字符矩阵中找四角都是井号的最大正方形，允许倾斜。

### 思路

取正方形最上方、并列时最左的顶点 P=(r,c)。它向右的相邻顶点可写为 Q=(r+dr,c+dc)，其中 dr>=0、dc>0；把边向量旋转九十度，另一相邻点为 R=(r+dc,c-dr)，最后一点为 S=Q+R-P。枚举 P、dr、dc，先保证四点不越界，再检查四角字符。边长平方为 dr²+dc²，直接比较整数平方，不开根号。这样的规范方向覆盖每个正方形。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> a(n);
    for (auto &row : a)
        cin >> row;
    int best = -1;
    array<pair<int, int>, 4> answer;
    for (int r = 0; r < n; r++)
        for (int c = 0; c < n; c++)
            if (a[r][c] == '#')
                for (int dr = 0; dr <= c && r + dr < n; dr++)
                    for (int dc = 1; c + dc < n && r + dr + dc < n; dc++) {
                        int length = dr * dr + dc * dc;
                        if (length <= best)
                            continue;
                        if (a[r + dr][c + dc] == '#' && a[r + dc][c - dr] == '#' &&
                            a[r + dr + dc][c + dc - dr] == '#') {
                            best = length;
                            answer = {{{r, c},
                                       {r + dr, c + dc},
                                       {r + dc, c - dr},
                                       {r + dr + dc, c + dc - dr}}};
                        }
                    }
    for (auto [r, c] : answer)
        cout << r + 1 << ' ' << c + 1 << '\n';
    return 0;
}
```

### 复杂度

最坏时间 $O(n^4)$，越界限制会剪去大量组合；存储矩阵 $O(n^2)$。

### 易错点

不要求边或内部都是井号。只枚举水平、竖直边会漏掉第二个样例中的倾斜正方形。输出任意一个最大解均可。
