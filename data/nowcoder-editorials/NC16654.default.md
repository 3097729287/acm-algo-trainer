## [NOIP2005]谁拿了最多奖学金

### 题意

按五项独立条件累计每名学生奖学金，输出最高者、最高金额及总金额。

### 思路

每条奖学金规则分别用一个 if 判断，符合多项就叠加多项。用总和累加全部学生金额；只有当前金额严格超过历史最高时才更新姓名，保证并列选择输入最早者。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    string bestName;
    int best = -1, total = 0;
    for (int i = 0; i < n; i++) {
        string name;
        int exam, review, papers;
        char leader, west;
        cin >> name >> exam >> review >> leader >> west >> papers;
        int award = 0;
        if (exam > 80 && papers >= 1)
            award += 8000;
        if (exam > 85 && review > 80)
            award += 4000;
        if (exam > 90)
            award += 2000;
        if (exam > 85 && west == 'Y')
            award += 1000;
        if (review > 80 && leader == 'Y')
            award += 850;
        total += award;
        if (award > best) {
            best = award;
            bestName = name;
        }
    }
    cout << bestName << '\n' << best << '\n' << total;
    return 0;
}
```

### 复杂度

时间 $O(n)$，除姓名外额外空间 $O(1)$。

### 易错点

五项规则不是互斥关系，不能写成 else if。成绩门槛均为严格高于。
