## [2016WF]Oil

### 题意

一条钻井直线穿过水平油层，最大总宽度。

### 思路

最优非水平直线可平移到某层端点而不损失已穿过的层，枚举2n个端点P。用“水平位移/竖直位移”作为无向直线斜率参数，每个不同高度油层对应一个闭参数区间，两端为(x0−Px)/(y−Py)、(x1−Px)/(y−Py)，权重是油层宽。求所有闭区间的最大覆盖权值，再加P所在层宽。

同高的其他油层与非水平井不可能同时经过，直接忽略。事件比较用有理数交叉乘，分母统一为正；相同参数先加后减，保证端点接触也计入。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Layer {
        long long l, r, y;
    };
    vector<Layer> layer(n);
    for (auto &a : layer) {
        cin >> a.l >> a.r >> a.y;
        if (a.l > a.r)
            swap(a.l, a.r);
    }
    struct Event {
        long long numerator, denominator, delta;
    };
    long long answer = 0;
    for (int pivot = 0; pivot < n; pivot++)
        for (long long px : {layer[pivot].l, layer[pivot].r}) {
            long long py = layer[pivot].y;
            vector<Event> event;
            for (int i = 0; i < n; i++)
                if (layer[i].y != py) {
                    long long denominator = layer[i].y - py, a = layer[i].l - px,
                              b = layer[i].r - px;
                    if (denominator < 0) {
                        denominator = -denominator;
                        a = -a;
                        b = -b;
                    }
                    if (a > b)
                        swap(a, b);
                    long long weight = layer[i].r - layer[i].l;
                    event.push_back({a, denominator, weight});
                    event.push_back({b, denominator, -weight});
                }
            sort(event.begin(), event.end(), [](auto a, auto b) {
                __int128 x = (__int128)a.numerator * b.denominator,
                         y = (__int128)b.numerator * a.denominator;
                return x != y ? x < y : a.delta > b.delta;
            });
            long long current = layer[pivot].r - layer[pivot].l;
            answer = max(answer, current);
            for (auto e : event) {
                current += e.delta;
                answer = max(answer, current);
            }
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n²\log n)$，空间 $O(n)$。

### 易错点

水平井不能从地表下钻到地下同高油层，样例2不能把两条同高不相交层相加。零宽点层权为0。
