## [NOIP2016]组合数问题

### 题意

批量统计矩形范围内被k整除的组合数C(i,j)。

### 思路

先用Pascal递推模k得到C(i,j)余数，余数为0就标记1。只在j≤i处标记，三角形外无组合数，不能当成0计入。对标记做二维前缀和，询问[0,n]×[0,m]直接取prefix[n][m]，前缀表自动只包含合法三角区。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests, k;
    cin >> tests >> k;
    const int limit = 2000;
    vector<vector<int>> prefix(limit + 1, vector<int>(limit + 1));
    vector<int> row(limit + 1);
    row[0] = 1 % k;
    for (int i = 0; i <= limit; i++) {
        if (i)
            for (int j = i; j >= 1; j--)
                row[j] = (row[j] + row[j - 1]) % k;
        for (int j = 0; j <= limit; j++) {
            int flag = j <= i && row[j] == 0;
            prefix[i][j] = flag + (i ? prefix[i - 1][j] : 0) + (j ? prefix[i][j - 1] : 0) -
                           (i && j ? prefix[i - 1][j - 1] : 0);
        }
    }
    while (tests--) {
        int n, m;
        cin >> n >> m;
        cout << prefix[n][m] << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(U^2)$，每问 $O(1)$，空间 $O(U^2)$。

### 易错点

k可能为合数，不能用阶乘逆元计算组合数。Pascal内层倒序。
