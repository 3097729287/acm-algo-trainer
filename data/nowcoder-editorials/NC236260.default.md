## 序列游戏

### 题意

末尾追加0..255值，查询从指定位置已选后谁获胜。

### 思路

固定序列从后向前，令lose表示“选中此处后，下一人无必胜策略”的位置值集合。位置i若能走到某个lose位置，就是胜态；否则是lose并加入其值。可走条件是两个值相同或仅差一个二进制位，所以一旦某个值被lose集合的邻值覆盖，此后永远不会成为lose。

因此同一个数只需看它的最后一次出现；按256种值的最后位置从大到小扫描，若该值尚未被覆盖，就选为lose，并覆盖自身及8个一位差邻值。为每种值v记录所有已选lose邻值的最大位置threshold[v]。

查询起点k已经由Alice选中，轮到Bob；Bob能赢当且仅当存在位置>k的lose邻值，即threshold[a[k]]>k。追加时把该值移到最近使用链表表头，重算256种值的覆盖即可；查询常数时间。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> a;
    a.reserve(n + m);
    array<int, 256> latest = {}, threshold = {};
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        a.push_back(x);
        latest[x] = i;
    }
    list<int> order;
    vector<int> values;
    for (int v = 0; v < 256; v++)
        if (latest[v])
            values.push_back(v);
    sort(values.begin(), values.end(), [&](int x, int y) { return latest[x] > latest[y]; });
    array<list<int>::iterator, 256> where;
    for (int v : values) {
        order.push_back(v);
        where[v] = prev(order.end());
    }
    auto rebuild = [&]() {
        array<bool, 256> blocked = {};
        threshold.fill(0);
        for (int v : order)
            if (!blocked[v]) {
                auto cover = [&](int x) {
                    blocked[x] = true;
                    threshold[x] = max(threshold[x], latest[v]);
                };
                cover(v);
                for (int b = 0; b < 8; b++)
                    cover(v ^ (1 << b));
            }
    };
    rebuild();
    while (m--) {
        int op, k;
        cin >> op >> k;
        if (op == 1) {
            if (latest[k])
                order.erase(where[k]);
            order.push_front(k);
            where[k] = order.begin();
            a.push_back(k);
            latest[k] = a.size();
            rebuild();
        } else
            cout << (threshold[a[k - 1]] > k ? "Bob\n" : "Alice\n");
    }
    return 0;
}
```

### 复杂度

初始化 $O(n+256\log256)$，追加 $O(256\cdot9)$，查询 $O(1)$；空间 $O(n+m+256)$。

### 易错点

相同数也可跳，邻域包含自身。全局记录中位置≤k的lose点不会误判，因为查询要求严格大于k。
