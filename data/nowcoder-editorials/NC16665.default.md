## [NOIP2004]虫食算

### 题意

N进制的三个N位字母数满足加法，数字与字母一一对应，允许前导零，求唯一映射。

### 思路

从最低位开始处理，已知这一位的输入进位。先给两个加数字母中尚未赋值者尝试未用数字，再由(a+b+carry)%N强制确定结果字母；输出进位为整除N。若结果字母已赋值就校验，否则必须占用一个尚未使用的数字。每列完成后递归下一列，最高列之后要求进位为0。

额外检查所有三个字母都已赋值的列：即使它们还未按顺序处理，输入进位也只可能是0或1，因此结果必须等于这两种余数之一。最高列两个加数已知且和≥N时必定溢出，也可立即剪枝。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string a, b, c;
    cin >> n >> a >> b >> c;
    array<int, 26> value;
    value.fill(-1);
    vector<bool> used(n);
    auto possible = [&]() {
        for (int p = 0; p < n; p++) {
            int x = value[a[p] - 'A'], y = value[b[p] - 'A'], z = value[c[p] - 'A'];
            if (p == 0 && x != -1 && y != -1 && x + y >= n)
                return false;
            if (x != -1 && y != -1 && z != -1 && (x + y) % n != z && (x + y + 1) % n != z)
                return false;
        }
        return true;
    };
    auto dfs = [&](auto &&self, int p, int carry) -> bool {
        if (p < 0)
            return carry == 0;
        int letters[2] = {a[p] - 'A', b[p] - 'A'}, result = c[p] - 'A';
        auto assign = [&](auto &&fill, int at) -> bool {
            if (at == 2) {
                int sum = value[letters[0]] + value[letters[1]] + carry, digit = sum % n;
                if (value[result] != -1)
                    return value[result] == digit && self(self, p - 1, sum / n);
                if (used[digit])
                    return false;
                value[result] = digit;
                used[digit] = true;
                if (possible() && self(self, p - 1, sum / n))
                    return true;
                used[digit] = false;
                value[result] = -1;
                return false;
            }
            int letter = letters[at];
            if (value[letter] != -1)
                return fill(fill, at + 1);
            for (int digit = n - 1; digit >= 0; digit--)
                if (!used[digit]) {
                    value[letter] = digit;
                    used[digit] = true;
                    if (possible() && fill(fill, at + 1))
                        return true;
                    used[digit] = false;
                    value[letter] = -1;
                }
            return false;
        };
        return assign(assign, 0);
    };
    dfs(dfs, n - 1, 0);
    for (int i = 0; i < n; i++)
        cout << value[i] << (i + 1 == n ? '\n' : ' ');
    return 0;
}
```

### 复杂度

最坏为排列搜索，粗略上界 $O(N^2N!)$，各列强制赋值和一致性检查大幅剪枝；空间 $O(N)$。

### 易错点

允许前导零。最高位不能再产生额外进位；相同字母在同列出现多次时只能赋同一个数字。
