## [网络流24题]最小路径覆盖问题

### 题意

DAG顶点不相交路径覆盖，输出最少路径与方案。

### 思路

把每个点拆为左出端、右入端，原边u→v对应匹配边u左→v右。匹配限制每点最多一个后继、一个前驱；DAG无环，所以得到若干条不相交路径。每增加一条匹配边，路径条数减少1，最少路径数=n−最大匹配。

从没有匹配前驱的点出发，沿匹配后继输出完整路径。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Matching {
    int left, right, shortest;
    vector<vector<int>> edge;
    vector<int> mateLeft, mateRight, distance;
    Matching(int left, int right)
        : left(left), right(right), edge(left), mateLeft(left, -1), mateRight(right, -1),
          distance(left) {}
    bool bfs() {
        queue<int> queue;
        fill(distance.begin(), distance.end(), -1);
        for (int u = 0; u < left; u++)
            if (mateLeft[u] < 0) {
                distance[u] = 0;
                queue.push(u);
            }
        shortest = INT_MAX;
        while (!queue.empty()) {
            int u = queue.front();
            queue.pop();
            if (distance[u] + 1 > shortest)
                continue;
            for (int v : edge[u])
                if (mateRight[v] < 0)
                    shortest = min(shortest, distance[u] + 1);
                else if (distance[mateRight[v]] < 0) {
                    distance[mateRight[v]] = distance[u] + 1;
                    queue.push(mateRight[v]);
                }
        }
        return shortest < INT_MAX;
    }
    bool dfs(int u) {
        for (int v : edge[u])
            if ((mateRight[v] < 0 && distance[u] + 1 == shortest) ||
                (mateRight[v] >= 0 && distance[mateRight[v]] == distance[u] + 1 &&
                 dfs(mateRight[v]))) {
                mateLeft[u] = v;
                mateRight[v] = u;
                return true;
            }
        distance[u] = -1;
        return false;
    }
    int maximum() {
        int result = 0;
        while (bfs())
            for (int u = 0; u < left; u++)
                if (mateLeft[u] < 0 && dfs(u))
                    result++;
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    Matching match(n, n);
    while (m--) {
        int u, v;
        cin >> u >> v;
        match.edge[u - 1].push_back(v - 1);
    }
    int maximum = match.maximum();
    for (int start = 0; start < n; start++)
        if (match.mateRight[start] < 0) {
            bool space = false;
            for (int u = start; u >= 0; u = match.mateLeft[u]) {
                if (space)
                    cout << ' ';
                space = true;
                cout << u + 1;
            }
            cout << '\n';
        }
    cout << n - maximum << '\n';
    return 0;
}
```

### 复杂度

时间 $O(m\sqrt n)$，空间 $O(n+m)$。

### 易错点

这里是顶点不相交覆盖，建原有边，不先做传递闭包。DAG保证匹配后继不会形成环。
