## 取石子游戏 1

### 题意

一堆N石子，每步取1到K，取完者胜。

### 思路

0是必败态。若剩余量是K+1的倍数，任何一步都会离开倍数；否则可取余数使对手面对倍数。之后对手取x，就取K+1−x回应。因此N mod(K+1)=0时后手胜，其余先手胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    cout << (n % (k + 1) ? 1 : 2);
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

这是最后取者胜的规则，取值范围包含K。
