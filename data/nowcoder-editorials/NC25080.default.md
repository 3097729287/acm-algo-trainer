## [USACO 2007 Ope S]Catch That Cow

### 题意

数轴上可减一、加一、翻倍，每次一分钟，求抓住不动的牛的最短时间。

### 思路

若起点不小于目标，直接一直减一最优；其他操作只会增大距离。否则在[0,2*目标+2]内BFS，枚举三个后继。任何越过该上界的路径都可用更早停止翻倍并靠步行替代，不会更优，故有界搜索足够。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int start, target;
    cin >> start >> target;
    if (start >= target) {
        cout << start - target;
        return 0;
    }
    int limit = 2 * target + 2;
    vector<int> distance(limit + 1, -1), queue{start};
    distance[start] = 0;
    for (size_t h = 0; h < queue.size(); h++) {
        int u = queue[h];
        if (u == target)
            break;
        for (int v : {u - 1, u + 1, u * 2})
            if (v >= 0 && v <= limit && distance[v] == -1) {
                distance[v] = distance[u] + 1;
                queue.push_back(v);
            }
    }
    cout << distance[target];
    return 0;
}
```

### 复杂度

时间、空间均为 $O(K)$，$K$为目标位置；起点不小于目标时为 $O(1)$。

### 易错点

翻倍也耗时1，不是零代价传送。0翻倍仍为0，需要访问标记防止重复。
