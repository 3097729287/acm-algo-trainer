## Sunscreen

### 题意

每头牛可接受一个防晒 SPF 区间，每瓶可供若干头，最大化匹配数量。

### 思路

按 SPF 从小到大处理防晒霜；把最低要求不超过当前 SPF 的牛加入按最高可接受 SPF 排序的小根堆。丢掉最高要求已小于当前 SPF 的牛，因为后续更高 SPF 也无法救它们。当前每份防晒霜优先给最高要求最小、最着急的牛；若某方案给了更宽松的牛，交换两者不会影响当前合法性，且把更宽松的牛留给后面也不会更差。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<pair<int, int>> cows(n), lotions(m);
    for (auto &[low, high] : cows)
        cin >> low >> high;
    for (auto &[spf, count] : lotions)
        cin >> spf >> count;
    sort(cows.begin(), cows.end());
    sort(lotions.begin(), lotions.end());
    priority_queue<int, vector<int>, greater<int>> waiting;
    int next = 0, answer = 0;
    for (auto [spf, count] : lotions) {
        while (next < n && cows[next].first <= spf)
            waiting.push(cows[next++].second);
        while (!waiting.empty() && waiting.top() < spf)
            waiting.pop();
        while (count > 0 && !waiting.empty()) {
            waiting.pop();
            count--;
            answer++;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log(n+m))$，空间 $O(n+m)$。

### 易错点

可接受区间两端都包含。每头牛只能领一份；一瓶容量大时也只循环实际分配成功的次数。
