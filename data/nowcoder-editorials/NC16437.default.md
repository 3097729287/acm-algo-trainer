## 买铅笔

### 题意

只允许买同一种包装，求至少买够 n 支铅笔的最低费用。

### 思路

对每种包装分别计算需要的包数 ceil(n/size)，用 (n+size-1)/size 完成整数上取整，再乘包价。三种方案取最小值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    long long ans = LLONG_MAX;
    for (int i = 0; i < 3; i++) {
        long long size, price;
        cin >> size >> price;
        ans = min(ans, (n + size - 1) / size * price);
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不允许混合买包装。单支价格便宜不代表补足整包后的总价最低。
