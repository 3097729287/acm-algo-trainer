## [USACO 2013 Nov G]No Change

### 题意

依次购买全部物品，每次用一枚硬币付一段连续购买且不找零，最大化剩下硬币面值。

### 思路

对固定的一枚硬币、固定的已买前缀，尽量多付连续物品不会更差：后续硬币从更靠后的前缀开始，其能覆盖到的最终位置也不会更靠前。用正价格前缀和和双指针，预处理jump[coin][prefix]表示这枚硬币能把已买前缀从prefix推进到哪里。

dp[mask]记录已使用硬币集合mask能买完的最长前缀，枚举下一枚硬币用jump推进。同一集合只需最远前缀，因为正价格使每枚后续硬币的推进函数单调。若已覆盖N件，剩余面值为硬币总和减mask面值和，更新最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int k, n;
    cin >> k >> n;
    vector<long long> coin(k), prefix(n + 1);
    long long total = 0;
    for (auto &x : coin) {
        cin >> x;
        total += x;
    }
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
    }
    vector<vector<int>> jump(k, vector<int>(n + 1));
    for (int i = 0; i < k; i++) {
        int end = 0;
        for (int begin = 0; begin <= n; begin++) {
            end = max(end, begin);
            while (end < n && prefix[end + 1] - prefix[begin] <= coin[i])
                end++;
            jump[i][begin] = end;
        }
    }
    int masks = 1 << k;
    vector<int> dp(masks, -1);
    vector<long long> spent(masks);
    dp[0] = 0;
    long long answer = -1;
    for (int mask = 0; mask < masks; mask++) {
        if (mask) {
            int bit = __builtin_ctz((unsigned)mask);
            spent[mask] = spent[mask & (mask - 1)] + coin[bit];
        }
        if (dp[mask] == -1)
            continue;
        if (dp[mask] == n) {
            answer = max(answer, total - spent[mask]);
            continue;
        }
        for (int i = 0; i < k; i++)
            if (!(mask >> i & 1))
                dp[mask | (1 << i)] = max(dp[mask | (1 << i)], jump[i][dp[mask]]);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(KN+K2^K)$，空间 $O(KN+2^K)$。

### 易错点

剩余的是未使用硬币，已用硬币多付的部分不能找回。物品顺序固定，不可跨过买不起的当前物品。
