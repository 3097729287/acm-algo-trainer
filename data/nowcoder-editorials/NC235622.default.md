## 叠积木

### 题意

整列积木放到另一列顶，查询某块下方积木数。

### 思路

并查集根表示整列最底部，size[root]记录列高，distance[x]记录x到父节点下方偏移。把x列根rx接到y列根ry时，distance[rx]=size[ry]，再增大ry列高。路径压缩时把原父节点到底部的距离加上，最终distance[x]就是下方块数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int limit = 30000;
    vector<int> parent(limit + 1), size(limit + 1, 1), distance(limit + 1);
    iota(parent.begin(), parent.end(), 0);
    auto find = [&](int x) {
        vector<int> path;
        int root = x;
        while (parent[root] != root) {
            path.push_back(root);
            root = parent[root];
        }
        int accumulated = 0;
        for (int i = (int)path.size() - 1; i >= 0; i--) {
            int u = path[i];
            accumulated += distance[u];
            parent[u] = root;
            distance[u] = accumulated;
        }
        return root;
    };
    int q;
    cin >> q;
    while (q--) {
        char op;
        int x;
        cin >> op >> x;
        if (op == 'M') {
            int y;
            cin >> y;
            int rx = find(x), ry = find(y);
            parent[rx] = ry;
            distance[rx] = size[ry];
            size[ry] += size[rx];
        } else {
            find(x);
            cout << distance[x] << '\n';
        }
    }
    return 0;
}
```

### 复杂度

路径压缩总计近线性，单次保守上界 $O(n)$；空间 $O(n)$，无递归压缩。

### 易错点

移动的是整列，不只是x上方部分。题目不输入n，按最大编号30000初始化。
