## Finding the Radius for an Inserted Circl

### 题意

三个等半径外切圆之间不断插入小圆，求第k个半径整数部分。

### 思路

以大圆曲率1/R为单位，两个固定圆的曲率均为1，尚未插圆时第三个大圆也是1。Descartes定理的两个解满足新旧曲率和为两倍其余三个圆曲率和，因此相邻插入圆的曲率满足$q_k=4+2q_{k-1}-q_{k-2}$。首项$q_0=1$、$q_1=3+2\sqrt3$，解得$q_k=2k^2+2\sqrt3k+1$，所以$R_k=R/q_k$。k最多10，直接代入并向下取整。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    long double R;
    cin >> tests >> R;
    while (tests--) {
        int k;
        cin >> k;
        long double curvature = 2.0L * k * k + 2 * sqrtl(3.0L) * k + 1;
        cout << k << ' ' << (long long)floorl(R / curvature) << '\n';
    }
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

这里输出整数部分，不是四舍五入。输入末尾−1是结束标志，不属于T个询问。π并不参与相切圆半径公式。
