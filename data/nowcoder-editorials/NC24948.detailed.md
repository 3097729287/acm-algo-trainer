## Cow Contest

> 原题：[P2419](https://www.luogu.com.cn/problem/P2419)
> 解法：传递闭包确定谁比谁强，再检查与所有人的关系 · C++17

### 题意

胜负始终由不同的真实实力决定，资料没有矛盾。根据部分比赛结果，统计具体名次已经可以唯一确定的奶牛数量。



### 思路

若 A 赢 B、B 赢 C，实力严格排名就保证 A 也强于 C，即使两者没有直接比赛。需要先补齐全部可以推出的大小关系。

$reach[u][v]$ 只表示“能根据资料确定 $u$ 比 $v$ 强”，不是任意猜测的真实胜负。初始化已给比赛后，按 $k$、$u$、$v$ 三层循环：如果 $u$ 强于 $k$ 且 $k$ 强于 $v$，就知道 $u$ 强于 $v$。$k$ 逐个加入允许经过的中转点，最终涵盖任意长度的关系链。

对于固定 $u$，若每个其它顶点与它都有已知大小关系，那么比 $u$ 强的数量固定，它的名次就是这个数量加一。其它牛之间即便仍无法排序，也不会改变它们在 $u$ 上面还是下面。

为什么只要还有不可比较对象，$u$ 的名次就不能确定？把必在 $u$ 前的祖先先排好；可以立刻放 $u$，得到最早位置。也可以先把所有不是 $u$ 后继的点排完再放 $u$，得到最晚位置：不存在从后继指回这些点的边，否则它们也会成为后继。两种位置相差不可比较点的数量。因此至少一个不可比较点就带来不同名次。

图无矛盾环，所以一对不同奶牛不会同时互相可达。程序检查所有 $v \ne u$，不把 $u$ 自己算作一个已比较对象。$n$ 不超过一百，三次方的传递闭包足够。

时间 $O(n^3)$，空间 $O(n^2)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<bool>> reach(n + 1, vector<bool>(n + 1));
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        reach[u][v] = true;
    }
    for (int k = 1; k <= n; k++)
        for (int u = 1; u <= n; u++)
            if (reach[u][k])
                for (int v = 1; v <= n; v++)
                    reach[u][v] = reach[u][v] || reach[k][v];
    int answer = 0;
    for (int u = 1; u <= n; u++) {
        bool fixed = true;
        for (int v = 1; v <= n; v++)
            if (v != u && !reach[u][v] && !reach[v][u])
                fixed = false;
        if (fixed)
            ++answer;
    }
    cout << answer << '\n';
    return 0;
}
```

### 易错点

Floyd 的中转点循环放最外层；统计可推导的全部关系；一个人的名次确定不要求全体排名唯一。
