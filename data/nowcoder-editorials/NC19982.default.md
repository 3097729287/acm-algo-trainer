## [HAOI2011]PROBLEM A

### 题意

每人声称比自己高、低分人数，最少说谎人数。

### 思路

声称(a,b)的人若说真话，其所在同分组占据排序名次[a+1,n−b]，长度为n−a−b。相同声明可同时为真，但至多选该长度的人数，权重为min(声明次数,区间长度)。不同真实同分组的名次区间必须互不重叠。

因此合并相同声明后，变成带权区间调度：dp[r]为前r个名次最多真实人数，dp[r]先继承dp[r−1]，再对所有以r结束的组更新dp[l−1]+weight。未选名次由说谎者补齐，不影响已选组。答案n−dp[n]。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    map<pair<int, int>, int> count;
    for (int i = 0; i < n; i++) {
        int a, b;
        cin >> a >> b;
        if (a + b < n)
            count[{a + 1, n - b}]++;
    }
    vector<vector<pair<int, int>>> ending(n + 1);
    for (auto [interval, frequency] : count) {
        auto [l, r] = interval;
        ending[r].push_back({l, min(frequency, r - l + 1)});
    }
    vector<int> dp(n + 1);
    for (int r = 1; r <= n; r++) {
        dp[r] = dp[r - 1];
        for (auto [l, w] : ending[r])
            dp[r] = max(dp[r], dp[l - 1] + w);
    }
    cout << n - dp[n];
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

a+b≥n时同分组长度非正，该声明必假。相同声明人数超过组大小，只能让其中一部分为真。
