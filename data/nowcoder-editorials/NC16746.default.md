## 神奇盘子

### 题意

圆盘内移动，到边界可免费传到对径点，求两点间最短步行距离。

### 思路

最优路只需考虑零次或一次传送。若有连续两次传送 P→-P、Q→-Q，中间步行长度至少 |-P-Q|；直接在盘内从 P 走到 -Q 的长度相同，就能删掉这两次传送。反复消去即可。

零次是直线距离；一次传送时，枚举圆周入口 P，代价为 |A-P|+|B+P|，也就是 P 到两个焦点 A、-B 的距离和。圆周上的函数不宜直接假定为单峰，这里使用可证明误差的分支定界：对任意角度弧段，分别求每个焦点到该弧段的最小距离，两者之和是整段代价的下界。单个最小距离若焦点的径向方向在弧内，就等于半径减焦点半径；否则取两个端点中较近的。

用最小堆优先细分下界最小的弧段，中点实际代价更新当前最好值 best。下界不小于 best 的弧段可丢弃；当堆中最小下界与 best 相差已不超过所需容差时，真实最优值被夹在两者之间，精度得到保证。代码把误差目标设为题目容差的百分之一，并用径向点和直线路径先提供上界。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Focus {
    long double x, y, length, angle;
};
struct Arc {
    long double left, right, lower;
    bool operator<(const Arc &other) const { return lower > other.lower; }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long double radius, ax, ay, bx, by;
    cin >> radius >> ax >> ay >> bx >> by;
    const long double pi = acosl(-1.0L);
    long double turn = 2 * pi;
    auto focus = [&](long double x, long double y) {
        long double angle = atan2l(y, x);
        if (angle < 0)
            angle += turn;
        return Focus{x, y, hypotl(x, y), angle};
    };
    Focus a = focus(ax, ay), b = focus(-bx, -by);
    auto distances = [&](long double angle) {
        long double x = radius * cosl(angle), y = radius * sinl(angle);
        return pair<long double, long double>{hypotl(x - a.x, y - a.y), hypotl(x - b.x, y - b.y)};
    };
    auto cost = [&](long double angle) {
        auto [x, y] = distances(angle);
        return x + y;
    };
    auto bound = [&](long double left, long double right) {
        auto dl = distances(left), dr = distances(right);
        long double x = min(dl.first, dr.first), y = min(dl.second, dr.second);
        if (left <= a.angle && a.angle <= right)
            x = radius - a.length;
        if (left <= b.angle && b.angle <= right)
            y = radius - b.length;
        return max(0.0L, x) + max(0.0L, y);
    };
    long double best = min({hypotl(ax - bx, ay - by), cost(a.angle), cost(b.angle)});
    priority_queue<Arc> queue;
    auto offer = [&](long double l, long double r) {
        long double lower = bound(l, r);
        if (lower < best)
            queue.push({l, r, lower});
    };
    for (int i = 0; i < 32; i++) {
        long double l = turn * i / 32, r = turn * (i + 1) / 32;
        best = min(best, cost((l + r) / 2));
        offer(l, r);
    }
    while (!queue.empty()) {
        Arc arc = queue.top();
        if (best - arc.lower <= 1e-8L * max(1.0L, best))
            break;
        queue.pop();
        long double mid = (arc.left + arc.right) / 2;
        best = min(best, cost(mid));
        offer(arc.left, mid);
        offer(mid, arc.right);
    }
    cout << fixed << setprecision(12) << best;
    return 0;
}
```

### 复杂度

设实际细分了 $K$ 个弧段，时间 $O(K\log K)$，空间 $O(K)$；停止依据上下界误差。

### 易错点

起终点在边界时，最短距离可能为零。所有候选路径都在凸圆盘内；弧段下界分别取两项的最小值，即使它们在不同位置达到，也仍是合法下界。
