## 栗酱的文明2

### 题意

选最多国家互相建立外交关系，每份使馆占一块地，有外交关系的国家还需预留一块地。

### 思路

选 k 个国家时，每国要放其余 k-1 国的大使馆，另预留一块，所以每个入选国家至少有 k 块土地。按土地数降序排列，若第 k 大土地数≥k，则前 k 国可组成方案。扫描最大的合法 k 即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        vector<int> a(n);
        for (int &x : a)
            cin >> x;
        sort(a.rbegin(), a.rend());
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (a[i] >= i + 1)
                ans = i + 1;
            else
                break;
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，数组空间 $O(n)$。

### 易错点

不能漏掉备用使馆占用的一块土地；只要求各国都够 k 块，不需要把土地数求和。
