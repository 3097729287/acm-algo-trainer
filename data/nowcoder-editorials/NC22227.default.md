## 约瑟夫环

### 题意

从编号 k 开始每报 m 淘汰一人，求零起始编号的最后幸存者。

### 思路

先按起点为零求幸存者。只有一人时下标为零；人数从 i-1 增加到 i 时，第一次出队后下一次报数起点为 m mod i，所以把旧幸存者位置加 m 再对 i 取余。最终再加初始起点 k，并对 n 取余。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k, m;
    cin >> n >> k >> m;
    int survivor = 0;
    for (int i = 2; i <= n; i++)
        survivor = (survivor + m) % i;
    cout << (survivor + k) % n;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

k 位置报的是一而不是零；报 m 的人出队后，从下一人重新报一。
