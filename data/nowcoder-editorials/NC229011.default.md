## Biorhythms

### 题意

周期23、28、33的峰值，求给定日期后下一次共同峰值。

### 思路

三个周期互素，总周期M=21252。CRT中，M/23乘其模23逆元得到5544，另两个对应14421、1288，所以峰值日x=(5544p+14421e+1288i) mod M。距离为(x−d)规范到模M后，若为0则取M，因为题目排除当天。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    const long long period = 21252;
    while (tests--) {
        long long p, e, i, d;
        cin >> p >> e >> i >> d;
        long long answer = (5544 * p + 14421 * e + 1288 * i - d) % period;
        if (answer <= 0)
            answer += period;
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均 $O(1)$。

### 易错点

输出只要天数，没有原始POJ版本的Case前缀。三重峰恰在当天时，应等待一个完整周期。
