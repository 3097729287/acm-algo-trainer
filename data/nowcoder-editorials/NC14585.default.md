## 大吉大利，今晚吃鸡

### 题意

只允许相邻柱移动，将 n 个盘从最左柱搬到最右柱，求最少步数。

### 思路

为了让最大盘从左经中到右，较小 n-1 个盘必须依次完成三次左右端柱之间的搬运；最大盘本身移动两次。所以 T[n]=3T[n-1]+2，T[0]=0，解得 T[n]=3^n-1。按整数循环乘三，避免浮点 pow。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        long long power = 1;
        for (int i = 0; i < n; i++)
            power *= 3;
        cout << power - 1 << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n)$，额外空间 $O(1)$。

### 易错点

普通汉诺塔的 2^n-1 不适用，因为最大盘不能从左柱直接移到右柱。
