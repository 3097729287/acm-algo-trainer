## 第k大与第m大

### 题意

所有长度至少 k 的子段各取第 k 大，求这些数中的第 m 大。

### 思路

二分候选值 x。某个子段的第 k 大至少为 x，当且仅当子段里至少有 k 个不小于 x 的数。扫描右端点，用左指针维护窗口中这类数少于 k：只要数量达到 k 就移出左端。此时起点为零到 left-1 的全部子段都曾包含至少 k 个，贡献 left 个。把每个右端的贡献相加，若至少为 m，说明最终第 m 大也至少为 x。目标值越大满足的子段越少，二分最大可行值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, k;
        long long m;
        cin >> n >> k >> m;
        vector<int> a(n);
        int high = 0;
        for (int &x : a) {
            cin >> x;
            high = max(high, x);
        }
        auto possible = [&](int value) {
            int left = 0, count = 0;
            long long segments = 0;
            for (int right = 0; right < n; right++) {
                count += a[right] >= value;
                while (count >= k) {
                    count -= a[left] >= value;
                    left++;
                }
                segments += left;
            }
            return segments >= m;
        };
        int low = 1;
        while (low < high) {
            int mid = low + (high - low + 1) / 2;
            if (possible(mid))
                low = mid;
            else
                high = mid - 1;
        }
        cout << low << '\n';
    }
    return 0;
}
```

### 复杂度

值域上限 $V$，时间 $O(n\log V)$，空间 $O(n)$。

### 易错点

要求的是两层第几大，不是第几小；判定使用大于等于以正确处理重复值。m 和子段数都可能超过有符号 int。
