## 求逆序数

### 题意

统计前面元素严格大于后面元素的有序位置对数。

### 思路

本题 n 不超过两千，可以直接枚举 i<j 的每一对，若 a[i]>a[j] 就计数。每对只在它的前后下标被枚举时出现一次，不会重复。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    long long ans = 0;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (a[i] > a[j])
                ans++;
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，数组空间 $O(n)$。

### 易错点

相同元素不构成逆序对。这里按两千的范围选双循环，不能照搬到五十万规模的逆序对模板。
