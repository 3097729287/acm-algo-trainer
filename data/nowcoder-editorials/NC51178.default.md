## 没有上司的舞会

### 题意

员工与直接上司不能同时参加，快乐值可为负，求最大总快乐。

### 思路

每点维护选、不选两状态。选u时各孩子都不选；不选u时每个孩子独立取两状态较大者。叶子选值等于自己的快乐，不选为0，允许全不选。由无父亲的校长向下遍历，再逆序计算，答案为根两状态最大。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> happiness(n);
    for (auto &x : happiness)
        cin >> x;
    vector<vector<int>> children(n);
    vector<int> parent(n, -1);
    int child, boss;
    while (cin >> child >> boss && (child || boss)) {
        child--;
        boss--;
        children[boss].push_back(child);
        parent[child] = boss;
    }
    int root = 0;
    while (parent[root] != -1)
        root = parent[root];
    vector<int> order{root};
    for (size_t i = 0; i < order.size(); i++)
        for (int v : children[order[i]])
            order.push_back(v);
    vector<array<long long, 2>> dp(n);
    for (int i = n - 1; i >= 0; i--) {
        int u = order[i];
        dp[u][1] = happiness[u];
        for (int v : children[u]) {
            dp[u][0] += max(dp[v][0], dp[v][1]);
            dp[u][1] += dp[v][0];
        }
    }
    cout << max(dp[root][0], dp[root][1]);
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

输入是下属L、上司K，边方向不要反。只禁止直接上司和下属同场，祖孙可以同选。
