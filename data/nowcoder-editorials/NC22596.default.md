## Rinne Loves Data Structure

### 题意

按图中规则向普通二叉搜索树插入，重复值不新建，每次输出深度总和。

### 思路

已查看原题伪代码：小于走左、大于走右，等于时不做任何事。新值的父亲一定是已插入值中的前驱或后继；两者都存在时，取深度更大的一个，再加一。原因是前驱与后继之间没有已插入键，新键所在空隙的两个边界中较深者就是直接父结点；若两边界都在树中，较浅者是较深者的祖先。用 map 保存已插入键的深度，根深度为零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    map<int, int> depth;
    long long total = 0;
    while (n--) {
        int x;
        cin >> x;
        auto it = depth.lower_bound(x);
        if (it == depth.end() || it->first != x) {
            int parentDepth = -1;
            if (it != depth.end())
                parentDepth = max(parentDepth, it->second);
            if (it != depth.begin())
                parentDepth = max(parentDepth, prev(it)->second);
            int d = parentDepth + 1;
            depth[x] = d;
            total += d;
        }
        cout << total << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

不能真的按普通BST一路走，升序输入会退化到平方。伪代码没有处理相等值，因此相等时深度总和不变。
