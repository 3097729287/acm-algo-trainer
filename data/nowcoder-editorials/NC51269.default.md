## Network of Schools

### 题意

最少起始软件副本，以及最少加边使全图强连通。

### 思路

缩点DAG中，每个源分量必须得到一个初始副本，其他点都能由源到达，所以第一问为源数。若只有一个SCC，第二问为0；否则至少要给每个源补入边、每个汇补出边，下界max(源数,汇数)。通过把源到汇的可达链连接成环并接入其余源汇可达到此界，因此第二问为两者最大。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

pair<int, vector<int>> components(const vector<vector<int>> &graph,
                                  const vector<vector<int>> &reverse) {
    int n = graph.size();
    vector<bool> seen(n);
    vector<int> finish;
    for (int start = 0; start < n; start++)
        if (!seen[start]) {
            vector<pair<int, int>> stack{{start, 0}};
            seen[start] = true;
            while (!stack.empty()) {
                int u = stack.back().first, &position = stack.back().second;
                if (position == (int)graph[u].size()) {
                    finish.push_back(u);
                    stack.pop_back();
                } else {
                    int v = graph[u][position++];
                    if (!seen[v]) {
                        seen[v] = true;
                        stack.push_back({v, 0});
                    }
                }
            }
        }
    vector<int> component(n, -1);
    int count = 0;
    for (int i = n - 1; i >= 0; i--) {
        int start = finish[i];
        if (component[start] != -1)
            continue;
        vector<int> stack{start};
        component[start] = count;
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            for (int v : reverse[u])
                if (component[v] == -1) {
                    component[v] = count;
                    stack.push_back(v);
                }
        }
        count++;
    }
    return {count, component};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> graph(n), reverse(n);
    for (int u = 0; u < n; u++) {
        int v;
        while (cin >> v && v) {
            v--;
            graph[u].push_back(v);
            reverse[v].push_back(u);
        }
    }
    auto [count, component] = components(graph, reverse);
    vector<int> in(count), out(count);
    for (int u = 0; u < n; u++)
        for (int v : graph[u])
            if (component[u] != component[v]) {
                in[component[v]]++;
                out[component[u]]++;
            }
    int sources = 0, sinks = 0;
    for (int c = 0; c < count; c++) {
        sources += in[c] == 0;
        sinks += out[c] == 0;
    }
    cout << sources << '\n' << (count == 1 ? 0 : max(sources, sinks));
    return 0;
}
```

### 复杂度

时间、空间均 $O(n+m)$。

### 易错点

已经强连通时第一问仍需1份副本，第二问才是0。
