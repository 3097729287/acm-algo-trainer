## 排队领水

### 题意

队伍有 n 人，前面至少 a 人、后面至多 b 人，求可能的位置数。

### 思路

若从前往后的位置为 p，则 p-1≥a、n-p≤b，所以 p≥max(a+1,n-b)。上界为 n，位置数为 n-max(a+1,n-b)+1，也就是 min(n-a,b+1)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, a, b;
    cin >> n >> a >> b;
    cout << min(n - a, b + 1);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

条件是前面不少于、后面不多于，两者都给位置的下界。
