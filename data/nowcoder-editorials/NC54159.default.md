## 上三角矩阵判定

### 题意

判断主对角线下方的元素是否全为零。

### 思路

按行列读取，每遇到 i>j 的位置就检查它是否为零。如果有非零值，最终输出 NO；否则输出 YES。对角线及上方没有限制。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    bool ok = true;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) {
            int x;
            cin >> x;
            if (i > j && x != 0)
                ok = false;
        }
    cout << (ok ? "YES\n" : "NO\n");
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，额外空间 $O(1)$。

### 易错点

上三角矩阵不要求对角线为一，也不要求对角线上方非零。
