## 弩蚊怒夏

### 题意

每次消灭位置区间内体形至少 p 的活蚊子，输出本次消灭的体形和。

### 思路

每个位置的蚊子按体形排序，活蚊子最大值在末尾。线段树维护区间最大活蚊子体形；若最大值小于阈值，整段不用访问。否则递归到有关叶子，从末尾连续删除不小于阈值的蚊子，累加体形，随后更新最大值。虽然一次可能删很多，但每只蚊子只能被删一次，所有深入删除的工作可以摊还到这只被删除的蚊子上；另加每次查询的边界访问即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct MosquitoTree {
    int n;
    vector<vector<int>> sizes;
    vector<int> maximum;
    explicit MosquitoTree(int count) : n(count), sizes(count + 1), maximum(4 * count + 4) {}
    void build(int p, int l, int r) {
        if (l == r) {
            sort(sizes[l].begin(), sizes[l].end());
            maximum[p] = sizes[l].empty() ? 0 : sizes[l].back();
            return;
        }
        int mid = (l + r) / 2;
        build(p * 2, l, mid);
        build(p * 2 + 1, mid + 1, r);
        maximum[p] = max(maximum[p * 2], maximum[p * 2 + 1]);
    }
    long long strike(int p, int l, int r, int ql, int qr, int threshold) {
        if (r < ql || qr < l || maximum[p] < threshold)
            return 0;
        if (l == r) {
            long long answer = 0;
            while (!sizes[l].empty() && sizes[l].back() >= threshold) {
                answer += sizes[l].back();
                sizes[l].pop_back();
            }
            maximum[p] = sizes[l].empty() ? 0 : sizes[l].back();
            return answer;
        }
        int mid = (l + r) / 2;
        long long answer = strike(p * 2, l, mid, ql, qr, threshold) +
                           strike(p * 2 + 1, mid + 1, r, ql, qr, threshold);
        maximum[p] = max(maximum[p * 2], maximum[p * 2 + 1]);
        return answer;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    MosquitoTree tree(n);
    for (int i = 0; i < m; i++) {
        int position, size;
        cin >> position >> size;
        tree.sizes[position].push_back(size);
    }
    tree.build(1, 1, n);
    while (k--) {
        int l, r, threshold;
        cin >> l >> r >> threshold;
        cout << tree.strike(1, 1, n, l, r, threshold) << '\n';
    }
    return 0;
}
```

### 复杂度

排序总计 $O(m\log m)$，所有操作摊还 $O((m+k)\log n)$，空间 $O(n+m)$。

### 易错点

同一位置可能有多只，不能只存一只。拍死后永久删除，之后查询不能再次计入。体形总和使用 long long。
