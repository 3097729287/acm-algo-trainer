## 栗酱的数列

### 题意

统计 A 的长度 m 子段，使它与 B 对位相加后模 k 的结果全相同。

### 思路

所有结果相同，等价于每一对相邻结果差为零，即 A段[i+1]-A段[i]≡B[i]-B[i+1] (mod k)。因此把 A 转为相邻正向差分模 k，把 B 转为反向差分模 k，问题变成长度 n-1 序列中匹配长度 m-1 序列的出现次数。用整数序列上的 KMP，允许重叠匹配。负差取模后加 k 规范为非负。

前缀函数 pi[i] 记录前缀 s[0..i] 的最长相同真前后缀长度。失配时令已匹配长度 j=pi[j-1]，保留仍可能匹配的后缀；成功时 j 增一。每次回退都会减少 j，增长总数只与串长成正比，因此预处理和扫描均为线性。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

template <class Sequence> vector<int> prefixFunction(const Sequence &s) {
    int n = s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])
            j = pi[j - 1];
        if (s[i] == s[j])
            j++;
        pi[i] = j;
    }
    return pi;
}

template <class Sequence>
long long occurrences(const Sequence &text, const Sequence &pattern, const vector<int> &pi) {
    if (pattern.empty())
        return text.size() + 1;
    int matched = 0;
    long long answer = 0;
    for (const auto &value : text) {
        while (matched > 0 && value != pattern[matched])
            matched = pi[matched - 1];
        if (value == pattern[matched])
            matched++;
        if (matched == (int)pattern.size()) {
            answer++;
            matched = pi[matched - 1];
        }
    }
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        long long k;
        cin >> n >> m >> k;
        vector<long long> a(n), b(m);
        for (auto &x : a)
            cin >> x;
        for (auto &x : b)
            cin >> x;
        vector<long long> text(n - 1), pattern(m - 1);
        for (int i = 0; i + 1 < n; i++)
            text[i] = (a[i + 1] - a[i] + k) % k;
        for (int i = 0; i + 1 < m; i++)
            pattern[i] = (b[i] - b[i + 1] + k) % k;
        auto pi = prefixFunction(pattern);
        cout << occurrences(text, pattern, pi) << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n+m)$。

### 易错点

B 的差分方向与 A 相反。k=1 时全部差分均为零，应该匹配全部 n-m+1 个窗口。
