## 逆序对

### 题意

累计全部长度 n 的零一串中，前一后一零的下标对总数。

### 思路

先固定一对位置 i<j，它们必须分别是一、零，其余 n-2 位任意，所以每对贡献 2^(n-2) 个串。位置对有 n(n-1)/2 个，答案为该组合数乘 2^(n-2)，模 10^9+7。n<2 时没有位置对，单独输出零。组合数中的除二用模逆元 500000004。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 1000000007;
    long long n;
    cin >> n;
    if (n < 2) {
        cout << 0;
        return 0;
    }
    long long power = 1, base = 2, exponent = n - 2;
    while (exponent) {
        if (exponent & 1)
            power = power * base % mod;
        base = base * base % mod;
        exponent >>= 1;
    }
    cout << (n % mod) * ((n - 1) % mod) % mod * 500000004 % mod * power % mod;
    return 0;
}
```

### 复杂度

时间 $O(\log n)$，额外空间 $O(1)$。

### 易错点

n 可达 10^18，不能直接先算 n(n-1)。指数保存原始值，不能无条件先对模数取余。
