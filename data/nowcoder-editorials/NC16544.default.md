## 简单环

### 题意

统计无向简单环，按环长模k分类，长度必须大于2，答案模998244353。

### 思路

每个环固定最小编号点s作为起点，只访问编号>s的其他点，消除选起点的重复。dp[mask][last]记录从s出发、依次访问mask中的其余点并停在last的简单路径数。若last与s相连且mask至少两点，这条路径可以闭合，按(popcount(mask)+1)%k计入。继续沿未访问邻点扩展。每个无向环仍被顺、逆两个方向各算一次，最后乘2的模逆元。

每次固定s单独开表，最多存(n−1)*2^(n−1)个32位数，而非对全部s同时开大表。邻接位集与最低位遍历只枚举存在的下一条边。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    vector<unsigned int> adjacency(n);
    while (m--) {
        int a, b;
        cin >> a >> b;
        --a;
        --b;
        adjacency[a] |= 1U << b;
        adjacency[b] |= 1U << a;
    }
    const int mod = 998244353;
    vector<int> answer(k);
    for (int start = 0; start + 2 < n; start++) {
        int remaining = n - start - 1, masks = 1 << remaining;
        vector<int> dp((size_t)masks * remaining);
        for (int j = 0; j < remaining; j++)
            if (adjacency[start] >> (start + 1 + j) & 1U)
                dp[(size_t)(1 << j) * remaining + j] = 1;
        for (int mask = 1; mask < masks; mask++) {
            int length = __builtin_popcount((unsigned)mask) + 1;
            unsigned int ends = mask;
            while (ends) {
                int last = __builtin_ctz(ends);
                ends &= ends - 1;
                int ways = dp[(size_t)mask * remaining + last];
                if (!ways)
                    continue;
                int u = start + 1 + last;
                if (length >= 3 && (adjacency[u] >> start & 1U)) {
                    int &target = answer[length % k];
                    target += ways;
                    if (target >= mod)
                        target -= mod;
                }
                unsigned int next = (adjacency[u] >> (start + 1)) & ~((unsigned)mask);
                while (next) {
                    int v = __builtin_ctz(next);
                    next &= next - 1;
                    int &target = dp[(size_t)(mask | (1 << v)) * remaining + v];
                    target += ways;
                    if (target >= mod)
                        target -= mod;
                }
            }
        }
    }
    for (int x : answer)
        cout << 1LL * x * 499122177 % mod << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n^2 2^n)$，峰值空间 $O(n2^{n-1})$，$n\le20$。

### 易错点

不把一条边来回走形成的长度2回路计入。固定最小顶点只去掉起点重复，仍需除以两个方向。
