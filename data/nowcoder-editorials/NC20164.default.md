## [JSOI2008]最大数MAXNUMBER

### 题意

末尾加入反馈取模后的数，查询最后L项最大值。

### 思路

维护下标递增、数值严格递减的候选栈。新值v加入时，栈尾值≤v的候选可以永久删除：未来任何包含旧下标的后缀也包含更新、更大的v。查询最后L项，就是找栈中第一个下标≥长度−L+1的候选，它是区间最大值，二分即可。每次把答案记录为t，供下次插入使用。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m;
    long long d;
    cin >> m >> d;
    vector<int> position;
    vector<long long> value;
    int length = 0;
    long long last = 0;
    while (m--) {
        char op;
        long long x;
        cin >> op >> x;
        if (op == 'A') {
            long long v = ((x % d) + last) % d;
            length++;
            while (!value.empty() && value.back() <= v) {
                value.pop_back();
                position.pop_back();
            }
            position.push_back(length);
            value.push_back(v);
        } else {
            int start = length - (int)x + 1;
            int index = lower_bound(position.begin(), position.end(), start) - position.begin();
            last = value[index];
            cout << last << '\n';
        }
    }
    return 0;
}
```

### 复杂度

插入总计 $O(M)$，每问 $O(\log M)$，空间 $O(M)$。

### 易错点

被支配候选可删，历史查询答案t仍独立保存。先对输入x取模，再加t，避免长整数输入相加溢出。
