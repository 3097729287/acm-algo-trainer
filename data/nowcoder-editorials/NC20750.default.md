## 小飞机

### 题意

按原题图片输出六行小飞机。

### 思路

前两行各是五个空格和两个星号，中间两行各十二个星号，最后两行各是四个空格、一个星号、两个空格、一个星号。逐行输出即可，行末不补空格。原站样例的输入输出均为空，形状以题面图片为准。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout << "     **\n     **\n************\n************\n    *  *\n    *  *";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

图案使用半角空格与星号；不能把原站空白样例误当作无需输出。
