## 迷你扫雷

### 题意

仅第一列可放雷，第二列给出相邻三格雷数，统计所有合法布雷。

### 思路

记第一列第 i 格是否有雷为 x[i]，边界 x[0]=x[n+1]=0。只需枚举 x[1] 为零或一；由 a[i]=x[i-1]+x[i]+x[i+1]，每个后续 x[i+1] 都被唯一确定。递推出的值必须为零或一，最后还必须满足棋盘外的 x[n+1]=0。统计两次尝试中合法的个数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    int answer = 0;
    for (int first = 0; first <= 1; first++) {
        int previous = 0, current = first;
        bool valid = true;
        for (int i = 1; i <= n; i++) {
            int next = a[i] - previous - current;
            if (next < 0 || next > 1 || (i == n && next != 0)) {
                valid = false;
                break;
            }
            previous = current;
            current = next;
        }
        answer += valid;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，保存输入 $O(n)$。

### 易错点

越出上下边界均无雷，最后一项必须专门检查。后续位置已被方程强迫，不需要枚举二的 n 次方种布局。
