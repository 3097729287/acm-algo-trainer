## 嗅探器

### 题意

两指定点的全部通路必经的最小编号中间服务器。

### 思路

n≤100，直接按编号枚举除a、b外的候选。暂时禁止经过该点，从a做BFS；若b不可达，该服务器就在全部a到b路径上，最先成功的编号即答案。若原图两中心就不连通，没有需截获的通信路径，输出No solution。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> edge(n);
    int u, v;
    while (cin >> u >> v && (u || v)) {
        u--;
        v--;
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    int a, b;
    cin >> a >> b;
    a--;
    b--;
    auto reachable = [&](int banned) {
        vector<bool> seen(n);
        vector<int> queue = {a};
        seen[a] = true;
        for (size_t i = 0; i < queue.size(); i++)
            for (int v : edge[queue[i]])
                if (v != banned && !seen[v]) {
                    seen[v] = true;
                    queue.push_back(v);
                }
        return (bool)seen[b];
    };
    if (reachable(-1))
        for (int candidate = 0; candidate < n; candidate++)
            if (candidate != a && candidate != b && !reachable(candidate)) {
                cout << candidate + 1;
                return 0;
            }
    cout << "No solution";
    return 0;
}
```

### 复杂度

时间 $O(n(n+m))$，空间 $O(n+m)$。

### 易错点

不能把两个中心自身当中间服务器。无需枚举所有简单路径，删除点后测试连通性等价。
