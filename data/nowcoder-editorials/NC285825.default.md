## 中位数图

### 题意

按样例与原 CQOI 题意，统计中位数为 b 的奇数长度连续子段。

### 思路

题面对子序列的注释与样例有歧义：样例统计的是连续子段，此处按样例及原题处理。排列中 b 只有一个，合法段必须包含它。把大于 b 的数看成 +1，小于 b 的数看成 -1，合法条件就变为两种数个数相同。以 b 为中心，枚举左边界，统计左侧符号和的频次（包含空左侧的零）；再从 b 向右累加，若右侧和为 s，就加入左侧和为 -s 的个数。符号和为零已保证除 b 外元素成对，长度自然为奇数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, b;
    cin >> n >> b;
    vector<int> a(n);
    int position = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] == b)
            position = i;
    }
    vector<long long> count(2 * n + 3);
    int offset = n + 1, balance = 0;
    count[offset] = 1;
    for (int i = position - 1; i >= 0; i--) {
        balance += a[i] > b ? 1 : -1;
        count[offset + balance]++;
    }
    long long answer = count[offset];
    balance = 0;
    for (int i = position + 1; i < n; i++) {
        balance += a[i] > b ? 1 : -1;
        answer += count[offset - balance];
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

这里的处理对象是连续子段；若按任意删除得到的非连续子序列计数，第一个样例就不再是三。答案可为二次量级，要用 long long。
