## FBI树

### 题意

对二进制串递归二分，以全零 B、全一 I、混合 F 标记结点，输出后序。

### 思路

递归函数返回当前子串的类型，并在左右递归完成后输出本结点类型。单字符直接判为 B 或 I；若两个子结点同为 B 或同为 I，父结点同类，其余情况为 F。两个子结点都是 F 时父结点仍为 F。每个结点只处理一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string s;
    cin >> n >> s;
    function<char(int, int)> solve = [&](int l, int r) {
        char result;
        if (l == r)
            result = s[l] == '0' ? 'B' : 'I';
        else {
            int mid = (l + r) / 2;
            char left = solve(l, mid), right = solve(mid + 1, r);
            result = left == right ? left : 'F';
        }
        cout << result;
        return result;
    };
    solve(0, (int)s.size() - 1);
    return 0;
}
```

### 复杂度

串长 $L=2^N$ 时，时间 $O(L)$，输入空间 $O(L)$，递归栈 $O(\log L)$。

### 易错点

后序必须先左、再右、最后父结点。不要在进入递归时就输出父结点。
