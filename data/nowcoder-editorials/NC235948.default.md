## 最大子串和

### 题意

求最大非空连续子数组和。

### 思路

维护end为恰以当前元素x结尾的最大子段和，更新end=max(x,end+x)，再更新全局最大值。初始用第一个元素，保证全负数组仍选出最大的单个负数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long ending = 0, answer = LLONG_MIN;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        ending = i ? max(x, ending + x) : x;
        answer = max(answer, ending);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

至少选一个，不能用0作为最终答案下界。百万个十亿值相加需64位。
