## 素数分布

### 题意

多次查询不超过 n 的素数个数。

### 思路

先筛出一千以内的素数，再令 prefix[i]=prefix[i-1]+isPrime[i]。每个查询直接输出 prefix[n]，所有查询共享一次预处理。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int limit = 1000;
    vector<bool> prime(limit + 1, true);
    prime[0] = prime[1] = false;
    for (int p = 2; p <= limit / p; p++)
        if (prime[p])
            for (int x = p * p; x <= limit; x += p)
                prime[x] = false;
    int prefix[limit + 1] = {};
    for (int i = 1; i <= limit; i++)
        prefix[i] = prefix[i - 1] + prime[i];
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        cout << prefix[n] << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(U\log\log U)$，每次查询 $O(1)$，空间 $O(U)$，$U=1000$。

### 易错点

查询包含 n 本身；n=1 时答案为零。
