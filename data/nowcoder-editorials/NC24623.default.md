## Tree Decoration

### 题意

每个子树有最少装饰数量，每个结点单件安装费用不同，求最小总费用。

### 思路

自底向上处理。每个子树维护已满足子树内部约束的装饰总数、总费用，以及本子树的最低单件安装费。先累加各孩子的装饰与费用，最低费用同时与本结点比较。若当前子树数量还不足C[u]，就在本子树最便宜结点补齐；这不会破坏任何后代下界，只会增加计数。后面祖先新增装饰同样不能替代当前子树已经必须付出的最低费用，因此局部补齐最优。迭代得到遍历顺序，再逆序处理避免长链递归。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> children(n);
    vector<long long> required(n), count(n), cost(n);
    vector<int> cheapest(n);
    int root = 0;
    for (int u = 0; u < n; u++) {
        int parent;
        cin >> parent >> required[u] >> cheapest[u];
        if (parent == -1)
            root = u;
        else
            children[parent - 1].push_back(u);
    }
    vector<int> order{root};
    for (size_t i = 0; i < order.size(); i++)
        for (int v : children[order[i]])
            order.push_back(v);
    for (int i = n - 1; i >= 0; i--) {
        int u = order[i];
        for (int v : children[u]) {
            count[u] += count[v];
            cost[u] += cost[v];
            cheapest[u] = min(cheapest[u], cheapest[v]);
        }
        if (count[u] < required[u]) {
            cost[u] += (required[u] - count[u]) * cheapest[u];
            count[u] = required[u];
        }
    }
    cout << cost[root];
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

父亲编号不一定小于孩子，不能直接按编号逆序。最低单价允许来自任何后代，不仅当前点。
