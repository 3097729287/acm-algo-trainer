## 绿魔法师

### 题意

每次先把x加入多重集，再求所有gcd(x,y)的k次方模p，k和p可每次变化。

### 思路

维护count[d]为已加入数中d的倍数个数，加入x只更新它的全部约数。对本次x，gcd只能是x的约数。设ways[d]为gcd恰等于d的次数，count[d]等于所有倍约数的ways之和。

在x的约数格上做反演：先复制ways[d]=count[d]，对x的每个不同质因子q，按约数d递增执行ways[d]−=ways[d*q]（仅d*q仍整除x时）。这相当于在该质因子的指数方向做相邻差分，各方向依次相消后得到精确gcd频次。约数必须递增，避免同一轮读到已差分的更高指数值。最后用快速幂算Σways[d]*d^k mod p。预处理十万内全部约数和最小质因子，避免每问扫描所有旧元素。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    constexpr int limit = 100000;
    vector<vector<int>> divisors(limit + 1);
    vector<int> smallest(limit + 1), count(limit + 1), position(limit + 1);
    for (int d = 1; d <= limit; d++)
        for (int x = d; x <= limit; x += d)
            divisors[x].push_back(d);
    for (int p = 2; p <= limit; p++)
        if (!smallest[p])
            for (int x = p; x <= limit; x += p)
                if (!smallest[x])
                    smallest[x] = p;
    auto power = [](long long a, int exponent, int mod) {
        long long result = 1 % mod;
        a %= mod;
        while (exponent) {
            if (exponent & 1)
                result = result * a % mod;
            a = a * a % mod;
            exponent >>= 1;
        }
        return result;
    };
    int n;
    cin >> n;
    while (n--) {
        int x, k, p;
        cin >> x >> k >> p;
        const auto &d = divisors[x];
        vector<int> ways(d.size());
        for (int i = 0; i < (int)d.size(); i++) {
            count[d[i]]++;
            ways[i] = count[d[i]];
            position[d[i]] = i;
        }
        int value = x;
        while (value > 1) {
            int prime = smallest[value];
            for (int i = 0; i < (int)d.size(); i++) {
                long long higher = 1LL * d[i] * prime;
                if (higher <= x && x % higher == 0)
                    ways[i] -= ways[position[higher]];
            }
            while (value % prime == 0)
                value /= prime;
        }
        long long answer = 0;
        for (int i = 0; i < (int)d.size(); i++)
            answer = (answer + ways[i] * power(d[i], k, p)) % p;
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

预处理上界 $U=10^5$，时间和空间 $O(U\log U)$；单次约数数 $D$、不同质因子数 $r$，时间 $O(D(r+\log k))$、临时空间 $O(D)$。

### 易错点

当前x先加入再查询，故包括gcd(x,x)=x。集合可重复，计数不能去重。模数p不保证素数，也无需对模数做除法。
