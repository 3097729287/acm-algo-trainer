## [USACO 2013 Dec G]Optimal Milking

### 题意

一排不选相邻机器，逐日单点修改，累加每天最大收益。

### 思路

每个区间保存2×2状态，索引为左端、右端是否选中，值为该限制下的最大独立集权和。合并两段时枚举相接的两个端点状态，禁止它们同时选中，其余取最大。叶子只有(0,0)=0、(1,1)=权值合法。点修改后沿树重算，根的四状态最大值为当日最优，累加到总答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, days;
    cin >> n >> days;
    const long long negative = LLONG_MIN / 4;
    struct Node {
        long long value[2][2];
        bool empty = true;
        Node() {
            for (auto &row : value)
                for (auto &x : row)
                    x = negative;
        }
    };
    auto leaf = [&](long long x) {
        Node node;
        node.empty = false;
        node.value[0][0] = 0;
        node.value[1][1] = x;
        return node;
    };
    auto merge = [&](const Node &a, const Node &b) {
        if (a.empty)
            return b;
        if (b.empty)
            return a;
        Node c;
        c.empty = false;
        for (int l = 0; l < 2; l++)
            for (int r = 0; r < 2; r++)
                for (int x = 0; x < 2; x++)
                    for (int y = 0; y < 2; y++)
                        if (!x || !y)
                            c.value[l][r] = max(c.value[l][r], a.value[l][x] + b.value[y][r]);
        return c;
    };
    int size = 1;
    while (size < n)
        size <<= 1;
    vector<Node> tree(2 * size);
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        tree[size + i] = leaf(x);
    }
    for (int u = size - 1; u; u--)
        tree[u] = merge(tree[u * 2], tree[u * 2 + 1]);
    long long total = 0;
    while (days--) {
        int p;
        long long x;
        cin >> p >> x;
        p += size - 1;
        tree[p] = leaf(x);
        for (p >>= 1; p; p >>= 1)
            tree[p] = merge(tree[p * 2], tree[p * 2 + 1]);
        long long best = 0;
        for (auto &row : tree[1].value)
            for (long long v : row)
                best = max(best, v);
        total += best;
    }
    cout << total;
    return 0;
}
```

### 复杂度

构建 $O(n)$，每天 $O(\log n)$，空间 $O(n)$。

### 易错点

每次更新在当天开始生效，累加更新后的根答案。空填充叶设empty，避免把无效负无穷与实际状态混合。
