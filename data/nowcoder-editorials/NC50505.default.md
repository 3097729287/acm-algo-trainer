## 二叉苹果树

### 题意

保留与根连通的指定数量树枝，最大化枝上苹果。

### 思路

dp[u][j]表示u子树中保留j条边、且保留部分连接u的最大苹果数。初始只留u，j=0值0。合并孩子v时可整棵不取；若取v方向的j条内部边，还必须加连接u、v的边，新增j+1条，贡献dp[v][j]+边权。用新数组按数量卷积，保证每个孩子只合并一次。最后取根的Q边状态。树是否恰好二叉不影响这一写法。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    q = min(q, n - 1);
    Tree tree(n);
    for (int i = 1; i < n; i++) {
        int a, b;
        long long w;
        cin >> a >> b >> w;
        tree.add(a - 1, b - 1, w);
    }
    tree.root(0);
    const long long neg = -(1LL << 60);
    vector<vector<long long>> dp(n);
    for (int index = n - 1; index >= 0; index--) {
        int u = tree.order[index];
        dp[u] = {0};
        for (auto [v, w] : tree.edge[u])
            if (v != tree.parent[u]) {
                int limit = min(q, (int)dp[u].size() + (int)dp[v].size() - 1);
                vector<long long> next(limit + 1, neg);
                for (int i = 0; i < (int)dp[u].size(); i++) {
                    next[i] = max(next[i], dp[u][i]);
                    for (int j = 0; j < (int)dp[v].size() && i + j + 1 <= limit; j++)
                        if (dp[u][i] != neg && dp[v][j] != neg)
                            next[i + j + 1] = max(next[i + j + 1], dp[u][i] + dp[v][j] + w);
                }
                dp[u].swap(next);
            }
    }
    cout << dp[0][q];
    return 0;
}
```

### 复杂度

保守时间 $O(nQ^2)$，按实际子树边数限制状态，空间 $O(nQ)$。

### 易错点

Q数的是边，不是点。取孩子的苹果必须先保留父子连接边，不能跨过剪掉的边去取远处高权边。
