## [NOIP2003]侦探推理

### 题意

恰有 N 人始终说谎，枚举谁有罪以及今天星期几，判断能否唯一确定罪犯。

### 思路

罪犯最多二十种，星期只有七种，可以全部枚举。固定这两项后，每句可识别证词的真假都确定了。同一个人的所有有效证词必须同真或同假，否则当前假设矛盾。设被确定说谎的人数为 liar，完全没有有效证词的人数为 unknown，只要 liar≤N≤liar+unknown，就能分配未知人的身份使假设成立。最后按罪犯身份去重：零人可能则 Impossible，一人则姓名，多人则 Cannot Determine。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, n, p;
    cin >> m >> n >> p;
    vector<string> names(m);
    map<string, int> index;
    for (int i = 0; i < m; i++) {
        cin >> names[i];
        index[names[i]] = i;
    }
    struct Statement {
        int speaker, kind, value;
    };
    vector<Statement> statements;
    vector<string> days = {"Monday", "Tuesday",  "Wednesday", "Thursday",
                           "Friday", "Saturday", "Sunday"};
    string line;
    getline(cin, line);
    for (int i = 0; i < p; i++) {
        getline(cin, line);
        auto colon = line.find(':');
        int speaker = index[line.substr(0, colon)];
        string message = line.substr(colon + 2);
        if (message == "I am guilty.")
            statements.push_back({speaker, 0, speaker});
        else if (message == "I am not guilty.")
            statements.push_back({speaker, 1, speaker});
        else {
            bool recognized = false;
            for (int d = 0; d < 7; d++)
                if (message == "Today is " + days[d] + ".") {
                    statements.push_back({speaker, 2, d});
                    recognized = true;
                    break;
                }
            if (recognized)
                continue;
            for (int who = 0; who < m; who++) {
                if (message == names[who] + " is guilty.") {
                    statements.push_back({speaker, 0, who});
                    break;
                }
                if (message == names[who] + " is not guilty.") {
                    statements.push_back({speaker, 1, who});
                    break;
                }
            }
        }
    }
    vector<int> possible;
    for (int guilty = 0; guilty < m; guilty++) {
        bool feasible = false;
        for (int day = 0; day < 7 && !feasible; day++) {
            vector<int> type(m, -1);
            bool valid = true;
            for (auto statement : statements) {
                bool truth = statement.kind == 2   ? day == statement.value
                             : statement.kind == 0 ? guilty == statement.value
                                                   : guilty != statement.value;
                int who = statement.speaker;
                if (type[who] != -1 && type[who] != truth) {
                    valid = false;
                    break;
                }
                type[who] = truth;
            }
            int liar = count(type.begin(), type.end(), 0),
                unknown = count(type.begin(), type.end(), -1);
            if (valid && liar <= n && n <= liar + unknown)
                feasible = true;
        }
        if (feasible)
            possible.push_back(guilty);
    }
    if (possible.empty())
        cout << "Impossible";
    else if (possible.size() > 1)
        cout << "Cannot Determine";
    else
        cout << names[possible[0]];
    return 0;
}
```

### 复杂度

枚举判断时间 $O(7M(P+M))$，识别证词预处理 $O(PM)$，空间 $O(P+M)$。

### 易错点

不符合五类格式的话完全忽略，不能当成假话。说谎者可以是罪犯也可以不是罪犯，没有额外约束。不同星期下同一罪犯只算一个候选。
