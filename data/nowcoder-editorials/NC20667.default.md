## 数学题

### 题意

求1到n中与n不互质的整数之和，模十亿加七，n至10^14。

### 思路

原图公式为 $\sum_{i=1}^n i[\gcd(i,n)\ne1]$。n>1时，互质数在i与n−i间配对，和为n*phi(n)/2；全部整数和n(n+1)/2，故答案为n*(n+1−phi(n))/2。n=1单独为0。分解n后按phi=n*Π(1−1/p)求欧拉函数，模意义下乘2的逆元500000004。

为了应对多组较大的素数或半素数，先用确定性64位Miller–Rabin判断素数，再用Pollard–Rho找非平凡因子。后者沿x²+c模n迭代，用Floyd快慢指针及gcd找出在某个质因子模数下先碰撞的位置；若只得到n则换参数重试。只影响分解耗时，不把随机结果直接当成正确因子。七个固定底数覆盖64位，乘法用128位取模。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using U64 = unsigned long long;
U64 multiplyMod(U64 a, U64 b, U64 mod) { return (unsigned __int128)a * b % mod; }
U64 powerMod(U64 a, U64 n, U64 mod) {
    U64 value = 1;
    while (n) {
        if (n & 1)
            value = multiplyMod(value, a, mod);
        a = multiplyMod(a, a, mod);
        n >>= 1;
    }
    return value;
}
bool isPrime(U64 n) {
    if (n < 2)
        return false;
    for (U64 p : {2ULL, 3ULL, 5ULL, 7ULL, 11ULL, 13ULL, 17ULL, 19ULL, 23ULL, 29ULL, 31ULL, 37ULL})
        if (n % p == 0)
            return n == p;
    U64 odd = n - 1;
    int twos = 0;
    while (!(odd & 1)) {
        odd >>= 1;
        twos++;
    }
    for (U64 base : {2ULL, 325ULL, 9375ULL, 28178ULL, 450775ULL, 9780504ULL, 1795265022ULL}) {
        if (base % n == 0)
            continue;
        U64 value = powerMod(base % n, odd, n);
        if (value == 1 || value == n - 1)
            continue;
        bool reachesMinusOne = false;
        for (int j = 1; j < twos; j++) {
            value = multiplyMod(value, value, n);
            if (value == n - 1) {
                reachesMinusOne = true;
                break;
            }
        }
        if (!reachesMinusOne)
            return false;
    }
    return true;
}
U64 rho(U64 n) {
    if (n % 2 == 0)
        return 2;
    if (n % 3 == 0)
        return 3;
    static mt19937_64 random(20261108);
    for (;;) {
        U64 constant = random() % (n - 1) + 1, x = random() % (n - 2) + 2, y = x, divisor = 1;
        auto step = [&](U64 value) {
            return (U64)(((unsigned __int128)multiplyMod(value, value, n) + constant) % n);
        };
        while (divisor == 1) {
            x = step(x);
            y = step(step(y));
            divisor = gcd(x > y ? x - y : y - x, n);
        }
        if (divisor != n)
            return divisor;
    }
}
void factor(U64 n, vector<U64> &factors) {
    if (n == 1)
        return;
    if (isPrime(n)) {
        factors.push_back(n);
        return;
    }
    U64 d = rho(n);
    factor(d, factors);
    factor(n / d, factors);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    U64 n;
    constexpr U64 mod = 1000000007;
    while (cin >> n) {
        if (n == 1) {
            cout << "0\n";
            continue;
        }
        vector<U64> factors;
        factor(n, factors);
        sort(factors.begin(), factors.end());
        factors.erase(unique(factors.begin(), factors.end()), factors.end());
        U64 phi = n;
        for (U64 p : factors)
            phi = phi / p * (p - 1);
        U64 value = n % mod * ((n + 1 - phi) % mod) % mod;
        cout << value * 500000004ULL % mod << '\n';
    }
    return 0;
}
```

### 复杂度

Miller–Rabin每次 $O(\log n)$ 次模乘；Rho寻找最小质因子 $p$ 的期望迭代约 $O(\sqrt p)$，即常用 $O(n^{1/4})$ 分解估计，随机重试无确定最坏界。空间 $O(\log n)$。

### 易错点

n本身与n不互质（n>1），要包含在和中。不要在取模后用普通整数除二；使用2的模逆元。
