## 石子合并

### 题意

线性排列的相邻沙堆依次合并，求最小总代价。

### 思路

dp[l][r]为把连续区间[l,r]合成一堆的最小代价。最后一定由[l,k]、[k+1,r]两堆合并，故枚举k，并加上区间总重量。长度1代价0，其余从短到长计算；前缀和常数时间求最后合并费用。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> prefix(n + 1);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
    }
    vector<vector<long long>> dp(n, vector<long long>(n));
    for (int length = 2; length <= n; length++)
        for (int l = 0; l + length <= n; l++) {
            int r = l + length - 1;
            dp[l][r] = 1LL << 60;
            for (int k = l; k < r; k++)
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r] + prefix[r + 1] - prefix[l]);
        }
    cout << dp[0][n - 1];
    return 0;
}
```

### 复杂度

时间 $O(n^3)$，空间 $O(n^2)$。

### 易错点

这里是一排，不能复制成环后另选起点。只有两子区间合并完成后，才加一次整个区间总重。
