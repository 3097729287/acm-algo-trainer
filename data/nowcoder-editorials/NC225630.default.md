## 智乃酱的子集与超集

### 题意

给集合U，求全部子集的异或价值和及全部超集的异或价值和。

### 思路

对子集按位统计：若U中该位至少有一个1，所有2^k个子集中恰一半异或为1。因此子集答案是OR(U)*2^(k−1)，空集答案0。

超集等于固定U再任选补集V。设free=|V|、X=XOR(U)、B=OR(V)。B中为1的位有一半超集为1，贡献B*2^(free−1)；B中为0而X为1的位在全部超集中为1，贡献(X & ~B)*2^free。free=0时唯一超集是U，单独输出X。预处理每个掩码的OR，查询读编号后得到mask及X。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    int size = 1 << n;
    vector<int> bitOr(size);
    for (int mask = 1; mask < size; mask++) {
        int bit = __builtin_ctz((unsigned)mask);
        bitOr[mask] = bitOr[mask & (mask - 1)] | a[bit];
    }
    while (m--) {
        int k, mask = 0, xorValue = 0;
        cin >> k;
        for (int i = 0; i < k; i++) {
            int p;
            cin >> p;
            p--;
            mask |= 1 << p;
            xorValue ^= a[p];
        }
        long long subset = k ? (long long)bitOr[mask] * (1LL << (k - 1)) : 0;
        int free = n - k, b = bitOr[(size - 1) ^ mask];
        long long superset =
            free ? (long long)b * (1LL << (free - 1)) + (long long)(xorValue & ~b) * (1LL << free)
                 : xorValue;
        cout << subset << ' ' << superset << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(2^n)$，每问 $O(k)$，空间 $O(2^n+n)$。

### 易错点

集合含元素自身和空子集，超集含U自身。补集某位有可选1时才有“一半为1”，不能把固定U的异或值直接乘超集数。
