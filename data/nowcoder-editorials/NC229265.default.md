## Birthday Cake

### 题意

巧克力方格中统计同一行或同一列的无序对。

### 思路

某行有c个巧克力，可选C(c,2)=c(c−1)/2对，列同理。两个不同方格不可能既同一行又同一列，所以行、列贡献可直接相加。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> row(n), column(n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) {
            char c;
            cin >> c;
            if (c == 'C') {
                row[i]++;
                column[j]++;
            }
        }
    long long answer = 0;
    for (int c : row)
        answer += 1LL * c * (c - 1) / 2;
    for (int c : column)
        answer += 1LL * c * (c - 1) / 2;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

只选含巧克力的两格，无序对需要除2。
