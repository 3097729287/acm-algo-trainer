## Meeting

### 题意

每个地点集合内任意两点间走一次耗时t，两人从1、n出发，求最早在哪些地点会合。

### 思路

每个集合建虚拟点，成员地点→虚拟点权t，虚拟点→成员地点权0。这样集合内任意两点费用恰为t，且只需O(集合大小)条边，不会两两连成平方边数。分别从1和n做Dijkstra。若选择地点v会合，两人同时出发并允许等待，时间为max(d1[v],dn[v])，在所有原地点中取最小并输出全部最优地点。虚拟点只是建图辅助，不是可会合的地点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<long long> dijkstra(const vector<vector<pair<int, long long>>> &graph, int source) {
    const long long inf = 1LL << 60;
    vector<long long> distance(graph.size(), inf);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                   greater<pair<long long, int>>>
        heap;
    distance[source] = 0;
    heap.push({0, source});
    while (!heap.empty()) {
        auto [cost, u] = heap.top();
        heap.pop();
        if (cost != distance[u])
            continue;
        for (auto [v, w] : graph[u])
            if (distance[v] > cost + w) {
                distance[v] = cost + w;
                heap.push({distance[v], v});
            }
    }
    return distance;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    for (int tc = 1; tc <= tests; tc++) {
        int n, m;
        cin >> n >> m;
        vector<vector<pair<int, long long>>> graph(n + m);
        for (int i = 0; i < m; i++) {
            long long time;
            int size;
            cin >> time >> size;
            while (size--) {
                int u;
                cin >> u;
                --u;
                graph[u].push_back({n + i, time});
                graph[n + i].push_back({u, 0});
            }
        }
        auto a = dijkstra(graph, 0), b = dijkstra(graph, n - 1);
        long long best = 1LL << 60;
        for (int u = 0; u < n; u++)
            best = min(best, max(a[u], b[u]));
        cout << "Case #" << tc << ": ";
        if (best == (1LL << 60)) {
            cout << "Evil John\n";
            continue;
        }
        cout << best << '\n';
        bool first = true;
        for (int u = 0; u < n; u++)
            if (max(a[u], b[u]) == best) {
                if (!first)
                    cout << ' ';
                first = false;
                cout << u + 1;
            }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

总集合元素数 $L$，时间 $O((n+m+L)\log(n+m))$，空间 $O(n+m+L)$。

### 易错点

不能把两人距离相加再除二，题目只能在原地点会合。实际输出带Case #编号，依原样例格式。
