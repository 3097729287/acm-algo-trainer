## Running Median

### 题意

每读入奇数个数，就输出当前中位数，答案每行至多十个。

### 思路

用大根堆存较小的一半，小根堆存较大的一半。插入时先按大根堆顶分边，再调整到左堆个数等于右堆或多一。保持左堆所有数不大于右堆所有数后，奇数时左堆堆顶就是中位数。每组先输出原数据编号与答案个数，随后按十个一行输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int id, n;
        cin >> id >> n;
        priority_queue<int> left;
        priority_queue<int, vector<int>, greater<int>> right;
        vector<int> answer;
        for (int i = 0; i < n; i++) {
            int x;
            cin >> x;
            if (left.empty() || x <= left.top())
                left.push(x);
            else
                right.push(x);
            if (left.size() > right.size() + 1) {
                right.push(left.top());
                left.pop();
            }
            if (left.size() < right.size()) {
                left.push(right.top());
                right.pop();
            }
            if (i % 2 == 0)
                answer.push_back(left.top());
        }
        cout << id << ' ' << answer.size() << '\n';
        for (int i = 0; i < (int)answer.size(); i++) {
            cout << answer[i];
            cout << ((i % 10 == 9 || i + 1 == (int)answer.size()) ? '\n' : ' ');
        }
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

比较原整数，不把两个堆顶相加，避免32位有符号整数溢出。本题只在奇数长度时输出，无需求偶数中位数。
