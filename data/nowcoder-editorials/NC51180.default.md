## Accumulation Degree

### 题意

每边有容量，节点向其他原始叶子能送出的总流量取最大，求最优源点。

### 思路

树上不同分支在离开当前点后互不共享边，因此分支流量相加。以任意根求down[u]：通向孩子v的贡献若v是原始叶子，就等于边容量；否则为min(边容量,down[v])，对子节点相加。

换根时，令up[u]为u经父边去父侧终端的可送流量，total[u]=down[u]+up[u]。给孩子v传父侧流量，要从total[u]减去v分支贡献，再与父子边容量取小。例外是u本身原度为1，此时它就是v方向的一个终端，可直接接收全部边容量，不能用删去v后的空和0。遍历所有u的total取最大，源点自身即使是叶子也不接收自己的流。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        Tree tree(n);
        for (int i = 1; i < n; i++) {
            int a, b;
            long long w;
            cin >> a >> b >> w;
            tree.add(a - 1, b - 1, w);
        }
        tree.root(0);
        vector<long long> down(n), up(n);
        for (int i = n - 1; i >= 0; i--) {
            int u = tree.order[i];
            for (auto [v, w] : tree.edge[u])
                if (v != tree.parent[u])
                    down[u] += tree.edge[v].size() == 1 ? w : min(w, down[v]);
        }
        long long answer = 0;
        for (int u : tree.order) {
            long long total = down[u] + up[u];
            answer = max(answer, total);
            for (auto [v, w] : tree.edge[u])
                if (v != tree.parent[u]) {
                    long long contribution = tree.edge[v].size() == 1 ? w : min(w, down[v]);
                    up[v] = tree.edge[u].size() == 1 ? w : min(w, total - contribution);
                }
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n)$。

### 易错点

叶子身份由原树度数决定，不随计算根变化。两点树两端都为终端，答案为唯一边容量；单点没有其他终端，答案0。
