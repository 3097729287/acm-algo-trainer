## Area

### 题意

由格点多边形每一步位移，求内部格点、边界格点与面积。

### 思路

从原点依次累加位移，还原顶点。鞋带公式给出二倍面积$S_2=\sum cross(P_i,P_{i+1})$。一条位移$(dx,dy)$的格点边对边界贡献$\gcd(|dx|,|dy|)$，这样每个顶点恰计一次，得边界数$B$。Pick定理$S=I+B/2-1$，所以$I=(S_2-B+2)/2$。全部先用整数计算，最后只按二倍面积奇偶输出.0或.5。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    for (int t = 1; t <= tests; t++) {
        int n;
        cin >> n;
        long long x = 0, y = 0, twice = 0, boundary = 0;
        for (int i = 0; i < n; i++) {
            long long dx, dy;
            cin >> dx >> dy;
            twice += x * dy - y * dx;
            boundary += gcd(abs(dx), abs(dy));
            x += dx;
            y += dy;
        }
        twice = abs(twice);
        cout << "Scenario #" << t << ":\n"
             << (twice - boundary + 2) / 2 << ' ' << boundary << ' ' << twice / 2
             << (twice % 2 ? ".5" : ".0") << "\n\n";
    }
    return 0;
}
```

### 复杂度

时间 $O(n\log C)$，空间 $O(1)$。

### 易错点

边界点数不是各边格点数gcd+1之和，否则每个顶点被重复计算。每组答案后有空行。
