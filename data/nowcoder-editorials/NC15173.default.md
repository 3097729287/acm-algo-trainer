## 大水题

### 题意

不断将整数替换成其各位数字之和，直到只剩一位。

### 思路

只要 n≥十，就用一个临时变量逐位求和，并把结果作为下一轮的 n。每轮结束后数值明显缩小，给定范围内很快会成为个位数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    while (n >= 10) {
        long long next = 0;
        while (n) {
            next += n % 10;
            n /= 10;
        }
        n = next;
    }
    cout << n;
    return 0;
}
```

### 复杂度

各轮处理的总数位量为 $O(\log n)$，额外空间 $O(1)$。

### 易错点

不是只求一次数位和，例如三十八第一次变十一，还要继续变二。
