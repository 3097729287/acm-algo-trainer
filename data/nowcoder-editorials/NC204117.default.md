## 牛牛的三角形

### 题意

从数组中选三个不同位置的正数，组成任意一个非退化三角形。

### 思路

排序后只需检查相邻三项。若某三个数 x≤y≤z 能成三角形，选定 z 前面最大的两个数也不会更小，因此同样满足两短边之和大于长边。于是只要存在答案，某一组相邻三项一定是答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    for (int i = 2; i < n; i++)
        if (a[i - 2] + a[i - 1] > a[i]) {
            cout << a[i - 2] << ' ' << a[i - 1] << ' ' << a[i];
            return 0;
        }
    cout << "No solution";
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，数组空间 $O(n)$。

### 易错点

等号只能组成退化线段，不算三角形。同值元素可来自不同位置，不能去重。原题允许任意合法答案，验证按元素重数与三角不等式进行。
