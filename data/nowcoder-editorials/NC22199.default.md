## 数位之和

### 题意

取整数绝对值后，计算各十进制数位之和。

### 思路

先把 n 变为非负，再反复取 n%10 加入答案，随后整除十移去最低位。输入为零时循环不执行，答案正好为零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    n = abs(n);
    int ans = 0;
    while (n) {
        ans += n % 10;
        n /= 10;
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(\log(|n|+1))$，额外空间 $O(1)$。

### 易错点

负号不是数位，不计入总和。
