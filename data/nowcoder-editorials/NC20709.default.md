## Balls

### 题意

黑白各1球，每次随机取球后同色净增1，求白球期望。

### 思路

过程在交换黑白颜色后完全对称，所以两色期望相同。每次总球数净增1，n次后总数确定为n+2；两色期望之和也是n+2，故白球期望为(n+2)/2。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    cout << fixed << setprecision(7) << (n + 2) / 2.0L;
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

取出的球被两个同色球替换，净增1，不是净增2。
