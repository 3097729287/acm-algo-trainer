## (Zero XOR Subset)-less

### 题意

分成最多段，要求各段异或值线性无关。

### 思路

任意非空段集合异或都非0，等价于段异或向量线性无关。若总异或为0，选全部段就违反，直接−1。否则令前缀异或P[i]，段向量依次为P[t1]、P[t1]xorP[t2]、...，这是可逆三角变换，所以段向量的秩等于所选分界前缀向量的秩。

全部前缀向量的秩r是上界。总前缀P[n]非0，在线性空间中它可以扩展为从所有前缀中选取的一组r个基向量；按下标排序后把n作为最后边界，便得到r个合法段。故答案为全部前缀异或的线性基秩。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    unsigned prefix = 0;
    array<unsigned, 31> basis = {};
    int rank = 0;
    while (n--) {
        unsigned x;
        cin >> x;
        prefix ^= x;
        x = prefix;
        for (int b = 30; b >= 0 && x; b--)
            if (x >> b & 1U) {
                if (basis[b])
                    x ^= basis[b];
                else {
                    basis[b] = x;
                    rank++;
                    break;
                }
            }
    }
    cout << (!prefix ? -1 : rank);
    return 0;
}
```

### 复杂度

时间 $O(31n)$，空间 $O(31)$。

### 易错点

插入的是每个前缀异或，不是原元素。总异或为0时，即使秩非0也无解。
