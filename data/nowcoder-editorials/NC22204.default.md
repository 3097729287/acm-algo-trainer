## 上下金字塔

### 题意

读入多组 n，输出上半高 n、总高 2n-1 的实心菱形。

### 思路

从行号零到 2n-2 枚举。该行距离中间行的距离 d=|i-(n-1)|，行首有 d 个空格，随后有 2(n-d)-1 个星号。多组数据连续输出，无额外空行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        for (int i = 0; i < 2 * n - 1; i++) {
            int d = abs(i - (n - 1));
            cout << string(d, ' ') << string(2 * (n - d) - 1, '*') << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每组输出 $O(n^2)$ 个字符，使用 $O(n)$ 临时字符串空间。

### 易错点

本题输入没有组数 T，循环读到文件结束。
