## Strategic game

### 题意

在树上选最少点，每条边至少一个端点有士兵。

### 思路

这是覆盖边的最小顶点覆盖。dp[u][0/1]表示u不选或选的最小数：u不选时每个孩子必须选，u选时孩子任选较少的状态。结点编号从0开始，输入每条边只出现一次，先建无向树再任取根处理。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        Tree tree(n);
        for (int i = 0; i < n; i++) {
            int u, k;
            char colon, open, close;
            cin >> u >> colon >> open >> k >> close;
            while (k--) {
                int v;
                cin >> v;
                tree.add(u, v);
            }
        }
        tree.root(0);
        vector<array<int, 2>> dp(n);
        for (int i = n - 1; i >= 0; i--) {
            int u = tree.order[i];
            dp[u][1] = 1;
            for (auto [v, w] : tree.edge[u])
                if (v != tree.parent[u]) {
                    dp[u][0] += dp[v][1];
                    dp[u][1] += min(dp[v][0], dp[v][1]);
                }
        }
        cout << min(dp[0][0], dp[0][1]) << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n)$。

### 易错点

题目覆盖全部边，孤立单点无需士兵。输入含冒号与括号，可逐字符读取，结点描述顺序不保证根先出现。
