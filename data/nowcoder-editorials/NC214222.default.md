## 疫情死亡率

### 题意

用死亡人数除以确诊人数，按百分数输出死亡率。

### 思路

百分数的数值是 d/c 的一百倍。先把一项转成浮点数再除，保留三位小数并在末尾输出百分号，满足题面的误差要求。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    double c, d;
    cin >> c >> d;
    cout << fixed << setprecision(3) << d * 100.0 / c << '%';
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

分母是确诊人数；整数相除会先截断，不能写成两个 int 直接相除。
