## 小小粉刷匠

### 题意

一次只能刷长度至多k的连续段，可覆盖，求得到目标颜色的最少次数。

### 思路

先求每个长度不超过k的区间的普通“覆盖涂色”最优次数paint[l][r]：可单独刷l后处理其余；也可把l与后面同色位置p放在同一笔中，代价paint[l+1][p−1]+paint[p][r]。因为整个区间长度≤k，其中任何一笔都不会超长。

为什么还可把整面墙分段？两笔若交叉为[a,c]、[b,d]且a<b≤c<d，较早那笔在重叠处已经被较晚那笔覆盖，可删掉这一端的无效部分，笔画长度只会缩短。不断消除交叉后，各笔区间呈包含或互不相交；最外层笔画将整墙划成互不相交的若干段，每段长度都≤k。段内用paint最优地刷，便不会比原方案更差。于是前缀DP best[i]=min(best[l]+paint[l][i−1])，枚举i−l≤k。反之任一这样的分段刷法也合法，故两边等价。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    while (cin >> n >> k) {
        vector<int> color(n);
        for (int &x : color)
            cin >> x;
        k = min(k, n);
        vector<vector<int>> paint(n, vector<int>(n));
        for (int l = n - 1; l >= 0; l--) {
            paint[l][l] = 1;
            for (int r = l + 1; r < n && r - l + 1 <= k; r++) {
                paint[l][r] = 1 + paint[l + 1][r];
                for (int p = l + 1; p <= r; p++)
                    if (color[p] == color[l])
                        paint[l][r] =
                            min(paint[l][r], (p == l + 1 ? 0 : paint[l + 1][p - 1]) + paint[p][r]);
            }
        }
        vector<int> best(n + 1, n + 1);
        best[0] = 0;
        for (int i = 1; i <= n; i++)
            for (int l = max(0, i - k); l < i; l++)
                best[i] = min(best[i], best[l] + paint[l][i - 1]);
        cout << best[n] << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(nk^2)$，空间 $O(n^2)$。

### 易错点

不能直接把无限长刷子的区间转移加一个“同色点距离≤k”条件，因为被合并的那笔还可能向右延伸，导致总跨度超长。先分成长度合法的最外层段再求段内覆盖。
