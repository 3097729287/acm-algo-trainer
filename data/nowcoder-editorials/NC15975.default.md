## 小C的记事本

### 题意

支持末尾插入、删除、第 k 字符查询与撤销最近一次修改。

### 思路

把每个字符结点连向前一个字符，当前文本只用末尾结点 root 表示。插入创建新结点，删除 k 个字符就是沿祖先退 k 步；撤销只需恢复修改前保存的 root，旧结点从不覆盖。第 k 个字符位于从末尾向前 length-k 步。用二进制倍增祖先表，让删除和查询都只走 O(log L) 次。历史栈只记录插入、删除之前的 root，查询与撤销不新增历史。

这种表示会共享不同版本的前缀，反复删除、撤销长文本也只切换结点编号，不复制整段内容。累计新建字符不超过输入 append 字符总量一百万；预留二十级祖先表约八十兆字节，连同其他数组在本题一百二十八兆限制内。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    while (cin >> q) {
        const int log = 20;
        vector<array<int, log>> up(1);
        vector<int> depth(1, 0), history;
        vector<char> letter(1, 0);
        up[0].fill(0);
        up.reserve(1000001);
        depth.reserve(1000001);
        letter.reserve(1000001);
        history.reserve(q);
        int root = 0;
        auto ancestor = [&](int node, int steps) {
            for (int bit = 0; bit < log; bit++)
                if (steps >> bit & 1)
                    node = up[node][bit];
            return node;
        };
        while (q--) {
            int type;
            cin >> type;
            if (type == 1) {
                string text;
                cin >> text;
                history.push_back(root);
                for (char c : text) {
                    array<int, log> row{};
                    row[0] = root;
                    for (int bit = 1; bit < log; bit++)
                        row[bit] = up[row[bit - 1]][bit - 1];
                    up.push_back(row);
                    letter.push_back(c);
                    depth.push_back(depth[root] + 1);
                    root = (int)letter.size() - 1;
                }
            } else if (type == 2) {
                int k;
                cin >> k;
                history.push_back(root);
                root = ancestor(root, k);
            } else if (type == 3) {
                int k;
                cin >> k;
                cout << letter[ancestor(root, depth[root] - k)] << '\n';
            } else {
                root = history.back();
                history.pop_back();
            }
        }
    }
    return 0;
}
```

### 复杂度

累计插入 $L$ 个字符、$q$ 个操作，时间 $O((L+q)\log L)$，空间 $O(L\log L+q)$。

### 易错点

样例允许删成空串，零号结点代表空文本。预留容量避免大祖先表扩容时同时占用新旧内存。撤销后再插入会分出新版本，不能重写旧结点。
