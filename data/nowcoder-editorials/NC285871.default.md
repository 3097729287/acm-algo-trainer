## 点名：hard

### 题意

已知全班字符串学号，删去到场者，按字典序输出两位缺席者。

### 思路

用有序集合保存全部学号，读到一个到场学号就删除。剩下的元素就是缺席者，集合遍历天然按字典序排列。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    set<string> absent;
    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;
        absent.insert(s);
    }
    for (int i = 0; i < n - 2; i++) {
        string s;
        cin >> s;
        absent.erase(s);
    }
    for (const auto &s : absent)
        cout << s << '\n';
    return 0;
}
```

### 复杂度

学号最大长度 $L=20$，时间 $O(nL\log n)$，空间 $O(nL)$。

### 易错点

学号含大小写字母和数字，需要保存字符串并按完整字符串字典序比较；不能转为整数。
