## [HAOI2008]木棍分割

### 题意

最多m刀分木棍，最小最长段长度并统计全部最优切法。

### 思路

先二分最大段长X，贪心从左向右尽量装满一段，所得段数最少；若≤m+1则可行。求得最优X后计数：dp[k][i]为前i根分成恰k个非空段且段长都≤X的方案数，转移Σdp[k−1][j]，其中prefix[i]−prefix[j]≤X、j<i。

长度正数使合法j形成移动窗口，维护上一行DP窗口和，每层O(n)。答案是k=1..m+1的dp[k][n]之和，因为允许最多m刀，最优切法不一定刀数相同。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> prefix(n + 1);
    long long low = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
        low = max(low, (long long)x);
    }
    long long high = prefix[n];
    auto feasible = [&](long long limit) {
        int groups = 1;
        long long sum = 0;
        for (int i = 1; i <= n; i++) {
            long long x = prefix[i] - prefix[i - 1];
            if (sum + x > limit) {
                groups++;
                sum = 0;
            }
            sum += x;
        }
        return groups <= m + 1;
    };
    while (low < high) {
        long long mid = (low + high) / 2;
        if (feasible(mid))
            high = mid;
        else
            low = mid + 1;
    }
    const int mod = 10007;
    vector<int> previous(n + 1), current(n + 1);
    previous[0] = 1;
    int answer = 0;
    for (int groups = 1; groups <= m + 1; groups++) {
        fill(current.begin(), current.end(), 0);
        int left = 0, sum = 0;
        for (int i = 1; i <= n; i++) {
            sum = (sum + previous[i - 1]) % mod;
            while (prefix[i] - prefix[left] > low) {
                sum = (sum - previous[left] + mod) % mod;
                left++;
            }
            current[i] = sum;
        }
        answer = (answer + current[n]) % mod;
        previous.swap(current);
    }
    cout << low << ' ' << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log(\sum L)+nm)$，空间 $O(n)$。

### 易错点

不能只统计恰好m刀；样例最优长度10既有一刀也有两刀，共2种。
