## 1408

### 题意

两种颜色各含1到n的球，最少相邻交换让各自编号递增。

### 思路

合法结果是白球递增序列和黑球递增序列的任意交错。构造最终顺序，每次只能选下一白球或下一黑球。将它从原序列尚未取出的部分移到最前，需要交换的次数就是它前面剩余球数；逐次这样抽取恰好计算该最终顺序相对原序列的逆序数。

dp[i][j]为取走前i个白球、前j个黑球的最小代价。白i的同色贡献固定为“原来在它前面且编号更大的白球数”，异色贡献为前面编号大于j的黑球数。黑球同理。外层递增i时，维护每个黑球前仍未取的球数；内层递增j时滚动扣除已取黑球对白i的贡献。于是每个状态常数时间，dp只保留一行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> white(n + 1), black(n + 1);
    for (int p = 0; p < 2 * n; p++) {
        char color;
        int label;
        cin >> color >> label;
        (color == 'W' ? white : black)[label] = p;
    }
    vector<int> fixedWhite(n + 1), blackCost(n + 1);
    for (int i = 1; i <= n; i++) {
        for (int j = i + 1; j <= n; j++) {
            fixedWhite[i] += white[j] < white[i];
            blackCost[i] += black[j] < black[i];
        }
        for (int j = 1; j <= n; j++)
            blackCost[i] += white[j] < black[i];
    }
    vector<long long> dp(n + 1);
    for (int j = 1; j <= n; j++)
        dp[j] = dp[j - 1] + blackCost[j];
    for (int i = 1; i <= n; i++) {
        int whiteCost = fixedWhite[i];
        for (int j = 1; j <= n; j++) {
            whiteCost += black[j] < white[i];
            if (white[i] < black[j])
                blackCost[j]--;
        }
        long long old = dp[0];
        dp[0] = old + whiteCost;
        for (int j = 1; j <= n; j++) {
            whiteCost -= black[j] < white[i];
            old = dp[j];
            dp[j] = min(old + whiteCost, dp[j - 1] + blackCost[j]);
        }
    }
    cout << dp[n];
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

同色编号顺序固定，只有两色之间的交错可选。向右更新时dp[j]仍是上一行，dp[j−1]已经是当前行。
