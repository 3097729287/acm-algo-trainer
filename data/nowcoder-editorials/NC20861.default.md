## 兔子的逆序对

### 题意

不断反转排列区间，只输出每次后的逆序数奇偶性。

### 思路

排列的逆序奇偶性等于把它变成恒等排列所需交换次数的奇偶性。一个长度 s 的置换环要 s-1 次交换，因此初始奇偶为 (n-置换环数)%2，可在线性时间得到。反转长度 len 的区间恰是 floor(len/2) 次两端交换，每次翻转奇偶，故仅需异或 (len/2)%2。无需真的反转数组或重算逆序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

class FastInput {
    static const int size = 1 << 16;
    char buffer[size];
    int position = 0, available = 0;
    int get() {
        if (position == available) {
            available = fread(buffer, 1, size, stdin);
            position = 0;
            if (!available)
                return EOF;
        }
        return buffer[position++];
    }

  public:
    int next() {
        int c = get(), sign = 1;
        while (c != '-' && (c < '0' || c > '9'))
            c = get();
        if (c == '-') {
            sign = -1;
            c = get();
        }
        long long x = 0;
        while (c >= '0' && c <= '9') {
            x = x * 10 + c - '0';
            c = get();
        }
        return (int)(x * sign);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    FastInput input;
    int n = input.next();
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++)
        a[i] = input.next();
    vector<bool> visited(n + 1);
    int cycles = 0;
    for (int i = 1; i <= n; i++)
        if (!visited[i]) {
            cycles++;
            for (int j = i; !visited[j]; j = a[j])
                visited[j] = true;
        }
    int parity = (n - cycles) % 2, m = input.next();
    string output;
    output.reserve((size_t)m * 8);
    while (m--) {
        int l = input.next(), r = input.next();
        parity ^= ((r - l + 1) / 2) % 2;
        output += parity ? "dislike\n" : "like\n";
    }
    cout << output;
    return 0;
}
```

### 复杂度

时间 $O(n+m)$，空间 $O(n+m)$（含批量输出缓冲）。

### 易错点

奇数逆序输出 dislike，偶数输出 like。利用环计数的前提是输入确为一到 n 的排列。
