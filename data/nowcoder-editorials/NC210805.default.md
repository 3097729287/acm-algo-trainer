## 涂色

### 题意

分割数组，每段代价为不同数字数的平方，最小总代价。

### 思路

dp[i]是前i项最小代价，且dp随i不减：任意前i项方案删掉末项后仍是前i−1项可行方案，代价不会增加。固定右端i，若最后一段允许至多k种数，最佳左端应尽量早，因为此前dp更小。

按各数最近一次出现位置从新到旧排列。第k+1新的出现位置p之后，至i恰好只含最近k种数，因此候选为dp[p]+k²；若不足k+1种则p=0。维护一个最近使用链表，每次把当前数移到表头，即可依次得到所有p。

逐个枚举k，若k²已经不小于当前答案就停止；总答案≤i（每个元素单独一段），所以只需O(sqrt n)个k，不会因相同数字连续出现而回扫很长区间。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n), coordinate;
    for (int &x : a)
        cin >> x;
    coordinate = a;
    sort(coordinate.begin(), coordinate.end());
    coordinate.erase(unique(coordinate.begin(), coordinate.end()), coordinate.end());
    list<int> recent;
    vector<list<int>::iterator> where(coordinate.size());
    vector<bool> present(coordinate.size());
    vector<int> dp(n + 1);
    for (int i = 1; i <= n; i++) {
        int id = lower_bound(coordinate.begin(), coordinate.end(), a[i - 1]) - coordinate.begin();
        if (present[id])
            recent.erase(where[id]);
        recent.push_front(i);
        where[id] = recent.begin();
        present[id] = true;
        dp[i] = dp[i - 1] + 1;
        auto it = recent.begin();
        for (int k = 1; it != recent.end() && k * k < dp[i]; k++) {
            it++;
            int previous = it == recent.end() ? 0 : *it;
            dp[i] = min(dp[i], dp[previous] + k * k);
        }
    }
    cout << dp[n];
    return 0;
}
```

### 复杂度

时间 $O(n\log n+n\sqrt n)$，空间 $O(n)$。

### 易错点

直接向左扫描直到sqrt n种数，在全相同数组上仍会退化平方时间；这里遍历的是不同数的最近位置链表。
