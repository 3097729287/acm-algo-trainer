## 整数的十位

### 题意

求非负整数的十位数字，不足两位时输出零。

### 思路

先整除十去掉个位，此时原来的十位移到个位，再对十取余。只有一位的数整除十自然得到零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a;
    cin >> a;
    cout << a / 10 % 10;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

只整除十会保留百位及更高数位，仍需取余。
