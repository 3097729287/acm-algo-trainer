## 标题统计

> 原题：[P5015](https://www.luogu.com.cn/problem/P5015)
> 解法：整行读取并跳过空白 · C++17

### 题意

标题由字母、数字和空格组成，统计其中非空格字符的个数。



### 思路

用 getline 读完整标题，逐字符检查，不是空格就计数。

标题长为 L，时间 $O(L)$、空间 $O(L)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    getline(cin, s);
    int count = 0;
    for (char c : s)
        if (c != ' ')
            ++count;
    cout << count << '\n';
    return 0;
}
```

### 易错点

不能用字符串长度直接作为答案，也不能只读第一个词。
