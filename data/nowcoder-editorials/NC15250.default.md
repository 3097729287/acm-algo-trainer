## 白兔的分身术

### 题意

在 p 的 k 次方等于 n 的正整数方案中，最大化 p+k。

### 思路

直接取 p=n、k=1，可得 n+1。任何可行方案都有 p≥2，且 p^k≥p+k-1：k=1 时相等，每增加一轮，幂值至少增加一。因此 p+k≤n+1，这个构造达到上界。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    cout << n + 1;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不必分解十的十八次方，也不能用浮点开根查找完全幂。
