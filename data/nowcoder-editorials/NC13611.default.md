## 树

### 题意

k色染树，要求每种已用颜色的节点构成连通块。

### 思路

合法方案中，每条异色边切开后得到若干单色连通块；同一种颜色不能出现在两个块，否则路径中出现别色。若有c块，则恰切c−1条树边，可任意选择C(n−1,c−1)种。给c个有区别的块分配不同颜色有k*(k−1)*...*(k−c+1)种。累加c=1..min(n,k)即可，树形不影响计数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
    }
    const long long mod = 1000000007;
    vector<long long> choose(n);
    choose[0] = 1;
    for (int i = 1; i < n; i++)
        for (int j = i; j >= 1; j--)
            choose[j] = (choose[j] + choose[j - 1]) % mod;
    long long falling = 1, answer = 0;
    for (int c = 1; c <= min(n, k); c++) {
        falling = falling * (k - c + 1) % mod;
        answer = (answer + choose[c - 1] * falling) % mod;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

颜色有区别，块之间颜色必须互不相同；不能只乘k^c。边仍须全部读入。
