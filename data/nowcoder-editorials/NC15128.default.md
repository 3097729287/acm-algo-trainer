## 老子的全排列呢

### 题意

按字典序输出一到八的全部排列，每行末尾没有空格。

### 思路

从递增排列开始，每次输出当前排列，再用 next_permutation 转到下一个字典序排列。该函数在没有下一个排列时返回 false，因此 do-while 正好输出首项到末项各一次，共 40320 行。原站样例中的英文是占位说明，不能作为真正输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    vector<int> a(8);
    iota(a.begin(), a.end(), 1);
    do {
        for (int i = 0; i < 8; i++) {
            if (i)
                cout << ' ';
            cout << a[i];
        }
        cout << '\n';
    } while (next_permutation(a.begin(), a.end()));
    return 0;
}
```

### 复杂度

一般 $n$ 个元素的全排列输出时间 $O(n·n!)$，数组空间 $O(n)$；这里 $n=8$。

### 易错点

必须从递增排列开始，才能覆盖所有排列。输出最后一项之后再调用一次只用于结束循环，不再输出重置的排列。
