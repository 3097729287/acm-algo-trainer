## 多组输入a+b II

### 题意

先读组数 T，再处理 T 对整数的加法。

### 思路

第一项是组数，不参与求和。循环 T 次，每次读取 a、b，并独立输出 a+b。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int a, b;
        cin >> a >> b;
        cout << a + b << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(T)$，额外空间 $O(1)$。

### 易错点

这里有组数 T，与读到文件结束的版本不同。
