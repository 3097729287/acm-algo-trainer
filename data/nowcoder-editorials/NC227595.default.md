## 跳跳跳

### 题意

环上每次选择左右最近的未访问格，按访问顺序乘递增权重，求最大分数。

### 思路

已访问格构成环上一段，所以未访问部分也是连续区间，每步只能取其两端。复制数组后，对所有长度至n的区间做“剩余区间DP”。剩余len格时，这一步系数为n−len+1，选择左端或右端后剩余长度减一。按长度递增可滚动为一维，左端l从小到大更新。最后对所有长度n窗口取最大，相当于任选开始位置。首步选择原环任意点，都可在某个窗口中作为端点出现。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(2 * n), dp(2 * n + 1);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        a[i + n] = a[i];
    }
    for (int length = 1; length <= n; length++)
        for (int l = 0; l + length <= 2 * n; l++) {
            int r = l + length - 1;
            long long coefficient = n - length + 1;
            dp[l] = max(a[l] * coefficient + dp[l + 1], a[r] * coefficient + dp[l]);
        }
    cout << *max_element(dp.begin(), dp.begin() + n);
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

跳过已访问格去找最近未访问格，不是每次只能移动到物理相邻的一格。总分用64位；滚动更新左端从小到大。
