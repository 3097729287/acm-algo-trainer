## [NOIP2007]纪念品分组

### 题意

每组最多两件且总价格不超过 w，最小化组数。

### 思路

排序后维护最便宜和最贵的剩余物品。最贵的总要放入一组：若它与最便宜的都放不下，就只能单独一组；否则把这两件配在一起。证明后一选择安全：若某最优方案把最贵的配给另一件，交换成最便宜的仍可行，被替换的那件放到最便宜原来的位置，也不会更贵于该位置原本搭配最贵物品时的上界；若其中一件原来单独成组，同样不会增加组数。每次确定一组，直到取完。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int w, n;
    cin >> w >> n;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    int left = 0, right = n - 1, answer = 0;
    while (left <= right) {
        if (left < right && a[left] + a[right] <= w)
            left++;
        right--;
        answer++;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，排序之外额外空间 $O(1)$。

### 易错点

只剩一件时直接成组，不能用同一个物品与自身配对。题目保证每件单独都能放下。
