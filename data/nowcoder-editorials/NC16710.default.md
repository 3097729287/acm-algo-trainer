## 最小公倍数(lcm)

### 题意

求两个unsigned long long范围正整数的最小公倍数，保证答案也在该范围。

### 思路

gcd(a,b)*lcm(a,b)=a*b。先用欧几里得求g，然后输出(a/g)*b。必须先除再乘，虽然最终最小公倍数装得下，原a*b仍可能溢出。全程使用unsigned long long读取、计算、输出，不能用有符号long long装输入。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    unsigned long long a, b;
    cin >> a >> b;
    auto g = gcd(a, b);
    cout << (a / g) * b;
    return 0;
}
```

### 复杂度

时间 $O(\log\min(a,b))$，空间 $O(1)$。

### 易错点

原题2026年10月更新数据后已覆盖完整无符号64位范围。unsigned long long最大值不能先读入有符号类型再转换。
