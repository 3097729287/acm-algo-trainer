## CSL的校园卡

### 题意

两人从同一位置出发，允许重复走，最少多少秒能合计访问所有非障碍格。

### 思路

最多16个可走格，编号后用二进制mask表示已访问集合。先做单人的状态BFS：(mask,当前位置)，一步走到邻居并把其位加入mask。得到每个集合的最少覆盖时间，结束位置任意。对每个mask再做超集最小值DP，使best[mask]表示至少访问mask的最少时间。

枚举把全部格分给两人的两部分mask和all^mask，两人可同时行动，总时间是二者覆盖时间的最大值，取最小。超集DP允许实际路线重叠，也允许必经起点或中间格归在另一人的集合中。任意最优双人路线都对应某个分工，因此枚举完整。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    vector<vector<int>> id(n, vector<int>(m, -1));
    int k = 0, start = 0;
    for (int r = 0; r < n; r++) {
        cin >> grid[r];
        for (int c = 0; c < m; c++)
            if (grid[r][c] != 'X') {
                id[r][c] = k;
                if (grid[r][c] == 'S')
                    start = k;
                k++;
            }
    }
    vector<vector<int>> graph(k);
    int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
    for (int r = 0; r < n; r++)
        for (int c = 0; c < m; c++)
            if (id[r][c] != -1)
                for (int d = 0; d < 4; d++) {
                    int rr = r + dr[d], cc = c + dc[d];
                    if (rr >= 0 && rr < n && cc >= 0 && cc < m && id[rr][cc] != -1)
                        graph[id[r][c]].push_back(id[rr][cc]);
                }
    int masks = 1 << k, initial = (1 << start) * k + start, inf = 1000000000;
    vector<int> distance(masks * k, -1), best(masks, inf), queue{initial};
    distance[initial] = 0;
    for (size_t h = 0; h < queue.size(); h++) {
        int state = queue[h], mask = state / k, u = state % k;
        best[mask] = min(best[mask], distance[state]);
        for (int v : graph[u]) {
            int next = (mask | (1 << v)) * k + v;
            if (distance[next] == -1) {
                distance[next] = distance[state] + 1;
                queue.push_back(next);
            }
        }
    }
    for (int bit = 0; bit < k; bit++)
        for (int mask = 0; mask < masks; mask++)
            if (!(mask >> bit & 1))
                best[mask] = min(best[mask], best[mask | (1 << bit)]);
    int answer = inf;
    for (int mask = 0; mask < masks; mask++)
        answer = min(answer, max(best[mask], best[(masks - 1) ^ mask]));
    cout << answer;
    return 0;
}
```

### 复杂度

可走格数 $K\le16$，网格度数至多4，时间、空间均为 $O(K2^K)$。

### 易错点

不能只枚举两条不重复经过格子的简单路径；最优方案可以回走中间格。两人同时出发，合计时间取最大值，不取和。
