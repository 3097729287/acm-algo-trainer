## 打印质数表

### 题意

按递增顺序输出一到 N 的全部素数。

### 思路

先把二到 N 标为可能素数。从小到大遇到未被删去的 p，就删除 p²、p²+p 等倍数；更小的倍数已经由更小因子处理过。最后输出未被删去的数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<bool> prime(n + 1, true);
    prime[0] = false;
    if (n >= 1)
        prime[1] = false;
    for (int p = 2; p <= n / p; p++)
        if (prime[p])
            for (int x = p * p; x <= n; x += p)
                prime[x] = false;
    bool first = true;
    for (int x = 2; x <= n; x++)
        if (prime[x]) {
            if (!first)
                cout << ' ';
            cout << x;
            first = false;
        }
    return 0;
}
```

### 复杂度

时间 $O(N\log\log N)$，筛数组空间 $O(N)$。

### 易错点

一不是素数，N=1 时应没有数字输出。
