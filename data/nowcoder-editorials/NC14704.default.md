## 美味菜肴

### 题意

每道菜选择至多一次，越晚完成美味衰减越多，在时间内至少完整做一道，最大化总美味。

### 思路

先确定任意所选菜的最优顺序。比较相邻两菜i、j，i先做比j先做多得b[i]*c[j]−b[j]*c[i]，与此前累计时间无关。因此按b[i]*c[j]≥b[j]*c[i]排序，即衰减速度与耗时的比值递减，可通过相邻交换得到所有子集通用的最优顺序。

再按此顺序做01背包。dp[t]表示选前面若干道菜、恰好用t时间的最大美味；选当前菜时，从dp[t−c]加a−t*b，t必须倒序以保证该道菜只做一次。dp[0]=0只作为开始状态，答案在t≥1中取最大，不能选空集。原题写原料无限，指同一原料可以供多种菜使用；样例2也排除了反复制作同一道菜的解释。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, totalTime;
    cin >> n >> m >> totalTime;
    vector<long long> decay(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> decay[i];
    struct Dish {
        long long value, rate;
        int duration;
    };
    vector<Dish> dishes(m);
    for (auto &d : dishes) {
        int ingredient;
        cin >> ingredient >> d.value >> d.duration;
        d.rate = decay[ingredient];
    }
    sort(dishes.begin(), dishes.end(),
         [](const auto &a, const auto &b) { return a.rate * b.duration > b.rate * a.duration; });
    const long long neg = -(1LL << 60);
    vector<long long> dp(totalTime + 1, neg);
    dp[0] = 0;
    for (auto d : dishes)
        for (int t = totalTime; t >= d.duration; t--)
            if (dp[t - d.duration] != neg)
                dp[t] = max(dp[t], dp[t - d.duration] + d.value - d.rate * t);
    cout << *max_element(dp.begin() + 1, dp.end());
    return 0;
}
```

### 复杂度

时间 $O(m\log m+mT)$，空间 $O(T+n+m)$。

### 易错点

用完成时刻而不是开始时刻扣衰减。不能将答案初始化为0，否则全部负收益时会错误选择不做菜。排序用交叉乘积，避免除零及浮点比较。
