## [国家集训队]最长双回文串

### 题意

求可拆成两个相邻非空回文的最长连续子串。

### 思路

预处理 end[i] 为恰在 i 结束的最长回文长度，start[i] 为恰在 i 开始的最长回文长度。先把每个中心的最大奇、偶回文记到它的左右端点。一个长度 L 的回文去掉两端后，得到向内缩一格、长度 L-2 的回文，所以 end 从右向左按 end[i+1]-2 传播，start 从左向右按 start[i-1]-2 传播，就补齐所有较短半径。最后枚举分割缝 i|i+1，最大化 end[i]+start[i+1]。两段正好相邻且都非空。

Manacher 的 odd[i] 表示以 i 为中心、包含中心的最大奇回文半径，长度为 2odd[i]-1；even[i] 表示中心在 i-1 与 i 之间的最大偶回文半径，长度为 2even[i]。维护已知最靠右的回文区间，利用镜像位置的半径初始化，再只向未知部分扩展。右边界只会前进，全部扩展次数为线性。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct PalindromeRadii {
    vector<int> odd, even;
    explicit PalindromeRadii(const string &s) {
        int n = s.size();
        odd.resize(n);
        even.resize(n);
        int left = 0, right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 1 : min(odd[left + right - i], right - i + 1);
            while (i - k >= 0 && i + k < n && s[i - k] == s[i + k])
                k++;
            odd[i] = k;
            if (i + k - 1 > right) {
                left = i - k + 1;
                right = i + k - 1;
            }
        }
        left = 0;
        right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 0 : min(even[left + right - i + 1], right - i + 1);
            while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k])
                k++;
            even[i] = k;
            if (i + k - 1 > right) {
                left = i - k;
                right = i + k - 1;
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int n = s.size();
    PalindromeRadii radius(s);
    vector<int> ending(n), starting(n);
    for (int i = 0; i < n; i++) {
        int r = radius.odd[i], length = 2 * r - 1;
        ending[i + r - 1] = max(ending[i + r - 1], length);
        starting[i - r + 1] = max(starting[i - r + 1], length);
        r = radius.even[i];
        if (r) {
            length = 2 * r;
            ending[i + r - 1] = max(ending[i + r - 1], length);
            starting[i - r] = max(starting[i - r], length);
        }
    }
    for (int i = n - 2; i >= 0; i--)
        ending[i] = max(ending[i], ending[i + 1] - 2);
    for (int i = 1; i < n; i++)
        starting[i] = max(starting[i], starting[i - 1] - 2);
    int answer = 0;
    for (int i = 0; i + 1 < n; i++)
        answer = max(answer, ending[i] + starting[i + 1]);
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

这是两个相邻回文，不能拿两个可能相交的全局最长回文直接相加。较短回文也可能参与最优答案，端点传播不能省略。
