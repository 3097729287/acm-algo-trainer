## Jelly

### 题意

在三维果冻中六方向移动，求从首格到末格最少吃的块数。

### 思路

将坐标压成 (x*n+y)*n+z，BFS求最少步数。起点也要吃一块，所以起点距离初始化为1；每移动一次加1。星号不能进入，终点没访问到则输出−1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int size = n * n * n;
    vector<char> grid(size);
    for (int i = 0; i < size; i++)
        cin >> grid[i];
    vector<int> distance(size, -1), queue{0};
    distance[0] = 1;
    int dx[] = {1, -1, 0, 0, 0, 0}, dy[] = {0, 0, 1, -1, 0, 0}, dz[] = {0, 0, 0, 0, 1, -1};
    for (size_t head = 0; head < queue.size(); head++) {
        int u = queue[head], x = u / (n * n), y = u / n % n, z = u % n;
        for (int d = 0; d < 6; d++) {
            int a = x + dx[d], b = y + dy[d], c = z + dz[d];
            if (a < 0 || a >= n || b < 0 || b >= n || c < 0 || c >= n)
                continue;
            int v = (a * n + b) * n + c;
            if (grid[v] != '*' && distance[v] == -1) {
                distance[v] = distance[u] + 1;
                queue.push_back(v);
            }
        }
    }
    cout << distance.back();
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n^3)$。

### 易错点

输出经过的块数，不是边数；n=1时答案为1。
