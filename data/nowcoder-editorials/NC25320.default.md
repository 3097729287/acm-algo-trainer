## 有序序列插入一个整数

### 题意

将一个整数插入升序序列，并保持有序。

### 思路

lower_bound 找到第一个不小于 x 的位置，把 x 插在它之前。若所有元素都小于 x，就在末尾插入；空数组时该位置也自然是末尾。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    int x;
    cin >> x;
    a.insert(lower_bound(a.begin(), a.end(), x), x);
    for (int i = 0; i <= n; i++) {
        if (i)
            cout << ' ';
        cout << a[i];
    }
    return 0;
}
```

### 复杂度

查找 $O(\log n)$、移动与输出 $O(n)$，总时间与数组空间为 $O(n)$。

### 易错点

二分只负责找位置；vector 插入仍需要移动后面的元素。
