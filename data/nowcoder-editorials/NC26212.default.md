## 小石的签到题

### 题意

取x后连续取其二分祖先直到缺失，拿走最后一个数者输。

### 思路

n=1时只能取最后一个，先手输。n>1时考虑先取1后的非空局面S：若S是必败局面，先取1就能赢；若S是必胜局面，设S中某个获胜首步选x。原局面直接选同一个x，沿祖先链到1后也恰好得到相同后继，因为S只是预先拿掉了1。因此原局面仍有一步通向必败局面。

反常规则下取空是输，这个论证仍成立：S的获胜步不会直接取空，所以原局面的对应步也不会直接取空。于是所有n>1均先手胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    cout << (n == 1 ? "Yang" : "Shi");
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

不能把“取最后一个输”误当普通Nim。证明依赖1属于所有祖先链，并且n>1时取1后仍非空。
