## 粉嘤花之恋

### 题意

每次新花瓣替换旧花瓣，求树上和地上的总数。

### 思路

第i次新长花瓣数为1+Σ(j=1..i−1)F[j]=F[i+1]。旧花瓣落地后仍计入，所以k次后总数是初始1加Σ(i=1..k)F[i+1]=F[k+3]−1。用快速倍增求F[k+3]：由(F[t],F[t+1])得到F[2t]=F[t]*(2F[t+1]−F[t])、F[2t+1]=F[t]²+F[t+1]²。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

pair<long long, long long> fibonacci(unsigned long long n, long long mod) {
    if (!n)
        return {0, 1};
    auto [a, b] = fibonacci(n / 2, mod);
    long long c = a * ((2 * b - a + mod) % mod) % mod;
    long long d = (a * a % mod + b * b % mod) % mod;
    if (n & 1)
        return {d, (c + d) % mod};
    return {c, d};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    unsigned long long k;
    cin >> k;
    const long long mod = 998244353;
    cout << (fibonacci(k + 3, mod).first + mod - 1) % mod;
    return 0;
}
```

### 复杂度

时间、递归空间均为 $O(\log k)$。

### 易错点

初始花瓣也在总数内，不能只加各次净增长。减1后规范到非负余数。
