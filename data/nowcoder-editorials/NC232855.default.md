## 神奇数组

### 题意

每段免费去掉最小floor(长度/c)项，求分割后的最小收费和。

### 思路

先求最大折扣，再用总和减去。长度kc+r的段，原折扣是该段最小k项之和。把其中连续kc项分成k个长度c的块，剩下r项单独处理，每块各免其最小值，相当于从原段选了k项；任意k项之和不少于全局最小k项，因此这样细分折扣只会更大。

所以只需考虑互不重叠的长度c块。f[i]=max(f[i−1],f[i−c]+min(a[i−c+1..i]))，分别不以i结束块、选择该块。用单调队列维护长度c的滑动最小值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, c;
    cin >> n >> c;
    vector<long long> a(n + 1), dp(n + 1);
    long long sum = 0;
    deque<int> queue;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        sum += a[i];
        while (!queue.empty() && a[queue.back()] >= a[i])
            queue.pop_back();
        queue.push_back(i);
        while (!queue.empty() && queue.front() <= i - c)
            queue.pop_front();
        dp[i] = dp[i - 1];
        if (i >= c)
            dp[i] = max(dp[i], dp[i - c] + a[queue.front()]);
    }
    cout << sum - dp[n];
    return 0;
}
```

### 复杂度

时间、空间均 $O(n)$。

### 易错点

不是每c个元素固定一组，可以跳过部分元素选择更好的不重叠块。c=1时所有元素免费，答案0。
