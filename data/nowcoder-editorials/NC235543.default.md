## 大魔法师牛可乐

### 题意

付费学若干双向跳长，要求能到达全部整数位置。

### 思路

可正反向使用跳长，能到达的位置恰是所选跳长gcd的倍数，所以目标是选出gcd=1的最小费用。dp[g]记录已处理卡片选择子集gcd为g的最少费用，空集用g=0。对每张卡，用旧表副本保留不选，再用gcd(g,l)更新选卡状态。相同gcd仅保留费用最小者。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> length(n), cost(n);
    for (int &x : length)
        cin >> x;
    for (int &x : cost)
        cin >> x;
    map<int, long long> dp = {{0, 0}};
    for (int i = 0; i < n; i++) {
        auto next = dp;
        for (auto [g, value] : dp) {
            int target = gcd(g, length[i]);
            long long candidate = value + cost[i];
            auto it = next.find(target);
            if (it == next.end() || candidate < it->second)
                next[target] = candidate;
        }
        dp.swap(next);
    }
    cout << (dp.count(1) ? dp[1] : -1);
    return 0;
}
```

### 复杂度

设最多S个不同gcd状态，时间 $O(nS(\log U+\log S))$，空间 $O(S)$。

### 易错点

允许反向跳，所以使用整数线性组合，不是非负背包。不能仅检查是否存在两张互素卡，可能需要更多张。
