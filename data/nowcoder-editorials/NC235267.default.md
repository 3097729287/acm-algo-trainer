## 星球大战

### 题意

横线或竖线轰炸，统计每次新摧毁的基地数。

### 思路

分别按x、y把基地编号分组。攻击某条线时遍历该组，未摧毁者计数并标记；处理后清空该组。同一基地最多在x组和y组各访问一次，总遍历量O(n)，重复轰炸空组不再扫描。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    map<long long, vector<int>> byX, byY;
    for (int i = 0; i < n; i++) {
        long long x, y;
        cin >> x >> y;
        byX[x].push_back(i);
        byY[y].push_back(i);
    }
    vector<bool> destroyed(n);
    while (m--) {
        int c;
        long long d;
        cin >> c >> d;
        auto &groups = c == 0 ? byX : byY;
        auto it = groups.find(d);
        int answer = 0;
        if (it != groups.end()) {
            for (int id : it->second)
                if (!destroyed[id]) {
                    destroyed[id] = true;
                    answer++;
                }
            groups.erase(it);
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log n)$，空间 $O(n)$。

### 易错点

已经被另一方向攻击摧毁的基地不会再计数。删除整组后总扫描量才有线性界。
