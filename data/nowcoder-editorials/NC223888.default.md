## 红色和紫色

### 题意

交替给网格空格染两色，相邻同色禁止，不能染色者输。

### 思路

若n、m均为奇数，先手先染中心格；此后把后手的每次落点绕中心旋转180度，在对应格染相同颜色。成对格不相邻，既有图案保持同色中心对称，所以回应始终合法。

否则没有固定中心格，后手始终在先手落点的中心对称格染相反颜色。已有图案保持反色中心对称，相邻约束也被保持；即便这一对格互相相邻，反色仍合法。故只有n、m均奇数时先手赢。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, m;
    cin >> n >> m;
    cout << ((n % 2 && m % 2) ? "akai" : "yukari");
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

奇数尺寸时中心格必须先占，否则对称回应缺少起点。偶数情形使用反色，兼顾对称格恰好相邻。
