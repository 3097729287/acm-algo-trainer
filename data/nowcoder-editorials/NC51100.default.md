## A Simple Problem with Integers

### 题意

维护区间加与区间求和。

### 思路

设差分d[i]=a[i]−a[i−1]。给[l,r]加x只改变d[l]+=x、d[r+1]−=x。前缀和Σ(i=1..p)a[i]=Σ(j=1..p)(p−j+1)d[j]=p*Σd[j]−Σ(j−1)d[j]。用两棵树状数组分别维护d[j]与(j−1)d[j]，区间和由两个前缀和相减得到。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    Fenwick first(n), second(n);
    auto point = [&](int p, long long x) {
        if (p <= n) {
            first.add(p, x);
            second.add(p, x * (p - 1));
        }
    };
    long long previous = 0;
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        point(i, x - previous);
        previous = x;
    }
    auto prefix = [&](int p) { return p * first.sum(p) - second.sum(p); };
    while (q--) {
        char op;
        int l, r;
        cin >> op >> l >> r;
        if (op == 'C') {
            long long x;
            cin >> x;
            point(l, x);
            point(r + 1, -x);
        } else
            cout << prefix(r) - prefix(l - 1) << '\n';
    }
    return 0;
}
```

### 复杂度

初始化 $O(n\log n)$，每次操作 $O(\log n)$，空间 $O(n)$。

### 易错点

初始数组也必须转换为差分写入两棵树。r=n时忽略n+1端点；节点、加权差分和总和均用64位。
