## 小A与任务

### 题意

允许付实数金币缩短任务耗时，不能缩到负数，求按时完成所有任务的最少金币。

### 思路

先按截止时间排序：若相邻两任务的截止时间逆序，交换后不影响较早截止任务完成，且较晚截止任务也不会更晚，因此可用截止时间顺序执行。依次加入任务的原始耗时。若累计耗时超过当前截止时间，必须从已经加入的任务中删去这段超时。每枚金币能减少 z 单位时间，优先缩短 z 最大的任务最省钱；用大根堆记录 z 和该任务尚可缩短的耗时。可删完整任务，也可只删够当前超时。

每个截止前缀都必须满足；在当前前缀内选择最便宜的时间缩减，不能用未来任务替代。对任一可行方案交换同等缩减量到更大 z 的已到期前缀内，不会破坏前缀约束且费用不增，故贪心成立。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Task {
        int z, x, deadline;
    };
    vector<Task> tasks(n);
    for (auto &t : tasks)
        cin >> t.z >> t.x >> t.deadline;
    sort(tasks.begin(), tasks.end(), [](auto a, auto b) { return a.deadline < b.deadline; });
    priority_queue<pair<int, int>> heap;
    long long elapsed = 0;
    long double cost = 0;
    for (auto t : tasks) {
        elapsed += t.x;
        heap.push({t.z, t.x});
        while (elapsed > t.deadline) {
            auto [z, remaining] = heap.top();
            heap.pop();
            long long remove = min<long long>(remaining, elapsed - t.deadline);
            elapsed -= remove;
            cost += (long double)remove / z;
            remaining -= remove;
            if (remaining)
                heap.push({z, remaining});
        }
    }
    cout << fixed << setprecision(1) << cost;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

金币可为实数，耗时的缺口和剩余可缩短时间仍是整数。优先比较 z，而不是原耗时或单个任务总费用。
