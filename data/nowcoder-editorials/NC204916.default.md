## 浅尝辄止

### 题意

求Σfloor(n/i)模998244353，n至10^13。

### 思路

相同商q=n/l对应右端r=n/q，区间[l,r]统一贡献q*(r−l+1)。枚举O(sqrt n)段，两个因子先取模再相乘，避免原始乘积溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    const long long mod = 998244353;
    long long answer = 0;
    for (long long l = 1, r; l <= n; l = r + 1) {
        long long quotient = n / l;
        r = n / quotient;
        answer = (answer + (quotient % mod) * ((r - l + 1) % mod)) % mod;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(\sqrt n)$，空间 $O(1)$。

### 易错点

n不是模数内整数，分块边界要用完整n做整数除法，不能先取模。
