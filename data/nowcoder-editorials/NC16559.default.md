## 异或(xor)

### 题意

聪明的鱼按顺序决定是否捕食前鱼，第一条鱼每天可吃饭的安全天数最多多少。

### 思路

固定当天有k条鱼，从末尾倒推：一条鱼吃前鱼后，若后面那条会继续捕食，它就不会吃；最后一条总敢吃，因此第一条能安全吃食物当且仅当k为奇数。奇数时第二条选择不吃，偶数时第一条自己不吃，所以理性策略下没有鱼被吃掉，繁殖数量不受影响。

按出生后成长两天再繁殖，头两天鱼数为1、1，此后每天的新增鱼是前两天已有的鱼，鱼数满足斐波那契递推。模2依次为1、1、0，每三天循环，因此只有3的倍数日不能喂TbGx，答案n−floor(n/3)。原站补充说明n不超过10^18，用Python整数直接计算。

### 参考代码

```python
import sys

if hasattr(sys, 'set_int_max_str_digits'):
    sys.set_int_max_str_digits(0)

for token in sys.stdin.buffer.read().split():
    n = int(token)
    print(n - n // 3)
```

### 复杂度

每组只做常数次大整数运算，时间包含十进制读写的开销，空间与输入数字位数相关。

### 易错点

只需鱼数的奇偶，无需计算增长极快的鱼数量。输入多组读至EOF，没有开头测试组数。
