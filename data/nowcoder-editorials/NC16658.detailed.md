## 不高兴的津津

> 原题：[P1085](https://www.luogu.com.cn/problem/P1085)
> 解法：扫描并保留首次最大值 · C++17

### 题意

一周七天，每天两种上课时间相加；超过八小时才不高兴，求最不高兴且最早的一天，否则输出零。



### 思路

若每天都不超过八小时，答案保持零。第一次遇到九小时就记录那一天；以后又遇到九小时不更新，因而保留最早的一天；遇到十小时才替换。循环之前 best=8、answer=0 表示还没有不高兴的日子。处理完每一天后，best 是已处理日期中大于八的最大值，answer 是第一次取得它的日期，所以最终正好满足阈值和并列规则。

时间与额外空间均为 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int best = 8, answer = 0;
    for (int day = 1; day <= 7; day++) {
        int a, b;
        cin >> a >> b;
        if (a + b > best) {
            best = a + b;
            answer = day;
        }
    }
    cout << answer << '\n';
    return 0;
}
```

### 易错点

更新条件用严格大于；恰好八小时不算不高兴。
