## 判断闰年

### 题意

按公历规则判断输入年份是否为闰年。

### 思路

能被四百整除时一定为闰年；其余年份需能被四整除而不能被一百整除。把两个充分条件用逻辑或连接。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    bool leap = n % 400 == 0 || (n % 4 == 0 && n % 100 != 0);
    cout << (leap ? "yes" : "no");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

只判断四的倍数会把一九〇〇年误判为闰年。
