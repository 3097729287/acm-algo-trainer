## 对称二叉树

### 题意

在最多一百万结点的有权二叉树中，求最大的镜像对称完整子树。

### 思路

先用迭代遍历得到从父到子的顺序，逆序计算每棵子树大小。只有左右子树大小相等，根才可能对称；对这些候选，用栈成对检查“左的左与右的右、左的右与右的左”，要求空位和权值都匹配。若候选大小不超过当前答案，可直接跳过。全过程不用深递归，也不依赖可能碰撞的树哈希。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> value(n + 1), left(n + 1), right(n + 1), size(n + 1), order;
    for (int i = 1; i <= n; i++)
        cin >> value[i];
    for (int i = 1; i <= n; i++) {
        cin >> left[i] >> right[i];
        if (left[i] < 0)
            left[i] = 0;
        if (right[i] < 0)
            right[i] = 0;
    }
    order.push_back(1);
    for (size_t i = 0; i < order.size(); i++) {
        int u = order[i];
        if (left[u])
            order.push_back(left[u]);
        if (right[u])
            order.push_back(right[u]);
    }
    for (int i = (int)order.size() - 1; i >= 0; i--) {
        int u = order[i];
        size[u] = 1 + size[left[u]] + size[right[u]];
    }
    int answer = 1;
    vector<pair<int, int>> pending;
    for (int u : order) {
        if (size[u] <= answer || size[left[u]] != size[right[u]])
            continue;
        bool same = true;
        pending.clear();
        pending.emplace_back(left[u], right[u]);
        while (!pending.empty() && same) {
            auto [a, b] = pending.back();
            pending.pop_back();
            if (a == 0 || b == 0) {
                if (a != b)
                    same = false;
                continue;
            }
            if (value[a] != value[b]) {
                same = false;
                break;
            }
            pending.emplace_back(left[a], right[b]);
            pending.emplace_back(right[a], left[b]);
        }
        if (same)
            answer = size[u];
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间上界 $O(n\log n)$：只有左右等大的结点才向下检查；沿任一后代路径，每经过一次这种被检查的祖先，所属子树至少减半，因此每个点最多被检查 $O(\log n)$ 次。数组与显式栈空间 $O(n)$。

### 易错点

相同权值不代表结构相同；两个对应位置若只有一边为空，必须判不对称。百万长链要避免递归栈溢出。
