## 脸盆大哥的木桶

### 题意

每 k 块木板组成一个桶，容量是最短板乘底面积，最大化总容量。

### 思路

把木板从高到低排序，每连续 k 块组成一个桶；不足 k 块的最矮木板不用。第 j 个桶的最短板取排序后的第 jk 块。证明可把任意方案的桶按最短板从高到低编号：前 j 桶共有 jk 块板都不短于第 j 桶的最短板，所以该最短板不能超过全体第 jk 高的板。连续分组恰好逐项达到这个上界。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n, k, s;
        cin >> n >> k >> s;
        vector<int> h(n);
        for (int &x : h)
            cin >> x;
        sort(h.begin(), h.end(), greater<int>());
        long long answer = 0;
        for (int i = k - 1; i < n; i += k)
            answer += 1LL * h[i] * s;
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

最矮的余数块应丢弃，不能先按升序从第一块开始组。k 大于 n 时造不出桶，答案为零。
