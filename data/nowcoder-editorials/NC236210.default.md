## 传送门

### 题意

两人通过同类传送门付费移动，最早相遇时间与全部相遇点。

### 思路

每类传送门建一个虚拟点，原点到该类虚点费用t，虚点到其全部原点费用0，避免把S个点完全连边。分别从1与n跑Dijkstra。两人可等候，因此在点u相遇时间为max(d1[u],dn[u])，对原始点取最小，再升序输出全部达到该时间者。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<long long> dijkstra(const vector<vector<pair<int, long long>>> &graph, int source) {
    const long long inf = 1LL << 60;
    vector<long long> distance(graph.size(), inf);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                   greater<pair<long long, int>>>
        heap;
    distance[source] = 0;
    heap.push({0, source});
    while (!heap.empty()) {
        auto [cost, u] = heap.top();
        heap.pop();
        if (cost != distance[u])
            continue;
        for (auto [v, w] : graph[u])
            if (distance[v] > cost + w) {
                distance[v] = cost + w;
                heap.push({distance[v], v});
            }
    }
    return distance;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, long long>>> graph(n + m);
    for (int i = 0; i < m; i++) {
        long long t;
        int count;
        cin >> t >> count;
        while (count--) {
            int u;
            cin >> u;
            u--;
            graph[u].push_back({n + i, t});
            graph[n + i].push_back({u, 0});
        }
    }
    auto first = dijkstra(graph, 0), second = dijkstra(graph, n - 1);
    long long best = (1LL << 60);
    for (int u = 0; u < n; u++)
        best = min(best, max(first[u], second[u]));
    if (best >= (1LL << 59)) {
        cout << -1;
        return 0;
    }
    cout << best << '\n';
    bool space = false;
    for (int u = 0; u < n; u++)
        if (max(first[u], second[u]) == best) {
            if (space)
                cout << ' ';
            space = true;
            cout << u + 1;
        }
    cout << '\n';
    return 0;
}
```

### 复杂度

令L为传送门出现总数，时间 $O((n+m+L)\log(n+m))$，空间 $O(n+m+L)$。

### 易错点

虚拟点不是可相遇地点，最后只枚举原始n点。两人并行，取最大到达时间而非距离和。
