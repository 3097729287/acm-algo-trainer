## A+B

### 题意

连续读入多组整数对，分别输出两数之和。

### 思路

本题没有提前给出数据组数。把 cin>>a>>b 作为 while 条件，每成功读取完整一组就输出一行，文件结束时自动退出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long a, b;
    while (cin >> a >> b)
        cout << a + b << '\n';
    return 0;
}
```

### 复杂度

若有 $T$ 组，时间 $O(T)$，额外空间 $O(1)$。

### 易错点

不能把第一组的第一个数误当成组数，也不能只处理一组。
