## wyh的吃鸡

### 题意

步行每格2秒，拿车后每格1秒，判断能否在时限内到达任一安全格并求最短时间。

### 思路

状态是 (位置,是否有车)。在当前状态下移动的耗时由出发时是否已有车决定；进入C后设为有车。车一旦获得就保留，没有额外代价，因此无需主动放弃。用Dijkstra处理权值1或2的移动，第一次弹出的X状态就是到安全区的最短时间，再与时限比较。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, limit;
        cin >> n >> limit;
        vector<string> grid(n);
        int start = 0;
        for (int r = 0; r < n; r++) {
            cin >> grid[r];
            for (int c = 0; c < n; c++)
                if (grid[r][c] == 'S')
                    start = 2 * (r * n + c);
        }
        vector<int> distance(2 * n * n, 1000000000);
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;
        distance[start] = 0;
        heap.push({0, start});
        int answer = -1, dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
        while (!heap.empty()) {
            auto [cost, u] = heap.top();
            heap.pop();
            if (cost != distance[u])
                continue;
            int car = u % 2, r = u / 2 / n, c = u / 2 % n;
            if (grid[r][c] == 'X') {
                answer = cost;
                break;
            }
            for (int d = 0; d < 4; d++) {
                int rr = r + dr[d], cc = c + dc[d];
                if (rr < 0 || rr >= n || cc < 0 || cc >= n || grid[rr][cc] == 'O')
                    continue;
                int v = 2 * (rr * n + cc) + (car || grid[rr][cc] == 'C');
                int next = cost + (car ? 1 : 2);
                if (next < distance[v]) {
                    distance[v] = next;
                    heap.push({next, v});
                }
            }
        }
        if (answer != -1 && answer <= limit)
            cout << "YES\n" << answer << '\n';
        else
            cout << "NO\n";
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2\log n)$，空间 $O(n^2)$。

### 易错点

走到车所在格的这一步仍按步行计费。安全区可能多格，找到任意X就足够。
