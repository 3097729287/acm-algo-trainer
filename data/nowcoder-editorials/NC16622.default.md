## 多项式输出

> 原题：[P1067](https://www.luogu.com.cn/problem/P1067)
> 解法：拆开符号、系数和幂次输出 · C++17

### 题意

按规范输出多项式：省略零项，处理首项符号、系数一以及一次项和常数项。



### 思路

按次数递减读取。零系数跳过；先按是否已经输出过项决定符号，再按次数与系数绝对值决定数字和 $x$ 的写法。

时间 $O(n)$、额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    bool first = true;
    for (int power = n; power >= 0; --power) {
        int coefficient;
        cin >> coefficient;
        if (coefficient == 0)
            continue;
        if (coefficient < 0)
            cout << '-';
        else if (!first)
            cout << '+';
        int value = abs(coefficient);
        if (power == 0 || value != 1)
            cout << value;
        if (power > 0) {
            cout << 'x';
            if (power > 1)
                cout << '^' << power;
        }
        first = false;
    }
    if (first)
        cout << 0;
    cout << '\n';
    return 0;
}
```

### 易错点

常数一不能省略；一次项只写 $x$，首个正项前不写加号。
