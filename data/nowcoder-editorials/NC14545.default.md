## B-经商

### 题意

只能与关系网中从1可接触的人交际，每人一次，在精力容量内最大化收益。

### 思路

关系可传递，先并查集合并全部无向关系，只保留与1同根的人。之后是独立的01背包。相同 (精力,收益) 的人可合为一类，把数量按1、2、4等二进制拆组，逐组倒序更新容量，减少重复物品带来的开销。起点1没有对应可选收益物品。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m, capacity;
        cin >> n >> m >> capacity;
        vector<pair<int, int>> items(n + 1);
        for (int i = 2; i <= n; i++)
            cin >> items[i].first >> items[i].second;
        DSU dsu(n);
        while (m--) {
            int a, b;
            cin >> a >> b;
            dsu.unite(a, b);
        }
        map<pair<int, int>, int> counts;
        for (int i = 2; i <= n; i++)
            if (dsu.find(i) == dsu.find(1))
                counts[items[i]]++;
        vector<long long> dp(capacity + 1);
        for (auto [item, count] : counts) {
            auto [cost, value] = item;
            for (int block = 1; count > 0; block *= 2) {
                int take = min(block, count);
                count -= take;
                int weight = cost * take;
                long long profit = 1LL * value * take;
                for (int c = capacity; c >= weight; c--)
                    dp[c] = max(dp[c], dp[c - weight] + profit);
            }
        }
        cout << dp[capacity] << '\n';
    }
    return 0;
}
```

### 复杂度

设保留物品数为 $R$、拆分后组数为 $G$，时间 $O((n+m)\alpha(n)+R\log R+GC)$，空间 $O(n+R+C)$。

### 易错点

只看1的连通块；不能将整块人数当成必须一起选的一个物品。分组后仍需倒序更新。
