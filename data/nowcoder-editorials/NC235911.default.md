## 走楼梯

### 题意

n阶楼梯，每次1或2阶，求方案数。

### 思路

按最后一步拆分，f[n]=f[n−1]+f[n−2]，f[0]=1、f[1]=1。从2滚动计算，n≤50需64位。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long previous = 1, current = 1;
    for (int i = 2; i <= n; i++) {
        long long next = previous + current;
        previous = current;
        current = next;
    }
    cout << current;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

空台阶有一种“已经完成”的方式，设f[0]=1才能正确得到f[2]=2。
