## 简写单词

### 题意

取每个单词首字母并大写，按原顺序连接。

### 思路

输入只有这一行复合词，可以用 cin 依次读取被空格分隔的单词，立即输出其首字母的大写形式。输出之间不加空格。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string word;
    while (cin >> word)
        cout << char(toupper(static_cast<unsigned char>(word[0])));
    return 0;
}
```

### 复杂度

时间 $O(L)$，临时空间为最长单词长度。

### 易错点

只取各词首字母，而不是输出原串的所有大写字母。
