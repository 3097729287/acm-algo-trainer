## 急速行走

### 题意

从 A 沿第一线段、转为平面行走，再沿第二线段到 D，最小化耗时。

### 思路

令离开第一线段的位置 E=A+t(B-A)，进入第二线段的位置 F=C+u(D-C)，t、u 都在零到一。耗时为 |AE|/p+|EF|/r+|FD|/q。固定 t 后，它对 u 是凸函数，可三分求最小；联合表达式是凸函数，对 u 取最小后的函数对 t 仍凸，因此外层再三分。每层固定迭代一百次，最后求值；两端位置也在闭区间中，无须额外假设最优在内部。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long double ax, ay, bx, by, cx, cy, dx, dy, p, q, r;
    cin >> ax >> ay >> bx >> by >> cx >> cy >> dx >> dy >> p >> q >> r;
    auto inner = [&](long double t) {
        long double ex = ax + t * (bx - ax), ey = ay + t * (by - ay);
        auto cost = [&](long double u) {
            long double fx = cx + u * (dx - cx), fy = cy + u * (dy - cy);
            return hypotl(ex - ax, ey - ay) / p + hypotl(ex - fx, ey - fy) / r +
                   hypotl(dx - fx, dy - fy) / q;
        };
        long double low = 0, high = 1;
        for (int i = 0; i < 100; i++) {
            long double x = (2 * low + high) / 3, y = (low + 2 * high) / 3;
            if (cost(x) <= cost(y))
                high = y;
            else
                low = x;
        }
        return cost((low + high) / 2);
    };
    long double low = 0, high = 1;
    for (int i = 0; i < 100; i++) {
        long double x = (2 * low + high) / 3, y = (low + 2 * high) / 3;
        if (inner(x) <= inner(y))
            high = y;
        else
            low = x;
    }
    cout << fixed << setprecision(2) << inner((low + high) / 2);
    return 0;
}
```

### 复杂度

每层迭代 $K=100$ 次，时间 $O(K^2)$，额外空间 $O(1)$。

### 易错点

按原 SCOI 题及样例，p、q、r 是通常的速度，时间为距离除速度；不要被题面“单位时间每单位距离”的措辞误导。
