## 食堂

### 题意

队首可能等待、排到末尾、离队或关门，求关门时仍在前k位的概率。

### 思路

f[i][j]表示队长i、自己第j位时事件成功概率，已打饭离队后为0。先消去等待自环，令A=p2/(1−p1)、B=p3/(1−p1)、C=p4/(1−p1)。j>1时，f[i][j]=A*f[i][j−1]+B*f[i−1][j−1]+C*[j≤k]；j=1时，自己没卡会排到末尾，f[i][1]=A*f[i][i]+C。

先把f[i][1]当变量x，递推得到f[i][i]=A^(i−1)*x+t，故x=(A*t+C)/(1−A^i)。求出首项再正序填本行，行间滚动。p4=0时不会发生关门事件，答案为0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    long double p1, p2, p3, p4;
    cin >> n >> m >> k >> p1 >> p2 >> p3 >> p4;
    if (p4 == 0) {
        cout << "0.00000";
        return 0;
    }
    long double a = p2 / (1 - p1), b = p3 / (1 - p1), c = p4 / (1 - p1);
    vector<long double> previous(n + 1), current(n + 1);
    for (int size = 1; size <= n; size++) {
        long double t = 0;
        for (int j = 2; j <= size; j++)
            t = a * t + b * previous[j - 1] + (j <= k ? c : 0);
        current[1] = (a * t + c) / (1 - powl(a, size));
        for (int j = 2; j <= size; j++)
            current[j] = a * current[j - 1] + b * previous[j - 1] + (j <= k ? c : 0);
        current.swap(previous);
    }
    cout << fixed << setprecision(5) << previous[m];
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

j=1成功打饭后离队，后续关门不计成功。不能把末尾回流当成上一行状态。
