## 字符串操作

### 题意

按顺序在指定闭区间内替换指定字符。

### 思路

n、m 都不超过一百，直接执行每次操作。把一开始的左右端点减一，逐个检查区间内当前字符是否等于 c1，相等则改成 c2。后续操作读取修改后的串。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    string s;
    cin >> n >> m >> s;
    while (m--) {
        int l, r;
        char a, b;
        cin >> l >> r >> a >> b;
        for (int i = l - 1; i < r; i++)
            if (s[i] == a)
                s[i] = b;
    }
    cout << s;
    return 0;
}
```

### 复杂度

时间 $O(nm)$，字符串空间 $O(n)$。

### 易错点

区间两端都包含；必须依次修改，不能把所有替换统一套在原串上。
