## [USACO 2008 Jan G]Cell Phone Network

### 题意

树上建最少通讯塔，每塔覆盖自己及相邻点，覆盖全部点。

### 思路

必须区分三个状态：A[u]在u建塔；B[u]不建塔，但由至少一个孩子塔覆盖；C[u]不建且未被孩子覆盖，需要父亲塔。A=1+Σmin(A[v],B[v],C[v])。C要求孩子全为B，否则孩子塔会覆盖u、或孩子需要u建塔。B先对每个孩子取min(A,B)，再补上最小的“强制一个孩子选A”的额外费用。没有孩子时B不可达、C=0、A=1。根不能依赖父亲，所以取min(A[root],B[root])。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    Tree tree(n);
    for (int i = 1; i < n; i++) {
        int a, b;
        cin >> a >> b;
        tree.add(a - 1, b - 1);
    }
    tree.root(0);
    const long long inf = 1000000000;
    vector<array<long long, 3>> dp(n);
    for (int i = n - 1; i >= 0; i--) {
        int u = tree.order[i];
        long long a = 1, b = 0, c = 0, force = inf;
        for (auto [v, w] : tree.edge[u])
            if (v != tree.parent[u]) {
                a += min({dp[v][0], dp[v][1], dp[v][2]});
                long long best = min(dp[v][0], dp[v][1]);
                b += best;
                force = min(force, dp[v][0] - best);
                c = min(inf, c + dp[v][1]);
            }
        dp[u] = {a, min(inf, b + force), c};
    }
    cout << min(dp[0][0], dp[0][1]);
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

覆盖点与覆盖边不同，不能套用顶点覆盖的两个状态。根没有父亲，不能选“需要父亲覆盖”。
