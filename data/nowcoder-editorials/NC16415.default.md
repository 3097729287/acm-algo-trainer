## 时间复杂度

### 题意

检查循环声明是否合法，并比较实际最高 n 次数与给出的复杂度。

### 思路

用栈保存每个循环的变量、是否本层永不执行、是否实际贡献一个 n 因子。n 当成大于所有常数的哨兵即可比较上下界；常数到 n 的活跃循环贡献一次方，n 到常数的循环不执行。维护当前被阻断层数，使不可执行循环内部不增加指数；但变量声明与 F/E 配对仍照常检查。并列循环取最高指数，嵌套的活跃循环指数相加。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int lines;
        string claimed;
        cin >> lines >> claimed;
        int expected = claimed == "O(1)" ? 0 : stoi(claimed.substr(claimed.find('^') + 1));
        struct Frame {
            int variable;
            bool dead, contributes;
        };
        vector<Frame> stack;
        int active[26] = {}, blocked = 0, exponent = 0, maximum = 0;
        bool error = false;
        for (int line = 0; line < lines; line++) {
            char command;
            cin >> command;
            if (command == 'F') {
                char variable;
                string x, y;
                cin >> variable >> x >> y;
                int id = variable - 'a';
                if (active[id] > 0)
                    error = true;
                active[id]++;
                int lower = x == "n" ? 1000 : stoi(x), upper = y == "n" ? 1000 : stoi(y);
                bool dead = lower > upper;
                bool contributes = blocked == 0 && !dead && x != "n" && y == "n";
                stack.push_back({id, dead, contributes});
                if (dead)
                    blocked++;
                if (contributes)
                    exponent++;
                maximum = max(maximum, exponent);
            } else {
                if (stack.empty()) {
                    error = true;
                    continue;
                }
                auto frame = stack.back();
                stack.pop_back();
                active[frame.variable]--;
                if (frame.dead)
                    blocked--;
                if (frame.contributes)
                    exponent--;
            }
        }
        if (!stack.empty())
            error = true;
        if (error)
            cout << "ERR\n";
        else
            cout << (maximum == expected ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

每行只进出一次栈，时间与栈空间均为 $O(L)$。

### 易错点

不会执行的代码仍可能有重复变量或括号配对错误，语法错误优先输出 ERR。变量只在对应 E 后销毁，后面的并列循环可重用。
