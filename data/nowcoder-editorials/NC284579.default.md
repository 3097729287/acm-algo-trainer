## 【模板】差分

### 题意

先进行所有区间加法，再一次性输出最终数组。

### 思路

令 d[i]=a[i]-a[i-1]，a[0]=0。给 [l,r] 加 x，只会使 d[l] 增加 x、d[r+1] 减少 x，区间内部相邻两项同时变化，差不变。所有操作记录完后，对 d 求前缀和即可还原结果。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    vector<long long> difference(n + 2);
    long long previous = 0;
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        difference[i] = x - previous;
        previous = x;
    }
    while (q--) {
        int l, r;
        long long x;
        cin >> l >> r >> x;
        difference[l] += x;
        difference[r + 1] -= x;
    }
    long long value = 0;
    for (int i = 1; i <= n; i++) {
        value += difference[i];
        if (i > 1)
            cout << ' ';
        cout << value;
    }
    return 0;
}
```

### 复杂度

时间 $O(n+q)$，空间 $O(n)$。

### 易错点

右端的反向标记在 r+1，不在 r。r=n 时仍可写 n+1，所以数组多留两格。叠加结果需要 long long。
