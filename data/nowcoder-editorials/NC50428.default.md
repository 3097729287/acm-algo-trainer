## 数星星 Stars

### 题意

按y再x升序给出星星，统计左下方点数的等级分布。

### 思路

输入顺序保证当前点左下方的点已经全部出现：y更小，或同y但x更小。用树状数组记录已出现的x频数，查询x以下含x的前缀和就是等级，给该等级的答案加1，然后把当前点插入。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    Fenwick bit(32002);
    vector<int> count(n);
    for (int i = 0; i < n; i++) {
        int x, y;
        cin >> x >> y;
        x++;
        count[bit.sum(x)]++;
        bit.add(x, 1);
    }
    for (int x : count)
        cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log U)$，空间 $O(U+n)$。

### 易错点

x可以为0，树状数组下标整体加1。同y的点也应按输入顺序立即插入，因为正左方包含在等级中。
