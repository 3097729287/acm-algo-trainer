## 【模板】双指针

### 题意

找出所有元素互异、长度达到全局最大的连续区间，按左端点排序输出。

### 思路

last[x] 保存数 x 上一次出现的位置。扫描右端点 right，若它的上次位置仍在当前区间内，就把 left 移到那个位置之后；其他元素本来互异，所以新区间重新合法，且是以 right 结尾的最长合法段。比当前最大长度更长就清空旧答案，等长则加入答案。右端点递增、长度相同，最终左端点也必递增。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> last(n + 1, 0);
    vector<pair<int, int>> answer;
    int left = 1, best = 0;
    for (int right = 1; right <= n; right++) {
        int x;
        cin >> x;
        left = max(left, last[x] + 1);
        last[x] = right;
        int length = right - left + 1;
        if (length > best) {
            best = length;
            answer.clear();
        }
        if (length == best)
            answer.push_back({left, right});
    }
    cout << answer.size() << '\n';
    for (auto [l, r] : answer)
        cout << l << ' ' << r << '\n';
    return 0;
}
```

### 复杂度

时间与空间均为 $O(n)$。

### 易错点

left 只能右移，不能无条件设成 last[x]+1。需要输出所有最长区间，不是只输出最大长度。
