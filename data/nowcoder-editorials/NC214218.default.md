## 涂小天与他的画

### 题意

每组给定奇数总高度 n，输出星号菱形。

### 思路

中间行为 n/2。第 i 行距离中间行 d=|i-n/2|，前导空格数为 d，星号数为 n-2d。逐行输出，不输出行末空格。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        for (int i = 0; i < n; i++) {
            int d = abs(i - n / 2);
            cout << string(d, ' ') << string(n - 2 * d, '*') << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2)$，临时空间 $O(n)$。

### 易错点

这里的 n 是总行数，与上下金字塔题中的半高含义不同。
