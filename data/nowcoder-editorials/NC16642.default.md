## [NOIP2007]Hanoi双塔问题

### 题意

把每种大小各两个的 n 层圆盘从 A 柱移到 C 柱，求最少移动次数。

### 思路

要移动最下面的两个最大盘，必须先把所有较小盘搬到另一根柱上，再用两步把最大盘移到目标柱，最后搬回小盘，得到 A[n]=2A[n-1]+2，A[0]=0。这个过程可以实现；反过来，在第一个最大盘离开起点和最后一个最大盘到达终点之间，小盘必须让出相应的柱子，因此不能少于这两次小盘转移与两次最大盘移动。递推也给出 A[n]=2^(n+1)-2。n 可达二百，直接用十进制数组反复乘二加二。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(1, 0);
    for (int i = 0; i < n; i++) {
        int carry = 2;
        for (int &digit : a) {
            int value = digit * 2 + carry;
            digit = value % 10;
            carry = value / 10;
        }
        while (carry) {
            a.push_back(carry % 10);
            carry /= 10;
        }
    }
    for (int i = (int)a.size() - 1; i >= 0; i--)
        cout << a[i];
    return 0;
}
```

### 复杂度

答案有 $O(n)$ 位，时间 $O(n^2)$，额外空间 $O(n)$。

### 易错点

同尺寸的两个盘允许叠放，且彼此不区分；不能按普通的 2n 个不同盘套 2^(2n)-1。数组最低位在前，输出时反向。
