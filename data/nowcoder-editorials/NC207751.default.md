## 牛牛的旅游纪念品

### 题意

恰选m个物品，任意两位置距离至少k，受欢迎度可为负，最大化总和。

### 思路

设dp[j][i]为前i个位置恰选j个的最优值。不选i转自dp[j][i−1]，选i转自dp[j−1][max(0,i−k)]+a[i]。j=0时所有前缀值为0，其他不可达状态设负无穷，避免负值物品被错误跳过。按j分层，仅保留上一层和本层数组。不同物品位置必须不同，故实现将间隔至少设为1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    k = max(k, 1);
    vector<long long> a(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    const long long neg = -(1LL << 60);
    vector<long long> previous(n + 1, 0), current(n + 1);
    for (int count = 1; count <= m; count++) {
        fill(current.begin(), current.end(), neg);
        for (int i = 1; i <= n; i++) {
            current[i] = current[i - 1];
            long long before = previous[max(0, i - k)];
            if (before != neg)
                current[i] = max(current[i], before + a[i]);
        }
        previous.swap(current);
    }
    cout << previous[n];
    return 0;
}
```

### 复杂度

时间 $O(nm)$，空间 $O(n)$。

### 易错点

要求恰好m个，不能把负收益都不选。选择i后，前一个可选位置最多是i−k，包括等号。
