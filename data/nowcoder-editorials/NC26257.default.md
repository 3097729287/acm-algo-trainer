## 小雨坐地铁

### 题意

地铁每次上线路付固定费，在线路内每走相邻一站付单位费，可换乘，求最便宜路线。

### 思路

把原站点当作“已下车”结点，给每个(线路,站点)新建一个车上结点。原站→车上结点权为该线路固定上车费，车上→原站权0；同线路相邻车上结点双向连每站费用b。这样可持续坐同一条线而不重复付上车费，换线则必须重新付对应费用。每站费用按线路站序算，不按原站编号差。扩展图规模与总线路站数线性，Dijkstra求原站s到t。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<long long> dijkstra(const vector<vector<pair<int, long long>>> &graph, int source) {
    const long long inf = 1LL << 60;
    vector<long long> distance(graph.size(), inf);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                   greater<pair<long long, int>>>
        heap;
    distance[source] = 0;
    heap.push({0, source});
    while (!heap.empty()) {
        auto [cost, u] = heap.top();
        heap.pop();
        if (cost != distance[u])
            continue;
        for (auto [v, w] : graph[u])
            if (distance[v] > cost + w) {
                distance[v] = cost + w;
                heap.push({distance[v], v});
            }
    }
    return distance;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, s, t;
    cin >> n >> m >> s >> t;
    vector<vector<pair<int, long long>>> graph(n);
    for (int line = 0; line < m; line++) {
        long long board, step;
        int count;
        cin >> board >> step >> count;
        int previous = -1;
        while (count--) {
            int station;
            cin >> station;
            --station;
            int node = graph.size();
            graph.emplace_back();
            graph[station].push_back({node, board});
            graph[node].push_back({station, 0});
            if (previous != -1) {
                graph[previous].push_back({node, step});
                graph[node].push_back({previous, step});
            }
            previous = node;
        }
    }
    auto d = dijkstra(graph, s - 1);
    cout << (d[t - 1] == (1LL << 60) ? -1 : d[t - 1]);
    return 0;
}
```

### 复杂度

总线路站数 $L$，时间 $O((n+L)\log(n+L))$，空间 $O(n+L)$。

### 易错点

固定费每次上车收，不是整趟行程只收一次。s=t可不乘车，答案0。
