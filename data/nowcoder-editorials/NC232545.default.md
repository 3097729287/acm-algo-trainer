## 三角碰撞(Triangle Collision)

### 题意

等边三角形内弹性反射，小球第k次撞边的时间。

### 思路

把每次反射改为把三角形沿边镜像展开，小球便始终沿原速度直线走。平面铺成等边三角网格，撞边对应穿越三族平行网格线。设H=√3L/2，三个归一化坐标为u=y/H、v=x/L+y/(√3L)+1/2、w=−x/L+y/(√3L)+1/2；它们各自等于整数时位于相应族网格线。

每个坐标都是a+b*t。若b<0先整体取反，使b为正，则t时刻前穿线数为floor(a+b*t)−floor(a)。三族相加就是撞击数，题目保证前k次没有顶点重合事件，故不重复计数。倍增时间上界，再二分最小使穿线数≥k的时间，避免逐次模拟百万次碰撞。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    cout << fixed << setprecision(12);
    while (tests--) {
        long double length, x, y, vx, vy;
        long long k;
        cin >> length >> x >> y >> vx >> vy >> k;
        long double root = sqrtl(3.0L);
        array<long double, 3> initial = {2 * y / (root * length),
                                         x / length + y / (root * length) + 0.5L,
                                         -x / length + y / (root * length) + 0.5L};
        array<long double, 3> speed = {2 * vy / (root * length), vx / length + vy / (root * length),
                                       -vx / length + vy / (root * length)};
        for (int i = 0; i < 3; i++)
            if (speed[i] < 0) {
                speed[i] = -speed[i];
                initial[i] = -initial[i];
            }
        auto count = [&](long double t) {
            long long result = 0;
            for (int i = 0; i < 3; i++)
                if (speed[i] > 0) {
                    long double value = floorl(initial[i] + speed[i] * t) - floorl(initial[i]);
                    if (value >= k)
                        return k;
                    result += (long long)value;
                    if (result >= k)
                        return k;
                }
            return result;
        };
        long double low = 0, high = 1;
        while (count(high) < k)
            high *= 2;
        for (int iteration = 0; iteration < 100; iteration++) {
            long double mid = (low + high) / 2;
            if (count(mid) >= k)
                high = mid;
            else
                low = mid;
        }
        cout << high << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log T+100)$，空间 $O(1)$。

### 易错点

横向撞线只是一族，必须加上两族斜线。小球半径10^−1000在此精度下按点处理；前k次无双边同时碰撞是计数前提。
