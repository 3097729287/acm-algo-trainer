## [HNOI2008]玩具装箱TOY

### 题意

连续玩具分箱，箱内相邻玩具间隔一单位，费用为箱长与L之差的平方，求最少费用。

### 思路

令S[i]=前i件玩具长度和+i，分界在j后时，该箱长度为S[i]−S[j]−1。记x=S[i]−L−1，则dp[i]=x²+min(dp[j]+S[j]²−2S[j]x)。每个已求出的j是一条斜率−2S[j]、截距dp[j]+S[j]²的直线。S严格增加，所以斜率递减、查询x递增，可用单调凸壳线性完成。

直线斜率按非增顺序加入，查询横坐标非减。维护下凸壳：新线使末尾两线的交点顺序逆转时，删除中间线，交点顺序用交叉乘积精确比较。斜率相同时只保留截距更小者。查询时若第二条线不劣于第一条，就弹掉第一条；随着横坐标变大，它也不会重新更优。每条线至多进出队一次。代码用128位处理中间乘积，避免平方及交点比较溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using Wide = __int128;
struct MonotoneHull {
    struct Line {
        Wide slope, intercept;
        Wide at(Wide x) const { return slope * x + intercept; }
    };
    deque<Line> lines;
    void add(Wide slope, Wide intercept) {
        Line line{slope, intercept};
        while (!lines.empty() && lines.back().slope == slope) {
            if (lines.back().intercept <= intercept)
                return;
            lines.pop_back();
        }
        while (lines.size() >= 2) {
            auto a = lines[lines.size() - 2], b = lines.back();
            if ((b.intercept - a.intercept) * (b.slope - line.slope) <
                (line.intercept - b.intercept) * (a.slope - b.slope))
                break;
            lines.pop_back();
        }
        lines.push_back(line);
    }
    Wide minimum(Wide x) {
        while (lines.size() >= 2 && lines[1].at(x) <= lines[0].at(x))
            lines.pop_front();
        return lines.front().at(x);
    }
};
void printWide(Wide value) {
    if (value < 0) {
        cout << '-';
        value = -value;
    }
    string digits;
    do {
        digits += char('0' + value % 10);
        value /= 10;
    } while (value);
    reverse(digits.begin(), digits.end());
    cout << digits;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long target;
    cin >> n >> target;
    MonotoneHull hull;
    hull.add(0, 0);
    Wide prefix = 0, best = 0;
    for (int i = 1; i <= n; i++) {
        long long length;
        cin >> length;
        prefix += length + 1;
        Wide x = prefix - target - 1;
        best = x * x + hull.minimum(x);
        hull.add(-2 * prefix, best + prefix * prefix);
    }
    printWide(best);
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(n)$。

### 易错点

相邻填充物数量为本箱玩具数减一，所以常数是L+1。即使最终费用能装64位，前缀平方和交叉乘积也可能超出，必须先转128位。
