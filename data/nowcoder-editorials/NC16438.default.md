## [NOIP2016]回文日期

### 题意

统计闭日期区间中，八位数字回文且日历上合法的日期。

### 思路

回文日期的后四位由年份唯一确定。枚举起止年份，反转四位年份得到 MMDD，拼回八位日期，检查是否在区间内。再检查月份一到十二、日期不超过对应月份天数，二月按公历闰年规则确定。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    int answer = 0;
    for (int year = a / 10000; year <= b / 10000; year++) {
        int reversed = 0, x = year;
        for (int i = 0; i < 4; i++) {
            reversed = reversed * 10 + x % 10;
            x /= 10;
        }
        int date = year * 10000 + reversed, month = reversed / 100, day = reversed % 100;
        if (date < a || date > b || month < 1 || month > 12)
            continue;
        int days[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0))
            days[2]++;
        if (day >= 1 && day <= days[month])
            answer++;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

设枚举年份数为 $Y$，时间 $O(Y)$，额外空间 $O(1)$。

### 易错点

数字回文不保证日期存在。反转必须处理恰好四位，产生的月日中允许有前导零。
