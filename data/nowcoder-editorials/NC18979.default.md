## 毒瘤xor

### 题意

每次查询选一个最小的非负 31 位整数 x，最大化区间内各数与 x 异或的总和。

### 思路

每个二进制位独立贡献。若该位原数组中零更多，令 x 的该位为一，就让更多结果位为一；若一更多，令 x 该位为零。两种数量相同则收益相同，为使 x 最小应选零。预处理每一位上一的前缀数量，每次查询在三十一位分别比较。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<int, 31>> prefix(n + 1);
    prefix[0].fill(0);
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        for (int b = 0; b <= 30; b++)
            prefix[i][b] = prefix[i - 1][b] + (x >> b & 1);
    }
    int q;
    cin >> q;
    while (q--) {
        int l, r;
        cin >> l >> r;
        long long answer = 0;
        for (int b = 0; b <= 30; b++) {
            int ones = prefix[r][b] - prefix[l - 1][b];
            if (2 * ones < r - l + 1)
                answer |= 1LL << b;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(31(n+q))$，空间 $O(31n)$。

### 易错点

即使 a[i] 小于 2^30，x 仍允许第 30 位为一；必须检查零到三十共三十一位。平票时选零。
