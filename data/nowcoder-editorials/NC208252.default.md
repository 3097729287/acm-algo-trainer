## 瘦了的牛牛去旅游

### 题意

多次查询DAG两点间最小平均边权。

### 思路

DAG路径至多n−1条边。对每个起点s，dp[k][v]表示恰走k条边到v的最短总长，按边数逐层沿所有边松弛。对每个终点枚举k=1..n−1，取dp[k][v]/k最小。这样无需对每个询问做浮点二分，预处理全部起终答案即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    struct Edge {
        int u, v, w;
    };
    vector<Edge> edge(m);
    for (auto &e : edge) {
        cin >> e.u >> e.v >> e.w;
        e.u--;
        e.v--;
    }
    const long long inf = LLONG_MAX / 4;
    vector<vector<long double>> answer(n, vector<long double>(n, 1e100L));
    for (int source = 0; source < n; source++) {
        vector<long long> previous(n, inf);
        previous[source] = 0;
        for (int count = 1; count < n; count++) {
            vector<long long> current(n, inf);
            for (auto e : edge)
                if (previous[e.u] < inf)
                    current[e.v] = min(current[e.v], previous[e.u] + e.w);
            for (int v = 0; v < n; v++)
                if (current[v] < inf)
                    answer[source][v] = min(answer[source][v], (long double)current[v] / count);
            previous.swap(current);
        }
    }
    int q;
    cin >> q;
    cout << fixed << setprecision(8);
    while (q--) {
        int u, v;
        cin >> u >> v;
        if (answer[u - 1][v - 1] > 1e90L)
            cout << "OMG!\n";
        else
            cout << answer[u - 1][v - 1] << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(n^2m+n^3)$，每问 $O(1)$，空间 $O(n^2+m)$。

### 易错点

0条边没有可定义的平均值，不把同点空路径当0。最短总长路径未必平均值最小。
