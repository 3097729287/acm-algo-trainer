## [NOIP1999]Cantor表

### 题意

沿 Cantor 表的斜对角线按 Z 字顺序，输出第 N 个分数。

### 思路

第 d 条对角线有 d 项，先不断减去整条长度，直到 N≤d，此时 N 是该条内部的一起始偏移。d 为偶数时分子从一递增，为奇数时分子从 d 递减，分子加分母总为 d+1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int diagonal = 1;
    while (n > diagonal) {
        n -= diagonal;
        diagonal++;
    }
    if (diagonal % 2 == 0)
        cout << n << '/' << diagonal - n + 1;
    else
        cout << diagonal - n + 1 << '/' << n;
    return 0;
}
```

### 复杂度

时间 $O(\sqrt N)$，额外空间 $O(1)$。

### 易错点

本题输出表格里的原分数，不需要约分。方向必须按第一条为 1/1、第二条为 1/2 到 2/1 核对。
