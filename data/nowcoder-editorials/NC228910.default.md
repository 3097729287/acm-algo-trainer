## Prime Distance

### 题意

在较大端点、较短区间内找最近和最远相邻素数对。

### 思路

先筛至sqrt(2^31−1)的素数。每组只开[R−L+1]标记，对每个p，从max(p²,ceil(L/p)*p)开始筛掉区间倍数；p²起步避免误删p自身。显式排除1，按升序扫描剩余素数并比较相邻距离。相等距离保持最先遇到者。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> sieve(int n) {
    vector<bool> composite(n + 1);
    vector<int> primes;
    for (int p = 2; p <= n; p++)
        if (!composite[p]) {
            primes.push_back(p);
            if (1LL * p * p <= n)
                for (int x = p * p; x <= n; x += p)
                    composite[x] = true;
        }
    return primes;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    auto primes = sieve(46341);
    int tests;
    cin >> tests;
    while (tests--) {
        long long l, r;
        cin >> l >> r;
        vector<bool> composite(r - l + 1);
        for (long long p : primes) {
            if (p * p > r)
                break;
            for (long long x = max(p * p, (l + p - 1) / p * p); x <= r; x += p)
                composite[x - l] = true;
        }
        if (l == 1)
            composite[0] = true;
        long long previous = -1, c1 = -1, c2 = -1, d1 = -1, d2 = -1, closest = LLONG_MAX,
                  distant = -1;
        for (long long x = l; x <= r; x++)
            if (!composite[x - l]) {
                if (previous != -1) {
                    long long gap = x - previous;
                    if (gap < closest) {
                        closest = gap;
                        c1 = previous;
                        c2 = x;
                    }
                    if (gap > distant) {
                        distant = gap;
                        d1 = previous;
                        d2 = x;
                    }
                }
                previous = x;
            }
        if (c1 == -1)
            cout << "There are no adjacent primes.\n";
        else
            cout << c1 << ',' << c2 << " are closest, " << d1 << ',' << d2
                 << " are most distant.\n";
    }
    return 0;
}
```

### 复杂度

每组 $O((R-L+1)\log\log R+\sqrt R)$，空间 $O(R-L+\sqrt R)$。

### 易错点

两端可能接近有符号32位上限，p²、起始倍数和扫描变量均用64位。
