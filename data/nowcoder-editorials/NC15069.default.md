## 守护白起

### 题意

n种颜色长度m的环，旋转和翻转等价，求不同方案数。

### 思路

对二面体群的2m种对称使用Burnside：答案为所有对称操作固定的着色数之和除以2m。旋转i格有gcd(i,m)个循环，贡献n^gcd(i,m)。按d=m/gcd(i,m)分组，旋转贡献Σ(d|m)phi(d)*n^(m/d)。

m为奇数时，每个翻转有1个不动点和(m−1)/2对位置，共m*n^((m+1)/2)。m为偶数时，一半翻转穿过两个位置，另一半穿过两条缝，贡献(m/2)*(n^(m/2+1)+n^(m/2))。最后乘(2m)的模逆元。预筛phi至10000，每组只枚举m的约数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000007;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int limit = 10000;
    vector<int> phi(limit + 1);
    iota(phi.begin(), phi.end(), 0);
    for (int p = 2; p <= limit; p++)
        if (phi[p] == p)
            for (int x = p; x <= limit; x += p)
                phi[x] = phi[x] / p * (p - 1);
    int tests;
    cin >> tests;
    while (tests--) {
        long long n, m;
        cin >> n >> m;
        long long sum = 0;
        auto addDivisor = [&](int d) { sum = (sum + phi[d] * power(n, m / d)) % mod; };
        for (int d = 1; d * d <= m; d++)
            if (m % d == 0) {
                addDivisor(d);
                if (d * d != m)
                    addDivisor(m / d);
            }
        if (m & 1)
            sum = (sum + m * power(n, (m + 1) / 2)) % mod;
        else
            sum = (sum + (m / 2) * ((power(n, m / 2) + power(n, m / 2 + 1)) % mod)) % mod;
        cout << sum * power(2 * m, mod - 2) % mod << '\n';
    }
    return 0;
}
```

### 复杂度

预筛 $O(U\log\log U)$；每组 $O(\sqrt m+\tau(m)\log m+\log P)$，空间 $O(U)$。

### 易错点

偶数长度的两类翻转不能合并成同一指数。m=1或2时，仍按群操作计重平均，公式照常成立。
