## 一个小问题

### 题意

十万条小模数同余约束，求最小非负共同解，无解输出负一。

### 思路

每个模数a小于十万，分解成互质的质数幂。x≡r mod a等价于对每个完整质数幂q都有x≡r mod q。对同一个质数，只保留目前最大的幂次约束；两个幂互相整除，用较小模数检查两个余数是否一致，不一致就无解。这一步先将十万条输入压缩成每个质数至多一条。

剩余模数两两互质，逐个做CRT。已有x≡answer mod M，新约束x≡r mod q，令x=answer+M*t，求t=(r−answer)*inverse(M mod q) mod q，再更新answer和M。使用Python任意精度，防止最终模数的最小公倍数远超64位。每次把t归一化后，answer自动处在[0,M)内。输出描述要求非负最小值，所以所有余数为0时输出0。

### 参考代码

```python
import sys

if hasattr(sys, 'set_int_max_str_digits'):
    sys.set_int_max_str_digits(0)


def inverse(a, mod):
    old_r, r = a, mod
    old_x, x = 1, 0
    while r:
        quotient = old_r // r
        old_r, r = r, old_r - quotient * r
        old_x, x = x, old_x - quotient * x
    return old_x % mod


data = list(map(int, sys.stdin.buffer.read().split()))
k = data[0]
bound = max(data[1::2], default=1)
smallest = [0] * (bound + 1)
for p in range(2, bound + 1):
    if smallest[p] == 0:
        for value in range(p, bound + 1, p):
            if smallest[value] == 0:
                smallest[value] = p

constraints = {}
valid = True
for i in range(k):
    a, residue = data[1 + 2 * i : 3 + 2 * i]
    while a > 1:
        p = smallest[a]
        power = 1
        while a % p == 0:
            a //= p
            power *= p
        remainder = residue % power
        old_power, old_remainder = constraints.get(p, (1, 0))
        if (remainder - old_remainder) % min(power, old_power):
            valid = False
        if power > old_power:
            constraints[p] = power, remainder

if not valid:
    print(-1)
else:
    answer, modulus = 0, 1
    for q, remainder in constraints.values():
        multiplier = (remainder - answer % q) * inverse(modulus % q, q) % q
        answer += modulus * multiplier
        modulus *= q
    print(answer)
```

### 复杂度

预筛上界 $U<10^5$，时间 $O(U\log\log U+k\log U)$ 加至多 $\pi(U)$ 次大整数CRT合并；空间 $O(U+k)$ 加最终大整数位数。

### 易错点

a不保证两两互质，不能对原模数直接套普通CRT。模数为1只约束余数0；相同质数的幂次只保留最强且兼容的一条。
