## Digital Deletions

### 题意

数字可减小，遇0可删该位及右侧，判断先手。

### 思路

最长6位，总共10+100+...+10^6种非空字符串，可全部预处理。按长度升序、同长按数值升序，每次操作都到更短或同长更小的状态，形成拓扑顺序。状态为固定长度下的数值，因此前导0不能丢失；用offset[len]+value编码。

若某位d>0，枚举降到0..d−1；若d=0，删除它和右侧，只留下左前缀。只要存在必败后继则当前必胜。空串为必败，因为上一手删空者已获胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    vector<string> query(tests);
    int maximum = 1;
    for (auto &s : query) {
        cin >> s;
        maximum = max(maximum, (int)s.size());
    }
    int power[7], offset[7];
    power[0] = 1;
    offset[0] = 0;
    for (int i = 1; i <= 6; i++) {
        power[i] = power[i - 1] * 10;
        offset[i] = offset[i - 1] + (i == 1 ? 1 : power[i - 1]);
    }
    vector<uint8_t> win(offset[maximum] + power[maximum]);
    for (int len = 1; len <= maximum; len++)
        for (int value = 0; value < power[len]; value++) {
            int id = offset[len] + value;
            for (int position = 0; position < len && !win[id]; position++) {
                int digit = value / power[position] % 10;
                if (!digit) {
                    int prefixLength = len - position - 1, prefix = value / power[position + 1];
                    if (!win[offset[prefixLength] + prefix])
                        win[id] = 1;
                } else
                    for (int smaller = 0; smaller < digit; smaller++)
                        if (!win[id - (digit - smaller) * power[position]]) {
                            win[id] = 1;
                            break;
                        }
            }
        }
    for (auto &s : query) {
        int value = stoi(s);
        cout << (win[offset[s.size()] + value] ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

最多S=1111110种非空状态，时间 $O(S\cdot6\cdot10+T)$，空间 $O(S+6T)$。

### 易错点

字符串00与0是不同局面，必须保存长度。删除0包括该0本身，不只是右侧。
