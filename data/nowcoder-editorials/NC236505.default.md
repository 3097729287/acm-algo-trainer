## Light of Stars

### 题意

相同角度区间光线照向其他星星，统计每个星星收到几次照射。

### 思路

角度从正x轴顺时针，且所有区间在[0,180)内。因此光源q一定在目标p的上方或同高。先计算Fθ(p)：向量p−q的顺时针角≤θ的光源数。0<θ<180时，这等价于q.y≥p.y，且sinθ*q.x+cosθ*q.y≤sinθ*p.x+cosθ*p.y。

按y降序扫描，先加入同y的所有光源，再用旋转投影值上的树状数组查前缀。求区间[l,r]时用F≤r−F<l，严格版本把upper_bound改为lower_bound。同一点不照射自身，≤查询减去自身，严格<查询天然排除自身。θ=0单独按同一行从左向右计数。

整数坐标能精确落在整数度数边界的非零向量，仅可能对应0、45、90、135度，分别用整数线性式处理，其他角使用long double。结果缓存相同端点的查询。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<pair<int, int>> p(n);
    for (auto &q : p)
        cin >> q.first >> q.second;
    vector<pair<int, int>> interval(k);
    for (auto &q : interval)
        cin >> q.first >> q.second;
    map<pair<int, bool>, vector<int>> cache;
    auto calculate = [&](int degree, bool strict) {
        vector<int> result(n);
        if (degree == 0) {
            if (strict)
                return result;
            vector<int> id(n);
            iota(id.begin(), id.end(), 0);
            sort(id.begin(), id.end(), [&](int a, int b) {
                return p[a].second != p[b].second ? p[a].second < p[b].second
                                                  : p[a].first < p[b].first;
            });
            int start = 0;
            for (int i = 0; i < n; i++) {
                if (i == 0 || p[id[i]].second != p[id[i - 1]].second)
                    start = i;
                result[id[i]] = i - start;
            }
            return result;
        }
        long double a = sinl(degree * acosl(-1.0L) / 180), b = cosl(degree * acosl(-1.0L) / 180);
        if (degree == 45) {
            a = 1;
            b = 1;
        }
        if (degree == 90) {
            a = 1;
            b = 0;
        }
        if (degree == 135) {
            a = 1;
            b = -1;
        }
        vector<long double> value(n), coordinate;
        vector<int> order(n);
        for (int i = 0; i < n; i++) {
            value[i] = a * p[i].first + b * p[i].second;
            order[i] = i;
        }
        coordinate = value;
        sort(coordinate.begin(), coordinate.end());
        coordinate.erase(unique(coordinate.begin(), coordinate.end()), coordinate.end());
        sort(order.begin(), order.end(), [&](int x, int y) { return p[x].second > p[y].second; });
        vector<int> bit(coordinate.size() + 1);
        auto add = [&](int at) {
            for (; at < (int)bit.size(); at += at & -at)
                bit[at]++;
        };
        for (int i = 0; i < n;) {
            int j = i;
            while (j < n && p[order[j]].second == p[order[i]].second) {
                int id = order[j++];
                add(lower_bound(coordinate.begin(), coordinate.end(), value[id]) -
                    coordinate.begin() + 1);
            }
            for (int at = i; at < j; at++) {
                int id = order[at],
                    rank = (strict ? lower_bound(coordinate.begin(), coordinate.end(), value[id])
                                   : upper_bound(coordinate.begin(), coordinate.end(), value[id])) -
                           coordinate.begin();
                int count = 0;
                for (; rank; rank -= rank & -rank)
                    count += bit[rank];
                result[id] = count - !strict;
            }
            i = j;
        }
        return result;
    };
    vector<long long> answer(n);
    for (auto [l, r] : interval) {
        for (auto [angle, strict, sign] : {tuple<int, bool, int>{r, false, 1}, {l, true, -1}}) {
            auto key = make_pair(angle, strict);
            if (!cache.count(key))
                cache[key] = calculate(angle, strict);
            for (int i = 0; i < n; i++)
                answer[i] += sign * cache[key][i];
        }
    }
    for (auto x : answer)
        cout << x << ' ';
    return 0;
}
```

### 复杂度

时间 $O(kn\log n)$，缓存空间 $O(kn)$。

### 易错点

输入是顺时针角，不能沿用常见逆时针极角。边界包含，左端必须减严格小于l的数量。各光区互不相交，最终可直接求和。
