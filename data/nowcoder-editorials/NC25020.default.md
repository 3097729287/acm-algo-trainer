## Cow Hurdles

### 题意

有向图多次查询，使路径最大障碍高度最小，不可达输出负一。

### 思路

将Floyd的加法换成取最大：经过中间点k的瓶颈为max(d[i][k],d[k][j])，再与原d[i][j]取最小。初始直接边取其高度，重边保留较小者，自己到自己为0。三重循环后得到所有最小瓶颈路径。不可达用无穷，自然不会改善正常值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, q;
    cin >> n >> m >> q;
    const int inf = 1000000000;
    vector<vector<int>> d(n, vector<int>(n, inf));
    for (int i = 0; i < n; i++)
        d[i][i] = 0;
    while (m--) {
        int a, b, w;
        cin >> a >> b >> w;
        --a;
        --b;
        d[a][b] = min(d[a][b], w);
    }
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                d[i][j] = min(d[i][j], max(d[i][k], d[k][j]));
    while (q--) {
        int a, b;
        cin >> a >> b;
        int answer = d[a - 1][b - 1];
        cout << (answer == inf ? -1 : answer) << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(N^3+T)$，空间 $O(N^2)$。

### 易错点

边是单向的。目标是最大障碍的高度，不是沿途高度之和。Floyd中间点k必须放最外层。
