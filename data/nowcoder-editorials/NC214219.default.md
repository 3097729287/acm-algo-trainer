## 黑大火与他的猫

### 题意

按给定顺序尝试购买猫粮，买得起就买，买不起跳过，统计购买种数。

### 思路

题目已经规定了购买决策，没有自由选择空间。维护剩余金额 money，遇到 price≤money 时扣款并增加计数，否则只继续读取下一项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int money, m;
        cin >> money >> m;
        int ans = 0;
        for (int i = 0; i < m; i++) {
            int p;
            cin >> p;
            if (p <= money) {
                money -= p;
                ans++;
            }
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(M)$，额外空间 $O(1)$。

### 易错点

不能按价格排序，也不能遇到买不起的猫粮就结束。
