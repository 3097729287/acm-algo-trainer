## 小H的询问

### 题意

单点修改，查询相邻奇偶交替的最大非空子段和。

### 思路

每段记录首尾奇偶、总和、整段是否交替、最大非空前缀/后缀/子段和。合并左右时，只有左尾与右首奇偶不同，才允许跨界连接。前缀向右延伸还要求左段整体交替，后缀同理。最大子段取左右答案，若可连接再与左最大后缀+右最大前缀比较。查询也按原顺序用相同合并函数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    long long sum = 0, prefix = 0, suffix = 0, best = LLONG_MIN;
    int left = 0, right = 0;
    bool all = true, empty = true;
};
Node mergeNode(const Node &a, const Node &b) {
    if (a.empty)
        return b;
    if (b.empty)
        return a;
    Node c;
    c.empty = false;
    c.left = a.left;
    c.right = b.right;
    bool join = a.right != b.left;
    c.sum = a.sum + b.sum;
    c.all = a.all && b.all && join;
    c.prefix = a.prefix;
    if (a.all && join)
        c.prefix = max(c.prefix, a.sum + b.prefix);
    c.suffix = b.suffix;
    if (b.all && join)
        c.suffix = max(c.suffix, b.sum + a.suffix);
    c.best = max(a.best, b.best);
    if (join)
        c.best = max(c.best, a.suffix + b.prefix);
    return c;
}
Node leaf(long long x) {
    Node a;
    a.empty = false;
    a.sum = a.prefix = a.suffix = a.best = x;
    a.left = a.right = (x % 2 + 2) % 2;
    return a;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    int size = 1;
    while (size < n)
        size <<= 1;
    vector<Node> tree(size * 2);
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        tree[size + i] = leaf(x);
    }
    for (int u = size - 1; u; u--)
        tree[u] = mergeNode(tree[u * 2], tree[u * 2 + 1]);
    while (m--) {
        int op, x;
        long long y;
        cin >> op >> x >> y;
        if (op == 1) {
            int p = size + x - 1;
            tree[p] = leaf(y);
            for (p >>= 1; p; p >>= 1)
                tree[p] = mergeNode(tree[p * 2], tree[p * 2 + 1]);
        } else {
            int l = size + x - 1, r = size + (int)y;
            Node left, right;
            for (; l < r; l >>= 1, r >>= 1) {
                if (l & 1)
                    left = mergeNode(left, tree[l++]);
                if (r & 1)
                    right = mergeNode(tree[--r], right);
            }
            cout << mergeNode(left, right).best << '\n';
        }
    }
    return 0;
}
```

### 复杂度

构建 $O(n)$，每次操作 $O(\log n)$，空间 $O(n)$。

### 易错点

不能允许空子段，否则全负区间会错误输出0。负数奇偶使用规范化余数；左右合并不可交换。
