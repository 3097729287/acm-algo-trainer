## DongDong认亲戚

### 题意

按姓名合并亲戚关系并查询连通性，重名视为同一个人。

### 思路

先把不同姓名映射到整数编号，重复姓名复用原编号。亲戚关系满足传递性，因此每个家族是一个并查集集合；类型一合并，类型二比较根。按集合大小合并并压缩路径。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    map<string, int> id;
    int count = 0;
    for (int i = 0; i < n; i++) {
        string name;
        cin >> name;
        if (!id.count(name))
            id[name] = ++count;
    }
    DSU dsu(count);
    while (m--) {
        int type;
        string a, b;
        cin >> type >> a >> b;
        if (type == 1)
            dsu.unite(id.at(a), id.at(b));
        else
            cout << (dsu.find(id.at(a)) == dsu.find(id.at(b))) << '\n';
    }
    return 0;
}
```

### 复杂度

映射使用平衡树，时间 $O((n+m)\log n)$，空间 $O(n)$。

### 易错点

两条相同姓名记录不能分配不同结点；查询不新增关系。
