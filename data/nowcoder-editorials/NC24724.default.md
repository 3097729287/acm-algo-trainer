## [USACO 2010 Feb S]Chocolate Eating

### 题意

顺序吃巧克力，隔夜快乐减半，最大化 d 天结束时的最低快乐并给出吃法。

### 思路

二分每天最低值 target。判定时按天模拟，先将上一天快乐减半，再按原顺序吃到至少 target 就停，把未必需要的巧克力留到以后。提前多吃只会让它的贡献在夜晚减半，延后到真正需要时不会更差，所以这种最晚食用的贪心判定充分。若巧克力耗尽仍不足就失败。目标越小越容易，二分上界可取全部快乐总和。最后按最优值重跑并记录食用日期；剩余巧克力全部放在末日，保证每块都有安排，也不会降低最低值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, days;
    cin >> n >> days;
    vector<long long> a(n);
    long long total = 0;
    for (auto &x : a) {
        cin >> x;
        total += x;
    }
    vector<int> plan(n);
    auto possible = [&](long long target, bool record) {
        long long happiness = 0;
        int next = 0;
        for (int day = 1; day <= days; day++) {
            happiness /= 2;
            while (happiness < target && next < n) {
                happiness += a[next];
                if (record)
                    plan[next] = day;
                next++;
            }
            if (happiness < target)
                return false;
        }
        if (record)
            while (next < n)
                plan[next++] = days;
        return true;
    };
    long long low = 0, high = total;
    while (low < high) {
        long long mid = low + (high - low + 1) / 2;
        if (possible(mid, false))
            low = mid;
        else
            high = mid - 1;
    }
    possible(low, true);
    cout << low << '\n';
    for (int day : plan)
        cout << day << '\n';
    return 0;
}
```

### 复杂度

总快乐为 $H$，时间 $O((n+d)\log(H+1))$，空间 $O(n)$。

### 易错点

同一天可以吃零块或多块。隔夜减半必须向下取整；日程应保持原巧克力顺序，任意最优日程均可。
