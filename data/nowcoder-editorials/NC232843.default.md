## Amphiphilic Carbon Molecules

### 题意

用直线分两种分子到不同侧，线上的两种都可溶解，最大正确分类数。

### 思路

最优分界线可平移至经过一个粒子而不损失已溶解粒子，枚举该枢轴。把另一种颜色的相对向量反向，则“颜色0在一侧、颜色1在另一侧”统一成所有向量落在同一闭半平面。极角排序，双指针找角跨度≤π的最多向量，再加枢轴同坐标粒子数。

闭半平面允许两条反向边界射线，正好体现分界线上的所有粒子都溶解。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    const long double pi = acosl(-1.0L);
    while (cin >> n && n) {
        vector<Point> p(n);
        vector<int> color(n);
        for (int i = 0; i < n; i++)
            cin >> p[i].x >> p[i].y >> color[i];
        int answer = 0;
        for (int origin = 0; origin < n; origin++) {
            vector<long double> angle;
            int same = 0;
            for (int i = 0; i < n; i++) {
                Point v = p[i] - p[origin];
                if (v.x == 0 && v.y == 0) {
                    same++;
                    continue;
                }
                if (color[i])
                    v = v * (-1);
                angle.push_back(atan2l(v.y, v.x));
            }
            sort(angle.begin(), angle.end());
            int m = angle.size();
            for (int i = 0; i < m; i++)
                angle.push_back(angle[i] + 2 * pi);
            answer = max(answer, same);
            int right = 0;
            for (int left = 0; left < m; left++) {
                right = max(right, left);
                while (right < left + m && angle[right] - angle[left] <= pi + 1e-15L)
                    right++;
                answer = max(answer, same + right - left);
            }
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n²\log n)$，空间 $O(n)$。

### 易错点

同一坐标粒子在枢轴上都计入，包括不同颜色。向量反向依据粒子自身颜色，不依赖枢轴颜色。
