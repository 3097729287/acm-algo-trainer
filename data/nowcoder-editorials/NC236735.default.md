## [POI2010]ANT-Antisymmetry

### 题意

统计反转并零一取反后保持不变的非空子串。

### 思路

反对称串不可能为奇数长度，因为中心字符无法与自身取反后相同。对所有位置 i，把原二进制字符异或 i 的奇偶性，得到 t[i]。偶长度子串中任意一对镜像下标奇偶性相反，所以原字符不同，当且仅当变换后的字符相同。因此原串的反对称子串，恰好对应变换串的偶长度回文。求 Manacher 的偶半径并求和即可，每个半径的一到其最大值各对应一个不同位置的子串。

Manacher 的 odd[i] 表示以 i 为中心、包含中心的最大奇回文半径，长度为 2odd[i]-1；even[i] 表示中心在 i-1 与 i 之间的最大偶回文半径，长度为 2even[i]。维护已知最靠右的回文区间，利用镜像位置的半径初始化，再只向未知部分扩展。右边界只会前进，全部扩展次数为线性。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct PalindromeRadii {
    vector<int> odd, even;
    explicit PalindromeRadii(const string &s) {
        int n = s.size();
        odd.resize(n);
        even.resize(n);
        int left = 0, right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 1 : min(odd[left + right - i], right - i + 1);
            while (i - k >= 0 && i + k < n && s[i - k] == s[i + k])
                k++;
            odd[i] = k;
            if (i + k - 1 > right) {
                left = i - k + 1;
                right = i + k - 1;
            }
        }
        left = 0;
        right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 0 : min(even[left + right - i + 1], right - i + 1);
            while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k])
                k++;
            even[i] = k;
            if (i + k - 1 > right) {
                left = i - k;
                right = i + k - 1;
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string s;
    cin >> n >> s;
    for (int i = 0; i < n; i++)
        s[i] = char('0' + ((s[i] - '0') ^ (i & 1)));
    PalindromeRadii radius(s);
    cout << accumulate(radius.even.begin(), radius.even.end(), 0LL);
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

只累计偶回文半径，不能加入奇回文。即使内容相同，只要起止位置不同也分别计数，答案需要 long long。
