## [NOIP2002]过河卒

### 题意

卒只能向下或向右，避开马自身和八个攻击点，统计到目标的路径。

### 思路

先标记马自身及八种日字跳的位置，只保留棋盘内点。dp[x][y]为到该点的路径数：禁点为0，其余由左和上相加。原点若未被控制，初始化为1。逐行逐列递增处理，依赖都已求出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, x, y;
    cin >> n >> m >> x >> y;
    vector<vector<bool>> blocked(n + 1, vector<bool>(m + 1));
    int dx[] = {0, 1, 1, -1, -1, 2, 2, -2, -2}, dy[] = {0, 2, -2, 2, -2, 1, -1, 1, -1};
    for (int k = 0; k < 9; k++) {
        int a = x + dx[k], b = y + dy[k];
        if (a >= 0 && a <= n && b >= 0 && b <= m)
            blocked[a][b] = true;
    }
    vector<vector<long long>> dp(n + 1, vector<long long>(m + 1));
    if (!blocked[0][0])
        dp[0][0] = 1;
    for (int i = 0; i <= n; i++)
        for (int j = 0; j <= m; j++)
            if (!blocked[i][j] && (i || j)) {
                if (i)
                    dp[i][j] += dp[i - 1][j];
                if (j)
                    dp[i][j] += dp[i][j - 1];
            }
    cout << dp[n][m];
    return 0;
}
```

### 复杂度

时间、空间均为 $O(nm)$。

### 易错点

棋盘包含坐标0，大小应开到n+1、m+1。路径数超过32位，用64位。
