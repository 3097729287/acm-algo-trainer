## 迁徙过程中的河流

### 题意

两人一船，每次耗时取较慢者，船必须随人返回，求所有人过河最少总时间。

### 思路

排序t1≤t2≤…。每次把最慢两人x、y永久送到对岸，有两种标准最优方式：最快两人先过、t1返回、x和y过、t2返回，代价t1+2t2+y；或t1分别带y、x过去并返回两次，代价2t1+x+y。取较小者，剩下问题规模减二。交换论证可把所有承担返回的人替成最快者或次快者，最后运送最慢两人的阶段便落入这两类。余下1人取t1，2人取t2，3人取t1+t2+t3。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> t(n);
    for (auto &x : t)
        cin >> x;
    sort(t.begin(), t.end());
    long long answer = 0;
    int remaining = n;
    while (remaining > 3) {
        answer +=
            min(t[0] + 2 * t[1] + t[remaining - 1], 2 * t[0] + t[remaining - 2] + t[remaining - 1]);
        remaining -= 2;
    }
    if (remaining == 3)
        answer += t[0] + t[1] + t[2];
    else if (remaining == 2)
        answer += t[1];
    else if (remaining == 1)
        answer += t[0];
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

船不能自己回来。最慢两人同船未必最优，必须比较两种搬运策略。总时间用64位。
