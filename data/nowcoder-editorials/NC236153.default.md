## Georgia and Bob

### 题意

棋子只能向左、不越子，判断胜负。

### 思路

排序后从右向左两两配对，每对之间的空格数视为一堆Nim；若棋子数奇数，最左棋子与左边界0配成一对。每对右棋子左移可任意减少这一堆。每对左棋子左移会增大配对间隔，对方可让对应右棋子同移，恢复间隔；标准配对策略给出这些间隔异或为0恰为必败态。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        vector<int> a(n);
        for (int &x : a)
            cin >> x;
        sort(a.begin(), a.end());
        if (n % 2)
            a.insert(a.begin(), 0);
        int total = 0;
        for (int i = 1; i < (int)a.size(); i += 2)
            total ^= a[i] - a[i - 1] - 1;
        cout << (total ? "Georgia will win\n" : "Bob will win\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

配对从右端确定，奇数个时补0在最左，不能漏掉最左棋子到边界的间隔。
