## 小w的糖果

### 题意

后缀分别加1、连续整数或连续平方，输出最终各点值。

### 思路

把每次贡献写成位置i的多项式。类型1为1；类型2为i+(1−pos)；类型3为i²+2(1−pos)i+(1−pos)²。每轮只从pos开始生效，所以在pos累加三个系数的差分，扫描i时累积当前系数A、B、C，答案即A*i²+B*i+C，模P计算。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    const long long mod = 1000000007;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        vector<array<long long, 3>> event(n + 1);
        while (m--) {
            int type, pos;
            cin >> type >> pos;
            long long shift = 1LL - pos;
            if (type == 1)
                event[pos][0]++;
            else if (type == 2) {
                event[pos][0] += shift;
                event[pos][1]++;
            } else {
                event[pos][0] += shift * shift;
                event[pos][1] += 2 * shift;
                event[pos][2]++;
            }
        }
        array<long long, 3> coefficient = {0, 0, 0};
        for (long long i = 1; i <= n; i++) {
            for (int d = 0; d < 3; d++)
                coefficient[d] = (coefficient[d] + event[i][d]) % mod;
            long long answer =
                (coefficient[2] * i % mod * i + coefficient[1] * i + coefficient[0]) % mod;
            if (answer < 0)
                answer += mod;
            cout << answer << (i == n ? '\n' : ' ');
        }
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n+m)$，空间 $O(n)$。

### 易错点

每轮从pos处贡献1，不是pos或pos²，必须使用i−pos+1。负系数取模后最终规范到非负。
