## Game

### 题意

双方轮流将一个数拆成两个大于一的因数，无数可拆时当前玩家输，问败者。

### 思路

设 n 分解质因数后共有 c 个因子，重数也计入。每次拆分让集合元素数增加一，最终必然恰好是这 c 个质因子，所以总操作数固定为 c-1，策略不会改变奇偶性。c≥二且为偶数时先手完成最后一步，败者是 Johnson；否则败者是 Nancy。n=1 时也无合法操作。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int count = 0;
    for (int p = 2; p <= n / p; p++)
        while (n % p == 0) {
            n /= p;
            count++;
        }
    if (n > 1)
        count++;
    cout << (count >= 2 && count % 2 == 0 ? "Johnson" : "Nancy");
    return 0;
}
```

### 复杂度

时间 $O(\sqrt n)$，额外空间 $O(1)$。

### 易错点

质因子要按重数计数；输出的是败者而不是胜者。
