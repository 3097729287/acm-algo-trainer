## [NOIP2012]Vigenère 密码

### 题意

给定循环密钥与 Vigenère 密文，恢复保留大小写的原文。

### 思路

密钥字母忽略大小写，映射为零到二十五的位移。密文的同一位置减去密钥位移，再加二十六取余得到原文字母序号；原文字母的大小写沿用密文，密钥下标对密钥长度取余。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string key, cipher;
    cin >> key >> cipher;
    for (size_t i = 0; i < cipher.size(); i++) {
        char base = isupper(static_cast<unsigned char>(cipher[i])) ? 'A' : 'a';
        int shift = tolower(static_cast<unsigned char>(key[i % key.size()])) - 'a';
        cout << char(base + (cipher[i] - base - shift + 26) % 26);
    }
    return 0;
}
```

### 复杂度

时间 $O(|密文|)$，输入字符串空间 $O(|密钥|+|密文|)$。

### 易错点

输入第二行是密文，要减密钥位移；直接加位移会再次加密。
