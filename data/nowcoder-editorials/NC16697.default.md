## [NOIP2001]Car的旅行路线

### 题意

各城四机场构成矩形，城内铁路与跨城飞机单价不同，从起点城任意机场到终点城任意机场求最便宜。

### 思路

每城已给三个矩形顶点，找到三点中直角点p，其余为q、r，则第四点为q+r−p。直角用点积等于0判定，整数坐标可精确判断。将每个机场当结点，同城两机场边费为欧氏距离乘本城铁路单价，异城边费为距离乘飞机单价。

最多400点，直接用稠密Dijkstra，初始起点城四机场距离均为0。每次选最小未定点后，枚举全部机场计算直达费用并松弛，允许经过第三座城市或多次换乘。终点四机场取最小，保留一位小数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int cities, start, target;
        long double flight;
        cin >> cities >> flight >> start >> target;
        --start;
        --target;
        vector<array<long long, 2>> point(4 * cities);
        vector<long double> rail(cities);
        for (int city = 0; city < cities; city++) {
            array<array<long long, 2>, 3> p;
            for (auto &v : p)
                cin >> v[0] >> v[1];
            cin >> rail[city];
            int right = 0;
            for (int i = 0; i < 3; i++) {
                int j = (i + 1) % 3, k = (i + 2) % 3;
                __int128 dot = (__int128)(p[j][0] - p[i][0]) * (p[k][0] - p[i][0]) +
                               (__int128)(p[j][1] - p[i][1]) * (p[k][1] - p[i][1]);
                if (dot == 0)
                    right = i;
            }
            for (int i = 0; i < 3; i++)
                point[4 * city + i] = p[i];
            for (int axis = 0; axis < 2; axis++)
                point[4 * city + 3][axis] =
                    p[(right + 1) % 3][axis] + p[(right + 2) % 3][axis] - p[right][axis];
        }
        int n = 4 * cities;
        vector<long double> d(n, 1e100L);
        vector<bool> done(n);
        for (int i = 0; i < 4; i++)
            d[4 * start + i] = 0;
        for (int step = 0; step < n; step++) {
            int u = -1;
            for (int v = 0; v < n; v++)
                if (!done[v] && (u == -1 || d[v] < d[u]))
                    u = v;
            done[u] = true;
            for (int v = 0; v < n; v++)
                if (!done[v]) {
                    long double dx = (long double)point[u][0] - point[v][0],
                                dy = (long double)point[u][1] - point[v][1];
                    long double cost = hypotl(dx, dy) * (u / 4 == v / 4 ? rail[u / 4] : flight);
                    d[v] = min(d[v], d[u] + cost);
                }
        }
        cout << fixed << setprecision(1)
             << *min_element(d.begin() + 4 * target, d.begin() + 4 * target + 4) << '\n';
    }
    return 0;
}
```

### 复杂度

每组机场数 $V=4S$，时间 $O(V^2)$，空间 $O(V)$。

### 易错点

三个输入机场的顺序任意，不能把第一个直接认作直角点。同城铁路也可能通过别城绕行更便宜，完整图最短路会自动比较。
