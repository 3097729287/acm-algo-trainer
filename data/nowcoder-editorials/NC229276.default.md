## Bus Number

### 题意

每种已见数字实际至少一次、至多出现次数，不允许前导0，统计车号。

### 思路

对每种出现过的数字d，枚举实际次数1..count[d]；未出现数字次数只能0。固定次数c[d]、长度L时，排列数为L!/Πc[d]!。若c[0]>0，减去前导0固定后的(L−1)!/((c[0]−1)!*Π(d>0)c[d]!)。累加全部次数选择。

输入长度至19，阶乘19!仍在64位范围内；可选频次组合数量由总位数限制，远小于10^19。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    array<int, 10> count = {}, chosen = {};
    for (char c : s)
        count[c - '0']++;
    unsigned long long factorial[20];
    factorial[0] = 1;
    for (int i = 1; i < 20; i++)
        factorial[i] = factorial[i - 1] * i;
    unsigned long long answer = 0;
    auto dfs = [&](auto &&self, int digit, int length) -> void {
        if (digit == 10) {
            unsigned long long all = factorial[length];
            for (int c : chosen)
                all /= factorial[c];
            if (chosen[0]) {
                unsigned long long bad = factorial[length - 1];
                for (int d = 0; d < 10; d++)
                    bad /= factorial[chosen[d] - (d == 0)];
                all -= bad;
            }
            answer += all;
            return;
        }
        int start = count[digit] ? 1 : 0;
        for (int c = start; c <= count[digit]; c++) {
            chosen[digit] = c;
            self(self, digit + 1, length + c);
        }
    };
    dfs(dfs, 0, 0);
    cout << answer;
    return 0;
}
```

### 复杂度

设频次组合数S=Π(max(1,count[d]))，时间 $O(10S)$，空间 $O(10+|s|)$。

### 易错点

不能完全删掉任何一种已出现数码，包括0。重复数码不可区分，需除以各频次阶乘。
