## 二分

### 题意

猜数回复可能错误，找最多同时正确的回复数。

### 思路

将每条回复变为目标整数的可行区间：“+”是目标≤v−1，“−”是目标≥v+1，“.”是目标=v。扫描目标值时，所有“+”先计入初始覆盖；在v处将它减1。“−”在v+1处加1；“.”在v处加1、v+1处减1。用有序map合并同坐标事件，扫描取最大覆盖数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    map<long long, int> event;
    int current = 0;
    while (n--) {
        long long v;
        char op;
        cin >> v >> op;
        if (op == '+') {
            current++;
            event[v]--;
        } else if (op == '-')
            event[v + 1]++;
        else {
            event[v]++;
            event[v + 1]--;
        }
    }
    int answer = current;
    for (auto [position, delta] : event) {
        current += delta;
        answer = max(answer, current);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

比较是严格不等，整数目标需使用v−1或v+1边界。同坐标事件先合并再计最大，避免制造不存在的区间。
