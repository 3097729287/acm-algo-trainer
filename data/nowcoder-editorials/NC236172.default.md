## 货船

### 题意

十万件货物，容量十万，求最大可装总重量。

### 思路

用位集possible表示可达到的重量集合，初始仅0。加入重量w时possible |= possible<<w，移位后的每一位对应在旧方案上选当前货物；整条位集一次更新，避免O(nA)逐状态。重量>A的货物无法选，直接忽略。最后从A向下找第一个置位。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, capacity;
    cin >> n >> capacity;
    bitset<100001> possible;
    possible[0] = 1;
    while (n--) {
        int w;
        cin >> w;
        if (w <= capacity)
            possible |= possible << w;
    }
    for (int x = capacity; x >= 0; x--)
        if (possible[x]) {
            cout << x;
            break;
        }
    return 0;
}
```

### 复杂度

时间 $O(nU/机器字长+U)$，空间 $O(U/机器字长)$，U=100000。

### 易错点

每件只有一份，右侧移位基于操作前位集，不能改成完全背包。bitset上界覆盖题目最大容量。
