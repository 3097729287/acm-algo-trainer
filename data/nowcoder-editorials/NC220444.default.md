## Mr. Main and Windmills

### 题意

沿线坐火车，问某风车第k次与别风车交换视角顺序时的位置。

### 思路

两个风车在视角中交换顺序，当且仅当观察者经过它们连线与火车路线的交点。对每对风车求交点在S+t(T−S)上的参数t，只保留0<t<1的事件，分别加入两个风车事件表，排序后第k项就是答案。所有风车在路线同侧，避免经过观察方向反面等额外顺序变化；无三点共线保证同一风车的交换时刻不重合。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    Point start, finish;
    cin >> start.x >> start.y >> finish.x >> finish.y;
    Point direction = finish - start;
    vector<Point> point(n);
    for (auto &p : point)
        cin >> p.x >> p.y;
    vector<vector<long double>> event(n);
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++) {
            Point edge = point[j] - point[i];
            long double denominator = cross(direction, edge);
            if (fabsl(denominator) < EPS)
                continue;
            long double t = cross(point[i] - start, edge) / denominator;
            if (t > 0 && t < 1) {
                event[i].push_back(t);
                event[j].push_back(t);
            }
        }
    for (auto &row : event)
        sort(row.begin(), row.end());
    cout << fixed << setprecision(12);
    while (m--) {
        int h, k;
        cin >> h >> k;
        h--;
        if (k > (int)event[h].size())
            cout << -1 << '\n';
        else {
            Point answer = start + direction * event[h][k - 1];
            cout << answer.x << ' ' << answer.y << '\n';
        }
    }
    return 0;
}
```

### 复杂度

时间 $O(n²\log n+m)$，空间 $O(n²)$。

### 易错点

直线交点必须位于实际行程线段内。平行风车连线不会交换顺序。
