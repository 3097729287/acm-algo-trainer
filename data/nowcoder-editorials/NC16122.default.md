## 郊区春游

### 题意

只需游览给定的R个地点，起终点自选，求总路费最少的顺序。

### 思路

先用Floyd求任意两点最短路，旅途中可以经过不在必游清单的地点。再对R≤15个必游点做子集DP：dp[mask][last]为已按某顺序游览mask并停在last的最少费用，转移追加一个未游点，加两者最短路费用。任一点都可以作为第一站，单点初值0，答案为全体集合的任意末站最小值，不需回到起点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, r;
    cin >> n >> m >> r;
    vector<int> target(r);
    for (int &x : target) {
        cin >> x;
        x--;
    }
    const long long inf = 1LL << 60;
    vector<vector<long long>> distance(n, vector<long long>(n, inf));
    for (int i = 0; i < n; i++)
        distance[i][i] = 0;
    while (m--) {
        int a, b;
        long long w;
        cin >> a >> b >> w;
        --a;
        --b;
        distance[a][b] = distance[b][a] = min(distance[a][b], w);
    }
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (distance[i][k] != inf && distance[k][j] != inf)
                    distance[i][j] = min(distance[i][j], distance[i][k] + distance[k][j]);
    vector<vector<long long>> dp(1 << r, vector<long long>(r, inf));
    for (int i = 0; i < r; i++)
        dp[1 << i][i] = 0;
    for (int mask = 1; mask < (1 << r); mask++)
        for (int last = 0; last < r; last++)
            if (dp[mask][last] != inf)
                for (int next = 0; next < r; next++)
                    if (!(mask >> next & 1) && distance[target[last]][target[next]] != inf)
                        dp[mask | (1 << next)][next] =
                            min(dp[mask | (1 << next)][next],
                                dp[mask][last] + distance[target[last]][target[next]]);
    long long answer = *min_element(dp.back().begin(), dp.back().end());
    cout << (answer == inf ? -1 : answer);
    return 0;
}
```

### 复杂度

时间 $O(n^3+R^2 2^R)$，空间 $O(n^2+R2^R)$。

### 易错点

学校到第一站、最后一站回学校不用计费，因此初始所有单点为0，终态无需闭环。不能只在原图必游点之间的直接边上做TSP。
