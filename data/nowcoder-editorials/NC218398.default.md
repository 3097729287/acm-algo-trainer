## 小G的约数

### 题意

G(n)为前n个数约数和之和，求G(G(n))。

### 思路

每个约数d对其floor(n/d)个倍数贡献d，所以G(n)=Σd*floor(n/d)。整除分块后，每段商q固定，贡献q*(l+r)*(r−l+1)/2。先求一次G(n)，再对这个结果求同样的函数。n≤50000时第二次参数约2×10^9，结果仍在64位内。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    auto sumDivisors = [](long long n) {
        long long answer = 0;
        for (long long l = 1, r; l <= n; l = r + 1) {
            long long quotient = n / l;
            r = n / quotient;
            long long count = r - l + 1, ends = l + r;
            if (count % 2 == 0)
                count /= 2;
            else
                ends /= 2;
            answer += quotient * count * ends;
        }
        return answer;
    };
    long long n;
    cin >> n;
    cout << sumDivisors(sumDivisors(n));
    return 0;
}
```

### 复杂度

时间 $O(\sqrt n+\sqrt{G(n)})$，空间 $O(1)$。

### 易错点

先把等差求和的偶数因子除2，再乘商，降低中间乘积。不要混成约数个数函数。
