## [HAOI2016]放棋子

### 题意

每行每列各有一个障碍，放n个棋子且每行每列一个，求精确方案数。

### 思路

障碍在每行、每列各出现一次，所以它们本身是一个排列。重新排列列号，让第i行障碍位于第i列，不改变合法方案数。问题便是求没有任何固定点的排列数D[n]。

看第1行选中列j≠1，有n−1种。若第j行选列1，剩下是D[n−2]；否则把第j行对列1的选择改记为对列j的选择，得到n−1个元素的错排，数量D[n−1]。于是D[n]=(n−1)*(D[n−1]+D[n−2])，D[0]=1、D[1]=0。题目没有取模，使用Python大整数。

### 参考代码

```python
import sys

values = list(map(int, sys.stdin.buffer.read().split()))
n = values[0]
previous, current = 1, 0
if n == 0:
    print(1)
else:
    for length in range(2, n + 1):
        previous, current = current, (length - 1) * (current + previous)
    print(current)
```

### 复杂度

读矩阵 $O(n^2)$；递推 $O(n)$ 次大整数运算，保存输入 $O(n^2)$。

### 易错点

矩阵需要读入，但答案仅取决于n，因为题目保证障碍在不同行、不同列。不要把精确答案取模或存入64位整数。
