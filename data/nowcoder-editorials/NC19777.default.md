## 卡牌游戏

### 题意

N种卡中M种稀有，已抽过的稀有从池中移除，求集齐K种的期望次数。

### 思路

已收集i种稀有时，抽卡池剩N−i种，稀有剩M−i种，下一次获得新稀有的概率为(M−i)/(N−i)。几何分布等待次数期望是其倒数，所以总期望Σ(i=0..K−1)(N−i)/(M−i)。普通卡会重复，不能从抽卡池删掉。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    cout << fixed << setprecision(10);
    for (int tc = 1; tc <= tests; tc++) {
        int n, m, k;
        cin >> n >> m >> k;
        long double answer = 0;
        for (int i = 0; i < k; i++)
            answer += (long double)(n - i) / (m - i);
        cout << "Case #" << tc << ": " << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(K)$，空间 $O(1)$。

### 易错点

分母随已收集稀有卡数量变化，分子也变化；不是固定池的优惠券模型。
