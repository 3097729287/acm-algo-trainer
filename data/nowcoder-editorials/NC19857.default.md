## 最后的晚餐(dinner)

### 题意

n对情侣围圆桌而坐，任何一对不相邻，旋转视为相同，n至三千万。

### 思路

n≥2时，容斥选k对必须相邻，把每对合成块并考虑两种方向，得到c[n]=Σ(-2)^k*C(n,k)*(2n−k−1)!。直接算组合数会使用大数组，下面把此式化为常数空间递推。

同时定义直线排列计数l[n]=Σ(-2)^k*C(n,k)*(2n−k)!。为推导，记q=t(t−2)，用∫₀∞e^(−t)t^r dt=r!将两式分别写成c[n]=∫e^(−t)q^n/t、l[n]=∫e^(−t)q^n。对q^n及t*q^n分部积分，令B[n]=∫e^(−t)t*q^n，得到l[n]=2n*(B[n−1]−l[n−1])、B[n]=(2n+1)l[n]+2n*B[n−1]。再用c[n]=B[n−1]−2l[n−1]消去B，便有：

l[n]=2n*(c[n]+l[n−1])；c[n+1]=4n²*c[n]+2n(2n+1)*l[n−1]。

从形式容斥值c[1]=−1、l[0]=1开始滚动。c[1]只是递推初值；真实n=1仅两个人，必然相邻，答案单独输出0。每步都在模数下计算系数，再乘旧状态。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    if (n == 1) {
        cout << 0;
        return 0;
    }
    constexpr long long mod = 1000000007;
    long long circle = mod - 1, previousLine = 1;
    for (long long i = 1; i < n; i++) {
        long long coefficientA = (4 * i % mod) * i % mod;
        long long coefficientB = (2 * i % mod) * ((2 * i + 1) % mod) % mod;
        long long nextCircle = (coefficientA * circle + coefficientB * previousLine) % mod;
        long long line = (2 * i % mod) * ((circle + previousLine) % mod) % mod;
        circle = nextCircle;
        previousLine = line;
    }
    cout << circle;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

圆桌只把旋转视为相同，镜像仍不同。初值−1是代数辅助量，不是n=1的实际方案数。4n²先取模，再乘状态，避免溢出。
