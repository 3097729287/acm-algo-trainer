## 华华开始学信息学

### 题意

给所有D倍数位置加K，询问区间和。

### 思路

按D大小分治。D≤B时，只累积small[D]，询问时该更新在[L,R]中的贡献是small[D]*(floor(R/D)−floor((L−1)/D))。D>B时，倍数至多N/B个，逐点加进树状数组；询问再加树状数组区间和。两类更新相互独立，可直接相加。代码取B约为sqrt(N log N)，平衡小D询问与大D逐点修改。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    int boundary = max(1, (int)sqrt(n * max(1.0, log2(n + 1.0))));
    boundary = min(boundary, n);
    vector<long long> small(boundary + 1);
    Fenwick bit(n);
    while (m--) {
        int op, l;
        long long r;
        cin >> op >> l >> r;
        if (op == 1) {
            if (l <= boundary)
                small[l] += r;
            else
                for (int p = l; p <= n; p += l)
                    bit.add(p, r);
        } else {
            long long answer = bit.sum((int)r) - bit.sum(l - 1);
            for (int d = 1; d <= boundary; d++)
                answer += small[d] * (r / d - (l - 1) / d);
            cout << answer << '\n';
        }
    }
    return 0;
}
```

### 复杂度

修改最坏 $O((N/B)\log N)$，询问 $O(B+\log N)$，空间 $O(N+B)$。

### 易错点

多次小D更新要累加，不能覆盖。K至10^8、操作十万次，权值及区间和均用64位。
