## [NOIP2005]过河

### 题意

青蛙每跳S到T整数距离，终点可越过，最少踩多少石子，桥长可达十亿。

### 思路

若S=T，落点固定为S的倍数，直接数这些位置的石子。否则S与S+1都允许。任意q≥S(S−1)都能表示成若干个S与S+1之和：取q模S个S+1，余下是非负个S。

用这一性质压缩无石子长间隙。考虑间隙前最近T个位置的DP值，最小值为v。从达到v的那个位置先跳T，便落在间隙中；之后再利用上面的表示式，可以在间隙内走到足够远的任一点。经过至少S(S−1)+2T−1个无石子位置后，最近T个位置均能取得v，也不可能小于v，后面再延长空白就不会改变DP窗口。S<T≤10时这个界至多91，因此相邻事件距离大于100时截成100完全保留窗口信息。

排序石子及终点，将每段距离截到100，做普通DP：f[x]=min(f[x−jump])+此处是否有石子。最终在压缩终点到终点+T−1的落点中取最小，允许跳过桥端。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long length;
    int s, t, m;
    cin >> length >> s >> t >> m;
    vector<long long> stones(m);
    for (auto &x : stones)
        cin >> x;
    sort(stones.begin(), stones.end());
    if (s == t) {
        int answer = 0;
        for (long long x : stones)
            answer += x % s == 0;
        cout << answer;
        return 0;
    }
    long long previous = 0;
    int compressed = 0;
    vector<int> marks;
    for (long long x : stones) {
        compressed += min<long long>(100, x - previous);
        marks.push_back(compressed);
        previous = x;
    }
    int target = compressed + min<long long>(100, length - previous), limit = target + t - 1;
    vector<int> stone(limit + 1), dp(limit + 1, 1000000);
    for (int x : marks)
        stone[x] = 1;
    dp[0] = 0;
    for (int x = 1; x <= limit; x++) {
        for (int jump = s; jump <= t && jump <= x; jump++)
            dp[x] = min(dp[x], dp[x - jump] + stone[x]);
    }
    cout << *min_element(dp.begin() + target, dp.end());
    return 0;
}
```

### 复杂度

压缩长度 $L_c\le100(M+1)+T$，时间 $O(M\log M+L_cT)$，空间 $O(L_c)$。

### 易错点

S=T时不存在相位混合，不能使用同样的截距压缩。终点不要求恰好落到L，答案需包含越过L的至多T−1个位置。
