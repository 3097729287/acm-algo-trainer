## Directory Traversal

### 题意

选择起始文件夹，使访问全部文件的相对路径字符串长度总和最小。

### 思路

先从顶层向下，统计每个子树文件数count和从该目录出发访问其子树全部文件的路径长度。走进孩子目录v，会给其全部文件多加len(name[v])+1字符（含斜杠）；孩子是文件则只加文件名长度。根的初始总代价因此可自底向上求得。

把起始目录从u移到孩子目录v：v子树内每个文件都省去name[v]/，共减count[v]*(len[v]+1)；外部文件都要多走../，共加(总文件数−count[v])*3。这个换根式常数时间得到每个目录的全局代价，文件不能作为起始目录。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> children(n);
    vector<int> length(n);
    for (int u = 0; u < n; u++) {
        string name;
        int m;
        cin >> name >> m;
        length[u] = name.size();
        while (m--) {
            int v;
            cin >> v;
            children[u].push_back(v - 1);
        }
    }
    vector<int> order{0};
    for (size_t i = 0; i < order.size(); i++)
        for (int v : children[order[i]])
            order.push_back(v);
    vector<long long> files(n), inside(n), total(n);
    for (int i = n - 1; i >= 0; i--) {
        int u = order[i];
        if (children[u].empty())
            files[u] = 1;
        else
            for (int v : children[u]) {
                files[u] += files[v];
                inside[u] += inside[v] + files[v] * (length[v] + !children[v].empty());
            }
    }
    total[0] = inside[0];
    long long answer = total[0];
    for (int u : order)
        if (!children[u].empty()) {
            answer = min(answer, total[u]);
            for (int v : children[u])
                if (!children[v].empty())
                    total[v] = total[u] - files[v] * (length[v] + 1) + (files[0] - files[v]) * 3;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

根目录本身的名字不计入相对路径。文件名后没有斜杠，目录名后有；../固定3字符。总长度用64位。
