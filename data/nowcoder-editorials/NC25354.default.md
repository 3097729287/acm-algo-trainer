## 愉快的递推式

### 题意

f[n]=3f[n−1]+2f[n−2]+2，求第n项。

### 思路

把常数1也放入状态列向量[f[i],f[i−1],1]，一步转移矩阵为[[3,2,2],[1,0,0],[0,0,1]]。从i=2的状态[1,1,1]出发，乘矩阵的n−2次幂即可。二进制快速幂遇到1位时直接把矩阵作用到当前向量。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using Matrix = vector<vector<long long>>;
constexpr long long MOD = 1000000007;
Matrix multiply(const Matrix &a, const Matrix &b) {
    int n = a.size();
    Matrix result(n, vector<long long>(n));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++)
            if (a[i][k])
                for (int j = 0; j < n; j++)
                    result[i][j] = (result[i][j] + a[i][k] * b[k][j]) % MOD;
    return result;
}
vector<long long> applyMatrix(const Matrix &a, const vector<long long> &v) {
    int n = a.size();
    vector<long long> result(n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            result[i] = (result[i] + a[i][j] * v[j]) % MOD;
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    unsigned long long n;
    cin >> n;
    if (n <= 2) {
        cout << 1;
        return 0;
    }
    Matrix transition = {{3, 2, 2}, {1, 0, 0}, {0, 0, 1}};
    vector<long long> state = {1, 1, 1};
    n -= 2;
    while (n) {
        if (n & 1)
            state = applyMatrix(transition, state);
        transition = multiply(transition, transition);
        n >>= 1;
    }
    cout << state[0];
    return 0;
}
```

### 复杂度

时间 $O(3^3\log n)$，空间 $O(3^2)$。

### 易错点

常数项2应乘状态中的1。初始状态是第2项，指数为n−2。
