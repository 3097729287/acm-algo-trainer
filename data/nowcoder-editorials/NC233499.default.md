## 葫芦和斌斌的字符串1

### 题意

找同时为前后缀且在整串中至少出现 k 次的最长非空串。

### 思路

对 S 求前缀函数。长度 len 的前缀的全部 border，沿 len→pi[len-1] 这条链依次出现。把每个前缀长度初始计数设为一，表示它自己在相应末尾的那次出现；按长度从大到小，把 count[len] 加到 count[pi[len-1]]，即可统计所有前缀的出现次数，包含重叠。最后从完整长度 n 开始沿 border 链回退，首个次数至少 k 的长度就是答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

template <class Sequence> vector<int> prefixFunction(const Sequence &s) {
    int n = s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])
            j = pi[j - 1];
        if (s[i] == s[j])
            j++;
        pi[i] = j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    string s;
    cin >> n >> k >> s;
    auto pi = prefixFunction(s);
    vector<int> count(n + 1, 1);
    count[0] = 0;
    for (int length = n; length > 0; length--)
        count[pi[length - 1]] += count[length];
    int length = n;
    while (length > 0 && count[length] < k)
        length = pi[length - 1];
    if (length == 0)
        cout << -1;
    else
        cout << s.substr(0, length);
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

本题不要求是真 border，所以 k=1 时可以直接选完整字符串。重叠出现也计数；只检查最长真 border 会漏掉更短但次数足够的候选。
