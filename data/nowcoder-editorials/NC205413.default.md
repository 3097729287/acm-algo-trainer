## L1-2 单位换算

### 题意

将整数英尺换算为毫米，有小数时只保留一位，不输出多余零。

### 思路

一英尺是 304.8 毫米，用整数 t=3048N 表示毫米的十分之一。先输出 t/10；如果 t%10 非零，再输出小数点和这一位，完全避免浮点格式问题。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int t = 3048 * n;
    cout << t / 10;
    if (t % 10 != 0)
        cout << '.' << t % 10;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

整毫米时不能带 .0，N=0 时输出零。
