## 方格取数

### 题意

从左上到右下取数两次，允许两路重合，但同一格数字只取一次。

### 思路

将两次行走同步，状态为(step,r1,r2)，列号由行列和step确定。每人上一状态来自上方或左方，枚举四种前驱，取最大再加当前两格的值。若两人此时在同一格，只加一次。所有可能重合都发生在同一步，因此无需保存访问集合。初态包括左上数字，终态包括右下数字一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long twoPaths(const vector<vector<int>> &a, bool disjoint) {
    int rows = a.size(), cols = a[0].size();
    if (disjoint && (rows == 1 || cols == 1))
        return 0;
    const long long neg = -(1LL << 60);
    vector<vector<long long>> dp(rows, vector<long long>(rows, neg)), next = dp;
    dp[0][0] = a[0][0];
    for (int step = 1; step <= rows + cols - 2; step++) {
        for (auto &row : next)
            fill(row.begin(), row.end(), neg);
        int low = max(0, step - cols + 1), high = min(rows - 1, step);
        for (int r1 = low; r1 <= high; r1++)
            for (int r2 = low; r2 <= high; r2++) {
                if (disjoint && r1 == r2 && step != rows + cols - 2)
                    continue;
                long long previous = neg;
                for (int d1 = 0; d1 <= 1; d1++)
                    for (int d2 = 0; d2 <= 1; d2++)
                        if (r1 >= d1 && r2 >= d2)
                            previous = max(previous, dp[r1 - d1][r2 - d2]);
                if (previous == neg)
                    continue;
                long long gain = a[r1][step - r1];
                if (r1 != r2)
                    gain += a[r2][step - r2];
                next[r1][r2] = previous + gain;
            }
        dp.swap(next);
    }
    return dp[rows - 1][rows - 1];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    int r, c, value;
    while (cin >> r && r != 0) {
        cin >> c >> value;
        a[r - 1][c - 1] = value;
    }
    cout << twoPaths(a, false);
    return 0;
}
```

### 复杂度

时间 $O(n^3)$，空间 $O(n^2)$。

### 易错点

本题允许重合，区别于纸条中间人只能帮助一次；重合位置扣掉重复计分即可。输入结束可能是一行0或0 0 0，按第一个0结束读取。
