## 温度转换

### 题意

用华氏温度计算摄氏温度，保留三位小数。

### 思路

直接代入 c=5(f-32)/9。用 5.0/9.0 保证比例是浮点数，华氏温度小于三十二时输出负数也正常。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    double f;
    cin >> f;
    cout << fixed << setprecision(3) << 5.0 / 9.0 * (f - 32);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

整数表达式 5/9 等于零，不能这样写比例。
