## 任务

### 题意

机器时间等级都不低于任务要求，最大任务数并最大报酬。

### 思路

任务按所需时间从大到小、同时间按等级从大到小处理；机器按可用时间降序。处理任务时，把时间足够的未用机器加入等级频数表，选择等级≥要求的最小等级机器。这样给当前任务留够能力，又保留高等级机器。时间每增1带来的500收益大于等级全部范围差的20收益，因此降序任务也对应优先较高报酬。

交换论证：可行分配若使用更强等级机器完成当前任务，可与贪心的较弱机器交换；若当前任务原本没被选，换掉其占用机器上的后续任务，任务数不减、报酬不降。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<pair<int, int>> machine(n), task(m);
    for (auto &[x, y] : machine)
        cin >> x >> y;
    for (auto &[x, y] : task)
        cin >> x >> y;
    sort(machine.rbegin(), machine.rend());
    sort(task.rbegin(), task.rend());
    array<int, 11> count = {};
    int p = 0, completed = 0;
    long long reward = 0;
    for (auto [time, level] : task) {
        while (p < n && machine[p].first >= time)
            count[machine[p++].second]++;
        for (int y = level; y <= 10; y++)
            if (count[y]) {
                count[y]--;
                completed++;
                reward += 500LL * time + 2 * level;
                break;
            }
    }
    cout << completed << ' ' << reward;
    return 0;
}
```

### 复杂度

时间 $O(n\log n+m\log m+11m)$，空间 $O(n+m)$。

### 易错点

每台机器至多一项任务；同所需时间时先安排等级高、收益也高的任务。
