## 诡异数字

### 题意

每个非零数字连续出现次数受上限约束，多组统计模20020219。

### 思路

同一个数字可能给出多条限制，取最小上限。状态为位置、上一数字、当前连续次数、是否已经开始、贴界。前导0不形成数码段；开始后遇同数字连续长度加1，换数字则重置1，超上限直接跳过。未限制数码把上限设19，0保证无限制。全程未开始代表整数0，应计入。每个测试重建与自身限制对应的缓存。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    const int mod = 20020219;
    while (tests--) {
        long long l, r;
        int n;
        cin >> l >> r >> n;
        array<int, 10> limit;
        limit.fill(19);
        while (n--) {
            int x, len;
            cin >> x >> len;
            limit[x] = min(limit[x], len);
        }
        auto count = [&](long long bound) {
            if (bound < 0)
                return 0;
            string s = to_string(bound);
            int memo[20][11][20];
            memset(memo, -1, sizeof(memo));
            auto dfs = [&](auto &&self, int p, int previous, int run, bool tight) -> int {
                if (p == (int)s.size())
                    return 1;
                int &cache = memo[s.size() - p][previous][run];
                if (!tight && cache != -1)
                    return cache;
                int maximum = tight ? s[p] - '0' : 9;
                long long result = 0;
                for (int d = 0; d <= maximum; d++) {
                    if (previous == 10 && d == 0)
                        result += self(self, p + 1, 10, 0, tight && d == maximum);
                    else {
                        int next = previous == d ? run + 1 : 1;
                        if (next <= limit[d])
                            result += self(self, p + 1, d, next, tight && d == maximum);
                    }
                }
                int value = result % mod;
                if (!tight)
                    cache = value;
                return value;
            };
            return dfs(dfs, 0, 10, 0, true);
        };
        cout << (count(r) - count(l - 1) + mod) % mod << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(D\cdot11\cdot D\cdot10)$，空间 $O(11D^2)$，D≤19。

### 易错点

限制“不能大于len”允许恰好len次；重复约束取较严者。整数0不是前导0产生的多位串。
