## [HNOI2004]宠物收养所

### 题意

宠物与领养人依次到来，异类按最近特点值匹配，同差优先较小值，累计不满意度。

### 思路

任意时刻等待者只会是一种类型。用 multiset 保存他们的特点值：新来者同类就加入；异类就找 lower_bound(x)，它是第一个不小于 x 的候选，再检查其前驱。最接近的值只可能是这两个，距离相同时取较小的前驱。配对后从集合中删掉被匹配的一项，累计距离并对一百万取模。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    multiset<long long> waiting;
    int kind = -1;
    long long answer = 0;
    while (n--) {
        int type;
        long long x;
        cin >> type >> x;
        if (waiting.empty() || type == kind) {
            kind = type;
            waiting.insert(x);
            continue;
        }
        auto right = waiting.lower_bound(x), chosen = right;
        if (right == waiting.end())
            chosen = prev(right);
        else if (right != waiting.begin()) {
            auto left = prev(right);
            if (x - *left <= *right - x)
                chosen = left;
        }
        answer = (answer + llabs(x - *chosen)) % 1000000;
        waiting.erase(chosen);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

同差时选较小特点值。集合为空时重新设置等待类型；没有配对的人或宠物不产生费用。
