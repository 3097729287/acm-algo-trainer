## 计算带余除法

### 题意

同时计算整数商和余数。

### 思路

整数除法 a/b 得到商，取余 a%b 得到余数。按商在前、余数在后的顺序，用空格连接输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    cout << a / b << ' ' << a % b;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不能把两个结果交换，也不用手工通过小数部分计算余数。
