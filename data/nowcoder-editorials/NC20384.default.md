## [SDOI2016]征途

### 题意

将连续路段分成恰好m天，最小化日路程方差，输出方差乘m²。

### 思路

设总长S，m天路程为d[t]，方差乘m²等于m*Σd[t]²−S²，因此只需最小化每日路程平方和。用前缀和P，分层DP：new[i]=P[i]²+min(old[j]+P[j]²−2P[i]P[j])，j<i且j≥当前天数−1。每层重新建凸壳，直线斜率−2P[j]、截距old[j]+P[j]²，横坐标为P[i]。先查询再把j=i的旧层状态加入，确保每段至少有一个原路段。

直线斜率按非增顺序加入，查询横坐标非减。维护下凸壳：新线使末尾两线的交点顺序逆转时，删除中间线，交点顺序用交叉乘积精确比较。斜率相同时只保留截距更小者。查询时若第二条线不劣于第一条，就弹掉第一条；随着横坐标变大，它也不会重新更优。每条线至多进出队一次。代码用128位处理中间乘积，避免平方及交点比较溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using Wide = __int128;
struct MonotoneHull {
    struct Line {
        Wide slope, intercept;
        Wide at(Wide x) const { return slope * x + intercept; }
    };
    deque<Line> lines;
    void add(Wide slope, Wide intercept) {
        Line line{slope, intercept};
        while (!lines.empty() && lines.back().slope == slope) {
            if (lines.back().intercept <= intercept)
                return;
            lines.pop_back();
        }
        while (lines.size() >= 2) {
            auto a = lines[lines.size() - 2], b = lines.back();
            if ((b.intercept - a.intercept) * (b.slope - line.slope) <
                (line.intercept - b.intercept) * (a.slope - b.slope))
                break;
            lines.pop_back();
        }
        lines.push_back(line);
    }
    Wide minimum(Wide x) {
        while (lines.size() >= 2 && lines[1].at(x) <= lines[0].at(x))
            lines.pop_front();
        return lines.front().at(x);
    }
};
void printWide(Wide value) {
    if (value < 0) {
        cout << '-';
        value = -value;
    }
    string digits;
    do {
        digits += char('0' + value % 10);
        value /= 10;
    } while (value);
    reverse(digits.begin(), digits.end());
    cout << digits;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, days;
    cin >> n >> days;
    vector<Wide> prefix(n + 1);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
    }
    const Wide inf = Wide(1) << 120;
    vector<Wide> previous(n + 1, inf), current(n + 1);
    previous[0] = 0;
    for (int day = 1; day <= days; day++) {
        fill(current.begin(), current.end(), inf);
        MonotoneHull hull;
        int initial = day - 1;
        hull.add(-2 * prefix[initial], previous[initial] + prefix[initial] * prefix[initial]);
        for (int i = day; i <= n; i++) {
            current[i] = prefix[i] * prefix[i] + hull.minimum(prefix[i]);
            if (previous[i] != inf)
                hull.add(-2 * prefix[i], previous[i] + prefix[i] * prefix[i]);
        }
        previous.swap(current);
    }
    printWide(days * previous[n] - prefix[n] * prefix[n]);
    return 0;
}
```

### 复杂度

时间 $O(mn)$，空间 $O(n)$。

### 易错点

不能漏乘m或误输出普通方差。每一层只用旧层值建线；费用与坐标取128位，避免上界或乘积影响比较。
