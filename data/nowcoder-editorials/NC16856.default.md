## [NOI1999]钉子和小球

### 题意

三角钉板中部分钉子被拔掉，求小球落入指定槽的精确既约分数。

### 思路

以2^n为共同分母，把概率表示为整数份数，顶点初始有2^n份。有钉子时各一半落到下一行的左、右结点；钉子被拔时，球竖直经过下一行两钉之间，直接落到下下行中间结点，全部份数传过去。最多碰n次钉子，所以整数份数每次除二都是精确的。最后取槽位的份数，与2^n求最大公约数约分。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, target;
    cin >> n >> target;
    vector<vector<char>> peg(n);
    for (int i = 0; i < n; i++) {
        peg[i].resize(i + 1);
        for (char &c : peg[i])
            cin >> c;
    }
    vector<vector<long long>> ways(n + 2, vector<long long>(n + 2));
    long long denominator = 1LL << n;
    ways[0][0] = denominator;
    for (int i = 0; i < n; i++)
        for (int j = 0; j <= i; j++) {
            if (peg[i][j] == '*') {
                ways[i + 1][j] += ways[i][j] / 2;
                ways[i + 1][j + 1] += ways[i][j] / 2;
            } else
                ways[i + 2][j + 1] += ways[i][j];
        }
    long long numerator = ways[n][target], divisor = gcd(numerator, denominator);
    cout << numerator / divisor << '/' << denominator / divisor;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n^2)$。

### 易错点

拔掉钉子是跳两行，不是向下一行传给某一边。读取字符会自动跳过任意空白，最后一行保证有钉子。
