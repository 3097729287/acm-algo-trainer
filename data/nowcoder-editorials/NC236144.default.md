## Deleting Divisors

### 题意

整数减去非1非自身约数，无法操作者输。

### 思路

奇数n的合法约数也是奇数，减后为带奇因子>1的偶数；后者总能减去其奇因子，走回奇数。因此所有奇数均必败，所有含奇因子的偶数必胜。

剩下n=2^r。减去2^s，若s≤r−2，结果含奇因子>1，属于必胜态；只有减半能走到另一纯2幂2^(r−1)。n=2无合法约数必败，所以r奇数必败、r偶数必胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        unsigned n;
        cin >> n;
        bool alice = false;
        if (n % 2 == 0) {
            if ((n & (n - 1)) != 0)
                alice = true;
            else
                alice = __builtin_ctz(n) % 2 == 0;
        }
        cout << (alice ? "Alice\n" : "Bob\n");
    }
    return 0;
}
```

### 复杂度

每组时间、空间均 $O(1)$。

### 易错点

1和素数都无合法操作。纯2幂需要看指数奇偶，不能一概判偶数胜。
