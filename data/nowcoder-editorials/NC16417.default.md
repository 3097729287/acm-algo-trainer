## [NOIP2017]奶酪

### 题意

同半径球形空洞相交或相切即可通行，判断能否从奶酪底面到顶面。

### 思路

增加底面和顶面两个虚拟结点。球心高度 z≤r 时连到底面，z+r≥h 时连到顶面；任意两球心距离平方不超过4r²时合并。所有合并完成后比较两虚拟结点是否同根。距离只比较平方，不用开根号。坐标差最多二十亿，三个平方的和可能超过64位，用128位做距离计算。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        long long h, r;
        cin >> n >> h >> r;
        vector<array<long long, 3>> p(n);
        DSU dsu(n + 1);
        int bottom = n, top = n + 1;
        for (int i = 0; i < n; i++) {
            cin >> p[i][0] >> p[i][1] >> p[i][2];
            if (p[i][2] <= r)
                dsu.unite(i, bottom);
            if (p[i][2] + r >= h)
                dsu.unite(i, top);
            for (int j = 0; j < i; j++) {
                __int128 distance = 0;
                for (int axis = 0; axis < 3; axis++) {
                    __int128 d = p[i][axis] - p[j][axis];
                    distance += d * d;
                }
                if (distance <= (__int128)4 * r * r)
                    dsu.unite(i, j);
            }
        }
        cout << (dsu.find(bottom) == dsu.find(top) ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2\alpha(n))$，空间 $O(n)$。

### 易错点

相切也允许，所以使用≤。每组重新初始化；先转128位再乘，避免乘法已溢出后才转换。
