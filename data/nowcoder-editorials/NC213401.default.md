## F 课程满意度计算

### 题意

求所有受访学生都喜欢的课程数量。

### 思路

为每门课程记录被多少名学生喜欢。每名学生的列表只贡献一次，全部读取后，计数等于 N 的课程恰好属于所有学生的交集。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> count(m + 1);
    for (int i = 0; i < n; i++) {
        int k;
        cin >> k;
        vector<bool> seen(m + 1);
        while (k--) {
            int x;
            cin >> x;
            if (!seen[x]) {
                seen[x] = true;
                count[x]++;
            }
        }
    }
    int ans = 0;
    for (int x = 1; x <= m; x++)
        if (count[x] == n)
            ans++;
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(NM)$，额外空间 $O(M)$。

### 易错点

某名学生喜欢零门课时结果必为零。统计的是课程种数，不是喜欢次数之和。
