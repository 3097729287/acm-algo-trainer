## 四舍五入

### 题意

最多四舍五入 t 次，每次只能处理小数部分，求最大的最终数并去除小数尾零。

### 思路

先找小数部分最靠左的至少为五的数字。直接在这里舍入，比先处理更右位置更有利。删去该位及其右侧，将前一位加一；若前一位变成五且还有机会，继续向左舍入。由于起点已经是最靠左的五以上数字，其左边小数位原来都不超过四，向左传递时不会遇到小数九的长进位；只有进到整数部分时，单独处理整数进位并结束。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long t;
    string s;
    cin >> n >> t >> s;
    int dot = s.find('.');
    if (dot < 0) {
        cout << s;
        return 0;
    }
    int p = dot + 1;
    while (p < (int)s.size() && s[p] < '5')
        p++;
    int cut = s.size();
    while (p < (int)s.size() && p > dot && s[p] >= '5' && t > 0) {
        t--;
        cut = p;
        if (p == dot + 1) {
            s.resize(dot);
            int j = (int)s.size() - 1;
            while (j >= 0 && s[j] == '9') {
                s[j] = '0';
                j--;
            }
            if (j >= 0)
                s[j]++;
            else
                s.insert(s.begin(), '1');
            cout << s;
            return 0;
        }
        s[p - 1]++;
        p--;
    }
    s.resize(cut);
    while (!s.empty() && s.back() == '0')
        s.pop_back();
    if (!s.empty() && s.back() == '.')
        s.pop_back();
    cout << s;
    return 0;
}
```

### 复杂度

每个字符最多向左处理一次，时间与字符串空间均为 $O(n)$，不按可能十亿次的 t 循环。

### 易错点

每次舍入只耗一次机会，之后新出现的五才需要再耗一次。整数中的末尾零不能删；代码只有在仍含小数点的分支删小数尾零。
