## S-Nim

### 题意

允许减集合S中数的多堆游戏，输出每问胜负字母。

### 思路

预处理0..10000的SG：sg[h]=mex{sg[h−s]，s∈S且s≤h}。用时间戳数组标记本轮后继，避免每个h清大数组。询问把各堆SG异或，非0输出W，否则L，所有询问连成一串。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int k;
    cin >> k;
    vector<int> move(k);
    for (int &x : move)
        cin >> x;
    sort(move.begin(), move.end());
    const int limit = 10000;
    vector<int> sg(limit + 1), seen(k + 2, -1);
    for (int h = 1; h <= limit; h++) {
        for (int s : move) {
            if (s > h)
                break;
            if (sg[h - s] < (int)seen.size())
                seen[sg[h - s]] = h;
        }
        while (seen[sg[h]] == h)
            sg[h]++;
    }
    int m;
    cin >> m;
    string answer;
    while (m--) {
        int count;
        cin >> count;
        int total = 0;
        while (count--) {
            int h;
            cin >> h;
            total ^= sg[h];
        }
        answer.push_back(total ? 'W' : 'L');
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(10000k+\sum l)$，空间 $O(10000+k)$。

### 易错点

空堆SG为0；不能只预处理单堆胜负，因为多堆组合需要完整SG值。
