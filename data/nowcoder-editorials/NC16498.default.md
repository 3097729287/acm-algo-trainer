## 寻找道路

### 题意

路径上的每个点，其全部出边都必须指向原图中能到终点的点，求最短合法路径。

### 思路

先从终点沿反向边BFS，标出原图中能到终点的集合R。再检查每个点：若存在一条出边指向R之外，该点不能在答案路径中；其余点可用。最后在只允许这些点的原图上从s做BFS。注意合法性依据原图的可达集合R，只筛一次，不能把删除非法点后的不可达性不断向前传递，因为题目并未要求所有分支都沿合法路径到达终点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> graph(n + 1), reverse(n + 1);
    while (m--) {
        int a, b;
        cin >> a >> b;
        graph[a].push_back(b);
        reverse[b].push_back(a);
    }
    int s, t;
    cin >> s >> t;
    vector<bool> reachable(n + 1), valid(n + 1, true);
    vector<int> queue{t};
    reachable[t] = true;
    for (size_t h = 0; h < queue.size(); h++)
        for (int v : reverse[queue[h]])
            if (!reachable[v]) {
                reachable[v] = true;
                queue.push_back(v);
            }
    for (int u = 1; u <= n; u++)
        for (int v : graph[u])
            if (!reachable[v])
                valid[u] = false;
    vector<int> distance(n + 1, -1);
    queue.clear();
    if (valid[s]) {
        queue.push_back(s);
        distance[s] = 0;
    }
    for (size_t h = 0; h < queue.size(); h++)
        for (int v : graph[queue[h]])
            if (valid[v] && distance[v] == -1) {
                distance[v] = distance[queue[h]] + 1;
                queue.push_back(v);
            }
    cout << distance[t];
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n+m)$。

### 易错点

不能只删掉不能到终点的点，还要禁止所有具有坏出边的点。终点无出边，天然合法。
