## 数位五五

### 题意

统计闭区间中数位和为五的倍数的非负整数个数。

### 思路

逐数提取十进制数位并求和，再检查和对五的余数。零的数位和为零，也是五的倍数，需要正常计入。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int l, r;
    cin >> l >> r;
    if (l > r)
        swap(l, r);
    int ans = 0;
    for (int x = l; x <= r; x++) {
        int sum = 0;
        for (int y = x; y > 0; y /= 10)
            sum += y % 10;
        if (sum % 5 == 0)
            ans++;
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O((r-l+1)\log(r+1))$，额外空间 $O(1)$。

### 易错点

条件是数位之和能被五整除，不是原数能被五整除。
