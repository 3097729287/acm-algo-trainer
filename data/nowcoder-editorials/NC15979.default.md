## 小q的数列

### 题意

求递推数列 f[n]，并找出这个值最早出现的下标。

### 思路

递推每次将 n 整除二，并加上 n 的最低二进制位，所以 f[n] 就是二进制一的个数 c。包含 c 个一的最小非负整数，是把这些一全部放在最低位的 2^c-1。n=0 时 c=0，最早下标仍为零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        unsigned long long n;
        cin >> n;
        int count = 0;
        for (auto x = n; x; x >>= 1)
            count += x & 1ULL;
        cout << count << ' ' << ((1ULL << count) - 1) << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log(n+1))$，额外空间 $O(1)$。

### 易错点

不能按输入 n 的大小建立数组，n 可以接近十的十八次方；只检查最多六十个二进制位。
