## 可达性

### 题意

最小出发点集覆盖全部可达点，字典序最小。

### 思路

强连通分量内部任一点都能到其他点。缩成DAG后，每个入度0分量必须选至少一个点，因为无法从外部进入；每个其他分量又都可由某个源分量到达。因此恰选每个源分量一个点。要让升序答案字典序最小，每个分量选最小原编号，再整体排序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

pair<int, vector<int>> components(const vector<vector<int>> &graph,
                                  const vector<vector<int>> &reverse) {
    int n = graph.size();
    vector<bool> seen(n);
    vector<int> finish;
    for (int start = 0; start < n; start++)
        if (!seen[start]) {
            vector<pair<int, int>> stack{{start, 0}};
            seen[start] = true;
            while (!stack.empty()) {
                int u = stack.back().first, &position = stack.back().second;
                if (position == (int)graph[u].size()) {
                    finish.push_back(u);
                    stack.pop_back();
                } else {
                    int v = graph[u][position++];
                    if (!seen[v]) {
                        seen[v] = true;
                        stack.push_back({v, 0});
                    }
                }
            }
        }
    vector<int> component(n, -1);
    int count = 0;
    for (int i = n - 1; i >= 0; i--) {
        int start = finish[i];
        if (component[start] != -1)
            continue;
        vector<int> stack{start};
        component[start] = count;
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            for (int v : reverse[u])
                if (component[v] == -1) {
                    component[v] = count;
                    stack.push_back(v);
                }
        }
        count++;
    }
    return {count, component};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> graph(n), reverse(n);
    while (m--) {
        int u, v;
        cin >> u >> v;
        u--;
        v--;
        graph[u].push_back(v);
        reverse[v].push_back(u);
    }
    auto [count, component] = components(graph, reverse);
    vector<int> indegree(count), minimum(count, n);
    for (int u = 0; u < n; u++) {
        minimum[component[u]] = min(minimum[component[u]], u);
        for (int v : graph[u])
            if (component[u] != component[v])
                indegree[component[v]]++;
    }
    vector<int> answer;
    for (int c = 0; c < count; c++)
        if (!indegree[c])
            answer.push_back(minimum[c] + 1);
    sort(answer.begin(), answer.end());
    cout << answer.size() << '\n';
    for (int i = 0; i < (int)answer.size(); i++)
        cout << answer[i] << (i + 1 == (int)answer.size() ? '\n' : ' ');
    return 0;
}
```

### 复杂度

时间 $O(n+m+n\log n)$，空间 $O(n+m)$。

### 易错点

不能直接按原图入度选点，环内可能所有点原入度非零。SCC模板使用迭代Kosaraju避免长链栈溢出。
