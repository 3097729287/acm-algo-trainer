## [SCOI2009]粉刷匠

### 题意

每次只能刷一条木板的一段，每格最多刷一次，总次数至多T，最大化正确颜色格数。

### 思路

先独立处理一条板。j次笔画可分成j个不相交段，每段涂成其中目标颜色的多数色，得分为两种颜色计数的最大值。允许不刷的间隙可延长相邻笔画覆盖，不会减少已正确格数，所以j≥1时可直接枚举把整板分成j个非空段。前缀计数求段得分，做分段DP得到gain[j]；gain[0]=0表示整板不刷。

再将每条木板当一组，枚举给这条板0到M次，做以总笔画次数为容量的分组背包。容量表示至多次数，故初始各容量0，最后取T处最优值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, budget;
    cin >> n >> m >> budget;
    budget = min(budget, n * m);
    vector<int> total(budget + 1);
    for (int row = 0; row < n; row++) {
        string s;
        cin >> s;
        vector<int> prefix(m + 1);
        for (int i = 0; i < m; i++)
            prefix[i + 1] = prefix[i] + (s[i] == '1');
        int cap = min(m, budget), neg = -1000000000;
        vector<int> gain(cap + 1), dp(m + 1, neg);
        dp[0] = 0;
        for (int strokes = 1; strokes <= cap; strokes++) {
            vector<int> next(m + 1, neg);
            for (int i = strokes; i <= m; i++)
                for (int p = strokes - 1; p < i; p++)
                    if (dp[p] != neg) {
                        int ones = prefix[i] - prefix[p];
                        next[i] = max(next[i], dp[p] + max(ones, i - p - ones));
                    }
            dp.swap(next);
            gain[strokes] = dp[m];
        }
        vector<int> next(budget + 1);
        for (int b = 0; b <= budget; b++)
            for (int use = 0; use <= cap && use <= b; use++)
                next[b] = max(next[b], total[b - use] + gain[use]);
        total.swap(next);
    }
    cout << total[budget];
    return 0;
}
```

### 复杂度

时间 $O(NM^3+NTM)$，空间 $O(M+T)$。

### 易错点

每格最多刷一次，与可以覆盖的“涂色”题不同。T可能超过格数，额外次数不增加收益，可截到N*M。
