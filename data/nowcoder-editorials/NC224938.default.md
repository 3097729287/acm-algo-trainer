## 加减

### 题意

至多 k 次把单个元素加一或减一，最大化某个值的出现次数。

### 思路

排序后，最优选出的若干数可取为一段连续元素：固定目标值时，优先选择距离它最近的数，不会跳过中间更近的数。把区间 [l,r] 全改成同一个数，最省操作的目标是其中位数 a[mid]。用前缀和 O(1) 算出左半部分增加的代价与右半部分减少的代价。右端递增时，若代价超过 k 就右移左端；删除元素不会增加最小代价，所以双指针能找到最长可行段。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long k;
    cin >> n >> k;
    vector<long long> a(n), prefix(n + 1);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    for (int i = 0; i < n; i++)
        prefix[i + 1] = prefix[i] + a[i];
    auto cost = [&](int l, int r) {
        int mid = (l + r) / 2;
        return a[mid] * (mid - l + 1) - (prefix[mid + 1] - prefix[l]) +
               (prefix[r + 1] - prefix[mid + 1]) - a[mid] * (r - mid);
    };
    int left = 0, answer = 0;
    for (int right = 0; right < n; right++) {
        while (cost(left, right) > k)
            left++;
        answer = max(answer, right - left + 1);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

允许同时增加、减少，目标应取中位数；一律改成最大值并不最省。前缀和与操作预算都需要 long long。
