## 带权中位数

### 题意

从有序位置中选一个集合点，使所有人的移动距离总和最小。

### 思路

取累计人数首次达到总人数一半的位置，即满足 2*prefix>=total 的第一个编号。它是带权中位数。把集合点从一个坐标向右移动一小步，左侧每人距离加一步，右侧每人距离减一步；左边人数少于一半时右移能降低总距离，达到一半后再右移已无益，所以该位置最优。人数恰好平分时可能有一段最优位置，取最左的一个即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> positions(n), weight(n);
    for (auto &x : positions)
        cin >> x;
    long long total = 0;
    for (auto &x : weight) {
        cin >> x;
        total += x;
    }
    long long prefix = 0;
    for (int i = 0; i < n; i++) {
        prefix += weight[i];
        if (prefix * 2 >= total) {
            cout << i + 1;
            break;
        }
    }
    return 0;
}
```

### 复杂度

时间 $O(n)$，保存输入空间 $O(n)$。

### 易错点

选的是人数加权后的中位数，不是位置数组的中间下标，也不是坐标加权平均。总人数可能超过 int。
