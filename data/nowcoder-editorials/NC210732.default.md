## 灯谜

### 题意

随机各开关按或不按，求亮灯数三次方的总和。

### 思路

令Y[i]为第i灯是否亮，则X³=Σ(i,j,k)Y[i]Y[j]Y[k]，三重求和允许下标重复。每灯状态是m个开关选择位的线性异或式，用64位掩码保存系数。某有序三元组对总和的贡献，恰为令这三个灯都亮的开关方案数。

对三条方程mask·choice=1做二进制高斯消元。若出现0=1则贡献0；否则秩为r，方案数2^(m−r)。枚举n³个三元组并相加即可，直接得到E(X³)*2^m，不必算概率逆元。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<unsigned long long> mask(n);
    for (int s = 0; s < m; s++) {
        int k;
        cin >> k;
        while (k--) {
            int lamp;
            cin >> lamp;
            mask[lamp - 1] ^= 1ULL << s;
        }
    }
    const long long mod = 1000000007;
    vector<long long> power(m + 1, 1);
    for (int i = 1; i <= m; i++)
        power[i] = power[i - 1] * 2 % mod;
    long long answer = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            for (int k = 0; k < n; k++) {
                array<unsigned long long, 50> basis = {};
                int rank = 0;
                bool valid = true;
                for (int lamp : {i, j, k}) {
                    unsigned long long row = mask[lamp] | (1ULL << m);
                    for (int bit = m - 1; bit >= 0; bit--)
                        if (row >> bit & 1) {
                            if (basis[bit])
                                row ^= basis[bit];
                            else {
                                basis[bit] = row;
                                rank++;
                                row = 0;
                                break;
                            }
                        }
                    if (row) {
                        valid = false;
                        break;
                    }
                }
                if (valid)
                    answer = (answer + power[m - rank]) % mod;
            }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^3m)$，空间 $O(n+m)$。

### 易错点

三次方要枚举有序三元组，重复灯号也需计入。开关可控制多盏灯，灯之间通常不独立。
