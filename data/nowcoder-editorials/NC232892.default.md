## Nearest Point

### 题意

随机旋转后按x差找最近点，求各返回点概率。

### 思路

固定查询点i，对候选j的投影距离为|(Pj−Pi)·u(θ)|，θ均匀。两个候选j、k优劣改变，只可能发生在绝对投影相等，即(Pj−Pk)·u=0或(Pj+Pk−2Pi)·u=0。把这些事件角及0、π排序，因绝对投影以π为周期，只分析[0,π]。

每相邻事件之间候选顺序不变，取中点扫描全部候选，找投影差最小者，把该角区间长度/π加到对应概率。若候选关于i中心对称，它们恒相等，按编号较小者选择；零向量方程不产生事件。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<Point> p(n);
    for (auto &a : p)
        cin >> a.x >> a.y;
    const long double pi = acosl(-1.0L);
    vector<vector<long double>> probability(n, vector<long double>(n));
    for (int i = 0; i < n; i++) {
        vector<long double> event = {0, pi};
        auto add = [&](Point v) {
            if (v.x == 0 && v.y == 0)
                return;
            long double a = atan2l(v.y, v.x) + pi / 2;
            a = fmodl(a, pi);
            if (a < 0)
                a += pi;
            event.push_back(a);
        };
        for (int j = 0; j < n; j++)
            if (j != i)
                for (int k = j + 1; k < n; k++)
                    if (k != i) {
                        add(p[j] - p[k]);
                        add(p[j] + p[k] - p[i] * 2);
                    }
        sort(event.begin(), event.end());
        for (int t = 1; t < (int)event.size(); t++) {
            long double width = event[t] - event[t - 1];
            if (width <= 1e-18L)
                continue;
            long double angle = (event[t] + event[t - 1]) / 2;
            Point direction = {cosl(angle), sinl(angle)};
            long double best = 1e100L;
            int winner = -1;
            for (int j = 0; j < n; j++)
                if (j != i) {
                    long double value = fabsl(dot(p[j] - p[i], direction));
                    if (value < best - 1e-12L) {
                        best = value;
                        winner = j;
                    }
                }
            probability[i][winner] += width / pi;
        }
    }
    cout << fixed << setprecision(12);
    for (auto &row : probability)
        for (int j = 0; j < n; j++)
            cout << row[j] << (j + 1 == n ? '\n' : ' ');
    return 0;
}
```

### 复杂度

时间 $O(n⁴+n³\log n)$，空间 $O(n²)$，n≤50。

### 易错点

比较的是投影差，不是欧氏距离。事件本身只有零测度，但恒相等的候选必须按最小编号处理。
