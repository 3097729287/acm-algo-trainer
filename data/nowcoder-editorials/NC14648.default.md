## 序列

### 题意

两个序列，统计gcd(x,y)=1且a[x]=b[y]的有序下标对。

### 思路

题面图片要求的是下标x、y互素，与数值互素不同。由[gcd(x,y)=1]=Σ(d|x,d|y)mu(d)，答案=Σ_d mu(d)*Σ_v countA[d][v]*countB[d][v]。

固定d，只扫描d的倍数下标，把a值写入临时频次数组，再扫描b的对应下标累加相等数对。结束后再扫a的倍数下标清零，避免每个d清空整个值域。先线性筛mu，mu=0的d可跳过。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n + 1), b(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    for (int i = 1; i <= n; i++)
        cin >> b[i];
    vector<int> mu(n + 1), primes;
    vector<bool> composite(n + 1);
    mu[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!composite[i]) {
            primes.push_back(i);
            mu[i] = -1;
        }
        for (int p : primes) {
            if (1LL * i * p > n)
                break;
            composite[i * p] = true;
            if (i % p == 0)
                break;
            mu[i * p] = -mu[i];
        }
    }
    vector<int> count(n + 1);
    long long answer = 0;
    for (int d = 1; d <= n; d++)
        if (mu[d]) {
            for (int i = d; i <= n; i += d)
                count[a[i]]++;
            long long pairs = 0;
            for (int i = d; i <= n; i += d)
                pairs += count[b[i]];
            answer += mu[d] * pairs;
            for (int i = d; i <= n; i += d)
                count[a[i]] = 0;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

原题全部文字嵌在图片中，已核对三张图：n≤10^5且a、b值均在1..n。样例n=3全1共7个互素有序对。
