## [SCOI2010]字符串

### 题意

n个1和m个0组成串，任意前缀中1不少于0，求数量模20100403。

### 思路

所有串有C(n+m,m)个。把1看成向上、0看成向下，非法串第一次到达高度−1前的步骤全部翻转，就得到含n+1个1、m−1个0的串；反过来也能唯一恢复第一次越界段。因此非法数是C(n+m,m−1)，答案为二者之差。模数20100403为素数，且n+m≤2000000小于模数，可预处理阶乘并用快速幂求逆阶乘。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    const long long mod = 20100403;
    int limit = n + m;
    vector<long long> factorial(limit + 1, 1), inverse(limit + 1);
    for (int i = 1; i <= limit; i++)
        factorial[i] = factorial[i - 1] * i % mod;
    auto power = [&](long long a, long long b) {
        long long result = 1;
        while (b) {
            if (b & 1)
                result = result * a % mod;
            a = a * a % mod;
            b >>= 1;
        }
        return result;
    };
    inverse[limit] = power(factorial[limit], mod - 2);
    for (int i = limit; i >= 1; i--)
        inverse[i - 1] = inverse[i] * i % mod;
    auto choose = [&](int k) {
        if (k < 0 || k > limit)
            return 0LL;
        return factorial[limit] * inverse[k] % mod * inverse[limit - k] % mod;
    };
    cout << (choose(m) - choose(m - 1) + mod) % mod;
    return 0;
}
```

### 复杂度

时间 $O(n+m+\log P)$，空间 $O(n+m)$。

### 易错点

非法串的反射是在第一次到达−1处，不是任意负前缀。最后做减法后加模数。
