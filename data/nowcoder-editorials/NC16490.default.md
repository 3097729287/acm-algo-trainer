## 金币

> 原题：[P2669](https://www.luogu.com.cn/problem/P2669)
> 解法：按工资段累加 · C++17

### 题意

第一个工资段每天一枚、持续一天；第二段每天两枚、持续两天，依此类推，求前 $k$ 天收入。



### 思路

对每天金额 pay，取当前剩余天数与 pay 的较小值作为本段实际天数，累加两者乘积，再转入下一段。

工资段数为 $O(\sqrt{k})$，时间 $O(\sqrt{k})$、额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int remaining;
    cin >> remaining;
    long long answer = 0;
    for (int pay = 1; remaining > 0; pay++) {
        int days = min(remaining, pay);
        answer += 1LL * days * pay;
        remaining -= days;
    }
    cout << answer << '\n';
    return 0;
}
```

### 易错点

最后一段可能只发一部分天数，不能直接加 pay 的平方。
