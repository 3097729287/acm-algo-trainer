## [NOIP2000]计算器的改良

### 题意

解析只含整数、同一未知数及加减等号的一元一次方程，输出唯一解。

### 思路

把两侧全部移到左边，累计成 Kx+C=0。扫描时记录所在一侧与当前项符号：等号右侧的项统一乘负一。读数字后若紧跟字母，就加入未知数系数，只有字母时系数为一；否则加入常数。最后解为 -C/K。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    long long coefficient = 0, constant = 0;
    int side = 1, sign = 1;
    char variable = 'x';
    for (size_t i = 0; i < s.size();) {
        if (s[i] == '=') {
            side = -1;
            sign = 1;
            i++;
            continue;
        }
        if (s[i] == '+') {
            sign = 1;
            i++;
            continue;
        }
        if (s[i] == '-') {
            sign = -1;
            i++;
            continue;
        }
        long long value = 0;
        bool hasDigit = false;
        while (i < s.size() && isdigit(static_cast<unsigned char>(s[i]))) {
            hasDigit = true;
            value = value * 10 + s[i] - '0';
            i++;
        }
        if (i < s.size() && isalpha(static_cast<unsigned char>(s[i]))) {
            variable = s[i++];
            coefficient += side * sign * (hasDigit ? value : 1);
        } else
            constant += side * sign * value;
    }
    cout << variable << '=' << fixed << setprecision(3) << -(long double)constant / coefficient;
    return 0;
}
```

### 复杂度

时间与输入字符串空间均为 $O(|S|)$。

### 易错点

右侧移项要同时改变未知项与常数项符号；x 与 -x 的省略系数分别是一与负一。
