## Xorto

### 题意

统计互不重叠的两个非空区间，使两段所有数合起来的异或为零。

### 思路

两段合并异或为零，等价于各自的异或相等。枚举右侧区间的左端点 l，频次数组保存所有结束位置小于 l 的区间异或值。先把刚结束在 l-1 的所有区间加入频次，再枚举从 l 开始的右段，求其异或 v 并加上 freq[v]。每对不重叠区间都有唯一左右顺序，也只会在这个 l 被计数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    vector<long long> frequency(1 << 17);
    long long answer = 0;
    for (int left = 0; left < n; left++) {
        int value = 0;
        for (int i = left - 1; i >= 0; i--) {
            value ^= a[i];
            frequency[value]++;
        }
        value = 0;
        for (int right = left; right < n; right++) {
            value ^= a[right];
            answer += frequency[value];
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^2+2^{17})$，空间 $O(n+2^{17})$。

### 易错点

不是要求两段各自异或都为零，而是两段异或相等。元素小于 100000，所有异或小于 2^17；答案需要 long long。
