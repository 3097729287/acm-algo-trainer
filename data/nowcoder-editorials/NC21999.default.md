## 牛牛学立体

### 题意

根据长宽高，输出长方体表面积和体积。

### 思路

三个方向的面各出现两次，表面积为 2(ab+bc+ca)；体积为 abc。用 long long 完成全部乘法，避免后续扩展范围时中间结果溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long a, b, c;
    cin >> a >> b >> c;
    cout << 2 * (a * b + b * c + c * a) << '\n' << a * b * c;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

只把最终结果存进 long long 而让乘法先用 int 计算，并不能避免中间溢出。
