## 数学考试

### 题意

选两个长度都为 k、互不重叠的连续区间，使得分总和最大。

### 思路

用前缀和求任意长度 k 的窗口和，best[i] 保存完全位于前 i 项的这类窗口的最大和。枚举第二段左端点 r，第一段必须完全位于前 r-1 项，候选就是 best[r-1]+第二段的和。二者覆盖所有合法选择，取最大即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, k;
        cin >> n >> k;
        vector<long long> prefix(n + 1), best(n + 1, LLONG_MIN / 4);
        for (int i = 1; i <= n; i++) {
            long long x;
            cin >> x;
            prefix[i] = prefix[i - 1] + x;
        }
        for (int i = k; i <= n; i++)
            best[i] = max(best[i - 1], prefix[i] - prefix[i - k]);
        long long answer = LLONG_MIN;
        for (int right = k + 1; right + k - 1 <= n; right++)
            answer = max(answer, best[right - 1] + prefix[right + k - 1] - prefix[right - 1]);
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n)$。

### 易错点

分数可以全负，最大值不能初始化为零。两段允许紧挨着，只需不重叠；R=L+k 合法。
