## [HAOI2012]音量调节

### 题意

每首歌前必须按指定幅度调高或调低，过程不越界，求最后最大音量。

### 思路

用布尔数组记录当前所有可达音量。初始只有begin。每个变化c从旧音量v分别转移到v−c、v+c，越界的不加入。用新数组替换，全部歌曲结束后从最大音量向下找首个可达者，没有则−1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, begin, limit;
    cin >> n >> begin >> limit;
    vector<bool> can(limit + 1);
    can[begin] = true;
    while (n--) {
        int change;
        cin >> change;
        vector<bool> next(limit + 1);
        for (int v = 0; v <= limit; v++)
            if (can[v]) {
                if (v >= change)
                    next[v - change] = true;
                if (v + change <= limit)
                    next[v + change] = true;
            }
        can.swap(next);
    }
    int answer = -1;
    for (int v = limit; v >= 0; v--)
        if (can[v]) {
            answer = v;
            break;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(nM)$，空间 $O(M)$。

### 易错点

每次必须调整，不能保留原音量作为“不操作”。更新必须基于上一首歌状态。
