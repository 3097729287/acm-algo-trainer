## 牛牛学数列4

### 题意

求一到 i 的和，再把这些前缀和从 i=1 累加到 n。

### 思路

维护 prefix 表示当前 1+…+i，每次先加上 i，再将 prefix 加入总答案。没有必要为每个 i 重新从一循环。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long prefix = 0, ans = 0;
    for (int i = 1; i <= n; i++) {
        prefix += i;
        ans += prefix;
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

累加到答案中的是前缀和，不是单独的 i。
