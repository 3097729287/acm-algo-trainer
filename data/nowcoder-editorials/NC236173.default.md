## 宝藏猎人

### 题意

向东跳，跳长每次至多改变1，收集最多宝石。

### 思路

dp[position][jump]表示最后一次跳长为jump时的最多宝石。下一跳尝试jump−1、jump、jump+1，正长度且不越界即可。关键是限制跳长范围：从初始d增加或减少250，必须经历至少250次逐级变化，仅这些跳长的最小总和就超过30000；减小的情况还要求d≥251。因此只需保存jump∈[d−250,d+250]与正整数的交集。

位置严格增加，按位置升序转移。总宝石至30000，16位有符号数足够存答案及−1不可达标记，约30MB。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, d;
    cin >> n >> d;
    const int limit = 30000, width = 501;
    vector<int> gem(limit + 1);
    for (int i = 0; i < n; i++) {
        int p;
        cin >> p;
        gem[p]++;
    }
    vector<int16_t> dp((limit + 1) * width, -1);
    dp[d * width + 250] = gem[d];
    int answer = 0;
    for (int p = d; p <= limit; p++)
        for (int index = 0; index < width; index++) {
            int current = dp[p * width + index];
            if (current < 0)
                continue;
            answer = max(answer, current);
            int jump = d + index - 250;
            for (int change = -1; change <= 1; change++) {
                int next = index + change, length = jump + change;
                if (next >= 0 && next < width && length > 0 && p + length <= limit) {
                    auto &value = dp[(p + length) * width + next];
                    value = max((int)value, current + gem[p + length]);
                }
            }
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(30000\sqrt{30000})$，空间同状态数，每状态16位。

### 易错点

同一个位置可能有多颗宝石，必须累计频数。第一次强制跳到d，不能从0随意选择第一跳。
