## 换个角度思考

### 题意

静态数组，询问[l,r]中≤x的元素数。

### 思路

将数组元素按值升序，询问按阈值x升序。处理一个询问前，把所有值≤x的元素在其原下标上加1。此时树状数组的区间计数就是答案。询问保留编号，最后按原顺序输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<pair<int, int>> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i].first;
        a[i].second = i + 1;
    }
    vector<array<int, 4>> query(m);
    for (int i = 0; i < m; i++) {
        int l, r, x;
        cin >> l >> r >> x;
        query[i] = {x, l, r, i};
    }
    sort(a.begin(), a.end());
    sort(query.begin(), query.end());
    Fenwick bit(n);
    vector<int> answer(m);
    int p = 0;
    for (auto [x, l, r, id] : query) {
        while (p < n && a[p].first <= x) {
            bit.add(a[p].second, 1);
            p++;
        }
        answer[id] = bit.sum(r) - bit.sum(l - 1);
    }
    for (int x : answer)
        cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log(n+m))$，空间 $O(n+m)$。

### 易错点

阈值相等的数组元素要先全部插入，条件是≤而非<。离线排序不能改变输出顺序。
