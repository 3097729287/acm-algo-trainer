## 斐波那契

### 题意

给出可能有一百万位的 n，求 F[n-1]F[n+1]-F[n]^2。

### 思路

记要求的式子为 D[n]。用 F[n+1]=F[n]+F[n-1]，可得 D[n+1]=F[n]F[n+2]-F[n+1]^2=F[n]^2-F[n-1]F[n+1]=-D[n]。而 D[2]=1，所以 D[n]=(-1)^n。根本不必算斐波那契数，只需读入十进制 n，判断末位奇偶。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string n;
    cin >> n;
    cout << ((n.back() - '0') % 2 == 0 ? 1 : -1);
    return 0;
}
```

### 复杂度

设输入有 $L$ 位，时间与保存输入的空间均为 $O(L)$。

### 易错点

n 本身也超出整数类型，不能用 long long 或把 n 转成普通整数。字符串读入的时间随位数增长。
