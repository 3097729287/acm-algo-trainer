## [NOIP2004]合唱队形

### 题意

删除最少同学，使剩余身高先严格上升再严格下降。

### 思路

每个位置i分别求以它结尾的严格上升子序列长度left[i]，以及以它开头的严格下降长度right[i]。二者拼接，以i为唯一最高点，总长left[i]+right[i]−1。枚举最高点取最大保留人数，答案为n减去该值。允许最高点在端点，一侧长度为1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n), left(n, 1), right(n, 1);
    for (int &x : a)
        cin >> x;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < i; j++)
            if (a[j] < a[i])
                left[i] = max(left[i], left[j] + 1);
    for (int i = n - 1; i >= 0; i--)
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[i])
                right[i] = max(right[i], right[j] + 1);
    int keep = 0;
    for (int i = 0; i < n; i++)
        keep = max(keep, left[i] + right[i] - 1);
    cout << n - keep;
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

相同身高不能出现在严格单调的一侧，比较必须用小于。峰顶在两边计了两次，需要减一。
