## N皇后问题

### 题意

n≤12的N皇后方案数。

### 思路

逐行放皇后，用三个位掩码记录已占列、两类对角线在当前行的攻击位置。当前可放列available=full & ~(columns|left|right)，依次取最低位放置。进入下一行时左右对角线分别左移、右移；放满n行计一种。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    unsigned full = (1U << n) - 1;
    long long answer = 0;
    auto dfs = [&](auto &&self, unsigned columns, unsigned left, unsigned right) -> void {
        if (columns == full) {
            answer++;
            return;
        }
        unsigned available = full & ~(columns | left | right);
        while (available) {
            unsigned bit = available & -available;
            available -= bit;
            self(self, columns | bit, (left | bit) << 1, (right | bit) >> 1);
        }
    };
    dfs(dfs, 0, 0, 0);
    cout << answer;
    return 0;
}
```

### 复杂度

保守时间 $O(n!)$，递归空间 $O(n)$。

### 易错点

每行恰放一个，列掩码满了就完成。越界对角线位由full在下次候选计算时屏蔽。
