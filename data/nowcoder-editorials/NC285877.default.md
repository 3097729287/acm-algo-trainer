## 中序序列

### 题意

给前序、后序恢复中序，单儿子约定为左儿子。

### 思路

按前序逐个创建结点，用栈保存尚未完成的祖先路径。每次新结点到来前，若栈顶值等于当前后序值，说明这棵子树已完成，就弹栈并推进后序；新结点接到剩下栈顶的第一个空儿子位置，先左后右。遍历结束后，再用显式栈输出中序。前序决定进入顺序，后序决定返回时机，单儿子自然先接左边。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
  public:
    vector<int> solve(int n, vector<int> &pre, vector<int> &suf) {
        if (n == 0)
            return {};
        vector<int> left(n, -1), right(n, -1), path;
        int finished = 0;
        for (int i = 0; i < n; i++) {
            while (!path.empty() && finished < n && pre[path.back()] == suf[finished]) {
                path.pop_back();
                finished++;
            }
            if (!path.empty()) {
                int parent = path.back();
                if (left[parent] == -1)
                    left[parent] = i;
                else
                    right[parent] = i;
            }
            path.push_back(i);
        }
        vector<int> result, stack;
        int current = 0;
        while (current != -1 || !stack.empty()) {
            while (current != -1) {
                stack.push_back(current);
                current = left[current];
            }
            current = stack.back();
            stack.pop_back();
            result.push_back(pre[current]);
            current = right[current];
        }
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> pre(n), post(n);
    for (int &x : pre)
        cin >> x;
    for (int &x : post)
        cin >> x;
    auto answer = Solution().solve(n, pre, post);
    for (int i = 0; i < n; i++) {
        if (i)
            cout << ' ';
        cout << answer[i];
    }
    return 0;
}
```

### 复杂度

每个结点进出各栈一次，时间、空间均为 $O(n)$。

### 易错点

前序、后序一般不能唯一恢复左右单儿子，本题明确把单儿子放左边。用迭代构造与遍历兼容十万结点长链。
