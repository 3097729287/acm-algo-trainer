## 爱因斯坦的名言

### 题意

输出题面给出的英文名言，包含两端的双引号。

### 思路

原始字符串中的内容原样输出，不把双引号或百分号解释为特殊指令。句首大写，末尾句号在右引号以内。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout << R"quote("Genius is 1% inspiration and 99% perspiration.")quote";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

使用 cout 时百分号不需要写成两个；题目给出的引号也是输出内容。
