## [HAOI2006]聪明的猴子

### 题意

不同猴子有不同跳距，判断有多少能在全部树冠间来回觅食。

### 思路

跳距d可觅食全部树，等价于只保留长度≤d的树冠连边后图连通。完整欧氏图的任一最小生成树，其最大边长是所有生成树中最小的瓶颈；故只需求MST的最大边，再比较每只猴子跳距。N≤1000，使用稠密Prim，不显式存百万条边。全程比较平方距离，无需浮点开根。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m;
    cin >> m;
    vector<long long> jump(m);
    for (auto &x : jump)
        cin >> x;
    int n;
    cin >> n;
    vector<array<long long, 2>> point(n);
    for (auto &p : point)
        cin >> p[0] >> p[1];
    vector<long long> best(n, 1LL << 60);
    vector<bool> used(n);
    best[0] = 0;
    long long threshold = 0;
    for (int step = 0; step < n; step++) {
        int u = -1;
        for (int v = 0; v < n; v++)
            if (!used[v] && (u == -1 || best[v] < best[u]))
                u = v;
        used[u] = true;
        threshold = max(threshold, best[u]);
        for (int v = 0; v < n; v++)
            if (!used[v]) {
                long long dx = point[u][0] - point[v][0], dy = point[u][1] - point[v][1];
                best[v] = min(best[v], dx * dx + dy * dy);
            }
    }
    int answer = 0;
    for (long long d : jump)
        answer += d * d >= threshold;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(N^2+M)$，空间 $O(N+M)$。

### 易错点

只要求可经中间树冠到所有树，不要求一跳到任意树。比较MST最大边，不是MST总长或最远两树距离。
