## 中序序列

### 题意

由互异结点的先序与后序恢复中序，单个孩子固定视为左孩子。原站使用 `Solution::solve` 函数接口，返回数组，无需自行读取输入或输出。

### 思路

先序顺序决定新结点的出现顺序，后序顺序决定哪些子树已经结束。用栈保存尚未完成的祖先路径；准备放入下一个先序结点前，只要栈顶已等于后序中下一个待结束的结点，就将它弹出。剩余栈顶就是新结点父亲：还没有左孩子就挂左边，否则挂右边。这样唯一的一个孩子自然成为左孩子。建完树后，用显式栈完成中序遍历，避免十万层链上的递归栈溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
class Solution {
  public:
    vector<int> solve(int n, vector<int> &pre, vector<int> &suf) {
        if (n == 0)
            return {};
        vector<int> left(n, -1), right(n, -1), path;
        int finished = 0;
        for (int i = 0; i < n; i++) {
            while (!path.empty() && finished < n && pre[path.back()] == suf[finished]) {
                path.pop_back();
                finished++;
            }
            if (!path.empty()) {
                int parent = path.back();
                if (left[parent] == -1)
                    left[parent] = i;
                else
                    right[parent] = i;
            }
            path.push_back(i);
        }
        vector<int> result, stack;
        int current = 0;
        while (current != -1 || !stack.empty()) {
            while (current != -1) {
                stack.push_back(current);
                current = left[current];
            }
            current = stack.back();
            stack.pop_back();
            result.push_back(pre[current]);
            current = right[current];
        }
        return result;
    }
};
```

### 复杂度

每个结点进出两次栈各一次，时间与数组空间均为 $O(n)$。

### 易错点

先序与后序本来不能唯一确定只有一个孩子时的左右关系，本题额外规定单孩子为左。原站给出的是参数与返回值样例，提交时保留指定类名、方法名和引用参数。
