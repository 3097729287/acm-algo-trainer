## Operation Love

### 题意

固定20点手掌多边形可旋转平移且正反序输入，判左右手。

### 思路

图形不缩放，掌底有唯一长度9的边，它的一端邻边长8，另一端邻边长6。把长9边规范定向为“朝长8邻边端”，再看该端转向长8边的叉积。给定右手模板中从(1,0)到(10,0)，再到(10,8)，叉积为正；镜像左手为负。旋转平移保留这个符号，反序输入通过规范定向消除。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        vector<Point> p(20);
        for (auto &v : p)
            cin >> v.x >> v.y;
        bool right = false;
        for (int i = 0; i < 20; i++) {
            int j = (i + 1) % 20;
            if (fabsl(dot(p[j] - p[i], p[j] - p[i]) - 81) > 1e-3L)
                continue;
            int after = (j + 1) % 20, before = (i + 19) % 20;
            if (fabsl(dot(p[after] - p[j], p[after] - p[j]) - 64) < 1e-3L)
                right = cross(p[j] - p[i], p[after] - p[j]) > 0;
            else
                right = cross(p[i] - p[j], p[before] - p[i]) > 0;
            break;
        }
        cout << (right ? "right\n" : "left\n");
    }
    return 0;
}
```

### 复杂度

每组时间、空间均 $O(20)$。

### 易错点

仅计算多边形有向面积会受输入顺逆时针影响，不能直接据此判断左右。长度比较用容差应对六位小数坐标。
