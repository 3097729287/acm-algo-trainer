## 集合与最大公因数

### 题意

n组四个数，两两gcd=k，组间不重复，最小化最大数。

### 思路

所有数都可除以k，问题变成每组四个数两两互素。一组至多一个偶数，因此4n个不同数中至少3n个为奇数，最大数至少6n−1。

对i=0..n−1构造{6i+1,6i+2,6i+3,6i+5}，恰用3个奇数和1个偶数。不同奇数差2或4，可能公共奇因子只有来自差的因子，故互素；偶数与两邻数连续，与6i+5差3但它不被3整除，也互素。所有组不重复，最大值6n−1达到下界。最后全体乘k。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, k;
    cin >> n >> k;
    cout << (6 * n - 1) * k << '\n';
    for (long long i = 0; i < n; i++)
        cout << (6 * i + 1) * k << ' ' << (6 * i + 2) * k << ' ' << (6 * i + 3) * k << ' '
             << (6 * i + 5) * k << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

最大公因数恰好k，构造基础数必须两两互素，不能只让整组gcd为1。
