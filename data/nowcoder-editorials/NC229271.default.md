## The World is a Theatre

### 题意

选t名演员，至少4男、至少1女。

### 思路

枚举选男生人数b，从4到min(n,t−1)，女生人数t−b。贡献C(n,b)*C(m,t−b)，女生人数不合法时为0。人数不超过30，Pascal表及最终答案可用64位精确计算。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, t;
    cin >> n >> m >> t;
    long long choose[31][31] = {};
    for (int i = 0; i <= 30; i++) {
        choose[i][0] = choose[i][i] = 1;
        for (int j = 1; j < i; j++)
            choose[i][j] = choose[i - 1][j - 1] + choose[i - 1][j];
    }
    long long answer = 0;
    for (int boys = 4; boys <= n && boys < t; boys++) {
        int girls = t - boys;
        if (girls <= m)
            answer += choose[n][boys] * choose[m][girls];
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(30^2)$，空间 $O(30^2)$。

### 易错点

至少1名女生，不允许boys=t。演员集合无顺序，不乘排列数。
