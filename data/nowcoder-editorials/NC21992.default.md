## 浮点除法

### 题意

输出 a 除以 b 的实数结果。

### 思路

把 a 读作 double，表达式 a/b 就进行浮点除法。保留六位小数能够覆盖输入范围下的误差要求。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    double a, b;
    cin >> a >> b;
    cout << fixed << setprecision(6) << a / b;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

先进行整数除法再转成 double，无法恢复丢掉的小数。
