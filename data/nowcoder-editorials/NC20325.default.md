## [SDOI2009]HH的项链

### 题意

多次查询静态颜色数组中，闭区间包含多少种不同颜色。

### 思路

将查询按右端点升序排列，依次把数组扫到当前右端。树状数组只在每种颜色最后出现的位置放一，较早的同色位置清零。这样，对于当前右端 R，颜色出现在 [L,R] 中，当且仅当它最后出现的位置不小于 L；树状数组的闭区间和就是不同颜色数。答案存回原查询编号，最后按输入顺序输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

class FastInput {
    static const int size = 1 << 16;
    char buffer[size];
    int position = 0, available = 0;
    int get() {
        if (position == available) {
            available = fread(buffer, 1, size, stdin);
            position = 0;
            if (!available)
                return EOF;
        }
        return buffer[position++];
    }

  public:
    int next() {
        int c = get(), sign = 1;
        while (c != '-' && (c < '0' || c > '9'))
            c = get();
        if (c == '-') {
            sign = -1;
            c = get();
        }
        long long x = 0;
        while (c >= '0' && c <= '9') {
            x = x * 10 + c - '0';
            c = get();
        }
        return (int)(x * sign);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    FastInput input;
    int n = input.next();
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++)
        a[i] = input.next();
    int m = input.next();
    struct Query {
        int left, right, id;
    };
    vector<Query> queries(m);
    for (int i = 0; i < m; i++)
        queries[i] = {input.next(), input.next(), i};
    sort(queries.begin(), queries.end(),
         [](const Query &a, const Query &b) { return a.right < b.right; });
    vector<int> tree(n + 1), last(1000001), answer(m);
    auto change = [&](int position, int value) {
        for (int i = position; i <= n; i += i & -i)
            tree[i] += value;
    };
    auto sum = [&](int position) {
        int result = 0;
        for (int i = position; i > 0; i -= i & -i)
            result += tree[i];
        return result;
    };
    int right = 0;
    for (auto query : queries) {
        while (right < query.right) {
            right++;
            if (last[a[right]])
                change(last[a[right]], -1);
            change(right, 1);
            last[a[right]] = right;
        }
        answer[query.id] = sum(query.right) - sum(query.left - 1);
    }
    for (int value : answer)
        cout << value << '\n';
    return 0;
}
```

### 复杂度

时间 $O(m\log m+(n+m)\log n)$，空间 $O(n+m+V)$，颜色值域 $V=10^6$。

### 易错点

按题面备注中更大的范围支持一百万元素与询问，并支持颜色零。不能直接把每个出现位置都加一，那会得到长度而非种类数。
