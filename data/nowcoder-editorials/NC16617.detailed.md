## ISBN号码

> 原题：[P1055](https://www.luogu.com.cn/problem/P1055)
> 解法：逐位计算校验码 · C++17

### 题意

ISBN 的前九位数字按一到九加权，和模十一作为校验码，十写成 X；正确则输出 Right，否则更正末位。



### 思路

连字符只负责分组，不占数字权重。例如首个数字权一，第二个数字即使隔着连字符也只权二。sum 把每位数字值乘对应权重后相加，最后取 $sum\bmod11$。结果在零到九时转成相应数字字符，等于十时使用 X。比较的是字符；不一致时只改字符串末位，原有连字符与数字位置都保持原样。

ISBN 长度固定，时间与额外空间均为 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int sum = 0, weight = 1;
    for (int i = 0; i + 1 < (int)s.size(); i++)
        if (s[i] != '-')
            sum += (s[i] - '0') * weight++;
    int r = sum % 11;
    char check = r == 10 ? 'X' : char('0' + r);
    if (s.back() == check)
        cout << "Right\n";
    else {
        s.back() = check;
        cout << s << '\n';
    }
    return 0;
}
```

### 易错点

末位不参与加权；校验值十用大写 X，不能输出两个字符 10。
