## H、Diff-prime Pairs

### 题意

统计有序数对(i,j)，二者除以gcd后均为素数，i、j不超过N。

### 思路

令i=g*p、j=g*q，其中p、q为素数。它们已除去最大公约数，故p、q必须不同。固定较大的素数q，较小素数p有π(q)−1个，g有floor(N/q)个，再乘2表示两种顺序。筛出素数后按从小到大扫描，用计数器记录q之前的素数个数，累加2*count*floor(N/q)，无需枚举g或素数对。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<bool> composite(n + 1);
    for (int p = 2; 1LL * p * p <= n; p++)
        if (!composite[p])
            for (int x = p * p; x <= n; x += p)
                composite[x] = true;
    long long earlier = 0, answer = 0;
    for (int q = 2; q <= n; q++)
        if (!composite[q]) {
            answer += 2 * earlier * (n / q);
            earlier++;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(N\log\log N)$，空间 $O(N)$ 位。

### 易错点

不能令p=q，否则约掉gcd后会得到1而不是素数。数对有序，最后乘2。
