## Alternating Sum

### 题意

周期正负号加权的a与b混合幂求和。

### 思路

令q=b/a mod P，先求第一周期B=a^n*Σ(i=0..k−1)s[i]q^i。往后每个周期整体乘r=q^k，共有blocks=(n+1)/k个周期。答案B*Σ(j=0..blocks−1)r^j；r=1时为B*blocks，否则为B*(r^blocks−1)/(r−1)。a<P且非零，可以求逆。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000009;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}
struct Combinations {
    vector<long long> factorial, inverse;
    Combinations(int n) : factorial(n + 1, 1), inverse(n + 1) {
        for (int i = 1; i <= n; i++)
            factorial[i] = factorial[i - 1] * i % mod;
        inverse[n] = power(factorial[n], mod - 2);
        for (int i = n; i >= 1; i--)
            inverse[i - 1] = inverse[i] * i % mod;
    }
    long long choose(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return factorial[n] * inverse[k] % mod * inverse[n - k] % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, a, b, k;
    string s;
    cin >> n >> a >> b >> k >> s;
    long long q = b * power(a, mod - 2) % mod, term = power(a, n), block = 0;
    for (int i = 0; i < k; i++) {
        block = (block + (s[i] == '+' ? term : mod - term)) % mod;
        term = term * q % mod;
    }
    long long ratio = power(q, k), blocks = (n + 1) / k, sum;
    if (ratio == 1)
        sum = blocks % mod;
    else
        sum =
            (power(ratio, blocks) - 1 + mod) % mod * power((ratio - 1 + mod) % mod, mod - 2) % mod;
    cout << block * sum % mod;
    return 0;
}
```

### 复杂度

时间 $O(k+\log n+\log P)$，空间 $O(k)$ 存符号串。

### 易错点

等比公比等于1时不能求(r−1)逆元。n+1恰为周期倍数，由题目保证。
