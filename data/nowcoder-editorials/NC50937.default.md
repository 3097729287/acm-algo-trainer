## 货仓选址

### 题意

数轴上放一个货仓，最小化到各店的距离总和。

### 思路

排序后将最左与最右两店配对。货仓放在这一对之间时，两段距离之和恒等于两店间距；放到区间外只会更大。所有配对区间的公共部分正是中位数位置（偶数时为中间两数之间），因此取任一中位数最优。计算到它的绝对距离总和。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    long long median = a[n / 2], answer = 0;
    for (long long x : a)
        answer += abs(x - median);
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

输出最小距离和，而非仓库坐标；总和可能超过32位。
