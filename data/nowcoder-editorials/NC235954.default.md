## 滑雪

### 题意

严格下降的四邻路径最大长度。

### 思路

把格子按高度升序处理，dp[u]=1+max(dp[v])，v为更低的四邻格；没有更低格时为1。低格已先处理，依赖顺序正确，最后对全部起点取最大。这样避免递归路径很长时的栈问题。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> height(n * m), order(n * m), dp(n * m, 1);
    for (int &x : height)
        cin >> x;
    iota(order.begin(), order.end(), 0);
    sort(order.begin(), order.end(), [&](int a, int b) { return height[a] < height[b]; });
    int answer = 1;
    const int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
    for (int u : order) {
        int r = u / m, c = u % m;
        for (int d = 0; d < 4; d++) {
            int rr = r + dr[d], cc = c + dc[d];
            if (rr >= 0 && rr < n && cc >= 0 && cc < m && height[rr * m + cc] < height[u])
                dp[u] = max(dp[u], dp[rr * m + cc] + 1);
        }
        answer = max(answer, dp[u]);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

格子数V=nm，时间 $O(V\log V)$，空间 $O(V)$。

### 易错点

相等高度不能滑动。路径长度按经过格子数，单格为1。
