## 石子游戏

### 题意

每次从一堆取任意正数石子，判断先手胜负。

### 思路

全部堆大小的异或X为0时，改变任一堆都会使异或非0；X非0时，取最高置位所在的一堆a，把它减为a xor X，该数小于a，且使总异或变0。故先手胜当且仅当异或非0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int total = 0;
    while (n--) {
        int x;
        cin >> x;
        total ^= x;
    }
    cout << (total ? "Alice" : "Bob");
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

每次只能改一堆，不能用总石子数奇偶判断。
