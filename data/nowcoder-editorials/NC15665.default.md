## maze

### 题意

四方向一步耗时1，可选单向传送耗时3，避开陷阱到终点。

### 思路

把每个非陷阱格看成图结点，普通四邻边权1，传送边权3。传送可以不用，多个入口、出口也可共处同一格，因此保留全部普通边和合法传送边。用Dijkstra求最短时间，过期堆记录跳过。传送入口或出口是陷阱时，这条边不能使用。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, q;
    while (cin >> n >> m >> q) {
        vector<string> grid(n);
        int start = 0, target = 0;
        for (int r = 0; r < n; r++) {
            cin >> grid[r];
            for (int c = 0; c < m; c++) {
                if (grid[r][c] == 'S')
                    start = r * m + c;
                if (grid[r][c] == 'T')
                    target = r * m + c;
            }
        }
        vector<vector<int>> portals(n * m);
        while (q--) {
            int a, b, c, d;
            cin >> a >> b >> c >> d;
            if (grid[a][b] != '#' && grid[c][d] != '#')
                portals[a * m + b].push_back(c * m + d);
        }
        const int inf = 1000000000;
        vector<int> distance(n * m, inf);
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;
        distance[start] = 0;
        heap.push({0, start});
        int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
        while (!heap.empty()) {
            auto [cost, u] = heap.top();
            heap.pop();
            if (cost != distance[u])
                continue;
            if (u == target)
                break;
            auto relax = [&](int v, int w) {
                if (distance[v] > cost + w) {
                    distance[v] = cost + w;
                    heap.push({distance[v], v});
                }
            };
            int r = u / m, c = u % m;
            for (int d = 0; d < 4; d++) {
                int rr = r + dr[d], cc = c + dc[d];
                if (rr >= 0 && rr < n && cc >= 0 && cc < m && grid[rr][cc] != '#')
                    relax(rr * m + cc, 1);
            }
            for (int v : portals[u])
                relax(v, 3);
        }
        cout << (distance[target] == inf ? -1 : distance[target]) << '\n';
    }
    return 0;
}
```

### 复杂度

记 $V=nm$，时间 $O((V+q)\log V)$，空间 $O(V+q)$。

### 易错点

坐标从0开始，传送是单向且要3秒，不可以用普通BFS把所有边视为一步。
