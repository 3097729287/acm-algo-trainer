## 小X的多边形

### 题意

按顺时针或逆时针给定凸多边形顶点，求面积并四舍五入为整数。

### 思路

用鞋带公式累加 x[i]y[i+1]-y[i]x[i+1]，其绝对值等于面积的两倍。坐标是整数，所以两倍面积是整数；取 (abs(sum)+1)/2 就实现非负面积的四舍五入。用 __int128 保存乘积与累加，最后按十进制输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> x(n), y(n);
    for (int i = 0; i < n; i++)
        cin >> x[i] >> y[i];
    __int128 area2 = 0;
    for (int i = 0; i < n; i++) {
        int j = (i + 1) % n;
        area2 += (__int128)x[i] * y[j] - (__int128)y[i] * x[j];
    }
    if (area2 < 0)
        area2 = -area2;
    __int128 ans = (area2 + 1) / 2;
    string out;
    do {
        out += char('0' + ans % 10);
        ans /= 10;
    } while (ans);
    reverse(out.begin(), out.end());
    cout << out;
    return 0;
}
```

### 复杂度

时间与坐标数组空间均为 $O(n)$。

### 易错点

最后一个点还要连接第一个点。顶点顺序可能相反，应在总和之后取绝对值。
