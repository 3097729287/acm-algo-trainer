## 牛牛国的战争

### 题意

每个我方部队只能攻击一次，必须消灭全部敌军，最大化战后我方存活总数。

### 思路

按敌军防御从大到小处理，将攻击力足够消灭当前敌人的全部未用我军放入按防御排序的 multiset。这些部队也都能打后面防御更低的敌人。若集合为空则无法完成。优先选防御严格大于敌军攻击的最小值，以存活且留下更强防御；若没有这样的部队，当前必有一支牺牲，选最小防御者。

交换论证：固定任一最优分配。当前贪心选的部队若原本分配给后面的敌人，可与最优方案当前用兵交换，攻击条件仍满足。选到最弱的可存活者时，被换到后面的部队防御不小于它，或当前方案原本要牺牲从而已多救一人；选到最弱且必死者时，其他可用部队也全会死，换到后面不会变差。故逐步固定贪心选择可保持最优。初始 n 支均存活，每次被敌军消灭才减一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    for (int tc = 1; tc <= tests; tc++) {
        int n, m;
        cin >> n >> m;
        vector<pair<int, int>> ours(n), enemies(m);
        for (auto &[attack, defense] : ours)
            cin >> attack >> defense;
        for (auto &[defense, attack] : enemies)
            cin >> attack >> defense;
        sort(ours.rbegin(), ours.rend());
        sort(enemies.rbegin(), enemies.rend());
        multiset<int> defense;
        int j = 0, survivors = n;
        bool possible = true;
        for (auto [need, enemyAttack] : enemies) {
            while (j < n && ours[j].first >= need) {
                defense.insert(ours[j].second);
                j++;
            }
            if (defense.empty()) {
                possible = false;
                break;
            }
            auto it = defense.upper_bound(enemyAttack);
            if (it == defense.end()) {
                it = defense.begin();
                survivors--;
            }
            defense.erase(it);
        }
        cout << "Case #" << tc << ": " << (possible ? survivors : -1) << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O((n+m)\log(n+m))$，空间 $O(n+m)$。

### 易错点

攻击力等于防御力也会消灭对手，我军存活要求防御严格大于敌攻击。没出战的我军也计入存活数。
