## 多组数据a+b III

### 题意

逐组相加，读到两个数同时为零时结束，该组不输出。

### 思路

先读取一整对，再判断 a==0 且 b==0；如果成立就退出，否则输出和。单独一个零仍是正常数据。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    while (cin >> a >> b) {
        if (a == 0 && b == 0)
            break;
        cout << a + b << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(T)$，额外空间 $O(1)$。

### 易错点

结束条件需要两个数都为零，不能写成 a==0 或 b==0。
