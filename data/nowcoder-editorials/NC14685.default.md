## 加边的无向图

### 题意

给无向图加最少的边，使任意两点可达。

### 思路

每次成功合并两个连通块，块数减一。最终若有 c 块，一条新边最多减少一个块，所以至少加 c−1 条；把各块代表连成一条链就能达到。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    DSU dsu(n);
    int components = n;
    while (m--) {
        int a, b;
        cin >> a >> b;
        if (dsu.unite(a, b))
            components--;
    }
    cout << components - 1;
    return 0;
}
```

### 复杂度

时间 $O((n+m)\alpha(n))$，空间 $O(n)$。

### 易错点

原有重边或自环不减少连通块数，只有合并成功才减。
