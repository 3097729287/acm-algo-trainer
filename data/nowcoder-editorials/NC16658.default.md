## 不高兴的津津

> 原题：[P1085](https://www.luogu.com.cn/problem/P1085)
> 解法：扫描并保留首次最大值 · C++17

### 题意

一周七天，每天两种上课时间相加；超过八小时才不高兴，求最不高兴且最早的一天，否则输出零。



### 思路

从周一向周日扫描。把“已知最大时长”初始化为八，只在当天总时长严格更大时更新答案。

时间与额外空间均为 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int best = 8, answer = 0;
    for (int day = 1; day <= 7; day++) {
        int a, b;
        cin >> a >> b;
        if (a + b > best) {
            best = a + b;
            answer = day;
        }
    }
    cout << answer << '\n';
    return 0;
}
```

### 易错点

更新条件用严格大于；恰好八小时不算不高兴。
