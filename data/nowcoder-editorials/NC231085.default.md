## Strange_Functions

### 题意

判断每个函数能否在某个自变量处严格小于其他所有函数。

### 思路

反正切在非负数上单调。把比较量$k_i/|\cos(x-a_i)|$取倒数，等价于让$|\cos(x-a_i)|/k_i$严格最大。展开余弦，令$v_i=(\cos a_i/k_i,\sin a_i/k_i)$、$u=(\cos x,\sin x)$，就是最大化$|u\cdot v_i|=\max(u\cdot v_i,u\cdot(-v_i))$。

因此构造所有±v_i的凸包。某个函数能够严格胜出，当且仅当它的一个点是严格凸包顶点，且该坐标没有另一个函数重复：顶点有一段非空外法向角域使它唯一取最大；边内点与内部点均不能唯一最大。a的单位为弧度，直接计算sin/cos，不转成度。删除共线中间点，最终标记保留下来的顶点所属函数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Vertex {
        long double x, y;
        int id;
    };
    vector<Vertex> p;
    for (int i = 0; i < n; i++) {
        long double k, a;
        cin >> k >> a;
        long double x = cosl(a) / k, y = sinl(a) / k;
        p.push_back({x, y, i});
        p.push_back({-x, -y, i});
    }
    sort(p.begin(), p.end(), [](auto a, auto b) { return a.x != b.x ? a.x < b.x : a.y < b.y; });
    auto turn = [](Vertex a, Vertex b, Vertex c) {
        return (b.x - a.x) * (c.y - b.y) - (b.y - a.y) * (c.x - b.x);
    };
    vector<Vertex> hull;
    for (auto q : p) {
        while (hull.size() >= 2 && turn(hull[hull.size() - 2], hull.back(), q) <= 0)
            hull.pop_back();
        hull.push_back(q);
    }
    int lower = hull.size();
    for (int i = (int)p.size() - 2; i >= 0; i--) {
        while ((int)hull.size() > lower && turn(hull[hull.size() - 2], hull.back(), p[i]) <= 0)
            hull.pop_back();
        hull.push_back(p[i]);
    }
    if (hull.size() > 1)
        hull.pop_back();
    string answer(n, '0');
    for (auto q : hull)
        answer[q.id] = '1';
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

输入保证(k,a)不重复，a为整数弧度；非零整数不可能恰为π的整数倍，故不同函数不会产生完全相同的±v。用long double计算，不设过大绝对EPS去吞掉小半径凸包转角。
