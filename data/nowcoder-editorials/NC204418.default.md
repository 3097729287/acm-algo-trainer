## 新集合

### 思路

n最多20，用二进制mask枚举所有子集。给每个数存不能与它同选的位集。去掉mask最低位得到rest；mask合法当且仅当rest合法，且新增数的禁配位集与rest不相交。每个mask常数次位运算即可，空集也算一种。

### 参考代码

原站已定义Point，提交时保留其x、y成员接口，无需重复定义。

```cpp
#include <bits/stdc++.h>
using namespace std;
// Point is supplied by the platform, with integer members x and y.
class Solution {
  public:
    int solve(int n, int m, vector<Point> &limit) {
        (void)m;
        vector<int> forbidden(n);
        for (auto p : limit) {
            forbidden[p.x - 1] |= 1 << (p.y - 1);
            forbidden[p.y - 1] |= 1 << (p.x - 1);
        }
        vector<bool> valid(1 << n);
        valid[0] = true;
        int answer = 1;
        for (int mask = 1; mask < (1 << n); mask++) {
            int bit = __builtin_ctz((unsigned)mask), rest = mask & (mask - 1);
            valid[mask] = valid[rest] && !(forbidden[bit] & rest);
            answer += valid[mask];
        }
        return answer;
    }
};
```

### 复杂度

时间O(m+2^n)，空间O(n+2^n)。

### 易错点

输入编号从1开始，压位前减一。限制重复不会多扣方案。
