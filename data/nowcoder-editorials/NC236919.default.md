## Stone Game

### 题意

每箱一次可添1到当前石子平方个，不超容量，多箱组合。

### 思路

单箱容量s、当前c。若c=0，无论剩余容量多少都不能放，SG=0。若c²≥s−c，一步可到任意更大c，故SG=s−c。

否则令t为满足t(t+1)≥s的最小整数。所有c≥t都属于上一种情形。对c<t，跨入高区的后继SG最小为s−(c+c²)，而s≥t²−t+1，所以它≥(t−1−c)(t+c)+1>t−1−c。这些高SG不会影响只看低区时的mex（低区后继总数不超过t−1−c），因此可把容量缩为t−1，SG不变。反复平方根缩小后进入直接求值情形，最后各箱SG异或。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    auto grundy = [](long long s, long long c) {
        if (!c)
            return 0LL;
        while (c * c < s - c) {
            long long t = sqrtl(s);
            while (t * (t + 1) < s)
                t++;
            while (t > 0 && (t - 1) * t >= s)
                t--;
            s = t - 1;
        }
        return s - c;
    };
    long long total = 0;
    while (n--) {
        long long s, c;
        cin >> s >> c;
        total ^= grundy(s, c);
    }
    cout << (total ? "Yes" : "No");
    return 0;
}
```

### 复杂度

每箱 $O(\log\log s)$ 轮整数阈值计算，空间 $O(1)$。

### 易错点

c=0时不能添加，必须单独返回0。缩减的是容量s，当前c保持不变。
