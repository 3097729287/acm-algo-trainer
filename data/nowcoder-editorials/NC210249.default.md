## 打砖块(brike)

### 题意

三角砖堆选m块，每块需先敲掉其上方两块，最大价值。

### 思路

按输入的从上到下层编号r，砖(r,j)要求(r−1,j)、(r−1,j+1)都已选。因此每一竖列j选择前h[j]块，并须h[j+1]≥h[j]−1，列长为n−j+1；这两个条件也充分。

按列DP，状态为已用块数及上一列高度。当前列选g块，合法上一高度h≤g+1，贡献为本列前g块价值和。对固定已用块数，预先对上一高度做前缀最大值，就能常数时间得到max(h≤g+1)，总复杂度降为O(n²m)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> value(n + 1, vector<int>(n + 1));
    for (int r = 1; r <= n; r++)
        for (int j = 1; j <= n - r + 1; j++)
            cin >> value[r][j];
    const int negative = -1000000000;
    vector<vector<int>> dp(m + 1, vector<int>(n + 2, negative));
    dp[0][0] = 0;
    for (int j = 1; j <= n; j++) {
        for (int used = 0; used <= m; used++)
            for (int h = 1; h <= n + 1; h++)
                dp[used][h] = max(dp[used][h], dp[used][h - 1]);
        vector<vector<int>> next(m + 1, vector<int>(n + 2, negative));
        int prefix = 0;
        for (int g = 0; g <= n - j + 1 && g <= m; g++) {
            if (g)
                prefix += value[g][j];
            for (int used = g; used <= m; used++)
                if (dp[used - g][g + 1] > negative)
                    next[used][g] = dp[used - g][g + 1] + prefix;
        }
        dp.swap(next);
    }
    cout << *max_element(dp[m].begin(), dp[m].end());
    return 0;
}
```

### 复杂度

时间 $O(n^2m)$，空间 $O(nm)$。

### 易错点

题面前半段的层长度措辞有混淆，按明确输入格式和依赖关系：最上层n块，下一层n−1块。选块数按恰好m处理。
