## [NOIP2001]统计单词个数

### 题意

把字符串分k个非空段，每段可数重叠单词，但同一起点最多选一个词，最大化总词数。

### 思路

对每个起点i，只需记录能匹配的最短字典词的结束位置end[i]：同起点最多计一个，更短词在任何包含较长词的区间中也完整存在。于是区间[l,r]的最多词数，是其中满足end[i]≤r的起点个数。预处理cost[l][r]=cost[l+1][r]+(end[l]≤r)。

再做分段DP，dp[t][i]表示前i个字符分成t段的最大词数，枚举末段起点j，转自dp[t−1][j]+cost[j][i−1]。只允许j<i，保证每段非空；不可达状态为负无穷。字典词可重叠，但不能跨分段边界。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int lines, parts;
    while (cin >> lines >> parts) {
        string s, fragment;
        for (int i = 0; i < lines; i++) {
            cin >> fragment;
            s += fragment;
        }
        int count;
        cin >> count;
        vector<string> words(count);
        for (auto &w : words)
            cin >> w;
        int n = s.size();
        vector<int> end(n, n);
        for (int i = 0; i < n; i++)
            for (const auto &w : words)
                if (i + (int)w.size() <= n && s.compare(i, w.size(), w) == 0)
                    end[i] = min(end[i], i + (int)w.size() - 1);
        vector<vector<int>> cost(n + 1, vector<int>(n));
        for (int l = n - 1; l >= 0; l--)
            for (int r = l; r < n; r++)
                cost[l][r] = cost[l + 1][r] + (end[l] <= r);
        const int neg = -1000000000;
        vector<int> dp(n + 1, neg);
        dp[0] = 0;
        for (int p = 1; p <= parts; p++) {
            vector<int> next(n + 1, neg);
            for (int i = p; i <= n; i++)
                for (int j = p - 1; j < i; j++)
                    if (dp[j] != neg)
                        next[i] = max(next[i], dp[j] + cost[j][i - 1]);
            dp.swap(next);
        }
        cout << dp[n] << '\n';
    }
    return 0;
}
```

### 复杂度

字符串长 $n\le200$、词数 $D\le6$、最长词 $L$，时间 $O(nDL+kn^2)$，空间 $O(n^2)$。

### 易错点

同起点匹配多个词仍只能算一次，不同起点可以重叠。各行输入先拼接，换行不是分段点。
