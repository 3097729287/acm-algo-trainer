## 默契

### 题意

两个数相等时输出 Tacit！，否则输出 No Tacit!。

### 思路

只需比较两个整数是否相等。相等分支的叹号是全角字符，另一分支使用半角叹号，分别保存完整字符串。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int x, y;
    cin >> x >> y;
    cout << (x == y ? "Tacit！" : "No Tacit!");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

两处叹号的编码不同，必须遵循原题样例。
