## [NOIP2018]道路铺设

### 题意

连续区间单位高度调整，求最少操作次数。

### 思路

从左到右看，每当当前高度h高于左邻prev，至少要从当前位置新开h−prev次操作；否则可以延续左边已有的层。所有上升差之和是下界，也能通过逐层延续区间实现。令最左外侧高度为0，答案Σmax(0,h[i]−h[i−1])。道路填坑可把方案反向看成从零堆出原深度，最少次数相同。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long previous = 0, answer = 0;
    while (n--) {
        long long h;
        cin >> h;
        answer += max(0LL, h - previous);
        previous = h;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

下降时不增加操作，也不从答案扣除。把初始左邻设为0，避免漏掉第一段。
