## [USACO 2007 Ope S]City Horizon

### 题意

求多个地面矩形楼房轮廓覆盖面积。

### 思路

把每座楼的左右端点变为加入/删除高度事件，按x排序。两事件x之间最高楼高不变，面积增加宽度乘当前最高高度。multiset保存全部在场楼高，加入0作为地面哨兵；删除仅删一份。相同x的事件之间宽度为0，不影响面积。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<long long, 3>> event;
    for (int i = 0; i < n; i++) {
        long long a, b, h;
        cin >> a >> b >> h;
        event.push_back({a, h, 1});
        event.push_back({b, h, -1});
    }
    sort(event.begin(), event.end());
    multiset<long long> height = {0};
    long long previous = event[0][0], area = 0;
    for (auto [x, h, delta] : event) {
        area += (x - previous) * *height.rbegin();
        previous = x;
        if (delta == 1)
            height.insert(h);
        else
            height.erase(height.find(h));
    }
    cout << area;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

重叠楼房只计最高处，不是把楼面积直接相加。面积用64位。
