## 牛牛的数学作业

### 题意

每组计算整数序列的极差与总体方差，方差保留三位小数。

### 思路

第一遍读取时求和、最大值与最小值，得到均值。第二遍累加每项与均值之差的平方，再除以 n。使用 long double，并按定义求偏差平方，避免“大数平方的平均值减均值平方”相消导致精度损失。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        vector<long long> a(n);
        long long lo = LLONG_MAX, hi = LLONG_MIN;
        long double sum = 0;
        for (long long &x : a) {
            cin >> x;
            sum += x;
            lo = min(lo, x);
            hi = max(hi, x);
        }
        long double mean = sum / n, variance = 0;
        for (long long x : a) {
            long double delta = x - mean;
            variance += delta * delta;
        }
        cout << hi - lo << ' ' << fixed << setprecision(3) << variance / n << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间与数组空间均为 $O(n)$。

### 易错点

题目使用总体方差，分母为 n 而非 n-1。所有数都相同时方差为零。
