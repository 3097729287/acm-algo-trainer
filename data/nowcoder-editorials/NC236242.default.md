## 序列求和

### 题意

区间向下开根，查询区间和。

### 思路

正整数反复向下开根很快变1，而1以后不变。用set只保存值>1的位置，修改区间时从lower_bound(l)遍历至r，逐点开根并给Fenwick加入差值，变1就从set移除。每个初值≤10^9最多约5次有效变化，总修改量远小于nQ。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    vector<long long> a(n + 1);
    Fenwick bit(n);
    set<int> active;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        bit.add(i, a[i]);
        if (a[i] > 1)
            active.insert(i);
    }
    while (q--) {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 2)
            cout << bit.sum(r) - bit.sum(l - 1) << '\n';
        else {
            auto it = active.lower_bound(l);
            while (it != active.end() && *it <= r) {
                int p = *it;
                long long x = sqrtl(a[p]);
                while ((x + 1) * (x + 1) <= a[p])
                    x++;
                while (x * x > a[p])
                    x--;
                bit.add(p, x - a[p]);
                a[p] = x;
                if (x == 1)
                    it = active.erase(it);
                else
                    it++;
            }
        }
    }
    return 0;
}
```

### 复杂度

总时间 $O((Q+n\log\log A)\log n)$，空间 $O(n)$。

### 易错点

不能把整个区间和开根。开方用整数平方校正，避免完全平方数的浮点误差。
