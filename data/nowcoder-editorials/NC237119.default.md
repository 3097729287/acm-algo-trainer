## Be the Winner

### 题意

每次删某堆连续苹果，可从中间分裂，取最后者输。

### 思路

长度a的一堆删连续段后剩两段b、c，b+c<a，故b xor c≤b+c<a；而只从一端删可达到0..a−1的任意值。因此普通规则单堆SG=a，新增分裂动作不会引入SG≥a的后继。

反常规则仍按反常Nim判定：若全为1，堆数偶数先手胜；否则总异或非0先手胜。证明必败大堆局面异或0时，分裂一堆将其SG从a改成严格更小的b xor c，不能保持异或0；又不可能一步进入错误的全1终局。其他局面用普通Nim的一端取法就能走到反常Nim必败态。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int total = 0;
    bool allOne = true;
    for (int i = 0; i < n; i++) {
        int a;
        cin >> a;
        total ^= a;
        allOne = allOne && a == 1;
    }
    cout << ((allOne ? n % 2 == 0 : total != 0) ? "Yes" : "No");
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

最后取者输，全1时与普通Nim结论相反。允许中间删不等于能把任意两堆合并。
