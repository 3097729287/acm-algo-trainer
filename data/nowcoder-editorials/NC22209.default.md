## 字符金字塔

### 题意

打印从 A 到指定大写字母的对称字母金字塔。

### 思路

若共有 n 层，第 i 层先输出 n-i 个空格，再输出从 A 到第 i 个字母的递增串，最后从前一个字母递减回 A。中心字母只出现一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    char last;
    cin >> last;
    int n = last - 'A' + 1;
    for (int i = 1; i <= n; i++) {
        cout << string(n - i, ' ');
        for (int j = 0; j < i; j++)
            cout << char('A' + j);
        for (int j = i - 2; j >= 0; j--)
            cout << char('A' + j);
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，临时字符串空间 $O(n)$，其中 $n≤26$。

### 易错点

下降半边从 i-2 开始，避免中心字母重复。
