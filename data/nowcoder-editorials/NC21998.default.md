## 牛牛学矩形

### 题意

先输出矩形周长，再输出面积。

### 思路

四条边由两组相等的长宽组成，周长为 2(a+b)，面积为 ab。输入最大一千，结果可以放入 int。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    cout << 2 * (a + b) << '\n' << a * b;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

两项各占一行，顺序是周长、面积。
