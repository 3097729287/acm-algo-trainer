## 第k小数

### 题意

多组整数序列中求第 k 小元素，重复值按出现次数计数。

### 思路

使用 nth_element 把下标 k-1 的元素放到排序后应在的位置，并让左边元素不大于它、右边不小于它。无需把两边内部都排好，因此平均只需线性工作量。输入可达五百万个数，使用分块 fread 快读；累计单个整数时先用 long long，兼容 int 最小值的绝对值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

class FastInput {
    static const int size = 1 << 16;
    char buffer[size];
    int position = 0, available = 0;
    int get() {
        if (position == available) {
            available = fread(buffer, 1, size, stdin);
            position = 0;
            if (!available)
                return EOF;
        }
        return buffer[position++];
    }

  public:
    int next() {
        int c = get(), sign = 1;
        while (c != '-' && (c < '0' || c > '9'))
            c = get();
        if (c == '-') {
            sign = -1;
            c = get();
        }
        long long x = 0;
        while (c >= '0' && c <= '9') {
            x = x * 10 + c - '0';
            c = get();
        }
        return (int)(x * sign);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    FastInput input;
    int tests = input.next();
    while (tests--) {
        int n = input.next(), k = input.next();
        vector<int> a(n);
        for (int &x : a)
            x = input.next();
        nth_element(a.begin(), a.begin() + k - 1, a.end());
        cout << a[k - 1] << '\n';
    }
    return 0;
}
```

### 复杂度

平均选择时间 $O(n)$，标准库可能采用退化保护；保存数组空间 $O(n)$。

### 易错点

第 k 小用零基下标 k-1。不能去重后求第 k 小；各组输入没有排序保证。
