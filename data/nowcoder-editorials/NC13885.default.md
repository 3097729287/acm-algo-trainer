## Music Problem

### 题意

每首歌至多一次，能否选非空集合使总秒数为3600的倍数。

### 思路

只关心和模3600，做非空子集余数DP。每首歌从旧状态转移，再单独加入只选此歌的余数。不能让空集合的余数0直接作为成功。

若n≥3600，一定成功：取前3600首的3600个非空前缀和，若某个模3600为0已成功，否则这些前缀只落在3599种非零余数中，必有两者同余，其间连续一段和可整除3600。故只对n<3600做DP，大输入读完后直接输出YES。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        vector<int> songs(n);
        for (int &x : songs) {
            cin >> x;
            x %= 3600;
        }
        if (n >= 3600) {
            cout << "YES\n";
            continue;
        }
        bitset<3600> can;
        for (int x : songs) {
            bitset<3600> rotated = (can << x) | (can >> (3600 - x));
            can |= rotated;
            can.set(x);
            if (can[0])
                break;
        }
        cout << (can[0] ? "YES\n" : "NO\n");
    }
    return 0;
}
```

### 复杂度

读取 $O(n)$；小规模用位集DP，时间 $O(n\lceil3600/w\rceil)$、额外状态 $O(3600)$ 位，其中 $w$ 为机器字长，输入数组 $O(n)$。

### 易错点

目标是小时，不是分钟。移位循环旋转必须基于旧can；0秒余数的单首歌就可成功。
