## Forsaken的三维数点

### 题意

动态加入三维点，查询以原点为心覆盖至少k点的最小整数半径。

### 思路

每个点仅由距离平方d=x²+y²+z²决定。先读操作，离散化全部插入点的d，再按时间执行。树状数组维护距离频数，用二进制提升查第k小距离平方，最后输出ceil(sqrt(d))。k=0时半径0；已插入数量不足k时输出−1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Operation {
        int type, k;
        long long distance;
    };
    vector<Operation> operation;
    vector<long long> coordinate;
    for (int i = 0; i < n; i++) {
        int op;
        cin >> op;
        if (op == 1) {
            long long x, y, z;
            cin >> x >> y >> z;
            long long d = x * x + y * y + z * z;
            operation.push_back({1, 0, d});
            coordinate.push_back(d);
        } else {
            int k;
            cin >> k;
            operation.push_back({2, k, 0});
        }
    }
    sort(coordinate.begin(), coordinate.end());
    coordinate.erase(unique(coordinate.begin(), coordinate.end()), coordinate.end());
    Fenwick bit(coordinate.size());
    int total = 0;
    for (auto op : operation) {
        if (op.type == 1) {
            int rank = lower_bound(coordinate.begin(), coordinate.end(), op.distance) -
                       coordinate.begin() + 1;
            bit.add(rank, 1);
            total++;
        } else if (!op.k)
            cout << 0 << '\n';
        else if (op.k > total)
            cout << -1 << '\n';
        else {
            int p = 0;
            long long remaining = op.k;
            int step = 1;
            while (step <= bit.n / 2)
                step <<= 1;
            for (; step; step >>= 1)
                if (p + step <= bit.n && bit.tree[p + step] < remaining) {
                    p += step;
                    remaining -= bit.tree[p];
                }
            long long d = coordinate[p], r = sqrtl(d);
            while (r * r < d)
                r++;
            while (r > 0 && (r - 1) * (r - 1) >= d)
                r--;
            cout << r << '\n';
        }
    }
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

重复坐标也会增加能量，频数要累加。距离平方用64位，最后用整数平方校正浮点开方。
