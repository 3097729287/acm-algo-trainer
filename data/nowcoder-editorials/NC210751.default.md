## 数字计数

### 题意

求不同数值中的最大、次大、次小、最小之间指定的四个差。

### 思路

先排序并去除重复数值，再取末尾两个与开头两个元素。依次计算最大减次大、最大减次小、次大减次小、次大减最小。重复出现不会改变数值的次序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    a.erase(unique(a.begin(), a.end()), a.end());
    int m = a.size();
    cout << a[m - 1] - a[m - 2] << ' ' << a[m - 1] - a[1] << ' ' << a[m - 2] - a[1] << ' '
         << a[m - 2] - a[0];
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，数组空间 $O(n)$。

### 易错点

次大是小于最大值的最大数值，不能让最大值的重复项占据次大位置。
