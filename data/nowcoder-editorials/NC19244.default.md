## 生日宴

### 题意

查询某个月日生日的人中，年龄第 k 大者的名字。

### 思路

用日期对一万取余得到月日，把朋友按月日分组。每组按完整出生日期从小到大排序，出生越早年龄越大；查询 (k,s) 直接输出 s 组的第 k-1 项。题目保证日期不重复且询问有答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    map<int, vector<pair<int, string>>> groups;
    for (int i = 0; i < n; i++) {
        string name;
        int date;
        cin >> name >> date;
        groups[date % 10000].push_back({date, name});
    }
    for (auto &[day, people] : groups)
        sort(people.begin(), people.end());
    while (m--) {
        int k, day;
        cin >> k >> day;
        cout << groups[day][k - 1].second << '\n';
    }
    return 0;
}
```

### 复杂度

排序总时间 $O(n\log n)$，每次定位分组 $O(\log n)$，空间 $O(n)$。

### 易错点

输入询问的顺序是 k、月日。用 cin 读入十进制整数 0220 会得到 220，和分组键一致，不要把它手写为 C++ 八进制常量。
