## [SCOI2005]最大子矩阵

### 题意

只有一列或两列，选恰好k个互不重叠子矩形，最大化总分，格值可为负。

### 思路

按行扫描，一个矩形跨越多行时，其占据的列集合必须不变。两列时当前行只有五种覆盖形态：空、仅左、仅右、左右两个独立矩形、横跨两列的一个矩形。记录“已启动矩形数、当前形态”的最优分数。

从上一行转移时，当前每个矩形可继续上一行列集合完全相同的矩形，也可重新启动；没有相同列集合则必须启动。枚举可继续者的子集，新增数等于当前矩形数减去继续数，再加本行被覆盖格的分数。允许相邻两行同一列重新启动，因为两个上下接触的矩形仍互不重叠。单列仅保留空与仅左两种形态。最后取启动数恰为k的最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    vector<array<int, 2>> a(n);
    for (int r = 0; r < n; r++)
        for (int c = 0; c < m; c++)
            cin >> a[r][c];
    vector<vector<int>> pattern{{}, {1}, {2}, {1, 2}, {3}};
    int states = m == 1 ? 2 : 5;
    const long long neg = -(1LL << 60);
    vector<vector<long long>> dp(k + 1, vector<long long>(states, neg));
    dp[0][0] = 0;
    for (int r = 0; r < n; r++) {
        vector<vector<long long>> next(k + 1, vector<long long>(states, neg));
        for (int previous = 0; previous < states; previous++)
            for (int current = 0; current < states; current++) {
                int rectangles = pattern[current].size(), covered = 0, allowed = 0;
                for (int j = 0; j < rectangles; j++) {
                    int columns = pattern[current][j];
                    covered |= columns;
                    if (find(pattern[previous].begin(), pattern[previous].end(), columns) !=
                        pattern[previous].end())
                        allowed |= 1 << j;
                }
                long long gain = (covered & 1 ? a[r][0] : 0) + (covered & 2 ? a[r][1] : 0);
                for (int continuation = allowed;; continuation = (continuation - 1) & allowed) {
                    int starts = rectangles - __builtin_popcount((unsigned)continuation);
                    for (int count = 0; count + starts <= k; count++)
                        if (dp[count][previous] != neg)
                            next[count + starts][current] =
                                max(next[count + starts][current], dp[count][previous] + gain);
                    if (continuation == 0)
                        break;
                }
            }
        dp.swap(next);
    }
    cout << *max_element(dp[k].begin(), dp[k].end());
    return 0;
}
```

### 复杂度

形态数至多5、继续子集至多4，时间 $O(nk)$，空间 $O(k+n)$，常数由固定五形态决定。

### 易错点

两列同被覆盖时，必须区分一个宽矩形与两个窄矩形，否则会错误计算启动次数。负数情况下仍要求恰好k个，不能初始化全部状态为0。
