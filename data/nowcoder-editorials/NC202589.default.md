## 魔法数字

### 思路

把当前整数作为状态，三种操作都是一条权值1的边，BFS首次到达目标就是最少次数。只需搜索0到2*max(n,m)+2：从不超过最大端点M的数平方跳到大于2M的值后，只能靠逐次减一回到目标，代价超过直接从原数步行至目标；这种超大跳跃不会最优。负数也无益，因为到负数前必须经过0，平方负数可由正数同值状态更早达到。

### 参考代码

保留原站函数接口。

```cpp
#include <bits/stdc++.h>
using namespace std;
class Solution {
  public:
    int solve(int n, int m) {
        int bound = 2 * max(n, m) + 2;
        vector<int> distance(bound + 1, -1), queue{n};
        distance[n] = 0;
        for (size_t h = 0; h < queue.size(); h++) {
            int u = queue[h];
            if (u == m)
                return distance[u];
            for (long long v : {1LL * u - 1, 1LL * u + 1, 1LL * u * u})
                if (v >= 0 && v <= bound && distance[v] == -1) {
                    distance[v] = distance[u] + 1;
                    queue.push_back(v);
                }
        }
        return -1;
    }
};
```

### 复杂度

设M=max(n,m)，时间、空间均为O(M)。

### 易错点

平方先转64位再计算，之后检查搜索边界。三个操作代价相同，使用普通BFS。
