## Number

### 题意

统计不超过 n 的数中，有多少个可以表示为素数平方、素数立方与素数四次方之和。

### 思路

先筛出不超过 √n 的素数，并分别保存不超过 n 的平方、立方、四次方列表。枚举三个列表的组合，和不超过 n 就给对应数打标记；首次标记时增加答案，避免多种表示重复计数。列表递增，部分和已超界就可以结束该层枚举。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int limit = sqrt(n);
    vector<bool> prime(limit + 1, true);
    if (limit >= 0)
        prime[0] = false;
    if (limit >= 1)
        prime[1] = false;
    for (int p = 2; p <= limit / p; p++)
        if (prime[p])
            for (int x = p * p; x <= limit; x += p)
                prime[x] = false;
    vector<long long> square, cube, fourth;
    for (long long p = 2; p <= limit; p++)
        if (prime[p]) {
            if (p * p <= n)
                square.push_back(p * p);
            if (p * p * p <= n)
                cube.push_back(p * p * p);
            if (p * p * p * p <= n)
                fourth.push_back(p * p * p * p);
        }
    vector<bool> seen(n + 1);
    int answer = 0;
    for (long long a : fourth)
        for (long long b : cube) {
            if (a + b > n)
                break;
            for (long long c : square) {
                long long sum = a + b + c;
                if (sum > n)
                    break;
                if (!seen[sum]) {
                    seen[sum] = true;
                    answer++;
                }
            }
        }
    cout << answer;
    return 0;
}
```

### 复杂度

筛法 $O(\sqrt n\log\log n)$；枚举最多 $O(\pi(n^{1/4})\pi(n^{1/3})\pi(\sqrt n))$ 次。标记空间 $O(n)$ 位。

### 易错点

同一个和可能来自不同素数组合，必须按数值去重。使用 vector<bool> 的位存储，不分配五千万个普通整数。
