## Chris and Road

### 题意

公交车向左，行人只沿竖线以至多u速度过路，求最短安全时间。

### 思路

把车固定，行人相对位置为(vt,y)。若立刻全速走，轨迹满足t−y/u=0。对车每个顶点算r=x/v−y/u，凸性使整车的r范围为[minR,maxR]。若0不在开区间内，立刻走就安全，时间w/u；否则必须等到从车后绕过，至少补足maxR的延迟。

等maxR后再全速即可实现总时间maxR+w/u。允许途中变速也不能更短：相对量t−y/u只能非减，要从凸障碍的后侧通过最终至少达到其最大r。边界接触不算撞，端点等号允许。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long double w, v, u;
    cin >> n >> w >> v >> u;
    long double minimum = 1e100L, maximum = -1e100L;
    for (int i = 0; i < n; i++) {
        long double x, y;
        cin >> x >> y;
        long double r = x / v - y / u;
        minimum = min(minimum, r);
        maximum = max(maximum, r);
    }
    long double answer = w / u;
    if (minimum < 0 && maximum > 0)
        answer += maximum;
    cout << fixed << setprecision(12) << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

车向负x移动，相对坐标要加vt。不能简单等车所有点都经过x=0，允许根据高度提前开始或贴边。
