## 【模板】乘法逆元

### 题意

素数模p下求1到n全部逆元。

### 思路

写p=q*i+r，则r≡−q*i(mod p)，两边乘逆元得到inv[i]≡−q*inv[r]。由于r<i，可以从小到大递推inv[i]=(p−p/i)*inv[p%i] mod p，初值inv[1]=1。n<p且p为素数，所有需要的逆元都存在。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, p;
    cin >> n >> p;
    vector<int> inverse(n + 1);
    inverse[1] = 1;
    for (int i = 2; i <= n; i++)
        inverse[i] = 1LL * (p - p / i) * inverse[p % i] % p;
    for (int i = 1; i <= n; i++)
        cout << inverse[i] << '\n';
    return 0;
}
```

### 复杂度

时间、空间均 $O(n)$。

### 易错点

乘法用64位；inv[0]不代表有效逆元，素数条件与i<p保证递推不会真正依赖它。
