## 选点

### 题意

二叉树选最多节点，根小于所选后代，所选左子树值大于右子树值。

### 思路

按“根、右子树、左子树”先序遍历。任意两个选中节点，若为祖孙，先出现的祖先必须更小；否则其最近公共祖先把它们分在右、左子树，右先出现且必须更小。因此合法选择与此遍历序列的严格上升子序列恰好对应。用tails二分求严格LIS即可，树遍历用栈。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> value(n + 1);
    vector<int> left(n + 1), right(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> value[i];
    for (int i = 1; i <= n; i++)
        cin >> left[i] >> right[i];
    vector<int> stack = {1};
    vector<long long> tails;
    while (!stack.empty()) {
        int u = stack.back();
        stack.pop_back();
        auto it = lower_bound(tails.begin(), tails.end(), value[u]);
        if (it == tails.end())
            tails.push_back(value[u]);
        else
            *it = value[u];
        if (left[u])
            stack.push_back(left[u]);
        if (right[u])
            stack.push_back(right[u]);
    }
    cout << tails.size();
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

顺序必须是根右左，栈中先压左再压右。严格上升用lower_bound，重复值不能同时选。
