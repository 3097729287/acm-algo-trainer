## 华华教月月做数学

### 题意

多次计算 A 的 B 次幂模 P，三者最大 10^18。

### 思路

按指数二进制做快速幂：若最低位为一就把当前底数乘入结果，再把底数平方、指数右移。每步结果都取模。两个小于 P 的数相乘仍可能接近 10^36，所以乘法先提升到 unsigned __int128，再取模转回 64 位。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        unsigned long long a, b, p;
        cin >> a >> b >> p;
        a %= p;
        unsigned long long answer = 1 % p;
        while (b) {
            if (b & 1)
                answer = (unsigned __int128)answer * a % p;
            a = (unsigned __int128)a * a % p;
            b >>= 1;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log B)$，额外空间 $O(1)$。

### 易错点

把溢出后的 long long 乘积再取模无效，必须在乘法前提升类型。P=1 时答案始终零。
