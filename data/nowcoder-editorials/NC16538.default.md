## 记数问题

### 题意

统计一到 n 的十进制表示中，目标数字出现的总次数。

### 思路

n 最大一百万，直接枚举每个数，反复对十取余检查最低位，再整除十。每出现一次都计数，同一个数可以贡献多次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, digit;
    cin >> n >> digit;
    int ans = 0;
    for (int i = 1; i <= n; i++)
        for (int x = i; x > 0; x /= 10)
            if (x % 10 == digit)
                ans++;
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，额外空间 $O(1)$。

### 易错点

不添加前导零；区间从一开始，数字零只在数的实际表示中计数。
