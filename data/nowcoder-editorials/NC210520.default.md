## Min酱要旅行

### 题意

分别禁用每件物品，输出其他物品恰好装满每个容量的方案数个位。

### 思路

先做全部物品的01计数背包f，取模10。禁用一件重量w后的方案数记g；按是否选该件物品分解，有f[j]=g[j]+g[j−w]。因此g[j]=f[j]−g[j−w]，从小到大递推，j<w时g[j]=f[j]。每件物品只需线性扫一遍容量，不必重做n次背包。重量相同的物品仍按不同编号区分，这个分解禁用的正是当前这一件。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    while (cin >> n >> m) {
        vector<int> weight(n), all(m + 1);
        for (int &x : weight)
            cin >> x;
        all[0] = 1;
        for (int w : weight)
            for (int j = m; j >= w; j--)
                all[j] = (all[j] + all[j - w]) % 10;
        for (int w : weight) {
            vector<int> without(m + 1);
            without[0] = 1;
            for (int j = 1; j <= m; j++) {
                without[j] = (all[j] - (j >= w ? without[j - w] : 0) + 10) % 10;
                cout << without[j];
            }
            cout << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每组时间 $O(nm)$，空间 $O(n+m)$。

### 易错点

求g时正序，建全体f时倒序，两种方向不同。每行各个位直接拼接，无空格。减法加10后取模。
