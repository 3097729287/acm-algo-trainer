## [JSOI2010]缓存交换

### 题意

已知全部访问请求，求容量固定的空缓存的最少缺失次数。

### 思路

先将任意大编号离散化，再倒序求每次访问的下次位置，不再访问记为 n。缓存满时淘汰下次使用最晚的页面。交换理由：若某最优策略先淘汰较早再用的页面，可改为淘汰较晚者；直到较早者再次被请求前都不增加缺失，届时再对齐两种缓存，故最优值不会变差。

大根堆存下次位置与页面，命中后也更新。旧的堆记录延迟删除，淘汰前跳过已不在缓存或下次位置过期的记录。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, capacity;
    cin >> n >> capacity;
    vector<int> a(n), values;
    for (int &x : a)
        cin >> x;
    values = a;
    sort(values.begin(), values.end());
    values.erase(unique(values.begin(), values.end()), values.end());
    for (int &x : a)
        x = lower_bound(values.begin(), values.end(), x) - values.begin();
    int kinds = values.size();
    vector<int> next(n), last(kinds, n), current(kinds, -1);
    for (int i = n - 1; i >= 0; i--) {
        next[i] = last[a[i]];
        last[a[i]] = i;
    }
    vector<bool> present(kinds);
    priority_queue<pair<int, int>> heap;
    int size = 0, misses = 0;
    for (int i = 0; i < n; i++) {
        int x = a[i];
        if (!present[x]) {
            misses++;
            if (size == capacity) {
                while (!present[heap.top().second] ||
                       current[heap.top().second] != heap.top().first)
                    heap.pop();
                present[heap.top().second] = false;
                heap.pop();
                size--;
            }
            present[x] = true;
            size++;
        }
        current[x] = next[i];
        heap.push({next[i], x});
    }
    cout << misses;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

题目编号可达十亿，不能按编号直接开数组。缓存初始为空；即使命中也要更新下次访问时间。
