## 牛牛学数列6

### 题意

首三项为零、一、一，之后每项等于前三项按一、二、一的权重求和。

### 思路

建立长度二十一的数组，初始化前三项。按下标递增计算 a[i]=a[i-3]+2a[i-2]+a[i-1]，所需的三项均已存在。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long a[21] = {};
    a[2] = a[3] = 1;
    for (int i = 4; i <= n; i++)
        a[i] = a[i - 3] + 2 * a[i - 2] + a[i - 1];
    cout << a[n];
    return 0;
}
```

### 复杂度

时间与数组空间均为 $O(n)$。

### 易错点

只有倒数第二项乘二；第一项是零，不能照搬斐波那契初始化。
