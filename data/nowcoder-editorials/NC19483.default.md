## Tobaku Mokushiroku Kaiji

### 题意

双方各有石头、剪刀、布若干张，求第一人最多能获胜几局。

### 思路

石头只能靠对方的剪刀取得胜场，贡献 min(a,e)；剪刀对布贡献 min(b,f)；布对石头贡献 min(c,d)。三类配对互不争用同一种牌，所以三个最大值可以同时取到，直接相加。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, c, d, e, f;
    cin >> a >> b >> c >> d >> e >> f;
    cout << min(a, e) + min(b, f) + min(c, d);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

目标只是最大胜场，剩余牌如何输或平不会增加胜场，也不影响已选出的获胜配对。
