## Clear And Present Danger

### 题意

必须按指定顺序经过岛屿，可绕行其他岛屿，最小化危险值总和。

### 思路

先Floyd求任意两岛间最小危险值。相邻两个指定目的地之间的绕行互不限制，可分别取最短路，再将整个指定序列的相邻距离相加。重复经过其他目的地并不妨碍之后按序正式到访，因此不必限制中间结点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> order(m);
    for (int &x : order) {
        cin >> x;
        --x;
    }
    vector<vector<long long>> distance(n, vector<long long>(n));
    for (auto &row : distance)
        for (auto &x : row)
            cin >> x;
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                distance[i][j] = min(distance[i][j], distance[i][k] + distance[k][j]);
    long long answer = 0;
    for (int i = 1; i < m; i++)
        answer += distance[order[i - 1]][order[i]];
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^3+m)$，空间 $O(n^2+m)$。

### 易错点

访问序列不能自行排序。即使经过指定序列后面的岛，也可之后再回去，题目允许多次访问。
