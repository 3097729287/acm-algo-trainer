## 选人

### 题意

选择恰好m个互不重叠非空连续段，最大总和。

### 思路

end[k]为当前前缀中选k段且最后一段以当前元素结尾的最大值，best[k]为当前前缀任意位置结束的最优值。加入x时，end[k]=max(旧end[k]+x,旧best[k−1]+x)，分别代表延长最后一段、从当前元素新开一段；best[k]取原值与新end[k]较大者。k倒序，保证best[k−1]还未使用当前元素。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    const long long negative = LLONG_MIN / 4;
    vector<long long> ending(m + 1, negative), best(m + 1, negative);
    best[0] = 0;
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        for (int k = min(i, m); k >= 1; k--) {
            ending[k] = max(ending[k], best[k - 1]) + x;
            best[k] = max(best[k], ending[k]);
        }
    }
    cout << best[m];
    return 0;
}
```

### 复杂度

时间 $O(nm)$，空间 $O(m)$。

### 易错点

恰好m段，不能把所有状态初始化0；全负数组仍必须选够。原任务需要m≤n才有合法方案。
