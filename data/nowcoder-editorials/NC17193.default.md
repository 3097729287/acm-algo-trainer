## 简单瞎搞题

### 题意

每个变量在指定整数区间取值，统计所有平方和的不同取值数。

### 思路

最大平方和是100*100²=一百万。用位集can的第s位表示和s可达，初始只有0。处理一组[l,r]时，新位集等于所有can向左平移x²位的按位或，x遍历[l,r]，完成后整体替换。每组恰选一个数，因此所有移位必须来自同一个旧位集。最后统计置一位数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    constexpr int limit = 1000001;
    bitset<limit> can, next;
    can[0] = 1;
    while (n--) {
        int l, r;
        cin >> l >> r;
        next.reset();
        for (int x = l; x <= r; x++)
            next |= can << (x * x);
        can = next;
    }
    cout << can.count();
    return 0;
}
```

### 复杂度

值域上界 $S=10^6$，区间总宽度 $R\le10^4$，时间 $O(R\lceil S/w\rceil)$，空间 $O(S)$ 位。

### 易错点

统计不同和值，方案重复不重复增加答案。不能在本组中边移位边写回can，否则会从一个区间选多个数。
