## Prime Land

### 题意

按素因子幂输入n，对n−1分解后降序输出。

### 思路

n≤30000，先用给定幂还原n，令remaining=n−1。试除全部不超过sqrt(remaining)的整数，每找到因子就除尽并记录指数；最后剩余值>1则是最后一个素因子。记录按升序生成，反向输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int k;
        cin >> k;
        int n = 1;
        while (k--) {
            int p, e;
            cin >> p >> e;
            while (e--)
                n *= p;
        }
        int remaining = n - 1;
        vector<pair<int, int>> factors;
        for (int p = 2; p * p <= remaining; p++)
            if (remaining % p == 0) {
                int exponent = 0;
                do {
                    remaining /= p;
                    exponent++;
                } while (remaining % p == 0);
                factors.push_back({p, exponent});
            }
        if (remaining > 1)
            factors.push_back({remaining, 1});
        for (int i = (int)factors.size() - 1; i >= 0; i--)
            cout << factors[i].first << ' ' << factors[i].second << (i ? ' ' : '\n');
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\sqrt n+\sum e_i)$，空间 $O(\log n)$。

### 易错点

输出不包含因子个数k，直接输出素数、指数对；次序必须降序。
