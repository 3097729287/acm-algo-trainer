## 舔狗舔到最后一无所有

### 题意

每天三种外卖，不能连续三天相同，统计n天方案数模十亿加七。

### 思路

按末尾相同店铺连续出现1天或2天分两类，数量记one、two。换店时有另外两家可选，所以新one=2*(one+two)；继续同店只允许原来连续1天，所以新two=one。第一天为one=3、two=0，预处理全部十万天后直接回答。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 1000000007;
    const int limit = 100000;
    vector<long long> answer(limit + 1);
    long long one = 3, two = 0;
    answer[1] = 3;
    for (int n = 2; n <= limit; n++) {
        long long nextOne = 2 * (one + two) % mod;
        two = one;
        one = nextOne;
        answer[n] = (one + two) % mod;
    }
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        cout << answer[n] << '\n';
    }
    return 0;
}
```

### 复杂度

预处理时间、空间 $O(10^5)$，每次询问 $O(1)$。

### 易错点

更新two前先保存新one，否则会读到本轮值。连续两天相同仍合法。
