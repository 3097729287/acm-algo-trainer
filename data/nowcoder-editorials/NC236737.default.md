## [APIO2014]回文串

### 题意

回文子串长度乘出现次数的最大值。

### 思路

回文树每个非根节点代表一个不同回文串，两个根分别为长度−1、0。加入字符c时，从当前最长回文后缀沿fail找能被c两侧包住的后缀，得到新回文；若节点不存在则建立并寻找其最长真回文后缀fail。给当前最长回文后缀次数加1。

每个位置结束的较短回文都在其fail链上，因此最后按创建编号逆序向fail累加次数，得到每个回文的真实出现次数。fail节点总比自己早建，逆编号即可。取len*count最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string s;
    cin >> n >> s;
    struct Node {
        array<int, 26> next = {};
        int length = 0, fail = 0, count = 0;
    };
    vector<Node> node;
    node.reserve(n + 2);
    node.emplace_back();
    node.emplace_back();
    node[0].length = -1;
    node[1].fail = 0;
    int last = 1;
    auto find = [&](int u, int position) {
        while (position - node[u].length - 1 < 0 || s[position - node[u].length - 1] != s[position])
            u = node[u].fail;
        return u;
    };
    for (int i = 0; i < n; i++) {
        int c = s[i] - 'a', p = find(last, i);
        if (!node[p].next[c]) {
            int u = node.size();
            node.emplace_back();
            node[u].length = node[p].length + 2;
            node[u].fail = node[u].length == 1 ? 1 : node[find(node[p].fail, i)].next[c];
            node[p].next[c] = u;
        }
        last = node[p].next[c];
        node[last].count++;
    }
    long long answer = 0;
    for (int u = (int)node.size() - 1; u >= 2; u--) {
        answer = max(answer, 1LL * node[u].length * node[u].count);
        node[node[u].fail].count += node[u].count;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

固定字母表时间 $O(n)$，空间 $O(26n)$。

### 易错点

长度−1根保证总能扩展，不参与答案。重复出现可重叠，不能只计不同回文节点数量。
