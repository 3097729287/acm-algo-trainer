## 【模板】AC 自动机（二次加强版）

### 题意

统计每个模式串在文本的出现次数，含重复模式。

### 思路

建立所有模式的Trie并构造fail指针，记录每个模式的终点。扫描文本时沿自动机转移，只给当前状态计数加1。若某模式是当前状态代表串的后缀，它的终点必在当前状态的fail祖先链上。扫描后按BFS序逆序把count[u]加到count[fail[u]]，一次性汇总全部后缀匹配。模式重复时共享终点，分别输出同一个计数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Aho {
    struct Node {
        array<int, 26> next = {};
        int fail = 0, parent = 0, letter = 0, longest = 0;
    };
    vector<Node> node;
    vector<int> order;
    int alphabet;
    char base;
    Aho(int alphabet, char base, size_t capacity) : alphabet(alphabet), base(base) {
        node.reserve(capacity);
        node.emplace_back();
    }
    int insert(const string &s) {
        int u = 0;
        for (char ch : s) {
            int c = ch - base;
            if (!node[u].next[c]) {
                int v = node.size();
                node[u].next[c] = v;
                node.emplace_back();
                node[v].parent = u;
                node[v].letter = c;
            }
            u = node[u].next[c];
        }
        node[u].longest = max(node[u].longest, (int)s.size());
        return u;
    }
    void build() {
        order = {0};
        for (int c = 0; c < alphabet; c++)
            if (node[0].next[c])
                order.push_back(node[0].next[c]);
        for (size_t i = 1; i < order.size(); i++) {
            int u = order[i], f = node[u].fail;
            node[u].longest = max(node[u].longest, node[f].longest);
            for (int c = 0; c < alphabet; c++) {
                int v = node[u].next[c];
                if (v) {
                    node[v].fail = node[f].next[c];
                    order.push_back(v);
                } else
                    node[u].next[c] = node[f].next[c];
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> pattern(n);
    size_t total = 1;
    for (auto &s : pattern) {
        cin >> s;
        total += s.size();
    }
    Aho ac(26, 'a', total);
    vector<int> end(n);
    for (int i = 0; i < n; i++)
        end[i] = ac.insert(pattern[i]);
    ac.build();
    string text;
    cin >> text;
    vector<long long> count(ac.node.size());
    int u = 0;
    for (char c : text) {
        u = ac.node[u].next[c - 'a'];
        count[u]++;
    }
    for (int i = (int)ac.order.size() - 1; i > 0; i--) {
        int v = ac.order[i];
        count[ac.node[v].fail] += count[v];
    }
    for (int v : end)
        cout << count[v] << '\n';
    return 0;
}
```

### 复杂度

模式总长L、文本长N，时间 $O(26L+N)$，空间 $O(26L+N)$。

### 易错点

不在每个字符处遍历整条fail链，否则重复字符数据可退化平方。出现允许重叠。
