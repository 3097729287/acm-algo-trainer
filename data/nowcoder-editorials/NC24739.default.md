## Lake Counting

### 题意

统计八方向相邻的水格形成多少池塘。

### 思路

逐格扫描，每遇到未处理的W就新增一个池塘，从该格BFS淹没整个八连通块。入队时把W改成点，保证每个水格只处理一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    for (auto &row : grid)
        cin >> row;
    int answer = 0;
    for (int r = 0; r < n; r++)
        for (int c = 0; c < m; c++)
            if (grid[r][c] == 'W') {
                answer++;
                vector<pair<int, int>> queue{{r, c}};
                grid[r][c] = '.';
                for (size_t h = 0; h < queue.size(); h++) {
                    auto [x, y] = queue[h];
                    for (int dx = -1; dx <= 1; dx++)
                        for (int dy = -1; dy <= 1; dy++) {
                            int xx = x + dx, yy = y + dy;
                            if (xx >= 0 && xx < n && yy >= 0 && yy < m && grid[xx][yy] == 'W') {
                                grid[xx][yy] = '.';
                                queue.push_back({xx, yy});
                            }
                        }
                }
            }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(nm)$。

### 易错点

斜对角也连通，不能只用四方向。这里直接修改地图作访问标记。
