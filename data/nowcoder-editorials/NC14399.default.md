## 素数判断

### 题意

判断是否为素数，并按升序输出全部不同质因子。

### 思路

先筛出不超过sqrt(10^9)的素数。每次用素数p试除当前剩余数，若整除就记录p一次，再反复除尽其全部幂次。p²超过剩余数后停止，剩余值若大于1则本身为最后的质因子。若得到的唯一质因子就是原数，原数为素数，否则为合数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int limit = 31623;
    vector<bool> composite(limit + 1);
    vector<int> primes;
    for (int p = 2; p <= limit; p++)
        if (!composite[p]) {
            primes.push_back(p);
            if (1LL * p * p <= limit)
                for (int x = p * p; x <= limit; x += p)
                    composite[x] = true;
        }
    int tests;
    cin >> tests;
    while (tests--) {
        long long x;
        cin >> x;
        long long remaining = x;
        vector<long long> factors;
        for (int p : primes) {
            if (1LL * p * p > remaining)
                break;
            if (remaining % p == 0) {
                factors.push_back(p);
                while (remaining % p == 0)
                    remaining /= p;
            }
        }
        if (remaining > 1)
            factors.push_back(remaining);
        cout << (factors.size() == 1 && factors[0] == x ? "isprime\n" : "noprime\n");
        for (int i = 0; i < (int)factors.size(); i++)
            cout << factors[i] << (i + 1 == (int)factors.size() ? '\n' : ' ');
    }
    return 0;
}
```

### 复杂度

预筛上界 $U=31623$，时间 $O(U\log\log U)$；每次至多 $O(\pi(\sqrt x)+\log x)$ 次运算，空间 $O(U)$。

### 易错点

例如9只输出质因子3一次。试除后剩余的大质因子也要输出，乘方比较先用64位。
