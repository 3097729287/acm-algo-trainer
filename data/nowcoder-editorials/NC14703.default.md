## 素数回文

### 题意

把给定素数除最后一位外的前缀倒序接到末尾，判断构造出的奇数长度回文数是否为素数。

### 思路

先按定义构造，如 127 变为 12721。原数可有九位，回文数最多十七位，逐因子试除到平方根可能太慢。使用六十四位范围内确定的 Miller–Rabin 检测：分解 n-1=d·2^s，对固定底数先算 a^d，再逐次平方检查是否出现 n-1；模乘用 unsigned __int128 保证中间积精确。固定七个底数的适用范围可核对 [KACTL 的原始算法说明](https://raw.githubusercontent.com/kth-competitive-programming/kactl/main/content/number-theory/MillerRabin.h)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using ull = unsigned long long;
ull multiply(ull a, ull b, ull mod) { return (unsigned __int128)a * b % mod; }
ull power(ull a, ull b, ull mod) {
    ull result = 1;
    while (b) {
        if (b & 1)
            result = multiply(result, a, mod);
        a = multiply(a, a, mod);
        b >>= 1;
    }
    return result;
}
bool isPrime(ull n) {
    if (n < 2)
        return false;
    for (ull p : {2ULL, 3ULL, 5ULL, 7ULL, 11ULL, 13ULL, 17ULL, 19ULL, 23ULL, 29ULL, 31ULL, 37ULL}) {
        if (n == p)
            return true;
        if (n % p == 0)
            return false;
    }
    ull d = n - 1;
    int s = 0;
    while ((d & 1) == 0) {
        d >>= 1;
        s++;
    }
    for (ull a : {2ULL, 325ULL, 9375ULL, 28178ULL, 450775ULL, 9780504ULL, 1795265022ULL}) {
        a %= n;
        if (a == 0)
            continue;
        ull x = power(a, d, n);
        if (x == 1 || x == n - 1)
            continue;
        bool passed = false;
        for (int r = 1; r < s; r++) {
            x = multiply(x, x, n);
            if (x == n - 1) {
                passed = true;
                break;
            }
        }
        if (!passed)
            return false;
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int originalLength = s.size();
    for (int i = originalLength - 2; i >= 0; i--)
        s += s[i];
    unsigned long long n = 0;
    for (char c : s)
        n = n * 10 + c - '0';
    cout << (isPrime(n) ? "prime" : "noprime");
    return 0;
}
```

### 复杂度

固定七个底数，每个进行 $O(\log n)$ 次常数宽整数模乘，额外空间 $O(\log n)$ 个输入字符。

### 易错点

中间那一位不能重复，如十三对应一三一而不是一三三一。普通 long long 直接相乘后再取模可能溢出。
