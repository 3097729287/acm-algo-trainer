## Winding Number

### 题意

有向闭折线对查询点的逆时针绕数，路径上输出EDGE。

### 思路

先用叉积为0且点在线段包围范围内判断边界。否则沿查询点向右发射射线，边从点下方上穿时，若点在边左侧就把绕数加1；从上方向下穿且点在边右侧时减1。纵坐标端点采用半开条件，避免射线经过顶点重复计数。各边贡献相加可得到负数和绝对值大于1的绕数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    using P = pair<long long, long long>;
    vector<P> point(n);
    for (auto &[x, y] : point)
        cin >> x >> y;
    int q;
    cin >> q;
    while (q--) {
        long long x, y;
        cin >> x >> y;
        int winding = 0;
        bool boundary = false;
        for (int i = 0; i < n; i++) {
            auto [ax, ay] = point[i];
            auto [bx, by] = point[(i + 1) % n];
            __int128 cross = (__int128)(bx - ax) * (y - ay) - (__int128)(by - ay) * (x - ax);
            if (cross == 0 && min(ax, bx) <= x && x <= max(ax, bx) && min(ay, by) <= y &&
                y <= max(ay, by)) {
                boundary = true;
                break;
            }
            if (ay <= y && by > y && cross > 0)
                winding++;
            if (ay > y && by <= y && cross < 0)
                winding--;
        }
        if (boundary)
            cout << "EDGE\n";
        else
            cout << winding << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(nm)$，空间 $O(n)$。

### 易错点

这不是只输出内外的奇偶规则，自交折线可绕多圈。坐标达10^9，叉积中间使用128位。
