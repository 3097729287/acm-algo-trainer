## 反向输出一个四位数

### 题意

反向输出四位整数，反向后开头的零也要保留。

### 思路

把输入当成四字符字符串，反转后原样输出。这样 1000 得到 0001，无须补零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    reverse(s.begin(), s.end());
    cout << s;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

如果按整数重建结果，前导零会被丢掉。
