## 只能吃土豆的牛牛

### 题意

按样例从小到大排列若干不同三的幂的非空和，求第 k 项。

### 思路

选不选第 i 个土豆，正好对应三进制第 i-1 位上的零或一。保持位序，把 k 的二进制解释成三进制即可。原文写“第 k 大”，但无限集合没有第 k 大，样例明确采用从小到大的第 k 项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    for (int tc = 1; tc <= t; tc++) {
        long long k;
        cin >> k;
        long long power = 1, ans = 0;
        while (k) {
            if (k & 1)
                ans += power;
            k >>= 1;
            power *= 3;
        }
        cout << "Case #" << tc << ": " << ans << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log k)$，额外空间 $O(1)$。

### 易错点

位数可达三十一，三的幂及答案必须使用 long long。输出含 Case、井号、冒号和空格。
