## Blocks

### 题意

四种颜色长n序列，红绿数量均为偶数。

### 思路

对红、绿的次数分别用(1+(-1)^count)/2筛偶数，展开四项。代入每种颜色的权值，四个总权和分别为4、2、2、0，所以答案(4^n+2*2^n+0^n)/4。n≥1，最后一项为0，快速幂模10007，乘4逆元2502。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    const long long mod = 10007;
    auto power = [&](long long a, int n) {
        long long result = 1;
        while (n) {
            if (n & 1)
                result = result * a % mod;
            a = a * a % mod;
            n >>= 1;
        }
        return result;
    };
    while (tests--) {
        int n;
        cin >> n;
        cout << (power(4, n) + 2 * power(2, n)) % mod * 2502 % mod << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log n)$，空间 $O(1)$。

### 易错点

两种颜色各自为偶数，比它们数量之和为偶数更严格。n=0不在输入范围内。
