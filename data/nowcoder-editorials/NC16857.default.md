## [NOI1999]生日蛋糕

### 题意

固定整数体积的多层圆柱蛋糕，半径和高度自下而上严格减小，最小化外表面积除以π。

### 思路

从最下层向上搜索剩余k层。半径、高度都至少k，否则放不下上面严格更小的k−1层。预处理最少体积Σ(i³)和最少侧面积Σ(2i²)，剩余体积不足或面积下界已不优就剪枝。侧面贡献为2rh，所有顶部和台阶水平面积会望远镜相消，合计只需最下层半径平方。

若下一层半径至多R−1，则剩余体积V产生的侧面积至少ceil(2V/(R−1))，还可加强下界。枚举合法r、h并扣体积、加面积，层数归零且体积恰为0时更新答案。无可行结构输出0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int volume, layers;
    cin >> volume >> layers;
    vector<int> minVolume(layers + 1), minSide(layers + 1);
    for (int i = 1; i <= layers; i++) {
        minVolume[i] = minVolume[i - 1] + i * i * i;
        minSide[i] = minSide[i - 1] + 2 * i * i;
    }
    int best = 1000000000;
    auto dfs = [&](auto &&self, int remaining, int k, int maxRadius, int maxHeight,
                   int area) -> void {
        if (k == 0) {
            if (remaining == 0)
                best = min(best, area);
            return;
        }
        if (remaining < minVolume[k] || area + minSide[k] >= best || maxRadius <= k ||
            maxHeight <= k)
            return;
        if (area + (2 * remaining + maxRadius - 2) / (maxRadius - 1) >= best)
            return;
        int upperRadius = min(maxRadius - 1, (int)sqrt((remaining - minVolume[k - 1]) / k));
        for (int r = upperRadius; r >= k; r--) {
            int upperHeight = min(maxHeight - 1, (remaining - minVolume[k - 1]) / (r * r));
            for (int h = upperHeight; h >= k; h--)
                self(self, remaining - r * r * h, k - 1, r, h,
                     area + 2 * r * h + (k == layers ? r * r : 0));
        }
    };
    dfs(dfs, volume, layers, (int)sqrt(volume) + 1, volume + 1, 0);
    cout << (best == 1000000000 ? 0 : best);
    return 0;
}
```

### 复杂度

枚举合法递减半径、高度组合，为指数搜索；各层受体积和面积下界强剪枝。预处理和搜索栈空间 $O(M)$。

### 易错点

不包括最底部下底面，水平外露总面积是底层半径平方，不能给每层都加一个顶面积。上下层的半径与高度都严格递减。
