## 草药大师

### 题意

n≤100但容量与价值至10^9的精确0/1背包。

### 思路

这些约束不能直接开O(S)容量DP，价值和DP也可能过大。采用精确分支限界：按价值/时间降序排，搜索取或不取。对每个搜索节点，暂时允许剩余草药按比例分割，贪心装满得到分数背包上界；若上界不超过已有整数最优值，整棵分支可剪。所有剩余草药都能装下时直接全部选取。

比例比较用128位交叉乘，分数上界只在最后不能完整装入的一件上向下取整；最优值为整数，向下取整仍是合法上界。先搜索取当前物品，尽早得到较好下界。

通用0/1背包的精确求解最坏仍为指数级；按当前题面的大容量界，不能声称这个搜索有多项式最坏时间。这里给出不丢正确性的精确算法，并明确此性能限制。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long capacity;
    cin >> n >> capacity;
    struct Item {
        long long weight, value;
    };
    vector<Item> a;
    for (int i = 0; i < n; i++) {
        long long w, v;
        cin >> w >> v;
        if (w <= capacity)
            a.push_back({w, v});
    }
    sort(a.begin(), a.end(), [](auto x, auto y) {
        return (__int128)x.value * y.weight > (__int128)y.value * x.weight;
    });
    n = a.size();
    vector<long long> suffixWeight(n + 1), suffixValue(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        suffixWeight[i] = suffixWeight[i + 1] + a[i].weight;
        suffixValue[i] = suffixValue[i + 1] + a[i].value;
    }
    long long answer = 0;
    auto dfs = [&](auto &&self, int i, long long remaining, long long value) -> void {
        answer = max(answer, value);
        if (i == n)
            return;
        if (suffixWeight[i] <= remaining) {
            answer = max(answer, value + suffixValue[i]);
            return;
        }
        long long bound = value, space = remaining;
        for (int j = i; j < n; j++) {
            if (a[j].weight <= space) {
                space -= a[j].weight;
                bound += a[j].value;
            } else {
                bound += (long long)((__int128)space * a[j].value / a[j].weight);
                break;
            }
        }
        if (bound <= answer)
            return;
        if (a[i].weight <= remaining)
            self(self, i + 1, remaining - a[i].weight, value + a[i].value);
        self(self, i + 1, remaining, value);
    };
    dfs(dfs, 0, capacity, 0);
    cout << answer;
    return 0;
}
```

### 复杂度

最坏 $O(n2^n)$ 时间，空间 $O(n)$；实际剪枝量依数据而定。

### 易错点

不要按单位价值直接贪心输出，那只对可分割物品成立。本代码仅把分数贪心用于安全上界，搜索仍精确。
