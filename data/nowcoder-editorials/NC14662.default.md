## 小咪买东西

### 题意

选恰好 k 个手办，求总价值除总花费的最大值的整数部分。

### 思路

按本题整数输出要求，二分整数比值 x。存在一组选 k 个满足总比值至少 x，等价于这些手办的 Σ(v[i]-x*c[i]) 非负。每轮取变换后分数最大的 k 项判定，寻找最大可行整数，正好就是最优实数比值的向下取整。全程整数运算，不需要先算浮点再转换。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, k;
        cin >> n >> k;
        vector<long long> cost(n), value(n), score(n);
        for (int i = 0; i < n; i++)
            cin >> cost[i] >> value[i];
        int low = 0, high = 10000;
        while (low < high) {
            int mid = (low + high + 1) / 2;
            for (int i = 0; i < n; i++)
                score[i] = value[i] - mid * cost[i];
            if (k < n)
                nth_element(score.begin(), score.begin() + k, score.end(), greater<long long>());
            if (accumulate(score.begin(), score.begin() + k, 0LL) >= 0)
                low = mid;
            else
                high = mid - 1;
        }
        cout << low << '\n';
    }
    return 0;
}
```

### 复杂度

每轮平均线性选择，总平均时间 $O(n\log 10000)$，空间 $O(n)$。

### 易错点

这里输出整数部分，采用最大可行整数；不是四舍五入到最近整数。比值应是总价值除总花费，不能选单件比值前 k 项后取平均。
