## 树学

### 题意

任选树根，使所有节点深度和最小。

### 思路

先以1为根求深度和W[1]及每棵子树大小size。根从u移到儿子v时，v子树的size[v]个点距离各减1，其余n−size[v]个点各加1，所以W[v]=W[u]+n−2*size[v]。一次逆序求size，再按先序换根，取全部W最小值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct EulerTree {
    int n;
    vector<vector<int>> edge;
    vector<int> parent, depth, in, out, order;
    EulerTree(int n) : n(n), edge(n + 1), parent(n + 1), depth(n + 1), in(n + 1), out(n + 1) {}
    void add(int u, int v) {
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    void root(int start) {
        vector<int> stack = {start};
        parent[start] = 0;
        order.clear();
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            in[u] = order.size() + 1;
            order.push_back(u);
            for (int v : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    depth[v] = depth[u] + 1;
                    stack.push_back(v);
                }
        }
        vector<int> size(n + 1, 1);
        for (int i = (int)order.size() - 1; i >= 0; i--) {
            int u = order[i];
            out[u] = in[u] + size[u] - 1;
            if (parent[u])
                size[parent[u]] += size[u];
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    EulerTree tree(n);
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        tree.add(u, v);
    }
    tree.root(1);
    vector<int> size(n + 1, 1);
    vector<long long> value(n + 1);
    for (int u : tree.order)
        value[1] += tree.depth[u];
    for (int i = n - 1; i > 0; i--) {
        int u = tree.order[i];
        size[tree.parent[u]] += size[u];
    }
    long long answer = value[1];
    for (int u : tree.order)
        if (u != 1) {
            value[u] = value[tree.parent[u]] + n - 2LL * size[u];
            answer = min(answer, value[u]);
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均 $O(n)$。

### 易错点

距离和长链可达n(n−1)/2，需64位。树百万节点，使用迭代遍历。
