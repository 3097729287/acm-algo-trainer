## 网络优化

### 题意

每条服务线只能接待某一编号区间中的用户，且有容量，最大化被接待人数。

### 思路

按用户编号从小到大处理，把左端点不超过当前用户的服务线入小根堆，按右端点排序，弹出已过期的线。若还有线就给当前用户分配右端点最早的一条，并减少其剩余容量。若最优方案用另一条线服务当前用户，可以交换两条线后续服务的用户：更晚结束的线能承接较早结束的线所承接的后续用户，故不减少人数。没有可用线时只能跳过。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    while (cin >> n >> m) {
        struct Line {
            int l, r, capacity;
        };
        vector<Line> lines(m);
        for (auto &x : lines)
            cin >> x.l >> x.r >> x.capacity;
        sort(lines.begin(), lines.end(), [](auto a, auto b) { return a.l < b.l; });
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;
        int j = 0, answer = 0;
        for (int user = 1; user <= n; user++) {
            while (j < m && lines[j].l <= user) {
                if (lines[j].capacity > 0)
                    heap.push({lines[j].r, lines[j].capacity});
                j++;
            }
            while (!heap.empty() && heap.top().first < user)
                heap.pop();
            if (!heap.empty()) {
                auto [r, c] = heap.top();
                heap.pop();
                answer++;
                if (--c)
                    heap.push({r, c});
            }
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O((n+m)\log m)$，空间 $O(m)$。

### 易错点

原题多组读至EOF，没有开头测试组数。每个用户只能分配一次，线的剩余容量归零后不再入堆。
