## 牛可乐的翻转游戏

### 题意

n×m翻灯变全黑或全白，最少按键数，m≤10。

### 思路

枚举目标颜色和第一行按键。第一行按法确定后，为消掉上一行残留，第i行按键被唯一确定。每行用m位掩码，按键p对本行的影响是p xor(p<<1) xor(p>>1)，再加上下行同列影响。依次强制推出所有行，检查最后一行是否清空，累计popcount取最少。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    int full = (1 << m) - 1;
    vector<int> original(n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            char c;
            cin >> c;
            original[i] |= (c - '0') << j;
        }
    int answer = INT_MAX;
    for (int target = 0; target < 2; target++) {
        vector<int> a = original;
        if (target)
            for (int &x : a)
                x ^= full;
        for (int first = 0; first <= full; first++) {
            vector<int> press(n);
            press[0] = first;
            for (int i = 1; i < n; i++)
                press[i] = (a[i - 1] ^ press[i - 1] ^ (press[i - 1] << 1) ^ (press[i - 1] >> 1) ^
                            (i >= 2 ? press[i - 2] : 0)) &
                           full;
            int last = (a[n - 1] ^ press[n - 1] ^ (press[n - 1] << 1) ^ (press[n - 1] >> 1) ^
                        (n >= 2 ? press[n - 2] : 0)) &
                       full;
            if (!last) {
                int count = 0;
                for (int p : press)
                    count += __builtin_popcount((unsigned)p);
                answer = min(answer, count);
            }
        }
    }
    if (answer == INT_MAX)
        cout << "Impossible";
    else
        cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(2^m n+nm)$，空间 $O(n)$。

### 易错点

必须同时考虑全黑和全白。每行位移后用full截掉棋盘外位。
