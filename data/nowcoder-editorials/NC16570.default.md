## 这是一道签到题

### 题意

按顺序输出七个指定单词，每个单词占一行。

### 思路

内容固定，不读取输入。把七个单词放入一个字符串，用换行符分隔，末尾按要求不额外换行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout << "zhe\nshi\nyi\ndao\nqian\ndao\nti";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不是在同一行输出整句话；样例输入的“无”不是需要处理的数据。
