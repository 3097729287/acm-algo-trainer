## Devu and Flowers

### 题意

n种花各有上限f，恰选s朵的方案数。

### 思路

无上限时非负解数量为C(s+n−1,n−1)。对违反第i种上限的变量先减f[i]+1，再用容斥枚举违规集合S：贡献(-1)^|S|*C(s−Σ(f[i]+1)+n−1,n−1)，剩余量为负时贡献0。

组合数上项可达10^14，但下项n−1≤19且小于模数，直接连乘上项起的n−1个因子，再乘(n−1)!逆元即可。这是整数多项式恒等式，允许上项大于模数，不必把整个阶乘预处理到上项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000007;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}
struct Combinations {
    vector<long long> factorial, inverse;
    Combinations(int n) : factorial(n + 1, 1), inverse(n + 1) {
        for (int i = 1; i <= n; i++)
            factorial[i] = factorial[i - 1] * i % mod;
        inverse[n] = power(factorial[n], mod - 2);
        for (int i = n; i >= 1; i--)
            inverse[i - 1] = inverse[i] * i % mod;
    }
    long long choose(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return factorial[n] * inverse[k] % mod * inverse[n - k] % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long s;
    cin >> n >> s;
    vector<long long> f(n);
    for (auto &x : f)
        cin >> x;
    long long factorial = 1;
    for (int i = 1; i < n; i++)
        factorial = factorial * i % mod;
    long long inverse = power(factorial, mod - 2);
    int size = 1 << n;
    vector<long long> removed(size);
    long long answer = 0;
    for (int mask = 0; mask < size; mask++) {
        if (mask) {
            int bit = __builtin_ctz((unsigned)mask);
            removed[mask] = removed[mask & (mask - 1)] + f[bit] + 1;
        }
        long long remaining = s - removed[mask];
        if (remaining < 0)
            continue;
        long long ways = inverse;
        for (int j = 1; j < n; j++)
            ways = ways * ((remaining + j) % mod) % mod;
        if (__builtin_popcount((unsigned)mask) & 1)
            answer = (answer - ways + mod) % mod;
        else
            answer = (answer + ways) % mod;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n2^n+\log P)$，空间 $O(2^n+n)$。

### 易错点

上限f允许取等号，违规时应平移f+1。n=1时组合式为空乘积1，容斥自动判是否超上限。
