## 二叉树游戏

### 题意

每次删除一棵完美二叉子树，判断胜负。

### 思路

题目定义的“完全二叉”实际是每层全满的完美二叉树，节点数为2^h−1，永远为奇数。因此每步删除奇数个节点，节点总数奇偶每步翻转。只要还剩节点就有叶子，单节点子树可以删除，游戏必在空树结束。总操作次数与初始n同奇偶，所以n奇数先手胜，偶数后手胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
    }
    cout << (n % 2 ? "Alice" : "Bob");
    return 0;
}
```

### 复杂度

读入时间 $O(n)$，额外空间 $O(1)$。

### 易错点

按题目给出的“所有叶同深度且非叶都有两儿子”定义，不能套用通常仅最后一层可缺的完全二叉树。
