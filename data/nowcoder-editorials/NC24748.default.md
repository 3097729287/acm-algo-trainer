## [USACO 2010 Nov G]Cow Photographs

### 题意

排列经相邻交换变为任意循环升序排列的最少次数。

### 思路

固定目标1,2,...,n时，最少相邻交换数就是原排列逆序数，用树状数组求出。把目标首项v移到目标末尾，相当于v从最小变最大：原排列中在v前面的p−1个元素原来与它构成逆序，现在消失；后面的n−p个元素新产生逆序。所以代价变化n+1−2p。记录每个编号原位置，依次枚举n种目标起点并取最小。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> position(n + 1);
    Fenwick bit(n);
    long long inversions = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        position[x] = i;
        inversions += i - 1 - bit.sum(x);
        bit.add(x, 1);
    }
    long long answer = inversions;
    for (int value = 1; value < n; value++) {
        inversions += n + 1 - 2LL * position[value];
        answer = min(answer, inversions);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

旋转的是目标编号顺序，变化量使用该编号在原排列中的位置，不是编号本身。
