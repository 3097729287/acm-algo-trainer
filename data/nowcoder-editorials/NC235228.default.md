## 素数的个数

### 题意

统计大端点短区间的素数个数。

### 思路

先筛出不超过sqrt(R)的素数，对每个p只标记[L,R]中的合数倍数，从max(p²,ceil(L/p)*p)开始。最后数未标记位置。L≥2，无需额外处理1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> sieve(int n) {
    vector<bool> composite(n + 1);
    vector<int> primes;
    for (int p = 2; p <= n; p++)
        if (!composite[p]) {
            primes.push_back(p);
            if (1LL * p * p <= n)
                for (int x = p * p; x <= n; x += p)
                    composite[x] = true;
        }
    return primes;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long l, r;
    cin >> l >> r;
    auto primes = sieve(46341);
    vector<bool> composite(r - l + 1);
    for (long long p : primes) {
        if (p * p > r)
            break;
        for (long long x = max(p * p, (l + p - 1) / p * p); x <= r; x += p)
            composite[x - l] = true;
    }
    long long answer = 0;
    for (bool x : composite)
        answer += !x;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O((R-L+1)\log\log R+\sqrt R\log\log R)$，空间 $O(R-L+\sqrt R)$。

### 易错点

从p²起防止把区间内的素数p自身划掉。扫描与乘法用64位。
