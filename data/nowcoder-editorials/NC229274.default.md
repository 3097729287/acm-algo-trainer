## Beautiful Numbers

### 题意

只含a、b的n位数，其数位和也只含a、b，求数量。

### 思路

枚举a出现k次，b出现n−k次，数位和S=a*k+b*(n−k)。若S的每个十进制数码都为a或b，则任意选择k个位置放a都合法，贡献C(n,k)。预处理阶乘、逆阶乘，枚举k并检查S。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000007;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}
struct Combinations {
    vector<long long> factorial, inverse;
    Combinations(int n) : factorial(n + 1, 1), inverse(n + 1) {
        for (int i = 1; i <= n; i++)
            factorial[i] = factorial[i - 1] * i % mod;
        inverse[n] = power(factorial[n], mod - 2);
        for (int i = n; i >= 1; i--)
            inverse[i - 1] = inverse[i] * i % mod;
    }
    long long choose(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return factorial[n] * inverse[k] % mod * inverse[n - k] % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, n;
    cin >> a >> b >> n;
    Combinations comb(n);
    long long answer = 0;
    for (int k = 0; k <= n; k++) {
        int sum = a * k + b * (n - k);
        bool good = true;
        do {
            int digit = sum % 10;
            if (digit != a && digit != b)
                good = false;
            sum /= 10;
        } while (sum);
        if (good)
            answer = (answer + comb.choose(n, k)) % mod;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log(9n)+\log P)$，空间 $O(n)$。

### 易错点

a、b均非零，原数没有前导0问题。判断的是数位和的十进制表示，而非和只等于a或b。
