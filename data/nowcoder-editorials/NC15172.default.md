## 情人节的电灯泡

### 题意

单点翻转灯泡，查询矩形亮灯数量。

### 思路

二维树状数组支持单点增量和左上前缀矩形和，矩形查询用四个前缀容斥。保存当前灯泡状态，0变1时加1，1变0时减1。初始化先把原矩阵写入bit，再依次沿两个维度向Fenwick父节点累加，可在线性于矩阵大小的时间建表。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> state(n + 1, vector<int>(n + 1)), bit = state;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++) {
            char c;
            cin >> c;
            state[i][j] = bit[i][j] = c - '0';
        }
    for (int i = 1; i <= n; i++)
        if (i + (i & -i) <= n)
            for (int j = 1; j <= n; j++)
                bit[i + (i & -i)][j] += bit[i][j];
    for (int j = 1; j <= n; j++)
        if (j + (j & -j) <= n)
            for (int i = 1; i <= n; i++)
                bit[i][j + (j & -j)] += bit[i][j];
    auto sum = [&](int x, int y) {
        int result = 0;
        for (int i = x; i; i -= i & -i)
            for (int j = y; j; j -= j & -j)
                result += bit[i][j];
        return result;
    };
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) {
            int delta = state[x][y] ? -1 : 1;
            state[x][y] ^= 1;
            for (int i = x; i <= n; i += i & -i)
                for (int j = y; j <= n; j += j & -j)
                    bit[i][j] += delta;
        } else {
            int xx, yy;
            cin >> xx >> yy;
            cout << sum(xx, yy) - sum(x - 1, yy) - sum(xx, y - 1) + sum(x - 1, y - 1) << '\n';
        }
    }
    return 0;
}
```

### 复杂度

构建 $O(n^2)$，每次操作 $O(\log^2 n)$，空间 $O(n^2)$。

### 易错点

原矩阵逐字符读0/1，可同时兼容有无空格的行。查询两个坐标分别是左上和右下。
