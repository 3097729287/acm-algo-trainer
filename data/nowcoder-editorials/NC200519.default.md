## Tic-Tac-Toe

### 题意

只按是否存在三子连线判断井字棋结果，不检查正常轮流落子的合法性。

### 思路

分别检查三行、三列和两条对角线，共八条线。如果某条线的三个位置都是 A 或 B，就标记对应玩家获胜。两人都赢输出 invalid，只有 A 赢输出 Yes，只有 B 赢输出 No，否则 draw。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        char a[3][3];
        for (auto &row : a)
            for (char &c : row)
                cin >> c;
        bool winA = false, winB = false;
        auto check = [&](char x, char y, char z) {
            if (x == y && y == z) {
                if (x == 'A')
                    winA = true;
                if (x == 'B')
                    winB = true;
            }
        };
        for (int i = 0; i < 3; i++) {
            check(a[i][0], a[i][1], a[i][2]);
            check(a[0][i], a[1][i], a[2][i]);
        }
        check(a[0][0], a[1][1], a[2][2]);
        check(a[0][2], a[1][1], a[2][0]);
        cout << (winA && winB ? "invalid" : winA ? "Yes" : winB ? "No" : "draw") << '\n';
    }
    return 0;
}
```

### 复杂度

每组固定九格与八条线，时间与空间均为常数。

### 易错点

空格三个点连成线也不算获胜。题目明确允许一人连下多手，不能额外用棋子个数判 invalid。
