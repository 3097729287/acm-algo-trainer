## 四季

### 题意

由六位 YYYYMM 中的月份判断季节。

### 思路

对一百取余提取月份。三到五是春季，六到八是夏季，九到十一是秋季，剩余的一、二、十二月为冬季。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int date;
    cin >> date;
    int m = date % 100;
    if (m >= 3 && m <= 5)
        cout << "spring";
    else if (m >= 6 && m <= 8)
        cout << "summer";
    else if (m >= 9 && m <= 11)
        cout << "autumn";
    else
        cout << "winter";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不能用 m/3 直接作为一到四季编号，因为十二月与一二月属于同一季节。
