## [网络流24题]魔术球问题

### 题意

n柱子依次放编号球，相邻和为平方，求最多球与放法。

### 思路

对1..M建DAG，小球i→j当i<j且i+j为平方。每根柱子是递增路径，所以最少柱数=M−最大匹配。逐个加入新球，只新增指向新右点的边及一个暂时无出边的左点；最大匹配至多增加1，只需从新右点反向尝试一次交替增广。

若新球使最少柱数首次超过n，前一个球数即最优。失败增广不改变既有匹配；从没有前驱的球沿匹配后继输出各柱。邻居可由平方数s²枚举，左点为s²−新球，避免检查所有球对。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int columns;
    cin >> columns;
    vector<int> successor(1), predecessor(1), seen(1);
    int stamp = 0, matched = 0, maximum = 0;
    for (int value = 1;; value++) {
        successor.push_back(0);
        predecessor.push_back(0);
        seen.push_back(0);
        stamp++;
        auto augment = [&](auto &&self, int right) -> bool {
            int first = (int)sqrt(right + 1);
            while (first * first <= right)
                first++;
            for (int s = first; s * s < 2 * right; s++) {
                int left = s * s - right;
                if (left <= 0 || left >= right || seen[left] == stamp)
                    continue;
                seen[left] = stamp;
                if (!successor[left] || self(self, successor[left])) {
                    successor[left] = right;
                    predecessor[right] = left;
                    return true;
                }
            }
            return false;
        };
        if (augment(augment, value))
            matched++;
        if (value - matched > columns) {
            maximum = value - 1;
            break;
        }
    }
    cout << maximum << '\n';
    for (int start = 1; start <= maximum; start++)
        if (!predecessor[start]) {
            bool space = false;
            for (int u = start; u; u = successor[u]) {
                if (space)
                    cout << ' ';
                space = true;
                cout << u;
            }
            cout << '\n';
        }
    return 0;
}
```

### 复杂度

最终球数B、候选边E=O(B√B)，增量匹配保守时间 $O(BE)$，空间 $O(B)$，邻边按需生成。

### 易错点

先尝试增广再判断柱数，贪心找第一根能放的柱子不能作为一般路径覆盖证明。失败球本身不输出。
