## 货物种类

### 题意

多次把某种货物放进连续仓库，求拥有不同货物种类最多的最小仓库编号。

### 思路

同一种货物重复覆盖同一仓库只算一种。先按货物编号、区间左端点排序，把每种货物的覆盖区间合并为互不重叠的段。对每个合并段 [l,r] 做差分 +1：d[l]++、d[r+1]--。最后前缀累加就是各仓库的种类数，从左到右仅在严格更大时更新答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<tuple<int, int, int>> intervals;
    for (int i = 0; i < m; i++) {
        int l, r, kind;
        cin >> l >> r >> kind;
        if (l > r)
            swap(l, r);
        intervals.push_back({kind, l, r});
    }
    sort(intervals.begin(), intervals.end());
    vector<int> difference(n + 2);
    int kind = -1, left = 0, right = -1;
    auto flush = [&]() {
        if (left <= right) {
            difference[left]++;
            difference[right + 1]--;
        }
    };
    for (auto [d, l, r] : intervals) {
        if (d == kind && l <= right + 1)
            right = max(right, r);
        else {
            flush();
            kind = d;
            left = l;
            right = r;
        }
    }
    flush();
    int count = 0, best = -1, answer = 1;
    for (int i = 1; i <= n; i++) {
        count += difference[i];
        if (count > best) {
            best = count;
            answer = i;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(m\log m+n)$，空间 $O(n+m)$。

### 易错点

直接对每条进货区间加一会把同种货物重复计算。需要先分货物做区间并集，再跨货物累加。
