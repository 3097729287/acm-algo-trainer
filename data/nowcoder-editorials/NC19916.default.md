## [CQOI2010]扑克牌

### 题意

n 种普通牌与 m 张百搭牌，每套至多用一张百搭，最多组成多少套。

### 思路

若要组成 x 套，第 i 类普通牌的缺口为 max(0,x-c[i])，总缺口 need 必须不超过百搭总数 m，也必须不超过套数 x，因为每套至多一张百搭。条件也充分：给每个缺口安排不同的套，所有缺口总数不超过 x，不会让一套出现两个百搭；余下位置用对应普通牌填满。判定对 x 单调，可二分最大可行值。上界为所有牌数除以 n。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long m;
    cin >> n >> m;
    vector<long long> count(n);
    long long total = m;
    for (auto &x : count) {
        cin >> x;
        total += x;
    }
    auto possible = [&](long long sets) {
        long long need = 0;
        for (long long x : count) {
            need += max(0LL, sets - x);
            if (need > m || need > sets)
                return false;
        }
        return true;
    };
    long long low = 0, high = total / n;
    while (low < high) {
        long long mid = low + (high - low + 1) / 2;
        if (possible(mid))
            low = mid;
        else
            high = mid - 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

最大可能套数为 $U$，时间 $O(n\log(U+1))$，空间 $O(n)$。

### 易错点

只比较缺口与 m 不够，还要比较缺口与套数；同一套中不能用两张 Joker。所有总量使用 long long。
