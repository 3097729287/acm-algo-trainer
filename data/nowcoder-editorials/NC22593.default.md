## 签到题

### 题意

动态集合中插入、删除闭整数线段，询问所有线段覆盖的整数点数。

### 思路

样例[1,2]贡献2，说明计算的是整数点个数。将[l,r]映射成半开单位段[l,r+1)，在坐标0..L上建树。节点维护直接覆盖次数cover；cover>0时整段全覆盖，否则由子段已覆盖长度相加。集合set负责去重，只有首次插入和确实存在的删除才修改覆盖树。一次删除与先前同段插入使用完全相同的节点分解，所以cover不会错误抵消其他区间。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, limit;
    cin >> n >> limit;
    vector<int> cover(4 * (limit + 1) + 4), length(cover.size());
    auto update = [&](auto &&self, int u, int l, int r, int ql, int qr, int delta) -> void {
        if (ql <= l && r <= qr)
            cover[u] += delta;
        else {
            int mid = (l + r) / 2;
            if (ql <= mid)
                self(self, u * 2, l, mid, ql, qr, delta);
            if (qr > mid)
                self(self, u * 2 + 1, mid + 1, r, ql, qr, delta);
        }
        if (cover[u])
            length[u] = r - l + 1;
        else
            length[u] = l == r ? 0 : length[u * 2] + length[u * 2 + 1];
    };
    set<pair<int, int>> active;
    while (n--) {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 1 && active.insert({l, r}).second)
            update(update, 1, 0, limit, l, r, 1);
        else if (op == 2 && active.erase({l, r}))
            update(update, 1, 0, limit, l, r, -1);
        else if (op == 3)
            cout << length[1] << '\n';
    }
    return 0;
}
```

### 复杂度

每次修改 $O(\log L+\log N)$，查询 $O(1)$，空间 $O(L+N)$。

### 易错点

这是set而非多重集，重复加入不能重复计数。询问行仍有两个无用参数，必须读完。
