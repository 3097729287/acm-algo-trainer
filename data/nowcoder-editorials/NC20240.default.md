## [SCOI2005]互不侵犯KING

### 题意

在n乘n棋盘放恰好k个互不攻击的国王，八方向近邻均攻击。

### 思路

预处理行内无相邻1的mask。两相邻行a、b相容，需a与b、b左移1、b右移1都不相交，分别排除竖直和两种斜攻击。dp[行mask][已放数]累加相容前行的方案，增加当前行1的数量。初始空前行、0个国王为1，处理n行后对放k个的所有末行求和。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> mask, count;
    for (int x = 0; x < (1 << n); x++)
        if (!(x & (x << 1))) {
            mask.push_back(x);
            count.push_back(__builtin_popcount((unsigned)x));
        }
    int states = mask.size();
    vector<vector<int>> compatible(states);
    for (int a = 0; a < states; a++)
        for (int b = 0; b < states; b++)
            if (!(mask[a] & mask[b]) && !(mask[a] & (mask[b] << 1)) && !(mask[a] & (mask[b] >> 1)))
                compatible[a].push_back(b);
    vector<vector<long long>> dp(states, vector<long long>(k + 1));
    dp[0][0] = 1;
    for (int r = 0; r < n; r++) {
        vector<vector<long long>> next(states, vector<long long>(k + 1));
        for (int a = 0; a < states; a++)
            for (int b : compatible[a])
                for (int used = 0; used + count[a] <= k; used++)
                    next[a][used + count[a]] += dp[b][used];
        dp.swap(next);
    }
    long long answer = 0;
    for (int x = 0; x < states; x++)
        answer += dp[x][k];
    cout << answer;
    return 0;
}
```

### 复杂度

行状态数 $S$，时间 $O(nkS^2+2^n)$，空间 $O(kS+S^2)$。

### 易错点

k=0时空棋盘有一种方案。方案数使用64位，题目不要求取模。
