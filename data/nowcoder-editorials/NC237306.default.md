## 最长公共子串

### 题意

求两个长度各不超过五十万的小写字符串的最长公共子串长度。

### 思路

将两个串中间放一个未出现在字母表中的分隔符，拼成一个整数序列。建立后缀数组与相邻 LCP，扫描来源不同的相邻后缀，取其 LCP 最大值。若某个公共子串长度为 L，那么所有以它开头的后缀在后缀数组中连续，里面同时有两个源串的后缀，必存在一对来源不同的相邻后缀，LCP 至少为 L；所以只看相邻项已足够。分隔符后缀不参与答案。

后缀数组将全部后缀按字典序排序，height[i] 为相邻后缀 sa[i-1]、sa[i] 的最长公共前缀长度。参考代码采用倍增：已有长度 L 的排名后，用两个半段排名确定长度 2L 的排名，计数排序每轮线性；末尾补唯一最小符号零，把普通后缀排序转成循环移位排序。最后用 Kasai 方法在线性时间构造 height，每次从上一次公共长度减一处继续比较。所有实际字符和分隔符编码都大于零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct SuffixArray {
    vector<int> sa, height;
    explicit SuffixArray(const vector<int> &data) {
        int size = data.size(), n = size + 1;
        vector<int> symbols = data;
        symbols.push_back(0);
        int alphabet = *max_element(symbols.begin(), symbols.end()) + 1;
        vector<int> order(n), rank(n), shifted(n), nextRank(n), count(max(n, alphabet), 0);
        for (int x : symbols)
            count[x]++;
        for (int x = 1; x < alphabet; x++)
            count[x] += count[x - 1];
        for (int i = n - 1; i >= 0; i--)
            order[--count[symbols[i]]] = i;
        int classes = 1;
        rank[order[0]] = 0;
        for (int i = 1; i < n; i++) {
            if (symbols[order[i]] != symbols[order[i - 1]])
                classes++;
            rank[order[i]] = classes - 1;
        }
        for (int length = 1; length < n && classes < n; length *= 2) {
            for (int i = 0; i < n; i++) {
                shifted[i] = order[i] - length;
                if (shifted[i] < 0)
                    shifted[i] += n;
            }
            fill(count.begin(), count.begin() + classes, 0);
            for (int x : shifted)
                count[rank[x]]++;
            for (int i = 1; i < classes; i++)
                count[i] += count[i - 1];
            for (int i = n - 1; i >= 0; i--)
                order[--count[rank[shifted[i]]]] = shifted[i];
            int nextClasses = 1;
            nextRank[order[0]] = 0;
            for (int i = 1; i < n; i++) {
                int a = order[i - 1], b = order[i];
                if (rank[a] != rank[b] || rank[(a + length) % n] != rank[(b + length) % n])
                    nextClasses++;
                nextRank[b] = nextClasses - 1;
            }
            rank.swap(nextRank);
            classes = nextClasses;
        }
        sa.assign(order.begin() + 1, order.end());
        for (int i = 0; i < size; i++)
            rank[sa[i]] = i;
        height.assign(size, 0);
        int common = 0;
        for (int i = 0; i < size; i++) {
            int position = rank[i];
            if (position == 0) {
                common = 0;
                continue;
            }
            int j = sa[position - 1];
            while (i + common < size && j + common < size && data[i + common] == data[j + common])
                common++;
            height[position] = common;
            if (common)
                common--;
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s, t;
    cin >> s >> t;
    vector<int> data;
    data.reserve(s.size() + t.size() + 1);
    for (char c : s)
        data.push_back(c - 'a' + 2);
    int separator = data.size();
    data.push_back(1);
    for (char c : t)
        data.push_back(c - 'a' + 2);
    SuffixArray index(data);
    auto owner = [&](int p) { return p < separator ? 0 : p == separator ? -1 : 1; };
    int answer = 0;
    for (int i = 1; i < (int)index.sa.size(); i++) {
        int a = owner(index.sa[i - 1]), b = owner(index.sa[i]);
        if (a >= 0 && b >= 0 && a != b)
            answer = max(answer, index.height[i]);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

总长 $N=|s|+|t|+1$，时间 $O(N\log N)$，空间 $O(N)$。

### 易错点

求的是连续子串，不是最长公共子序列。分隔符必须不同于所有字符，防止公共前缀跨越两个源串。
