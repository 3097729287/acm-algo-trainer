## Ranking the Cows

### 题意

已有部分产奶高低关系，预先固定追加比较清单，保证比较后能完全排序，求最少对数。

### 思路

先求已有大小关系的传递闭包。已能比较的点对无需询问；每个互不可比点对都必须在固定清单中比较：对任意这样的a、b，可将二者共同前驱先排好，再令a、b相邻，分别交换它们可得两个符合全部旧关系的全序。它们对除(a,b)外所有点对的比较结果都相同，因此漏掉该对就无法保证区分。故答案正是不可比无序对数。

用bitset维护每点能到的低排名点，Floyd发现i能到k时，将k的整个集合并给i，字长并行加速。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<bitset<1000>> reach(n);
    while (m--) {
        int a, b;
        cin >> a >> b;
        reach[a - 1][b - 1] = 1;
    }
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            if (reach[i][k])
                reach[i] |= reach[k];
    int answer = 0;
    for (int a = 0; a < n; a++)
        for (int b = a + 1; b < n; b++)
            if (!reach[a][b] && !reach[b][a])
                answer++;
    cout << answer;
    return 0;
}
```

### 复杂度

机器字长 $w$，时间 $O(n^3/w+n^2)$，空间 $O(n^2)$ 位。

### 易错点

清单要事先固定并保证所有可能答案都能排序，因此不是自适应比较排序所需次数。每对只按a<b统计一次。
