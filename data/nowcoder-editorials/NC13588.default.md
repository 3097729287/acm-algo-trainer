## 从后台研发到跑路

### 题意

删除引号外完整配对的块注释，保留字符串、转义引号和未配对的注释符号。

### 思路

读入整个文件并扫描。当前若在引号内，就保留字符直到对应的非转义引号；转义引号作为普通文本保留。只有在引号外遇到 /* 时才寻找后面的第一个 */，有则整段跳过，没有则余下全部原样保留。注释内的引号与另一个 /* 都不改变它的结束位置。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s((istreambuf_iterator<char>(cin)), istreambuf_iterator<char>()), answer;
    char quote = 0;
    for (size_t i = 0; i < s.size();) {
        if (s[i] == '\\' && i + 1 < s.size() && (s[i + 1] == '"' || s[i + 1] == '\'')) {
            answer += s[i++];
            answer += s[i++];
            continue;
        }
        if (quote) {
            char c = s[i++];
            answer += c;
            if (c == quote)
                quote = 0;
            continue;
        }
        if (s[i] == '"' || s[i] == '\'') {
            quote = s[i];
            answer += s[i++];
            continue;
        }
        if (i + 1 < s.size() && s[i] == '/' && s[i + 1] == '*') {
            auto end = s.find("*/", i + 2);
            if (end == string::npos) {
                answer += s.substr(i);
                break;
            }
            i = end + 2;
        } else
            answer += s[i++];
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间与输入输出缓冲空间均为 $O(L)$，这里 $L≤5$ KB。

### 易错点

输出需要逐字保留注释之外的空格和换行，不能按单词读取再拼接。未配对的 /* 不是注释，应保留。
