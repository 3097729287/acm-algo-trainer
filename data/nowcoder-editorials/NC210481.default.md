## 筛子游戏

### 题意

三骰指定组合清零，其余加点数，求分数超过n的期望次数。

### 思路

设E[i]是当前分数i的剩余次数，超过n后为0。一次掷骰后E[i]=1+pReset*E[0]+Σ pSum[s]*E[i+s]。把E[i]表示为A[i]*E[0]+B[i]，倒序计算A[i]=pReset+ΣpSum[s]A[i+s]、B[i]=1+ΣpSum[s]B[i+s]。最后E[0]=B[0]/(1−A[0])。

枚举全部骰子组合，只把非清零组合按点数和归类。若三个骰子都只有1面，则每次必清零，期望无穷；当前题面没有规定此退化情况的输出，代码用inf表达，有限期望数据按公式输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k1, k2, k3, a, b, c;
    cin >> n >> k1 >> k2 >> k3 >> a >> b >> c;
    int maximum = k1 + k2 + k3;
    long double total = k1 * k2 * k3;
    vector<long double> probability(maximum + 1);
    for (int x = 1; x <= k1; x++)
        for (int y = 1; y <= k2; y++)
            for (int z = 1; z <= k3; z++)
                if (x != a || y != b || z != c)
                    probability[x + y + z] += 1 / total;
    vector<long double> coefficient(n + maximum + 1), constant(n + maximum + 1);
    for (int i = n; i >= 0; i--) {
        coefficient[i] = 1 / total;
        constant[i] = 1;
        for (int s = 3; s <= maximum; s++) {
            coefficient[i] += probability[s] * coefficient[i + s];
            constant[i] += probability[s] * constant[i + s];
        }
    }
    if (k1 * k2 * k3 == 1)
        cout << "inf";
    else
        cout << fixed << setprecision(12) << constant[0] / (1 - coefficient[0]);
    return 0;
}
```

### 复杂度

时间 $O(k_1k_2k_3+n(k_1+k_2+k_3))$，空间 $O(n+k_1+k_2+k_3)$。

### 易错点

目标是严格大于n，i=n仍需继续。清零组合不能同时计入普通点数和。
