## 鱼

### 题意

鱼随机两两相遇并互食，求每条鱼最后存活概率。

### 思路

dp[mask]为当前存活集合恰是mask的概率，初始全体为1。集合有k条鱼时，每个无序鱼对相遇概率为1/C(k,2)。枚举集合中的i<j，按a[i][j]转移到删j的集合，按a[j][i]转移到删i的集合。删位后掩码严格变小，按掩码倒序即可保证前驱先处理。最终dp[1<<i]就是i独活概率。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<long double>> a(n, vector<long double>(n));
    for (auto &row : a)
        for (auto &x : row)
            cin >> x;
    int size = 1 << n;
    vector<long double> dp(size);
    dp[size - 1] = 1;
    for (int mask = size - 1; mask >= 1; mask--) {
        int count = __builtin_popcount((unsigned)mask);
        if (count < 2)
            continue;
        long double pairProbability = dp[mask] * 2 / (count * (count - 1));
        for (int bits = mask; bits; bits &= bits - 1) {
            int i = __builtin_ctz((unsigned)bits);
            int others = mask & ~((1 << (i + 1)) - 1);
            for (; others; others &= others - 1) {
                int j = __builtin_ctz((unsigned)others);
                dp[mask ^ (1 << j)] += pairProbability * a[i][j];
                dp[mask ^ (1 << i)] += pairProbability * a[j][i];
            }
        }
    }
    cout << fixed << setprecision(10);
    for (int i = 0; i < n; i++)
        cout << dp[1 << i] << (i + 1 == n ? '\n' : ' ');
    return 0;
}
```

### 复杂度

时间 $O(n^2 2^n)$，空间 $O(2^n+n^2)$。

### 易错点

相遇的是无序对，不能再次乘2。只从当前存活鱼中选择；n=1初始状态就是最终状态。
