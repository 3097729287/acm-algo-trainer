## 素数中的等差数列

### 题意

从区间内连续素数里找至少三项的等差段，已经输出的素数不得再用于后一段。

### 思路

先筛出区间中的递增素数表。从左往右检查相邻三项，若前两段差不相同就推进起点；若相同，就尽量延长当前差值的等差段并输出，随后把起点移到这整段之后。这样不会让前后两段共享端点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    vector<bool> prime(b + 1, true);
    prime[0] = prime[1] = false;
    for (int p = 2; p <= b / p; p++)
        if (prime[p])
            for (int x = p * p; x <= b; x += p)
                prime[x] = false;
    vector<int> values;
    for (int x = max(2, a); x <= b; x++)
        if (prime[x])
            values.push_back(x);
    int i = 0;
    while (i + 2 < (int)values.size()) {
        int d = values[i + 1] - values[i];
        if (values[i + 2] - values[i + 1] != d) {
            i++;
            continue;
        }
        int j = i + 2;
        while (j + 1 < (int)values.size() && values[j + 1] - values[j] == d)
            j++;
        for (int k = i; k <= j; k++) {
            if (k > i)
                cout << ' ';
            cout << values[k];
        }
        cout << '\n';
        i = j + 1;
    }
    return 0;
}
```

### 复杂度

筛法 $O(b\log\log b)$，扫描 $O(\pi(b))$，空间 $O(b)$。

### 易错点

本题明确禁止相邻等差段共享一个素数，输出后必须从末项的下一项继续。
