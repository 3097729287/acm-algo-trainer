## 送分了QAQ

### 题意

统计区间中包含数字4或相邻子串38的讨厌数。

### 思路

数位状态保存上一位是否为3、此前是否已经讨厌、是否贴上界。加入d后，若d=4或上一位为3且d=8就永久标记讨厌；结束时只计讨厌状态。前导0既不是3也不是4，不会凭空产生38，因此可以补到相同位数，无需额外开始标记。非贴界状态按剩余位数记忆化，区间由两个前缀计数相减。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    auto count = [&](long long n) {
        if (n < 0)
            return 0LL;
        string s = to_string(n);
        long long memo[20][2][2];
        memset(memo, -1, sizeof(memo));
        auto dfs = [&](auto &&self, int p, bool previous3, bool bad, bool tight) -> long long {
            if (p == (int)s.size())
                return bad;
            auto &cached = memo[s.size() - p][previous3][bad];
            if (!tight && cached != -1)
                return cached;
            int limit = tight ? s[p] - '0' : 9;
            long long result = 0;
            for (int d = 0; d <= limit; d++)
                result += self(self, p + 1, d == 3, bad || d == 4 || (previous3 && d == 8),
                               tight && d == limit);
            if (!tight)
                cached = result;
            return result;
        };
        return dfs(dfs, 0, false, false, true);
    };
    long long l, r;
    while (cin >> l >> r && (l || r))
        cout << count(r) - count(l - 1) << '\n';
    return 0;
}
```

### 复杂度

每组时间 $O(位数\cdot 2^2\cdot10)$，空间 $O(位数)$。

### 易错点

题目输出讨厌数数量，不是避开讨厌数的数量。38必须相邻，不能只出现3和8就判定。
