## 小A买彩票

### 题意

买n张三元彩票，奖金均匀为1到4元，求总奖金至少3n的精确概率。

### 思路

所有4^n种奖金序列等可能。dp[sum]记录已经买若干张后，奖金总和为sum的序列数，每张依次加1、2、3、4。最后把sum≥3n的计数相加作为分子，分母为4^n，用gcd约分。n≤30，4^30=2^60在64位范围内，无需浮点或大整数。n=0的空序列不亏，概率1/1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> dp(4 * n + 1);
    dp[0] = 1;
    long long denominator = 1;
    for (int i = 0; i < n; i++) {
        vector<long long> next(4 * n + 1);
        for (int sum = 0; sum <= 4 * i; sum++)
            for (int reward = 1; reward <= 4; reward++)
                next[sum + reward] += dp[sum];
        dp.swap(next);
        denominator *= 4;
    }
    long long numerator = 0;
    for (int sum = 3 * n; sum <= 4 * n; sum++)
        numerator += dp[sum];
    long long divisor = gcd(numerator, denominator);
    cout << numerator / divisor << '/' << denominator / divisor;
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

不亏包括刚好收回3n。每张只能选四种奖金之一，不能把奖金总额视为等概率。
