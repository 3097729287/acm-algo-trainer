## 带富翁

### 题意

重掷越界骰子，向前走至终点，求累计奖励期望。

### 思路

E[i]含当前位置奖励。越界会重新掷到合法步长，因此合法的1..min(6,n−i)步等概率，E[i]=a[i]+平均(E[i+1..i+limit])。终点E[n]=a[n]，倒序求解，输出E[1]。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long double> value(n + 1), expected(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> value[i];
    for (int i = n; i >= 1; i--) {
        expected[i] = value[i];
        int limit = min(6, n - i);
        if (limit)
            for (int step = 1; step <= limit; step++)
                expected[i] += expected[i + step] / limit;
    }
    cout << fixed << setprecision(10) << expected[1];
    return 0;
}
```

### 复杂度

时间 $O(6n)$，空间 $O(n)$。

### 易错点

起点奖励也计入；接近终点时分母是合法步数，不总为6。
