## [NOIP2006]金明的预算方案

### 题意

附件必须连同所属主件购买，每主件最多两附件，最大化价格乘重要度之和。

### 思路

把一个主件及其附件组成一组。组内合法购买方案只有主件，以及主件搭配附件的所有子集，最多四种；不买整组也允许。逐主件做分组背包，预算倒序，枚举该组全部合法方案。每个方案一次性加入总价格和总价值，避免附件脱离主件。先读完全部物品，附件可能在主件前出现。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int budget, n;
    cin >> budget >> n;
    vector<int> price(n + 1), value(n + 1), parent(n + 1);
    vector<vector<int>> attachment(n + 1);
    for (int i = 1; i <= n; i++) {
        int importance;
        cin >> price[i] >> importance >> parent[i];
        value[i] = price[i] * importance;
        if (parent[i])
            attachment[parent[i]].push_back(i);
    }
    vector<int> dp(budget + 1);
    for (int main = 1; main <= n; main++)
        if (!parent[main]) {
            vector<pair<int, int>> choices;
            int k = attachment[main].size();
            for (int mask = 0; mask < (1 << k); mask++) {
                int cost = price[main], gain = value[main];
                for (int j = 0; j < k; j++)
                    if (mask >> j & 1) {
                        int id = attachment[main][j];
                        cost += price[id];
                        gain += value[id];
                    }
                choices.push_back({cost, gain});
            }
            for (int c = budget; c >= 0; c--)
                for (auto [cost, gain] : choices)
                    if (cost <= c)
                        dp[c] = max(dp[c], dp[c - cost] + gain);
        }
    cout << dp[budget];
    return 0;
}
```

### 复杂度

每组至多4种选择，时间 $O(mB)$，空间 $O(m+B)$。

### 易错点

不能对附件单独做普通01背包；必须与主件组合。预算倒序后，读取的较小预算仍是上一组状态。
