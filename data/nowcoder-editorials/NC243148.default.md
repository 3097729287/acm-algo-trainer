## The Designer

### 题意

两个内切圆之间按图示顺序填圆，求前N个小圆面积之和。

### 思路

先令大半径R、小半径r，d=R−r。第一个填圆半径为d，之后上、下两侧对称地各形成一条相切圆链。固定两个大圆的带符号曲率为−1/R、1/r；由Descartes定理，圆链曲率的二阶差分为$2(1/r-1/R)$，对称性给出$q_k=1/d+k^2d/(Rr)$，半径$\rho_k=dRr/(Rr+k^2d^2)$。

顺序是k=0一个，k=1两个，k=2两个……因此成对计入前floor((N−1)/2)层；若N为偶数，还需加下一层的一个。N可达10^7，不能对所有层逐个求和。当k>K时有$\rho_k\le A/k^2$，其中$A=Rr/d\le9900$，两条链剩余总面积不超过$2\pi A^2/(3K^3)$。取K=30000，此界小于$8\times10^{-6}$，严格低于允许的$10^{-4}$。所以只算到该层即可，舍弃有明确误差界的尾项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    const long double pi = acosl(-1.0L);
    while (tests--) {
        long double R, r;
        long long n;
        cin >> R >> r >> n;
        if (R < r)
            swap(R, r);
        long double d = R - r;
        if (d == 0) {
            cout << "0.000000000000\n";
            continue;
        }
        auto radius = [&](long long k) { return d * R * r / (R * r + (long double)k * k * d * d); };
        long long pairs = (n - 1) / 2;
        long double answer = pi * d * d;
        for (int k = 1; k <= min(30000LL, pairs); k++) {
            long double value = radius(k);
            answer += 2 * pi * value * value;
        }
        if (n % 2 == 0 && n / 2 <= 30000) {
            long double value = radius(n / 2);
            answer += pi * value * value;
        }
        cout << fixed << setprecision(12) << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\min(N,30000))$，额外空间 $O(1)$。

### 易错点

R1、R2大小顺序没有保证，应先交换。圆2和圆3半径相等，不能按同一侧链把每个编号都当成新层。截断由尾项积分界保证精度。
