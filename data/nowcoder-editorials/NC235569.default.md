## 牛可乐与NCPC

### 题意

每次加入一位候选人，统计两个评分均越小越好的非支配者人数；完全同分者互不支配。

### 思路

非支配前沿按第一评分 x 递增后，第二评分 y 必须严格递减。用 map 将 x 映射到 (y,人数)。插入 (x,y) 时，先看同 x 的旧点：旧 y 更小则新点被支配；相等则增加人数；更大则旧点应删除。再看 x 更小的最近前驱，若其 y≤新 y，新点被支配。否则新点有效，并依次删除右侧所有 y≥新 y 的点。前沿的严格单调性保证被删除点连续，每个点最多删一次。答案维护人数而非不同评分对个数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    for (int tc = 1; tc <= tests; tc++) {
        int n;
        cin >> n;
        map<int, pair<int, int>> frontier;
        int total = 0;
        cout << "Case #" << tc << ":\n";
        for (int i = 0; i < n; i++) {
            int x, y;
            cin >> x >> y;
            auto it = frontier.lower_bound(x);
            bool dominated = false;
            if (it != frontier.begin() && prev(it)->second.first <= y)
                dominated = true;
            if (it != frontier.end() && it->first == x) {
                if (it->second.first < y)
                    dominated = true;
                else if (it->second.first == y) {
                    it->second.second++;
                    total++;
                    cout << total << '\n';
                    continue;
                }
            }
            if (!dominated) {
                while (it != frontier.end() && it->second.first >= y) {
                    total -= it->second.second;
                    it = frontier.erase(it);
                }
                frontier[x] = {y, 1};
                total++;
            }
            cout << total << '\n';
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

每组摊还时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

相同的两个评分必须保留两个人；支配定义要求至少一个评分严格更好。每组结束后额外输出一个空行。
