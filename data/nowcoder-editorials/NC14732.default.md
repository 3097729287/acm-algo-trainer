## 锁

### 题意

居民权值和至少m才可打开全部锁，求最少锁数。

### 思路

没有达到阈值的集合称失败集合。考虑其中“再加任何一个外部居民就成功”的极大失败集合S：它必须至少缺一把钥匙，而所有不在S中的居民都必须持有这把钥匙，否则S再加那个人仍打不开。故这把锁的无钥匙者集合恰好是S。两个不同极大失败集合不能共用此锁，所以至少需要极大失败集合个数把锁。

反过来，为每个极大失败集合各建一锁，只给其外部居民钥匙。所有失败集合都包含于某个极大失败集合而缺该钥匙；任意成功集合不包含于失败集合，故每锁都至少有一名持钥匙者，构造成立。

枚举全部掩码，求权值和；未达m且加上补集中最小权值后达到m，就恰为极大失败集合。补集为空时也算极大失败。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long threshold;
    cin >> n >> threshold;
    vector<long long> weight(n);
    for (auto &x : weight)
        cin >> x;
    int size = 1 << n;
    vector<long long> sum(size), minimum(size, LLONG_MAX / 4);
    for (int mask = 1; mask < size; mask++) {
        int bit = __builtin_ctz((unsigned)mask), rest = mask & (mask - 1);
        sum[mask] = sum[rest] + weight[bit];
        minimum[mask] = min(minimum[rest], weight[bit]);
    }
    int answer = 0;
    for (int mask = 0; mask < size; mask++)
        if (sum[mask] < threshold &&
            (mask == size - 1 || sum[mask] + minimum[(size - 1) ^ mask] >= threshold))
            answer++;
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均 $O(2^n)$。

### 易错点

权值均正，所以只需检查最小外部权值。所有人总权仍不足m时，完整集合是唯一极大失败集合，一把无人有钥匙的锁即可。
