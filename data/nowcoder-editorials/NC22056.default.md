## 箭形图案

### 题意

多组读入 n，打印总高 2n+1 的右向箭形。

### 思路

中间行下标为 n。第 i 行令 d=|i-n|，先输出 2d 个空格，再输出 n-d+1 个星号。上下两半通过绝对值统一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        for (int i = 0; i <= 2 * n; i++) {
            int d = abs(i - n);
            cout << string(2 * d, ' ') << string(n - d + 1, '*') << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2)$，临时空间 $O(n)$。

### 易错点

缩进每层相差两个空格，星号数每层相差一个，不能套普通菱形公式。
