## [网络流24题]最长递增子序列问题

### 题意

最长不下降长度及最多不相交最长子序列，另允许首尾复用。

### 思路

O(n²)求f[i]为以i结尾的最长不下降长度S。建源连f=1点、f=S点连汇，每点拆入出容量1；i<j、a[i]≤a[j]且f[j]=f[i]+1时，连i出→j入容量1。每条单位流对应一条长度S的子序列，节点容量保证互不重叠。

第三问将点1、n的拆点容量及相应源/汇边容量改大，其他不变。转移边保持1，避免同一条仅含首尾的序列被无穷重复。S=1时有n个单点序列，两问均输出n。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Dinic {
    struct Edge {
        int to, reverse;
        long long capacity;
    };
    vector<vector<Edge>> graph;
    vector<int> level, current;
    explicit Dinic(int n) : graph(n), level(n), current(n) {}
    void resize(int n) {
        graph.resize(n);
        level.resize(n);
        current.resize(n);
    }
    int add(int u, int v, long long capacity) {
        int index = graph[u].size(), reverse = graph[v].size();
        graph[u].push_back({v, reverse, capacity});
        graph[v].push_back({u, index, 0});
        return index;
    }
    bool bfs(int source, int sink) {
        fill(level.begin(), level.end(), -1);
        vector<int> queue = {source};
        level[source] = 0;
        for (size_t i = 0; i < queue.size(); i++)
            for (auto e : graph[queue[i]])
                if (e.capacity > 0 && level[e.to] < 0) {
                    level[e.to] = level[queue[i]] + 1;
                    queue.push_back(e.to);
                }
        return level[sink] >= 0;
    }
    long long send(int u, int sink, long long amount) {
        if (u == sink)
            return amount;
        for (int &i = current[u]; i < (int)graph[u].size(); i++) {
            auto &e = graph[u][i];
            if (e.capacity > 0 && level[e.to] == level[u] + 1) {
                long long value = send(e.to, sink, min(amount, e.capacity));
                if (value) {
                    e.capacity -= value;
                    graph[e.to][e.reverse].capacity += value;
                    return value;
                }
            }
        }
        return 0;
    }
    long long maximum(int source, int sink, long long limit = LLONG_MAX / 4) {
        long long total = 0;
        while (total < limit && bfs(source, sink)) {
            fill(current.begin(), current.end(), 0);
            while (total < limit) {
                long long value = send(source, sink, limit - total);
                if (!value)
                    break;
                total += value;
            }
        }
        return total;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n), length(n, 1);
    for (int &x : a)
        cin >> x;
    int longest = 1;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (a[j] <= a[i])
                length[i] = max(length[i], length[j] + 1);
        longest = max(longest, length[i]);
    }
    cout << longest << '\n';
    if (longest == 1) {
        cout << n << '\n' << n;
        return 0;
    }
    auto solve = [&](bool reusable) {
        int source = 2 * n, sink = source + 1;
        Dinic flow(sink + 1);
        for (int i = 0; i < n; i++) {
            int capacity = reusable && (i == 0 || i == n - 1) ? n + 1 : 1;
            flow.add(i, n + i, capacity);
            if (length[i] == 1)
                flow.add(source, i, capacity);
            if (length[i] == longest)
                flow.add(n + i, sink, capacity);
            for (int j = i + 1; j < n; j++)
                if (a[i] <= a[j] && length[j] == length[i] + 1)
                    flow.add(n + i, j, 1);
        }
        return flow.maximum(source, sink);
    };
    cout << solve(false) << '\n' << solve(true);
    return 0;
}
```

### 复杂度

建图 $O(n²)$；一般Dinic最坏 $O(V²E)$，空间 $O(n²)$。

### 易错点

原题虽称“递增”，明确求的是不下降，允许相等。第三问只放宽编号1和n，不能放宽所有最长序列端点。
