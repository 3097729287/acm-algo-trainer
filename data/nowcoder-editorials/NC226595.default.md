## 势能线段树模板题一

### 题意

区间内各正整数开平方向下取整，并查询区间和。

### 思路

线段树维护区间和与最大值。开方时，最大值不超过一的节点已经稳定，整段跳过；其他节点递归到叶子修改并回算。初值最大十亿，连续开方至多六次就变成一，因此每个叶子真正改变的次数有固定小上界。后面的开方查询只会走到边界及尚未稳定的位置。浮点开根后用整数平方校正，确保完全平方数边界准确。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct RootTree {
    int n;
    vector<long long> sum, maximum;
    explicit RootTree(const vector<long long> &a)
        : n((int)a.size() - 1), sum(4 * n + 4), maximum(4 * n + 4) {
        build(1, 1, n, a);
    }
    void pull(int p) {
        sum[p] = sum[p * 2] + sum[p * 2 + 1];
        maximum[p] = max(maximum[p * 2], maximum[p * 2 + 1]);
    }
    void build(int p, int l, int r, const vector<long long> &a) {
        if (l == r) {
            sum[p] = maximum[p] = a[l];
            return;
        }
        int mid = (l + r) / 2;
        build(p * 2, l, mid, a);
        build(p * 2 + 1, mid + 1, r, a);
        pull(p);
    }
    void change(int p, int l, int r, int ql, int qr) {
        if (maximum[p] <= 1)
            return;
        if (l == r) {
            long long value = sqrtl(sum[p]);
            while ((value + 1) * (value + 1) <= sum[p])
                value++;
            while (value * value > sum[p])
                value--;
            sum[p] = maximum[p] = value;
            return;
        }
        int mid = (l + r) / 2;
        if (ql <= mid)
            change(p * 2, l, mid, ql, qr);
        if (qr > mid)
            change(p * 2 + 1, mid + 1, r, ql, qr);
        pull(p);
    }
    long long query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr)
            return sum[p];
        int mid = (l + r) / 2;
        long long answer = 0;
        if (ql <= mid)
            answer += query(p * 2, l, mid, ql, qr);
        if (qr > mid)
            answer += query(p * 2 + 1, mid + 1, r, ql, qr);
        return answer;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> a(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    RootTree tree(a);
    while (m--) {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 1)
            tree.change(1, 1, n, l, r);
        else
            cout << tree.query(1, 1, n, l, r) << '\n';
    }
    return 0;
}
```

### 复杂度

初值上限 $A$，总时间 $O((m+n\log\log A)\log n)$，空间 $O(n)$。

### 易错点

区间和开方不等于逐个元素开方后的和。剪枝依据最大值，而不是区间和；这一版没有区间加法，稳定值不会重新变大。
