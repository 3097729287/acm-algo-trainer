## Eustia of the Tarnished Wings

### 题意

领导人属性差不超过 m 的两势力可合并，并保留两位领导人之一。

### 思路

把属性升序排序。相邻差不超过 m 的一段可全部合并：从左到右合并，每次保留右侧较大的领导人，它就能继续与下一个相邻领导人连接。相邻差大于 m 的地方两边任何属性差都大于 m，领导人又始终来自原集合，因此永远无法跨过。答案就是这些段的数量。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long m;
    cin >> n >> m;
    vector<long long> a(n);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    int answer = 1;
    for (int i = 1; i < n; i++)
        if (a[i] - a[i - 1] > m)
            answer++;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，保存输入的空间 $O(n)$。

### 易错点

合并后可以主动保留新的领导人，所以一段的最大值减最小值可以远大于 m。不能直接按整段极差分组。
