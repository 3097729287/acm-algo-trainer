## Obstacle Course 障碍训练课

### 题意

迷宫中四方向移动，起终朝向任意，最少需要转多少个90度弯。

### 思路

状态为(格子,面向方向)，移动到方向d的邻格时，费用为旧朝向与d之间的最少四分之一圈数：相同0、垂直1、相反2。起点四个方向都初始化为0，表示初始朝向任意。Dijkstra求所有方向状态的最少转角次数，终点取四个方向最小。按每步代价建模，比只在格子上记录一个最优值准确，因为相同格子的不同朝向会影响后续费用。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<char> cells;
    string token;
    while ((int)cells.size() < n * n && cin >> token) {
        size_t p;
        while ((p = token.find(u8"…")) != string::npos)
            token.replace(p, string(u8"…").size(), "...");
        for (char c : token)
            if (c == '.' || c == 'x' || c == 'A' || c == 'B')
                cells.push_back(c);
    }
    int start = 0, target = 0;
    for (int i = 0; i < n * n; i++) {
        if (cells[i] == 'A')
            start = i;
        if (cells[i] == 'B')
            target = i;
    }
    const int inf = 1000000000;
    vector<int> distance(4 * n * n, inf);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;
    for (int d = 0; d < 4; d++) {
        distance[start * 4 + d] = 0;
        heap.push({0, start * 4 + d});
    }
    int dr[] = {-1, 0, 1, 0}, dc[] = {0, 1, 0, -1};
    while (!heap.empty()) {
        auto [cost, state] = heap.top();
        heap.pop();
        if (cost != distance[state])
            continue;
        int u = state / 4, facing = state % 4, r = u / n, c = u % n;
        for (int d = 0; d < 4; d++) {
            int rr = r + dr[d], cc = c + dc[d];
            if (rr < 0 || rr >= n || cc < 0 || cc >= n || cells[rr * n + cc] == 'x')
                continue;
            int difference = abs(d - facing), turn = min(difference, 4 - difference),
                next = (rr * n + cc) * 4 + d;
            if (distance[next] > cost + turn) {
                distance[next] = cost + turn;
                heap.push({distance[next], next});
            }
        }
    }
    int answer = *min_element(distance.begin() + target * 4, distance.begin() + target * 4 + 4);
    cout << (answer == inf ? -1 : answer);
    return 0;
}
```

### 复杂度

时间 $O(N^2\log N)$，空间 $O(N^2)$。

### 易错点

输入可能是逐字符带空格，也可能整行连续字符，读取词后逐字符展开均可。起点朝向不能固定成一个方向。
