## 素数判断

### 题意

分别判断 T 个正整数是否为素数。

### 思路

小于二的数不是素数。其余数只需试除到平方根：若 n=ab 为合数，则 a、b 中至少有一个不超过平方根。找到任意整除因子就判合数，否则判素数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        bool prime = n >= 2;
        for (int d = 2; d <= n / d; d++)
            if (n % d == 0) {
                prime = false;
                break;
            }
        cout << (prime ? "Yes" : "No") << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\sqrt n)$，额外空间 $O(1)$。

### 易错点

一不是素数；输出只有首字母大写。用 d≤n/d 避免平方溢出。
