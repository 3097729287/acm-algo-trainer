## 233

### 题意

计算两个长度最多五十的十进制整数串的乘积。

### 思路

按竖式乘法，让 a 的第 i 位与 b 的第 j 位乘积累加到结果第 i+j+1 位。先累加所有乘积，再从右往左统一进位。最后跳过结果开头的零，并输出剩余数位。一般高精度乘法已经足以处理五十位，无须利用 233 的特殊模式。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        string a, b;
        cin >> a >> b;
        int n = a.size(), m = b.size();
        vector<int> c(n + m);
        for (int i = n - 1; i >= 0; i--)
            for (int j = m - 1; j >= 0; j--)
                c[i + j + 1] += (a[i] - '0') * (b[j] - '0');
        for (int i = n + m - 1; i > 0; i--) {
            c[i - 1] += c[i] / 10;
            c[i] %= 10;
        }
        int start = 0;
        while (start + 1 < n + m && c[start] == 0)
            start++;
        for (int i = start; i < n + m; i++)
            cout << c[i];
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

两个串长度为 $n,m$ 时，时间 $O(nm)$，结果空间 $O(n+m)$。

### 易错点

五十位不能放进任何常用整数类型；每个结果位置会收到多个乘积，进位要考虑全部累加量。
