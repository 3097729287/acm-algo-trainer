## 求距离

### 题意

允许交换一次排列中的两个数，最大化一与 n 的下标差。

### 思路

若交换不同时涉及一与 n，最多只移动其中一个，另一个位置保持固定。移动的数放在距固定数最远的端点最好；若同时交换一与 n，两者距离不变。因此分别考虑固定一或固定 n 时到两个端点的距离，取四者最大。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int p = 1, q = 1;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (x == 1)
            p = i;
        if (x == n)
            q = i;
    }
    cout << max({p - 1, n - p, q - 1, n - q});
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

只有一次交换，一和 n 通常不能同时分别移到两端。n=1 时距离为零。
