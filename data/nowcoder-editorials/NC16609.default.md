## 潜伏者

### 题意

由已知密文与原文推断双射密码，必须获得全部二十六字母映射后才能译出新密文。

### 思路

同时维护密文字母到原文和原文字母到密文两个映射。逐位加入对应关系，如果任意一端已有不同对应值则失败。扫描结束后两端都必须覆盖二十六种字母，否则也输出 Failed；成功时逐字符查表译出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string cipher, plain, query;
    cin >> cipher >> plain >> query;
    int forward[26], reverseMap[26];
    fill(forward, forward + 26, -1);
    fill(reverseMap, reverseMap + 26, -1);
    bool ok = true;
    for (size_t i = 0; i < cipher.size(); i++) {
        int a = cipher[i] - 'A', b = plain[i] - 'A';
        if ((forward[a] != -1 && forward[a] != b) || (reverseMap[b] != -1 && reverseMap[b] != a))
            ok = false;
        forward[a] = b;
        reverseMap[b] = a;
    }
    for (int i = 0; i < 26; i++)
        if (forward[i] == -1 || reverseMap[i] == -1)
            ok = false;
    if (!ok)
        cout << "Failed";
    else
        for (char c : query)
            cout << char('A' + forward[c - 'A']);
    return 0;
}
```

### 复杂度

时间 $O(|已知串|+|查询串|)$，映射空间 $O(26)$。

### 易错点

只建立单向映射会漏掉两个字母共用密字的冲突；即便新密文只使用已知字母，缺少其他字母的映射也仍须失败。
