## 本质不同公共子串个数

### 题意

求两串本质不同公共子串数量。

### 思路

后缀自动机把结束位置集合相同的子串合并为一个状态。状态u代表的长度恰为(len[link[u]],len[u]]，这些子串出现次数相同。每加入一个字符，建立当前完整前缀的状态并令初始次数为1；必要时克隆旧状态，分离较短的结束位置类，克隆初始次数为0。按len降序把次数加到link，得到每个状态的真实出现次数；link长度严格减小，所以可以用计数排序得到传播顺序。

对s建SAM，扫描t维护当前最长匹配后缀长度L和状态u；失配时沿link缩短，能转移后继续匹配，并记best[u]=max(best[u],L)。扫描后按len降序把best[u]传给link父亲，传递长度不能超过父亲len。

状态u原本代表(len[parent],len[u]]内的不同子串，如今t能匹配的最长长度为best[u]，所以公共贡献为max(0,min(best[u],len[u])−len[parent])。逐状态累加就不会重复统计。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct SuffixAutomaton {
    struct Node {
        array<int, 26> next = {};
        int link = -1, length = 0, count = 0;
    };
    vector<Node> node;
    vector<int> prefix, order;
    int last = 0;
    explicit SuffixAutomaton(const string &s) {
        node.reserve(2 * s.size() + 1);
        node.emplace_back();
        prefix.reserve(s.size() + 1);
        prefix.push_back(0);
        for (char ch : s) {
            int c = ch - 'a', current = node.size();
            node.emplace_back();
            node[current].length = node[last].length + 1;
            node[current].count = 1;
            int p = last;
            while (p != -1 && !node[p].next[c]) {
                node[p].next[c] = current;
                p = node[p].link;
            }
            if (p == -1)
                node[current].link = 0;
            else {
                int q = node[p].next[c];
                if (node[p].length + 1 == node[q].length)
                    node[current].link = q;
                else {
                    int clone = node.size();
                    node.push_back(node[q]);
                    node[clone].length = node[p].length + 1;
                    node[clone].count = 0;
                    while (p != -1 && node[p].next[c] == q) {
                        node[p].next[c] = clone;
                        p = node[p].link;
                    }
                    node[q].link = node[current].link = clone;
                }
            }
            last = current;
            prefix.push_back(last);
        }
        vector<int> count(s.size() + 1);
        for (auto &v : node)
            count[v.length]++;
        for (size_t i = 1; i < count.size(); i++)
            count[i] += count[i - 1];
        order.resize(node.size());
        for (int u = (int)node.size() - 1; u >= 0; u--)
            order[--count[node[u].length]] = u;
        for (int i = (int)order.size() - 1; i > 0; i--) {
            int u = order[i];
            node[node[u].link].count += node[u].count;
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s, t;
    cin >> s >> t;
    SuffixAutomaton sam(s);
    vector<int> best(sam.node.size());
    int u = 0, length = 0;
    for (char ch : t) {
        int c = ch - 'a';
        while (u && !sam.node[u].next[c]) {
            u = sam.node[u].link;
            length = sam.node[u].length;
        }
        if (sam.node[u].next[c]) {
            u = sam.node[u].next[c];
            length++;
        } else {
            u = 0;
            length = 0;
        }
        best[u] = max(best[u], length);
    }
    for (int i = (int)sam.order.size() - 1; i > 0; i--) {
        int v = sam.order[i], p = sam.node[v].link;
        best[p] = max(best[p], min(best[v], sam.node[p].length));
    }
    long long answer = 0;
    for (int v = 1; v < (int)sam.node.size(); v++)
        answer += max(0, min(best[v], sam.node[v].length) - sam.node[sam.node[v].link].length);
    cout << answer;
    return 0;
}
```

### 复杂度

固定字母表时间 $O(|s|+|t|)$，空间 $O(26|s|+|t|)$。

### 易错点

这里只计不同字符串，不乘出现次数。向link传播时须截断为父状态长度。
