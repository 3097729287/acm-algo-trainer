## 购物

### 题意

每天有不同价格的糖果，每天买k个另付k²，确保每天吃一个，求最少花费。

### 思路

同一天买k个一定取当天最便宜的k个，排序后用前缀和给出商品费用。dp[j]表示前面若干天一共买j个的最小费用。第d天枚举买k个，费用加当天前k个之和及k²，只允许新累计数量j+k≥d，保证此前每日都有糖吃。所有价格和附加费为正，最终只需恰买n个，多买不会更省；故累计数量只开0到n。每一天用新数组，避免重复使用当天糖果。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    const long long inf = 1LL << 60;
    vector<long long> dp(n + 1, inf);
    dp[0] = 0;
    for (int day = 1; day <= n; day++) {
        vector<long long> price(m), prefix(m + 1);
        for (auto &x : price)
            cin >> x;
        sort(price.begin(), price.end());
        for (int k = 1; k <= m; k++)
            prefix[k] = prefix[k - 1] + price[k - 1];
        vector<long long> next(n + 1, inf);
        for (int previous = 0; previous <= n; previous++)
            if (dp[previous] != inf)
                for (int buy = 0; buy <= m && previous + buy <= n; buy++)
                    if (previous + buy >= day)
                        next[previous + buy] =
                            min(next[previous + buy], dp[previous] + prefix[buy] + 1LL * buy * buy);
        dp.swap(next);
    }
    cout << dp[n];
    return 0;
}
```

### 复杂度

时间 $O(nm\log m+n^2m)$，空间 $O(n+m)$。

### 易错点

允许提前买来囤着，但不能使用未来糖果；累计买入量必须在每个日期都不低于日期。附加费按当天总购买数平方，只收一次。
