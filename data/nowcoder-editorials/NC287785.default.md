## 借教室

### 题意

按订单先后借教室，求第一笔无法满足的订单；全可满足输出零。

### 思路

前 x 笔订单能否完成具有单调性。判定时把前 x 笔的闭区间需求用差分累加，再还原每天总需求，检查是否超过该日容量。二分最大的可行前缀长度 low；若 low=m 就无失败订单，否则首笔失败为 low+1。每次判定先清空差分。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> capacity(n + 1), difference(n + 2);
    for (int i = 1; i <= n; i++)
        cin >> capacity[i];
    struct Order {
        long long count;
        int left, right;
    };
    vector<Order> orders(m);
    for (auto &o : orders)
        cin >> o.count >> o.left >> o.right;
    auto possible = [&](int count) {
        fill(difference.begin(), difference.end(), 0);
        for (int i = 0; i < count; i++) {
            auto o = orders[i];
            difference[o.left] += o.count;
            difference[o.right + 1] -= o.count;
        }
        long long used = 0;
        for (int day = 1; day <= n; day++) {
            used += difference[day];
            if (used > capacity[day])
                return false;
        }
        return true;
    };
    int low = 0, high = m;
    while (low < high) {
        int mid = low + (high - low + 1) / 2;
        if (possible(mid))
            low = mid;
        else
            high = mid - 1;
    }
    cout << (low == m ? 0 : low + 1);
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log(m+1))$，空间 $O(n+m)$。

### 易错点

本版本失败时只输出申请人编号，与原 NOIP 版本的输出格式不同。每天总需求可达 10^15，差分使用 long long。
