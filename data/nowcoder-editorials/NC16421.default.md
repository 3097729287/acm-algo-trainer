## 成绩

> 原题：[P3954](https://www.luogu.com.cn/problem/P3954)
> 解法：整数加权求和 · C++17

### 题意

作业、小测、期末分别占总成绩的百分之二十、三十、五十，输入三项成绩，输出总成绩。



### 思路

把比例写成十分之二、三、五，先求 $2A+3B+5C$，最后整体除以十。

时间与额外空间均为 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, c;
    cin >> a >> b >> c;
    cout << (2 * a + 3 * b + 5 * c) / 10 << '\n';
    return 0;
}
```

### 易错点

三项权重不同；不要把百分数二十、三十、五十直接当作乘数而忘记分母。
