## 计算平均成绩

### 题意

求五个整数成绩的平均值，保留一位小数。

### 思路

循环读五个数求和，再除以浮点数 5.0，避免整数商截断。五个成绩的和不超过五百。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        int x;
        cin >> x;
        sum += x;
    }
    cout << fixed << setprecision(1) << sum / 5.0;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

平均值的分母是五，固定小数位要配合 fixed。
