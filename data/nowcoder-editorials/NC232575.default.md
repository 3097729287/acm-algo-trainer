## [2017WF]Airport Construction

### 题意

简单多边形内最长直线段，允许沿边界。

### 思路

最优跑道所在直线可取经过两个多边形顶点，但两端不一定是顶点。理由是先延长到边界，再平移或旋转，在尚未碰到新顶点的局部区间中，总能朝不缩短的一侧推进，直至由两个顶点限制方向。因此枚举所有顶点对所定的完整直线，求它与闭多边形交集的最长连通区间。

对固定直线，将所有顶点投影成参数t，并按叉积正负区分直线两侧。边两端是否严格在正侧不同，就产生一次半开穿越事件；排序后两两配对得到内部区间。与直线共线的多边形边另作为边界区间加入，最后合并相交或相接区间，保留最长真实长度。这既处理穿过顶点，也允许在凹顶点只接触边界。

候选直线性质参见[2017 ICPC官方题解](https://icpc.global/worldfinals/problems/2017-ICPC-World-Finals/finals2017solutions.pdf)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<Point> point(n);
    for (auto &p : point)
        cin >> p.x >> p.y;
    long double answer = 0;
    for (int a = 0; a < n; a++)
        for (int b = a + 1; b < n; b++) {
            Point origin = point[a], direction = point[b] - origin;
            long double squared = dot(direction, direction);
            vector<long double> parameter(n), side(n), events;
            vector<pair<long double, long double>> interval;
            for (int i = 0; i < n; i++) {
                parameter[i] = dot(point[i] - origin, direction) / squared;
                side[i] = cross(direction, point[i] - origin);
            }
            for (int i = 0; i < n; i++) {
                int j = (i + 1) % n;
                if ((side[i] > 0) != (side[j] > 0)) {
                    long double t =
                        (parameter[i] * side[j] - parameter[j] * side[i]) / (side[j] - side[i]);
                    events.push_back(t);
                }
                if (side[i] == 0 && side[j] == 0)
                    interval.push_back(minmax(parameter[i], parameter[j]));
            }
            sort(events.begin(), events.end());
            for (int i = 1; i < (int)events.size(); i += 2)
                interval.push_back({events[i - 1], events[i]});
            sort(interval.begin(), interval.end());
            bool active = false;
            long double left = 0, right = 0;
            for (auto [l, r] : interval) {
                if (!active || l > right + 1e-12L) {
                    if (active)
                        answer = max(answer, (right - left) * sqrtl(squared));
                    left = l;
                    right = r;
                    active = true;
                } else
                    right = max(right, r);
            }
            if (active)
                answer = max(answer, (right - left) * sqrtl(squared));
        }
    cout << fixed << setprecision(12) << answer;
    return 0;
}
```

### 复杂度

时间 $O(n³\log n)$，空间 $O(n)$。

### 易错点

不能只求顶点间合法对角线，最长段的端点可能都落在边内部。凹多边形截面可不连通，不能直接取最外两个交点。
