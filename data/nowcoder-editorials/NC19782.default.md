## Tree

### 题意

对每个结点分别统计包含它的连通点集数量，模十亿加七，n至一百万。

### 思路

固定一棵根树。down[u]表示只在u子树里、包含u的连通集合数。每个孩子方向可以不选，或选一个包含孩子的连通集合，所以down[u]=Π(down[v]+1)。再定义up[u]为父亲方向、包含父亲的连通集合数，则答案为down[u]*(up[u]+1)。给孩子v传递时，up[v]=(up[u]+1)*Π其他孩子(down[child]+1)。

乘积中可能有0，不能用模逆元除掉当前孩子。对每个u的孩子列表建前缀乘积，再从后往前用后缀乘积组合，线性求出所有排除单个孩子的积。树遍历和换根都用迭代，邻接表用连续数组减少百万结点的内存开销。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> head(n, -1), to(max(0, 2 * n - 2)), next(to.size());
    int edges = 0;
    auto addEdge = [&](int a, int b) {
        to[edges] = b;
        next[edges] = head[a];
        head[a] = edges++;
    };
    for (int i = 1; i < n; i++) {
        int a, b;
        cin >> a >> b;
        --a;
        --b;
        addEdge(a, b);
        addEdge(b, a);
    }
    vector<int> parent(n, -1), order{0};
    parent[0] = 0;
    order.reserve(n);
    for (size_t i = 0; i < order.size(); i++) {
        int u = order[i];
        for (int e = head[u]; e != -1; e = next[e])
            if (to[e] != parent[u]) {
                parent[to[e]] = u;
                order.push_back(to[e]);
            }
    }
    const long long mod = 1000000007;
    vector<long long> down(n, 1), up(n);
    for (int i = n - 1; i >= 0; i--) {
        int u = order[i];
        for (int e = head[u]; e != -1; e = next[e])
            if (to[e] != parent[u])
                down[u] = down[u] * (down[to[e]] + 1) % mod;
    }
    vector<int> children;
    vector<long long> prefix;
    for (int u : order) {
        children.clear();
        for (int e = head[u]; e != -1; e = next[e])
            if (to[e] != parent[u])
                children.push_back(to[e]);
        prefix.assign(children.size() + 1, 1);
        for (size_t i = 0; i < children.size(); i++)
            prefix[i + 1] = prefix[i] * (down[children[i]] + 1) % mod;
        long long suffix = 1;
        for (int i = (int)children.size() - 1; i >= 0; i--) {
            int v = children[i];
            up[v] = (up[u] + 1) * prefix[i] % mod * suffix % mod;
            suffix = suffix * (down[v] + 1) % mod;
        }
    }
    for (int u = 0; u < n; u++)
        cout << down[u] * (up[u] + 1) % mod << '\n';
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

每个方向可以整个不选，但只要选就必须包含邻点以保持连通。先把原方向值全部求好，再换根，不能覆盖down原值。
