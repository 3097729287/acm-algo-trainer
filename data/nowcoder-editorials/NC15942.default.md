## 有趣的二进制

### 题意

对每组有符号整数，统计它的六十四位补码中一的数量。

### 思路

先将 long long 转成 unsigned long long，转换保留模 2^64 的位模式。再不断读取最低位并逻辑右移，直到无符号数变零；负数也会在六十四次内结束。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    while (cin >> n) {
        unsigned long long x = static_cast<unsigned long long>(n);
        int ans = 0;
        while (x) {
            ans += x & 1ULL;
            x >>= 1;
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 复杂度

每组至多六十四步，额外空间 $O(1)$。

### 易错点

直接右移负的有符号数可能不断补一，导致死循环；先转换为无符号类型。
