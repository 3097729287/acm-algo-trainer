## 仓鼠的鸡蛋

### 题意

每堆鸡蛋放入编号最小、剩余容量足够且未达 k 堆限制的篮子。

### 思路

线段树每个叶子保存篮子的可用容量，若已经放了 k 堆就记为 -1；内部维护最大可用容量。根最大值小于当前鸡蛋数，说明没有篮子能装。否则从根向下，左子树最大值够用就走左边，不够才走右边，得到最小可行编号。更新该篮子容量和堆数，沿途重算最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, capacity, limit;
        cin >> n >> capacity >> limit;
        vector<int> maximum(4 * n + 4, capacity), used(n + 1);
        function<int(int, int, int, int)> place = [&](int p, int l, int r, int amount) {
            if (l == r) {
                maximum[p] -= amount;
                if (++used[l] == limit)
                    maximum[p] = -1;
                return l;
            }
            int mid = (l + r) / 2, answer;
            if (maximum[p * 2] >= amount)
                answer = place(p * 2, l, mid, amount);
            else
                answer = place(p * 2 + 1, mid + 1, r, amount);
            maximum[p] = max(maximum[p * 2], maximum[p * 2 + 1]);
            return answer;
        };
        for (int i = 0; i < n; i++) {
            int amount;
            cin >> amount;
            cout << (maximum[1] < amount ? -1 : place(1, 1, n, amount)) << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

篮子有容量和堆数两项限制。某堆超过所有篮子的容量时输出 -1，不能把它拆成多堆，也不能改变后面鸡蛋的顺序。
