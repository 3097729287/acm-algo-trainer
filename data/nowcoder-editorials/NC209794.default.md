## 使徒袭来

### 题意

三个正实数乘积固定为 n，求最小可能的和。

### 思路

由算术平均数不小于几何平均数，x+y+z≥3∛(xyz)=3∛n。当三个数均为 ∛n 时可以取到等号，因此输出 3*cbrt(n)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long double n;
    cin >> n;
    cout << fixed << setprecision(3) << 3 * cbrtl(n);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

战斗力是正实数，可以三者相等，不需要枚举整数因子。
