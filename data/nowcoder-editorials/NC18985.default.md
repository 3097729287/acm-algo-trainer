## 数字权重

### 题意

首位非零的n位数，其相邻位差之和为K，求方案数。

### 思路

所有中间项消去，相邻位差之和恰为末位减首位。枚举首位a=1..9，只要0≤a+K≤9，就确定了合法末位。其余n−2位完全自由，各有10种选择，因此答案是合法首位数乘10^(n−2)。指数至10^13，用快速幂。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, k;
    cin >> n >> k;
    const long long mod = 1000000007;
    long long count = 0;
    for (int first = 1; first <= 9; first++)
        if (0 <= first + k && first + k <= 9)
            count++;
    long long power = 1, base = 10, exponent = n - 2;
    while (exponent) {
        if (exponent & 1)
            power = power * base % mod;
        base = base * base % mod;
        exponent >>= 1;
    }
    cout << count * power % mod;
    return 0;
}
```

### 复杂度

时间 $O(\log n)$，空间 $O(1)$。

### 易错点

K可以为负数，最高位不能为0。n=2时中间没有位置，幂应为1。
