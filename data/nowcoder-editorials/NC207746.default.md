## 背包

### 题意

八类物品不同数量限制，N可至10^18，求方案数。

### 思路

每类物品用允许数量的生成函数表示：两种最多1个给(1+x)²，最多2和3个给(1+x+x²)(1+x+x²+x³)，偶数鸡翅和奇数鸡汤给x/(1−x²)²，4倍数鸡块与3倍数鸡蛋给1/((1−x⁴)(1−x³))。

用1+x=(1−x²)/(1−x)、1+x+x²=(1−x³)/(1−x)、1+x+x²+x³=(1−x⁴)/(1−x)，所有分子分母抵消后只剩x/(1−x)^4。N次系数为C(N+2,3)=N(N+1)(N+2)/6。模P下乘6的逆元。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    unsigned long long n;
    cin >> n;
    const long long mod = 1000000007;
    long long x = n % mod;
    cout << x * ((x + 1) % mod) % mod * ((x + 2) % mod) % mod * 166666668 % mod;
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

鸡汤必须奇数，所以生成函数多一个x，结果不是C(N+3,3)。N很大，只对因子先取模。
