## 青蛙的约会

### 题意

两只青蛙沿圆环同步跳，求首次同时相遇的步数。

### 思路

相遇条件x+m*t≡y+n*t(mod L)，即(m−n)t≡y−x。把系数和常数规范到0..L−1，令g=gcd(m−n,L)。若g不整除常数则无解；否则扩展欧几里得求系数的Bezout系数u，最小非负解为u*((y−x)/g) mod(L/g)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long extendedGcd(long long a, long long b, long long &x, long long &y) {
    if (!b) {
        x = 1;
        y = 0;
        return a;
    }
    long long previousX, previousY;
    long long g = extendedGcd(b, a % b, previousX, previousY);
    x = previousY;
    y = previousX - (a / b) * previousY;
    return g;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long x, y, m, n, length;
    cin >> x >> y >> m >> n >> length;
    long long a = ((m - n) % length + length) % length, b = ((y - x) % length + length) % length, u,
              v, g = extendedGcd(a, length, u, v);
    if (b % g)
        cout << "Impossible";
    else {
        long long period = length / g;
        cout << ((u * (b / g)) % period + period) % period;
    }
    return 0;
}
```

### 复杂度

时间 $O(\log L)$，空间 $O(\log L)$。

### 易错点

速度差可以为负，要先规范余数。两青蛙同速而不同位置时判无解；位置在模L意义重合时0步合法。
