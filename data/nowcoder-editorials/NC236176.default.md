## 分层图最短路

### 题意

邻层任意点付C移动，另有特殊边，同层不能免费互达。

### 思路

为每层建立入口汇集点hub[l]，让hub[l]到本层每个原点有0边；原点u只向hub[layer[u]−1]与hub[layer[u]+1]连C边，不能连向本层hub。这样恰好实现一次付费到相邻层任意原点，不引入同层免费通道。再加入特殊双向边，Dijkstra求1到n。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<long long> dijkstra(const vector<vector<pair<int, long long>>> &graph, int source) {
    const long long inf = 1LL << 60;
    vector<long long> distance(graph.size(), inf);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                   greater<pair<long long, int>>>
        heap;
    distance[source] = 0;
    heap.push({0, source});
    while (!heap.empty()) {
        auto [cost, u] = heap.top();
        heap.pop();
        if (cost != distance[u])
            continue;
        for (auto [v, w] : graph[u])
            if (distance[v] > cost + w) {
                distance[v] = cost + w;
                heap.push({distance[v], v});
            }
    }
    return distance;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    long long cost;
    cin >> n >> m >> cost;
    vector<int> layer(n);
    for (int &x : layer)
        cin >> x;
    vector<vector<pair<int, long long>>> graph(2 * n);
    for (int u = 0; u < n; u++) {
        int l = layer[u] - 1;
        graph[n + l].push_back({u, 0});
        if (l)
            graph[u].push_back({n + l - 1, cost});
        if (l + 1 < n)
            graph[u].push_back({n + l + 1, cost});
    }
    while (m--) {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        graph[u - 1].push_back({v - 1, w});
        graph[v - 1].push_back({u - 1, w});
    }
    auto distance = dijkstra(graph, 0);
    cout << (distance[n - 1] >= (1LL << 59) ? -1 : distance[n - 1]);
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log n)$，空间 $O(n+m)$。

### 易错点

原点到本层hub若也连0，会误把同层任意两点免费连接。空层hub没有出边，无法作为中转通道。
