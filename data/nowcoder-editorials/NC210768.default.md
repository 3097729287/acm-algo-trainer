## younik要排号

### 题意

忽略重复叫号，求第一次叫到 younik 时她是第几位不同的人。

### 思路

逐个名字插入集合，集合大小就是到目前为止叫过的不同人数。首次遇到 younik 时记录当时大小，后面的名字不再影响她的序号。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    set<string> people;
    int answer = 0;
    for (int i = 0; i < n; i++) {
        string name;
        cin >> name;
        people.insert(name);
        if (name == "younik" && answer == 0)
            answer = people.size();
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，名字长度视为输入成本，存储空间 $O(n)$。

### 易错点

重复名字不能重复增加人数，题目求的不是输入行号。
