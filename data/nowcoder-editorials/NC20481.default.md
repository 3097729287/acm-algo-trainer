## [ZJOI2008]骑士

### 题意

每个骑士恨一个人，不能同选，求最大总战力。

### 思路

将每人指向其厌恶者，得到每点出度1的功能图，每个连通块恰有一个有向环。先按入度0剥叶，维护not[u]、yes[u]为以u为根的附属树不选/选u的最大战力，剥去u后向parent累加max(not,yes)和not。剥完剩下的都是环。

每个环上节点已汇总其外接树。枚举第一个环点不选或选，用链式独立集DP逐点更新；首点选中时强制末点不选，保证闭环边合法。各连通块答案相加，百万点也无需递归。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> parent(n), indegree(n);
    vector<long long> no(n), yes(n);
    for (int i = 0; i < n; i++) {
        cin >> yes[i] >> parent[i];
        parent[i]--;
        indegree[parent[i]]++;
    }
    queue<int> queue;
    for (int i = 0; i < n; i++)
        if (!indegree[i])
            queue.push(i);
    while (!queue.empty()) {
        int u = queue.front();
        queue.pop();
        int p = parent[u];
        no[p] += max(no[u], yes[u]);
        yes[p] += no[u];
        if (--indegree[p] == 0)
            queue.push(p);
    }
    vector<bool> seen(n);
    long long answer = 0;
    const long long negative = LLONG_MIN / 4;
    for (int start = 0; start < n; start++)
        if (indegree[start] && !seen[start]) {
            vector<int> cycle;
            int u = start;
            do {
                cycle.push_back(u);
                seen[u] = true;
                u = parent[u];
            } while (u != start);
            auto solve = [&](bool firstSelected) {
                long long previousNo = firstSelected ? negative : no[cycle[0]],
                          previousYes = firstSelected ? yes[cycle[0]] : negative;
                for (int i = 1; i < (int)cycle.size(); i++) {
                    int v = cycle[i];
                    long long currentNo = max(previousNo, previousYes) + no[v],
                              currentYes = previousNo + yes[v];
                    previousNo = currentNo;
                    previousYes = currentYes;
                }
                return firstSelected ? previousNo : max(previousNo, previousYes);
            };
            answer += max(solve(false), solve(true));
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均 $O(n)$。

### 易错点

相互厌恶构成长度2的环，也只要求二者不能同选，环DP照常适用。总战力用64位。
