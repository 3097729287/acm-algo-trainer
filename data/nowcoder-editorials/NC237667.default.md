## 多模式最长公共子串

### 题意

求同时是所有给定字符串子串的最长字符串长度。

### 思路

给每个源串分配不同的分隔符，将它们拼接后建立后缀数组与相邻 LCP。每个后缀标记其起点所属源串，分隔符位置记为无来源。在后缀数组上滑动窗口，维护每种来源出现次数；窗口包含全部源串时，这些后缀的公共前缀长度是 height[left+1..right] 的最小值，用递增单调队列求它。记录答案后移出左端继续缩短，直到缺少一种来源。

正确性来自字典序的连续性：任何公共子串都对应一整段以它为前缀的后缀，其中包含所有来源；反过来，某窗口里全部后缀的公共前缀也出现在所有来源中。对固定右端，缩短窗口不会降低 LCP 最小值，因此把可行窗口逐一缩短不会漏掉最优值。

后缀数组将全部后缀按字典序排序，height[i] 为相邻后缀 sa[i-1]、sa[i] 的最长公共前缀长度。参考代码采用倍增：已有长度 L 的排名后，用两个半段排名确定长度 2L 的排名，计数排序每轮线性；末尾补唯一最小符号零，把普通后缀排序转成循环移位排序。最后用 Kasai 方法在线性时间构造 height，每次从上一次公共长度减一处继续比较。所有实际字符和分隔符编码都大于零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct SuffixArray {
    vector<int> sa, height;
    explicit SuffixArray(const vector<int> &data) {
        int size = data.size(), n = size + 1;
        vector<int> symbols = data;
        symbols.push_back(0);
        int alphabet = *max_element(symbols.begin(), symbols.end()) + 1;
        vector<int> order(n), rank(n), shifted(n), nextRank(n), count(max(n, alphabet), 0);
        for (int x : symbols)
            count[x]++;
        for (int x = 1; x < alphabet; x++)
            count[x] += count[x - 1];
        for (int i = n - 1; i >= 0; i--)
            order[--count[symbols[i]]] = i;
        int classes = 1;
        rank[order[0]] = 0;
        for (int i = 1; i < n; i++) {
            if (symbols[order[i]] != symbols[order[i - 1]])
                classes++;
            rank[order[i]] = classes - 1;
        }
        for (int length = 1; length < n && classes < n; length *= 2) {
            for (int i = 0; i < n; i++) {
                shifted[i] = order[i] - length;
                if (shifted[i] < 0)
                    shifted[i] += n;
            }
            fill(count.begin(), count.begin() + classes, 0);
            for (int x : shifted)
                count[rank[x]]++;
            for (int i = 1; i < classes; i++)
                count[i] += count[i - 1];
            for (int i = n - 1; i >= 0; i--)
                order[--count[rank[shifted[i]]]] = shifted[i];
            int nextClasses = 1;
            nextRank[order[0]] = 0;
            for (int i = 1; i < n; i++) {
                int a = order[i - 1], b = order[i];
                if (rank[a] != rank[b] || rank[(a + length) % n] != rank[(b + length) % n])
                    nextClasses++;
                nextRank[b] = nextClasses - 1;
            }
            rank.swap(nextRank);
            classes = nextClasses;
        }
        sa.assign(order.begin() + 1, order.end());
        for (int i = 0; i < size; i++)
            rank[sa[i]] = i;
        height.assign(size, 0);
        int common = 0;
        for (int i = 0; i < size; i++) {
            int position = rank[i];
            if (position == 0) {
                common = 0;
                continue;
            }
            int j = sa[position - 1];
            while (i + common < size && j + common < size && data[i + common] == data[j + common])
                common++;
            height[position] = common;
            if (common)
                common--;
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int sources;
    cin >> sources;
    vector<int> data, owner;
    data.reserve(1100000);
    owner.reserve(1100000);
    for (int id = 0; id < sources; id++) {
        string s;
        cin >> s;
        for (char c : s) {
            data.push_back(sources + 1 + c - 'a');
            owner.push_back(id);
        }
        data.push_back(id + 1);
        owner.push_back(-1);
    }
    SuffixArray index(data);
    vector<int> count(sources);
    deque<int> minimum;
    int left = 0, kinds = 0, answer = 0;
    for (int right = 0; right < (int)index.sa.size(); right++) {
        int id = owner[index.sa[right]];
        if (id >= 0 && count[id]++ == 0)
            kinds++;
        while (!minimum.empty() && index.height[minimum.back()] >= index.height[right])
            minimum.pop_back();
        minimum.push_back(right);
        while (kinds == sources) {
            while (!minimum.empty() && minimum.front() <= left)
                minimum.pop_front();
            if (!minimum.empty())
                answer = max(answer, index.height[minimum.front()]);
            int removed = owner[index.sa[left++]];
            if (removed >= 0 && --count[removed] == 0)
                kinds--;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

拼接总长 $N$，时间 $O(N\log N)$，空间 $O(N)$。

### 易错点

多个分隔符也必须彼此不同，避免公共前缀穿过串尾。队列保存的是 LCP 下标，窗口左端对应的 height[left] 在窗口之外，要删去。
