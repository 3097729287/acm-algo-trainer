## [NOIP2011]计算系数

### 题意

计算(ax+by)^k中x^n*y^m项的系数。

### 思路

从k个因子中选n个提供ax，其余m个提供by，系数就是C(k,n)*a^n*b^m。用一维Pascal递推求第k行组合数，内层倒序，随后分别乘n次a和m次b，始终模10007。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, k, n, m;
    cin >> a >> b >> k >> n >> m;
    const int mod = 10007;
    vector<int> choose(k + 1);
    choose[0] = 1;
    for (int i = 1; i <= k; i++)
        for (int j = i; j >= 1; j--)
            choose[j] = (choose[j] + choose[j - 1]) % mod;
    long long answer = choose[n];
    for (int i = 0; i < n; i++)
        answer = answer * (a % mod) % mod;
    for (int i = 0; i < m; i++)
        answer = answer * (b % mod) % mod;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(k^2)$，空间 $O(k)$。

### 易错点

组合数的一维更新必须倒序；0次幂按1处理，包括底数为0的情况。
