## 浇水大师

### 题意

长度2A到2B的装置恰铺满[0,L]，指定区间不能被切开。

### 思路

装置半径为整数，覆盖长度为偶数，所以从0开始所有分界都为偶数。令dp[i]表示覆盖到2i的最少装置数；若2i严格位于某个指定(S,E)内，此处不能作为分界。用差分标记全部禁用整数分界，端点S、E本身允许。

对允许的i，dp[i]=1+min(dp[j])，j∈[i−B,i−A]且j允许。维护这个移动窗口中dp递增的单调队列，dp[0]=0，答案dp[L/2]。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, length, a, b;
    cin >> n >> length >> a >> b;
    vector<int> difference(length + 2);
    for (int i = 0; i < n; i++) {
        int s, e;
        cin >> s >> e;
        difference[s + 1]++;
        difference[e]--;
    }
    vector<bool> allowed(length / 2 + 1);
    int active = 0;
    for (int x = 0; x <= length; x++) {
        active += difference[x];
        if (x % 2 == 0)
            allowed[x / 2] = active == 0;
    }
    int target = length / 2, inf = 1000000000;
    vector<int> dp(target + 1, inf);
    dp[0] = 0;
    deque<int> queue;
    for (int i = 1; i <= target; i++) {
        int enter = i - a;
        if (enter >= 0 && allowed[enter] && dp[enter] < inf) {
            while (!queue.empty() && dp[queue.back()] >= dp[enter])
                queue.pop_back();
            queue.push_back(enter);
        }
        while (!queue.empty() && queue.front() < i - b)
            queue.pop_front();
        if (allowed[i] && !queue.empty())
            dp[i] = dp[queue.front()] + 1;
    }
    cout << (dp[target] == inf ? -1 : dp[target]);
    return 0;
}
```

### 复杂度

时间 $O(L+N)$，空间 $O(L)$。

### 易错点

禁止切的是区间内部，不是两端；重叠约束用覆盖次数并集处理，不能只逐条判断。
