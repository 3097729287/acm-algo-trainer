## 假的字符串

### 题意

可任意重排字母表，找出哪些输入字符串能够成为字典序最小者。

### 思路

将全部词放进 Trie。检查某个候选词时沿其路径走：若途中已遇到另一个词的终点，它是候选的真前缀，无论字母顺序如何都会更小，候选失败。否则在每个节点，候选走字符 c 的边，所有其他存在的字符边 d 都要求 c<d，给字母图连 c→d。所有比较都由首次分叉决定，所以这些约束既必要又充分。字母图无环就能拓扑排序成一个合法字母表；有环则顺序要求矛盾。按输入顺序输出无环且没有短前缀的词。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> words(n);
    size_t total = 1;
    for (auto &s : words) {
        cin >> s;
        total += s.size();
    }
    vector<array<int, 26>> trie(1);
    vector<bool> terminal(1, false);
    trie.reserve(total);
    terminal.reserve(total);
    for (const auto &s : words) {
        int node = 0;
        for (char c : s) {
            int letter = c - 'a';
            if (!trie[node][letter]) {
                trie[node][letter] = trie.size();
                trie.push_back({});
                terminal.push_back(false);
            }
            node = trie[node][letter];
        }
        terminal[node] = true;
    }
    vector<int> answer;
    for (int id = 0; id < n; id++) {
        unsigned int edges[26] = {};
        int node = 0;
        bool valid = true;
        for (char raw : words[id]) {
            if (terminal[node]) {
                valid = false;
                break;
            }
            int c = raw - 'a';
            for (int d = 0; d < 26; d++)
                if (d != c && trie[node][d])
                    edges[c] |= 1U << d;
            node = trie[node][c];
        }
        if (!valid)
            continue;
        int degree[26] = {};
        for (int c = 0; c < 26; c++)
            for (int d = 0; d < 26; d++)
                if (edges[c] >> d & 1U)
                    degree[d]++;
        vector<int> order;
        for (int c = 0; c < 26; c++)
            if (!degree[c])
                order.push_back(c);
        for (size_t i = 0; i < order.size(); i++) {
            int c = order[i];
            for (int d = 0; d < 26; d++)
                if ((edges[c] >> d & 1U) && --degree[d] == 0)
                    order.push_back(d);
        }
        if (order.size() == 26)
            answer.push_back(id);
    }
    cout << answer.size() << '\n';
    for (int id : answer)
        cout << words[id] << '\n';
    return 0;
}
```

### 复杂度

总字符数 $L$、词数 $n$，时间 $O(26L+26^2n)$，空间 $O(26L)$。

### 易错点

不能把不同候选词的字母约束混在一起，每个词允许使用自己的字母表。前缀长短关系不受重排字母影响。重复边用位集去重，避免入度重复。
