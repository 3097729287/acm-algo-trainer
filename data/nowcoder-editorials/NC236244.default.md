## 树和序列

### 题意

动态加点，沿最近不小权祖先链在预算内取最多节点。

### 思路

每点下一步被规则唯一确定为“最近的权值不小于自己的祖先”，称单调父亲；沿此链权值非递减。新点挂在R下时，若w[R]够大就取R，否则沿R的单调祖先倍增跳过仍小于新权的节点，再取其单调父亲。这不会漏掉原树中合格祖先，因为被单调父亲跳过的点权都更小。

同时维护jump[b][u]及cost[b][u]：从u开始取2^b个链点的总代价与之后位置。查询从高位到低位尝试整块加入，预算够就扣除并前进。权值非负，跳过可支付的最长块是最优。0号为无穷权哨兵，防止越过根多计零节点，根1权为0可正常选一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    const int levels = 20;
    const unsigned long long inf = 4000000000000000000ULL;
    vector<array<int, levels>> up(q + 2);
    vector<array<unsigned long long, levels>> cost(q + 2);
    vector<unsigned long long> weight(q + 2, inf);
    cost[0].fill(inf);
    cost[1].fill(inf);
    cost[1][0] = 0;
    weight[1] = 0;
    int nodes = 1;
    unsigned long long last = 0;
    while (q--) {
        int op;
        unsigned long long p, value;
        cin >> op >> p >> value;
        int r = (int)(p ^ last);
        value ^= last;
        if (op == 1) {
            int parent = r;
            if (weight[parent] < value) {
                for (int b = levels - 1; b >= 0; b--)
                    if (weight[up[parent][b]] < value)
                        parent = up[parent][b];
                parent = up[parent][0];
            }
            int u = ++nodes;
            weight[u] = value;
            up[u][0] = parent;
            cost[u][0] = value;
            for (int b = 1; b < levels; b++) {
                int v = up[u][b - 1];
                up[u][b] = up[v][b - 1];
                cost[u][b] = min(inf, cost[u][b - 1] + cost[v][b - 1]);
            }
        } else {
            last = 0;
            int u = r;
            for (int b = levels - 1; b >= 0; b--)
                if (cost[u][b] <= value) {
                    value -= cost[u][b];
                    last += 1ULL << b;
                    u = up[u][b];
                }
            cout << last << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每次操作 $O(\log Q)$，空间 $O(Q\log Q)$。

### 易错点

每行p、q都先与上次查询答案异或；添加操作不更新last。样例包含零权新点，代码同样支持。
