## wyh的迷宫

### 题意

多组迷宫，判断不经过x障碍能否四方向到达t。

### 思路

从s开始BFS，入队时标记已访问，不重复经过同一格也足以判断存在路径：任何可达路径删掉环后仍可达。访问到t输出YES，否则NO。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        vector<string> grid(n);
        int start = 0, target = 0;
        for (int r = 0; r < n; r++) {
            cin >> grid[r];
            for (int c = 0; c < m; c++) {
                if (grid[r][c] == 's')
                    start = r * m + c;
                if (grid[r][c] == 't')
                    target = r * m + c;
            }
        }
        vector<bool> seen(n * m);
        vector<int> queue{start};
        seen[start] = true;
        int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
        for (size_t h = 0; h < queue.size(); h++) {
            int r = queue[h] / m, c = queue[h] % m;
            for (int d = 0; d < 4; d++) {
                int rr = r + dr[d], cc = c + dc[d];
                if (rr >= 0 && rr < n && cc >= 0 && cc < m && grid[rr][cc] != 'x' &&
                    !seen[rr * m + cc]) {
                    seen[rr * m + cc] = true;
                    queue.push_back(rr * m + cc);
                }
            }
        }
        cout << (seen[target] ? "YES\n" : "NO\n");
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(nm)$。

### 易错点

字符均小写，输出要求大写YES/NO。每组重新清空队列和标记。
