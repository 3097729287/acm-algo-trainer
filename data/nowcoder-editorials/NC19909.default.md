## [CQOI2007]涂色PAINT

### 题意

一次可把任意连续段刷成同色，后刷覆盖前刷，求达到目标的最少次数。

### 思路

dp[l][r]为从空白刷出目标区间的最少次数。先考虑单独刷l，代价1+dp[l+1][r]。若某个k>l与l同色，可让刷到k的那一笔同时覆盖l，再单独修复中间[l+1,k−1]，代价dp[l+1][k−1]+dp[k][r]。枚举所有同色k取最小，空区间代价0，按长度递增计算。这样的合并对应最优方案中最后留下l颜色的那笔所覆盖的后续同色位置。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int n = s.size();
    vector<vector<int>> dp(n, vector<int>(n));
    for (int l = n - 1; l >= 0; l--) {
        dp[l][l] = 1;
        for (int r = l + 1; r < n; r++) {
            dp[l][r] = 1 + dp[l + 1][r];
            for (int k = l + 1; k <= r; k++)
                if (s[k] == s[l])
                    dp[l][r] = min(dp[l][r], (k == l + 1 ? 0 : dp[l + 1][k - 1]) + dp[k][r]);
        }
    }
    cout << dp[0][n - 1];
    return 0;
}
```

### 复杂度

时间 $O(n^3)$，空间 $O(n^2)$。

### 易错点

颜色可以覆盖，不能只统计相邻色块数。刷同色两端时，中间可以先被一起刷后再重刷。
