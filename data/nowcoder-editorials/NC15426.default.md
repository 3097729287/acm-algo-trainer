## wyh的矩阵

### 题意

顺序填入一到 n² 的奇数阶矩阵，只保留连接四边中点围成的菱形，求和。

### 思路

菱形关于中心对称，每对相对元素之和为 n²+1，中心元素为 (n²+1)/2。若半径 r=(n-1)/2，菱形元素数是 1+4(1+…+r)=(n²+1)/2。因此所有元素的平均值与元素个数相同，答案是 ((n²+1)/2)²。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        long long n;
        cin >> n;
        long long middle = (n * n + 1) / 2;
        cout << middle * middle << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间与额外空间均为 $O(1)$。

### 易错点

n 可接近一万，不能真的建矩阵；答案约为 n⁴/4，需要 long long。
