## 牛牛学数列

### 题意

求一到 n 的交错和，奇数项加、偶数项减。

### 思路

按照定义枚举每个整数，奇数加到答案中，偶数从答案中减去。n 不超过一百，直接累加足够。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int ans = 0;
    for (int i = 1; i <= n; i++)
        ans += (i % 2 ? i : -i);
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

第一项为正，第二项为负。
