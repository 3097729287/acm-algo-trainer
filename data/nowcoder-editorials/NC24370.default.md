## Milk Routing

### 题意

路径耗时为延迟和加X除以最小容量，求最小耗时向下取整。

### 思路

最优路径的瓶颈容量一定等于某条边容量。枚举容量下限c，只用容量≥c的边，Dijkstra求最小延迟L，再用L+floor(X/c)更新答案。若实际路径容量更大，本轮估计只会偏大；而枚举到其真实瓶颈时会得到不差于最优路径的延迟，因此最终恰为最优。所有候选的向下取整可先做再取最小，无需浮点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    long long milk;
    cin >> n >> m >> milk;
    struct Edge {
        int to, latency, capacity;
    };
    vector<vector<Edge>> graph(n);
    vector<int> capacities;
    while (m--) {
        int a, b, l, c;
        cin >> a >> b >> l >> c;
        --a;
        --b;
        graph[a].push_back({b, l, c});
        graph[b].push_back({a, l, c});
        capacities.push_back(c);
    }
    if (n == 1) {
        cout << 0;
        return 0;
    }
    sort(capacities.begin(), capacities.end());
    capacities.erase(unique(capacities.begin(), capacities.end()), capacities.end());
    const long long inf = 1LL << 60;
    long long answer = inf;
    for (int threshold : capacities) {
        vector<long long> distance(n, inf);
        priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                       greater<pair<long long, int>>>
            heap;
        distance[0] = 0;
        heap.push({0, 0});
        while (!heap.empty()) {
            auto [cost, u] = heap.top();
            heap.pop();
            if (cost != distance[u])
                continue;
            if (u == n - 1)
                break;
            for (auto e : graph[u])
                if (e.capacity >= threshold && distance[e.to] > cost + e.latency) {
                    distance[e.to] = cost + e.latency;
                    heap.push({distance[e.to], e.to});
                }
        }
        if (distance[n - 1] != inf)
            answer = min(answer, distance[n - 1] + milk / threshold);
    }
    cout << (answer == inf ? -1 : answer);
    return 0;
}
```

### 复杂度

不同容量数 $K\le M$，时间 $O(K(N+M)\log N)$，空间 $O(N+M)$。

### 易错点

不能只求一次最短延迟后再算容量；更长延迟可能换来更大容量。原题输出向下取整，不四舍五入。
