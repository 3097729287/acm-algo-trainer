## C Simple math problem

### 题意

如果 X 是 Y 的因数，输出 X+Y，否则输出 Y-X。

### 思路

用 Y%X==0 判断 X 是否整除 Y。输入可能达到十的十四次方，变量与结果均使用 long long。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long x, y;
    cin >> x >> y;
    cout << (y % x == 0 ? x + y : y - x);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不要写成 X%Y；除数与被除数的角色不同。
