## 数字三角形

### 题意

多组输入边长n，打印第i行从1到i的数字三角形，每个数字后有空格。

### 思路

外层循环控制行号i从1到n，内层依次输出1到i，每个数字后输出一个空格，行末换行。读到文件结束即可处理全部组，不另加分隔空行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n)
        for (int i = 1; i <= n; i++) {
            for (int value = 1; value <= i; value++)
                cout << value << ' ';
            cout << '\n';
        }
    return 0;
}
```

### 复杂度

每组输出 $O(n^2)$ 个数字，额外空间 $O(1)$。

### 易错点

这是打印图案题，不是求最大路径的数字三角形DP。n可以超过9，每项按整数正常输出。
