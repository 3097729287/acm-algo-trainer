## 月月给华华出题

### 题意

对每个N不超过n，求Σi/gcd(i,N)。

### 思路

按d=N/gcd(i,N)分类，令i=(N/d)*j，则1≤j≤d且gcd(j,d)=1，贡献变为j。d>1时，互质数j和d−j配对，所以这一组的和是d*phi(d)/2；d=1单独贡献1。令g(N)=Σ(d|N)d*phi(d)，统一答案为(g(N)+1)/2。先筛phi，再枚举约数d向它的所有倍数加d*phi(d)，最后逐行输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> phi(n + 1);
    iota(phi.begin(), phi.end(), 0);
    for (int p = 2; p <= n; p++)
        if (phi[p] == p)
            for (int x = p; x <= n; x += p)
                phi[x] = phi[x] / p * (p - 1);
    vector<long long> sum(n + 1);
    for (int d = 1; d <= n; d++)
        for (int x = d; x <= n; x += d)
            sum[x] += 1LL * d * phi[d];
    for (int x = 1; x <= n; x++)
        cout << (sum[x] + 1) / 2 << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

d=1的互质和为1，不能也按d*phi(d)/2做整数除法。先累加再统一除二，使用64位。
