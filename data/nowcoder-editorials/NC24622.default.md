## Brownie Slicing

### 题意

先水平切为 A 条，每条独立竖切为 B 块，最大化所有块中的最少巧克力数。

### 思路

二分每块至少 target。对当前横条累计每列的巧克力，沿列从左到右累计到至少 target 就竖切一块；若可切出至少 B 块，这个横条就合格，立即在当前行后横切并清空列和。两层都采用最早可行的切点：巧克力非负，把切点向后拖只会占用后续可用的行或列，不会改善后续机会。能得到至少 A 个横条就成功。剩余列、剩余行并入各自最后一块即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, columns, a, b;
    cin >> rows >> columns >> a >> b;
    vector<vector<long long>> grid(rows, vector<long long>(columns));
    long long total = 0;
    for (auto &row : grid)
        for (auto &x : row) {
            cin >> x;
            total += x;
        }
    auto possible = [&](long long target) {
        vector<long long> sums(columns);
        int strips = 0;
        for (const auto &row : grid) {
            for (int c = 0; c < columns; c++)
                sums[c] += row[c];
            long long sum = 0;
            int pieces = 0;
            for (long long x : sums) {
                sum += x;
                if (sum >= target) {
                    pieces++;
                    sum = 0;
                }
            }
            if (pieces >= b) {
                strips++;
                if (strips >= a)
                    return true;
                fill(sums.begin(), sums.end(), 0);
            }
        }
        return false;
    };
    long long low = 0, high = total / a / b;
    while (low < high) {
        long long mid = low + (high - low + 1) / 2;
        if (possible(mid))
            low = mid;
        else
            high = mid - 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

时间 $O(RC\log(H+1))$，空间 $O(RC)$，$H$ 为总巧克力数。

### 易错点

每条横带的竖切位置可独立选择，不要求整块布朗尼使用相同竖线。target=0 时每块仍须非空，代码每列至多切出一块。
