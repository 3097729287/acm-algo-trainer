## [NOIP2011]聪明的质监员

### 题意

选重量阈值，让所有区间内的数量乘价值和之和，最接近标准 S。

### 思路

阈值 W 增大时，选中的矿石只会减少，每个区间数量与价值和均不增，所以总检验值 Y 单调不增。固定 W，预处理符合阈值矿石的计数前缀与价值前缀，每个区间 O(1) 求数量乘价值和。二分第一个 Y<=S 的阈值，只需比较这个阈值与前一个阈值，分别给出跨越 S 两侧的最近候选。W=maxWeight+1 会选不到任何矿石，保证二分有界。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    long long standard;
    cin >> n >> m >> standard;
    vector<int> weight(n + 1), value(n + 1);
    int maxWeight = 0;
    for (int i = 1; i <= n; i++) {
        cin >> weight[i] >> value[i];
        maxWeight = max(maxWeight, weight[i]);
    }
    vector<pair<int, int>> intervals(m);
    for (auto &[l, r] : intervals)
        cin >> l >> r;
    vector<long long> count(n + 1), sum(n + 1);
    auto evaluate = [&](int threshold) {
        for (int i = 1; i <= n; i++) {
            bool chosen = weight[i] >= threshold;
            count[i] = count[i - 1] + chosen;
            sum[i] = sum[i - 1] + (chosen ? value[i] : 0);
        }
        __int128 result = 0;
        for (auto [l, r] : intervals)
            result += (__int128)(count[r] - count[l - 1]) * (sum[r] - sum[l - 1]);
        return result;
    };
    int low = 1, high = maxWeight + 1;
    while (low < high) {
        int mid = (low + high) / 2;
        if (evaluate(mid) <= standard)
            high = mid;
        else
            low = mid + 1;
    }
    long long answer = standard;
    for (int threshold : {low, low - 1})
        if (threshold >= 1) {
            __int128 result = evaluate(threshold),
                     difference = result >= standard ? result - standard : standard - result;
            if (difference < answer)
                answer = (long long)difference;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log W_{max})$，空间 $O(n+m)$。

### 易错点

总检验值按题面完整范围可超过 64 位，累加使用 __int128。最终最小差不超过 S，因为可选择空集；因此答案可安全用 long long。
