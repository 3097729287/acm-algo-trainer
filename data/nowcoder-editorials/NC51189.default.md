## Mondriaan's Dream

### 题意

用1乘2或2乘1骨牌铺满矩形，统计全部不同铺法，多组0 0结束。

### 思路

取较短边作列宽。行mask表示当前行哪些格已被上一行竖骨牌占住。对每个mask从左到右递归填剩余格：横放占当前行相邻两空格；竖放占当前格，并把下一行对应位设1。填完当前行后得到一个下一行mask转移。预处理全部行转移，再按行累加。初态与终态都必须为0，保证没有骨牌伸出上下边界。面积奇数时直接0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols;
    while (cin >> rows >> cols && (rows || cols)) {
        if ((rows * cols) % 2) {
            cout << "0\n";
            continue;
        }
        if (cols > rows)
            swap(rows, cols);
        int masks = 1 << cols;
        vector<vector<int>> transition(masks);
        for (int incoming = 0; incoming < masks; incoming++) {
            auto fill = [&](auto &&self, int c, int outgoing) -> void {
                if (c == cols) {
                    transition[incoming].push_back(outgoing);
                    return;
                }
                if (incoming >> c & 1)
                    self(self, c + 1, outgoing);
                else {
                    self(self, c + 1, outgoing | (1 << c));
                    if (c + 1 < cols && !(incoming >> (c + 1) & 1))
                        self(self, c + 2, outgoing);
                }
            };
            fill(fill, 0, 0);
        }
        vector<long long> dp(masks), next(masks);
        dp[0] = 1;
        for (int r = 0; r < rows; r++) {
            fill(next.begin(), next.end(), 0);
            for (int mask = 0; mask < masks; mask++)
                for (int out : transition[mask])
                    next[out] += dp[mask];
            dp.swap(next);
        }
        cout << dp[0] << '\n';
    }
    return 0;
}
```

### 复杂度

短边 $W\le11$，行转移总数 $E$，时间 $O(2^W3^W+HE)$ 为保守界，空间 $O(2^W+E)$。

### 易错点

对称、旋转后不同的铺法依然分别计数。最后不是所有mask求和，只能取没有悬空竖骨牌的0。
