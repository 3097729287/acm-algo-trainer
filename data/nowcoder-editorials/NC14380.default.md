## 位数差

### 题意

对原下标 i<j，累计 a[i]+a[j] 的十进制位数减 a[i] 位数，零按一位算。

### 思路

一个非负整数的位数等于一，加上它达到的阈值 10、100、1000……的数量。因此先把所有数对各自的一贡献记入，再减去原下标权重 (n-1-i)*digits(a[i])。剩下只需对每个十进制阈值 T，统计有多少无序数对满足 a[i]+a[j]>=T；这一部分与原顺序无关，可以排序后双指针。若最小与最大之和已达到 T，就有 right-left 对以最大值为右端的数对达标，然后右端减一；否则左端加一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    long long answer = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        int digits = 1;
        for (long long x = a[i]; x >= 10; x /= 10)
            digits++;
        answer += (n - 1LL - i) * (1 - digits);
    }
    sort(a.begin(), a.end());
    for (long long threshold = 10; threshold <= 200000000; threshold *= 10) {
        int left = 0, right = n - 1;
        while (left < right) {
            if (a[left] + a[right] >= threshold) {
                answer += right - left;
                right--;
            } else
                left++;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n+n\log A)$，空间 $O(n)$；本题最多八个十进制阈值。

### 易错点

h(a,b) 对 a、b 不对称，减去 a[i] 位数的那部分必须在排序前按原下标算。h(0,100)=2，h(100,0)=0。
