## 扫雷

### 题意

地雷保留星号，其他格输出八邻域中的地雷数。

### 思路

保存原棋盘。对每个非雷格，枚举行偏移和列偏移各为负一、零、一的九种组合，排除自身和越界位置，统计原棋盘中的雷。输出过程中不修改原棋盘，避免把已填的数字误当成输入。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> a(n);
    for (string &s : a)
        cin >> s;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (a[i][j] == '*') {
                cout << '*';
                continue;
            }
            int count = 0;
            for (int dx = -1; dx <= 1; dx++)
                for (int dy = -1; dy <= 1; dy++) {
                    int x = i + dx, y = j + dy;
                    if (dx == 0 && dy == 0)
                        continue;
                    if (x >= 0 && x < n && y >= 0 && y < m && a[x][y] == '*')
                        count++;
                }
            cout << count;
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间与棋盘空间均为 $O(nm)$。

### 易错点

斜向四格也在邻域中；边界处要先检查坐标再访问。
