## 牛牛学梯形

### 题意

根据上下底和高求梯形面积。

### 思路

梯形面积是两底之和乘高再除以二。用 double 保存，除数写为 2.0，使奇数面积保留小数部分。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    double up, down, height;
    cin >> up >> down >> height;
    cout << fixed << setprecision(3) << (up + down) * height / 2.0;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

先算两底之和；输出固定三位小数。
