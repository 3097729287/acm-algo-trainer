## 给定长度和数位和。。。

### 题意

构造位数为 m、数位和为 s 的最小和最大非负十进制整数。

### 思路

除单个零外，多位数首位不能为零；若 s 为零或超过 9m 就无解。最大值从高位开始尽量填九。最小值则从高位枚举当前可用的最小数字 d，要求剩余数位和非负且不超过剩下位数的九倍；该条件充分，所以选第一个可行 d 即可。每一步选最小可行前缀，整体即最小。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int m, s;
        cin >> m >> s;
        if (m == 1 && s == 0) {
            cout << "0 0\n";
            continue;
        }
        if (s == 0 || s > 9 * m) {
            cout << "-1\n";
            continue;
        }
        string minimum, maximum;
        int remaining = s;
        for (int i = 0; i < m; i++)
            for (int d = i == 0 ? 1 : 0; d <= 9; d++)
                if (remaining >= d && remaining - d <= 9 * (m - i - 1)) {
                    minimum += char('0' + d);
                    remaining -= d;
                    break;
                }
        remaining = s;
        for (int i = 0; i < m; i++) {
            int d = min(9, remaining);
            maximum += char('0' + d);
            remaining -= d;
        }
        cout << minimum << ' ' << maximum << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(10m)$，结果空间 $O(m)$。

### 易错点

本牛客版本第一行有测试组数，无解只输出一个 -1；不要直接照搬原 Codeforces 版本的输入输出格式。
