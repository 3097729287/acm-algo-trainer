## 牛牛是否被叫家长

### 题意

三科平均分低于六十则请家长，输出 YES；否则输出 NO。

### 思路

平均分低于六十等价于总分小于一百八十，直接比较整数和即可。这样没有浮点误差，也不用整数除法。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, c;
    cin >> a >> b >> c;
    cout << (a + b + c < 180 ? "YES" : "NO");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

恰好六十分不会请家长。YES 表示会被请家长，不能反过来理解。
