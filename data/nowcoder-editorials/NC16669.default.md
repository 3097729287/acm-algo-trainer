## [NOIP2006]明明的随机数

> 原题：[P1059](https://www.luogu.com.cn/problem/P1059)
> 解法：布尔桶去重并升序扫描 · C++17

### 题意

对一到一千范围内的随机数去重，并按升序输出不同数字。



### 思路

用布尔桶记录某个值是否出现，再从一到一千顺序扫描；出现过的值只输出一次。

值域为 V，时间 $O(n+V)$、空间 $O(V)$，本题 V=1000。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    bool present[1001] = {};
    while (n--) {
        int x;
        cin >> x;
        present[x] = true;
    }
    int count = 0;
    for (int x = 1; x <= 1000; x++)
        count += present[x];
    cout << count << '\n';
    bool first = true;
    for (int x = 1; x <= 1000; x++)
        if (present[x]) {
            if (!first)
                cout << ' ';
            cout << x;
            first = false;
        }
    cout << '\n';
    return 0;
}
```

### 易错点

只保留是否出现，不保存重复次数；使用题目给定的小值域。
