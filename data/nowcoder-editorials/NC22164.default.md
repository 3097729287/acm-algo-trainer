## 更相减损术

### 题意

求两个正整数的最大公约数。

### 思路

从较大数反复减小数，不会改变公约数集合。把连续相减合并成一次取余，就得到欧几里得算法 gcd(a,b)=gcd(b,a%b)，直到第二项为零。该写法与更相减损术结果相同且避免悬殊输入的过多相减。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    while (b != 0) {
        int remainder = a % b;
        a = b;
        b = remainder;
    }
    cout << a;
    return 0;
}
```

### 复杂度

时间 $O(\log\min(a,b))$，额外空间 $O(1)$。

### 易错点

终止时返回非零的 a，而不是已经变为零的 b。
