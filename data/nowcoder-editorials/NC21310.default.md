## 明天星期几？

### 题意

将今天的星期编号推进一天，星期日之后回到星期一。

### 思路

d%7 把星期日映射为零，其余天数不变，再加一正好得到明天的编号。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int d;
    cin >> d;
    cout << d % 7 + 1;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

星期天用七表示，不能直接输出 d+1。
