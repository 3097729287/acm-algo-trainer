## KiKi的最高分

### 题意

输出三门成绩中最高的一个。

### 思路

先读入三个整数，用 max 对三项一起取最大值。相同成绩无需特别处理。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, c;
    cin >> a >> b >> c;
    cout << max({a, b, c});
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

输出最高分本身，不是它在输入中的位置。
