## [JSOI2007]建筑抢修

### 题意

每栋建筑有抢修耗时和截止时刻，一次修一栋，求最多抢修数。

### 思路

按截止时刻递增。把当前建筑加入已选任务，若累计耗时超过截止时刻，从所有已选任务中删去耗时最长的一个。原已选任务均可行，删去最大耗时至少抵消新加入耗时，因此删一个就恢复可行。

同数量的可行任务中，选择总耗时最小者能给后续留最多时间。遇到超时时必须舍弃至少一项，而舍弃最长项使剩余总耗时最小；由这一不变式逐项处理可保持最优数量。大根堆支持删除最长耗时。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<int, int>> tasks(n);
    for (auto &[deadline, duration] : tasks)
        cin >> duration >> deadline;
    sort(tasks.begin(), tasks.end());
    priority_queue<int> selected;
    long long elapsed = 0;
    for (auto [deadline, duration] : tasks) {
        elapsed += duration;
        selected.push(duration);
        if (elapsed > deadline) {
            elapsed -= selected.top();
            selected.pop();
        }
    }
    cout << selected.size();
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

截止时刻恰好完成仍可抢救。总耗时需64位；不能简单地忽略所有当前放不下的任务，替换最长任务可能为后续腾出时间。
