## Forsaken喜欢独一无二的树

### 题意

删除最小权值总和的边，让原MST权值不变且MST唯一。

### 思路

按权值分组Kruskal。进入权值w组前，先按更小权边收缩连通块。组内两端已在同一旧块的边永远不在任何MST中，可保留；其余候选边若在收缩图中有环，环上等权边可替换，MST就不唯一。必须把这些候选边删成森林，最少删除数为候选边数减该组的连通秩。

先完整收集本组所有候选边，再对它们做并查集合并。成功合并的数就是秩，失败合并的候选边各必须删除一条，费用同为w，累计即可。收缩图每个分量保留任意生成树都能使后续Kruskal连通关系不变，所以原MST权值保持。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    struct Edge {
        int a, b;
        long long w;
    };
    vector<Edge> edges(m);
    for (auto &e : edges)
        cin >> e.a >> e.b >> e.w;
    sort(edges.begin(), edges.end(), [](auto a, auto b) { return a.w < b.w; });
    DSU dsu(n);
    long long answer = 0;
    for (int l = 0; l < m;) {
        int r = l;
        while (r < m && edges[r].w == edges[l].w)
            r++;
        vector<pair<int, int>> candidates;
        for (int i = l; i < r; i++) {
            int a = dsu.find(edges[i].a), b = dsu.find(edges[i].b);
            if (a != b)
                candidates.push_back({a, b});
        }
        for (auto [a, b] : candidates)
            if (!dsu.unite(a, b))
                answer += edges[l].w;
        l = r;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(m\log m+(n+m)\alpha(n))$，空间 $O(n+m)$。

### 易错点

必须在合并本组任何边之前筛候选，不能把本组造成的同根误认为更小权已经连通。原来就不是MST候选的重边或环边无需删除。
