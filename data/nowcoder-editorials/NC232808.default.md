## Sort Points by Argument

### 题意

按arg从−π到π排序，负x轴算π，原点算0。

### 思路

先按四个连续角区分组：y<0；y=0且x≥0（含原点）；y>0；y=0且x<0。组内非共线时叉积>0者在前，同方向用输入编号打破平局。这样完全避免atan2精度，并把负x轴放在最后、原点与正x轴放在0角。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct P {
        long long x, y;
        int id;
    };
    vector<P> point(n);
    for (int i = 0; i < n; i++) {
        cin >> point[i].x >> point[i].y;
        point[i].id = i;
    }
    auto part = [](const P &p) {
        if (p.y < 0)
            return 0;
        if (p.y == 0 && p.x >= 0)
            return 1;
        if (p.y > 0)
            return 2;
        return 3;
    };
    sort(point.begin(), point.end(), [&](auto a, auto b) {
        int x = part(a), y = part(b);
        if (x != y)
            return x < y;
        __int128 value = (__int128)a.x * b.y - (__int128)a.y * b.x;
        if (value)
            return value > 0;
        return a.id < b.id;
    });
    for (auto p : point)
        cout << p.x << ' ' << p.y << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

原点没有天然方向，题目指定arg=0，不能让它参与一般半平面叉积比较而破坏严格弱序。
