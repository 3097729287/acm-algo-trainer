## 整数的个位

### 题意

求非负整数的个位数字。

### 思路

十进制中每十个数个位循环一次，所以对十取余即可。零的个位仍为零。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a;
    cin >> a;
    cout << a % 10;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

按当前题面输入非负，不需要负数余数的额外处理。
