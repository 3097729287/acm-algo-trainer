## 计数器

### 题意

可反复加给定正整数，求模m后可达余数数量。

### 思路

令g=gcd(m,a1,...,an)。任何组合都是g倍数，因此只有m/g个候选余数。裴蜀定理保证整数线性组合能得到g；负系数在模m下也能改为非负，因为加a共m次回到同一余数。因此所有g倍数余数都可达，答案m/g，包括初始余数0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long m;
    cin >> n >> m;
    long long g = m;
    while (n--) {
        long long a;
        cin >> a;
        g = gcd(g, a);
    }
    cout << m / g;
    return 0;
}
```

### 复杂度

时间 $O(n\log m)$，空间 $O(1)$。

### 易错点

可达余数包含0，操作次数允许为0。不是只求a之间的gcd，还要把模数m加入。
