## 【模板】牛牛学加法

### 题意

计算两个非负整数的和。

### 思路

按输入顺序读入 a、b，输出 a+b。最大结果为两千，int 足够保存。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

相加后只输出一个整数。
