## Colorful String

### 题意

每个回文子串的价值为不同字母数，累计所有回文出现的价值。

### 思路

按字母分别计贡献。对某字母 c，所有包含 c 的回文各贡献一；其数量等于全部回文数，减去不含 c 的回文数。把字符串按 c 的出现位置切成若干个不含 c 的连续段，不含 c 的回文必完整落在其中某一段，在各段独立用 Manacher 计数即可。于是答案是 26*全部回文数，再减去二十六次所有无 c 段中的回文数。固定字母只有二十六种，每轮段长之和不超过 n，所以总共线性乘一个常数。

计数函数分别求奇、偶回文半径，将半径求和；数组可在各段间复用。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long countPalindromes(const string &s, int begin, int end, vector<int> &radius) {
    long long answer = 0;
    int left = begin, right = begin - 1;
    for (int i = begin; i < end; i++) {
        int k = i > right ? 1 : min(radius[left + right - i], right - i + 1);
        while (i - k >= begin && i + k < end && s[i - k] == s[i + k])
            k++;
        radius[i] = k;
        answer += k;
        if (i + k - 1 > right) {
            left = i - k + 1;
            right = i + k - 1;
        }
    }
    left = begin;
    right = begin - 1;
    for (int i = begin; i < end; i++) {
        int k = i > right ? 0 : min(radius[left + right - i + 1], right - i + 1);
        while (i - k - 1 >= begin && i + k < end && s[i - k - 1] == s[i + k])
            k++;
        radius[i] = k;
        answer += k;
        if (i + k - 1 > right) {
            left = i - k;
            right = i + k - 1;
        }
    }
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int n = s.size();
    vector<int> radius(n);
    long long total = countPalindromes(s, 0, n, radius), answer = 26 * total;
    for (char c = 'a'; c <= 'z'; c++) {
        int begin = 0;
        for (int i = 0; i <= n; i++)
            if (i == n || s[i] == c) {
                answer -= countPalindromes(s, begin, i, radius);
                begin = i + 1;
            }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(26n)$，额外空间 $O(n)$。

### 易错点

同一个字母在回文里出现多次仍只贡献一。不能把“回文长度”当价值；空段没有回文。总贡献可超过 32 位。
