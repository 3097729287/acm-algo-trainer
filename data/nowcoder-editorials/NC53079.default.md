## Forsaken喜欢数论

### 题意

求1到n每个数的最小质因子之和，n至三千万，1的贡献为0。

### 思路

所有偶数的最小质因子都是2。奇数只需存一个16位最小质因子：奇合数的最小质因子≤sqrt(n)<5500，未填表示奇素数。按递增奇素数p，从p²起每隔2p给尚未填的奇合数记录p，第一次填入就是最小质因子。最后逐数求和，奇数未填时加它自身。只为奇数开数组，约三千万字节，避免每个数用32位因子的内存。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<uint16_t> smallest(n / 2 + 1);
    for (int p = 3; 1LL * p * p <= n; p += 2)
        if (!smallest[p / 2])
            for (int x = p * p; x <= n; x += 2 * p)
                if (!smallest[x / 2])
                    smallest[x / 2] = p;
    long long answer = 2LL * (n / 2);
    for (int x = 3; x <= n; x += 2)
        answer += smallest[x / 2] ? smallest[x / 2] : x;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log\log n)$，存约 $n/2$ 个16位数，空间 $O(n)$ 字节。

### 易错点

未填的奇数是素数，其贡献不是0。1单独跳过；总和用64位。
