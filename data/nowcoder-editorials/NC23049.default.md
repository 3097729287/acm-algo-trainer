## 华华给月月准备礼物

### 题意

把已有木棍裁成至少 K 段等长整数木棍，求最大段长，无法得到正长度则为零。

### 思路

给定正长度 d，每根原木能贡献 floor(L[i]/d) 段。总段数至少 K 就可行，目标 d 越大段数越少。二分最大可行正长度，以零为已知可行的哨兵；判定从不除以零。累计达到 K 后即可提前返回。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long k;
    cin >> n >> k;
    vector<long long> a(n);
    long long high = 0;
    for (auto &x : a) {
        cin >> x;
        high = max(high, x);
    }
    auto possible = [&](long long length) {
        long long count = 0;
        for (long long x : a) {
            count += x / length;
            if (count >= k)
                return true;
        }
        return false;
    };
    long long low = 0;
    while (low < high) {
        long long mid = low + (high - low + 1) / 2;
        if (possible(mid))
            low = mid;
        else
            high = mid - 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

时间 $O(n\log L_{max})$，空间 $O(n)$。

### 易错点

允许丢掉剩余段，也允许多切出 K 段后只使用 K 段，因此判定是至少 K。若总原长都不足 K，输出零。
