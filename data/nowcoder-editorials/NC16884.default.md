## [NOI2001]食物链

### 题意

逐条判定三类动物的同类、捕食关系是否与之前真话冲突，统计假话。

### 思路

每只动物建三个结点 x、x+n、x+2n，表示循环三种相对类。相同关系要求三组对应相连；x吃y要求 x 与 y+n、x+n 与 y+2n、x+2n 与 y 相连。加入前先判断与另外两种关系是否冲突。相同关系若 x 已与 y+n 或 y+2n 同组就是假话；捕食关系若 x 已与 y 或 y+2n 同组就是假话。越界同样是假话。只合并真话，假话完全忽略。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    DSU dsu(3 * n);
    int lies = 0;
    while (k--) {
        int type;
        long long rawX, rawY;
        cin >> type >> rawX >> rawY;
        if (rawX < 1 || rawX > n || rawY < 1 || rawY > n) {
            lies++;
            continue;
        }
        int x = rawX, y = rawY;
        bool falsehood =
            type == 1 ? (dsu.find(x) == dsu.find(y + n) || dsu.find(x) == dsu.find(y + 2 * n))
                      : (dsu.find(x) == dsu.find(y) || dsu.find(x) == dsu.find(y + 2 * n));
        if (falsehood) {
            lies++;
            continue;
        }
        if (type == 1) {
            for (int offset = 0; offset < 3; offset++)
                dsu.unite(x + offset * n, y + offset * n);
        } else {
            dsu.unite(x, y + n);
            dsu.unite(x + n, y + 2 * n);
            dsu.unite(x + 2 * n, y);
        }
    }
    cout << lies;
    return 0;
}
```

### 复杂度

时间 $O((n+k)\alpha(n))$，空间 $O(n)$。

### 易错点

捕食是有方向的三循环，不能只维护敌我两类。假话不写入并查集。x吃x会由同根检测自动判假。
