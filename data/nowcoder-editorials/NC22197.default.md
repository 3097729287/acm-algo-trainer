## 零钱兑换

### 题意

把 n 元换成一元、二元、五元，统计各种面额数量的组合。

### 思路

枚举五元的张数 five，剩余 rest=n-5five。二元可以取零到 floor(rest/2) 张，而一元数量随之唯一确定。因此这一轮贡献 floor(rest/2)+1 种，求和即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int answer = 0;
    for (int five = 0; five * 5 <= n; five++)
        answer += (n - five * 5) / 2 + 1;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

只区分各面额的数量，不区分拿钱的先后顺序；循环必须包含一种面额完全不用的情况。
