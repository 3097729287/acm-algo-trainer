## 华华对月月的忠诚

### 题意

类斐波那契数列初值A、B，N可有十万位，求相邻两项gcd。

### 思路

欧几里得性质gcd(x+y,y)=gcd(x,y)说明相邻两项gcd始终不变：gcd(F[N+1],F[N])=gcd(F[N],F[N−1])，一路退回gcd(A,B)。因此无需生成大数，也不用把N转成整数，只读成字符串后计算初值gcd。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    unsigned long long a, b;
    string n;
    cin >> a >> b >> n;
    cout << gcd(a, b);
    return 0;
}
```

### 复杂度

读入时间 $O(|N|)$，gcd时间 $O(\log A)$；存N的空间 $O(|N|)$。

### 易错点

N很长但完全不影响答案。A、B至10^17，需64位读取。
