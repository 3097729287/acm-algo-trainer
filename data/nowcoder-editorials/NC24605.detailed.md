## Corn Maze

> 原题：[P1825](https://www.luogu.com.cn/problem/P1825)
> 解法：把踏入传送门与瞬移合成一次移动 · C++17

### 题意

四向移动花一时间，踏入大写字母格必须立刻传到同字母另一格，传送不花时间。求从 @ 到 = 的最短时间。



### 思路

样例先向右走到 W，花一时间，立即到上面的 W，不额外花时间；再向右、向上，各花一，共三。若把传送也算一步，就会多算；若允许踏入 W 后不传送，又加入了题目没有的选择。

一次完整行动是“走到相邻格；若它是入口，立刻传到配对位置”。把这个行动合并成一条代价一的边，就仍是一张等权有向图，可以普通 BFS，不必把门另画成可选的零费用边而漏掉强制性。

站在传送后的端点时，这一次瞬移已经结束，下一步可以走到它旁边。只有以后再次从相邻格踏入某个端点，才触发新一次传送，不能立刻把刚落脚的位置反复当作新入口。代码在选出邻格后最多替换一次坐标，正好表达这个规则。

同一个门的两端仍是两个不同状态。从 A 端进入会落在 B 端，反过来则落在 A，接下来可走的邻格不同，所以不能把两端一起标成“门已使用”。每个落脚格首次到达最短，后续无须重复入队。

时间、空间均为 $O(nm)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    vector<pair<int, int>> port[26];
    int sx = 0, sy = 0;
    for (int i = 0; i < n; i++) {
        cin >> grid[i];
        for (int j = 0; j < m; j++) {
            char c = grid[i][j];
            if (c == '@') {
                sx = i;
                sy = j;
            }
            if ('A' <= c && c <= 'Z')
                port[c - 'A'].push_back({i, j});
        }
    }
    vector<vector<int>> distance(n, vector<int>(m, -1));
    queue<pair<int, int>> todo;
    todo.push({sx, sy});
    distance[sx][sy] = 0;
    int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    while (!todo.empty()) {
        auto [x, y] = todo.front();
        todo.pop();
        if (grid[x][y] == '=') {
            cout << distance[x][y] << '\n';
            return 0;
        }
        for (int d = 0; d < 4; d++) {
            int nx = x + dr[d], ny = y + dc[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m || grid[nx][ny] == '#')
                continue;
            char c = grid[nx][ny];
            if ('A' <= c && c <= 'Z') {
                auto &ends = port[c - 'A'];
                pair<int, int> entered = {nx, ny};
                auto destination = (ends[0] == entered ? ends[1] : ends[0]);
                nx = destination.first;
                ny = destination.second; // 同一次行动只传送一次。
            }
            if (distance[nx][ny] == -1) {
                distance[nx][ny] = distance[x][y] + 1;
                todo.push({nx, ny});
            }
        }
    }
    cout << -1 << '\n';
    return 0;
}
```

### 易错点

踏入门必须传送且只传一次；两端是不同落脚状态；访问标记放在传送后位置。
