## 回文数

### 题意

在指定进制中不断把数与自身反转相加，求三十步以内首次出现回文数的步数。

### 思路

用低位在前的数位数组保存原数，不转换为机器整数。每轮先比较首尾判断回文；若不是，就把当前数位与反向数位逐位相加，按输入进制进位。每次相加最多增加一位，三十轮足以直接模拟。检查第零步到第三十步，第三十次相加后的结果也必须检查。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int base;
    string s;
    cin >> base >> s;
    vector<int> a;
    for (int i = (int)s.size() - 1; i >= 0; i--) {
        char c = toupper(static_cast<unsigned char>(s[i]));
        a.push_back(c <= '9' ? c - '0' : c - 'A' + 10);
    }
    for (int step = 0; step <= 30; step++) {
        if (equal(a.begin(), a.end(), a.rbegin())) {
            cout << "STEP=" << step;
            return 0;
        }
        if (step == 30)
            break;
        vector<int> next;
        int carry = 0, n = a.size();
        for (int i = 0; i < n; i++) {
            int value = a[i] + a[n - 1 - i] + carry;
            next.push_back(value % base);
            carry = value / base;
        }
        if (carry)
            next.push_back(carry);
        a.swap(next);
    }
    cout << "Impossible!";
    return 0;
}
```

### 复杂度

若初始位数为 $L$，时间 $O(30(L+30))$，数位空间 $O(L+30)$。

### 易错点

进位基数是输入的 N，不能始终按十进制处理。原题失败输出采用半角叹号的 Impossible!；回文初值需要零步。
