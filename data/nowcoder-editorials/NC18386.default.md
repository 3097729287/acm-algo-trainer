## 字符串

### 题意

找包含全部二十六种小写字母的最短连续子串。

### 思路

窗口维护各字母次数与已出现种类数。右端加入一个字符后，只要种类数为二十六，就用当前长度更新答案，再删去左端字符尝试缩短；某种次数变零时窗口不再合法，继续扩张右端。每个端点都只向右走。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int count[26] = {}, kinds = 0, left = 0, answer = INT_MAX;
    for (int right = 0; right < (int)s.size(); right++) {
        if (count[s[right] - 'a']++ == 0)
            kinds++;
        while (kinds == 26) {
            answer = min(answer, right - left + 1);
            if (--count[s[left] - 'a'] == 0)
                kinds--;
            left++;
        }
    }
    cout << (answer == INT_MAX ? -1 : answer);
    return 0;
}
```

### 复杂度

时间 $O(|s|)$，频次数组额外空间 $O(1)$。

### 易错点

重复字母不增加种类数；删字符后只有次数变为零才减少种类。窗口长度的理论下限是二十六。
