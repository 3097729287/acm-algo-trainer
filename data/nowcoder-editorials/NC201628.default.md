## 纸牌游戏

### 题意

对方出牌顺序已知，可重排自己的牌，使所有 max(自己的牌-对方的牌,0) 之和最大。

### 思路

把对方牌升序排，自己的牌降序排，逐项累加正差。可从获胜的 k 轮看出上界：总分至多为自己的最大 k 张之和，减对方最小 k 张之和。这两个序列一降一升，逐项差单调不增，取所有正差正好最大化该上界；把其余牌任意配给剩下的轮次即可达到。只求分数，原出牌顺序可以通过重新安排自己的牌还原，不影响最优值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n), b(n);
    for (auto &x : a)
        cin >> x;
    for (auto &x : b)
        cin >> x;
    sort(a.begin(), a.end());
    sort(b.begin(), b.end(), greater<long long>());
    __int128 answer = 0;
    for (int i = 0; i < n; i++)
        if (b[i] > a[i])
            answer += b[i] - a[i];
    if (!answer)
        cout << 0;
    else {
        string s;
        while (answer) {
            s += char('0' + answer % 10);
            answer /= 10;
        }
        reverse(s.begin(), s.end());
        cout << s;
    }
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

单张牌可达 10^18，总分可能超过 64 位；用 __int128 累加并按十进制输出。目标不是获胜轮数。
