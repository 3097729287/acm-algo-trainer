## [NOIP2013]表达式求值

### 题意

按乘法优先于加法求值，只输出结果最后四位且不补前导零。

### 思路

把表达式看成若干乘法段的和。扫描一个整数后，将它乘入当前段；遇到加号或表达式结束，就把该段加入答案并将乘积重置为一。数字解析、乘法、加法都对一万取模，既保留最后四位又避免大整数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    long long answer = 0, product = 1;
    size_t i = 0;
    while (i < s.size()) {
        int value = 0;
        while (i < s.size() && isdigit(static_cast<unsigned char>(s[i]))) {
            value = (value * 10 + s[i] - '0') % 10000;
            i++;
        }
        product = product * value % 10000;
        if (i == s.size() || s[i] == '+') {
            answer = (answer + product) % 10000;
            product = 1;
        }
        i++;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间与输入字符串空间均为 $O(|S|)$。

### 易错点

当前乘法段初始值是一，不能是零。余数四应输出 4 而不是 0004。
