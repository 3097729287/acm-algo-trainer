## 小Z的袜子

### 题意

每次从指定区间随机抽两只袜子，输出颜色相同的概率的最简分数。

### 思路

设窗口内每色数量为 count[c]，同色无序对数 pairs=ΣC(count[c],2)，总无序对数为 C(len,2)。加入一只颜色 c 时，它与原有 count[c] 只各形成一对，所以先加 count[c] 再把计数加一；删除时先减计数，再减去剩下的 count[c]。这使窗口左右端移动一步只需常数时间。

把询问按左端所在块、再按右端排序，用莫队维护当前窗口；相邻块采用相反右端方向以减少来回移动。答案为 pairs/C(len,2)，用最大公约数约分，零概率单独写成 0/1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> color(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> color[i];
    int block = max(1, (int)sqrt(n));
    struct Query {
        int l, r, id;
    };
    vector<Query> queries(m);
    for (int i = 0; i < m; i++) {
        cin >> queries[i].l >> queries[i].r;
        queries[i].id = i;
    }
    sort(queries.begin(), queries.end(), [&](auto a, auto b) {
        int x = a.l / block, y = b.l / block;
        if (x != y)
            return x < y;
        return x % 2 ? a.r > b.r : a.r < b.r;
    });
    vector<long long> count(n + 1);
    vector<pair<long long, long long>> answer(m);
    long long pairs = 0;
    int left = 1, right = 0;
    auto add = [&](int p) { pairs += count[color[p]]++; };
    auto remove = [&](int p) { pairs -= --count[color[p]]; };
    for (auto q : queries) {
        while (left > q.l)
            add(--left);
        while (right < q.r)
            add(++right);
        while (left < q.l)
            remove(left++);
        while (right > q.r)
            remove(right--);
        long long length = q.r - q.l + 1, total = length * (length - 1) / 2;
        if (pairs == 0 || total == 0)
            answer[q.id] = {0, 1};
        else {
            long long divisor = gcd(pairs, total);
            answer[q.id] = {pairs / divisor, total / divisor};
        }
    }
    for (auto [a, b] : answer)
        cout << a << '/' << b << '\n';
    return 0;
}
```

### 复杂度

时间 $O((n+m)\sqrt n+m\log m)$，空间 $O(n+m)$。

### 易错点

加入与删除时修改计数的先后不同，写反会漏或多算一组。分子、分母都要 long long；输出按原查询顺序恢复。
