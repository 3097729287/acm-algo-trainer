## 答题卡

### 题意

统计每行恰有一个黑格、转置后不变的 n 阶零一矩阵。

### 思路

矩阵对称使每列也恰有一个黑格。考察第 n 行：若黑格在对角线 (n,n)，剩下 f[n-1] 种；否则它在第 j 列，对称性强迫 (j,n) 为黑，两行两列都已确定，j 有 n-1 种，剩下 f[n-2] 种。因此 f[n]=f[n-1]+(n-1)f[n-2]，边界 f[0]=f[1]=1。只保存相邻两项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 1000000007;
    int n;
    cin >> n;
    long long previous = 1, current = 1;
    for (int i = 2; i <= n; i++) {
        long long next = (current + (i - 1LL) * previous) % mod;
        previous = current;
        current = next;
    }
    cout << current;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

横竖一致指关于主对角线转置相等，不要求关于水平中线或竖直中线对称。乘法在 long long 中计算后取模。
