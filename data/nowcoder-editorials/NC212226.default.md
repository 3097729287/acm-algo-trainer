## 回文数

### 题意

必须用完给定的各数字次数，构造无前导零的最小回文数。

### 思路

回文两侧成对，最多只有一个数字出现奇数次，它必须居中。若总长大于一，左半边第一位必须取有至少一对的最小非零数字；没有就无解。先消耗这对作为最外侧，再把剩余左半边按零到九递增排列，接上可选中间数及左半边反转。单个零单独允许。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int count[10], length = 0, center = -1, odd = 0;
    for (int i = 0; i < 10; i++) {
        cin >> count[i];
        length += count[i];
        if (count[i] % 2) {
            odd++;
            center = i;
        }
    }
    if (odd > 1) {
        cout << -1;
        return 0;
    }
    if (length == 1) {
        cout << center;
        return 0;
    }
    int first = -1;
    for (int d = 1; d <= 9; d++)
        if (count[d] >= 2) {
            first = d;
            break;
        }
    if (first == -1) {
        cout << -1;
        return 0;
    }
    count[first] -= 2;
    string left(1, char('0' + first));
    for (int d = 0; d <= 9; d++)
        left += string(count[d] / 2, char('0' + d));
    string right = left;
    reverse(right.begin(), right.end());
    cout << left;
    if (center != -1)
        cout << center;
    cout << right;
    return 0;
}
```

### 复杂度

时间与结果空间均为总数字数 $O(L)$。

### 易错点

不能把唯一出现一次的非零数挪到开头，它只能居中。全零的多位数违反无前导零要求。
