## 二叉树

### 题意

检查给定二叉树是否满足左子树≤根≤右子树。

### 思路

允许相等的二叉搜索树，当且仅当中序遍历权值非递减。用显式栈按左、根、右遍历，每次与前一个权值比较；出现下降就不合法。等价性来自中序顺序把整个左子树放在根前、整个右子树放在根后，而不是只比较两个直接儿子。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, root;
        cin >> n >> root;
        vector<unsigned long long> value(n + 1);
        vector<int> left(n + 1), right(n + 1);
        for (int i = 1; i <= n; i++)
            cin >> value[i] >> left[i] >> right[i];
        vector<int> stack;
        int u = root;
        bool ok = true, hasPrevious = false;
        unsigned long long previous = 0;
        while (u || !stack.empty()) {
            while (u) {
                stack.push_back(u);
                u = left[u];
            }
            u = stack.back();
            stack.pop_back();
            if (hasPrevious && value[u] < previous)
                ok = false;
            previous = value[u];
            hasPrevious = true;
            u = right[u];
        }
        cout << (ok ? "yes\n" : "no\n");
    }
    return 0;
}
```

### 复杂度

每棵树时间、空间均 $O(n)$。

### 易错点

相同值允许，比较用<。根编号由输入给出；迭代遍历适用于退化长链。
