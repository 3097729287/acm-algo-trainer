## EXTENDED LIGHTS OUT

### 题意

5×6翻灯，按自身和四邻翻转，求全部按键方案。

### 思路

枚举第一行6个按钮的64种按法。第一行按法确定后，上一行第j灯若仍亮，唯一还可改变它的未来按钮是下一行第j按钮，必须按下；若已灭就不能按。依次强制推出其余四行，最后检查第五行是否全灭，成功即输出。每个按钮按两次抵消，所以只需0/1选择。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    cout << fixed;
    for (int tc = 1; tc <= tests; tc++) {
        int original[5][6];
        for (auto &row : original)
            for (int &x : row)
                cin >> x;
        int answer[5][6] = {};
        for (int mask = 0; mask < 64; mask++) {
            int light[5][6], press[5][6] = {};
            copy(&original[0][0], &original[0][0] + 30, &light[0][0]);
            auto push = [&](int i, int j) {
                press[i][j] = 1;
                const int di[] = {0, 0, 0, -1, 1}, dj[] = {0, -1, 1, 0, 0};
                for (int d = 0; d < 5; d++) {
                    int x = i + di[d], y = j + dj[d];
                    if (x >= 0 && x < 5 && y >= 0 && y < 6)
                        light[x][y] ^= 1;
                }
            };
            for (int j = 0; j < 6; j++)
                if (mask >> j & 1)
                    push(0, j);
            for (int i = 1; i < 5; i++)
                for (int j = 0; j < 6; j++)
                    if (light[i - 1][j])
                        push(i, j);
            bool ok = true;
            for (int j = 0; j < 6; j++)
                if (light[4][j])
                    ok = false;
            if (ok) {
                copy(&press[0][0], &press[0][0] + 30, &answer[0][0]);
                break;
            }
        }
        cout << "PUZZLE #" << tc << '\n';
        for (auto &row : answer)
            for (int j = 0; j < 6; j++)
                cout << row[j] << (j == 5 ? '\n' : ' ');
    }
    return 0;
}
```

### 复杂度

每组时间 $O(2^6\cdot5\cdot6)$，空间 $O(5\cdot6)$。

### 易错点

输出的是按键矩阵，不是最终灯状态。按题目保证可解的固定规格处理。
