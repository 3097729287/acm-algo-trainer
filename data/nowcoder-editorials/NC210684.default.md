## 排列游戏

### 题意

给相邻升降或任意关系，统计合法排列。

### 思路

构造长度i排列，dp[j]表示最后元素在这i个元素中排名j（从0开始）的方案数。加入下一元素，新排名为j时，旧最后元素原排名k在“上升”情形需k<j，在“下降”情形需k≥j；无约束取全部k。用上一行dp前缀和常数时间求三个转移，每层增加一个排名。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    const int mod = 998244353;
    vector<int> dp(1, 1);
    for (char relation : s) {
        int length = dp.size();
        vector<int> prefix(length + 1);
        for (int j = 0; j < length; j++) {
            prefix[j + 1] = prefix[j] + dp[j];
            if (prefix[j + 1] >= mod)
                prefix[j + 1] -= mod;
        }
        vector<int> next(length + 1);
        for (int j = 0; j <= length; j++) {
            if (relation == '1')
                next[j] = prefix[j];
            else if (relation == '2')
                next[j] = (prefix[length] - prefix[j] + mod) % mod;
            else
                next[j] = prefix[length];
        }
        dp.swap(next);
    }
    long long answer = 0;
    for (int x : dp)
        answer = (answer + x) % mod;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，空间 $O(n)$。

### 易错点

插入新元素会让原来≥j的值整体加1，因此下降条件在旧排名里是k≥j。
