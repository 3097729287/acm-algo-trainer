## Let's Play Curling

### 题意

选择任意实数中心，最大化严格比所有蓝石更近的红石数量。

### 思路

能得分的红石必须处于同一段相邻蓝石之间，或最左、最右的外侧区间。因为距中心小于最近蓝石距离的所有位置构成一个不含蓝石的开区间，不可能跨过蓝石。反过来，有限蓝石间隙的中点能让间隙内全部红石得分；外侧间隙也可把中心移得足够远以覆盖所有红石。因此排序后统计每个蓝石间隙内红石的数量，取最大值，坐标等于蓝石的红石永不得分。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n, m;
        cin >> n >> m;
        vector<int> red(n), blue(m);
        for (int &x : red)
            cin >> x;
        for (int &x : blue)
            cin >> x;
        sort(red.begin(), red.end());
        sort(blue.begin(), blue.end());
        vector<int> count(m + 1);
        int p = 0, answer = 0;
        for (int x : red) {
            while (p < m && blue[p] < x)
                p++;
            if (p < m && blue[p] == x)
                continue;
            answer = max(answer, ++count[p]);
        }
        if (answer == 0)
            cout << "Impossible\n";
        else
            cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n+m\log m)$，数组空间 $O(n+m)$。

### 易错点

输出最大得分而不是中心坐标。多个蓝石同坐标不改变间隙，红蓝同坐标时严格不等式永远失败。
