## 丢手绢

### 题意

在边长不等的圆环上选两点，最大化顺、逆时针距离的较小值。

### 思路

设圆周长为 total。两点间顺时针距离为 d 时，实际距离 min(d,total-d) 在 d 接近 total/2 时最大。把环复制一遍，用前缀和得到距离；枚举左端点，让右指针尽量靠近但不超过半周，再检查该点与下一个点。边长都为正，左端前进时最优右端不会后退，因此双指针线性完成。若第一条边就超过半周，也检查它，此时半周之前没有其他不同的点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n), prefix(2 * n + 1);
    for (auto &x : a)
        cin >> x;
    for (int i = 0; i < 2 * n; i++)
        prefix[i + 1] = prefix[i] + a[i % n];
    long long total = prefix[n], answer = 0;
    int right = 1;
    for (int left = 0; left < n; left++) {
        right = max(right, left + 1);
        while (right + 1 < left + n && 2 * (prefix[right + 1] - prefix[left]) <= total)
            right++;
        for (int end = right; end <= right + 1 && end < left + n; end++) {
            long long d = prefix[end] - prefix[left];
            answer = max(answer, min(d, total - d));
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

每组只输入 n 个间隔；题面末行描述仍指第 n 个间隔。只比较直线距离或直接输出半周都会错误。用 long long 避免翻倍溢出。
