## [USACO 2011 Ope S]Learning Languages

### 题意

有共同语言的牛能互相传话，最少买语言书使所有牛连通，并输出具体教书方案。

### 思路

每种语言记一只已经会它的牛，以后遇到也会该语言的牛就将两者合并。得到 c 个牛的连通块后，一本书最多使两个块连起来，因此至少 c−1 本。选牛1已经会的一种语言，给其余每个块的一只代表牛各买一本这种语言的书，恰好 c−1 本便全部连通。每只牛至少会一种语言，故所选公共语言一定存在。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    DSU dsu(n);
    vector<int> owner(m + 1);
    int common = 0;
    for (int cow = 1; cow <= n; cow++) {
        int k;
        cin >> k;
        while (k--) {
            int language;
            cin >> language;
            if (cow == 1 && common == 0)
                common = language;
            if (owner[language])
                dsu.unite(cow, owner[language]);
            else
                owner[language] = cow;
        }
    }
    vector<int> representatives;
    for (int cow = 1; cow <= n; cow++)
        if (dsu.find(cow) == cow && dsu.find(cow) != dsu.find(1))
            representatives.push_back(cow);
    cout << representatives.size() << '\n';
    for (int cow : representatives)
        cout << common << ' ' << cow << '\n';
    return 0;
}
```

### 复杂度

总已知语言条数 $L$，时间 $O((n+L)\alpha(n)+m)$，空间 $O(n+m)$。

### 易错点

未被任何牛使用的语言不构成需要连通的块。输出先是语言编号，再是牛编号；题面样例只给书本数，但完整提交仍要输出方案。
