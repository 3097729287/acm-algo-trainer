## a+b

### 题意

将两个十进制整数的和以小写十六进制输出。

### 思路

先按十进制读取并相加，再用 hex 改变整数的输出进制。cout 默认使用小写十六进制字母，且不输出 0x 前缀。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    cout << hex << a + b;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

进制只改变表示方式，不需要把输入当成十六进制读取。
