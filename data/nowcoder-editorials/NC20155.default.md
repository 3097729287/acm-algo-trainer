## [JSOI2007]文本生成器

### 题意

统计长M大写文本中至少出现一个模式的数量。

### 思路

先数没有任何模式的文本，用26^M减去。AC状态若自身或fail祖先是模式终点则禁用，DP只保留安全状态。朴素逐状态枚举26字符可以正确求解；为兼容M至10000的加强版，下面把每一层转移压到与节点数线性。

设mass[u]为本层DP在fail子树u中的总量，按逆BFS累加得到。先把全部质量乘26放入根作为默认转移。对每条真实Trie边u−c→v，把mass[u]从fallback转移目标移到v：fallback为go(fail[u],c)，根边的fallback为根。对同一个源状态和字符，沿其fail祖先上的这些改道正好依次抵消，只剩最长可用前缀边，所以等价于完整AC转移。最后把所有禁用状态置0。

每层只遍历节点和真实Trie边，既避免漏算重复字母转移，也减少加强版26倍循环。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Aho {
    struct Node {
        array<int, 26> next = {};
        int fail = 0, parent = 0, letter = 0, longest = 0;
    };
    vector<Node> node;
    vector<int> order;
    int alphabet;
    char base;
    Aho(int alphabet, char base, size_t capacity) : alphabet(alphabet), base(base) {
        node.reserve(capacity);
        node.emplace_back();
    }
    int insert(const string &s) {
        int u = 0;
        for (char ch : s) {
            int c = ch - base;
            if (!node[u].next[c]) {
                int v = node.size();
                node[u].next[c] = v;
                node.emplace_back();
                node[v].parent = u;
                node[v].letter = c;
            }
            u = node[u].next[c];
        }
        node[u].longest = max(node[u].longest, (int)s.size());
        return u;
    }
    void build() {
        order = {0};
        for (int c = 0; c < alphabet; c++)
            if (node[0].next[c])
                order.push_back(node[0].next[c]);
        for (size_t i = 1; i < order.size(); i++) {
            int u = order[i], f = node[u].fail;
            node[u].longest = max(node[u].longest, node[f].longest);
            for (int c = 0; c < alphabet; c++) {
                int v = node[u].next[c];
                if (v) {
                    node[v].fail = node[f].next[c];
                    order.push_back(v);
                } else
                    node[u].next[c] = node[f].next[c];
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> pattern(n);
    size_t total = 1;
    for (auto &s : pattern) {
        cin >> s;
        total += s.size();
    }
    Aho ac(26, 'A', total);
    for (auto &s : pattern)
        ac.insert(s);
    ac.build();
    const int mod = 10007;
    int size = ac.node.size();
    vector<int> dp(size), mass(size), next(size);
    dp[0] = 1;
    int all = 1;
    for (int step = 0; step < m; step++) {
        all = all * 26 % mod;
        mass = dp;
        for (int i = (int)ac.order.size() - 1; i > 0; i--) {
            int u = ac.order[i], f = ac.node[u].fail;
            mass[f] = (mass[f] + mass[u]) % mod;
        }
        fill(next.begin(), next.end(), 0);
        next[0] = 26 * mass[0] % mod;
        for (int v = 1; v < size; v++) {
            int u = ac.node[v].parent, c = ac.node[v].letter,
                fallback = u ? ac.node[ac.node[u].fail].next[c] : 0;
            next[v] = (next[v] + mass[u]) % mod;
            next[fallback] = (next[fallback] - mass[u] + mod) % mod;
        }
        for (int u = 0; u < size; u++)
            dp[u] = ac.node[u].longest ? 0 : next[u];
    }
    int safe = 0;
    for (int x : dp)
        safe = (safe + x) % mod;
    cout << (all - safe + mod) % mod;
    return 0;
}
```

### 复杂度

模式总长L，时间 $O(26L+ML)$，空间 $O(26L)$。

### 易错点

要把fail链上的模式终点也视为禁用。重定向只遍历原始Trie边，不能把补全的自动机边都当真实边。
