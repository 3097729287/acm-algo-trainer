## [JSOI2011]分特产

### 题意

多种同类物品不可区分，分给n名有区别同学，人人至少一个。

### 思路

先允许空手。若只给s名指定同学，第j种a[j]件的非负分配数由隔板法得到C(a[j]+s−1,s−1)，不同种相乘。容斥选择k名空手者：答案Σ(-1)^k*C(n,k)*ΠC(a[j]+n−k−1,n−k−1)。对s≥1枚举，s=0仅当所有物品总数为0时有1种；n≥1且物品全0直接答案0。预处理不超过1999的阶乘、逆阶乘。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000007;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> amount(m);
    long long total = 0;
    int maximum = 0;
    for (int &a : amount) {
        cin >> a;
        total += a;
        maximum = max(maximum, a);
    }
    if (!total) {
        cout << 0;
        return 0;
    }
    int limit = n + maximum;
    vector<long long> factorial(limit + 1, 1), inverse(limit + 1);
    for (int i = 1; i <= limit; i++)
        factorial[i] = factorial[i - 1] * i % mod;
    inverse[limit] = power(factorial[limit], mod - 2);
    for (int i = limit; i >= 1; i--)
        inverse[i - 1] = inverse[i] * i % mod;
    auto choose = [&](int a, int b) {
        return factorial[a] * inverse[b] % mod * inverse[a - b] % mod;
    };
    long long answer = 0;
    for (int empty = 0; empty < n; empty++) {
        int students = n - empty;
        long long ways = choose(n, empty);
        for (int a : amount)
            ways = ways * choose(a + students - 1, students - 1) % mod;
        answer = (answer + (empty % 2 ? mod - ways : ways)) % mod;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(nm+n+\max a+\log P)$，空间 $O(n+m+\max a)$。

### 易错点

同类特产不可区分，不应给每件物品贴编号。容斥选的是同学集合，必须乘C(n,k)。
