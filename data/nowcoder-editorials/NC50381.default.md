## 道路和航线

### 题意

非负双向道路与可为负的单向航线，航线不会处于回路中，求从S到各点最短费用。

### 思路

先只按道路划分连通块。任何航线都连两个不同道路块，否则道路可从终点回起点，违反保证；所有块之间的航线组成DAG。按块拓扑处理：一个块所有入航线已处理后，将块内所有已有有限距离的点一起放入堆，在仅道路的块内跑多源Dijkstra。道路非负，因此这一阶段正确。

块内距离确定后，再逐条松弛出航线，允许负费用，并减少目标块入度；入度归零的块入队。不可达块也要完成拓扑出边计数，否则会卡住后继。这样负边只在DAG层传播，不会进入Dijkstra堆。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, r, p, start;
    cin >> n >> r >> p >> start;
    --start;
    vector<vector<pair<int, long long>>> road(n);
    DSU dsu(n);
    while (r--) {
        int a, b;
        long long w;
        cin >> a >> b >> w;
        --a;
        --b;
        road[a].push_back({b, w});
        road[b].push_back({a, w});
        dsu.unite(a, b);
    }
    vector<vector<int>> members(n);
    for (int u = 0; u < n; u++)
        members[dsu.find(u)].push_back(u);
    struct Flight {
        int from, to;
        long long cost;
    };
    vector<vector<Flight>> flight(n);
    vector<int> degree(n);
    while (p--) {
        int a, b;
        long long w;
        cin >> a >> b >> w;
        --a;
        --b;
        flight[dsu.find(a)].push_back({a, b, w});
        degree[dsu.find(b)]++;
    }
    const long long inf = 1LL << 60;
    vector<long long> distance(n, inf);
    distance[start] = 0;
    vector<int> queue;
    for (int c = 0; c < n; c++)
        if (!members[c].empty() && !degree[c])
            queue.push_back(c);
    for (size_t h = 0; h < queue.size(); h++) {
        int component = queue[h];
        priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                       greater<pair<long long, int>>>
            heap;
        for (int u : members[component])
            if (distance[u] != inf)
                heap.push({distance[u], u});
        while (!heap.empty()) {
            auto [cost, u] = heap.top();
            heap.pop();
            if (cost != distance[u])
                continue;
            for (auto [v, w] : road[u])
                if (distance[v] > cost + w) {
                    distance[v] = cost + w;
                    heap.push({distance[v], v});
                }
        }
        for (auto e : flight[component]) {
            if (distance[e.from] != inf)
                distance[e.to] = min(distance[e.to], distance[e.from] + e.cost);
            int target = dsu.find(e.to);
            if (--degree[target] == 0)
                queue.push_back(target);
        }
    }
    for (long long d : distance) {
        if (d == inf)
            cout << "NO PATH\n";
        else
            cout << d << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O((N+R)\log N+P+(N+R)\alpha(N))$，空间 $O(N+R+P)$。

### 易错点

有负航线，不能对整图直接Dijkstra。块内起点可能不止一个，且带着不同的已有费用，必须全部入堆。
