## D 博弈与核心能源动力

### 题意

可以用钱买酒、两空瓶换酒或四瓶盖换酒，求最多能喝的总数。

### 思路

先用非负可用现金买尽可能多的酒，喝完得到对应空瓶和瓶盖。之后只要能兑换，就同时把全部可用空瓶和瓶盖换成新酒，喝完再加入新产生的两种资源，直到都不够兑换。每换一瓶，两倍空瓶数加瓶盖数恰好减少一，所以不会无限兑换。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long m, bottles, caps, price;
    cin >> m >> bottles >> caps >> price;
    long long ans = max(0LL, m / price);
    bottles += ans;
    caps += ans;
    while (bottles >= 2 || caps >= 4) {
        long long next = bottles / 2 + caps / 4;
        bottles = bottles % 2 + next;
        caps = caps % 4 + next;
        ans += next;
    }
    cout << ans;
    return 0;
}
```

### 复杂度

按批量兑换，资源规模每轮按比例下降，时间为初始资源规模的对数级，额外空间 $O(1)$。

### 易错点

负债时只能兑换现有空瓶和瓶盖，不能用负的买酒数量扣掉资源。兑换后喝完还会产生新空瓶、新瓶盖。
