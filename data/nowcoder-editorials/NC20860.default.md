## 兔子的区间密码

### 题意

从同一闭区间中选两整数，使它们的异或最大。

### 思路

若 l=r，只能得到零。否则令 k 为 l 与 r 最高的不同位：所有区间数在更高位都相同，所以异或不超过低 k+1 位全一。去掉公共前缀，区间跨过第 k 位的零一边界；边界前一个数是 0 后接 k 个一，边界数是 1 后接 k 个零，两者都在区间中，异或达到 2^(k+1)-1。计算 l^r 的位数后输出同位数全一即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        unsigned long long l, r;
        cin >> l >> r;
        auto different = l ^ r;
        unsigned long long answer = 0;
        while (different) {
            answer = answer * 2 + 1;
            different >>= 1;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log r)$，额外空间 $O(1)$。

### 易错点

可以选相同的两个数，单点区间答案为零。这里输出最大异或值，不需要输出选中的两个整数。
