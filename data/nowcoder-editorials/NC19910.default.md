## [CQOI2007]矩形RECT

### 题意

沿格线把矩形分成两个均连通、均接触原边界的非空部分，求不区分两部分的方案数。

### 思路

两部分都连通且都碰外边界时，它们之间的分界线必须是一条从外边界到外边界、不自交的简单格线路径。闭环会把一块包在内部；多条分界弧会让某一块分裂。因此可枚举这条线：两个端点在边界非角点，中间仅经过内部格点，每个内部格点至多一次。每条这样的弧恰好分出两块合法区域。

把内部格点建四邻接图。boundary[u]记录它有几个外边界邻点，作为进入或离开端点的选择数。枚举起始内部点，DFS不重复内部点，随时按boundary[当前]计结束方案。起点未走时要排除“从同一端点进出”，贡献为b*(b−1)。最终除二去掉路径的两个方向。左右、上下反射对称的起点只算一个，再乘轨道大小，减少重复搜索。若一边宽度为1，只有逐条直线切割，答案a*b−1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    if (a == 1 || b == 1) {
        cout << a * b - 1;
        return 0;
    }
    int rows = a - 1, cols = b - 1, n = rows * cols;
    vector<unsigned long long> adjacent(n);
    vector<int> boundary(n);
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++) {
            int u = r * cols + c;
            boundary[u] = (r == 0) + (r + 1 == rows) + (c == 0) + (c + 1 == cols);
            if (r)
                adjacent[u] |= 1ULL << (u - cols);
            if (r + 1 < rows)
                adjacent[u] |= 1ULL << (u + cols);
            if (c)
                adjacent[u] |= 1ULL << (u - 1);
            if (c + 1 < cols)
                adjacent[u] |= 1ULL << (u + 1);
        }
    auto dfs = [&](auto &&self, int u, unsigned long long used) -> long long {
        long long count = boundary[u];
        unsigned long long next = adjacent[u] & ~used;
        while (next) {
            int v = __builtin_ctzll(next);
            next &= next - 1;
            count += self(self, v, used | (1ULL << v));
        }
        return count;
    };
    long long oriented = 0;
    for (int r = 0; r <= (rows - 1) / 2; r++)
        for (int c = 0; c <= (cols - 1) / 2; c++) {
            int u = r * cols + c;
            if (!boundary[u])
                continue;
            int symmetry = (r == rows - 1 - r ? 1 : 2) * (c == cols - 1 - c ? 1 : 2);
            oriented += symmetry * boundary[u] * (dfs(dfs, u, 1ULL << u) - 1);
        }
    cout << oriented / 2;
    return 0;
}
```

### 复杂度

内部格点数 $V=(a-1)(b-1)\le30$，时间为简单路径枚举的指数级，可界为 $O(V3^V)$，栈及图空间 $O(V)$。

### 易错点

枚举的是格线交点，不是单元格染色。边界只能作为首尾，不能沿外边界继续走；路径方向不构成不同划分。
