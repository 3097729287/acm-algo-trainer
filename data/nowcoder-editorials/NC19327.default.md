## 好朋友

### 题意

统计十进制表示中含子序列007的数，多个区间答案异或。

### 思路

状态0、1、2、3表示已经依次匹配007的长度，3为吸收态。当前数码等于下一个所需字符时匹配长度加1，不相等则保持。还需started区分前导0，未开始的0不能用于匹配。按剩余位数、匹配状态、started缓存自由状态，十万组询问共用；每问两个前缀差，异或进最终结果。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long memo[20][4][2];
    memset(memo, -1, sizeof(memo));
    auto count = [&](long long bound) {
        if (bound < 0)
            return 0LL;
        string s = to_string(bound), pattern = "007";
        auto dfs = [&](auto &&self, int p, int state, bool started, bool tight) -> long long {
            if (p == (int)s.size())
                return state == 3;
            long long &cache = memo[s.size() - p][state][started];
            if (!tight && cache != -1)
                return cache;
            int maximum = tight ? s[p] - '0' : 9;
            long long result = 0;
            for (int d = 0; d <= maximum; d++) {
                bool begun = started || d;
                int next = state;
                if (begun && next < 3 && d == pattern[next] - '0')
                    next++;
                result += self(self, p + 1, next, begun, tight && d == maximum);
            }
            if (!tight)
                cache = result;
            return result;
        };
        return dfs(dfs, 0, 0, false, true);
    };
    int tests;
    cin >> tests;
    long long answer = 0;
    while (tests--) {
        long long l, r;
        cin >> l >> r;
        answer ^= count(r) - count(l - 1);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

预处理自由状态 $O(D\cdot8\cdot10)$，每次边界 $O(10D)$，总 $O(TD)$，空间 $O(8D)$。

### 易错点

007是子序列，可以不连续；前导0不属于名字。匹配成功后不可被后续数码取消。
