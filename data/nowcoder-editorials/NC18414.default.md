## 绩点

### 题意

用各科绩点和学分计算总绩点，保留一位小数。

### 思路

分子累加每科绩点乘学分，分母累加学分。全部读完后一次相除并四舍五入输出，避免对每科先舍入带来误差。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    double sum = 0, credits = 0;
    for (int i = 0; i < n; i++) {
        double g, s;
        cin >> g >> s;
        sum += g * s;
        credits += s;
    }
    cout << fixed << setprecision(1) << sum / credits;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

不同课程的学分不同，不能直接对绩点做普通平均。
