## 活动安排

### 题意

安排所有活动，最小化最大超时扣分。

### 思路

按截止时间从早到晚做。若相邻两活动先做截止晚的 B、再做截止早的 A，交换它们后，A 更早完成，B 的新完成时间等于原 A 的完成时间，而 B 的截止时间更晚，因此这两项的最大超时不会增加。不断消除逆序即得到截止时间顺序。累加用时，记录 max(0,完成时刻-截止时间)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<long long, long long>> tasks(n);
    for (auto &[deadline, cost] : tasks)
        cin >> cost >> deadline;
    sort(tasks.begin(), tasks.end());
    long long time = 0, answer = 0;
    for (auto [deadline, cost] : tasks) {
        time += cost;
        answer = max(answer, time - deadline);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

目标是最大扣分最小，不是总扣分最小，也不是按活动耗时排序。完成时刻与截止时刻相等不扣分。
