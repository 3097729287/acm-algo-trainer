## Sum of gcd of Tuples (Hard)

### 题意

求全部n元组的gcd之和，元素范围1..k。

### 思路

利用恒等式g=Σ(d|g)phi(d)，把每个元组gcd展开成约数和，交换求和顺序。能让全部元素被d整除的元组共有floor(k/d)^n个，故答案Σ(d=1..k)phi(d)*floor(k/d)^n。筛出phi，用快速幂求每项。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    const long long mod = 1000000007;
    vector<int> phi(k + 1);
    iota(phi.begin(), phi.end(), 0);
    for (int p = 2; p <= k; p++)
        if (phi[p] == p)
            for (int x = p; x <= k; x += p)
                phi[x] = phi[x] / p * (p - 1);
    long long answer = 0;
    for (int d = 1; d <= k; d++) {
        long long base = k / d, value = 1;
        int exponent = n;
        while (exponent) {
            if (exponent & 1)
                value = value * base % mod;
            base = base * base % mod;
            exponent >>= 1;
        }
        answer = (answer + phi[d] * value) % mod;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(k(\log\log k+\log n))$，空间 $O(k)$。

### 易错点

元组有顺序，允许重复，因此数量是幂，不是组合数。
