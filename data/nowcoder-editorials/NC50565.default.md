## 同余方程

### 题意

保证有解，求a*x模b等于1的最小正整数x。

### 思路

扩展欧几里得求a*x+b*y=gcd(a,b)。题目保证逆元存在，即gcd为1，所以所得x就是一组解；全部解相差b的整数倍，归一化到[0,b)后就是最小正解。b≥2且互质，结果不会为0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long extendedGcd(long long a, long long b, long long &x, long long &y) {
    if (!b) {
        x = 1;
        y = 0;
        return a;
    }
    long long previousX, previousY;
    long long g = extendedGcd(b, a % b, previousX, previousY);
    x = previousY;
    y = previousX - (a / b) * previousY;
    return g;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long a, b, x, y;
    cin >> a >> b;
    extendedGcd(a, b, x, y);
    cout << (x % b + b) % b;
    return 0;
}
```

### 复杂度

时间 $O(\log\min(a,b))$，递归栈空间同阶。

### 易错点

系数可以为负，要归一化两次取模。参数至二十亿，系数更新使用64位。
