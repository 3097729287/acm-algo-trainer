## 【模板】牛牛学除法

### 题意

输出两个正整数相除得到的整数商。

### 思路

两个 int 之间的除法丢弃小数部分；输入均为正数，所以这就是向下取整的商。直接输出 a/b。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    cout << a / b << '\n';
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

本题要商，不是余数，也不是浮点除法。
