## Magic Rabbit

### 题意

三瓶浓度按非负比例混合，查询能否得到目标两维浓度。

### 思路

混合浓度是三个浓度点按体积比例的凸组合，因此目标能配出当且仅当在三点凸包中。非共线时用三条边叉积同号或0判断三角形内部含边界；共线时凸包为线段，检查点是否在任意一对端点的闭线段上，也支持三瓶完全相同。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    array<Point, 3> a;
    for (auto &p : a)
        cin >> p.x >> p.y;
    long double area = cross(a[1] - a[0], a[2] - a[0]);
    int n;
    cin >> n;
    while (n--) {
        Point p;
        cin >> p.x >> p.y;
        bool ok = false;
        if (area == 0) {
            for (int i = 0; i < 3; i++) {
                Point x = a[i], y = a[(i + 1) % 3];
                if (cross(y - x, p - x) == 0 && dot(p - x, p - y) <= 0)
                    ok = true;
            }
        } else {
            long double x = cross(a[1] - a[0], p - a[0]), y = cross(a[2] - a[1], p - a[1]),
                        z = cross(a[0] - a[2], p - a[2]);
            ok = (x >= 0 && y >= 0 && z >= 0) || (x <= 0 && y <= 0 && z <= 0);
        }
        cout << (ok ? "YES\n" : "NO\n");
    }
    return 0;
}
```

### 复杂度

每问时间 $O(1)$，空间 $O(1)$。

### 易错点

可以不使用某瓶，故边界可行。不能随意加入纯水；只有给定三瓶的凸组合可用。
