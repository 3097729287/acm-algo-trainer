## [NOIP2006]明明的随机数

> 原题：[P1059](https://www.luogu.com.cn/problem/P1059)
> 解法：布尔桶去重并升序扫描 · C++17

### 题意

对一到一千范围内的随机数去重，并按升序输出不同数字。



### 思路

输入二十、四十、二十时，第二次看到二十只会把同一个桶再次设为 true，仍只保留一个二十。桶的下标直接等于数字值，按下标升序扫描就自然得到排序结果。先统计 true 桶数量作为第一行，再按同一顺序输出各个值。这里适用桶，是因为值域只有一千；数值到十的九次方时不能照搬同等大的数组。

值域为 V，时间 $O(n+V)$、空间 $O(V)$，本题 V=1000。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    bool present[1001] = {};
    while (n--) {
        int x;
        cin >> x;
        present[x] = true;
    }
    int count = 0;
    for (int x = 1; x <= 1000; x++)
        count += present[x];
    cout << count << '\n';
    bool first = true;
    for (int x = 1; x <= 1000; x++)
        if (present[x]) {
            if (!first)
                cout << ' ';
            cout << x;
            first = false;
        }
    cout << '\n';
    return 0;
}
```

### 易错点

只保留是否出现，不保存重复次数；使用题目给定的小值域。
