## [USACO 2015 Jan G]Moovie Mooving

### 题意

每部电影至多选一个场次，可中途进入退出，连续覆盖时间0到L，最少看几部。

### 思路

dp[mask]表示使用这些不同电影后，能从0连续覆盖到的最晚时刻，初始dp[0]=0，其余不可达。加入未选电影i时，在它的场次中二分找不晚于当前结束时刻的最晚开场；它结束也最晚。若该场仍在放映，就能接上，结束时刻扩展到开场+片长。

同一电影集合只保留最远结束是充分的：既然已经覆盖到更远处，任何能从较早结束继续并向外延伸的下一场，要么也能从更远处接上，要么早已落在已覆盖区间内，后者无助于继续向外覆盖。枚举所有达到L的mask，取置一位数最小。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, target;
    cin >> n >> target;
    vector<int> duration(n);
    vector<vector<int>> show(n);
    for (int i = 0; i < n; i++) {
        int count;
        cin >> duration[i] >> count;
        show[i].resize(count);
        for (int &x : show[i])
            cin >> x;
    }
    vector<int> dp(1 << n, -1);
    dp[0] = 0;
    int answer = n + 1;
    for (int mask = 0; mask < (1 << n); mask++)
        if (dp[mask] != -1) {
            int used = __builtin_popcount((unsigned)mask);
            if (dp[mask] >= target) {
                answer = min(answer, used);
                continue;
            }
            if (used >= answer)
                continue;
            for (int i = 0; i < n; i++)
                if (!(mask >> i & 1)) {
                    auto it = upper_bound(show[i].begin(), show[i].end(), dp[mask]);
                    if (it == show[i].begin())
                        continue;
                    int end = *prev(it) + duration[i];
                    if (end > dp[mask])
                        dp[mask | (1 << i)] = max(dp[mask | (1 << i)], end);
                }
        }
    cout << (answer == n + 1 ? -1 : answer);
    return 0;
}
```

### 复杂度

每电影最多 $C$ 场，时间 $O(n2^n\log C)$，空间 $O(2^n+\sum C_i)$。

### 易错点

必须从0开始无空档观看。可进入已经放映的场次，不要求开场恰好等于上一部结束时间；同一电影不能换场次重复使用。
