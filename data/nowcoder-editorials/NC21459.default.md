## 总成绩和平均分计算

### 题意

输出三个成绩的总分和平均分，两项均保留两位小数。

### 思路

成绩可能本来就带小数，使用 double 保存。总分是三项之和，平均分是总分除以三，再设置 fixed 和 setprecision(2)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    double a, b, c;
    cin >> a >> b >> c;
    double sum = a + b + c;
    cout << fixed << setprecision(2) << sum << ' ' << sum / 3;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

总分也需要两位小数，两个输出之间有一个空格。
