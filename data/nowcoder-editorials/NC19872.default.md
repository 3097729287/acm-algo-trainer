## [AHOI2005]SHUFFLE 洗牌

### 题意

偶数张牌进行M次交错洗牌，求最终第L张的原编号。

### 思路

原位置i在前半叠时进入2i，后半叠时进入2i−N−1，统一为2i mod(N+1)。因此M次后原位置乘2^M。题目反查最终位置L的来源，应乘逆置换：N+1为奇数，2的逆元是(N+2)/2。答案L*((N+2)/2)^M mod(N+1)。N+1未必为素数，这个显式逆元仍成立。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, m, l;
    cin >> n >> m >> l;
    long long mod = n + 1, base = (n + 2) / 2, inversePower = 1;
    while (m) {
        if (m & 1)
            inversePower = (__int128)inversePower * base % mod;
        base = (__int128)base * base % mod;
        m >>= 1;
    }
    cout << (long long)((__int128)l * inversePower % mod);
    return 0;
}
```

### 复杂度

时间 $O(\log(M+1))$，空间 $O(1)$。

### 易错点

问的是最终位置的牌面，方向要取逆。乘积可达10^20，使用128位中间乘法。M=0自然输出L。
