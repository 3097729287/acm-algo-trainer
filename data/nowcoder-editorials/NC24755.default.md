## [USACO 2010 Dec S]Apple Delivery

### 题意

从PB出发，把苹果送到PA1、PA2，先后任选，不需回起点。

### 思路

仅两种顺序：PB→PA1→PA2，或PB→PA2→PA1。图无向，两目标间距离共用，答案为dist(PA1,PA2)+min(dist(PB,PA1),dist(PB,PA2))。分别从两个目标做Dijkstra即可取得这三个距离。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<long long> dijkstra(const vector<vector<pair<int, long long>>> &graph, int source) {
    const long long inf = 1LL << 60;
    vector<long long> distance(graph.size(), inf);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                   greater<pair<long long, int>>>
        heap;
    distance[source] = 0;
    heap.push({0, source});
    while (!heap.empty()) {
        auto [cost, u] = heap.top();
        heap.pop();
        if (cost != distance[u])
            continue;
        for (auto [v, w] : graph[u])
            if (distance[v] > cost + w) {
                distance[v] = cost + w;
                heap.push({distance[v], v});
            }
    }
    return distance;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, n, start, a, b;
    cin >> m >> n >> start >> a >> b;
    --start;
    --a;
    --b;
    vector<vector<pair<int, long long>>> graph(n);
    while (m--) {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        --u;
        --v;
        graph[u].push_back({v, w});
        graph[v].push_back({u, w});
    }
    auto da = dijkstra(graph, a), db = dijkstra(graph, b);
    cout << da[b] + min(da[start], db[start]);
    return 0;
}
```

### 复杂度

时间 $O((P+C)\log P)$，空间 $O(P+C)$。

### 易错点

首行先给道路数C，再给草地数P。距离和保证输入边总长不超过二十亿，但组合运算仍使用64位。
