## A Chess Game

### 题意

DAG上若干棋子独立移动，判断先手。

### 思路

单棋子在u的SG值为所有后继SG的mex，终点为0。题目保证边指向更大编号，按编号倒序计算即可。多个棋子是独立游戏和，SG异或非0时先手赢。重复棋子也逐个异或，相同状态两枚会抵消。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> edge(n);
    for (auto &row : edge) {
        int k;
        cin >> k;
        row.resize(k);
        for (int &v : row)
            cin >> v;
    }
    vector<int> sg(n);
    for (int u = n - 1; u >= 0; u--) {
        vector<bool> seen(edge[u].size() + 1);
        for (int v : edge[u])
            if (sg[v] < (int)seen.size())
                seen[sg[v]] = true;
        while (sg[u] < (int)seen.size() && seen[sg[u]])
            sg[u]++;
    }
    int m;
    while (cin >> m && m) {
        int total = 0;
        while (m--) {
            int u;
            cin >> u;
            total ^= sg[u];
        }
        cout << (total ? "WIN\n" : "LOSE\n");
    }
    return 0;
}
```

### 复杂度

预处理 $O(n+E)$，每问 $O(m)$，空间 $O(n+E)$。

### 易错点

输出说明一处误写LOST，样例与来源使用LOSE，代码采用LOSE。mex只需标记到出度，因为mex不会超过可达状态数。
