## 队列Q

### 题意

把任意指定元素移到队首或队尾，最终输出排列。

### 思路

用双向链表存队列，另按元素值保存它的迭代器。每次操作借助 list::splice，把指定结点直接挪到表头或表尾，结点迭代器保持有效，不用重新搜索或移动中间元素。最后顺序遍历链表。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    list<int> queue;
    vector<list<int>::iterator> location(n + 1);
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        queue.push_back(x);
        location[x] = prev(queue.end());
    }
    int p;
    cin >> p;
    while (p--) {
        string op;
        int x;
        cin >> op >> x;
        if (op == "FIRST")
            queue.splice(queue.begin(), queue, location[x]);
        else
            queue.splice(queue.end(), queue, location[x]);
    }
    bool first = true;
    for (int x : queue) {
        if (!first)
            cout << ' ';
        first = false;
        cout << x;
    }
    return 0;
}
```

### 复杂度

时间 $O(n+p)$，空间 $O(n)$。

### 易错点

每个编号只出现一次，移动时应挪动已有结点。单纯在 vector 中查找、擦除会退化为每次线性。
