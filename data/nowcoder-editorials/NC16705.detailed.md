## 级数求和

> 原题：[P1035](https://www.luogu.com.cn/problem/P1035)
> 解法：逐项累加到首次越界 · C++17

### 题意

求最小的 $n$，使调和和 $1+1/2+\cdots+1/n$ 严格大于给定 $k$。



### 思路

$k=1$ 时，加入第一项后和等于一，还没有严格超过；加入二分之一后得到一点五，所以答案为二。用 $n$ 记录已经加入几项，sum 记录这些项的和，初始 $n=0$、sum=0。

每项都是正数，逐项加入使 sum 严格增加。循环只在 $sum \le k$ 时继续，结束时刚刚第一次超过 $k$；前一个项数未达标，所以当前 $n$ 就是最小答案。`1.0/n` 使用实数除法，不能写成整数除法 `1/n`，否则从第二项起都被截成零。

若答案为 $n$，时间 $O(n)$、额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int k;
    cin >> k;
    int n = 0;
    double sum = 0;
    while (sum <= k) {
        ++n;
        sum += 1.0 / n;
    }
    cout << n << '\n';
    return 0;
}
```

### 易错点

条件是严格大于 $k$，等于时必须继续；先增加 $n$，再计算新项。
