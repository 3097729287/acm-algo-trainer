## X-factor Chains

### 题意

从1经严格整除链到x，求最多步数与最长链数量。

### 思路

每一步的倍数至少是一个素数，因此最多步数等于x质因子指数总和M，且每步恰乘一个素因子即可达到。最长链与这些质因子的排列一一对应，数量为M!/Πe[p]!。预处理百万内最小质因子，让每组快速分解。M≤19，阶乘用64位精确计算。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int limit = 1000000;
    vector<int> smallest(limit + 1);
    for (int p = 2; p <= limit; p++)
        if (!smallest[p])
            for (int x = p; x <= limit; x += p)
                if (!smallest[x])
                    smallest[x] = p;
    unsigned long long factorial[21];
    factorial[0] = 1;
    for (int i = 1; i <= 20; i++)
        factorial[i] = factorial[i - 1] * i;
    int tests;
    cin >> tests;
    while (tests--) {
        int x, total = 0;
        cin >> x;
        vector<int> exponent;
        while (x > 1) {
            int p = smallest[x], count = 0;
            do {
                x /= p;
                count++;
            } while (x > 1 && x % p == 0);
            exponent.push_back(count);
            total += count;
        }
        unsigned long long ways = factorial[total];
        for (int e : exponent)
            ways /= factorial[e];
        cout << total << ' ' << ways << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(U\log\log U)$，每组 $O(\log x)$，空间 $O(U)$。

### 易错点

输出m是跳跃步数，链含m+1个数。相同素因子的交换不会产生新链。
