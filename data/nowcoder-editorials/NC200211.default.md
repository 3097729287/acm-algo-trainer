## 装备合成

### 题意

两种配方分别消耗 (2,3) 与 (4,1) 件材料，最大化装备数量。

### 思路

假设共做 z 件，其中 q 件使用第二种配方，则材料用量为 2z+2q 与 3z-2q。因此 q 至少为 max(0,ceil((3z-y)/2))，至多为 min(z,floor((x-2z)/2))。先确保 x>=2z，再比较整数上下界是否相交即可判定。能做 z 件就能少做，二分最大 z，上界 min(x/2,y)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        long long x, y;
        cin >> x >> y;
        auto possible = [&](long long count) {
            if (2 * count > x)
                return false;
            long long lower = max(0LL, (3 * count - y + 1) / 2),
                      upper = min(count, (x - 2 * count) / 2);
            return lower <= upper;
        };
        long long low = 0, high = min(x / 2, y);
        while (low < high) {
            long long mid = low + (high - low + 1) / 2;
            if (possible(mid))
                low = mid;
            else
                high = mid - 1;
        }
        cout << low << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log\min(x,y))$，额外空间 $O(1)$。

### 易错点

不能只看材料总数除五，配方需要满足两种材料各自的整数约束。例如 x=3、y=2 虽合计五件，却一件装备也做不了。
