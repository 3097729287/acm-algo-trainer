## ranko的手表

### 题意

两次手表显示可能含问号，且同一天内第一次严格早于第二次，求间隔最小、最大值。

### 思路

一天只有一千四百四十分钟，按时间递增枚举。用格式 HH:MM 检查是否匹配两种显示。当前分钟若匹配第二次显示，就和之前最晚的合法第一次时间求最小差，和之前最早的合法第一次时间求最大差。处理完第二次匹配后，才把当前分钟作为第一次的候选加入，保证两次不能相等。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string first, second;
    cin >> first >> second;
    auto match = [](const string &pattern, int minute) {
        string s = "00:00";
        int h = minute / 60, m = minute % 60;
        s[0] += h / 10;
        s[1] += h % 10;
        s[3] += m / 10;
        s[4] += m % 10;
        for (int i = 0; i < 5; i++)
            if (pattern[i] != '?' && pattern[i] != s[i])
                return false;
        return true;
    };
    int earliest = -1, latest = -1, minimum = INT_MAX, maximum = 0;
    for (int t = 0; t < 1440; t++) {
        if (match(second, t) && earliest != -1) {
            minimum = min(minimum, t - latest);
            maximum = max(maximum, t - earliest);
        }
        if (match(first, t)) {
            if (earliest == -1)
                earliest = t;
            latest = t;
        }
    }
    cout << minimum << ' ' << maximum;
    return 0;
}
```

### 复杂度

时间 $O(1440)$，额外空间 $O(1)$。

### 易错点

不能允许跨午夜，也不能只单独取两次时间的最早、最晚值而忘记严格先后条件。
