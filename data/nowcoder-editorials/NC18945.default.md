## 纸牌

### 题意

两张初始均为 n 的牌，交替操作三次，减数不能大于另一张，求最后总和最小值。

### 思路

设第一次后操作牌剩 x，则第二张最少剩 n-x。第三次结束时，总和至少为 max(x,n-x)，最小值是 n 的一半向上取整。取 x=floor(n/2)，第二次把另一张减到 n-x，第三次清空第一张即可达到。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    cout << (n + 1) / 2;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

第一次直接减到零会使第二次无法减少另一张牌，并非最优。每次可减零。
