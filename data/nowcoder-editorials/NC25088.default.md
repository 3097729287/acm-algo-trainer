## Corn Fields

### 题意

只能在肥沃格种玉米，上下左右不能相邻，统计方案模一亿，空方案也算。

### 思路

一行用mask表示，合法mask不能有相邻1，还必须是本行肥沃位集的子集。上下行a、b只需a&b=0，因为斜对角不相邻。dp[当前mask]累加所有相容前行状态。初始空行方案1，处理完所有行后对末行全部状态求和，包含所有行都空的方案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols;
    while (cin >> rows >> cols) {
        vector<int> fertile(rows);
        for (int r = 0; r < rows; r++)
            for (int c = 0; c < cols; c++) {
                int x;
                cin >> x;
                if (x)
                    fertile[r] |= 1 << c;
            }
        vector<int> masks;
        for (int mask = 0; mask < (1 << cols); mask++)
            if (!(mask & (mask << 1)))
                masks.push_back(mask);
        int states = masks.size();
        const int mod = 100000000;
        vector<int> dp(states);
        dp[0] = 1;
        for (int r = 0; r < rows; r++) {
            vector<int> next(states);
            for (int a = 0; a < states; a++)
                if ((masks[a] & fertile[r]) == masks[a])
                    for (int b = 0; b < states; b++)
                        if (!(masks[a] & masks[b])) {
                            next[a] += dp[b];
                            if (next[a] >= mod)
                                next[a] -= mod;
                        }
            dp.swap(next);
        }
        int answer = 0;
        for (int x : dp) {
            answer += x;
            if (answer >= mod)
                answer -= mod;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

合法行状态数 $S\le377$，时间 $O(MS^2+2^N)$，空间 $O(S+M)$。

### 易错点

只有四方向限制，斜邻可以同时放。模数是100000000，不是十亿加七。
