## 斐波那契

### 题意

n至10^18，求前n项斐波那契平方和模十亿加七。

### 思路

由F[i+1]−F[i−1]=F[i]，有F[i]²=F[i]F[i+1]−F[i−1]F[i]，相加后中间项抵消，平方和恰为F[n]F[n+1]。快速倍增同时求(F[k],F[k+1])：F[2k]=F[k]*(2F[k+1]−F[k])，F[2k+1]=F[k]²+F[k+1]²，再按n奇偶返回相邻两项，递归每次减半。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    unsigned long long n;
    cin >> n;
    const long long mod = 1000000007;
    auto fibonacci = [&](auto &&self, unsigned long long index) -> pair<long long, long long> {
        if (index == 0)
            return {0, 1};
        auto [a, b] = self(self, index / 2);
        long long c = a * ((2 * b - a + mod) % mod) % mod, d = (a * a + b * b) % mod;
        if (index % 2)
            return {d, (c + d) % mod};
        return {c, d};
    };
    auto [a, b] = fibonacci(fibonacci, n);
    cout << a * b % mod;
    return 0;
}
```

### 复杂度

时间、递归栈空间均为 $O(\log n)$。

### 易错点

斐波那契从F1=F2=1开始，公式中F0=0。模减法先加模数，乘法使用64位。
