## 热杆上的蚂蚁

### 题意

可以选择每只蚂蚁的初始方向，求全部离开热杆的最早时间。

### 思路

每只蚂蚁至少需要走到最近的一端，即 min(x,L-x)。让所有蚂蚁都朝更近的一端爬即可同时达到这些下界；全部离开时刻是各自离开时刻的最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int length, n;
    cin >> length >> n;
    int ans = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        ans = max(ans, min(x, length - x));
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

不是把各只蚂蚁的时间相加，它们同时运动。
