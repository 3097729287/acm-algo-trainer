## [HAOI2012]ROAD

### 题意

对每条有向边统计它经过多少条任意起终点的不同最短路，模十亿加七。

### 思路

枚举起点s做Dijkstra，取出满足d[u]+w=d[v]的最短路DAG。正边权保证距离递增是拓扑序。prefix[u]为从s到u的最短路数，按正序相加；suffix[u]为从u出发、沿这个DAG到任意终点的路径数，包含终点就是u的空后缀，故suffix[u]=1+Σsuffix[v]，反序计算。

对DAG中的每条原边u→v，经过它且起点为s的最短路有prefix[u]*suffix[v]条：任选到u的最短前缀、这条边、从v起的后缀，因DAG不会重复点且整路均在最短路结构中，一一对应。对所有s累加。重边按不同原道路分别保留，符合道路序列区分路径的定义。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    struct Edge {
        int from, to, w;
    };
    vector<Edge> edges(m);
    vector<vector<int>> graph(n);
    for (int i = 0; i < m; i++) {
        auto &e = edges[i];
        cin >> e.from >> e.to >> e.w;
        --e.from;
        --e.to;
        graph[e.from].push_back(i);
    }
    const long long mod = 1000000007, inf = 1LL << 60;
    vector<long long> answer(m);
    for (int start = 0; start < n; start++) {
        vector<long long> distance(n, inf), prefix(n), suffix(n, 1);
        vector<int> order;
        priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                       greater<pair<long long, int>>>
            heap;
        distance[start] = 0;
        heap.push({0, start});
        while (!heap.empty()) {
            auto [cost, u] = heap.top();
            heap.pop();
            if (cost != distance[u])
                continue;
            order.push_back(u);
            for (int id : graph[u]) {
                auto e = edges[id];
                if (distance[e.to] > cost + e.w) {
                    distance[e.to] = cost + e.w;
                    heap.push({distance[e.to], e.to});
                }
            }
        }
        prefix[start] = 1;
        for (int u : order)
            for (int id : graph[u]) {
                auto e = edges[id];
                if (distance[u] + e.w == distance[e.to])
                    prefix[e.to] = (prefix[e.to] + prefix[u]) % mod;
            }
        for (int i = (int)order.size() - 1; i >= 0; i--) {
            int u = order[i];
            for (int id : graph[u]) {
                auto e = edges[id];
                if (distance[u] + e.w == distance[e.to]) {
                    suffix[u] = (suffix[u] + suffix[e.to]) % mod;
                    answer[id] = (answer[id] + prefix[u] * suffix[e.to]) % mod;
                }
            }
        }
    }
    for (long long x : answer)
        cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n(n+m)\log n)$，空间 $O(n+m)$。

### 易错点

suffix必须加1，表示在当前点结束，不然会漏掉以v为终点的路径。只计算从当前s可达的DAG结点，边不是无向的。
