## Bits

### 题意

在闭区间 [l,r] 中找二进制一最多的整数。

### 思路

从 x=l 开始，x|(x+1) 会把最低的零位改为一，同时把更低位补成一，是从当前形态继续增加一位一所需的最小增量。若结果仍不大于 r 就采用，否则停止。也可以理解为逐渐把 l 的低位后缀补满：想在更高零位处改一，就先付出比填较低零位更大的增量，因此停止时区间里不会存在一更多的数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        unsigned long long l, r;
        cin >> l >> r;
        unsigned long long x = l;
        while ((x | (x + 1)) <= r)
            x |= x + 1;
        cout << x << '\n';
    }
    return 0;
}
```

### 复杂度

每组最多处理六十个零位，时间 $O(\log r)$，额外空间 $O(1)$。

### 易错点

允许输出任意最优整数，无须恰等于样例。范围含零且可达 10^18，使用 64 位整数。
