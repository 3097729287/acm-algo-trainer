## [SCOI2012]滑雪与时间胶囊

### 题意

只能沿不升高的边滑行，回到历史点免费，先最大化可达景点，再最小化实际滑行总长。

### 思路

先将每条轨道按高到低定向，等高则双向，从1搜索得到全部可达点；免费回溯允许遍历一个根连通的滑行树，因此最多访问全部这些点。

按高度从高到低建立它们的最小进入树。处理高度h时，已处理的更高可达点均已连到起点，可视为一个超级根。候选边包括高处到h的边及h内部的等高边，这是一个无向MST子问题：在同高度连通部分内，边可任选方向，高到低边总能作向下入口。按“较低端高度递减、边长递增”排序，Kruskal依次连不同块，就等价于逐高度求这个局部MST。每层选到可达点与已有根连通，局部最小费用可独立相加；每条可达点的进入边至少要付一次，故下界达到。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> height(n);
    for (auto &x : height)
        cin >> x;
    struct Edge {
        int high, low;
        long long w;
    };
    vector<Edge> edges(m);
    vector<vector<int>> downhill(n);
    for (auto &e : edges) {
        cin >> e.high >> e.low >> e.w;
        --e.high;
        --e.low;
        if (height[e.high] < height[e.low])
            swap(e.high, e.low);
        downhill[e.high].push_back(e.low);
        if (height[e.high] == height[e.low])
            downhill[e.low].push_back(e.high);
    }
    vector<bool> reachable(n);
    vector<int> queue{0};
    reachable[0] = true;
    for (size_t h = 0; h < queue.size(); h++)
        for (int v : downhill[queue[h]])
            if (!reachable[v]) {
                reachable[v] = true;
                queue.push_back(v);
            }
    edges.erase(remove_if(edges.begin(), edges.end(),
                          [&](auto e) { return !reachable[e.high] || !reachable[e.low]; }),
                edges.end());
    sort(edges.begin(), edges.end(), [&](auto a, auto b) {
        if (height[a.low] != height[b.low])
            return height[a.low] > height[b.low];
        return a.w < b.w;
    });
    DSU dsu(n);
    long long answer = 0;
    for (auto e : edges)
        if (dsu.unite(e.high, e.low))
            answer += e.w;
    cout << queue.size() << ' ' << answer;
    return 0;
}
```

### 复杂度

时间 $O(m\log m+(n+m)\alpha(n))$，空间 $O(n+m)$。

### 易错点

不能全图只按边长普通Kruskal，否则树的边方向可能使景点无法从1到达。首先筛掉不可达点，高度层之间保持从高到低。
