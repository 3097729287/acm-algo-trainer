## 挂科

### 题意

总人数 n 中，两门分别有 x、y 人挂科，求同时挂科人数的最大与最小值。

### 思路

交集不超过任一集合大小，最大为 min(x,y)，让较小集合包含在较大集合中可达到。由并集至多 n，交集至少 x+y-n，同时不能为负，所以最小为 max(0,x+y-n)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, x, y;
    cin >> n >> x >> y;
    cout << min(x, y) << ' ' << max(0, x + y - n);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

输出顺序是最大值在前、最小值在后。
