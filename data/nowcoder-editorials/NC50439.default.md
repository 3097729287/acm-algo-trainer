## tokitsukaze and Soldier

### 题意

选择士兵，人数不能超过每个入选士兵的上限，最大化战力和。

### 思路

按人数上限 s 从大到小扫描。处理上限为 s 的士兵时，之前见过的士兵都允许至少 s 人的队伍；用小根堆保留至多 s 个战力最大的士兵。加入当前士兵后，堆过大就弹掉最弱者，记录战力和最大值。任一最优队伍都有最小上限 s，在该上限处理完后堆给出的战力至少同样大，因此不会漏解。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<int, int>> soldiers(n);
    for (auto &[limit, value] : soldiers)
        cin >> value >> limit;
    sort(soldiers.rbegin(), soldiers.rend());
    priority_queue<int, vector<int>, greater<int>> heap;
    long long sum = 0, answer = 0;
    for (auto [limit, value] : soldiers) {
        heap.push(value);
        sum += value;
        while ((int)heap.size() > limit) {
            sum -= heap.top();
            heap.pop();
        }
        answer = max(answer, sum);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

战力全为正，所以容量允许时应尽量保留。战力总和可达十万乘十亿，必须用64位。
