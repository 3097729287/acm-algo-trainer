## [SDOI2016]齿轮

### 题意

链条约束两齿轮的带符号转速比，判断全部齿轮能否同时非零转动。

### 思路

每条边u→v要求 speed[v]=speed[u]*y/x。直接连乘浮点数可能溢出或累计误差；由于|x|、|y|≤100，把绝对值分解为25个不超过100的质数的指数，另用一位表示符号。每个连通块任选根转速为1，遍历边时指数向量相加、符号异或。若到达已经赋值的点，要求整向量和符号完全一致；不一致说明环上乘积不是1，无法全部非零转动。不同块可独立选根，不必联系起来。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    vector<int> primes;
    for (int p = 2; p <= 100; p++) {
        bool prime = true;
        for (int d = 2; d * d <= p; d++)
            if (p % d == 0)
                prime = false;
        if (prime)
            primes.push_back(p);
    }
    array<array<int, 25>, 101> factor{};
    for (int x = 1; x <= 100; x++) {
        int value = x;
        for (int j = 0; j < 25; j++)
            while (value % primes[j] == 0) {
                factor[x][j]++;
                value /= primes[j];
            }
    }
    int tests;
    cin >> tests;
    for (int tc = 1; tc <= tests; tc++) {
        int n, m;
        cin >> n >> m;
        struct Edge {
            int to, sign;
            array<int, 25> delta;
        };
        vector<vector<Edge>> graph(n + 1);
        while (m--) {
            int u, v, x, y;
            cin >> u >> v >> x >> y;
            Edge forward{v, y < 0, {}}, backward{u, y < 0, {}};
            for (int j = 0; j < 25; j++) {
                forward.delta[j] = factor[abs(y)][j] - factor[x][j];
                backward.delta[j] = -forward.delta[j];
            }
            graph[u].push_back(forward);
            graph[v].push_back(backward);
        }
        vector<bool> seen(n + 1);
        vector<int> sign(n + 1);
        vector<array<int, 25>> speed(n + 1);
        bool valid = true;
        for (int root = 1; root <= n; root++)
            if (!seen[root]) {
                vector<int> queue{root};
                seen[root] = true;
                for (size_t h = 0; h < queue.size(); h++) {
                    int u = queue[h];
                    for (const auto &e : graph[u]) {
                        auto next = speed[u];
                        for (int j = 0; j < 25; j++)
                            next[j] += e.delta[j];
                        int nextSign = sign[u] ^ e.sign;
                        if (!seen[e.to]) {
                            seen[e.to] = true;
                            speed[e.to] = next;
                            sign[e.to] = nextSign;
                            queue.push_back(e.to);
                        } else if (speed[e.to] != next || sign[e.to] != nextSign)
                            valid = false;
                    }
                }
            }
        cout << "Case #" << tc << ": " << (valid ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(25(n+m))$。

### 易错点

y可为负，方向矛盾也会导致系统锁死。检查的是乘法比例，不是普通距离差。指数可为负，表示分母。
