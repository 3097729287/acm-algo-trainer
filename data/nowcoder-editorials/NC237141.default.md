## A tree game

### 题意

剪去一边并丢掉不连根部分，多组判断胜者。

### 思路

根的各儿子分支互相独立，按Sprague–Grundy定理异或。一个分支是“父边接一棵子树”，绿树删边博弈的加根边规则使其SG为子树SG+1：剪掉父边可到0，其余动作对应子树内部删边，mex归纳得到加1。于是sg[u]=xor(sg[v]+1)，叶子为0，根SG非0则Alice胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct EulerTree {
    int n;
    vector<vector<int>> edge;
    vector<int> parent, depth, in, out, order;
    EulerTree(int n) : n(n), edge(n + 1), parent(n + 1), depth(n + 1), in(n + 1), out(n + 1) {}
    void add(int u, int v) {
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    void root(int start) {
        vector<int> stack = {start};
        parent[start] = 0;
        order.clear();
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            in[u] = order.size() + 1;
            order.push_back(u);
            for (int v : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    depth[v] = depth[u] + 1;
                    stack.push_back(v);
                }
        }
        vector<int> size(n + 1, 1);
        for (int i = (int)order.size() - 1; i >= 0; i--) {
            int u = order[i];
            out[u] = in[u] + size[u] - 1;
            if (parent[u])
                size[parent[u]] += size[u];
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        EulerTree tree(n);
        for (int i = 1; i < n; i++) {
            int u, v;
            cin >> u >> v;
            tree.add(u, v);
        }
        tree.root(1);
        vector<int> sg(n + 1);
        for (int i = n - 1; i > 0; i--) {
            int u = tree.order[i];
            sg[tree.parent[u]] ^= sg[u] + 1;
        }
        cout << (sg[1] ? "Alice\n" : "Bob\n");
    }
    return 0;
}
```

### 复杂度

每组时间、空间均 $O(n)$。

### 易错点

独立分支先加1再异或，不能先把儿子SG异或后统一加1。没有边的单根树先手输。
