## 石子游戏2

### 题意

堆栈增删石子堆，每天最小代价丢若干堆使Nim和为0。

### 思路

当前总异或为X，Bob获胜要求保留堆异或0，等价于丢弃子集异或X。令dp[s]为丢弃子集异或s的最小代价。添加(a,b)对应0/1异或背包，按x与x xor a成对更新，可原地同时使用两份旧值。

删除不能直接撤销最小值，所以先读完操作，把每个ADD到对应DEL之前的存在期记为时间区间。将物品加入覆盖其存在期的时间线段树。DFS进入节点时复制父DP，加入本节点物品；叶子查询dp[当日总异或]。兄弟节点各用父表，天然恢复删除前状态。

值小于2^14，DP最多16384项。若dp[a]≤b，新增物品可由已有更便宜的同异或子集替代，整件更新可以安全跳过；每节点按b升序加入，让这一支配剪枝尽早生效。代价为正，即使替代集合与原方案重叠，抵消重复元素只会更便宜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Item {
        int value, cost, left, right;
    };
    vector<Item> item;
    vector<int> stack, totalXor(n);
    int current = 0, maximum = 0;
    for (int day = 0; day < n; day++) {
        string op;
        cin >> op;
        if (op == "ADD") {
            int a, b;
            cin >> a >> b;
            item.push_back({a, b, day, n - 1});
            stack.push_back(item.size() - 1);
            current ^= a;
            maximum = max(maximum, a);
        } else {
            int id = stack.back();
            stack.pop_back();
            item[id].right = day - 1;
            current ^= item[id].value;
        }
        totalXor[day] = current;
    }
    int states = 1;
    while (states <= maximum)
        states <<= 1;
    vector<vector<int>> event(4 * n + 4);
    auto insert = [&](auto &&self, int u, int l, int r, int ql, int qr, int id) -> void {
        if (ql <= l && r <= qr) {
            event[u].push_back(id);
            return;
        }
        int mid = (l + r) / 2;
        if (ql <= mid)
            self(self, u * 2, l, mid, ql, qr, id);
        if (qr > mid)
            self(self, u * 2 + 1, mid + 1, r, ql, qr, id);
    };
    for (int id = 0; id < (int)item.size(); id++)
        insert(insert, 1, 0, n - 1, item[id].left, item[id].right, id);
    for (auto &row : event)
        sort(row.begin(), row.end(), [&](int a, int b) { return item[a].cost < item[b].cost; });
    const int inf = 1000000000;
    vector<int> initial(states, inf), answer(n);
    initial[0] = 0;
    auto solve = [&](auto &&self, int u, int l, int r, const vector<int> &parent) -> void {
        vector<int> dp = parent;
        for (int id : event[u]) {
            auto it = item[id];
            if (dp[it.value] <= it.cost)
                continue;
            int pivot = 1;
            while (pivot <= it.value / 2)
                pivot <<= 1;
            for (int block = 0; block < states; block += 2 * pivot)
                for (int offset = 0; offset < pivot; offset++) {
                    int x = block + offset, y = x ^ it.value, oldX = dp[x], oldY = dp[y];
                    dp[x] = min(oldX, oldY + it.cost);
                    dp[y] = min(oldY, oldX + it.cost);
                }
        }
        if (l == r)
            answer[l] = dp[totalXor[l]];
        else {
            int mid = (l + r) / 2;
            self(self, u * 2, l, mid, dp);
            self(self, u * 2 + 1, mid + 1, r, dp);
        }
    };
    solve(solve, 1, 0, n - 1, initial);
    for (int x : answer)
        cout << x << '\n';
    return 0;
}
```

### 复杂度

令U≤2^14、A为ADD次数，最坏时间 $O((A\log n+n)U)$，空间 $O(A\log n+U\log n+n)$；支配剪枝改善实际耗时，不改变最坏界。

### 易错点

当天DEL后该堆已不存在，生存区间右端为删除日−1。两个异或成对状态必须保存旧值后一起更新，避免同件重复使用。
