## 珂朵莉的假动态仙人掌

### 题意

每天送至少一个本子，相邻两天数量不同，给定 n 个本子最多送几天。

### 思路

任意相邻两天至少消耗三个本子。最省的送法是 1,2,1,2,…，每三个本子支持两天；余一个能多送一天，余两个也只能多送一天。因此答案为 2*(n/3)+(n%3>0)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    cout << 2 * (n / 3) + (n % 3 != 0);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

剩下两个本子不能再送两天，否则两天都只能送一个，违反相邻不同。
