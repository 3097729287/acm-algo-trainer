## [NOIP2015]信息传递

### 题意

每人把信息传给固定对象，最早何时有人听回自己的生日。

### 思路

每点只有一条出边，自己的信息绕环一周才可能回到自己，所以答案是函数图最短有向环长。先统计入度，拓扑删除全部入度0点及随之变成0的点；剩下的点恰为各个互不相交的环。对每个未处理剩余点沿出边走一周计长，取最小。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> next(n), degree(n);
    for (int &v : next) {
        cin >> v;
        --v;
        degree[v]++;
    }
    vector<int> queue;
    for (int u = 0; u < n; u++)
        if (!degree[u])
            queue.push_back(u);
    for (size_t h = 0; h < queue.size(); h++)
        if (--degree[next[queue[h]]] == 0)
            queue.push_back(next[queue[h]]);
    int answer = n;
    for (int u = 0; u < n; u++)
        if (degree[u]) {
            int length = 0, v = u;
            do {
                degree[v] = 0;
                length++;
                v = next[v];
            } while (v != u);
            answer = min(answer, length);
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

树枝上的信息只会进入环而不会回到自己，不影响最早轮数。不是求最长环，也不是数所有环节点。
