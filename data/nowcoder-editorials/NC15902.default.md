## Hello I am HERE!

### 题意

对最多五千位的正整数做加法，并去掉答案的前导零。

### 思路

从两串末尾开始逐位相加，加上上一位进位。把和的个位加入结果，十位作为下一轮进位；两边都读完后仍有进位就继续。暂存的结果从低位到高位，先去掉高位多余零，再反转。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        string a, b, answer;
        cin >> a >> b;
        int i = (int)a.size() - 1, j = (int)b.size() - 1, carry = 0;
        while (i >= 0 || j >= 0 || carry) {
            int sum = carry;
            if (i >= 0)
                sum += a[i--] - '0';
            if (j >= 0)
                sum += b[j--] - '0';
            answer += char('0' + sum % 10);
            carry = sum / 10;
        }
        while (answer.size() > 1 && answer.back() == '0')
            answer.pop_back();
        reverse(answer.begin(), answer.end());
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

时间与结果空间均为 $O(\max(|A|,|B|))$。

### 易错点

两个整数可以长度不同，也可能含很多前导零，不能按相同下标直接从左往右加。
