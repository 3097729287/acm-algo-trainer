## [NOIP2010]关押罪犯

### 题意

把罪犯分进两座监狱，使同狱仇恨边的最大权尽量小。

### 思路

按仇恨值从大到小，尝试把每条边两端强制分到不同监狱。用两倍并查集表示“某人”和“某人的对立阵营”。若处理权值w时两人已经同组，说明所有权值至少w的边不能全跨监狱，答案至少w；此前更大边约束均可满足，故答案恰为w。若所有约束都可满足，整图二分，答案0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    struct Edge {
        int a, b, w;
    };
    vector<Edge> edges(m);
    for (auto &e : edges)
        cin >> e.a >> e.b >> e.w;
    sort(edges.begin(), edges.end(), [](auto a, auto b) { return a.w > b.w; });
    DSU dsu(2 * n);
    int answer = 0;
    for (auto e : edges) {
        if (dsu.find(e.a) == dsu.find(e.b)) {
            answer = e.w;
            break;
        }
        dsu.unite(e.a, e.b + n);
        dsu.unite(e.a + n, e.b);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(m\log m+(n+m)\alpha(n))$，空间 $O(n+m)$。

### 易错点

有矛盾时输出当前权值，不是减一。两监狱允许空置，目标只取最大冲突。
