## 数字组合

### 题意

四组各选一个数，统计和为0的方案数。

### 思路

枚举前两组的n²个和并排序。再枚举后两组和s，用equal_range统计前表中−s的出现次数，累加即可。各行只是输入四组数据，不限制选取数字来自同一行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n), b(n), c(n), d(n);
    for (int i = 0; i < n; i++)
        cin >> a[i] >> b[i] >> c[i] >> d[i];
    vector<long long> sum;
    sum.reserve(n * n);
    for (auto x : a)
        for (auto y : b)
            sum.push_back(x + y);
    sort(sum.begin(), sum.end());
    long long answer = 0;
    for (auto x : c)
        for (auto y : d) {
            auto range = equal_range(sum.begin(), sum.end(), -x - y);
            answer += range.second - range.first;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^2\log n)$，空间 $O(n^2)$。

### 易错点

相同数值在不同下标属于不同选择，所以保留重复和。答案最多n⁴，使用64位。
