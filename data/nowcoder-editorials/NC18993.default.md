## 硬币游戏

### 题意

双方轮流选同一组列位置，各取自己那一行硬币，比较得到的二进制串。

### 思路

把每列分成UU、UD、DU、DD。当前位优先取U；同为U时优先UU，因为还能阻止对手获得一个U。自己没有U时优先拿走对手的U。这三条优先级可通过交换首个不同选择证明：不降低自己的当前位，同时只减少对手未来可取的1。

设UU有c个、UD有a个、DU有b个。双方先轮流消耗UU。c为偶数时回到先手轮，双方再各自取独有U：a>b先手胜；a=b平局；a<b时先手先耗尽，但还能取走对手一个DU，所以b=a+1也平局，b≥a+2才后手胜。

c为奇数时，后手必须先取一个DU来匹配先手刚取得的最后一个UU，否则立刻输；取后等价于偶数情况中把b减1。统一令d=a−b+(c mod 2)：d>0先手胜，d=0或−1平局，d<−1后手胜。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    string a, b;
    cin >> n >> a >> b;
    int both = 0, first = 0, second = 0;
    for (int i = 0; i < 2 * n; i++) {
        if (a[i] == 'U' && b[i] == 'U')
            both++;
        else if (a[i] == 'U')
            first++;
        else if (b[i] == 'U')
            second++;
    }
    int difference = first - second + (both % 2);
    if (difference > 0)
        cout << "clccle trl!";
    else if (difference < -1)
        cout << "sarlendy tql!";
    else
        cout << "orz sarlendy!";
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(n)$ 存输入。

### 易错点

每选一列就同时占用双方对应位置，不是从两行任取一枚。相等时输出指定平局字符串。
