## 幸运数字Ⅱ

### 题意

幸运数只含4、7，求区间内每个数向上取到首个幸运数后的总和。

### 思路

生成不超过10位的全部幸运数并排序，其中4444444444已覆盖十亿上界。相邻幸运数previous、value之间，所有整数 (previous,value] 的next都等于value。将该段与[l,r]求交，用交集整数个数乘value累加。无需逐个枚举原区间。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long l, r;
    cin >> l >> r;
    vector<long long> lucky;
    auto dfs = [&](auto &&self, long long x, int digits) -> void {
        if (digits)
            lucky.push_back(x);
        if (digits == 10)
            return;
        self(self, x * 10 + 4, digits + 1);
        self(self, x * 10 + 7, digits + 1);
    };
    dfs(dfs, 0, 0);
    sort(lucky.begin(), lucky.end());
    long long previous = 0, answer = 0;
    for (long long value : lucky) {
        long long left = max(l, previous + 1), right = min(r, value);
        if (left <= right)
            answer += (right - left + 1) * value;
        previous = value;
        if (value >= r)
            break;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

本题最多生成2046个数，记数量为 $K$，时间 $O(K\log K)$，空间 $O(K)$。

### 易错点

生成的幸运数需要超出r，才能覆盖最后一段；区间包括幸运数本身。答案用64位。
