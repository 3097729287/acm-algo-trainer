## 漂亮数

### 题意

多次统计闭区间中恰好分解为两个素数乘积的数，包括素数平方。

### 思路

先读全部询问，只预处理到最大右端N。漂亮数可唯一写为p*q且p≤q，所以只需生成至N/2的全部素数，再枚举p≤sqrt(N)、q从p到N/p，把乘积的位标记为1。素数平方自然包含，三个及以上素因子的数不会被标记。

N至一亿，逐整数32位前缀和会占四亿字节。用64位字打包标记，每个字再存一个“此前整字置一总数”。查询前缀t时，整字计数加本字低t%64+1位的popcount，即可常数时间求数量。每次区间用rank(r)−rank(l−1)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    vector<pair<int, int>> query(tests);
    int maximum = 0;
    for (auto &[l, r] : query) {
        cin >> l >> r;
        maximum = max(maximum, r);
    }
    int limit = maximum / 2;
    vector<bool> composite(limit + 1);
    for (int p = 2; 1LL * p * p <= limit; p++)
        if (!composite[p])
            for (int x = p * p; x <= limit; x += p)
                composite[x] = true;
    vector<int> primes;
    for (int p = 2; p <= limit; p++)
        if (!composite[p])
            primes.push_back(p);
    vector<bool>().swap(composite);
    size_t words = ((size_t)maximum + 64) / 64;
    vector<unsigned long long> bits(words);
    for (size_t i = 0; i < primes.size() && 1LL * primes[i] * primes[i] <= maximum; i++)
        for (size_t j = i; j < primes.size(); j++) {
            long long value = 1LL * primes[i] * primes[j];
            if (value > maximum)
                break;
            bits[value / 64] |= 1ULL << (value % 64);
        }
    vector<int> prefix(words + 1);
    for (size_t i = 0; i < words; i++)
        prefix[i + 1] = prefix[i] + __builtin_popcountll(bits[i]);
    auto rank = [&](int x) {
        if (x < 0)
            return 0;
        int word = x / 64, bit = x % 64;
        unsigned long long mask = bit == 63 ? ~0ULL : (1ULL << (bit + 1)) - 1;
        return prefix[word] + __builtin_popcountll(bits[word] & mask);
    };
    for (auto [l, r] : query)
        cout << rank(r) - rank(l - 1) << '\n';
    return 0;
}
```

### 复杂度

枚举素数对数为 $P$，时间 $O(N\log\log N+P+T)$，空间为 $O(N/64+\pi(N/2)+T)$ 个机器字。

### 易错点

重复素因子允许，如4=2²。构造64位掩码时，移位64是未定义行为，末位为63时直接用全一掩码。乘积先转64位再判断上界。
