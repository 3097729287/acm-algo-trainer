## 拼数

### 题意

重排正整数并连接，得到最大的十进制数。

### 思路

把每个数当作字符串。两个相邻串 a、b 应在 a+b>b+a 时把 a 放前面；如果一个排列存在相反的相邻顺序，交换这两项就能使完整连接串变大。因此按该比较规则排序，再依次输出。这个比较对应重复串的字典序，满足排序所需的严格弱序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> a(n);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end(), [](const string &x, const string &y) { return x + y > y + x; });
    for (const auto &x : a)
        cout << x;
    return 0;
}
```

### 复杂度

单串最多 $L=10$ 位，时间 $O(nL\log n)$，空间 $O(nL)$。

### 易错点

按数值或单个字符串的字典序降序都不保证最大；例如 9 应放在 91 之前。比较相等时返回 false，不能写大于等于。
