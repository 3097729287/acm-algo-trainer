## 数字三角形

### 题意

第 i 行输出 i 个连续整数，从一开始，每个数至少占四列。

### 思路

用一个自增计数器记录下一个待输出的数，外层控制行数、内层控制该行数量，每次使用 setw(4)。宽度是最小宽度，大于四位的数字仍完整输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int value = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++)
            cout << setw(4) << value++;
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n^2)$，除输出缓冲外额外空间 $O(1)$。

### 易错点

此处各数字靠字段宽度衔接，不另加分隔空格。
