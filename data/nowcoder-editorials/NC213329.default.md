## K匹配

### 题意

统计 S 的所有连续子串中，有多少个包含完整的 T。

### 思路

因为 T 的长度正好是 k，和 T 满足 k 匹配就等价于子串内包含 T。按右端点 i 扫描，令 last 是截至 i 已经完整出现的 T 中最靠右的起点（一基编号）。以 i 结尾的子串，左端点选一到 last 时恰好包含一次完整 T，贡献 last 个；没有出现时贡献零。KMP 找到每次出现时更新 last，逐项累加即可，重叠出现不会重复计同一个区间。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

template <class Sequence> vector<int> prefixFunction(const Sequence &s) {
    int n = s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])
            j = pi[j - 1];
        if (s[i] == s[j])
            j++;
        pi[i] = j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    string s, t;
    cin >> n >> k;
    s.reserve(n);
    t.reserve(k);
    cin >> s >> t;
    auto pi = prefixFunction(t);
    int matched = 0, last = 0;
    long long answer = 0;
    for (int i = 0; i < n; i++) {
        while (matched > 0 && s[i] != t[matched])
            matched = pi[matched - 1];
        if (s[i] == t[matched])
            matched++;
        if (matched == k) {
            last = i - k + 2;
            matched = pi[matched - 1];
        }
        answer += last;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n+k)$，额外前缀表空间 $O(k)$，另保存两输入串。

### 易错点

一个子串即使含多次 T 也只算一次，使用最靠右起点统一计数。n 可达一千万，答案要用 long long，字符串预留容量减少内存扩容。
