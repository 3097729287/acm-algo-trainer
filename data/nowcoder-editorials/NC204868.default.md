## 斗兽棋

### 题意

按大象吃虎、虎吃猫、猫吃鼠、鼠吃象的四环关系判断输赢。

### 思路

把四种棋子按环顺序编号零到三。若第一种的后一项等于第二种，就为 win；反向关系成立则为 lose，其余都是 tie，包括同种与相隔两步。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    vector<string> names = {"elephant", "tiger", "cat", "mouse"};
    string a, b;
    cin >> a >> b;
    int x = find(names.begin(), names.end(), a) - names.begin(),
        y = find(names.begin(), names.end(), b) - names.begin();
    if ((x + 1) % 4 == y)
        cout << "win";
    else if ((y + 1) % 4 == x)
        cout << "lose";
    else
        cout << "tie";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不是所有不同种棋子都分胜负，例如大象与猫之间没有吃子关系。
