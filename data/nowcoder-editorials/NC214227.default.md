## 成绩统计

### 题意

输出成绩平均分、最高分和最低分。

### 思路

一次读取中累加总分，并更新最大与最小值。总分除以浮点数 n 得平均值，平均值固定两位，其余按整数输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int sum = 0, lo = 100, hi = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        sum += x;
        lo = min(lo, x);
        hi = max(hi, x);
    }
    cout << fixed << setprecision(2) << (double)sum / n << ' ' << hi << ' ' << lo;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

不要对平均值先做整数除法。三个输出的顺序按题目要求。
