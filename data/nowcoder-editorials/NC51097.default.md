## Parity game

### 题意

区间一的个数奇偶约束，求最长一致的陈述前缀。

### 思路

设 prefix[i] 为前 i 位异或，区间 [l,r] 奇偶就是 prefix[l−1]^prefix[r]。只对出现的 l−1、r 离散化。用两倍并查集：结点 x 表示该前缀值，x+K 表示它的反值。偶约束将同值合并、反值合并；奇约束交叉合并。加入前先检查是否已被强制成相反关系；首次矛盾时，之前陈述数就是答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int length, m;
    cin >> length >> m;
    struct Query {
        int l, r, odd;
    };
    vector<Query> queries(m);
    vector<int> values;
    for (auto &q : queries) {
        string kind;
        cin >> q.l >> q.r >> kind;
        q.l--;
        q.odd = kind == "odd";
        values.push_back(q.l);
        values.push_back(q.r);
    }
    sort(values.begin(), values.end());
    values.erase(unique(values.begin(), values.end()), values.end());
    int k = values.size();
    DSU dsu(2 * k);
    int answer = m;
    for (int i = 0; i < m; i++) {
        auto q = queries[i];
        int a = lower_bound(values.begin(), values.end(), q.l) - values.begin(),
            b = lower_bound(values.begin(), values.end(), q.r) - values.begin();
        bool conflict = q.odd ? dsu.find(a) == dsu.find(b) : dsu.find(a) == dsu.find(b + k);
        if (conflict) {
            answer = i;
            break;
        }
        if (q.odd) {
            dsu.unite(a, b + k);
            dsu.unite(a + k, b);
        } else {
            dsu.unite(a, b);
            dsu.unite(a + k, b + k);
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(m\log m)$，空间 $O(m)$。

### 易错点

左端点用 l−1，不能用 l。输出矛盾之前的条数，不是第一条矛盾的编号。原序列十亿长度，不可直接开数组。
