## [NOIP2003]加分二叉树

### 题意

在中序编号固定的二叉树中，最大化左右子树加分的乘积加根分数，并输出一种最优先序。

### 思路

一棵子树的中序编号必然是连续区间 [l,r]。枚举根 k，左右两边独立取最优，候选为 dp[l][k-1]·dp[k+1][r]+score[k]。空区间加分为一，单个叶子加分直接等于自身分数，不能套成分数加一。按区间长度计算，并记录取得最大值的根，用它递归输出先序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> value(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> value[i];
    vector<vector<long long>> dp(n + 2, vector<long long>(n + 2, 1));
    vector<vector<int>> root(n + 2, vector<int>(n + 2));
    for (int i = 1; i <= n; i++) {
        dp[i][i] = value[i];
        root[i][i] = i;
    }
    for (int length = 2; length <= n; length++)
        for (int l = 1; l + length - 1 <= n; l++) {
            int r = l + length - 1;
            dp[l][r] = 0;
            for (int k = l; k <= r; k++) {
                long long candidate = dp[l][k - 1] * dp[k + 1][r] + value[k];
                if (candidate > dp[l][r]) {
                    dp[l][r] = candidate;
                    root[l][r] = k;
                }
            }
        }
    cout << dp[1][n] << '\n';
    bool first = true;
    function<void(int, int)> output = [&](int l, int r) {
        if (l > r)
            return;
        int k = root[l][r];
        if (!first)
            cout << ' ';
        first = false;
        cout << k;
        output(l, k - 1);
        output(k + 1, r);
    };
    output(1, n);
    return 0;
}
```

### 复杂度

时间 $O(n^3)$，DP 与根记录空间 $O(n^2)$。

### 易错点

最高分可能超过有符号 32 位范围，dp 与乘积使用 long long。根编号就是中序下标，不是输入分数。
