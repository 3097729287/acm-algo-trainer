## 抽卡

### 题意

每个卡池抽一次，求至少抽到一张想要卡的概率。

### 思路

卡池i不出想要卡的概率为(a[i]−b[i])/a[i]。独立抽取时全部落空概率是这些分数乘积，所以答案为1−Π(a−b)/Πa。分别累乘分子、分母，最后只用一次快速幂求分母逆元。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    const long long mod = 1000000007;
    vector<long long> a(n);
    long long denominator = 1, numerator = 1;
    for (auto &x : a) {
        cin >> x;
        denominator = denominator * x % mod;
    }
    for (int i = 0; i < n; i++) {
        long long b;
        cin >> b;
        numerator = numerator * (a[i] - b) % mod;
    }
    long long inverse = 1, exponent = mod - 2;
    while (exponent) {
        if (exponent & 1)
            inverse = inverse * denominator % mod;
        denominator = denominator * denominator % mod;
        exponent >>= 1;
    }
    cout << (1 - numerator * inverse % mod + mod) % mod;
    return 0;
}
```

### 复杂度

时间 $O(n+\log P)$，空间 $O(n)$。

### 易错点

题意是至少一个池成功，样例也对应补事件；不是所有池都成功。a[i]<P且非零，分母必可逆。
