## Sum of Consecutive Prime Numbers

### 题意

多组统计由连续素数之和组成n的方式。

### 思路

一次筛出所有不超过最大n的素数。每组对素数序列用双指针维护正数窗口和：向右扩展后，和>n就从左缩小；等于n时计一种。素数均正，每个端点只移动一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> sieve(int n) {
    vector<bool> composite(n + 1);
    vector<int> primes;
    for (int p = 2; p <= n; p++)
        if (!composite[p]) {
            primes.push_back(p);
            if (1LL * p * p <= n)
                for (int x = p * p; x <= n; x += p)
                    composite[x] = true;
        }
    return primes;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    vector<int> query(tests);
    int maximum = 0;
    for (int &n : query) {
        cin >> n;
        maximum = max(maximum, n);
    }
    auto primes = sieve(maximum);
    for (int n : query) {
        int left = 0, answer = 0;
        long long sum = 0;
        for (int right = 0; right < (int)primes.size() && primes[right] <= n; right++) {
            sum += primes[right];
            while (sum > n)
                sum -= primes[left++];
            if (sum == n)
                answer++;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

预筛 $O(U\log\log U)$；各组 $O(\pi(n))$，空间 $O(U)$ 位加素数表。

### 易错点

连续指素数序列中连续，不是允许任意素数相加。单个素数本身也算一种。
