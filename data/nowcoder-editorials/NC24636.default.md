## 值周

### 题意

在长度上亿的整数道路上删除多个闭区间中的树，求剩余棵数。

### 思路

道路共有 l+1 棵树，不能逐点建数组。把删除区间按左端点排序，维护当前合并段 [left,right]；新区间若与当前段重叠或相邻就扩展右端，否则结算 right-left+1 并开始下一段。最后扣除删除并集大小。相邻整数段可以合并，因为两段间没有遗漏整数点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long length;
    int n;
    cin >> length >> n;
    vector<pair<long long, long long>> a(n);
    for (auto &[l, r] : a)
        cin >> l >> r;
    sort(a.begin(), a.end());
    long long left = a[0].first, right = a[0].second, removed = 0;
    for (int i = 1; i < n; i++) {
        if (a[i].first <= right + 1)
            right = max(right, a[i].second);
        else {
            removed += right - left + 1;
            left = a[i].first;
            right = a[i].second;
        }
    }
    removed += right - left + 1;
    cout << length + 1 - removed;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

闭区间长度是 right-left+1，不是几何长度。道路的零号位置也有树。
