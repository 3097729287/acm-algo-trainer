## 游戏

### 题意

三人轮流把左上矩形按R→G→B→R变色，选点必须非B，求最终不能操作的人。

### 思路

每次操作必包含左上角，所以它每步都沿R→G→B→R变化。终局全B，因此总操作数L模3仅由初始左上角决定：R需2步、G需1步、B需0步。下一位即失败者，分别为dreagonm、fengxunling、BLUESKY007。

还需确认不会无限循环：把格子按从右下到左上的行优先顺序作为三进制位，令R=2、G=1、B=0，越靠右下权越高。选中格是本次影响范围内权最高的格，它从2降1或1降0，所有更高位不变，因此整个势能严格下降。游戏必结束，策略不影响失败者。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        string row;
        char first = 'B';
        for (int i = 0; i < n; i++) {
            cin >> row;
            if (i == 0)
                first = row[0];
        }
        if (first == 'R')
            cout << "dreagonm\n";
        else if (first == 'G')
            cout << "fengxunling\n";
        else
            cout << "BLUESKY007\n";
    }
    return 0;
}
```

### 复杂度

读入时间 $O(nm)$，空间 $O(m)$。

### 易错点

左上角一开始为B并不表示立即结束，但最终总步数必为3的倍数。
