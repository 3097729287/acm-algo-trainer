## 一袋小球

### 题意

P先抽，D抽黑后会多带出一个球，求P先抽到白球概率。

### 思路

f[w][b]为轮到P、袋内有w白b黑时P获胜概率。P直接抽白贡献w/(w+b)。若P与D都抽黑，概率b/(w+b)*(b−1)/(w+b−1)，再由D带出一球：带黑转f[w][b−3]，带白转f[w−1][b−2]，按剩余球比例加权。D抽到白则P失败，不加贡献。w=0时恒0，b=0且w>0时恒1。按w、b升序计算。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int w, b;
    cin >> w >> b;
    vector<vector<long double>> dp(w + 1, vector<long double>(b + 1));
    for (int white = 1; white <= w; white++)
        for (int black = 0; black <= b; black++) {
            long double total = white + black;
            dp[white][black] = white / total;
            if (black >= 2) {
                long double reach = black / total * (black - 1) / (total - 1),
                            remaining = total - 2;
                if (black >= 3)
                    dp[white][black] += reach * (black - 2) / remaining * dp[white][black - 3];
                dp[white][black] += reach * white / remaining * dp[white - 1][black - 2];
            }
        }
    cout << fixed << setprecision(12) << dp[w][b];
    return 0;
}
```

### 复杂度

时间、空间均 $O(wb)$。

### 易错点

带出白球不算D抽到白球，但会减少下一轮白球数。空袋判D赢，所以dp[0][0]=0。
