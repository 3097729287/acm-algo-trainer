## 病毒

### 题意

是否存在无限长二进制串避开全部病毒子串。

### 思路

在AC自动机中去掉所有模式终点及其fail后代代表的禁用状态。无限安全串等价于从根出发的安全转移图能到达一个环：有环即可无限重复其边字符，无限路径在有限状态图中也必重复状态。

先BFS标记根可达的安全状态，再对这部分计算入度并做拓扑删除。若删完所有可达点则无环，否则剩余部分包含环，输出TAK。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Aho {
    struct Node {
        array<int, 26> next = {};
        int fail = 0, parent = 0, letter = 0, longest = 0;
    };
    vector<Node> node;
    vector<int> order;
    int alphabet;
    char base;
    Aho(int alphabet, char base, size_t capacity) : alphabet(alphabet), base(base) {
        node.reserve(capacity);
        node.emplace_back();
    }
    int insert(const string &s) {
        int u = 0;
        for (char ch : s) {
            int c = ch - base;
            if (!node[u].next[c]) {
                int v = node.size();
                node[u].next[c] = v;
                node.emplace_back();
                node[v].parent = u;
                node[v].letter = c;
            }
            u = node[u].next[c];
        }
        node[u].longest = max(node[u].longest, (int)s.size());
        return u;
    }
    void build() {
        order = {0};
        for (int c = 0; c < alphabet; c++)
            if (node[0].next[c])
                order.push_back(node[0].next[c]);
        for (size_t i = 1; i < order.size(); i++) {
            int u = order[i], f = node[u].fail;
            node[u].longest = max(node[u].longest, node[f].longest);
            for (int c = 0; c < alphabet; c++) {
                int v = node[u].next[c];
                if (v) {
                    node[v].fail = node[f].next[c];
                    order.push_back(v);
                } else
                    node[u].next[c] = node[f].next[c];
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> pattern(n);
    size_t total = 1;
    for (auto &s : pattern) {
        cin >> s;
        total += s.size();
    }
    Aho ac(2, '0', total);
    for (auto &s : pattern)
        ac.insert(s);
    ac.build();
    int size = ac.node.size();
    vector<bool> reachable(size);
    vector<int> order = {0}, indegree(size);
    reachable[0] = true;
    for (size_t i = 0; i < order.size(); i++)
        for (int c = 0; c < 2; c++) {
            int v = ac.node[order[i]].next[c];
            if (!ac.node[v].longest && !reachable[v]) {
                reachable[v] = true;
                order.push_back(v);
            }
        }
    for (int u : order)
        for (int c = 0; c < 2; c++) {
            int v = ac.node[u].next[c];
            if (reachable[v])
                indegree[v]++;
        }
    queue<int> queue;
    for (int u : order)
        if (!indegree[u])
            queue.push(u);
    int removed = 0;
    while (!queue.empty()) {
        int u = queue.front();
        queue.pop();
        removed++;
        for (int c = 0; c < 2; c++) {
            int v = ac.node[u].next[c];
            if (reachable[v] && --indegree[v] == 0)
                queue.push(v);
        }
    }
    cout << (removed < (int)order.size() ? "TAK" : "NIE");
    return 0;
}
```

### 复杂度

时间、空间均 $O(L)$，二进制字母表固定为2。

### 易错点

不可达的安全环无用，必须从根筛可达性。两字符可能指向同一状态，入度与删除均按两条边计数。
