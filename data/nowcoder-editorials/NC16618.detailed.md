## 排座椅

> 原题：[P1056](https://www.luogu.com.cn/problem/P1056)
> 解法：分别选择能隔开最多对的横纵通道 · C++17

### 题意

给出只在相邻位置交谈的同学对，选择规定条数的横向和纵向通道，使未被隔开的交谈对最少。



### 思路

一对上下相邻的同学，只能由中间的横通道隔开，任何竖通道都不起作用。左右相邻的情况正相反。因此每对交谈唯一归属于一条候选通道，没有同一对被横、竖同时覆盖的重复计算问题。

对上下相邻的行号 $x$、$p$，通道编号为 $\min(x, p)$，表示这一行与下一行之间；左右相邻则取列号的较小者。分别累加 row 与 column 的计数。因为每条通道的收益相互独立，若选了低收益线却没选高收益线，交换后会更优，所以直接选最大的 K 条横线与 L 条竖线。

选择依据是收益，但题目输出顺序要求通道编号升序，因此取出编号后还要再排序。K 或 L 为零时对应输出一个空行。题目保证最优方案唯一，不必额外设计不同最优方案间的优先级。

时间 $O(d+m\log m+n\log n)$、空间 $O(m+n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
void print_best(const vector<int> &counts, int number) {
    vector<pair<int, int>> rank;
    for (int i = 1; i < (int)counts.size(); i++)
        rank.push_back({counts[i], i});
    sort(rank.rbegin(), rank.rend());
    vector<int> answer;
    for (int i = 0; i < number; i++)
        answer.push_back(rank[i].second);
    sort(answer.begin(), answer.end());
    for (int i = 0; i < number; i++) {
        if (i)
            cout << ' ';
        cout << answer[i];
    }
    cout << '\n';
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, n, k, l, d;
    cin >> m >> n >> k >> l >> d;
    vector<int> rows(m), columns(n);
    while (d--) {
        int x, y, p, q;
        cin >> x >> y >> p >> q;
        if (x != p)
            ++rows[min(x, p)];
        else
            ++columns[min(y, q)];
    }
    print_best(rows, k);
    print_best(columns, l);
    return 0;
}
```

### 易错点

横通道编号来自行，纵通道来自列；选完按位置输出，不按收益顺序输出。
