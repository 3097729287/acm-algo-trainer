## 兔子的序列

### 题意

输出序列中最大的非完全平方数。

### 思路

对每个数求整数平方根 r，若 r*r 不等于原数，它就是候选，维护最大候选即可。输入不超过一千，普通 sqrt 的结果转整数足够，最后仍用平方检验。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int ans = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        int r = sqrt(x);
        if (r * r != x)
            ans = max(ans, x);
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

一是完全平方数。题目保证至少存在一个非平方数。
