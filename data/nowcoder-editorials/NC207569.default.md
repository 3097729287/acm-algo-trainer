## 牛牛爱奇数

### 思路

从最大的偶数开始操作。同一数值的所有副本能一次一起处理；先处理较大值，能让它们除二后与较小值合并，再一起操作。若先处理较小值，则未来可能需要为到达这个值的数重复付费，所以交换为降序处理不会更差。用大根堆去掉同值副本，每个不同堆顶计一次操作，除二后仍偶数才入堆。

### 参考代码

原站采用函数接口，保留指定方法 `oddNumber`。

```cpp
#include <bits/stdc++.h>
using namespace std;
class Solution {
  public:
    int oddNumber(int n, vector<int> &a) {
        (void)n;
        vector<int> even;
        for (int x : a)
            if (x % 2 == 0)
                even.push_back(x);
        sort(even.begin(), even.end());
        even.erase(unique(even.begin(), even.end()), even.end());
        priority_queue<int> heap(even.begin(), even.end());
        int answer = 0;
        while (!heap.empty()) {
            int x = heap.top();
            heap.pop();
            if (!heap.empty() && heap.top() == x)
                continue;
            answer++;
            x /= 2;
            if (x % 2 == 0)
                heap.push(x);
        }
        return answer;
    }
};
```

### 复杂度

每个偶数每次至少减半，记生成的不同偶数状态数为 $K$。时间 $O(n\log n+K\log n)$，空间 $O(n)$。

### 易错点

一次处理全部相同值；奇数无需入堆。输入的方括号样例由平台驱动读取，提交代码只提供类和函数。
