## [NOIP2018]货币系统

### 题意

删减或重建无限货币面额，保留可表示的全部金额，求最少面额数。

### 思路

先排序面额，从小到大检查。若当前面额x已可由更小保留面额组成，它可以删除，所有使用x的表示都能替换。若不能组成，就必须加入：任意等价系统中用于组成x的面额均≤x，且它们自己也必须能由原系统表示；若不直接用x，只可能来自比x更小的原面额，矛盾。加入新面额后正序做完全背包可达性，更新到最大原面额即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        vector<int> a(n);
        for (int &x : a)
            cin >> x;
        sort(a.begin(), a.end());
        int limit = a.back(), answer = 0;
        vector<bool> can(limit + 1);
        can[0] = true;
        for (int x : a)
            if (!can[x]) {
                answer++;
                for (int s = x; s <= limit; s++)
                    can[s] = can[s] || can[s - x];
            }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n+nA)$，空间 $O(A)$，$A\le25000$。

### 易错点

每种面额无限张，更新要正序。重复面额会自然被可达性去掉，不会重复计数。
