## 吐泡泡

### 题意

从左到右处理小泡泡合并、大泡泡消除，输出稳定后的泡泡串。

### 思路

用字符串作栈，保持栈内已经不能变化。加入新字符后，若栈顶两项相同，就弹出这两项；两个小 o 还需压入一个大 O，两个大 O 则直接消失。新形成的大 O 可能继续与前一个相消，所以反复检查，直到末尾稳定。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        string s, st;
        cin >> s;
        for (char c : s) {
            st += c;
            while (st.size() >= 2 && st.back() == st[st.size() - 2]) {
                char last = st.back();
                st.pop_back();
                st.pop_back();
                if (last == 'o')
                    st += 'O';
            }
        }
        cout << st << '\n';
    }
    return 0;
}
```

### 复杂度

每次变化缩短序列，摊还时间 $O(|S|)$，栈空间 $O(|S|)$。

### 易错点

合并后必须继续处理连锁变化，不能只替换一次相邻字符。大小写分别表示两类泡泡。
