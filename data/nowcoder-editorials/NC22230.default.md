## 回型矩阵

### 题意

从左上角向右开始，顺时针螺旋填入一到 n²。

### 思路

保存当前坐标和方向，按右、下、左、上的次序移动。如果下一步越界或已填过，就顺时针转一次。每次放入下一个整数，因此所有格子恰好填一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    int row = 0, col = 0, direction = 0;
    int dr[] = {0, 1, 0, -1}, dc[] = {1, 0, -1, 0};
    for (int value = 1; value <= n * n; value++) {
        a[row][col] = value;
        int x = row + dr[direction], y = col + dc[direction];
        if (x < 0 || x >= n || y < 0 || y >= n || a[x][y]) {
            direction = (direction + 1) % 4;
            x = row + dr[direction];
            y = col + dc[direction];
        }
        row = x;
        col = y;
    }
    for (auto &r : a) {
        for (int j = 0; j < n; j++) {
            if (j)
                cout << ' ';
            cout << r[j];
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间与矩阵空间均为 $O(n^2)$。

### 易错点

必须在访问下一格之前检查是否越界。零作为未填标记，因为真正填入的数从一开始。
