## 小A的回文串

### 题意

允许把前缀移到末尾，最大化旋转后某个回文子串的长度。

### 思路

令T=S+S。S任意旋转是T中一个长度n的窗口；反过来，T中任何长度不超过n的连续段，都能放入某个这样的窗口（越过第二份起点的段可整体左移n）。因此只需找T中长度不超过n的最长回文。

Manacher 的 odd[i] 表示以 i 为中心、包含中心的最大奇回文半径，长度为 2odd[i]-1；even[i] 表示中心在 i-1 与 i 之间的最大偶回文半径，长度为 2even[i]。维护已知最靠右的回文区间，利用镜像位置的半径初始化，再只向未知部分扩展。右边界只会前进，全部扩展次数为线性。

奇、偶回文分别把长度截到不超过n的最大同奇偶长度，取最大即可。截短同中心回文仍是回文，故不需要重新验证。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct PalindromeRadii {
    vector<int> odd, even;
    explicit PalindromeRadii(const string &s) {
        int n = s.size();
        odd.resize(n);
        even.resize(n);
        int left = 0, right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 1 : min(odd[left + right - i], right - i + 1);
            while (i - k >= 0 && i + k < n && s[i - k] == s[i + k])
                k++;
            odd[i] = k;
            if (i + k - 1 > right) {
                left = i - k + 1;
                right = i + k - 1;
            }
        }
        left = 0;
        right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 0 : min(even[left + right - i + 1], right - i + 1);
            while (i - k - 1 >= 0 && i + k < n && s[i - k - 1] == s[i + k])
                k++;
            even[i] = k;
            if (i + k - 1 > right) {
                left = i - k;
                right = i + k - 1;
            }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    int n = s.size();
    string doubled = s + s;
    PalindromeRadii p(doubled);
    int oddLimit = n % 2 ? n : n - 1, evenLimit = n % 2 ? n - 1 : n, answer = 1;
    for (int i = 0; i < 2 * n; i++) {
        answer = max(answer, min(2 * p.odd[i] - 1, oddLimit));
        answer = max(answer, min(2 * p.even[i], evenLimit));
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

不能允许回文超过原串长度。截断奇回文与偶回文时要分别保留奇偶性。
