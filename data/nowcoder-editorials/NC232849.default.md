## 一起玩音游

### 题意

独立O/X序列，每段连续O长度平方，求分数期望。

### 思路

设上一位置末尾连续O长度为L，本次成功会把对应段贡献从L²变成(L+1)²，增量2L+1；失败时总分不变、末尾长度清零。只维护末尾长度期望len：本次分数期望增加p*(2len+1)，之后len=p*(len+1)。利用期望线性性，不需要二阶矩。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long double length = 0, answer = 0;
    while (n--) {
        long double p;
        cin >> p;
        answer += p * (2 * length + 1);
        length = p * (length + 1);
    }
    cout << fixed << setprecision(12) << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，空间 $O(1)$。

### 易错点

先用旧len计算分数增量，再更新len。失败不会扣除此前已获得的连续段分数。
