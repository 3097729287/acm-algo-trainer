## [NOIP2009]靶形数独

### 题意

满足数独约束的所有填法中，最大化数字乘靶形格子权值的总和。

### 思路

用行、列、宫位集求候选，每次选候选最少的空格搜索。格子权值为6+min(行号,列号,8−行号,8−列号)，中心恰为10。所有格填满时更新最大总分，不能找到首个解就退出。优先尝试大数字便于较早找到高分。

对当前每个空格，取其候选中最大数字乘该格权值，加到已确定得分，得到乐观上界。忽略空格之间的冲突只会高估，若这个上界仍不超过已知最好分数，就可剪枝。无候选也立即剪枝。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Sudoku {
    int board[81] = {}, row[9] = {}, column[9] = {}, block[9] = {}, best = -1;
    bool first = false, consistent = true;
    int weight(int p) {
        int r = p / 9, c = p % 9;
        return 6 + min({r, c, 8 - r, 8 - c});
    }
    int box(int p) { return p / 27 * 3 + p % 9 / 3; }
    int choices(int p) { return 511 & ~(row[p / 9] | column[p % 9] | block[box(p)]); }
    void toggle(int p, int digit) {
        int bit = 1 << (digit - 1);
        row[p / 9] ^= bit;
        column[p % 9] ^= bit;
        block[box(p)] ^= bit;
    }
    bool search(int score) {
        int selected = -1, mask = 0, fewest = 10, upper = score;
        for (int p = 0; p < 81; p++)
            if (!board[p]) {
                int options = choices(p), count = __builtin_popcount((unsigned)options);
                if (!count)
                    return false;
                upper += (32 - __builtin_clz((unsigned)options)) * weight(p);
                if (count < fewest) {
                    fewest = count;
                    selected = p;
                    mask = options;
                }
            }
        if (selected == -1) {
            best = max(best, score);
            return first;
        }
        if (!first && upper <= best)
            return false;
        for (int digit = 9; digit >= 1; digit--)
            if (mask >> (digit - 1) & 1) {
                board[selected] = digit;
                toggle(selected, digit);
                if (search(score + digit * weight(selected)))
                    return true;
                toggle(selected, digit);
                board[selected] = 0;
            }
        return false;
    }
    void solve() {
        int score = 0;
        for (int p = 0; p < 81; p++)
            if (board[p]) {
                if (!(choices(p) >> (board[p] - 1) & 1)) {
                    consistent = false;
                    return;
                }
                toggle(p, board[p]);
                score += board[p] * weight(p);
            }
        search(score);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    Sudoku solver;
    for (int &x : solver.board)
        cin >> x;
    solver.solve();
    cout << solver.best;
    return 0;
}
```

### 复杂度

空格数 $E\le57$，保守时间上界 $O(81\cdot9^E)$，实际依赖约束传播和上界剪枝；栈空间 $O(E)$。

### 易错点

给定数字同样计分。不同解可能得分不同，必须搜索全部未被合法上界剪掉的分支；无解输出−1。
