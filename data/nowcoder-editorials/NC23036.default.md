## 华华听月月唱歌

### 题意

选最少闭整数区间，使并集覆盖一到 N 的所有整数点。

### 思路

维护下一处未覆盖整数 need，初始为一。把左端点不超过 need 的所有片段读入，选择其中右端点最远的一段；若最远仍小于 need，说明无法覆盖。否则使用一次片段并令 need=最远右端+1。任何可行方案都必须用一段覆盖 need，选更远的段只会留下更短的待覆盖后缀，因此贪心成立。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    int m;
    cin >> n >> m;
    vector<pair<long long, long long>> segments(m);
    for (auto &[l, r] : segments)
        cin >> l >> r;
    sort(segments.begin(), segments.end());
    long long need = 1;
    int next = 0, answer = 0;
    while (need <= n) {
        long long farthest = need - 1;
        while (next < m && segments[next].first <= need) {
            farthest = max(farthest, segments[next].second);
            next++;
        }
        if (farthest < need) {
            cout << -1;
            return 0;
        }
        answer++;
        need = farthest + 1;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(m\log m)$，空间 $O(m)$。

### 易错点

只关注整数，所以 [1,2] 与 [3,4] 可以无缝覆盖一到四；下一目标是 r+1，而不是 r。
