## lcryin的排序题

### 题意

按点到原点的距离平方递增输出坐标及距离平方。

### 思路

平方距离为 x²+y²，与真实距离具有相同大小顺序，无须开根。坐标可接近一百万，平方距离用 long long；稳定排序让同距点保留输入顺序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Point {
        long long x, y, distance;
    };
    vector<Point> a(n);
    for (auto &p : a) {
        cin >> p.x >> p.y;
        p.distance = p.x * p.x + p.y * p.y;
    }
    stable_sort(a.begin(), a.end(),
                [](const Point &a, const Point &b) { return a.distance < b.distance; });
    for (auto p : a)
        cout << p.x << ' ' << p.y << ' ' << p.distance << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，数组空间 $O(n)$。

### 易错点

只把距离变量声明为 long long 还不够，参与乘法的坐标也要先使用 long long。
