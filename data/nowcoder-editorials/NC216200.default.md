## 年轻人不讲5的

### 题意

把数字字符串中的所有字符五改为星号。

### 思路

字符串可能有一百万位，无法存进整数类型。逐字符检查，遇到字符五就替换成星号，其余位置保持原样。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    for (char &c : s)
        if (c == '5')
            c = '*';
    cout << s;
    return 0;
}
```

### 复杂度

时间与字符串空间均为 $O(|s|)$。

### 易错点

需要修改字符串中的字符时使用引用 char&，不能只修改循环变量的副本。
