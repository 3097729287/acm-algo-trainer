## 可编程拖拉机比赛

### 题意

奖牌数量从按比例下取整改为上取整，分别求跨金银、银铜、铜铁边界的人数。

### 思路

令 dg、ds、db 分别为三种奖牌数量上取整比下取整多出的数量，各为零或一。金牌边界后移 dg 位；银牌尾部边界由金银总数决定，后移 dg+ds 位；铜牌尾部边界后移 dg+ds+db 位。原本紧邻边界之后的这些队伍分别得到升级。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int dg = n % 10 != 0, ds = (2 * n) % 10 != 0, db = (3 * n) % 10 != 0;
    cout << dg << ' ' << dg + ds << ' ' << dg + ds + db;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

第二项不是只看银牌增加几枚，还包含金牌增加导致整个银牌区间向后移动的影响。
