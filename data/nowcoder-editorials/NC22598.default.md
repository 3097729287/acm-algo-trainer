## Rinne Loves Edges

### 题意

删除带权树边，让指定点S与所有其他原始叶子断开，最小化删除费用。

### 思路

备注明确M=N−1且连通，因此实际是树。以S为根，处理孩子v方向有两个选择：切掉父子边，付边权；保留它，则必须在v子树内切断全部原叶子，付dp[v]。取较小值后各方向相加。若v本身就是原始叶子，它没有可在下方切的边，必须直接切父子边，不能误用空子树代价0。指定S即使原度为1也不作为要隔离的终端。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, s;
    cin >> n >> m >> s;
    Tree tree(n);
    while (m--) {
        int a, b;
        long long w;
        cin >> a >> b >> w;
        tree.add(a - 1, b - 1, w);
    }
    tree.root(s - 1);
    vector<long long> dp(n);
    for (int i = n - 1; i >= 0; i--) {
        int u = tree.order[i];
        __int128 sum = 0;
        for (auto [v, w] : tree.edge[u])
            if (v != tree.parent[u])
                sum += tree.edge[v].size() == 1 ? w : min(w, dp[v]);
        dp[u] = (long long)min(sum, (__int128)numeric_limits<long long>::max());
    }
    cout << dp[s - 1];
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

叶子按删边前的度数定义。边权和可能有较大中间值，内部累加用128位并饱和到64位上界，根答案保证可装入64位。
