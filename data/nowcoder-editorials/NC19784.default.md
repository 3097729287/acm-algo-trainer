## Shopping

### 题意

最多 m 辆购物车，每辆含凳子的车可将最贵的一件商品半价。

### 思路

设凳子有 s 件，最多可得到 k=min(m,s) 次折扣。任意方案省下的钱不超过全体最贵 k 件价格之和的一半。这个上界可达：给这 k 件商品各放一辆车，若某件本身是凳子就已有资格，否则从剩余凳子中给它配一件。因为总凳子数至少 k，必能配齐；剩余商品都不比这 k 件贵，放进其中任一车不会降低折扣。没有凳子时原价购买。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n, m, stools = 0;
        cin >> n >> m;
        vector<long long> prices(n);
        long long total = 0;
        for (auto &price : prices) {
            int isStool;
            cin >> price >> isStool;
            total += price;
            stools += isStool;
        }
        sort(prices.begin(), prices.end(), greater<long long>());
        long long twice = 2 * total;
        for (int i = 0; i < min(m, stools); i++)
            twice -= prices[i];
        cout << twice / 2 << (twice % 2 ? ".5\n" : ".0\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

凳子本身也可成为半价商品。用金额的两倍做整数运算，避免浮点格式误差；购物车不要求全都使用。
