## [HAOI2010]最长公共子序列

### 题意

求LCS长度及匹配方案数模一亿。

### 思路

长度f[i][j]按标准LCS求。计数g[i][j]汇总所有达到该长度的来源：若末字符相同，加入对角子问题的匹配方案；若上方或左方长度也等于当前最优，分别加入它们。上、左共有的对角方案若长度同样最优，要减去一次避免重复。空前缀的空匹配计数为1。

这里计数按两串中选取的位置区分。样例最长长度4，不同字面字符串只有5种，但有7组位置匹配，所以不能用“不同LCS字符串”算法代替。滚动两行保存长度和计数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string a, b;
    cin >> a >> b;
    if (!a.empty() && a.back() == '.')
        a.pop_back();
    if (!b.empty() && b.back() == '.')
        b.pop_back();
    int n = a.size(), m = b.size();
    const int mod = 100000000;
    vector<int> previousLength(m + 1), currentLength(m + 1), previousCount(m + 1, 1),
        currentCount(m + 1, 1);
    for (int i = 1; i <= n; i++) {
        currentLength[0] = 0;
        currentCount[0] = 1;
        for (int j = 1; j <= m; j++) {
            int best = max(previousLength[j], currentLength[j - 1]);
            if (a[i - 1] == b[j - 1])
                best = max(best, previousLength[j - 1] + 1);
            long long count = 0;
            if (a[i - 1] == b[j - 1] && previousLength[j - 1] + 1 == best)
                count += previousCount[j - 1];
            if (previousLength[j] == best)
                count += previousCount[j];
            if (currentLength[j - 1] == best)
                count += currentCount[j - 1];
            if (previousLength[j - 1] == best)
                count -= previousCount[j - 1];
            currentLength[j] = best;
            currentCount[j] = (count % mod + mod) % mod;
        }
        previousLength.swap(currentLength);
        previousCount.swap(currentCount);
    }
    cout << previousLength[m] << '\n' << previousCount[m];
    return 0;
}
```

### 复杂度

时间 $O(nm)$，空间 $O(m)$。

### 易错点

字符串末尾点号是终止符，不能参与LCS。减法后取非负模；空LCS有一种空匹配。
