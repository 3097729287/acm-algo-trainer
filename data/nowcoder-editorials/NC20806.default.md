## 区区区间间间

### 题意

累计所有长度至少二的区间中，最大值减最小值的总和。

### 思路

区间价值就是 max-min，可分别累计所有区间最大值、最小值，再相减。计算最大值贡献时，让每个区间归属于其中最右边的最大元素 j。设左侧首个严格更大位置为 L，右侧首个大于等于的位置为 R，则左端有 j-L 种选法、右端有 R-j 种，贡献 a[j]*(j-L)*(R-j)。用递减栈，遇到大于等于栈顶的当前值就弹出并结算，恰好得到这两个边界。最小值将比较反过来。单元素区间的最大最小相同，会自行抵消，可以一起统计。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long contribution(const vector<long long> &a, bool maximum) {
    int n = a.size();
    vector<int> stack;
    long long answer = 0;
    for (int i = 0; i <= n; i++) {
        while (!stack.empty() &&
               (i == n || (maximum ? a[stack.back()] <= a[i] : a[stack.back()] >= a[i]))) {
            int j = stack.back();
            stack.pop_back();
            int left = stack.empty() ? -1 : stack.back();
            answer += a[j] * (j - left) * (i - j);
        }
        if (i < n)
            stack.push_back(i);
    }
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        vector<long long> a(n);
        for (auto &x : a)
            cin >> x;
        cout << contribution(a, true) - contribution(a, false) << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n)$。

### 易错点

左右不能都用严格比较，否则重复最值会被重复归属或遗漏。当前实现统一归给最右边的相同最值；计数乘积与总和使用 long long。
