## I love you

### 题意

忽略大小写，统计 iloveyou 作为子序列的出现次数，并对 20010905 取模。

### 思路

dp[j] 表示已处理前缀能选出目标前 j 个字母的方案数，dp[0]=1。读入字符 c 后，若它匹配目标第 j 个字母，就把原 dp[j-1] 加到 dp[j]。j 从八往一倒序更新，确保当前字符在一次选择中只用一次；不选当前字符的方案保留在原 dp[j] 中。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int mod = 20010905;
    string s, target = "iloveyou";
    cin >> s;
    int dp[9] = {1};
    for (unsigned char raw : s) {
        char c = tolower(raw);
        for (int j = 8; j >= 1; j--)
            if (c == target[j - 1])
                dp[j] = (dp[j] + dp[j - 1]) % mod;
    }
    cout << dp[8];
    return 0;
}
```

### 复杂度

目标长度固定为八，时间 $O(8|S|)$，DP 额外空间 $O(1)$。

### 易错点

子序列不要求连续，但所选下标必须递增。目标中的两个 o 分别属于不同匹配阶段，不能只统计字母频次后相乘。
