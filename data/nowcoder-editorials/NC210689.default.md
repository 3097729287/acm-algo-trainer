## 区间价值

### 题意

预处理所有窗口长度的不同数总数，百万次询问。

### 思路

对每个出现过的数x，长度L窗口一共n−L+1个，其中不含x的窗口必完全位于相邻x之间（含首尾）的空隙。长g空隙能放max(0,g−L+1)个窗口。因此答案=不同数个数*(n−L+1)−Σ(g≥L)countGap[g]*(g−L+1)。

扫描数组记录每个数上次位置，统计前方和中间空隙；最后补尾部空隙。对空隙长度做后缀个数、后缀长度和，可常数时间求上式并预处理全部L。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    const int limit = 1000000;
    vector<int> previous(limit + 1);
    vector<long long> gap(n + 1);
    int distinct = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        if (!previous[x])
            distinct++;
        gap[i - previous[x] - 1]++;
        previous[x] = i;
    }
    for (int x = 1; x <= limit; x++)
        if (previous[x])
            gap[n - previous[x]]++;
    vector<long long> answer(n + 1);
    long long count = 0, length = 0;
    for (int l = n; l >= 1; l--) {
        count += gap[l];
        length += gap[l] * l;
        answer[l] = 1LL * distinct * (n - l + 1) - (length - (l - 1) * count);
    }
    int q;
    cin >> q;
    while (q--) {
        int l;
        cin >> l;
        cout << answer[l] << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n+U+q)$，空间 $O(n+U)$。

### 易错点

只统计实际出现过的数；每个数首尾空隙都需加入。总价值可超过32位。
