## [CQOI2009]中位数图

### 题意

1到n的排列，统计奇数长度连续段中位数为b的数量。

### 思路

b只出现一次，合格区间必含其位置p。将大于b的数记+1、小于b记−1，b记0，中位数为b恰是区间总和0，因为左右两类数量相等，也自然保证总长度为奇数。枚举从p往左扩展的平衡值，统计各值出现次数（含只留p的平衡0）；再从p向右扩展，当前平衡为x时，左侧需−x，将其频次加入答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, b;
    cin >> n >> b;
    vector<int> a(n);
    int position = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] == b)
            position = i;
    }
    vector<long long> count(2 * n + 1);
    count[n] = 1;
    int balance = 0;
    for (int i = position - 1; i >= 0; i--) {
        balance += a[i] > b ? 1 : -1;
        count[n + balance]++;
    }
    long long answer = count[n];
    balance = 0;
    for (int i = position + 1; i < n; i++) {
        balance += a[i] > b ? 1 : -1;
        answer += count[n - balance];
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

只统计平衡0，不要套用下中位数计数中的平衡0或1。先将空左侧计一次，避免漏掉从b开始的区间。
