## 小魂和他的数列

### 题意

统计长度K的严格递增下标子序列，n至五十万。

### 思路

设dp[len][i]为以第i项结尾、长len的严格递增子序列数，转移是所有之前值小于a[i]的dp[len−1]之和。值离散化，对每个长度维护一棵树状数组，查询rank−1前缀并把结果加到当前rank。长度倒序更新，最后插入长1的一种方案。长度K的总数单独累加。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> a(n), coordinate;
    for (int &x : a)
        cin >> x;
    coordinate = a;
    sort(coordinate.begin(), coordinate.end());
    coordinate.erase(unique(coordinate.begin(), coordinate.end()), coordinate.end());
    int size = coordinate.size();
    constexpr int mod = 998244353;
    vector<vector<int>> bit(k + 1, vector<int>(size + 1));
    auto addValue = [&](int len, int p, int value) {
        for (; p <= size; p += p & -p) {
            bit[len][p] += value;
            if (bit[len][p] >= mod)
                bit[len][p] -= mod;
        }
    };
    auto prefix = [&](int len, int p) {
        int result = 0;
        for (; p; p -= p & -p) {
            result += bit[len][p];
            if (result >= mod)
                result -= mod;
        }
        return result;
    };
    int answer = 0;
    for (int x : a) {
        int rank = lower_bound(coordinate.begin(), coordinate.end(), x) - coordinate.begin() + 1;
        for (int len = k; len >= 2; len--) {
            int value = prefix(len - 1, rank - 1);
            addValue(len, rank, value);
            if (len == k) {
                answer += value;
                if (answer >= mod)
                    answer -= mod;
            }
        }
        addValue(1, rank, 1);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(nK\log n)$，空间 $O(nK)$。

### 易错点

相同值不能接在一起，查询到rank−1。相同数值但不同下标的选择属于不同子序列。
