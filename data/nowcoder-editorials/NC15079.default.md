## 大水题

### 题意

求1到n中不被2、5、11、13整除的数的数量，多组至10^18。

### 思路

从全部n个数出发，对非空质数子集做容斥。子集中每个质数都整除的数，共有floor(n/子集乘积)个。奇数大小子集减去，偶数大小子集加回；只有15个子集，所有乘积至1430。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    const int prime[] = {2, 5, 11, 13};
    while (cin >> n) {
        long long answer = n;
        for (int mask = 1; mask < 16; mask++) {
            int product = 1;
            for (int i = 0; i < 4; i++)
                if (mask >> i & 1)
                    product *= prime[i];
            if (__builtin_popcount((unsigned)mask) & 1)
                answer -= n / product;
            else
                answer += n / product;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(2^4\cdot4)$，空间 $O(1)$。

### 易错点

输入一直读到EOF。n及答案使用64位，不能只减四种倍数而忽略交集。
