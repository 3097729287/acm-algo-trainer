## [NOIP2006]开心的金明

题源：[洛谷原题](https://www.luogu.com.cn/problem/P1060)。

### 题意

总预算有限，每件商品只能买一次。已知价格和重要度，要求价格×重要度的总和最大，总花费不超过预算。



### 怎么从题面想到这个模型

先用题目要最大化的表达式定义价值，再决定转移加什么。

价格决定一个组合是否合法，价格乘重要度决定组合之间谁更好。这两个量必须分开；重要度更高不保证组合收益更大。加入一件商品时，扣掉的是 price，增加的是 price×importance。保留原值和来源加新收益覆盖全部方案，按每件仅一次的旧值依赖倒序更新。

### 先用小数据确认目标

这是教学小例，不是原题样例。预算为 10，三件商品的 (价格,重要度) 分别为 (6,4)、(4,5)、(5,3)。

预算 10，表中三件商品的最大收益是多少？

买价格 6 和 4 的两件，收益是 6×4+4×5=44。重要度之和 9 不是本题目标。

### 从基础背包改到本题

dp[c]：花费不超过 c 的最大收益。当前价格 price，重要度 importance。

```cpp
dp[c] = max(dp[c], dp[c - price] + price * importance);
```

先扣价格得到剩余预算，再把题目定义的收益 price×importance 加回。

所有 dp 初始为 0：不购物花费 0，收益 0。每件商品一轮，c 从总预算 N 倒序到 price。输出 dp[N]。

时间 O(mN)，空间 O(N)；N<30000，m<25。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int N, m;
    if (!(cin >> N >> m))
        return 0;
    vector<int> dp(N + 1, 0);
    for (int i = 0; i < m; i++) {
        int price, importance;
        cin >> price >> importance;
        for (int c = N; c >= price; --c)
            dp[c] = max(dp[c], dp[c - price] + price * importance);
    }
    cout << dp[N] << '\n';
}
```

### 代码出错时，先缩小到这组数据

如果转移只加重要度？

预算 10，商品为 (价格 6，重要度 4)、(4，5)。

错误程序得到 4+5=9，正确目标是 6×4+4×5=44。用只有一两件商品的数据，就能检查收益有没有翻译对。

其余边界：一件商品，预算刚好够：收益是价格×重要度；价格高但买不起的商品不能贡献收益；不要把价格与重要度读反，也不要求花光预算。
