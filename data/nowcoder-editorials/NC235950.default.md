## 多重背包

### 题意

每种有限个物品，容量至100，最大价值。

### 思路

按物品种类逐层转移。用旧dp副本保留不选，对每个旧容量和数量1..x枚举，不能超过总容量。只从旧数组转移，保证同一类最多取x件。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, capacity;
    cin >> n >> capacity;
    vector<int> dp(capacity + 1);
    while (n--) {
        int count, weight, value;
        cin >> count >> weight >> value;
        auto next = dp;
        for (int used = 0; used <= capacity; used++)
            for (int k = 1; k <= count && used + k * weight <= capacity; k++)
                next[used + k * weight] = max(next[used + k * weight], dp[used] + k * value);
        dp.swap(next);
    }
    cout << *max_element(dp.begin(), dp.end());
    return 0;
}
```

### 复杂度

时间 $O(nT\max x)$，空间 $O(T)$。

### 易错点

输入顺序是数量、重量、价值。容量不要求恰好用满。
