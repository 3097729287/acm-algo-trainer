## 游戏

### 题意

给定朋友有向图，批量询问恰好m次传球从a到b的方案数。

### 思路

邻接矩阵A[i][j]表示一步从i到j的方案数。矩阵乘法按中间接球者k枚举，故A^m[i][j]恰好是走m条边的方案数。m对所有询问相同，先用快速幂计算整个矩阵，再每问常数时间取值。m=0时单位矩阵表示不传球。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using Matrix = vector<vector<long long>>;
constexpr long long MOD = 1000000007;
Matrix multiply(const Matrix &a, const Matrix &b) {
    int n = a.size();
    Matrix result(n, vector<long long>(n));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++)
            if (a[i][k])
                for (int j = 0; j < n; j++)
                    result[i][j] = (result[i][j] + a[i][k] * b[k][j]) % MOD;
    return result;
}
vector<long long> applyMatrix(const Matrix &a, const vector<long long> &v) {
    int n = a.size();
    vector<long long> result(n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            result[i] = (result[i] + a[i][j] * v[j]) % MOD;
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q, n;
    unsigned long long m;
    cin >> q >> n >> m;
    Matrix base(n, vector<long long>(n)), answer(n, vector<long long>(n));
    for (auto &row : base)
        for (auto &x : row) {
            cin >> x;
            x = x != 0;
        }
    for (int i = 0; i < n; i++)
        answer[i][i] = 1;
    while (m) {
        if (m & 1)
            answer = multiply(answer, base);
        m >>= 1;
        if (m)
            base = multiply(base, base);
    }
    while (q--) {
        int a, b;
        cin >> a >> b;
        cout << answer[a - 1][b - 1] << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n^3\log(m+1)+Q)$，空间 $O(n^2)$。

### 易错点

朋友关系有向，不能对称补边；恰好m步与至多m步不同。每人每轮必须传球，不额外加入自环。
