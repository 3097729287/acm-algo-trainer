## 字符串输出1.0

### 题意

分三行输出 Welcome to ACM / ICPC!，不含引号。

### 思路

相同内容需要重复三次，用循环控制次数。每次完整输出一句并换行，不在单词或斜杠两侧遗漏空格。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    for (int i = 0; i < 3; i++)
        cout << "Welcome to ACM / ICPC!\n";
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

ACM、ICPC 使用大写字母，斜杠两侧各有一个空格。
