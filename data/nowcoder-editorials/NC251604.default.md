## 四值零和

### 题意

四列各选一个元素，统计四项和为零的不同下标四元组。

### 思路

枚举前两列所有 n² 个和放入 left，后两列同理放入 right，分别排序。一个指针从 left 最小值出发，另一个从 right 最大值出发：和为负就增大左指针，和为正就减小右指针；和为零时统计两边当前值各自的重复次数，乘起来加入答案，再跳过整组重复值。每组下标选择恰对应一次和的配对。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<int, 4>> a(n);
    for (auto &row : a)
        for (int &x : row)
            cin >> x;
    vector<int> left, right;
    left.reserve((size_t)n * n);
    right.reserve((size_t)n * n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) {
            left.push_back(a[i][0] + a[j][1]);
            right.push_back(a[i][2] + a[j][3]);
        }
    sort(left.begin(), left.end());
    sort(right.begin(), right.end());
    int i = 0, j = (int)right.size() - 1;
    long long answer = 0;
    while (i < (int)left.size() && j >= 0) {
        long long sum = (long long)left[i] + right[j];
        if (sum < 0)
            i++;
        else if (sum > 0)
            j--;
        else {
            int x = left[i], y = right[j];
            long long cx = 0, cy = 0;
            while (i < (int)left.size() && left[i] == x) {
                i++;
                cx++;
            }
            while (j >= 0 && right[j] == y) {
                j--;
                cy++;
            }
            answer += cx * cy;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n^2\log n)$，空间 $O(n^2)$，两和数组在上限约占五十兆字节。

### 易错点

和相同但下标不同也算不同四元组，不能只算不同数值。单个两数和可存 int，总方案数用 long long。
