## 走出迷宫

### 题意

判断四方向移动能否从S到E，不能通过井号格。

### 思路

从S开始BFS，把所有尚未访问且不是障碍的相邻格入队。每个格只入队一次，搜索结束检查E是否被访问。只求存在性，深搜也可以，但大地图用队列避免递归栈过深。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    while (cin >> n >> m) {
        vector<string> grid(n);
        int start = -1, target = -1;
        for (int r = 0; r < n; r++) {
            cin >> grid[r];
            for (int c = 0; c < m; c++) {
                if (grid[r][c] == 'S')
                    start = r * m + c;
                if (grid[r][c] == 'E')
                    target = r * m + c;
            }
        }
        vector<bool> seen(n * m);
        vector<int> queue{start};
        seen[start] = true;
        const int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
        for (size_t head = 0; head < queue.size(); head++) {
            int r = queue[head] / m, c = queue[head] % m;
            for (int d = 0; d < 4; d++) {
                int rr = r + dr[d], cc = c + dc[d];
                if (rr >= 0 && rr < n && cc >= 0 && cc < m && grid[rr][cc] != '#' &&
                    !seen[rr * m + cc]) {
                    seen[rr * m + cc] = true;
                    queue.push_back(rr * m + cc);
                }
            }
        }
        cout << (seen[target] ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(nm)$。

### 易错点

多组输入直到EOF。入队时标记，避免同一格被多个方向重复入队。
