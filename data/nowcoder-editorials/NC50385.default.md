## 虫洞 Wormholes

### 题意

道路花正时间，虫洞倒退时间，判断图中任意位置是否存在可回到出发前的行程。

### 思路

给双向路加两条正权边，虫洞加一条负权有向边。回到出发前等价于存在负环。起点不限，所以将所有点初始距离设0，相当于超级源向全图连0边。Bellman-Ford若第N轮仍有松弛则有负环，提前一轮不变则无负环。只从1号点开始会漏掉其他连通块的虫洞环。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m, w;
        cin >> n >> m >> w;
        struct Edge {
            int a, b, w;
        };
        vector<Edge> edges;
        while (m--) {
            int a, b, c;
            cin >> a >> b >> c;
            edges.push_back({a - 1, b - 1, c});
            edges.push_back({b - 1, a - 1, c});
        }
        while (w--) {
            int a, b, c;
            cin >> a >> b >> c;
            edges.push_back({a - 1, b - 1, -c});
        }
        vector<long long> d(n);
        bool cycle = false;
        for (int round = 1; round <= n; round++) {
            bool changed = false;
            for (auto e : edges)
                if (d[e.b] > d[e.a] + e.w) {
                    d[e.b] = d[e.a] + e.w;
                    changed = true;
                }
            if (!changed)
                break;
            if (round == n)
                cycle = true;
        }
        cout << (cycle ? "YES\n" : "NO\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(N(2M+W))$，空间 $O(N+M+W)$。

### 易错点

虫洞时间输入是回退的正数，存边时取负。判断全图负环，不要求与某个指定起点连通。
