## 安卓图案解锁

### 题意

检查九宫格解锁路径是否重复使用数字，或越过了尚未使用的中间点。

### 思路

把一到九转成三乘三网格坐标。相邻两次选点若行坐标之和、列坐标之和均为偶数，连线中点恰好也是一个网格点；如果它不是两端点，就必须已经被访问。每一步还要检查当前点未曾使用，然后才打上访问标记。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    while (cin >> s) {
        bool used[10] = {}, ok = true;
        for (int i = 0; i < (int)s.size(); i++) {
            int current = s[i] - '0';
            if (used[current])
                ok = false;
            if (i > 0) {
                int previous = s[i - 1] - '0', r1 = (previous - 1) / 3, c1 = (previous - 1) % 3,
                    r2 = (current - 1) / 3, c2 = (current - 1) % 3;
                if ((r1 + r2) % 2 == 0 && (c1 + c2) % 2 == 0) {
                    int middle = (r1 + r2) / 2 * 3 + (c1 + c2) / 2 + 1;
                    if (middle != previous && middle != current && !used[middle])
                        ok = false;
                }
            }
            used[current] = true;
        }
        cout << (ok ? "YES" : "NO") << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(|S|)$，访问表空间 $O(1)$。

### 易错点

题面只规定这两条规则，不额外要求至少四个点。判断中点时，要使用本次选点之前的访问状态。
