## 【模板】KMP字符串匹配

### 题意

输出模式串在文本中所有出现位置，并输出模式每个前缀的最长 border 长度。

### 思路

前缀函数 pi[i] 记录前缀 s[0..i] 的最长相同真前后缀长度。失配时令已匹配长度 j=pi[j-1]，保留仍可能匹配的后缀；成功时 j 增一。每次回退都会减少 j，增长总数只与串长成正比，因此预处理和扫描均为线性。

先对模式串计算 pi，它本身就是最后一行所需答案。再扫描文本，维护当前匹配长度；达到整个模式长度时输出起点 i-|pattern|+2（一基编号），随后退到 pi[matched-1]，继续寻找可能重叠的出现。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

template <class Sequence> vector<int> prefixFunction(const Sequence &s) {
    int n = s.size();
    vector<int> pi(n);
    for (int i = 1; i < n; i++) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j])
            j = pi[j - 1];
        if (s[i] == s[j])
            j++;
        pi[i] = j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string text, pattern;
    cin >> text >> pattern;
    auto pi = prefixFunction(pattern);
    int matched = 0;
    for (int i = 0; i < (int)text.size(); i++) {
        while (matched > 0 && text[i] != pattern[matched])
            matched = pi[matched - 1];
        if (text[i] == pattern[matched])
            matched++;
        if (matched == (int)pattern.size()) {
            cout << i - (int)pattern.size() + 2 << '\n';
            matched = pi[matched - 1];
        }
    }
    for (int i = 0; i < (int)pi.size(); i++) {
        if (i)
            cout << ' ';
        cout << pi[i];
    }
    cout << '\n';
    return 0;
}
```

### 复杂度

文本长 $n$、模式长 $m$，时间 $O(n+m)$，前缀表空间 $O(m)$。

### 易错点

border 不含整个前缀本身。找到一次后不能清零匹配长度，否则会漏重叠匹配，例如 ABA 在 ABABA 中出现两次。
