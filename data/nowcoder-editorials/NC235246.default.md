## 田忌赛马

> 原题：[P1650](https://www.luogu.com.cn/problem/P1650)
> 解法：优先拿下可赢的两端对局 · C++17

### 题意

两方各有 $n$ 匹马，胜负收益分别为正负二百、平局零，求田忌能够取得的最大净收益。



### 思路

两方速度升序排好。自己的最快若能赢对方最快就配这对；否则自己的最慢若能赢对方最慢就配这对；两端都不能这样赢时，用自己最慢消耗对方最快，按实际胜负计分。

时间 $O(n\log n)$、空间 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n), b(n);
    for (int &x : a)
        cin >> x;
    for (int &x : b)
        cin >> x;
    sort(a.begin(), a.end());
    sort(b.begin(), b.end());
    int al = 0, ar = n - 1, bl = 0, br = n - 1, score = 0;
    while (al <= ar) {
        if (a[ar] > b[br]) {
            ++score;
            --ar;
            --br;
        } else if (a[al] > b[bl]) {
            ++score;
            ++al;
            ++bl;
        } else {
            score += (a[al] > b[br]) - (a[al] < b[br]);
            ++al;
            --br;
        }
    }
    cout << 200 * score << '\n';
    return 0;
}
```

### 易错点

允许速度相同，牺牲局也可能是平局；答案是净收益而非赢局数。
