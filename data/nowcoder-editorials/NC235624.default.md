## 牛可乐和最长公共子序列

### 题意

多组两个字符串，求LCS长度。

### 思路

f[i][j]表示前i、j字符的LCS长度。末字符相等时可由f[i−1][j−1]+1转移，否则从跳过其中一个末字符的两个状态取最大。仅依赖上一行和本行左方，滚动一维，另存被覆盖前的左上角值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s, t;
    while (cin >> s >> t) {
        vector<int> dp(t.size() + 1);
        for (char c : s) {
            int diagonal = 0;
            for (int j = 1; j <= (int)t.size(); j++) {
                int old = dp[j];
                if (c == t[j - 1])
                    dp[j] = diagonal + 1;
                else
                    dp[j] = max(dp[j], dp[j - 1]);
                diagonal = old;
            }
        }
        cout << dp.back() << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(|s||t|)$，空间 $O(|t|)$。

### 易错点

子序列不要求连续；输入直到EOF，每组重新初始化。
