## 【模板】牛牛学取余

### 题意

输出正整数 a 除以 b 的余数。

### 思路

正整数满足 a=(a/b)*b+a%b，其中余数在零到 b-1 之间。C++ 的百分号运算直接得到该余数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    cout << a % b << '\n';
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

能够整除时余数是零。
