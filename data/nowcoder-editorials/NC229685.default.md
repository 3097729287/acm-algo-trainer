## 模板题【线性筛求积性函数】

### 题意

批量求千万内整数的约数个数。

### 思路

d(n)=Π(e[p]+1)。线性筛维护约数数d以及最小质因子的指数e。若p不整除i，d(i*p)=2d(i)、e=1；若p整除i，则最小质因子仍为p，d(i*p)=d(i)/(e(i)+1)*(e(i)+2)、e加1并停止。用d=0表示尚未筛到的素数，素数设d=2。指数用8位、约数数用16位，降低千万规模内存。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    cin >> q;
    vector<int> query(q);
    int maximum = 1;
    for (int &n : query) {
        cin >> n;
        maximum = max(maximum, n);
    }
    vector<uint16_t> count(maximum + 1);
    vector<uint8_t> exponent(maximum + 1);
    vector<int> primes;
    count[1] = 1;
    for (int i = 2; i <= maximum; i++) {
        if (!count[i]) {
            primes.push_back(i);
            count[i] = 2;
            exponent[i] = 1;
        }
        for (int p : primes) {
            long long next = 1LL * i * p;
            if (next > maximum)
                break;
            if (i % p == 0) {
                exponent[next] = exponent[i] + 1;
                count[next] = count[i] / (exponent[i] + 1) * (exponent[i] + 2);
                break;
            }
            exponent[next] = 1;
            count[next] = count[i] * 2;
        }
    }
    for (int n : query)
        cout << count[n] << '\n';
    return 0;
}
```

### 复杂度

时间 $O(U+q)$，空间 $O(U+\pi(U)+q)$，主要数组约3U字节。

### 易错点

1有一个正因数。千万内约数个数远低于65535，但不能把约数数也存8位。
