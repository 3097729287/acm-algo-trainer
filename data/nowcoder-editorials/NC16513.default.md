## 无关(relationship)

### 题意

求[L,R]内不被集合中任一素数整除的数的数量。

### 思路

定义F(x)统计1..x内没有任何给定素因子的数，答案F(R)−F(L−1)。枚举质数子集并按奇偶容斥，交集大小为x/子集乘积。递归增加下标，若当前乘积已经大于x/下一个质数，则新交集及其全部扩展都为空，直接跳过，并避免64位乘法溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long l, r;
    int k;
    cin >> l >> r >> k;
    vector<long long> prime(k);
    for (auto &p : prime)
        cin >> p;
    sort(prime.begin(), prime.end());
    auto count = [&](long long x) {
        long long result = x;
        auto dfs = [&](auto &&self, int start, long long product, int sign) -> void {
            for (int i = start; i < k; i++) {
                if (product > x / prime[i])
                    break;
                long long next = product * prime[i];
                result += sign * (x / next);
                self(self, i + 1, next, -sign);
            }
        };
        dfs(dfs, 0, 1, -1);
        return result;
    };
    cout << count(r) - count(l - 1);
    return 0;
}
```

### 复杂度

最坏时间 $O(2^k)$，递归空间 $O(k)$。

### 易错点

集合元素保证是不同素数，交集的最小公倍数才等于乘积。L=1时F(0)=0，递归自然不进入。
