## Gregor and the Odd Cows (Easy)

### 题意

全部坐标为偶数时，统计内部格点数为奇数的三角形。

### 思路

把三个顶点都除以2，记缩小三角形边界格点数为$b$。原面积为缩小面积的4倍，一定是偶整数；原边界数为$2b$。由Pick定理，原内部点数$I=S-b+1$，故$I$为奇数当且仅当$b$为偶数。

一条缩小后的边gcd为偶数，当且仅当两个端点的x、y奇偶都相同。把点按(x mod2,y mod2)分4类：三个点全在同类，三条边gcd均偶，满足；恰好两类相同，两条奇边一条偶边，也满足；三个点分别来自三个不同类，三条奇边，不满足。因此答案是C(n,3)减去四种“三类各选一个”的乘积。无需枚举点对。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    long long count[4] = {};
    for (int i = 0; i < n; i++) {
        long long x, y;
        cin >> x >> y;
        count[((x / 2) & 1) * 2 + ((y / 2) & 1)]++;
    }
    long long answer = n * (n - 1) * (n - 2) / 6;
    for (int i = 0; i < 4; i++)
        for (int j = i + 1; j < 4; j++)
            for (int k = j + 1; k < 4; k++)
                answer -= count[i] * count[j] * count[k];
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

必须先将坐标除以2，再判断奇偶。原坐标本身全偶，直接分类会把所有点放进同一类。
