## [ZJOI2009]狼和羊的故事

### 题意

网格各有固定狼领地、羊领地或空地，添最短单位篱笆让狼羊无法相通。

### 思路

把每格分到狼侧或羊侧，固定狼格必须在狼侧、固定羊格必须在羊侧，空地可任意选择。相邻两格若分到不同侧，就在它们公共边加一段篱笆，费用1。因此建源点连狼格无穷容量边，羊格连汇点无穷容量边，每对相邻格连两个方向各容量1。任意有限s-t割都保持固定领地，并恰为一组合法隔离篱笆，割容量就是长度，故求最大流即最短篱笆。外边界已有篱笆，不另加费用。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Dinic {
    struct Edge {
        int to, reverse, capacity;
    };
    vector<vector<Edge>> graph;
    vector<int> level, current;
    explicit Dinic(int n) : graph(n), level(n), current(n) {}
    void add(int a, int b, int c) {
        int x = graph[a].size(), y = graph[b].size();
        graph[a].push_back({b, y, c});
        graph[b].push_back({a, x, 0});
    }
    bool bfs(int source, int sink) {
        fill(level.begin(), level.end(), -1);
        vector<int> queue{source};
        level[source] = 0;
        for (size_t h = 0; h < queue.size(); h++)
            for (auto e : graph[queue[h]])
                if (e.capacity && level[e.to] == -1) {
                    level[e.to] = level[queue[h]] + 1;
                    queue.push_back(e.to);
                }
        return level[sink] != -1;
    }
    int send(int u, int sink, int amount) {
        if (u == sink)
            return amount;
        for (int &i = current[u]; i < (int)graph[u].size(); i++) {
            auto &e = graph[u][i];
            if (e.capacity && level[e.to] == level[u] + 1) {
                int value = send(e.to, sink, min(amount, e.capacity));
                if (value) {
                    e.capacity -= value;
                    graph[e.to][e.reverse].capacity += value;
                    return value;
                }
            }
        }
        return 0;
    }
    int maximum(int source, int sink) {
        int total = 0;
        while (bfs(source, sink)) {
            fill(current.begin(), current.end(), 0);
            while (int value = send(source, sink, 1000000000))
                total += value;
        }
        return total;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols;
    cin >> rows >> cols;
    int source = rows * cols, sink = source + 1;
    Dinic flow(sink + 1);
    vector<int> type(source);
    for (int &x : type)
        cin >> x;
    const int inf = 1000000000;
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++) {
            int u = r * cols + c;
            if (type[u] == 1)
                flow.add(source, u, inf);
            if (type[u] == 2)
                flow.add(u, sink, inf);
            if (r + 1 < rows) {
                int v = u + cols;
                flow.add(u, v, 1);
                flow.add(v, u, 1);
            }
            if (c + 1 < cols) {
                int v = u + 1;
                flow.add(u, v, 1);
                flow.add(v, u, 1);
            }
        }
    cout << flow.maximum(source, sink);
    return 0;
}
```

### 复杂度

格点数 $V=nm$、邻边数 $E=O(V)$，一般Dinic最坏时间 $O(V^2E)$，实际由网格容量层次推进；空间 $O(V+E)$。

### 易错点

固定狼羊格不能互换，必须用足够大的容量锁定。相邻无向公共边建两条容量1有向边，割时只计狼侧到羊侧的一个方向。
