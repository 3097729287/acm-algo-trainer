## [NOIP2014]飞扬的小鸟

### 题意

点击可反复上升、无点击则下降，管道只准严格穿缝，求最少点击或失败前过管数。

### 思路

dp[h]为到当前横坐标、位于高度h的最少点击数，最左边任意合法高度初值0。进入下一列先处理至少一次点击：由旧dp[h]点击一次，到min(m,h+X)，再按高度递增从本列已上升状态继续点击，类似完全背包。必须先算完上升，再用旧dp的高度h下降Y补入零点击转移，不能从下降后的本列状态继续上升。

随后按该列管道筛掉h≤L或h≥H的状态。若全部不可达，输出0和之前已经通过的管道数；否则若本列有管道，过管数加一。全部列处理完后，输出1及各高度最小值。高度封顶m，反复点击不会高于m。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    vector<int> up(n), down(n), low(n + 1, 0), high(n + 1, m + 1);
    vector<bool> pipe(n + 1);
    for (int i = 0; i < n; i++)
        cin >> up[i] >> down[i];
    while (k--) {
        int p, l, h;
        cin >> p >> l >> h;
        low[p] = l;
        high[p] = h;
        pipe[p] = true;
    }
    const int inf = 1000000000;
    vector<int> dp(m + 1, 0);
    dp[0] = inf;
    int passed = 0;
    for (int x = 0; x < n; x++) {
        vector<int> next(m + 1, inf);
        for (int h = 1; h <= m; h++) {
            int destination = min(m, h + up[x]);
            if (dp[h] != inf)
                next[destination] = min(next[destination], dp[h] + 1);
            if (next[h] != inf)
                next[destination] = min(next[destination], next[h] + 1);
        }
        for (int h = down[x] + 1; h <= m; h++)
            next[h - down[x]] = min(next[h - down[x]], dp[h]);
        for (int h = 1; h <= m; h++)
            if (h <= low[x + 1] || h >= high[x + 1])
                next[h] = inf;
        if (*min_element(next.begin() + 1, next.end()) == inf) {
            cout << "0\n" << passed;
            return 0;
        }
        if (pipe[x + 1])
            passed++;
        dp.swap(next);
    }
    cout << "1\n" << *min_element(dp.begin() + 1, dp.end());
    return 0;
}
```

### 复杂度

时间 $O(nm+k)$，空间 $O(n+m)$。

### 易错点

缝隙上下边缘均不能碰，必须严格大于L且严格小于H。失败列的管道不能计入已通过数。点击与不点击是互斥的本秒选择。
