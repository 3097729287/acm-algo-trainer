## 智乃酱的区间乘积

### 题意

正整数数组多次查询区间乘积模十亿加七。

### 思路

模数P为素数，且所有a[i]介于1和10^9，小于P，所以前缀乘积pref[i]始终非0。区间乘积=pref[r]*inv(pref[l−1])。只需对pref[n]做一次快速幂求逆，再按invPref[i−1]=invPref[i]*a[i]倒推全部前缀逆元。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    const long long mod = 1000000007;
    vector<long long> a(n + 1), prefix(n + 1, 1), inverse(n + 1);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        prefix[i] = prefix[i - 1] * a[i] % mod;
    }
    long long base = prefix[n], exponent = mod - 2, value = 1;
    while (exponent) {
        if (exponent & 1)
            value = value * base % mod;
        base = base * base % mod;
        exponent >>= 1;
    }
    inverse[n] = value;
    for (int i = n; i >= 1; i--)
        inverse[i - 1] = inverse[i] * a[i] % mod;
    while (m--) {
        int l, r;
        cin >> l >> r;
        cout << prefix[r] * inverse[l - 1] % mod << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n+m+\log P)$，空间 $O(n)$。

### 易错点

模意义下不能直接整数除法。此方法依赖输入没有0，也没有模P的倍数。
