## Beautiful Numbers

### 题意

统计1到N中能被自身数位和整除的数，多组上界。

### 思路

直接把数位和作为动态模数不可行，改为枚举最终数位和S。固定S后，数位DP状态为已用和sum、当前数模S的余数remainder；结束要求sum=S且余数0。若sum>S或sum+9*剩余位<S，立刻剪枝。

外层固定S，再依次处理全部测试。非贴界状态只取决于剩余位数、sum、remainder，能跨测试复用同一缓存；换S再清空。这样不用为每个N重复填整张状态表。S≥1自动排除0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    vector<long long> bound(tests), answer(tests);
    int digits = 1;
    for (auto &x : bound) {
        cin >> x;
        digits = max(digits, (int)to_string(x).size());
    }
    for (int target = 1; target <= 9 * digits; target++) {
        int sums = target + 1;
        vector<long long> memo((digits + 1) * sums * target, -1);
        for (int tc = 0; tc < tests; tc++) {
            string s = to_string(bound[tc]);
            auto dfs = [&](auto &&self, int p, int sum, int remainder, bool tight) -> long long {
                int remaining = s.size() - p;
                if (sum > target || sum + remaining * 9 < target)
                    return 0;
                if (!remaining)
                    return sum == target && remainder == 0;
                long long &cache = memo[(remaining * sums + sum) * target + remainder];
                if (!tight && cache != -1)
                    return cache;
                int maximum = tight ? s[p] - '0' : 9;
                long long result = 0;
                for (int d = 0; d <= maximum; d++)
                    result += self(self, p + 1, sum + d, (remainder * 10 + d) % target,
                                   tight && d == maximum);
                if (!tight)
                    cache = result;
                return result;
            };
            answer[tc] += dfs(dfs, 0, 0, 0, true);
        }
    }
    for (int tc = 0; tc < tests; tc++)
        cout << "Case " << tc + 1 << ": " << answer[tc] << '\n';
    return 0;
}
```

### 复杂度

令最大位数D、Smax=9D，缓存转移上界 $O(10D Smax^3)$，各边界另有 $O(10TD Smax)$；空间 $O(D Smax^2)$。

### 易错点

缓存必须包含目标S，代码通过每个S单独开表实现；同一S可跨不同长度上界复用“剩余位数”状态。
