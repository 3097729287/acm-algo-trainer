## Contest

### 题意

三场比赛中，两队都至少有一场排名胜过对方，求这种无序队伍对数。

### 思路

对任意队伍对，考察三场排名给出的胜负方向。若方向全相同，两队不会互相认为强；若不全相同，必是一边赢两场、另一边赢一场，此时三个比赛对 (a,b)、(a,c)、(b,c) 中恰有两个给出相反方向。因此分别统计两场排名之间的逆序对数，三项相加后除二就是答案。每次按一场排名排序，用树状数组统计另一场的逆序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long disagreements(vector<array<int, 3>> a, int x, int y) {
    sort(a.begin(), a.end(), [=](const auto &u, const auto &v) { return u[x] < v[x]; });
    int n = a.size();
    vector<int> tree(n + 1);
    long long result = 0;
    for (int i = 0; i < n; i++) {
        int rank = a[i][y], count = 0;
        for (int p = rank; p > 0; p -= p & -p)
            count += tree[p];
        result += i - count;
        for (int p = rank; p <= n; p += p & -p)
            tree[p]++;
    }
    return result;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<int, 3>> ranks(n);
    for (auto &row : ranks)
        cin >> row[0] >> row[1] >> row[2];
    cout << (disagreements(ranks, 0, 1) + disagreements(ranks, 0, 2) + disagreements(ranks, 1, 2)) /
                2;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

每场名次为一到 n 的排列，无并列名次。无序队伍对在三次统计中恰出现两次，所以最后除二。
