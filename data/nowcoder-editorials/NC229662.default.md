## 智乃的LCA

### 题意

树结构固定，每次指定一个新根，再查询两点的最近公共祖先。

### 思路

任选一号点作为预处理根，求所有点深度与倍增祖先。对查询 (root,x,y)，分别计算 a=LCA(x,y)、b=LCA(x,root)、c=LCA(y,root)，返回三者中在固定根下最深的点。

理由是三个点之间的三条路径有唯一交汇点，它正是以 root 为根时 x、y 的公共祖先中距离 root 最远者。固定根下的这三个两两 LCA 中，两个相同且较浅，另一个就是该交汇点；因此取最深者。树从未改边，不必针对每个查询重新预处理。用迭代遍历建立父子与深度，兼容十万结点长链。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    const int log = 18;
    vector<vector<int>> edges(n + 1);
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        edges[u].push_back(v);
        edges[v].push_back(u);
    }
    vector<array<int, log>> up(n + 1);
    vector<int> depth(n + 1), order{1};
    for (size_t i = 0; i < order.size(); i++) {
        int u = order[i];
        for (int v : edges[u])
            if (v != up[u][0]) {
                up[v][0] = u;
                depth[v] = depth[u] + 1;
                for (int b = 1; b < log; b++)
                    up[v][b] = up[up[v][b - 1]][b - 1];
                order.push_back(v);
            }
    }
    auto lca = [&](int x, int y) {
        if (depth[x] < depth[y])
            swap(x, y);
        int difference = depth[x] - depth[y];
        for (int b = 0; b < log; b++)
            if (difference >> b & 1)
                x = up[x][b];
        if (x == y)
            return x;
        for (int b = log - 1; b >= 0; b--)
            if (up[x][b] != up[y][b]) {
                x = up[x][b];
                y = up[y][b];
            }
        return up[x][0];
    };
    int m;
    cin >> m;
    while (m--) {
        int root, x, y;
        cin >> root >> x >> y;
        int answer = lca(x, y);
        for (int candidate : {lca(x, root), lca(y, root)})
            if (depth[candidate] > depth[answer])
                answer = candidate;
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(n\log n)$，每次查询 $O(\log n)$，空间 $O(n\log n)$。

### 易错点

取的是预处理根下深度最大的候选，不是编号最大。查询改根不会改变实际边，所有倍增表始终共用。
