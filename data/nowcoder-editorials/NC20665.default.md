## 7的意志

### 题意

数和数位和都能被某个全7正整数整除。

### 思路

全7序列中最小的7整除其余每一项，所以“能被任一项整除”等价于能被7整除；数位和条件同理。只需状态维护当前值模7、数位和模7，添加d后分别更新(10*value+d)%7、(sum+d)%7。结束两者为0就计数。前导0不影响两个状态，内部把0计入两个前缀后会抵消。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long memo[20][7][7];
    memset(memo, -1, sizeof(memo));
    auto count = [&](long long n) {
        if (n < 0)
            return 0LL;
        string s = to_string(n);
        auto dfs = [&](auto &&self, int p, int value, int sum, bool tight) -> long long {
            if (p == (int)s.size())
                return value == 0 && sum == 0;
            auto &cache = memo[s.size() - p][value][sum];
            if (!tight && cache != -1)
                return cache;
            int limit = tight ? s[p] - '0' : 9;
            long long result = 0;
            for (int d = 0; d <= limit; d++)
                result +=
                    self(self, p + 1, (value * 10 + d) % 7, (sum + d) % 7, tight && d == limit);
            if (!tight)
                cache = result;
            return result;
        };
        return dfs(dfs, 0, 0, 0, true);
    };
    long long l, r;
    while (cin >> l >> r && (l || r))
        cout << count(r) - count(l - 1) << '\n';
    return 0;
}
```

### 复杂度

缓存预处理 $O(D\cdot49\cdot10)$，每次边界计数 $O(D\cdot10)$，空间 $O(49D)$。

### 易错点

两个整除条件必须同时满足，不能只检查数字本身含7。
