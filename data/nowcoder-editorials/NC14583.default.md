## 糖糖别胡说，我真的不是签到题目

### 题意

两组糖糖依次消灭前方能力更弱的异组者，期间有全已出现前缀加一，求最终存活数。

### 思路

令 P[t] 为时刻不超过 t 的加一操作次数。第 j 个糖糖在第 i 秒开始时（j<i）的能力是 b[j]+P[i-1]-P[j-1]，新来的 i 尚未获得以前的加成，能力是 b[i]。故 j 会被 i 消灭当且仅当两者异组且 b[j]-P[j-1]<b[i]-P[i-1]。把每个能力改写成这个固定值后，从右向左维护两组后缀最大值；当前不小于异组最大值才可存活。即使后面的某个糖糖最终也死了，它此前的消灭已经发生，仍需参与最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        vector<int> group(n + 1), boost(n + 1);
        vector<long long> strength(n + 1);
        for (int i = 1; i <= n; i++)
            cin >> group[i] >> strength[i];
        for (int i = 0; i < m; i++) {
            int t;
            cin >> t;
            boost[t]++;
        }
        long long elapsed = 0;
        for (int i = 1; i <= n; i++) {
            strength[i] -= elapsed;
            elapsed += boost[i];
        }
        long long maximum[2] = {LLONG_MIN, LLONG_MIN};
        int answer = 0;
        for (int i = n; i >= 1; i--) {
            if (strength[i] >= maximum[group[i] ^ 1])
                answer++;
            maximum[group[i]] = max(maximum[group[i]], strength[i]);
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n+m)$，空间 $O(n)$。

### 易错点

加成发生在当秒结束后，所以固定值减的是 P[i-1]。能力相等不会消灭，判断必须保留等号。
