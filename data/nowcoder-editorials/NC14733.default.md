## 完全平方数

### 题意

多次统计闭非负整数区间中的完全平方数，零也算平方。

### 思路

定义 count(x) 为零到 x 中的平方数个数。x<0 时为零，否则平方根的整数取值为零到 floor(sqrt(x))，所以 count(x)=floor(sqrt(x))+1。查询答案为 count(r)-count(l-1)。用整数二分找最大的根，平方在 long long 中计算，避免浮点临界误差。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    auto count = [](long long x) {
        if (x < 0)
            return 0LL;
        long long low = 0, high = 100000;
        while (low < high) {
            long long mid = (low + high + 1) / 2;
            if (mid * mid <= x)
                low = mid;
            else
                high = mid - 1;
        }
        return low + 1;
    };
    int q;
    cin >> q;
    while (q--) {
        long long l, r;
        cin >> l >> r;
        cout << count(r) - count(l - 1) << '\n';
    }
    return 0;
}
```

### 复杂度

每次查询时间 $O(\log r)$，额外空间 $O(1)$。

### 易错点

零的平方根为零，[0,0] 应得到一。l=0 时，辅助函数应支持 -1。
