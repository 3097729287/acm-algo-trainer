## 道路建设

### 题意

预算内能否修路连通全部城市，允许重边，多组。

### 思路

Kruskal求最小生成树总费用，选不到m−1条边说明图不连通；选满且总费用不超过预算则Yes，否则No。只判断费用而忽略是否连通，会把便宜但缺路的图误判成功。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long budget;
    int roads, cities;
    while (cin >> budget >> roads >> cities) {
        struct Edge {
            int a, b, w;
        };
        vector<Edge> edges(roads);
        for (auto &e : edges)
            cin >> e.a >> e.b >> e.w;
        sort(edges.begin(), edges.end(), [](auto a, auto b) { return a.w < b.w; });
        DSU dsu(cities);
        long long total = 0;
        int used = 0;
        for (auto e : edges)
            if (dsu.unite(e.a, e.b)) {
                total += e.w;
                used++;
            }
        cout << (used == cities - 1 && total <= budget ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(R\log R+(V+R)\alpha(V))$，空间 $O(V+R)$。

### 易错点

输入顺序是预算、道路数、城市数。预算恰好够也成功，输出大小写为Yes/No。
