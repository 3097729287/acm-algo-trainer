## 字符统计

### 题意

统计字符串中不同 ASCII 字符的数量，大小写视为不同。

### 思路

用长度二百五十六的布尔表记录每个字节是否出现，扫描字符串打标记，再统计为真的位置。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    bool seen[256] = {};
    for (unsigned char c : s)
        seen[c] = true;
    int ans = 0;
    for (bool x : seen)
        ans += x;
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(|S|+256)$，额外标记空间 $O(1)$。

### 易错点

a 与 A 是不同字符，不能先统一大小写。
