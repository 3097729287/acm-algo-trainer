## 花店橱窗

### 题意

按花束顺序选不同花瓶，最大化可为负的美观总值，同值时位置序列字典序最小。

### 思路

用后缀DP：dp[i][j]表示花i到末尾只能使用花瓶j到末尾的最优值。可跳过瓶j，或把花i放入j并转到dp[i+1][j+1]。没有剩余花时值为0，有花而无瓶时不可达，用负无穷。恢复时从左向右为每束花找最早的j，使本次美观值加剩余最优值仍等于当前最优值，立即选择。这样每一位都尽量靠前，保证全局字典序最小。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int f, v;
    cin >> f >> v;
    vector<vector<long long>> value(f, vector<long long>(v));
    for (auto &row : value)
        for (auto &x : row)
            cin >> x;
    const long long neg = -(1LL << 60);
    vector<vector<long long>> dp(f + 1, vector<long long>(v + 1, neg));
    fill(dp[f].begin(), dp[f].end(), 0);
    for (int i = f - 1; i >= 0; i--)
        for (int j = v - 1; j >= 0; j--) {
            dp[i][j] = dp[i][j + 1];
            if (dp[i + 1][j + 1] != neg)
                dp[i][j] = max(dp[i][j], value[i][j] + dp[i + 1][j + 1]);
        }
    cout << dp[0][0] << '\n';
    int start = 0;
    long long remaining = dp[0][0];
    for (int i = 0; i < f; i++)
        for (int j = start; j < v; j++)
            if (dp[i + 1][j + 1] != neg && value[i][j] + dp[i + 1][j + 1] == remaining) {
                cout << j + 1 << (i + 1 == f ? '\n' : ' ');
                remaining -= value[i][j];
                start = j + 1;
                break;
            }
    return 0;
}
```

### 复杂度

时间、空间均为 $O(FV)$。

### 易错点

负数美观值也必须放完所有花，不能用全0初始化不可达状态。普通正向回溯随意处理平局可能不满足字典序。
