## 激光炸弹

### 题意

用轴对齐、边长 r 的开正方形覆盖最多目标价值，同坐标价值累加。

### 思路

整数坐标的两个点若相差 r 就不能同时落在开区间内；一边能覆盖的恰是至多 r 个连续整数坐标。按 x 维护宽为 r 的竖条，把条内各点价值累计到 y 数组。竖条右移一格，移出一列并移入一列。每个竖条内，再用长度 r 的 y 滑动窗口求最大和。目标均非负，边缘不足 r 的窗口可向外延伸，不影响合法性。这样不必保存完整的五千平方前缀和表。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, radius;
    cin >> n >> radius;
    const int limit = 5000;
    vector<vector<pair<int, int>>> columns(limit + 1);
    int maxX = 0, maxY = 0;
    for (int i = 0; i < n; i++) {
        int x, y, value;
        cin >> x >> y >> value;
        columns[x].push_back({y, value});
        maxX = max(maxX, x);
        maxY = max(maxY, y);
    }
    vector<int> band(maxY + 1);
    auto change = [&](int x, int sign) {
        for (auto [y, value] : columns[x])
            band[y] += sign * value;
    };
    for (int x = 0; x <= min(maxX, radius - 1); x++)
        change(x, 1);
    int answer = 0;
    for (int x = 0; x <= maxX; x++) {
        if (x > 0) {
            change(x - 1, -1);
            if (x + radius - 1 <= maxX)
                change(x + radius - 1, 1);
        }
        int sum = 0;
        for (int y = 0; y <= maxY; y++) {
            sum += band[y];
            if (y >= radius)
                sum -= band[y - radius];
            answer = max(answer, sum);
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

坐标上限为 $M=5000$，时间 $O(M^2+n)$，空间 $O(M+n)$。

### 易错点

同位置可能有多目标，必须累加。窗口含 r 个整数位置，不含 r+1 个；可以把正方形边放在半整数上来避开边界。
