## [NOIP2004]合并果子

### 题意

反复合并任意两堆，代价为两堆之和，最小化累计代价。

### 思路

把合并过程看作二叉树，每堆重量会按它的叶子深度重复计入代价。最深处有一对兄弟叶子，把最小的两堆交换到这里不会增加总费用。因此可以先合并当前最小两堆，缩成一堆后继续同样的问题。用小根堆重复取两项、累加其和、把和放回。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    priority_queue<long long, vector<long long>, greater<long long>> heap;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        heap.push(x);
    }
    long long answer = 0;
    while (heap.size() > 1) {
        long long x = heap.top();
        heap.pop();
        long long y = heap.top();
        heap.pop();
        answer += x + y;
        heap.push(x + y);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

新合成的一堆也必须参与之后的最小值选择。n=1 时已经是一堆，代价零。
