## [AHOI2009]CHESS 中国象棋

### 题意

棋盘上任意放若干中国象棋炮，使任何两炮不能隔恰好一炮互攻。

### 思路

同一行或列若至少三炮，其中按位置相邻的第一、第三炮恰有一个炮架，必互攻；反之每行每列至多两炮就安全。逐行放置，每行只放0、1、2炮。dp[one][two]记录已有one列放一炮、two列放两炮的方案，剩余empty列无炮。

放一炮可选空列（empty种）或一炮列（one种）；放两炮有两空列、空列加一炮列、两一炮列三类，组合系数分别C(empty,2)、empty*one、C(one,2)。两炮列不能再放。按类型更新列计数并乘选择数，最后对全部列状态求和，含全空棋盘。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    const long long mod = 9999973;
    vector<vector<long long>> dp(m + 1, vector<long long>(m + 1));
    dp[0][0] = 1;
    for (int r = 0; r < n; r++) {
        vector<vector<long long>> next(m + 1, vector<long long>(m + 1));
        for (int one = 0; one <= m; one++)
            for (int two = 0; one + two <= m; two++)
                if (dp[one][two]) {
                    int empty = m - one - two;
                    long long ways = dp[one][two];
                    auto add = [&](int a, int b, long long choices) {
                        next[a][b] = (next[a][b] + ways * choices) % mod;
                    };
                    add(one, two, 1);
                    if (empty)
                        add(one + 1, two, empty);
                    if (one)
                        add(one - 1, two + 1, one);
                    if (empty >= 2)
                        add(one + 2, two, 1LL * empty * (empty - 1) / 2);
                    if (empty && one)
                        add(one, two + 1, 1LL * empty * one);
                    if (one >= 2)
                        add(one - 2, two + 2, 1LL * one * (one - 1) / 2);
                }
        dp.swap(next);
    }
    long long answer = 0;
    for (auto &row : dp)
        for (long long x : row)
            answer = (answer + x) % mod;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(NM^2)$，空间 $O(M^2)$。

### 易错点

两炮同一行但中间没有炮架时不互攻，所以不能误用普通车的每行每列最多一个。模数为9999973。
