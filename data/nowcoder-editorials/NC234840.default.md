## Machining Disc Rotors

### 题意

互不相交的圆形切割之后，求原圆剩余部分的直径。

### 思路

剩余区域的凸包由原大圆上未被切掉的圆弧及连接弧端点的弦组成：每个切割造成向内的凹口，凹口圆弧不是凸包极点。直径因此可以只在剩余的大圆圆弧上寻找。

若存在一对保留的对径点，直径为2R。若不存在，对固定端点Q，与它距离最远的保留圆弧点，只能是Q的对径点或某个圆弧端点；前者不可用，所以最远点对都可取圆弧端点。端点就是切割圆与大圆的交点，最多2n个。

如何检查连续圆弧上有无对径点：保留角度集合与其平移π后的交集若非空，除整圆情形外，一定有一个交集端点来自某个圆弧端点。因此逐个检查端点的对径点是否在所有切割圆外即可；若大圆没有交点，整段大圆边界仍保留，直接2R。其余情况枚举端点两两距离。切口边界是否保留不影响直径的上确界。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

vector<Point> circleIntersections(Point a, long double r, Point b, long double s) {
    Point e = b - a;
    long double d = norm(e);
    if (d < EPS || d > r + s + EPS || d < fabsl(r - s) - EPS)
        return {};
    long double x = (r * r - s * s + d * d) / (2 * d), h2 = r * r - x * x;
    if (h2 < -EPS)
        return {};
    Point center = a + e * (x / d), offset = rotate90(e) * (sqrtl(max(0.0L, h2)) / d);
    if (norm(offset) < EPS)
        return {center};
    return {center + offset, center - offset};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    for (int t = 1; t <= tests; t++) {
        int n;
        long double R;
        cin >> n >> R;
        vector<Point> c(n), endpoint;
        vector<long double> radius(n);
        for (int i = 0; i < n; i++) {
            cin >> c[i].x >> c[i].y >> radius[i];
            auto points = circleIntersections({0, 0}, R, c[i], radius[i]);
            endpoint.insert(endpoint.end(), points.begin(), points.end());
        }
        bool diameterExists = endpoint.empty();
        for (Point p : endpoint) {
            Point opposite = p * (-1);
            bool valid = true;
            for (int i = 0; i < n; i++)
                if (dot(opposite - c[i], opposite - c[i]) < radius[i] * radius[i] - 1e-12L) {
                    valid = false;
                    break;
                }
            if (valid) {
                diameterExists = true;
                break;
            }
        }
        long double answer = 0;
        if (diameterExists)
            answer = 2 * R;
        else
            for (int i = 0; i < (int)endpoint.size(); i++)
                for (int j = i + 1; j < (int)endpoint.size(); j++)
                    answer = max(answer, distance(endpoint[i], endpoint[j]));
        cout << "Case #" << t << ": " << fixed << setprecision(15) << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^2)$，空间 $O(n)$。

### 易错点

利用了切割圆两两不相交、没有切割圆包含整个原圆这两个保证。必须先检查连续圆弧上的对径点，不能只枚举有限个交点。
