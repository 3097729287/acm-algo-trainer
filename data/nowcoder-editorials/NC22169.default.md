## 回文对称数

### 题意

按递增顺序输出不超过 n 的正回文数。

### 思路

从一到 n 枚举，将当前整数转成字符串，复制后反转。如果两串相等，说明从两端读取完全相同，就输出该整数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    for (int x = 1; x <= n; x++) {
        string s = to_string(x), r = s;
        reverse(r.begin(), r.end());
        if (s == r)
            cout << x << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，临时字符串空间 $O(\log n)$。

### 易错点

零不是本题从一开始的输出对象；个位数天然都是回文。
