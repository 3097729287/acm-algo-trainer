## 珂朵莉的数列

### 题意

求所有子区间的逆序对数量总和。

### 思路

固定逆序对i<j、a[i]>a[j]，包含它的子区间左端有i种、右端有n−j+1种，贡献i*(n−j+1)。从左向右扫描j，用按值离散化的树状数组维护先前下标之和。所有已出现下标和减去≤a[j]的前缀和，就是满足a[i]>a[j]的下标总和，再乘n−j+1。

最坏答案为四次规模，n至百万时超过64位，累加使用128位并自行输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Fenwick {
    int n;
    vector<long long> tree;
    Fenwick(int n) : n(n), tree(n + 1) {}
    void add(int p, long long v) {
        for (; p <= n; p += p & -p)
            tree[p] += v;
    }
    long long sum(int p) {
        long long result = 0;
        for (; p; p -= p & -p)
            result += tree[p];
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n), coordinate;
    for (int &x : a)
        cin >> x;
    coordinate = a;
    sort(coordinate.begin(), coordinate.end());
    coordinate.erase(unique(coordinate.begin(), coordinate.end()), coordinate.end());
    Fenwick bit(coordinate.size());
    long long previous = 0;
    __int128 answer = 0;
    for (int j = 1; j <= n; j++) {
        int rank =
            lower_bound(coordinate.begin(), coordinate.end(), a[j - 1]) - coordinate.begin() + 1;
        answer += (__int128)(previous - bit.sum(rank)) * (n - j + 1);
        bit.add(rank, j);
        previous += j;
    }
    string text;
    do {
        text.push_back('0' + answer % 10);
        answer /= 10;
    } while (answer);
    reverse(text.begin(), text.end());
    cout << text;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

相等不构成逆序对，必须减去≤当前值的全部贡献。树状数组存下标之和，不是出现次数。
