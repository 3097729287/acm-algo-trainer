## 【模板】三维偏序（陌上花开）

### 题意

统计每个点被多少其他点三维同时不大于，并输出频数分布。

### 思路

先按(a,b,c)字典序排序，把完全相同的点合成一个带count的点。CDQ按此顺序分左右，左组a不会大于右组；递归后两组各按b排序，扫右点时把所有左组b≤当前b的count加入c上的树状数组，查c前缀即跨组贡献。回滚本轮加入后，按b归并。一个合并点最终答案=跨组smaller+自身count−1，频数桶增加count。

相同a也可计入：字典序下，若两个不同合并点可互相满足偏序，必然b、c也相同，早已被合并；否则只有排在前面的点可能支配后面的点。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int a, b, c, count;
    long long smaller = 0;
};
vector<Node> node, buffer;
vector<int> bit;
void update(int p, int value) {
    for (; p < (int)bit.size(); p += p & -p)
        bit[p] += value;
}
int query(int p) {
    int sum = 0;
    for (; p; p -= p & -p)
        sum += bit[p];
    return sum;
}
void solve(int l, int r) {
    if (r - l <= 1)
        return;
    int mid = (l + r) / 2;
    solve(l, mid);
    solve(mid, r);
    int i = l;
    for (int j = mid; j < r; j++) {
        while (i < mid && node[i].b <= node[j].b) {
            update(node[i].c, node[i].count);
            i++;
        }
        node[j].smaller += query(node[j].c);
    }
    for (int j = l; j < i; j++)
        update(node[j].c, -node[j].count);
    merge(node.begin() + l, node.begin() + mid, node.begin() + mid, node.begin() + r,
          buffer.begin() + l, [](const auto &a, const auto &b) { return a.b < b.b; });
    copy(buffer.begin() + l, buffer.begin() + r, node.begin() + l);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<array<int, 3>> p(n);
    for (auto &q : p)
        cin >> q[0] >> q[1] >> q[2];
    sort(p.begin(), p.end());
    for (auto q : p) {
        if (!node.empty() && node.back().a == q[0] && node.back().b == q[1] &&
            node.back().c == q[2])
            node.back().count++;
        else
            node.push_back({q[0], q[1], q[2], 1, 0});
    }
    buffer.resize(node.size());
    bit.resize(k + 1);
    solve(0, node.size());
    vector<int> answer(n);
    for (auto q : node)
        answer[q.smaller + q.count - 1] += q.count;
    for (int x : answer)
        cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n\log k)$，空间 $O(n+k)$。

### 易错点

≤条件含等号，扫b时不能写成<。必须合并完全重复三元组，不然同组重复点的贡献会随输入顺序丢失。
