## 小石的妹子

### 题意

不断取出没有更强者的妹子，求各自被取出的轮数。

### 思路

比i更强的点满足a、b都更大。i必须等所有更强点移除后才能取，因此t[i]=1+max(t[j])，j遍历同时严格大于它的点。按a从大到小处理，b离散化为反向排名，树状数组维护前缀最大值。查询当前b反向排名之前的位置，得到所有b更大点的最大轮数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<array<int, 3>> point(n);
    vector<int> coordinate;
    for (int i = 0; i < n; i++) {
        cin >> point[i][0] >> point[i][1];
        point[i][2] = i;
        coordinate.push_back(point[i][1]);
    }
    sort(coordinate.begin(), coordinate.end(), greater<int>());
    sort(point.begin(), point.end(), [](auto a, auto b) { return a[0] > b[0]; });
    vector<int> bit(n + 1), answer(n);
    for (auto [a, b, id] : point) {
        int rank = lower_bound(coordinate.begin(), coordinate.end(), b, greater<int>()) -
                   coordinate.begin() + 1;
        int value = 1;
        for (int p = rank - 1; p; p -= p & -p)
            value = max(value, bit[p] + 1);
        answer[id] = value;
        for (int p = rank; p <= n; p += p & -p)
            bit[p] = max(bit[p], value);
    }
    for (int x : answer)
        cout << x << '\n';
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

题目保证a和b各自互不相同，无需对同a批量延迟更新。输出恢复原输入顺序。
