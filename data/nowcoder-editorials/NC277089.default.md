## 灯下定影

### 题意

行人按射线运动进入灯的感应圆，离开后延迟熄灭，求总亮灯时长。

### 思路

对每个行人，将给定方向单位化。把圆心相对起点的向量投影到方向上，得投影长度 projection；叉积绝对值是圆心到直线的垂距。若垂距超过半径，或投影在身后，则未来不会触圆。否则由勾股得到半弦长 half，进入、离开时刻分别为 (projection-half)/speed、(projection+half)/speed。包含边界，因此相切也触发。这个人的亮灯区间是 [进入,离开+延迟]。对所有这样的实数区间排序求并集长度，即总时长。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long double x0, y0, radius, delay;
    int n;
    cin >> x0 >> y0 >> radius >> n >> delay;
    vector<pair<long double, long double>> intervals;
    for (int i = 0; i < n; i++) {
        long double xs, ys, xe, ye, speed;
        cin >> xs >> ys >> xe >> ye >> speed;
        long double dx = xe - xs, dy = ye - ys, length = hypotl(dx, dy);
        dx /= length;
        dy /= length;
        long double qx = x0 - xs, qy = y0 - ys, projection = qx * dx + qy * dy,
                    perpendicular = fabsl(qx * dy - qy * dx);
        if (projection < 0 || perpendicular > radius + 1e-12L)
            continue;
        long double half = sqrtl(max(0.0L, radius * radius - perpendicular * perpendicular));
        long double enter = max(0.0L, (projection - half) / speed),
                    leave = (projection + half) / speed;
        if (leave >= 0)
            intervals.push_back({enter, leave + delay});
    }
    sort(intervals.begin(), intervals.end());
    long double answer = 0, left = 0, right = 0;
    bool started = false;
    for (auto [l, r] : intervals) {
        if (!started) {
            left = l;
            right = r;
            started = true;
        } else if (l <= right)
            right = max(right, r);
        else {
            answer += right - left;
            left = l;
            right = r;
        }
    }
    if (started)
        answer += right - left;
    cout << fixed << setprecision(12) << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

给出的第二个点只确定方向，行人会继续越过它。延迟加在离开时刻之后；不能把各人照明时长直接相加。
