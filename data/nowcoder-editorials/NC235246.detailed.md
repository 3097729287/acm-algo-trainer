## 田忌赛马

> 原题：[P1650](https://www.luogu.com.cn/problem/P1650)
> 解法：优先拿下可赢的两端对局 · C++17

### 题意

两方各有 $n$ 匹马，胜负收益分别为正负二百、平局零，求田忌能够取得的最大净收益。



### 思路

不能只比较同名次的马，也不能把“牺牲最慢马”无条件记成一负，可能两匹速度相等，应算平局。维护两方尚未使用的最慢、最快四个端点，每次确定一对并移走。

若我方最快 A 能赢对方最快 B，可将 A 配 B。任意方案若 A 配较慢的 $b$、B 配另一匹 $a$，交换为 A 对 B、$a$ 对 $b$ 不会降低总分：原先 A 对 $b$ 已是一胜，交换后这一胜仍在；而 $b \le B$，让 $a$ 的对手变弱，其结果只会改善。

否则最快不能赢对方最快。若我方最慢 $a$ 能赢对方最慢 $b$，也可以先配这一对：若原方案 $a$ 对其它 B、$b$ 对其它 A，交换后 A 对 B 的结果不比 $a$ 对 B 更差，而 $a$ 对 $b$ 仍保留原先 A 对 $b$ 的胜利。两种情况都能安全拿下一胜。

最后两端都不能直接拿胜时，$a \le b$ 且 $A \le B$，用 $a$ 对 B。若最优方案已经这样配对就无需改动；否则看其中 $a$ 原来的对手 $u$、B 原来的对手 $v$：因为 $u \ge b \ge a$、$v \le A \le B$，这两局原本都不能赢。改为 $a$ 对 B、$v$ 对 $u$ 后，如果原来两局都输，新的两局最差也只输两局；如果其中有平局，则 $a=u$ 或 $v=B$，交换后 $v$ 对 $u$ 至少能保住相应的平局，若原来两局都平则交换后恰为一胜一负。因此总收益不会降低。若 $a=B$，则所有剩余马都同速，直接算平即可。每轮只去掉一匹双方马，再对剩余同类问题继续。

时间 $O(n\log n)$、空间 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n), b(n);
    for (int &x : a)
        cin >> x;
    for (int &x : b)
        cin >> x;
    sort(a.begin(), a.end());
    sort(b.begin(), b.end());
    int al = 0, ar = n - 1, bl = 0, br = n - 1, score = 0;
    while (al <= ar) {
        if (a[ar] > b[br]) {
            ++score;
            --ar;
            --br;
        } else if (a[al] > b[bl]) {
            ++score;
            ++al;
            ++bl;
        } else {
            score += (a[al] > b[br]) - (a[al] < b[br]);
            ++al;
            --br;
        }
    }
    cout << 200 * score << '\n';
    return 0;
}
```

### 易错点

允许速度相同，牺牲局也可能是平局；答案是净收益而非赢局数。
