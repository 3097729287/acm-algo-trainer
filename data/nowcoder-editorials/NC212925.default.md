## 牛牛的猜球游戏

### 题意

十个杯子按给定区间的交换操作执行，恢复每杯球编号。

### 思路

保存P[i][j]为从初始状态执行前i次操作后，位置j中的球编号。交换两杯即交换这一行两个位置。若只执行[l,r]，其结果S满足P[r][j]=P[l−1][S[j]]，所以S[j]=inverse(P[l−1])[P[r][j]]。每问先构造十个元素的逆置换，再逐位置查表。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<array<int, 10>> prefix(n + 1);
    iota(prefix[0].begin(), prefix[0].end(), 0);
    for (int i = 1; i <= n; i++) {
        int a, b;
        cin >> a >> b;
        prefix[i] = prefix[i - 1];
        swap(prefix[i][a], prefix[i][b]);
    }
    while (m--) {
        int l, r;
        cin >> l >> r;
        array<int, 10> inverse;
        for (int j = 0; j < 10; j++)
            inverse[prefix[l - 1][j]] = j;
        for (int j = 0; j < 10; j++)
            cout << inverse[prefix[r][j]] << (j == 9 ? '\n' : ' ');
    }
    return 0;
}
```

### 复杂度

时间 $O(10(n+m))$，空间 $O(10n)$。

### 易错点

操作交换的是杯子位置，不能把a、b当球编号。区间抵消使用逆置换，不能逐项相减。
