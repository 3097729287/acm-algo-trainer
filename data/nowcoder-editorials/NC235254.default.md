## 晾衣服

### 题意

自然每分钟干1，单台烘干器每分钟使一件干k，求全部干的最短时间。

### 思路

若总时间T，每件自然干T，剩余max(0,a[i]−T)必须由烘干器的额外k−1效率补足，所需烘干分钟ceil(剩余/(k−1))。所有所需分钟之和≤T即能排入单台机器。可行性单调，二分0..max(a)。k=1时机器没有额外效果，直接取最大水量。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    long long high = 0;
    for (auto &x : a) {
        cin >> x;
        high = max(high, x);
    }
    long long k;
    cin >> k;
    if (k == 1) {
        cout << high;
        return 0;
    }
    auto feasible = [&](long long time) {
        long long needed = 0;
        for (long long x : a)
            if (x > time) {
                needed += (x - time + k - 2) / (k - 1);
                if (needed > time)
                    return false;
            }
        return true;
    };
    long long low = 0;
    while (low < high) {
        long long mid = (low + high) / 2;
        if (feasible(mid))
            high = mid;
        else
            low = mid + 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

时间 $O(n\log\max a)$，空间 $O(n)$。

### 易错点

烘干时总下降k，不是自然1再额外k，所以额外效率为k−1。
