## [NOI2014]起床困难综合症

### 题意

初始攻击值在零到 m 内，经过同一组 AND、OR、XOR 后最大化最终值。

### 思路

位运算不会在各位间传递影响。让初始数分别为全零和低三十位全一，跑完全部操作，即同时得到每一位输入零或一时的最终结果。再从高到低构造输入：若输入零就能让结果位为一，优先选零以节约额度；否则只有输入一能改善结果且累计输入仍不超过 m 时才选一。高位结果比所有低位之和更重要，当前保留更小输入又给后续留下最多选择，所以此贪心成立。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long m;
    cin >> n >> m;
    long long zero = 0, one = (1LL << 30) - 1;
    for (int i = 0; i < n; i++) {
        string op;
        long long t;
        cin >> op >> t;
        if (op == "AND") {
            zero &= t;
            one &= t;
        } else if (op == "OR") {
            zero |= t;
            one |= t;
        } else {
            zero ^= t;
            one ^= t;
        }
    }
    long long input = 0, answer = 0;
    for (int b = 29; b >= 0; b--) {
        long long bit = 1LL << b;
        if (zero & bit)
            answer |= bit;
        else if ((one & bit) && input + bit <= m) {
            input += bit;
            answer |= bit;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n+\log m)$，额外空间 $O(1)$。

### 易错点

上限限制的是初始输入，不是最终输出。相同结果时选输入零，不能浪费额度。
