## 饥饿的牛

### 题意

从队列中保持顺序挑出严格递增的编号，求最多数量。

### 思路

tails[len−1]记录长度len的严格上升子序列的最小末尾。扫描编号x，找到第一个≥x的位置并替换；若不存在就追加。更小末尾使未来更容易接上，而不会改变已有长度的可行性，故最终数组长度即LIS长度。编号可能使用完整32位无符号范围，用64位读取。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> tails;
    while (n--) {
        long long x;
        cin >> x;
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end())
            tails.push_back(x);
        else
            *it = x;
    }
    cout << tails.size();
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

要求严格递增，用lower_bound而非upper_bound；相同编号不会增加长度。
