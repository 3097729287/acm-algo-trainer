## 挖沟

### 题意

用最少沟数连通所有据点，再最小化沟的总长度。

### 思路

连通n个点至少需要n−1条边；达到该数量的连通图就是生成树。因此按边长排序，Kruskal每次加入连接不同连通块的最短边，累计长度，选满n−1条结束。切分性质保证每次选择可属于某棵最小生成树。题目保证原图可连通。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    struct Edge {
        int a, b, w;
    };
    vector<Edge> edges(m);
    for (auto &e : edges)
        cin >> e.a >> e.b >> e.w;
    sort(edges.begin(), edges.end(), [](auto a, auto b) { return a.w < b.w; });
    DSU dsu(n);
    long long answer = 0;
    int used = 0;
    for (auto e : edges)
        if (dsu.unite(e.a, e.b)) {
            answer += e.w;
            if (++used == n - 1)
                break;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(m\log m+(n+m)\alpha(n))$，空间 $O(n+m)$。

### 易错点

重边可保留，形成环的边不选。目标是所挖沟的长度和，不是树上任意点对距离总和，样例3点答案7据此理解。
