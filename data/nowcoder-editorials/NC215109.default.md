## jyq跳格子

### 题意

从一号格每次跳两格或四格，判断能否恰好到 n。

### 思路

每次增加偶数，所以位置始终是奇数。反过来任何奇数 n 都可通过 (n-1)/2 次两格跳到达，故奇数输出 n，偶数输出负一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    cout << (n % 2 ? n : -1);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

n=1 时零次跳跃就已到达，应输出一。
