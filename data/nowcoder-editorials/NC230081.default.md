## Magic Gems

### 题意

长度1或m的宝石块恰占n空间，求方案数。

### 思路

按最后一块长度，f[n]=f[n−1]+f[n−m]，f[0..m−1]=1。对这个m阶递推，特征多项式给出x^m=x^(m−1)+1。计算x^n在此关系下的余式Σc[i]x^i，则f[n]=Σc[i]f[i]=Σc[i]。

用二进制快速幂乘多项式：先普通卷积，再从高次往低次把x^j替换成x^(j−1)+x^(j−m)。每次O(m²)，优于100维稠密矩阵乘法。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    unsigned long long n;
    int m;
    cin >> n >> m;
    const long long mod = 1000000007;
    auto multiply = [&](const vector<long long> &a, const vector<long long> &b) {
        vector<long long> c(2 * m - 1);
        for (int i = 0; i < m; i++)
            for (int j = 0; j < m; j++)
                c[i + j] = (c[i + j] + a[i] * b[j]) % mod;
        for (int j = 2 * m - 2; j >= m; j--) {
            c[j - 1] = (c[j - 1] + c[j]) % mod;
            c[j - m] = (c[j - m] + c[j]) % mod;
        }
        c.resize(m);
        return c;
    };
    vector<long long> result(m), base(m);
    result[0] = 1;
    base[1] = 1;
    while (n) {
        if (n & 1)
            result = multiply(result, base);
        n >>= 1;
        if (n)
            base = multiply(base, base);
    }
    long long answer = 0;
    for (auto x : result)
        answer = (answer + x) % mod;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(m^2\log n)$，空间 $O(m)$。

### 易错点

普通宝石必须以完整m个块出现。多项式降幂从高到低，才能继续归约新产生的高次项。
