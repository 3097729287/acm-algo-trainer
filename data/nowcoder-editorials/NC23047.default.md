## 华华给月月出题

### 题意

求所有i的i^N模十亿加七后再异或，N至一千三百万。

### 思路

对固定指数N，f(x)=x^N mod P是完全积性函数，f(a*b)=f(a)*f(b) mod P。在线性筛里，每个素数用一次快速幂求f(p)，每个合数按其唯一线性筛生成方式用一次模乘求值，避免对一千多万个数各做一次快速幂。

所有i<P且P为素数，所以f(i)不可能为0；数组值0便可兼作“尚未筛到”的素数标记，不另存最小质因子表。每生成一个i的f值就异或进答案。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    const long long mod = 1000000007;
    auto power = [&](long long a) {
        long long result = 1;
        int exponent = n;
        while (exponent) {
            if (exponent & 1)
                result = result * a % mod;
            a = a * a % mod;
            exponent >>= 1;
        }
        return (int)result;
    };
    vector<int> value(n + 1), primes;
    value[1] = 1;
    int answer = 1;
    for (int i = 2; i <= n; i++) {
        if (value[i] == 0) {
            primes.push_back(i);
            value[i] = power(i);
        }
        answer ^= value[i];
        for (int p : primes) {
            long long composite = 1LL * i * p;
            if (composite > n)
                break;
            value[composite] = 1LL * value[i] * value[p] % mod;
            if (i % p == 0)
                break;
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(N+\pi(N)\log N)$，空间 $O(N+\pi(N))$，主要为32位函数值表。

### 易错点

每项先取模再做异或，不能把指数、底数或最后异或结果另外取模替代。0作标记依赖N小于模数，不能无条件搬到其他完全积性函数。
