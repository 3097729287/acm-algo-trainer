## 平方根

### 题意

求整数平方根，也就是平方不超过 n 的最大整数。

### 思路

在零到 31623 中二分第一个平方大于 n 的数，其前一个就是答案。乘法用 long long，避免上界平方溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    long long l = 0, r = 31624;
    while (l + 1 < r) {
        long long mid = (l + r) / 2;
        if (mid * mid <= n)
            l = mid;
        else
            r = mid;
    }
    cout << l;
    return 0;
}
```

### 复杂度

时间 $O(\log n)$，额外空间 $O(1)$。

### 易错点

恰为完全平方数时应保留其平方根；答案不是四舍五入。
