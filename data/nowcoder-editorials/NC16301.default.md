## 强迫症

### 题意

每步用两数之和替换其中一个，使 n 个正整数最终互不相同。

### 思路

若原来有 D 个不同值，一步至多让不同值数量增加一，故至少 n-D 步。这个下界可达到：每次挑一个重复值 x，把它与当前最大值 M 相加，替换这个重复项。x>0，所以新数 M+x 比所有旧数大；原值 x 还有另一份，不会失去旧的不同值，恰好增加一种。重复做 n-D 次即可，因此只需数不同值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    set<long long> values;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        values.insert(x);
    }
    cout << n - values.size();
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

构造仅用于证明，不需要真的累加这些可能越来越大的数。所有输入为正数是新值严格大于当前最大值的关键。
