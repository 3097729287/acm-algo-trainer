## 焦虑的蚂蚁

### 题意

蚂蚁等速行走、相遇后掉头，求所有蚂蚁离开路径的时间。

### 思路

两只完全相同的蚂蚁相遇后交换方向，忽略身份就等价于穿过彼此。因此只需分别计算每只蚂蚁保持原方向直到端点的时间：向左为 x，向右为 n-x，再取最大值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    int ans = 0;
    for (int i = 0; i < m; i++) {
        int direction, x;
        cin >> direction >> x;
        ans = max(ans, direction == 0 ? x : n - x);
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间 $O(m)$，额外空间 $O(1)$。

### 易错点

该转化保留了所有蚂蚁位置的集合及最后离开时刻，但不保留某只蚂蚁的身份轨迹。
