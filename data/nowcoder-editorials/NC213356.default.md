## 好数

### 题意

统计闭区间里百位乘十位的个位等于原个位的三位数。

### 思路

合法对象只有一百到九百九十九，直接枚举这九百个候选。提取百位 x/100、十位 x/10%10 与个位 x%10，同时检查候选位于输入区间。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        long long l, r;
        cin >> l >> r;
        int ans = 0;
        for (int x = 100; x <= 999; x++)
            if (l <= x && x <= r && (x / 100 * (x / 10 % 10)) % 10 == x % 10)
                ans++;
        cout << ans << '\n';
    }
    return 0;
}
```

### 复杂度

每组固定九百次检查，额外空间 $O(1)$。

### 易错点

定义只针对三位数，不能把区间里的两位数或四位数也按相同规则计入。
