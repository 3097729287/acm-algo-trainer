## Signal Interference

### 题意

求简单多边形内满足|PB|≤k|PA|的区域面积。

### 思路

将距离平方展开配方，干扰区域是圆盘，圆心$C=(B-k^2A)/(1-k^2)$，半径$R=k|A-B|/(1-k^2)$。平移C到原点，按多边形边AB求有向三角形OAB与圆盘交面积，最后取总和绝对值。

把线段AB与圆的交点参数加入0、1并排序。每段的中点在圆内时，贡献cross(P,Q)/2；在圆外时，贡献R²*atan2(cross(P,Q),dot(P,Q))/2，即有向扇形面积。各边相加自动抵消内部射线，凹多边形和任意输入方向都能处理。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, t = 0;
    long double k;
    while (cin >> n >> k) {
        vector<Point> p(n);
        for (auto &q : p)
            cin >> q.x >> q.y;
        Point a, b;
        cin >> a.x >> a.y >> b.x >> b.y;
        Point center = (b - a * (k * k)) / (1 - k * k);
        long double radius = k * distance(a, b) / (1 - k * k), answer = 0;
        for (int i = 0; i < n; i++) {
            Point u = p[i] - center, v = p[(i + 1) % n] - center, e = v - u;
            vector<long double> cut = {0, 1};
            long double A = dot(e, e), B = 2 * dot(u, e), C = dot(u, u) - radius * radius,
                        discriminant = B * B - 4 * A * C;
            if (A > 0 && discriminant > 0) {
                long double root = sqrtl(discriminant);
                for (long double x : {(-B - root) / (2 * A), (-B + root) / (2 * A)})
                    if (x > 0 && x < 1)
                        cut.push_back(x);
            }
            sort(cut.begin(), cut.end());
            for (int j = 1; j < (int)cut.size(); j++) {
                Point x = u + e * cut[j - 1], y = u + e * cut[j], mid = (x + y) / 2;
                if (dot(mid, mid) <= radius * radius)
                    answer += cross(x, y) / 2;
                else
                    answer += radius * radius * atan2l(cross(x, y), dot(x, y)) / 2;
            }
        }
        cout << "Case " << ++t << ": " << fixed << setprecision(12) << fabsl(answer) << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n)$，空间 $O(n)$。

### 易错点

A、B塔不是多边形顶点。圆心分母是1−k²；面积累加有符号贡献，不能对每条边先取绝对值。
