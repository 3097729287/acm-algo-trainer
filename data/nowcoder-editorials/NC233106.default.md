## 恶意竞争

### 题意

随机漏洞同时覆盖全部类型和全部组件的期望天数。

### 思路

E[i][j]为已见i种漏洞、j个组件时的剩余期望。一天后有四种情况：都旧ij，都新(n−i)(s−j)，仅类型新(n−i)j，仅组件新i(s−j)，总分母ns。把自环ij*E[i][j]移到左侧：E[i][j]=(ns+(n−i)jE[i+1][j]+i(s−j)E[i][j+1]+(n−i)(s−j)E[i+1][j+1])/(ns−ij)。终点E[n][s]=0，按i、j倒序计算，保留两行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, s;
    cin >> n >> s;
    vector<long double> next(s + 2), current(s + 2);
    for (int i = n; i >= 0; i--) {
        fill(current.begin(), current.end(), 0);
        for (int j = s; j >= 0; j--) {
            if (i == n && j == s)
                continue;
            current[j] = ((long double)n * s + (long double)(n - i) * j * next[j] +
                          (long double)i * (s - j) * current[j + 1] +
                          (long double)(n - i) * (s - j) * next[j + 1]) /
                         ((long double)n * s - i * j);
        }
        next.swap(current);
    }
    cout << fixed << setprecision(10) << next[0];
    return 0;
}
```

### 复杂度

时间 $O(ns)$，空间 $O(s)$。

### 易错点

组件和类型是同时抽取的一对标签，不能分别求期望后直接取最大或相加。
