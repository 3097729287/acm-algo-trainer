## 小G有一个大树

### 题意

删一个点，最大剩余连通块尽可能小，并列取编号最小。

### 思路

任取根求子树大小size[u]。删u后，各孩子子树各成一块，父亲方向那块大小为n−size[u]，取这些数最大值作为balance[u]。遍历所有点选择balance最小、编号最小者。迭代建立父亲与遍历顺序，逆序累加大小，避免递归。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        Tree tree(n);
        for (int i = 1; i < n; i++) {
            int a, b;
            cin >> a >> b;
            tree.add(a - 1, b - 1);
        }
        tree.root(0);
        vector<int> size(n, 1), largest(n);
        for (int i = n - 1; i >= 0; i--) {
            int u = tree.order[i];
            for (auto [v, w] : tree.edge[u])
                if (v != tree.parent[u]) {
                    size[u] += size[v];
                    largest[u] = max(largest[u], size[v]);
                }
            largest[u] = max(largest[u], n - size[u]);
        }
        int best = 0;
        for (int u = 1; u < n; u++)
            if (largest[u] < largest[best])
                best = u;
        cout << best + 1 << ' ' << largest[best] << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n)$。

### 易错点

父亲方向的剩余部分也必须考虑。按编号递增扫描且只在严格更好时更新，就自然保留小编号。
