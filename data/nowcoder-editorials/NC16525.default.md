## [NOIP2013]转圈游戏

### 题意

每轮位置加m，求10^k轮后x的位置。

### 思路

每轮所有人顺时针移动m，轮数为t时位置就是(x+m*t) mod n。只需要10^k mod n，用二进制快速幂计算，再代入即可，不需要模拟或求循环节。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, m, k, x;
    cin >> n >> m >> k >> x;
    long long turns = 1 % n, base = 10 % n;
    while (k) {
        if (k & 1)
            turns = turns * base % n;
        base = base * base % n;
        k >>= 1;
    }
    cout << (x + m * turns) % n;
    return 0;
}
```

### 复杂度

时间 $O(\log k)$，空间 $O(1)$。

### 易错点

位置从0编号。10^k是轮数，不是k轮；乘法使用64位。
