## Captcha Cracker

### 题意

按出现顺序输出验证码中的零、二、四、六、九及它们的英文单词对应的数字。

### 思路

从左到右枚举每个起点。若当前字符是指定的五种数字就直接输出；否则分别检查 zero、two、four、six、nine 是否从这里开始，匹配就输出对应数字。固定五个模式都很短，直接比较足够。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    vector<pair<string, char>> words = {
        {"zero", '0'}, {"two", '2'}, {"four", '4'}, {"six", '6'}, {"nine", '9'}};
    while (t--) {
        string s;
        cin >> s;
        for (size_t i = 0; i < s.size(); i++) {
            if (string("02469").find(s[i]) != string::npos)
                cout << s[i];
            else
                for (auto [word, digit] : words)
                    if (s.compare(i, word.size(), word) == 0) {
                        cout << digit;
                        break;
                    }
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

固定模式总长为常数，时间 $O(|S|)$，字符串空间 $O(|S|)$。

### 易错点

其他数字及其单词都忽略，例如 one、three 不输出。需要匹配完整英文拼写，多个 i 的 siiiiix 不是 six。
