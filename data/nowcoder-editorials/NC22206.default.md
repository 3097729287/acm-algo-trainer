## 乘法表

### 题意

输出下三角的九九乘法表，乘积宽度为二，每项之间一个空格。

### 思路

外层枚举行号 i，内层枚举从一到 i 的乘数 j，输出 j*i 的算式。每个乘积单独使用 setw(2) 右对齐；同一行第二项起先输出一个分隔空格。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            if (j > 1)
                cout << ' ';
            cout << j << '*' << i << '=' << setw(2) << j * i;
        }
        if (i < 9)
            cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

setw 只作用于紧随其后的一个输出项，所以每个乘积前都要设置。算式中的乘号是半角星号。
