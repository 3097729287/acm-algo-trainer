## 蓝魔法师

### 题意

删任意树边，所有剩余连通块大小不超过k，统计方案模998244353。

### 思路

dp[u][s]表示u子树内所有已封闭块都合法，而包含u、还可向父亲连接的块大小为s的方案数。初始只有u，大小1。合并孩子v时：若切边，v的开放块也封闭，其所有大小1到k的方案都可用，保持u块大小不变；若保留边，两开放块合并，大小相加须≤k，方案数相乘。逐孩子用新数组做卷积，所有非u块的合法性由子状态保证。最后根的开放块也封闭，对其全部大小求和。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    k = min(k, n);
    Tree tree(n);
    for (int i = 1; i < n; i++) {
        int a, b;
        cin >> a >> b;
        tree.add(a - 1, b - 1);
    }
    tree.root(0);
    const long long mod = 998244353;
    vector<vector<long long>> dp(n);
    for (int index = n - 1; index >= 0; index--) {
        int u = tree.order[index];
        dp[u] = {0, 1};
        for (auto [v, w] : tree.edge[u])
            if (v != tree.parent[u]) {
                long long cutWays = 0;
                for (long long x : dp[v])
                    cutWays = (cutWays + x) % mod;
                int cap = min(k, (int)dp[u].size() + (int)dp[v].size() - 2);
                vector<long long> next(cap + 1);
                for (int a = 1; a < (int)dp[u].size(); a++) {
                    next[a] = (next[a] + dp[u][a] * cutWays) % mod;
                    for (int b = 1; b < (int)dp[v].size() && a + b <= cap; b++)
                        next[a + b] = (next[a + b] + dp[u][a] * dp[v][b]) % mod;
                }
                dp[u].swap(next);
            }
    }
    long long answer = 0;
    for (long long x : dp[0])
        answer = (answer + x) % mod;
    cout << answer;
    return 0;
}
```

### 复杂度

按实际子树规模限制卷积，总时间 $O(n^2)$，存全部子树表的空间上界 $O(nk)$。

### 易错点

切边不要求孩子块与u块大小相加≤k；只有保留边才合并大小。每条边两种决策各算一次。
