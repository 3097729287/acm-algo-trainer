## [HNOI2007]分裂游戏

### 题意

从瓶i取一豆，在更后j、k各加一豆，统计获胜首步。

### 思路

把每颗豆视为独立游戏子项，位于瓶i的豆可变成位于j、k的两个子项，因此sg[i]=mex{sg[j] xor sg[k]，i<j≤k}。从最后瓶向前计算。瓶i有p颗相同豆时，偶数份SG抵消，只在p为奇数时异或sg[i]。

枚举每个有豆的i及j、k，操作后的总异或为X xor sg[i] xor sg[j] xor sg[k]；为0就是获胜首步。按i、j、k升序枚举自然得到字典序首解，并统计全部三元组。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        cin >> n;
        vector<int> count(n), sg(n);
        for (int &x : count)
            cin >> x;
        for (int i = n - 1; i >= 0; i--) {
            set<int> reachable;
            for (int j = i + 1; j < n; j++)
                for (int k = j; k < n; k++)
                    reachable.insert(sg[j] ^ sg[k]);
            while (reachable.count(sg[i]))
                sg[i]++;
        }
        int total = 0;
        for (int i = 0; i < n; i++)
            if (count[i] % 2)
                total ^= sg[i];
        array<int, 3> first = {-1, -1, -1};
        int ways = 0;
        for (int i = 0; i < n; i++)
            if (count[i])
                for (int j = i + 1; j < n; j++)
                    for (int k = j; k < n; k++)
                        if ((total ^ sg[i] ^ sg[j] ^ sg[k]) == 0) {
                            if (!ways)
                                first = {i, j, k};
                            ways++;
                        }
        cout << first[0] << ' ' << first[1] << ' ' << first[2] << '\n' << ways << '\n';
    }
    return 0;
}
```

### 复杂度

每组 $O(n³\log n)$，空间 $O(n²)$ 临时mex集合。

### 易错点

同瓶豆不可区分，首步按三元组计数，不乘p[i]。j=k合法，会给同一瓶加两豆，SG异或抵消。
