## 跳石头

### 题意

至多移走 M 块中间岩石，最大化保留石头相邻距离的最小值。

### 思路

二分最小跳距 d，从起点贪心保留最早能距上一块至少 d 的岩石；若距离不足就移走当前石头。保留位置越靠前，越有利于后续选石，所以这样使用最少移除数。把终点也放进扫描：若最后一跳不足，计一次移除可理解为移除之前最后保留的中间石头；此前两跳合并后足够长。移除数不超过 M 则 d 可行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long length;
    int n, m;
    cin >> length >> n >> m;
    vector<long long> positions(n + 1);
    for (int i = 0; i < n; i++)
        cin >> positions[i];
    positions[n] = length;
    auto possible = [&](long long distance) {
        int removed = 0;
        long long previous = 0;
        for (long long x : positions) {
            if (x - previous < distance)
                removed++;
            else
                previous = x;
        }
        return removed <= m;
    };
    long long low = 1, high = length;
    while (low < high) {
        long long mid = low + (high - low + 1) / 2;
        if (possible(mid))
            low = mid;
        else
            high = mid - 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

时间 $O(n\log L)$，空间 $O(n)$。

### 易错点

起终点不能真的删除，末跳不足的计数必须按删除前一中间石头理解。没有中间石头时答案就是 L。
