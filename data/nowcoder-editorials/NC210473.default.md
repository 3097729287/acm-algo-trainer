## 吉吉王国

### 题意

预算内切断所有根到叶路径，最小化所切边的最大长度。

### 思路

二分最长可切边限制X。自底向上计算dp[u]为阻断u到其子树所有原叶子的最小代价；非根叶子设无穷。对每个儿子v，或者在内部支付dp[v]，或者在边权w≤X时直接切父子边支付w，取较小值，各儿子求和。dp[root]≤预算即可行。可行性随X增大单调，搜索0到最大边长；若最大边长仍不可行输出−1。只有根时没有叛军，答案0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Tree {
    vector<vector<pair<int, long long>>> edge;
    vector<int> parent, order;
    vector<long long> incoming;
    explicit Tree(int n) : edge(n), parent(n, -1), incoming(n) {}
    void add(int u, int v, long long w = 1) {
        edge[u].push_back({v, w});
        edge[v].push_back({u, w});
    }
    void root(int start) {
        order = {start};
        parent[start] = start;
        for (size_t i = 0; i < order.size(); i++) {
            int u = order[i];
            for (auto [v, w] : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    incoming[v] = w;
                    order.push_back(v);
                }
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long budget;
    cin >> n >> budget;
    Tree tree(n);
    int maximum = 0;
    for (int i = 1; i < n; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        tree.add(u - 1, v - 1, w);
        maximum = max(maximum, w);
    }
    tree.root(0);
    auto feasible = [&](int limit) {
        vector<long long> dp(n);
        for (int i = n - 1; i >= 0; i--) {
            int u = tree.order[i];
            if (u && tree.edge[u].size() == 1) {
                dp[u] = budget + 1;
                continue;
            }
            for (auto [v, w] : tree.edge[u])
                if (tree.parent[v] == u)
                    dp[u] = min(budget + 1, dp[u] + min(dp[v], w <= limit ? w : budget + 1));
        }
        return dp[0] <= budget;
    };
    if (!feasible(maximum)) {
        cout << -1;
        return 0;
    }
    int low = 0, high = maximum;
    while (low < high) {
        int mid = (low + high) / 2;
        if (feasible(mid))
            high = mid;
        else
            low = mid + 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

时间 $O(n\log W)$，空间 $O(n)$。

### 易错点

叶子是原树中除根外度数1的点。预算超出后截为budget+1，防止无穷累加。
