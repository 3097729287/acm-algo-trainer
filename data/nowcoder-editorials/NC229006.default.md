## 【模板】扩展中国剩余定理

### 题意

模数可不互素的同余方程组，求最小非负解。

### 思路

维护已合并解x≡R(mod M)。加入x≡r(mod p)，令x=R+M*t，需M*t≡r−R(mod p)。g=gcd(M,p)，若g不整除差则无解；否则用扩展欧几里得系数u得到t=(r−R)/g*u mod(p/g)。新模数为M*(p/g)，新余数R+M*t再规范化。

最终最小公倍数保证≤10^18，但求t的乘积与合并余数的中间值使用128位，防止先乘溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long extendedGcd(long long a, long long b, long long &x, long long &y) {
    if (!b) {
        x = 1;
        y = 0;
        return a;
    }
    long long previousX, previousY;
    long long g = extendedGcd(b, a % b, previousX, previousY);
    x = previousY;
    y = previousX - (a / b) * previousY;
    return g;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long remainder = 0, period = 1;
    bool possible = true;
    while (n--) {
        long long p, r;
        cin >> p >> r;
        if (!possible)
            continue;
        long long u, v, g = extendedGcd(period, p, u, v), delta = r - remainder;
        if (delta % g) {
            possible = false;
            continue;
        }
        long long reduced = p / g;
        long long step = (long long)(((__int128)(delta / g) * u % reduced + reduced) % reduced);
        long long nextPeriod = period * reduced;
        remainder = (long long)(((__int128)remainder + (__int128)period * step) % nextPeriod);
        period = nextPeriod;
    }
    cout << (possible ? remainder : -1);
    return 0;
}
```

### 复杂度

时间 $O(n\log U)$，空间 $O(\log U)$。

### 易错点

模数不互素不能套标准CRT直接相乘。输入余数即使等于模数，也可按同余自然处理。
