## 数独挑战

### 题意

解唯一解的9×9数独，空位用0表示。

### 思路

分别用9位二进制记录每行、每列、每宫已经用过的数字。空格的候选等于全集去掉三个位集的并。每次选择候选最少的空格，依次尝试候选，递归后撤销；某格没有候选立刻回退。所有格填满即得到唯一解。选择最少候选不改变搜索范围，但能尽早发现矛盾。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Sudoku {
    int board[81] = {}, row[9] = {}, column[9] = {}, block[9] = {}, best = -1;
    bool first = false, consistent = true;
    int weight(int p) {
        int r = p / 9, c = p % 9;
        return 6 + min({r, c, 8 - r, 8 - c});
    }
    int box(int p) { return p / 27 * 3 + p % 9 / 3; }
    int choices(int p) { return 511 & ~(row[p / 9] | column[p % 9] | block[box(p)]); }
    void toggle(int p, int digit) {
        int bit = 1 << (digit - 1);
        row[p / 9] ^= bit;
        column[p % 9] ^= bit;
        block[box(p)] ^= bit;
    }
    bool search(int score) {
        int selected = -1, mask = 0, fewest = 10, upper = score;
        for (int p = 0; p < 81; p++)
            if (!board[p]) {
                int options = choices(p), count = __builtin_popcount((unsigned)options);
                if (!count)
                    return false;
                upper += (32 - __builtin_clz((unsigned)options)) * weight(p);
                if (count < fewest) {
                    fewest = count;
                    selected = p;
                    mask = options;
                }
            }
        if (selected == -1) {
            best = max(best, score);
            return first;
        }
        if (!first && upper <= best)
            return false;
        for (int digit = 9; digit >= 1; digit--)
            if (mask >> (digit - 1) & 1) {
                board[selected] = digit;
                toggle(selected, digit);
                if (search(score + digit * weight(selected)))
                    return true;
                toggle(selected, digit);
                board[selected] = 0;
            }
        return false;
    }
    void solve() {
        int score = 0;
        for (int p = 0; p < 81; p++)
            if (board[p]) {
                if (!(choices(p) >> (board[p] - 1) & 1)) {
                    consistent = false;
                    return;
                }
                toggle(p, board[p]);
                score += board[p] * weight(p);
            }
        search(score);
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    Sudoku solver;
    solver.first = true;
    for (int &x : solver.board)
        cin >> x;
    solver.solve();
    for (int r = 0; r < 9; r++)
        for (int c = 0; c < 9; c++)
            cout << solver.board[r * 9 + c] << (c == 8 ? '\n' : ' ');
    return 0;
}
```

### 复杂度

若有 $E$ 个空格，保守上界 $O(81\cdot9^E)$，剪枝后通常远小于此；固定81格，搜索栈 $O(E)$。

### 易错点

试填和撤销必须成对更新行、列、宫。行尾不加空格；每行输出九个数字。
