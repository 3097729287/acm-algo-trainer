## Problem of Apollonius

### 题意

构造经过给定点且与两个已知圆外切的全部圆。

### 思路

以给定点P为反演中心，反演半径取1。将P平移到原点，已知圆(c,r)变成(c/(|c|²−r²), r/(|c|²−r²))。未知圆经过原点，反演后变成一条直线；原先与两个圆外切，等价于这条线是两反演圆的公外切线，且原点与两圆位于线的同一侧。

把切线写成单位法向量n·x=d，两圆在线的≤侧，则n·(c1−c2)=r2−r1。设e为两圆心连线单位向量，t=(r2−r1)/|c1−c2|，两个候选法向量是t*e±sqrt(1−t²)*rotate90(e)。d=n·c1+r1，只有d>0满足原点在线的同侧。反演回去得到圆心n/(2d)、半径1/(2d)，再平移P。

本题允许任意答案顺序，验证同时检查解数、过点以及与两圆的外切等式。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        Point a, b, p;
        long double r, s;
        cin >> a.x >> a.y >> r >> b.x >> b.y >> s >> p.x >> p.y;
        a = a - p;
        b = b - p;
        long double da = dot(a, a) - r * r, db = dot(b, b) - s * s;
        a = a / da;
        r /= da;
        b = b / db;
        s /= db;
        Point e = a - b;
        long double length = norm(e), t = (s - r) / length;
        vector<array<long double, 3>> answer;
        if (fabsl(t) <= 1 + EPS) {
            e = e / length;
            long double h = sqrtl(max(0.0L, 1 - t * t));
            for (int sign : {-1, 1}) {
                Point normal = e * t + rotate90(e) * (sign * h);
                long double d = dot(normal, a) + r;
                if (d <= 1e-18L)
                    continue;
                Point center = p + normal / (2 * d);
                long double radius = 1 / (2 * d);
                if (!answer.empty() && distance(center, {answer[0][0], answer[0][1]}) < 1e-10L)
                    continue;
                answer.push_back({center.x, center.y, radius});
            }
        }
        cout << answer.size() << '\n';
        for (auto q : answer)
            cout << fixed << setprecision(12) << q[0] << ' ' << q[1] << ' ' << q[2] << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间与空间均为 $O(1)$。

### 易错点

反演中心严格在两个已知圆外，两个分母均为正。只解公切线还不够，必须检查d>0，否则反演得到的圆会包住已知圆。
