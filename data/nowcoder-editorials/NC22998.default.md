## 奶牛异或

### 题意

找异或最大的非空连续段；并列先取最早结束，再取最短长度。

### 思路

区间 [l,r] 异或为 prefix[r]^prefix[l-1]。按 r 从小到大，把已经出现的前缀异或放入二进制 Trie，查询与 prefix[r] 异或最大的旧前缀。相同旧前缀只保留最新下标，便能在固定 r、固定最大异或时取最大 l，也就是最短段。只有找到严格更大异或时才更新全局答案，扫描顺序自然保留最早的结束位置。查询后才插入 prefix[r]，确保区间非空。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Node {
        int child[2] = {}, latest = 0;
    };
    vector<Node> trie(1);
    trie.reserve(1 + 21 * (n + 1));
    auto insert = [&](int value, int index) {
        int node = 0;
        for (int b = 20; b >= 0; b--) {
            int bit = value >> b & 1;
            if (!trie[node].child[bit]) {
                trie[node].child[bit] = trie.size();
                trie.push_back({});
            }
            node = trie[node].child[bit];
        }
        trie[node].latest = index;
    };
    insert(0, 0);
    int prefix = 0, best = -1, answerLeft = 1, answerRight = 1;
    for (int r = 1; r <= n; r++) {
        int x;
        cin >> x;
        prefix ^= x;
        int node = 0, value = 0;
        for (int b = 20; b >= 0; b--) {
            int bit = prefix >> b & 1;
            if (trie[node].child[bit ^ 1]) {
                value |= 1 << b;
                node = trie[node].child[bit ^ 1];
            } else
                node = trie[node].child[bit];
        }
        if (value > best) {
            best = value;
            answerLeft = trie[node].latest + 1;
            answerRight = r;
        }
        insert(prefix, r);
    }
    cout << best << ' ' << answerLeft << ' ' << answerRight;
    return 0;
}
```

### 复杂度

时间、最坏空间均为 $O(21n)$。

### 易错点

社会等级越高对应编号越小，所以并列优先结束下标小。重复前缀要保留最新位置才能满足次级的最短长度要求。
