## [NOIP2013]车站分级

### 题意

每趟车停站的级别高于区间内全部不停站，求最少等级。

### 思路

对每趟车引入一个虚拟结点：区间内每个不停站向虚拟点连权0边，虚拟点向每个停站连权1边，表示后者等级至少比前者高1。这样每趟只连O(n)条边，避免所有不停站与停站两两连边。输入保证约束可满足，所以图是DAG。原车站初始等级1，虚拟点初始0，拓扑排序时做最长路转移level[v]=max(level[v],level[u]+w)。最终原车站最大等级就是最少分级数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, int>>> graph(n + m);
    vector<int> degree(n + m), level(n + m);
    fill(level.begin(), level.begin() + n, 1);
    auto addEdge = [&](int a, int b, int w) {
        graph[a].push_back({b, w});
        degree[b]++;
    };
    for (int train = 0; train < m; train++) {
        int count;
        cin >> count;
        vector<int> stops(count);
        vector<bool> stopped(n);
        for (int &x : stops) {
            cin >> x;
            --x;
            stopped[x] = true;
        }
        int virtualNode = n + train;
        for (int x = stops.front(); x <= stops.back(); x++)
            if (!stopped[x])
                addEdge(x, virtualNode, 0);
        for (int x : stops)
            addEdge(virtualNode, x, 1);
    }
    vector<int> queue;
    for (int u = 0; u < n + m; u++)
        if (!degree[u])
            queue.push_back(u);
    for (size_t h = 0; h < queue.size(); h++) {
        int u = queue[h];
        for (auto [v, w] : graph[u]) {
            level[v] = max(level[v], level[u] + w);
            if (--degree[v] == 0)
                queue.push_back(v);
        }
    }
    cout << *max_element(level.begin(), level.begin() + n);
    return 0;
}
```

### 复杂度

时间、空间均为 $O(nm+n+m)$。

### 易错点

只约束始发和终点之间的站。虚拟点的入边权0、出边权1，一条高一级约束不能被算成两级。
