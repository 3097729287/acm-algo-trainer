## 病菌感染

### 题意

每个空格至少有两个已感染四邻格才感染，初始感染数 m 严格小于边长 n，问能否铺满。

### 思路

考虑所有感染格组成图形的周长。初始每格至多贡献四条边，总周长至多 4m。新增格与 k≥二个感染邻格相接，周长变化为 4-2k≤零，所以周长不可能增大。整个 n×n 方格的周长为 4n，但 m<n 导致初始周长严格小于 4n，因此无论初始位置如何都不可能铺满，只能输出 NO。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int x, y;
        cin >> x >> y;
    }
    cout << "NO";
    return 0;
}
```

### 复杂度

读完输入时间 $O(m)$，额外空间 $O(1)$。

### 易错点

结论使用了当前题面 m<n 的严格限制，不能推广成“任意初始感染都不可能铺满”。不需要分配一百万格或逐轮模拟。
