## 【模板】最小圆覆盖Ⅰ ‖ 小范围

### 题意

求覆盖全部给定点的最小圆的半径与圆心。

### 思路

最小覆盖圆由至多三个边界点决定。随机打乱点，逐个加入；新点已在圆内就不变，否则它必须在新圆边界上，先把圆重置为这个点。重新扫描之前的点，若又遇到外点，就固定这两个点，先取它们为直径；继续检查更早的点，仍在圆外时，由三个边界点求外接圆。这是固定边界点数量逐层增加的增量算法，最多三层。随机顺序使触发重建的概率很小，期望线性。两点圆用中点，三点圆解垂直平分线的二元方程；共线时取最远两点为直径。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    long double x, y;
};
struct Circle {
    Point center;
    long double square;
};
long double distance2(Point a, Point b) {
    return (a.x - b.x) * (a.x - b.x) + (a.y - b.y) * (a.y - b.y);
}
Circle diameter(Point a, Point b) {
    Point center{(a.x + b.x) / 2, (a.y + b.y) / 2};
    return {center, distance2(a, b) / 4};
}
bool outside(Circle c, Point p) {
    return distance2(c.center, p) > c.square + 1e-12L * max(1.0L, c.square);
}
Circle through(Point a, Point b, Point c) {
    long double ux = b.x - a.x, uy = b.y - a.y, vx = c.x - a.x, vy = c.y - a.y,
                determinant = 2 * (ux * vy - uy * vx);
    if (fabsl(determinant) < 1e-18L) {
        Circle result = diameter(a, b), ac = diameter(a, c), bc = diameter(b, c);
        if (ac.square > result.square)
            result = ac;
        if (bc.square > result.square)
            result = bc;
        return result;
    }
    long double u2 = ux * ux + uy * uy, v2 = vx * vx + vy * vy;
    Point center{a.x + (u2 * vy - v2 * uy) / determinant, a.y + (ux * v2 - vx * u2) / determinant};
    return {center, distance2(center, a)};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<Point> a(n);
    for (auto &p : a)
        cin >> p.x >> p.y;
    mt19937 generator(20261108);
    shuffle(a.begin(), a.end(), generator);
    Circle circle{a[0], 0};
    for (int i = 1; i < n; i++)
        if (outside(circle, a[i])) {
            circle = {a[i], 0};
            for (int j = 0; j < i; j++)
                if (outside(circle, a[j])) {
                    circle = diameter(a[i], a[j]);
                    for (int k = 0; k < j; k++)
                        if (outside(circle, a[k]))
                            circle = through(a[i], a[j], a[k]);
                }
        }
    cout << fixed << setprecision(12) << sqrtl(circle.square) << '\n'
         << circle.center.x << ' ' << circle.center.y;
    return 0;
}
```

### 复杂度

随机顺序下期望时间 $O(n)$，最坏 $O(n^3)$；输入存储空间 $O(n)$。

### 易错点

最小圆圆心一般不是点的算术平均值。共线点没有三点外接圆，必须处理；判断在圆内时用很小的容差，输出保留足够位数。
