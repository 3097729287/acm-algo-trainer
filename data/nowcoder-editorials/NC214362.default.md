## 第 k 小

### 题意

只插入元素，多次查询固定的第 k 小，不足 k 个输出负一。

### 思路

维护一个最多有 k 个元素的大根堆，始终保留已经出现的最小 k 个数。每次插入后，若超过 k 个就删除最大者。因此满 k 个时堆顶恰是第 k 小；未满则不存在答案。重复值作为独立元素保留。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    priority_queue<int> heap;
    auto insert = [&](int x) {
        heap.push(x);
        if ((int)heap.size() > k)
            heap.pop();
    };
    for (int i = 0, x; i < n; i++) {
        cin >> x;
        insert(x);
    }
    while (m--) {
        int type;
        cin >> type;
        if (type == 1) {
            int x;
            cin >> x;
            insert(x);
        } else
            cout << ((int)heap.size() < k ? -1 : heap.top()) << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O((n+m)\log k)$，空间 $O(k)$。

### 易错点

k 固定才可以丢弃更大的元素。第 k 小按重数计，不能用会去重的 set。
