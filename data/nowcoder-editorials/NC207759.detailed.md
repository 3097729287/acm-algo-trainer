## 几乎毁灭牛市的流星雨

> 原题：[P2895](https://www.luogu.com.cn/problem/P2895)
> 解法：记录各格最早毁灭时刻，搜索首次到达永久安全点 · C++17

### 题意

陨石在指定时刻毁掉自身及四邻格，毁灭不可恢复。起点为原点，每秒向第一象限四邻移动，求最早逃到永不毁灭的位置。



### 思路

同一个格子被多颗陨石影响时，最早一次已经把它永久毁掉，后来的时刻没有恢复作用，故必须取最小值。到达时刻恰好等于毁灭时刻也会被击中，判定是严格小于。

当前安全与永久安全不同。一个时刻五才毁掉的格，时刻二可以经过，却不能在这里结束逃生。BFS 只有到达从未受任何陨石影响的格，才能报告成功。

对固定格，越早到达越有利：所有通行约束都是“到达时间早于某个上限”，后到不会得到任何新通路。所以每格只保存首次到达，不必把时间加入无限状态。初始原点若时刻零已毁灭，不能先移动逃走；若原点永远安全，答案就是零。

坐标范围为什么有限？陨石坐标不超过三百，四邻影响最多到三百零一。因此横坐标或纵坐标达到三百零二的格一定永久安全。任何往更远处逃的路径，之前就已走过这种安全格；搜索零到三百零二的方框足以找到最优终点，不会漏掉更远处的更优答案。

第一象限包含两条坐标轴，坐标零可以走，负坐标不能走。

设固定网格边长为 L=303，时间 $O(M+L^2)$、空间 $O(L^2)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int size = 303, inf = 1000000000;
    vector<vector<int>> destroy(size, vector<int>(size, inf));
    int m;
    cin >> m;
    int dr[] = {0, 1, -1, 0, 0}, dc[] = {0, 0, 0, 1, -1};
    for (int i = 0; i < m; i++) {
        int x, y, t;
        cin >> x >> y >> t;
        for (int d = 0; d < 5; d++) {
            int nx = x + dr[d], ny = y + dc[d];
            if (0 <= nx && nx < size && 0 <= ny && ny < size)
                destroy[nx][ny] = min(destroy[nx][ny], t);
        }
    }
    if (destroy[0][0] == 0) {
        cout << -1 << '\n';
        return 0;
    }
    vector<vector<int>> distance(size, vector<int>(size, -1));
    queue<pair<int, int>> todo;
    todo.push({0, 0});
    distance[0][0] = 0;
    while (!todo.empty()) {
        auto [x, y] = todo.front();
        todo.pop();
        if (destroy[x][y] == inf) {
            cout << distance[x][y] << '\n';
            return 0;
        }
        for (int d = 1; d < 5; d++) {
            int nx = x + dr[d], ny = y + dc[d], arrival = distance[x][y] + 1;
            // 等于毁灭时刻也来不及，只有严格更早才能进入。
            if (0 <= nx && nx < size && 0 <= ny && ny < size && distance[nx][ny] == -1 &&
                arrival < destroy[nx][ny]) {
                distance[nx][ny] = arrival;
                todo.push({nx, ny});
            }
        }
    }
    cout << -1 << '\n';
    return 0;
}
```

### 易错点

毁灭取最早时刻；到达需严格早于毁灭；永久安全才是终点；原点时刻零已毁灭直接失败。
