## 圆凸包

### 题意

求多个圆盘凸包的周长，圆之间可包含或相交。

### 思路

方向$u=(\cos\theta,\sin\theta)$上的支撑值是$h(\theta)=\max_i(x_i\cos\theta+y_i\sin\theta+r_i)$。凸体周长等于$\int_0^{2\pi}h(\theta)\,d\theta$；平移产生的正弦、余弦积分恰抵消。

两圆支撑值相等时满足Δx*cosθ+Δy*sinθ=Δr，最多两个解。枚举所有这样的角，再加0和2π排序；相邻事件间最外圆固定，用中点找它并精确积分：x(sin右−sin左)−y(cos右−cos左)+r(右−左)。被包含的圆从不成为严格最大，自然不贡献；相同圆也不影响结果。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    const long double pi = acosl(-1.0L);
    while (tests--) {
        int n;
        cin >> n;
        struct Disc {
            Point c;
            long double r;
        };
        vector<Disc> p(n);
        for (auto &d : p)
            cin >> d.c.x >> d.c.y >> d.r;
        vector<long double> event = {0, 2 * pi};
        auto normalize = [&](long double a) {
            a = fmodl(a, 2 * pi);
            if (a < 0)
                a += 2 * pi;
            return a;
        };
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++) {
                Point d = p[i].c - p[j].c;
                long double length = norm(d), value = p[j].r - p[i].r;
                if (length > 0 && fabsl(value) <= length) {
                    long double base = atan2l(d.y, d.x),
                                delta = acosl(clamp(value / length, -1.0L, 1.0L));
                    event.push_back(normalize(base + delta));
                    event.push_back(normalize(base - delta));
                }
            }
        sort(event.begin(), event.end());
        long double answer = 0;
        for (int j = 1; j < (int)event.size(); j++) {
            long double l = event[j - 1], r = event[j], mid = (l + r) / 2;
            int best = 0;
            auto support = [&](int i) {
                return p[i].c.x * cosl(mid) + p[i].c.y * sinl(mid) + p[i].r;
            };
            for (int i = 1; i < n; i++)
                if (support(i) > support(best))
                    best = i;
            auto d = p[best];
            answer += d.c.x * (sinl(r) - sinl(l)) - d.c.y * (cosl(r) - cosl(l)) + d.r * (r - l);
        }
        cout << fixed << setprecision(12) << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n^3+n^2\log n)$，空间 $O(n^2)$。

### 易错点

仅对圆心求凸包再加某个统一半径，只适用于所有半径相同。这里每个圆的半径都参与支撑值比较。
