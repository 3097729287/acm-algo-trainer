## [NOIP2017]图书管理员

### 题意

每位读者指定编码后缀，求满足后缀的最小图书编码。

### 思路

先将所有图书编码递增排序。后缀长度为 d 时，编码的最后 d 位就是对 10^d 取余。每个查询从最小编码开始扫描，第一个余数等于需求码的书就是答案，没有则负一。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    vector<long long> a(n);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    while (q--) {
        int length;
        long long code;
        cin >> length >> code;
        long long mod = 1;
        for (int i = 0; i < length; i++)
            mod *= 10;
        long long ans = -1;
        for (long long x : a)
            if (x % mod == code) {
                ans = x;
                break;
            }
        cout << ans << '\n';
    }
    return 0;
}
```

### 复杂度

排序 $O(n\log n)$，查询合计 $O(nq)$，数组空间 $O(n)$。

### 易错点

需求码相同但长度不同，应使用不同的模数。重复图书编码无需删除。
