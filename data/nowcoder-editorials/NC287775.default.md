## 大水题

### 题意

反复求各位数字之和，直到只剩一位。

### 思路

直接按定义模拟即可：数至少为十时，不断除十、取余求各位和，再替换原数。每轮都会缩小，输入最多十位，很快就会剩一位。也可利用同余九得到正整数的数根 (n-1)%9+1。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    while (n >= 10) {
        int sum = 0;
        while (n) {
            sum += n % 10;
            n /= 10;
        }
        n = sum;
    }
    cout << n;
    return 0;
}
```

### 复杂度

时间为各轮处理的十进制位数总和，额外空间 $O(1)$。

### 易错点

停止条件是小于十；不能把九的倍数输出为零。
