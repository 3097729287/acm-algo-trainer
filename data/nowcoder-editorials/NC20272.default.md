## [SCOI2009]生日快乐

### 题意

用平行于边的贯穿切割把矩形分成N块等面积小矩形，最小化最大长宽比。

### 思路

当前矩形x×y要分k人。第一刀若一边给i人，面积必须占i/k，因此横切两块边长分别为 x*i/k、x*(k−i)/k，纵切同理。枚举i=1到k−1和两种方向，递归求两块各自的最优值；当前方案取两者最大值，再对所有切法取最小。k=1时直接返回max(x/y,y/x)。每个完整切割方案都有某一条第一刀，所以枚举不会漏。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    double x, y;
    int n;
    cin >> x >> y >> n;
    auto solve = [&](auto &&self, double a, double b, int count) -> double {
        if (count == 1)
            return max(a / b, b / a);
        double answer = 1e100;
        for (int left = 1; left < count; left++) {
            double ratio = (double)left / count;
            answer = min(answer, max(self(self, a * ratio, b, left),
                                     self(self, a * (1 - ratio), b, count - left)));
            answer = min(answer, max(self(self, a, b * ratio, left),
                                     self(self, a, b * (1 - ratio), count - left)));
        }
        return answer;
    };
    cout << fixed << setprecision(6) << solve(solve, x, y, n);
    return 0;
}
```

### 复杂度

递归调用数满足 $T(k)=4\sum_{i<k}T(i)+O(k)$，可界为 $O(5^N)$；栈空间 $O(N)$，$N\le10$。

### 易错点

不能只切等宽条；各子矩形可选不同切割方向。每刀分配的人数必须是整数，面积比例才确定。
