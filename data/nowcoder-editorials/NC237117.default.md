## A New Tetris Game(2)

### 题意

多个有禁格棋盘放2×2，最后不能放者输。

### 思路

把每个初始可放的2×2位置视为一种动作，两个动作若共享格子就冲突。状态mask表示仍可选动作，选择i后删除其自身及全部冲突邻居，SG取所有后继SG的mex。R*C<50且可用格≤40，动作数量可用64位保存。

若剩余动作冲突图分成连通分量，不同分量独立，SG是各分量SG异或。每次先按位BFS拆分，再对连通状态记忆化搜索，减少长条棋盘和分裂局面的重复枚举。不同棋盘再作SG异或。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int boards;
    cin >> boards;
    int total = 0;
    while (boards--) {
        int rows, cols;
        cin >> rows >> cols;
        vector<string> grid(rows);
        for (auto &s : grid)
            cin >> s;
        vector<unsigned long long> cells;
        for (int r = 0; r + 1 < rows; r++)
            for (int c = 0; c + 1 < cols; c++)
                if (grid[r][c] == '0' && grid[r + 1][c] == '0' && grid[r][c + 1] == '0' &&
                    grid[r + 1][c + 1] == '0')
                    cells.push_back((1ULL << (r * cols + c)) | (1ULL << (r * cols + c + 1)) |
                                    (1ULL << ((r + 1) * cols + c)) |
                                    (1ULL << ((r + 1) * cols + c + 1)));
        int moves = cells.size();
        vector<unsigned long long> conflict(moves);
        for (int i = 0; i < moves; i++)
            for (int j = 0; j < moves; j++)
                if (cells[i] & cells[j])
                    conflict[i] |= 1ULL << j;
        unordered_map<unsigned long long, int> memo;
        memo[0] = 0;
        auto grundy = [&](auto &&self, unsigned long long mask) -> int {
            auto found = memo.find(mask);
            if (found != memo.end())
                return found->second;
            unsigned long long component = 0, frontier = mask & -mask;
            while (frontier) {
                component |= frontier;
                unsigned long long next = 0;
                for (auto bits = frontier; bits; bits &= bits - 1)
                    next |= conflict[__builtin_ctzll(bits)];
                frontier = next & mask & ~component;
            }
            if (component != mask)
                return memo[mask] = self(self, component) ^ self(self, mask ^ component);
            unsigned long long seen = 0;
            for (auto bits = mask; bits; bits &= bits - 1) {
                int i = __builtin_ctzll(bits);
                seen |= 1ULL << self(self, mask & ~conflict[i]);
            }
            int value = __builtin_ctzll(~seen);
            return memo[mask] = value;
        };
        total ^= grundy(grundy, moves ? (1ULL << moves) - 1 : 0);
    }
    cout << (total ? "Yes" : "No");
    return 0;
}
```

### 复杂度

设初始动作数M（本范围小于64）、访问状态数Z，最坏 $O(ZM²)$，空间 $O(Z+M)$；连通分解通常显著减少Z。

### 易错点

压缩的是可放动作，状态转移必须删除所有重叠动作。空棋盘SG=0。精确记忆化最坏仍指数。
