## 蛇形矩阵

### 题意

按斜对角线往返填写蛇形矩阵。

### 思路

同一条斜线上的格子满足 row+col=s。s 为奇数时行号递增，s 为偶数时行号递减。每条斜线可用的行号范围是 max(0,s-n+1) 到 min(n-1,s)，列号由 s-row 得到。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    int value = 1;
    for (int s = 0; s <= 2 * n - 2; s++) {
        int lo = max(0, s - n + 1), hi = min(n - 1, s);
        if (s % 2) {
            for (int i = lo; i <= hi; i++)
                a[i][s - i] = value++;
        } else {
            for (int i = hi; i >= lo; i--)
                a[i][s - i] = value++;
        }
    }
    for (auto &row : a) {
        for (int j = 0; j < n; j++) {
            if (j)
                cout << ' ';
            cout << row[j];
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间与矩阵空间均为 $O(n^2)$。

### 易错点

这是斜对角蛇形，不是逐行左右往返。跨过主反对角线后，每条斜线的长度会递减。
