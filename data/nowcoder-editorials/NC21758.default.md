## little w and Discretization

### 题意

子数组独立离散化，求数值发生变化的元素个数。

### 思路

正整数x离散化后仍等于x，当且仅当区间内1..x全部出现。令M为区间最小缺失正整数mex，则不变元素恰为值<M的元素，其余全变。

按右端点建可持久化值域树，节点同时记录出现总数count和每种值最近出现位置的最小值minimum。版本R中，mex就是第一个最近位置<L的值：看左子树minimum是否<L决定向左或向右。随后用版本R与L−1之差统计值<M的频次，答案为长度减去该频次。

值域只需1..n+1，超出值域的数一定改变，可不插入。空节点minimum=0，正确表示从未出现。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Node {
        int left = 0, right = 0, count = 0, minimum = 0;
    };
    vector<Node> tree;
    tree.reserve((size_t)n * 21 + 1);
    tree.emplace_back();
    vector<int> root(n + 1);
    auto update = [&](auto &&self, int old, int l, int r, int position, int time) -> int {
        int u = tree.size();
        tree.push_back(tree[old]);
        tree[u].count++;
        if (l == r) {
            tree[u].minimum = time;
            return u;
        }
        int mid = (l + r) / 2;
        if (position <= mid)
            tree[u].left = self(self, tree[old].left, l, mid, position, time);
        else
            tree[u].right = self(self, tree[old].right, mid + 1, r, position, time);
        tree[u].minimum = min(tree[tree[u].left].minimum, tree[tree[u].right].minimum);
        return u;
    };
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        root[i] = x <= n + 1 ? update(update, root[i - 1], 1, n + 1, x, i) : root[i - 1];
    }
    auto prefix = [&](auto &&self, int u, int l, int r, int bound) -> int {
        if (!u || bound < l)
            return 0;
        if (r <= bound)
            return tree[u].count;
        int mid = (l + r) / 2;
        return self(self, tree[u].left, l, mid, bound) +
               self(self, tree[u].right, mid + 1, r, bound);
    };
    int q;
    cin >> q;
    while (q--) {
        int l, r;
        cin >> l >> r;
        int u = root[r], low = 1, high = n + 1;
        while (low < high) {
            int mid = (low + high) / 2;
            if (tree[tree[u].left].minimum < l) {
                u = tree[u].left;
                high = mid;
            } else {
                u = tree[u].right;
                low = mid + 1;
            }
        }
        int unchanged = prefix(prefix, root[r], 1, n + 1, low - 1) -
                        prefix(prefix, root[l - 1], 1, n + 1, low - 1);
        cout << r - l + 1 - unchanged << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O((n+q)\log n)$，空间 $O(n\log n)$。

### 易错点

离散化rank不可能大于原正整数值；只找mex还不够，答案要按元素出现次数计数，重复元素不能去重。
