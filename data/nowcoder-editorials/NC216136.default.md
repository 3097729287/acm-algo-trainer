## Alanyyds

### 题意

统计昵称中包含 alan 的人数，不区分大小写。

### 思路

每个昵称单独转小写，检查 find("alan") 是否成功。只要包含一次就把人数加一，同一昵称出现多次 alan 也只计一个人。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int ans = 0;
    while (n--) {
        string s;
        cin >> s;
        for (char &c : s)
            c = tolower(static_cast<unsigned char>(c));
        if (s.find("alan") != string::npos)
            ans++;
    }
    cout << ans;
    return 0;
}
```

### 复杂度

时间为所有昵称总长度，空间为最长昵称长度。

### 易错点

昵称可能含数字与符号，但这些字符不影响固定子串检查。
