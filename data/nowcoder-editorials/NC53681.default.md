## 「土」巨石滚滚

### 题意

安排先损失 a、再回复 b 的障碍顺序，判断初始稳定性能否完成全部障碍。

### 思路

先处理 b>=a 的不亏障碍，按 a 升序；越容易的增益越应先拿，完成后不会降低后续可行性。再处理 b<a 的亏损障碍，按 b 降序。对两个亏损障碍 A、B，若 bA>=bB，先 A 再 B 所需初始量 max(aA,aA-bA+aB)，不超过反序所需的 max(aB,aB-bB+aA)，因此该顺序安全。按排序模拟，每次先检查当前量至少为 a，再加 b-a。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n;
        long long stability;
        cin >> n >> stability;
        vector<pair<long long, long long>> a(n);
        for (auto &[loss, gain] : a)
            cin >> loss >> gain;
        sort(a.begin(), a.end(), [](const auto &x, const auto &y) {
            bool gx = x.second >= x.first, gy = y.second >= y.first;
            if (gx != gy)
                return gx > gy;
            return gx ? x.first < y.first : x.second > y.second;
        });
        bool possible = true;
        for (auto [loss, gain] : a) {
            if (stability < loss) {
                possible = false;
                break;
            }
            stability += gain - loss;
        }
        cout << (possible ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

必须先承担损失才收到回复；即使 a=b，也不能在当前稳定性小于 a 时通过。零稳定性允许存在，负数才散架。
