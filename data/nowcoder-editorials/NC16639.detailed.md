## [NOIP2007]奖学金

> 原题：[P1093](https://www.luogu.com.cn/problem/P1093)
> 解法：三关键字排序 · C++17

### 题意

按总分降序、语文降序、学号升序评选奖学金，输出前五名的学号与总分。



### 思路

总分相同时不能立即按学号排序，还要先比较语文。例如两个学生同为二百七十九分，语文高者应在前，即使学号更大。结构体把总分、语文分和学号作为同一条记录保存；比较器在第一项不同的时候就返回结果，只有相等才看下一项。学号按输入次序从一编号，最后一层规则让不同学生的先后唯一。

时间 $O(n\log n)$、空间 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
struct Scholar {
    int id, chinese, total;
};
bool before(const Scholar &a, const Scholar &b) {
    if (a.total != b.total)
        return a.total > b.total;
    if (a.chinese != b.chinese)
        return a.chinese > b.chinese;
    return a.id < b.id;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<Scholar> a(n);
    for (int i = 0; i < n; i++) {
        int math, english;
        cin >> a[i].chinese >> math >> english;
        a[i].id = i + 1;
        a[i].total = a[i].chinese + math + english;
    }
    sort(a.begin(), a.end(), before);
    for (int i = 0; i < 5; i++)
        cout << a[i].id << ' ' << a[i].total << '\n';
    return 0;
}
```

### 易错点

第二关键字只有语文，不是数学；输出的是学号和总分。
