## [NOIP2009]Hankson的趣味题

### 题意

统计gcd(x,a0)=a1且lcm(x,b0)=b1的正整数x。

### 思路

x必为b1约数。分解b1，对每个质因子p枚举x的指数e=0..v_p(b1)，只保留min(e,v_p(a0))=v_p(a1)、max(e,v_p(b0))=v_p(b1)的指数。各素因子独立，可选指数数相乘。若a1不整除b1，直接无解；如此a0中不在b1里的质因子必不在a1中，不会产生额外约束。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const int limit = 44722;
    vector<bool> composite(limit + 1);
    vector<int> primes;
    for (int p = 2; p <= limit; p++)
        if (!composite[p]) {
            primes.push_back(p);
            if (1LL * p * p <= limit)
                for (int x = p * p; x <= limit; x += p)
                    composite[x] = true;
        }
    int tests;
    cin >> tests;
    while (tests--) {
        long long a0, a1, b0, b1;
        cin >> a0 >> a1 >> b0 >> b1;
        if (b1 % a1) {
            cout << 0 << '\n';
            continue;
        }
        long long remaining = b1, answer = 1;
        auto consume = [&](long long p) {
            auto exponent = [&](long long x) {
                int result = 0;
                while (x % p == 0) {
                    result++;
                    x /= p;
                }
                return result;
            };
            int aa = exponent(a0), ab = exponent(a1), ba = exponent(b0), bb = exponent(b1),
                choices = 0;
            for (int e = 0; e <= bb; e++)
                if (min(e, aa) == ab && max(e, ba) == bb)
                    choices++;
            answer *= choices;
            while (remaining % p == 0)
                remaining /= p;
        };
        for (int p : primes) {
            if (1LL * p * p > remaining)
                break;
            if (remaining % p == 0)
                consume(p);
        }
        if (remaining > 1)
            consume(remaining);
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

预筛 $O(U\log\log U)$；每组 $O(\pi(\sqrt {b1})+\log(a0b1))$，空间 $O(U)$。

### 易错点

不用逐个枚举x或b1的全部因子。最后残留的大素因子也要处理；题目已保证a1|a0、b0|b1。
