## 「土」秘法地震

### 题意

统计地图中含至少一座建筑的 k 乘 k 正方形窗口数。

### 思路

二维前缀和 prefix[r][c] 保存左上矩形建筑数量。枚举所有能完整放入地图的 k 乘 k 窗口，用四项容斥得到窗口总和；大于零就让答案加一。即使窗口内有多个建筑也只算一种施法位置。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    vector<vector<int>> prefix(n + 1, vector<int>(m + 1));
    for (int r = 1; r <= n; r++)
        for (int c = 1; c <= m; c++) {
            char x;
            cin >> x;
            prefix[r][c] = prefix[r - 1][c] + prefix[r][c - 1] - prefix[r - 1][c - 1] + (x == '1');
        }
    int answer = 0;
    for (int r = k; r <= n; r++)
        for (int c = k; c <= m; c++)
            if (prefix[r][c] - prefix[r - k][c] - prefix[r][c - k] + prefix[r - k][c - k] > 0)
                answer++;
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(nm)$。

### 易错点

矩阵样例是不带空格的字符串，逐字符读入也能兼容有空格的写法。窗口不能越出地图。
