## 最大的差

### 题意

在 n 个整数中选两个，求最大的差值。

### 思路

任意差都不超过最大值减最小值，直接选这两个极值就能取到上界。读取时同时维护最大与最小值，最后相减。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    int lo = INT_MAX, hi = INT_MIN;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        lo = min(lo, x);
        hi = max(hi, x);
    }
    cout << hi - lo;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

数组可以全负，最大值不能随意初始化为零。
