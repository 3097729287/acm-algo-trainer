## 栈和排序

### 题意

固定入栈顺序，允许随时出栈，求字典序最大的出栈序列。

### 思路

若栈顶小于尚未读入的最大数，现在弹出它会让下一位变小，所以应继续压栈等待更大数。反之，栈顶已经大于后面所有数，立即输出它就是当前能获得的最大下一项。预处理后缀最大值，每读入一项后反复弹出大于剩余后缀最大值的栈顶。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n), suffix(n + 1), st;
    for (int &x : a)
        cin >> x;
    for (int i = n - 1; i >= 0; i--)
        suffix[i] = max(suffix[i + 1], a[i]);
    bool first = true;
    for (int i = 0; i < n; i++) {
        st.push_back(a[i]);
        while (!st.empty() && st.back() > suffix[i + 1]) {
            if (!first)
                cout << ' ';
            first = false;
            cout << st.back();
            st.pop_back();
        }
    }
    return 0;
}
```

### 复杂度

每项进出栈各一次，时间与数组空间均为 $O(n)$。

### 易错点

不能通过排序改变入栈顺序。比较对象是还没入栈的整个后缀最大值，而不只是紧邻的下一个元素。
