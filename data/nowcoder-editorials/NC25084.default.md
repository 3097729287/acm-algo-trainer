## [USACO 2006 Nov S]Bad Hair Day

### 题意

每头牛向右看到第一头不矮于自己的牛之前，统计全部可见的更矮牛对数。

### 思路

从左到右扫描，栈中保存尚未被不矮者挡住的牛，身高严格递减。当前牛到来时，弹出所有身高小于等于它的栈顶，因为这些牛今后都被当前牛挡住。剩下的每头栈中牛都比当前牛高、且中间没有挡住它的牛，恰好都能看到当前牛，答案加栈大小，再将当前身高入栈。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> stack;
    long long answer = 0;
    for (int i = 0; i < n; i++) {
        long long height;
        cin >> height;
        while (!stack.empty() && stack.back() <= height)
            stack.pop_back();
        answer += stack.size();
        stack.push_back(height);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均为 $O(n)$。

### 易错点

同高牛也会遮挡，且看不到对方头顶，弹栈应使用小于等于。总对数可能超过 int。
