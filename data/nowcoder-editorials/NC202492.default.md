## 仓库选址

### 题意

在需求矩阵中选仓库，使需求次数乘曼哈顿距离的总和最小。

### 思路

横纵距离可分开：将每行需求加总，得到选仓库行号的一维带权绝对距离问题；每列同理。每一维都取累计权重首次达到总权重一半的位置，即带权中位数，然后求所有权重乘与该位置的距离。两个一维最小费用相加就是答案，仓库可位于有需求的格子。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        vector<long long> rows(m), columns(n);
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++) {
                long long x;
                cin >> x;
                rows[r] += x;
                columns[c] += x;
            }
        auto cost = [](const vector<long long> &weights) {
            long long total = accumulate(weights.begin(), weights.end(), 0LL), prefix = 0,
                      answer = 0;
            int median = 0;
            for (int i = 0; i < (int)weights.size(); i++) {
                prefix += weights[i];
                if (prefix * 2 >= total) {
                    median = i;
                    break;
                }
            }
            for (int i = 0; i < (int)weights.size(); i++)
                answer += weights[i] * abs(i - median);
            return answer;
        };
        cout << cost(rows) + cost(columns) << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(nm+n+m)$，额外空间 $O(n+m)$。

### 易错点

输入先给宽 n、高 m，之后是 m 行 n 列。每次需求只按题意计算运输距离，不额外乘二；样例首组答案二可核对这一点。
