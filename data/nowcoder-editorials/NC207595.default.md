## 糖果俱乐部

### 题意

选择若干整堆糖果，使总数为偶数且尽量多。

### 思路

先求所有糖果的和。若已经为偶数就全部带走；若为奇数，必须去掉奇数总量，最少可去掉最小的一堆奇数糖果。任何其他奇数总量至少包含一堆奇数，去除量不会更小。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long sum = 0;
    int odd = INT_MAX;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        sum += x;
        if (x % 2)
            odd = min(odd, x);
    }
    if (sum % 2)
        sum -= odd;
    cout << sum;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

总和为奇数时一定存在奇数堆，因此最小奇数一定有定义；允许最终选择零堆。
