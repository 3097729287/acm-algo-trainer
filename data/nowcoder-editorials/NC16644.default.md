## 字符串的展开

### 题意

按大小写、重复次数、正反序规则，展开合法减号。

### 思路

从左到右只检查原串。一个减号合法，当且仅当它不在两端、左右同为数字或同为小写字母，且左端严格小于右端。枚举两端之间的字符，按 p1 转换，再重复 p2 次，最后按 p3 决定是否反转整段填充串。两端字符本身仍由原串扫描正常输出。相邻字符之间没有待填字符，合法减号直接消失。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int p1, p2, p3;
    string s;
    cin >> p1 >> p2 >> p3 >> s;
    auto kind = [](char c) {
        return isdigit((unsigned char)c) ? 1 : islower((unsigned char)c) ? 2 : 0;
    };
    for (int i = 0; i < (int)s.size(); i++) {
        bool expand = s[i] == '-' && i > 0 && i + 1 < (int)s.size() && kind(s[i - 1]) &&
                      kind(s[i - 1]) == kind(s[i + 1]) && s[i - 1] < s[i + 1];
        if (!expand) {
            cout << s[i];
            continue;
        }
        string fill;
        for (char c = s[i - 1] + 1; c < s[i + 1]; c++) {
            char value = p1 == 3                                ? '*'
                         : p1 == 2 && islower((unsigned char)c) ? toupper((unsigned char)c)
                                                                : c;
            fill += string(p2, value);
        }
        if (p3 == 2)
            reverse(fill.begin(), fill.end());
        cout << fill;
    }
    return 0;
}
```

### 复杂度

设输出长度为 $L$，时间 $O(|s|+L)$，单段缓冲最多 $O(26p_2)$。

### 易错点

不要把展开后的字符串继续展开，也不要把减号两侧改成大写。a-b 要删减号，a-a 必须保留。
