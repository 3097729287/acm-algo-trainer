## [SCOI2007]降雨量

### 题意

部分年份降雨已知，判断“X是自Y以来最多”的真假或不确定。

### 思路

二分找到Y、X是否已知，并查询严格中间(Y,X)内已知雨量最大值M。若两端已知且rain[Y]<rain[X]，必假；X已知且M≥rain[X]，必假；X未知但Y已知且M≥rain[Y]，也必假，因为X既须大于M又不能超过Y。

排除矛盾后，只有两端都已知且X−Y等于两端记录下标差，才说明整段每一年都已记录，可输出true；否则仍有未知年份，输出maybe。未知两端也不应擅自补为0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct RangeMaximum {
    int size = 1;
    vector<long long> tree;
    RangeMaximum(int n) {
        while (size < n)
            size <<= 1;
        tree.assign(size * 2, LLONG_MIN);
    }
    void setValue(int p, long long value) {
        p += size;
        tree[p] = value;
        for (p >>= 1; p; p >>= 1)
            tree[p] = max(tree[p * 2], tree[p * 2 + 1]);
    }
    long long query(int l, int r) {
        long long result = LLONG_MIN;
        for (l += size, r += size; l < r; l >>= 1, r >>= 1) {
            if (l & 1)
                result = max(result, tree[l++]);
            if (r & 1)
                result = max(result, tree[--r]);
        }
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> year(n), rain(n);
    RangeMaximum maximum(n);
    for (int i = 0; i < n; i++) {
        cin >> year[i] >> rain[i];
        maximum.setValue(i, rain[i]);
    }
    int q;
    cin >> q;
    while (q--) {
        long long y, x;
        cin >> y >> x;
        int iy = lower_bound(year.begin(), year.end(), y) - year.begin(),
            ix = lower_bound(year.begin(), year.end(), x) - year.begin();
        bool knownY = iy < n && year[iy] == y, knownX = ix < n && year[ix] == x;
        int left = upper_bound(year.begin(), year.end(), y) - year.begin(),
            right = lower_bound(year.begin(), year.end(), x) - year.begin();
        long long middle = maximum.query(left, right);
        bool bad = (knownY && knownX && rain[iy] < rain[ix]) || (knownX && middle >= rain[ix]) ||
                   (knownY && !knownX && middle >= rain[iy]);
        if (bad)
            cout << "false\n";
        else if (knownY && knownX && x - y == ix - iy)
            cout << "true\n";
        else
            cout << "maybe\n";
    }
    return 0;
}
```

### 复杂度

预处理 $O(n\log n)$，每问 $O(\log n)$，空间 $O(n)$。

### 易错点

中间年份降雨必须严格小于X，因此相等也是假。年份可能为负，差值用64位。原查询语义为Y<X。
