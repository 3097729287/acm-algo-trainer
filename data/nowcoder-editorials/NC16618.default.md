## 排座椅

> 原题：[P1056](https://www.luogu.com.cn/problem/P1056)
> 解法：分别选择能隔开最多对的横纵通道 · C++17

### 题意

给出只在相邻位置交谈的同学对，选择规定条数的横向和纵向通道，使未被隔开的交谈对最少。



### 思路

上下相邻的交谈对只会被它们之间那条横线隔开，左右相邻同理。分别统计每条横线与竖线的收益，各自选收益最大的规定条数，最后按位置升序输出。

时间 $O(d+m\log m+n\log n)$、空间 $O(m+n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
void print_best(const vector<int> &counts, int number) {
    vector<pair<int, int>> rank;
    for (int i = 1; i < (int)counts.size(); i++)
        rank.push_back({counts[i], i});
    sort(rank.rbegin(), rank.rend());
    vector<int> answer;
    for (int i = 0; i < number; i++)
        answer.push_back(rank[i].second);
    sort(answer.begin(), answer.end());
    for (int i = 0; i < number; i++) {
        if (i)
            cout << ' ';
        cout << answer[i];
    }
    cout << '\n';
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int m, n, k, l, d;
    cin >> m >> n >> k >> l >> d;
    vector<int> rows(m), columns(n);
    while (d--) {
        int x, y, p, q;
        cin >> x >> y >> p >> q;
        if (x != p)
            ++rows[min(x, p)];
        else
            ++columns[min(y, q)];
    }
    print_best(rows, k);
    print_best(columns, l);
    return 0;
}
```

### 易错点

横通道编号来自行，纵通道来自列；选完按位置输出，不按收益顺序输出。
