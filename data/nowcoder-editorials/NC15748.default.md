## 旅游

### 题意

住宿点不能已被游览，首日固定在s，求最多天数。

### 思路

某日住宿会游览自身及所有邻点，因此全部住宿点必须两两不相邻；反过来任何包含s的独立集都可按任意顺序住宿。问题就是必须选s的树上最大独立集。以s为根，dp[u][1]=1+Σdp[v][0]，dp[u][0]=Σmax(dp[v][0],dp[v][1])，输出dp[s][1]。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct EulerTree {
    int n;
    vector<vector<int>> edge;
    vector<int> parent, depth, in, out, order;
    EulerTree(int n) : n(n), edge(n + 1), parent(n + 1), depth(n + 1), in(n + 1), out(n + 1) {}
    void add(int u, int v) {
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    void root(int start) {
        vector<int> stack = {start};
        parent[start] = 0;
        order.clear();
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            in[u] = order.size() + 1;
            order.push_back(u);
            for (int v : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    depth[v] = depth[u] + 1;
                    stack.push_back(v);
                }
        }
        vector<int> size(n + 1, 1);
        for (int i = (int)order.size() - 1; i >= 0; i--) {
            int u = order[i];
            out[u] = in[u] + size[u] - 1;
            if (parent[u])
                size[parent[u]] += size[u];
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, s;
    cin >> n >> s;
    EulerTree tree(n);
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        tree.add(u, v);
    }
    tree.root(s);
    vector<array<int, 2>> dp(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = tree.order[i];
        dp[u][1] = 1;
        for (int v : tree.edge[u])
            if (tree.parent[v] == u) {
                dp[u][0] += max(dp[v][0], dp[v][1]);
                dp[u][1] += dp[v][0];
            }
    }
    cout << dp[s][1];
    return 0;
}
```

### 复杂度

时间、空间均 $O(n)$。

### 易错点

首日s强制选中，不能输出根两个状态的最大值。题目没有要求每天住宿点与前一天相邻。
