## 魔法数字变换

### 题意

重复奇数乘三加一、偶数除二，统计首次变成一所需的操作数。

### 思路

只要 n 不等于一就执行一次规定变换，并将计数加一。给定范围不超过一百，直接模拟即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    cin >> n;
    int steps = 0;
    while (n != 1) {
        n = n % 2 ? 3 * n + 1 : n / 2;
        steps++;
    }
    cout << steps;
    return 0;
}
```

### 复杂度

若实际经过 $s$ 步，时间 $O(s)$，额外空间 $O(1)$。

### 易错点

输入一时零次操作已经完成；这题需要循环，与单次卡拉兹函数题不同。
