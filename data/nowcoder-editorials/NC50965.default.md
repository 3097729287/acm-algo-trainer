## Largest Rectangle in a Histogram

### 题意

多个单位宽柱状图中求最大矩形面积，读到 n=0 结束。

### 思路

栈保存高度不下降的柱下标。读到更矮柱 i 时，栈顶柱 j 的向右扩展第一次被挡住，弹栈后新的栈顶 left 是左侧边界，矩形可占 left+1 到 i-1，面积 h[j]*(i-left-1)。相等高度可暂时都留在栈中，最终最左的同高柱会覆盖完整跨度。末尾补一根零高柱，结算全部正高度。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n && n) {
        vector<long long> height(n + 2);
        for (int i = 1; i <= n; i++)
            cin >> height[i];
        vector<int> stack;
        long long answer = 0;
        for (int i = 1; i <= n + 1; i++) {
            while (!stack.empty() && height[stack.back()] > height[i]) {
                int j = stack.back();
                stack.pop_back();
                int left = stack.empty() ? 0 : stack.back();
                answer = max(answer, height[j] * (i - left - 1));
            }
            stack.push_back(i);
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间、空间均为 $O(n)$。

### 易错点

最高柱不一定给出最大面积。面积可达 10^14，使用 long long；结束标记零不是一个需输出答案的测试。
