## [HAOI2012]容易题(EASY)

### 题意

各位置可取1到n并排除指定值，求全部合法序列的乘积之和。

### 思路

由乘法分配律，所有序列的乘积之和等于各位置“允许值之和”的乘积。无约束位置的值和S=n(n+1)/2，共有m−不同受限位置数个，用S的快速幂一次处理。受限位置则从S减掉所有不同禁用值。把(x,y)排序去重，按x分组计算，避免重复限制重复扣减。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, m;
    int k;
    cin >> n >> m >> k;
    vector<pair<long long, long long>> forbidden(k);
    for (auto &[x, y] : forbidden)
        cin >> x >> y;
    sort(forbidden.begin(), forbidden.end());
    forbidden.erase(unique(forbidden.begin(), forbidden.end()), forbidden.end());
    const long long mod = 1000000007;
    long long total = n * (n + 1) / 2 % mod, answer = 1, groups = 0;
    for (int i = 0; i < (int)forbidden.size();) {
        int j = i;
        long long allowed = total;
        while (j < (int)forbidden.size() && forbidden[j].first == forbidden[i].first) {
            allowed = (allowed - forbidden[j].second % mod + mod) % mod;
            j++;
        }
        answer = answer * allowed % mod;
        groups++;
        i = j;
    }
    long long exponent = m - groups, base = total;
    while (exponent) {
        if (exponent & 1)
            answer = answer * base % mod;
        base = base * base % mod;
        exponent >>= 1;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(k\log k+\log m)$，空间 $O(k)$。

### 易错点

同一条限制可重复出现。某位置允许值之和模P为0时，直接让总乘积变0，无需做除法。
