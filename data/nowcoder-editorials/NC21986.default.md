## 【模板】牛牛学说话之-浮点数

### 题意

读入一个浮点数并输出，允许千分之一量级的误差。

### 思路

使用 double 读入，并以固定小数格式保留六位。样例中三位与九位两种写法表示同一个近似数，题目没有要求与样例保留相同位数。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    double x;
    cin >> x;
    cout << fixed << setprecision(6) << x;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不能用 int 保存小数；满足误差即可，不要为了模仿某个样例而截断精度。
