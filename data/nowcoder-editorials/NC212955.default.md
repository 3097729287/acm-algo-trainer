## 比大小

### 题意

比较两个整数，输出小于、等于或大于符号。

### 思路

依次判断 a<b、a==b，剩余情况就是 a>b。三个分支恰好覆盖所有输入。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    if (a < b)
        cout << '<';
    else if (a == b)
        cout << '=';
    else
        cout << '>';
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

只输出一个比较符，不输出双引号或解释文字。
