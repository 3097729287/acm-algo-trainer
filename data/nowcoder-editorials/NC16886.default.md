## [NOI2001]炮兵阵地

### 题意

平原可放炮兵，同一行或列距离一、二格不能互相攻击，最大化数量。

### 思路

一行用mask表示布置，行内合法要求mask与左移1、左移2均不相交，且不占山地。纵向约束跨最近两行，因此状态保留上一行和上上行。枚举当前行mask，只需与前两行分别不相交，转移加当前炮数。更远的行互不影响。初始两行都为空，答案取末行所有状态最大。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> blocked(n);
    for (int r = 0; r < n; r++) {
        string s;
        cin >> s;
        for (int c = 0; c < m; c++)
            if (s[c] == 'H')
                blocked[r] |= 1 << c;
    }
    vector<int> masks, count;
    for (int mask = 0; mask < (1 << m); mask++)
        if (!(mask & (mask << 1)) && !(mask & (mask << 2))) {
            masks.push_back(mask);
            count.push_back(__builtin_popcount((unsigned)mask));
        }
    int states = masks.size(), neg = -1000000000;
    vector<vector<int>> dp(states, vector<int>(states, neg));
    dp[0][0] = 0;
    for (int r = 0; r < n; r++) {
        vector<vector<int>> next(states, vector<int>(states, neg));
        for (int current = 0; current < states; current++)
            if (!(masks[current] & blocked[r]))
                for (int previous = 0; previous < states; previous++)
                    if (!(masks[current] & masks[previous]))
                        for (int older = 0; older < states; older++)
                            if (!(masks[current] & masks[older]) && dp[previous][older] != neg)
                                next[current][previous] = max(next[current][previous],
                                                              dp[previous][older] + count[current]);
        dp.swap(next);
    }
    int answer = 0;
    for (auto &row : dp)
        answer = max(answer, *max_element(row.begin(), row.end()));
    cout << answer;
    return 0;
}
```

### 复杂度

合法行状态数 $S\le60$，时间 $O(NS^3+2^M)$，空间 $O(S^2+N)$。

### 易错点

山地不能挡住炮火。必须同时检查上上行，只有上一行状态不够。
