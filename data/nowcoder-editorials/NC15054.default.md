## 添加逗号

### 题意

在整数的十进制表示中，从右往左每三位插入逗号。

### 思路

从左往右输出数字。如果当前不是首位，并且从当前位置到末尾的位数为三的倍数，就先输出逗号。这样从右侧数每三位恰好分一组。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    for (size_t i = 0; i < s.size(); i++) {
        if (i > 0 && (s.size() - i) % 3 == 0)
            cout << ',';
        cout << s[i];
    }
    return 0;
}
```

### 复杂度

时间与字符串空间均为 $O(|S|)$。

### 易错点

分组是从右侧开始，不能固定每输出三个字符就加逗号，否则首组长度会错误。
