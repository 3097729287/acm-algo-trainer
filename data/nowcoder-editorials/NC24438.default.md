## [USACO 2016 Ope P]262144

### 题意

相邻相等值可合成加一的值，最大化最后能生成的某个数字，N至262144。

### 思路

对目标值v，end[v][l]表示从l开始能完整合成一个v的区间的右开端点，不存在记0。若原a[l]=v，区间就是单点；否则要把两个相邻的v−1拼起来，设mid=end[v−1][l]，再接end[v−1][mid]。

为什么每个起点、目标值只有一个可能端点？把数x看成质量2^x，合并保持总质量；所有初始质量正，固定起点的前缀质量严格递增，所以给定2^v至多对应一个端点。只需上一层end数组，v最多40+log2N≤58，滚动处理并记录有解的最大v。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a)
        cin >> x;
    vector<int> previous(n + 1), current(n + 1);
    int answer = 0;
    for (int value = 1; value <= 58; value++) {
        fill(current.begin(), current.end(), 0);
        for (int l = n - 1; l >= 0; l--) {
            if (a[l] == value)
                current[l] = l + 1;
            else {
                int mid = previous[l];
                if (mid > 0 && mid < n)
                    current[l] = previous[mid];
            }
            if (current[l])
                answer = value;
        }
        previous.swap(current);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(58n)$，空间 $O(n)$。

### 易错点

不能总是先合并最左边的一对，样例已经给出反例。右端点用右开下标，n表示恰好用到末尾，不能再接第二段。
