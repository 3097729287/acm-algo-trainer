## Job Hunt

### 题意

每到一城可赚D，路免费、航线收费且可借款，求最大余额或可无限赚钱。

### 思路

初始在S先赚D。免费道路u→v增加D，航线增加D−票价，问题变为从S出发可随时结束的最长收益路。用Bellman-Ford最大化余额，仅从可达状态松弛。若第C轮仍有更新，存在从S可达的正收益环，可以无限重复，输出−1；否则最优路可删掉非正环，至多C−1条边，取所有城市余额最大值。允许用未来收入付机票，所以中间余额可为负，不能限制边的可走性。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int income, p, n, f, start;
    cin >> income >> p >> n >> f >> start;
    struct Edge {
        int a, b, gain;
    };
    vector<Edge> edges;
    for (int i = 0; i < p; i++) {
        int a, b;
        cin >> a >> b;
        edges.push_back({a - 1, b - 1, income});
    }
    for (int i = 0; i < f; i++) {
        int a, b, price;
        cin >> a >> b >> price;
        edges.push_back({a - 1, b - 1, income - price});
    }
    const long long neg = -(1LL << 60);
    vector<long long> best(n, neg);
    best[start - 1] = income;
    bool unlimited = false;
    for (int round = 1; round <= n; round++) {
        bool changed = false;
        for (auto e : edges)
            if (best[e.a] != neg && best[e.b] < best[e.a] + e.gain) {
                best[e.b] = best[e.a] + e.gain;
                changed = true;
            }
        if (!changed)
            break;
        if (round == n)
            unlimited = true;
    }
    cout << (unlimited ? -1 : *max_element(best.begin(), best.end()));
    return 0;
}
```

### 复杂度

时间 $O(C(P+F))$，空间 $O(C+P+F)$。

### 易错点

只需任意可达正环，不要求还能去某个指定终点。无法从S到达的正环不影响答案。起始城市的D也计入。
