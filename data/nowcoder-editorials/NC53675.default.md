## 「木」迷雾森林

### 题意

从左下走到右上，只能向上或向右，避开树，方案数模2333。

### 思路

反过来从右上向左下走，允许向下或向左，路径一一对应。这样可以按输入从上到下逐行处理，并在每行从右往左更新。dp[c]原来是上一行同列的方案，加上当前行右侧dp[c+1]；遇树则清零。首行右上角的起点单独初始化为1。只需保留一行，不存九百万格地图。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols;
    cin >> rows >> cols;
    vector<int> dp(cols + 1), blocked(cols);
    for (int r = 0; r < rows; r++) {
        for (int &x : blocked)
            cin >> x;
        for (int c = cols - 1; c >= 0; c--) {
            if (blocked[c])
                dp[c] = 0;
            else if (r == 0 && c == cols - 1)
                dp[c] = 1;
            else
                dp[c] = (dp[c] + dp[c + 1]) % 2333;
        }
    }
    cout << dp[0];
    return 0;
}
```

### 复杂度

时间 $O(mn)$，额外空间 $O(n)$。

### 易错点

原题起点在左下，按左上起点普通转移会算错。反向路径允许流式读取，仍需每行先读完才能倒序更新。
