## Redundant Paths

### 题意

加最少无向边让任意两点有两条边不重合路线。

### 思路

两条边不相交路径等价于没有桥。找出所有桥，把非桥边相连的点缩为边双连通分量，原连通图缩成一棵桥树。每个叶分量都需要至少一条新边接到外部，一条边最多照顾两个叶子，因此下界ceil(叶子数/2)；按DFS叶序跨半圈配对可让新边形成的环覆盖所有桥，达到下界。桥树只有一个节点时答案0。

参考代码用迭代DFS记录dfn/low，回退时判low[child]>dfn[parent]为桥。以边编号跳过父边，保留平行边的回边作用。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> parent, size;
    DSU(int n) : parent(n + 1), size(n + 1, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    bool unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b)
            return false;
        if (size[a] < size[b])
            swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, int>>> edge(n);
    vector<pair<int, int>> endpoints(m);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        u--;
        v--;
        endpoints[i] = {u, v};
        edge[u].push_back({v, i});
        edge[v].push_back({u, i});
    }
    vector<int> dfn(n), low(n), parent(n, -1), parentEdge(n, -1), next(n), stack = {0};
    vector<bool> bridge(m);
    int timer = 1;
    dfn[0] = low[0] = 1;
    while (!stack.empty()) {
        int u = stack.back();
        if (next[u] < (int)edge[u].size()) {
            auto [v, id] = edge[u][next[u]++];
            if (id == parentEdge[u])
                continue;
            if (!dfn[v]) {
                parent[v] = u;
                parentEdge[v] = id;
                dfn[v] = low[v] = ++timer;
                stack.push_back(v);
            } else
                low[u] = min(low[u], dfn[v]);
        } else {
            stack.pop_back();
            if (parent[u] >= 0) {
                int p = parent[u];
                low[p] = min(low[p], low[u]);
                if (low[u] > dfn[p])
                    bridge[parentEdge[u]] = true;
            }
        }
    }
    DSU dsu(n);
    for (int i = 0; i < m; i++)
        if (!bridge[i])
            dsu.unite(endpoints[i].first, endpoints[i].second);
    vector<int> degree(n);
    for (int i = 0; i < m; i++)
        if (bridge[i]) {
            degree[dsu.find(endpoints[i].first)]++;
            degree[dsu.find(endpoints[i].second)]++;
        }
    int leaves = 0;
    for (int x : degree)
        leaves += x == 1;
    cout << (leaves + 1) / 2;
    return 0;
}
```

### 复杂度

时间 $O(n+m\alpha(n))$，空间 $O(n+m)$。

### 易错点

原图允许重边，不能仅用父节点编号跳过所有返父边。题目保证原图连通。
