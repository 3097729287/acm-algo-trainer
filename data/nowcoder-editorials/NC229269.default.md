## Makes And The Product

### 题意

正整数数组中乘积最小的三下标组数量。

### 思路

正数乘积最小的值组合必是排序后前三项。令第三小值x，前三项中严格小于x的元素必须全部选；剩余need个位置从所有等于x的元素中任选，答案C(countX,need)，need只可能1、2、3。无需计算可能溢出的乘积。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a)
        cin >> x;
    sort(a.begin(), a.end());
    long long x = a[2], before = lower_bound(a.begin(), a.end(), x) - a.begin(),
              count = upper_bound(a.begin(), a.end(), x) - lower_bound(a.begin(), a.end(), x),
              need = 3 - before, answer = 1;
    for (int i = 1; i <= need; i++)
        answer = answer * (count - i + 1) / i;
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

不同下标算不同选择，重复数值要用组合数。所有数为正是取前三小值的前提。
