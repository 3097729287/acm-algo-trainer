## K 蝴蝶

### 题意

按输入顺序计算两个记忆量的差。

### 思路

直接输出a−b。样例2020与1906得到114，题目中的诗句不参与运算。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b;
    cin >> a >> b;
    cout << a - b;
    return 0;
}
```

### 复杂度

时间、空间均 $O(1)$。

### 易错点

保留输入顺序，不排序两个数。差值可能为负，使用有符号整数。
