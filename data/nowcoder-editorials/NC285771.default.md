## 小q的数列

### 题意

求二进制拆位递推值，以及该值第一次出现的下标。

### 思路

递推每次去掉最低二进制位，并加上这一位的零或一，因此 f(n) 就是二进制一的个数 k。具有 k 个一的最小整数，要把这些一放在最低的 k 位，得到 2^k-1。零的一数为零，最早下标也为零，统一公式仍成立。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        unsigned long long n;
        cin >> n;
        int ones = __builtin_popcountll(n);
        cout << ones << ' ' << ((1ULL << ones) - 1) << '\n';
    }
    return 0;
}
```

### 复杂度

每组在固定 64 位字长上计数，时间、空间均为 $O(1)$。

### 易错点

题面正数范围与含零样例不完全一致，代码一并支持零。n 最大 10^18，一的数量小于六十四，移位安全。
