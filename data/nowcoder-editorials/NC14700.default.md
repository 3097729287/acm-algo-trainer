## 追债之旅

### 题意

每条路走一天，抓人须不晚于k天，路费加每天累计挥霍最少。

### 思路

dp[d][v]为恰走d天到v的最少总损失。由前一天道路另一端转移，加本条路费和第d天的挥霍a[d]。每轮用新数组，避免同一天走多条路。终点可能早到更省，也可能走便宜的多段路更省，答案取0到k天所有终点状态的最小值。初态在1号城为0；n=1时可在第0天抓到。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    struct Edge {
        int a, b, w;
    };
    vector<Edge> edges(m);
    for (auto &e : edges) {
        cin >> e.a >> e.b >> e.w;
        --e.a;
        --e.b;
    }
    vector<int> waste(k + 1);
    for (int d = 1; d <= k; d++)
        cin >> waste[d];
    const long long inf = 1LL << 60;
    vector<long long> dp(n, inf);
    dp[0] = 0;
    long long answer = dp[n - 1];
    for (int day = 1; day <= k; day++) {
        vector<long long> next(n, inf);
        for (auto e : edges) {
            if (dp[e.a] != inf)
                next[e.b] = min(next[e.b], dp[e.a] + e.w + waste[day]);
            if (dp[e.b] != inf)
                next[e.a] = min(next[e.a], dp[e.b] + e.w + waste[day]);
        }
        dp.swap(next);
        answer = min(answer, dp[n - 1]);
    }
    cout << (answer == inf ? -1 : answer);
    return 0;
}
```

### 复杂度

时间 $O(k(n+m))$，空间 $O(n+m+k)$。

### 易错点

第d天的挥霍在所有当日转移中只加一次；不能只加到达那天的挥霍而漏掉之前各天。
