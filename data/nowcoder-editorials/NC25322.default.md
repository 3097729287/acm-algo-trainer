## 序列中整数去重

### 题意

保留每个数第一次出现的位置，按原顺序输出去重序列。

### 思路

用 seen[x] 记录此前是否输出过该数，依输入顺序扫描。未出现过时输出并打标记，出现过则跳过。这样既去重又保留第一次出现的顺序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    bool seen[5001] = {};
    bool first = true;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (!seen[x]) {
            if (!first)
                cout << ' ';
            cout << x;
            first = false;
            seen[x] = true;
        }
    }
    return 0;
}
```

### 复杂度

时间 $O(n+U)$，标记数组空间 $O(U)$，其中 $U=5000$。

### 易错点

不能排序后再去重，因为题目要求原输入顺序。
