## [USACO 2016 Jan S]Angry Cows

### 题意

用最多 K 个半径相同的爆炸闭区间覆盖数轴上所有草捆，求最小整数半径。

### 思路

排序后，半径 R 的爆炸最多覆盖长度 2R 的区间。每次取最左未覆盖点 x，把爆炸中心放在 x+R，使覆盖右端尽量到 x+2R；跳过这段内所有点。任何覆盖 x 的爆炸都不可能比这更向右，因此该贪心使用最少牛。次数不超过 K 则 R 可行，二分最小值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<long long> x(n);
    for (auto &v : x)
        cin >> v;
    sort(x.begin(), x.end());
    auto possible = [&](long long radius) {
        int next = 0, used = 0;
        while (next < n) {
            if (++used > k)
                return false;
            long long right = x[next] + 2 * radius;
            while (next < n && x[next] <= right)
                next++;
        }
        return true;
    };
    long long low = 0, high = x.back() - x.front();
    while (low < high) {
        long long mid = (low + high) / 2;
        if (possible(mid))
            high = mid;
        else
            low = mid + 1;
    }
    cout << low;
    return 0;
}
```

### 复杂度

时间 $O(n\log n+n\log X)$，空间 $O(n)$，$X$ 是坐标跨度。

### 易错点

爆炸中心不必是草捆位置。覆盖总长度为直径 2R，不是半径 R；一个点或已有足够多牛时允许 R=0。
