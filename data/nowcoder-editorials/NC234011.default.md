## Square Card

### 题意

正方形能旋转进入两个圆时，求同时获奖的条件概率。

### 思路

先确定可得分的正方形中心区域。中心距圆心为d时，旋转正方形，使一条边平行于中心连线，能使最远顶点距离最小，其平方为$(d+a/2)^2+(a/2)^2$。所以允许中心距为$\rho=\sqrt{r^2-a^2/4}-a/2$，可行中心区域是半径ρ的圆盘。

两次只要求“各自存在一个转角”，无需同一转角同时进入两个圆。因此条件概率是两个可行中心圆盘交面积除以第一圆盘面积。奖金圆若r≤a/√2，可行中心区域没有正面积，概率为0。相交面积分别处理相离、包含和相交两扇形减三角形。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

long double intersectionArea(long double r, long double s, long double d) {
    if (r <= 0 || s <= 0 || d >= r + s)
        return 0;
    const long double pi = acosl(-1.0L);
    if (d <= fabsl(r - s))
        return pi * min(r, s) * min(r, s);
    long double a = acosl(clamp((r * r + d * d - s * s) / (2 * r * d), -1.0L, 1.0L));
    long double b = acosl(clamp((s * s + d * d - r * r) / (2 * s * d), -1.0L, 1.0L));
    return r * r * (a - sinl(2 * a) / 2) + s * s * (b - sinl(2 * b) / 2);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        long double r, s, a;
        Point p, q;
        cin >> r >> p.x >> p.y >> s >> q.x >> q.y >> a;
        auto available = [&](long double radius) {
            if (2 * radius * radius <= a * a)
                return 0.0L;
            return sqrtl(radius * radius - a * a / 4) - a / 2;
        };
        r = available(r);
        s = available(s);
        cout << fixed << setprecision(6)
             << intersectionArea(r, s, distance(p, q)) / (acosl(-1.0L) * r * r) << '\n';
    }
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

不能直接把大圆半径减去正方形外接圆半径：允许旋转时可行中心更大。严格内含只排除边界，对连续概率无影响。
