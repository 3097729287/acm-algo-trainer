## 这河里吗？

### 题意

判断填满的九乘九盘面是否同时满足各行、各列、各宫一到九各一次。

### 思路

为每行、每列、每个三乘三宫建立出现标记。位置 (i,j) 所属宫号为 (i/3)*3+j/3。读入数值时检查范围以及三个标记中是否已有这个数，有任何重复即不合法。每组恰有九格，不重复且都在一到九内便意味着每种数字恰一次。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    bool rows[9][10] = {}, cols[9][10] = {}, boxes[9][10] = {};
    bool ok = true;
    for (int i = 0; i < 9; i++)
        for (int j = 0; j < 9; j++) {
            int x;
            cin >> x;
            int b = i / 3 * 3 + j / 3;
            if (x < 1 || x > 9) {
                ok = false;
                continue;
            }
            if (rows[i][x] || cols[j][x] || boxes[b][x])
                ok = false;
            rows[i][x] = cols[j][x] = boxes[b][x] = true;
        }
    cout << (ok ? "YES" : "NO");
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

只检查每行或每列的和等于四十五并不充分，重复值可能抵消。棋盘已经填满，不需要求解数独。
