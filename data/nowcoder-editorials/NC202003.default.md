## 数颜色

### 题意

支持单点改色和区间不同颜色计数，按本题 n、m 各一万及至多一千次修改范围处理。

### 思路

先读入全部操作，将初始颜色与修改中会出现的颜色统一离散化；最多一万一千种颜色。把位置按约一百个一块划分，每块维护每种颜色出现次数，以及哪些颜色存在的压位集合。修改时只更新一个块的两种计数与对应位。

查询时，零散边缘逐个把颜色位设为一，完整块则把该块位集按机器字或进临时集合，最后统计一的数量。位集做的是集合并，不会重复计颜色；块内频数则保证删掉一个位置后，只有同色真的消失才清位。这里能预读操作且范围较小，压位分块足够，不需要假定输入是强制在线。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> a(n), keys;
    for (int &x : a) {
        cin >> x;
        keys.push_back(x);
    }
    struct Operation {
        char type;
        int x, y;
    };
    vector<Operation> operations(m);
    for (auto &op : operations) {
        cin >> op.type >> op.x >> op.y;
        if (op.type == 'R')
            keys.push_back(op.y);
    }
    sort(keys.begin(), keys.end());
    keys.erase(unique(keys.begin(), keys.end()), keys.end());
    auto compressed = [&](int x) {
        return (int)(lower_bound(keys.begin(), keys.end(), x) - keys.begin());
    };
    for (int &x : a)
        x = compressed(x);
    for (auto &op : operations)
        if (op.type == 'R')
            op.y = compressed(op.y);
    int block = max(1, (int)sqrt(n)), blocks = (n + block - 1) / block, values = keys.size(),
        words = (values + 63) / 64;
    vector<vector<int>> count(blocks, vector<int>(values));
    vector<vector<unsigned long long>> present(blocks, vector<unsigned long long>(words));
    for (int i = 0; i < n; i++) {
        count[i / block][a[i]]++;
        present[i / block][a[i] / 64] |= 1ULL << (a[i] % 64);
    }
    for (auto op : operations) {
        if (op.type == 'R') {
            int p = op.x - 1, group = p / block, old = a[p];
            if (--count[group][old] == 0)
                present[group][old / 64] &= ~(1ULL << (old % 64));
            if (++count[group][op.y] == 1)
                present[group][op.y / 64] |= 1ULL << (op.y % 64);
            a[p] = op.y;
        } else {
            int l = op.x - 1, r = op.y - 1;
            vector<unsigned long long> colors(words);
            auto include = [&](int p) { colors[a[p] / 64] |= 1ULL << (a[p] % 64); };
            while (l <= r && l % block)
                include(l++);
            while (l + block - 1 <= r) {
                for (int w = 0; w < words; w++)
                    colors[w] |= present[l / block][w];
                l += block;
            }
            while (l <= r)
                include(l++);
            int answer = 0;
            for (auto word : colors)
                answer += __builtin_popcountll(word);
            cout << answer << '\n';
        }
    }
    return 0;
}
```

### 复杂度

设颜色种数为 $V$、块长 $B\approx\sqrt n$，修改 $O(1)$；查询 $O(B+(n/B)\lceil V/64\rceil)$，空间 $O((n/B)V+n+m)$。预处理离散化另需 $O((n+m)\log(n+m))$。

### 易错点

离散化时要包含未来修改的新颜色。修改成原颜色也合法，计数先减后加可正确还原。每条查询都重新清空临时集合。
