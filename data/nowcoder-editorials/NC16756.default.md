## 进制转换

### 题意

将十进制整数转换成指定的负进制，数码使用零到九及大写字母。

### 思路

反复做除基取余。负进制也要求数码非负，因此若 C++ 余数 r<0，就令 r-=base，并把商加一。这个调整仍保持 n=quotient*base+r。收集余数后反转，零单独输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n;
    int base;
    cin >> n >> base;
    long long original = n;
    string ans;
    const string digits = "0123456789ABCDEFGHIJ";
    do {
        long long q = n / base, r = n % base;
        if (r < 0) {
            r -= base;
            q++;
        }
        ans += digits[r];
        n = q;
    } while (n != 0);
    reverse(ans.begin(), ans.end());
    cout << original << '=' << ans << "(base" << base << ')';
    return 0;
}
```

### 复杂度

时间与数码空间均为 $O(\log_{|base|}(|N|+1))$。

### 易错点

调整余数后必须同时调整商；输出中保留原十进制数的符号，负进制数本身不用另加负号。
