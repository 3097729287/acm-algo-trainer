## 牛牛的考试

### 题意

按题面明确的唯一最短、唯一最长规则，在四个选项中作答。

### 思路

计算四行长度及最短、最长长度的出现次数。仅有唯一最短而没有唯一最长时选最短；仅有唯一最长而没有唯一最短时选最长。两者同时存在或都不存在时都选 C。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    string line;
    getline(cin, line);
    while (t--) {
        vector<int> length(4);
        for (int i = 0; i < 4; i++) {
            getline(cin, line);
            if (!line.empty() && line.back() == '\r')
                line.pop_back();
            length[i] = line.size();
        }
        int lo = *min_element(length.begin(), length.end()),
            hi = *max_element(length.begin(), length.end());
        int cl = count(length.begin(), length.end(), lo),
            ch = count(length.begin(), length.end(), hi), ans = 2;
        if (cl == 1 && ch != 1)
            ans = find(length.begin(), length.end(), lo) - length.begin();
        else if (ch == 1 && cl != 1)
            ans = find(length.begin(), length.end(), hi) - length.begin();
        cout << char('A' + ans) << '\n';
    }
    return 0;
}
```

### 复杂度

每题时间为四个选项总长度，额外空间为最长选项长度。

### 易错点

四个长度完全不同会同时有唯一最长和最短，按当前定义应选 C。使用 getline 保留选项整行。
