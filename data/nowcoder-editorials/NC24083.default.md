## Greedy Gift Takers

### 题意

队首牛领取礼物后按固定插队数归队，求永远拿不到礼物的牛数。

### 思路

未拿过礼物的牛之间不能互相越过，因此能拿到的牛是原队列的一个前缀。令 d[i]=N-c[i]，表示领取后插回的一基位置。判断前 x 头是否已能形成永久阻塞：统计这 x 个 d 中，是否存在 j 使 d<=j 的牛至少有 j 头。若存在，这 j 头总能挡在后续未领取者前面：队首拿完后仍插在前 j 位，不会跑到目标牛后方。反之，第一头永远无法领取的牛最终会稳定在某个正位置 j，其前方的 j 头领取后都不越过它，所以恰有至少 j 个 d<=j。该条件充分且必要。

对前 x 头按 d 做频次数组，再扫前缀计数检查条件。它随 x 增加只会从假变真。二分第一个满足条件的 x，前 x 头都至少领取一次，之后 N-x 头永远不能领取。x=N 时总能满足，统一涵盖所有牛都拿得到的情况。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> position(n), frequency(n + 1);
    for (int &x : position) {
        cin >> x;
        x = n - x;
    }
    auto blocks = [&](int count) {
        fill(frequency.begin(), frequency.end(), 0);
        for (int i = 0; i < count; i++)
            frequency[position[i]]++;
        int prefix = 0;
        for (int j = 1; j <= n; j++) {
            prefix += frequency[j];
            if (prefix >= j)
                return true;
        }
        return false;
    };
    int low = 1, high = n;
    while (low < high) {
        int mid = (low + high) / 2;
        if (blocks(mid))
            high = mid;
        else
            low = mid + 1;
    }
    cout << n - low;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

插回位置是 N-c[i]，不要混同为原始插队数。无限过程不能靠给一个任意模拟步数来断言永远领不到。
