## Steadily Growing Steam

### 题意

选择卡牌分两组点数相等，可将至多k张点数翻倍，最大总价值。

### 思路

用差值D=两组点数差，维度j表示已经翻倍的张数。每张卡有五种有效去向：不选、正常放左/右、翻倍后放左/右；只要选中，不论哪组都加同一个v。用旧表转移到新表，防止重复使用。点数每张至13，全部翻倍后绝对差至2600，数组范围固定；最后在D=0、j≤k中取最大，空集给0。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<pair<long long, int>> card(n);
    int total = 0;
    for (auto &[v, t] : card) {
        cin >> v >> t;
        total += 2 * t;
    }
    int width = 2 * total + 1;
    const long long negative = LLONG_MIN / 4;
    vector<long long> dp((k + 1) * width, negative);
    dp[total] = 0;
    int processed = 0;
    for (auto [value, point] : card) {
        auto next = dp;
        for (int doubled = 0; doubled <= min(k, processed); doubled++)
            for (int d = -total; d <= total; d++) {
                long long old = dp[doubled * width + d + total];
                if (old == negative)
                    continue;
                for (int sign : {-1, 1}) {
                    int normal = d + sign * point;
                    if (abs(normal) <= total)
                        next[doubled * width + normal + total] =
                            max(next[doubled * width + normal + total], old + value);
                    int large = d + sign * 2 * point;
                    if (doubled < k && abs(large) <= total)
                        next[(doubled + 1) * width + large + total] =
                            max(next[(doubled + 1) * width + large + total], old + value);
                }
            }
        dp.swap(next);
        processed++;
    }
    long long answer = 0;
    for (int j = 0; j <= k; j++)
        answer = max(answer, dp[j * width + total]);
    cout << answer;
    return 0;
}
```

### 复杂度

总翻倍点数和B≤2600，时间 $O(nkB)$，空间 $O(kB)$。

### 易错点

负价值卡可能帮助点数平衡，不能直接删掉。翻倍的是点数t，价值v不翻倍。
