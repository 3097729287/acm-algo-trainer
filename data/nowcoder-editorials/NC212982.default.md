## hello world

### 题意

把 hello world 中每个字符的 ASCII 编码加一后输出。

### 思路

遍历固定字符串，逐字符转换为 char(c+1)。空格也是一个字符，编码加一后成为感叹号，所以不能保留原来的空格。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s = "hello world";
    for (char c : s)
        cout << char(c + 1);
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

题名不是要输出原来的 hello world；空格同样需要转换。
