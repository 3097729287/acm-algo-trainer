## 求最值

### 题意

最小化 (i-j)² 加上两下标之间按题意求和的平方。

### 思路

令 prefix[i] 为前 i 个 a 的和，则 g(i,j) 的绝对值是 |prefix[i]-prefix[j]|，式子就是平面点 (i,prefix[i]) 的欧氏距离平方。注意只建立 i=1 到 n 的点，不建立零号点。按横坐标分治求最近点对：递归处理左右两半，设已知最小平方距离 d，只检查到分界线横向距离小于 sqrt(d) 的点。每半内任意两点至少相距 sqrt(d)，将窄条按纵坐标排序后，一个点在纵差小于 sqrt(d) 的范围内只有常数个候选（可由小方格装箱证明）。归并维护纵序，使每层线性。全程比较整数平方。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    long long x, y;
};
vector<Point> points, buffer;
long long closest(int l, int r) {
    if (r - l <= 1)
        return LLONG_MAX;
    int mid = (l + r) / 2;
    long long dividingX = points[mid].x;
    long long best = min(closest(l, mid), closest(mid, r));
    merge(points.begin() + l, points.begin() + mid, points.begin() + mid, points.begin() + r,
          buffer.begin() + l, [](const Point &a, const Point &b) { return a.y < b.y; });
    copy(buffer.begin() + l, buffer.begin() + r, points.begin() + l);
    vector<Point> strip;
    strip.reserve(r - l);
    for (int i = l; i < r; i++) {
        auto p = points[i];
        if ((p.x - dividingX) * (p.x - dividingX) >= best)
            continue;
        for (int j = (int)strip.size() - 1; j >= 0; j--) {
            long long dy = p.y - strip[j].y;
            if (dy * dy >= best)
                break;
            long long dx = p.x - strip[j].x;
            best = min(best, dx * dx + dy * dy);
        }
        strip.push_back(p);
    }
    return best;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    points.resize(n);
    buffer.resize(n);
    long long prefix = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        prefix += x;
        points[i] = {i + 1, prefix};
    }
    cout << closest(0, n);
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，峰值额外空间 $O(n)$。

### 易错点

递归后数组改成纵坐标顺序，因此必须先保存 dividingX，再递归两半。每层只新建自己的窄条，不按浮点开根号筛选。
