## 旅行

### 题意

选三个不同景点A、B、C，司机每段走最短路，最大化两段最短路之和。

### 思路

枚举中转景点B，对稀疏无向图做一次Dijkstra。起点和终点只需是与B连通、不同于B的两个最远景点，因此取距离最大的两项相加。它们下标不同，由每个点只扫描一次保证。若任何B都没有两个可达其他点，就不存在合法三点方案，输出−1。无须三重枚举，也不适合对1000点稀疏图做Floyd。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<long long> dijkstra(const vector<vector<pair<int, long long>>> &graph, int source) {
    const long long inf = 1LL << 60;
    vector<long long> distance(graph.size(), inf);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>,
                   greater<pair<long long, int>>>
        heap;
    distance[source] = 0;
    heap.push({0, source});
    while (!heap.empty()) {
        auto [cost, u] = heap.top();
        heap.pop();
        if (cost != distance[u])
            continue;
        for (auto [v, w] : graph[u])
            if (distance[v] > cost + w) {
                distance[v] = cost + w;
                heap.push({distance[v], v});
            }
    }
    return distance;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        vector<vector<pair<int, long long>>> graph(n);
        while (m--) {
            int a, b;
            long long w;
            cin >> a >> b >> w;
            --a;
            --b;
            graph[a].push_back({b, w});
            graph[b].push_back({a, w});
        }
        long long answer = -1;
        for (int center = 0; center < n; center++) {
            auto d = dijkstra(graph, center);
            long long first = -1, second = -1;
            for (int u = 0; u < n; u++)
                if (u != center && d[u] != (1LL << 60)) {
                    if (d[u] > first) {
                        second = first;
                        first = d[u];
                    } else if (d[u] > second)
                        second = d[u];
                }
            if (second != -1)
                answer = max(answer, first + second);
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(n(n+m)\log n)$，空间 $O(n+m)$。

### 易错点

不能把不可达的无穷距离当成最大值。两个不同景点距离相同也允许分别作为两端。
