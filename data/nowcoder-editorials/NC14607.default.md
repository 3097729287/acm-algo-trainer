## 递推

### 题意

a[0]=0，a[n]=2a[n−1]+n²，n至10^18。

### 思路

寻找二次多项式特解P(n)=An²+Bn+C，代入P(n)=2P(n−1)+n²，比较系数得P(n)=−n²−4n−6。齐次项为K*2^n，代入a[0]=0得K=6。所以a[n]=6*2^n−n²−4n−6。先把n模P，快速幂求2^n，再计算公式。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 1000000009;
    long long n;
    while (cin >> n) {
        long long exponent = n, base = 2, value = 1;
        while (exponent) {
            if (exponent & 1)
                value = value * base % mod;
            base = base * base % mod;
            exponent >>= 1;
        }
        long long x = n % mod;
        long long answer = (6 * value % mod - x * x % mod - 4 * x % mod - 6) % mod;
        if (answer < 0)
            answer += mod;
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(\log n)$，空间 $O(1)$。

### 易错点

指数使用完整n，不能把指数直接模P；n²则应先把n模P，避免原n平方溢出。
