## 有序序列合并

### 题意

把两个升序序列合成一个升序序列，保留重复值。

### 思路

各用一个指针指向当前未取的最小元素，比较后取较小者并只移动它的指针。一边用完后，依次取另一边剩余元素。每次输出的都是全部未输出元素中的最小值。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> a(n), b(m);
    for (int &x : a)
        cin >> x;
    for (int &x : b)
        cin >> x;
    int i = 0, j = 0;
    bool first = true;
    while (i < n || j < m) {
        int x;
        if (j == m || (i < n && a[i] <= b[j]))
            x = a[i++];
        else
            x = b[j++];
        if (!first)
            cout << ' ';
        cout << x;
        first = false;
    }
    return 0;
}
```

### 复杂度

时间与数组空间均为 $O(n+m)$。

### 易错点

合并不等于去重；两个相等元素都需要输出。条件短路保证不会读取越界元素。
