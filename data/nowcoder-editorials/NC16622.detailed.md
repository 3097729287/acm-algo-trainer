## 多项式输出

> 原题：[P1067](https://www.luogu.com.cn/problem/P1067)
> 解法：拆开符号、系数和幂次输出 · C++17

### 题意

按规范输出多项式：省略零项，处理首项符号、系数一以及一次项和常数项。



### 思路

系数序列 $[1, -1, 0, 3]$ 对应三次到零次，输出 $x^3-x^2+3$。符号、系数、幂次应分别判断，否则很容易把某个特例遗漏。

维护 first 表示还没输出任何非零项。负系数总输出减号；正系数仅在不是首项时输出加号。随后只看绝对值：常数项必须输出完整数字；其它项在绝对值为一时省略数字。正次数输出 $x$，大于一次才追加 ^ 和次数。输出完非零项后将 first 设为 false；跳过零项不能改变它。题目保证最高次系数非零，代码也兼容全零输入，最终补一个零。

时间 $O(n)$、额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    bool first = true;
    for (int power = n; power >= 0; --power) {
        int coefficient;
        cin >> coefficient;
        if (coefficient == 0)
            continue;
        if (coefficient < 0)
            cout << '-';
        else if (!first)
            cout << '+';
        int value = abs(coefficient);
        if (power == 0 || value != 1)
            cout << value;
        if (power > 0) {
            cout << 'x';
            if (power > 1)
                cout << '^' << power;
        }
        first = false;
    }
    if (first)
        cout << 0;
    cout << '\n';
    return 0;
}
```

### 易错点

常数一不能省略；一次项只写 $x$，首个正项前不写加号。
