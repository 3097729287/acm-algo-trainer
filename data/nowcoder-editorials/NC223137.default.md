## 智乃酱的双塔问题

### 题意

两塔向上通行，每层一条定向跨塔楼梯，询问区间起终塔的路径数。

### 思路

用列向量[左方案数,右方案数]。字符/对应左→右，矩阵[[1,0],[1,1]]；反斜线对应右→左，矩阵[[1,1],[0,1]]。第i层转移左乘旧状态。令P[i]=A[i]*...*A[1]，查询从hs到ht的转移为P[ht−1]*inverse(P[hs−1])。

每个基本矩阵行列式都是1，故所有前缀行列式仍为1。2×2逆矩阵直接为[[d,−b],[−c,a]]，不需求逆元。答案取转移矩阵[pt][ps]。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 1000000007;
using Matrix = array<array<long long, 2>, 2>;
Matrix product(const Matrix &a, const Matrix &b) {
    Matrix c = {{{0, 0}, {0, 0}}};
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            for (int k = 0; k < 2; k++)
                c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % mod;
    return c;
}
Matrix inverse(const Matrix &a) {
    return {{{a[1][1], (mod - a[0][1]) % mod}, {(mod - a[1][0]) % mod, a[0][0]}}};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    string s;
    cin >> n >> m >> s;
    Matrix identity = {{{1, 0}, {0, 1}}};
    vector<Matrix> prefix(n);
    prefix[0] = identity;
    for (int i = 1; i < n; i++) {
        Matrix step = identity;
        if (s[i - 1] == '/')
            step[1][0] = 1;
        else
            step[0][1] = 1;
        prefix[i] = product(step, prefix[i - 1]);
    }
    while (m--) {
        int hs, ht, ps, pt;
        cin >> hs >> ht >> ps >> pt;
        Matrix segment = product(prefix[ht - 1], inverse(prefix[hs - 1]));
        cout << segment[pt][ps] << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(n+m)$，空间 $O(n)$，2×2乘法为常数。

### 易错点

矩阵乘法不可交换，区间前缀逆矩阵要放右边。hs到ht恰好经过hs..ht−1层的楼梯。
