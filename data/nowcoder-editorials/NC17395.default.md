## 瑰丽华尔兹

### 题意

每段时间只沿固定方向滑行或停下，不能撞障碍，最大化总滑行格数。

### 思路

将同方向持续的时间合成一次转移。在这一方向的一条无障碍线上，沿运动方向给格子编号p。若本段至多D步，从q到p的贡献为p−q，且q在[p−D,p]内，于是new[p]=p+max(old[q]−q)。用单调队列维护这个滑动最大值。遇到障碍立刻清队列，禁止跨家具转移。

向北按每列从下往上扫描，南反之；向西按每行从右往左，东反之。每段用完整旧数组生成新数组，允许q=p表示全程停住。初态只有起点分数0，其余不可达。每个时间段只扫一遍地图，最后取所有位置的最大分。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, cols, x, y, k;
    cin >> rows >> cols >> x >> y >> k;
    vector<string> grid(rows);
    for (auto &row : grid)
        cin >> row;
    const int neg = -1000000000;
    vector<int> dp(rows * cols, neg), next(dp.size());
    dp[(x - 1) * cols + y - 1] = 0;
    while (k--) {
        int begin, end, direction;
        cin >> begin >> end >> direction;
        int duration = end - begin + 1;
        fill(next.begin(), next.end(), neg);
        auto process = [&](const vector<int> &line) {
            deque<pair<int, int>> queue;
            for (int p = 0; p < (int)line.size(); p++) {
                int cell = line[p];
                if (grid[cell / cols][cell % cols] == 'x') {
                    queue.clear();
                    continue;
                }
                while (!queue.empty() && queue.front().first < p - duration)
                    queue.pop_front();
                if (dp[cell] != neg) {
                    int value = dp[cell] - p;
                    while (!queue.empty() && queue.back().second <= value)
                        queue.pop_back();
                    queue.push_back({p, value});
                }
                if (!queue.empty())
                    next[cell] = p + queue.front().second;
            }
        };
        if (direction <= 2) {
            for (int c = 0; c < cols; c++) {
                vector<int> line;
                line.reserve(rows);
                for (int p = 0; p < rows; p++) {
                    int r = direction == 1 ? rows - 1 - p : p;
                    line.push_back(r * cols + c);
                }
                process(line);
            }
        } else {
            for (int r = 0; r < rows; r++) {
                vector<int> line;
                line.reserve(cols);
                for (int p = 0; p < cols; p++) {
                    int c = direction == 3 ? cols - 1 - p : p;
                    line.push_back(r * cols + c);
                }
                process(line);
            }
        }
        dp.swap(next);
    }
    cout << *max_element(dp.begin(), dp.end());
    return 0;
}
```

### 复杂度

时间 $O(KNM)$，空间 $O(NM+\max(N,M))$。

### 易错点

每段允许的步数是end−begin+1。输出滑动格数，不是时间；施法停留不加分。队列必须在障碍处断开。
