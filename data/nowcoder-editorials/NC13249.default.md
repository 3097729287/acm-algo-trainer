## 黑白树

### 题意

选择向祖先染黑的操作，最少覆盖整棵树。

### 思路

操作u覆盖深度区间[depth[u]−k[u]+1,depth[u]]上的祖先链。先忽略“选点必须白色”：任何选点集合都可按深度从浅到深执行，之前的操作只染祖先，不会提前染黑后面要选的深点，所以限制不会改变最优值。

按后序处理最深的尚未覆盖节点u。要覆盖它，操作起点必在它的子树内；选择其中能向上延伸最远的起点最优。交换证明：替换任意覆盖u的操作，u以下节点此前已覆盖，u以上新操作覆盖至少一样高，因此不变差。

维护best[u]为整个子树内所有候选操作最浅能到的深度，covered[u]为已选操作最浅覆盖深度。合并儿子取最小，再加入u自己的候选。若covered[u]>depth[u]，u尚未覆盖，答案加1并选best[u]。只需传递深度，不必实际染色。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct EulerTree {
    int n;
    vector<vector<int>> edge;
    vector<int> parent, depth, in, out, order;
    EulerTree(int n) : n(n), edge(n + 1), parent(n + 1), depth(n + 1), in(n + 1), out(n + 1) {}
    void add(int u, int v) {
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    void root(int start) {
        vector<int> stack = {start};
        parent[start] = 0;
        order.clear();
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            in[u] = order.size() + 1;
            order.push_back(u);
            for (int v : edge[u])
                if (v != parent[u]) {
                    parent[v] = u;
                    depth[v] = depth[u] + 1;
                    stack.push_back(v);
                }
        }
        vector<int> size(n + 1, 1);
        for (int i = (int)order.size() - 1; i >= 0; i--) {
            int u = order[i];
            out[u] = in[u] + size[u] - 1;
            if (parent[u])
                size[parent[u]] += size[u];
        }
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    EulerTree tree(n);
    for (int v = 2; v <= n; v++) {
        int p;
        cin >> p;
        tree.add(p, v);
    }
    vector<int> k(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> k[i];
    tree.root(1);
    const int inf = INT_MAX / 2;
    vector<int> best(n + 1), covered(n + 1, inf);
    int answer = 0;
    for (int i = n - 1; i >= 0; i--) {
        int u = tree.order[i];
        best[u] = tree.depth[u] - k[u] + 1;
        for (int v : tree.edge[u])
            if (tree.parent[v] == u) {
                best[u] = min(best[u], best[v]);
                covered[u] = min(covered[u], covered[v]);
            }
        if (covered[u] > tree.depth[u]) {
            answer++;
            covered[u] = best[u];
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间、空间均 $O(n)$。

### 易错点

候选包括已被其他操作覆盖的节点，它可以在最终执行顺序中提前操作。仅对尚未染黑节点直接操作的朴素后序贪心不正确。
