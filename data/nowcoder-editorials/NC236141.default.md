## Bash游戏

### 题意

每次取1到K，取完赢，多组判断A/B。

### 思路

N是K+1倍数时必败，否则取余数使对手面对倍数。之后对手取x，就补K+1−x，始终能把倍数交回给对手。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        long long n, k;
        cin >> n >> k;
        cout << (n % (k + 1) ? "A\n" : "B\n");
    }
    return 0;
}
```

### 复杂度

每组时间、空间均 $O(1)$。

### 易错点

K可以大于N，此时先手直接取完。K+1与取模使用64位。
