## kotori和糖果

### 题意

从 n 堆各一颗糖出发，两堆合并代价为大小差，求总成本最小值。

### 思路

定义 G[0]=G[1]=0，G[n]=G[floor(n/2)]+G[ceil(n/2)]+n%2。它对应尽量等分的合并树：两子堆相等就零代价，不等只差一。记忆化后，每层只会有两个相邻规模，单次询问只产生 O(log n) 个状态。

为什么等分可达最优？关键不等式是 G[a+b]<=G[a]+G[b]+|a-b|。对 a+b 归纳即可证明，按 a、b 奇偶展开 G：例如 a=2u、b=2v+1 且 u<=v，左式展开后分别对 (u,v) 与 (u,v+1) 使用归纳假设，额外项合计恰为 2(v-u)+1=b-a；两者都偶时直接把同一个归纳式乘二；两者都奇时分别对 (u,v+1)、(u+1,v) 使用归纳式，u=v 时取等号，其余情况界更宽。另一种一奇一偶对称。

把这个不等式用于任意合并树的每个节点并相加，所有子堆的 G 抵消，得到实际总代价至少 G[n]，因为初始 G[1]=0。等分递推又恰好实现 G[n]，所以下界可达。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

unordered_map<long long, long long> memo{{0, 0}, {1, 0}};
long long balanced(long long n) {
    auto found = memo.find(n);
    if (found != memo.end())
        return found->second;
    long long answer = balanced(n / 2) + balanced(n - n / 2) + n % 2;
    return memo[n] = answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int tests;
    cin >> tests;
    while (tests--) {
        long long n;
        cin >> n;
        cout << balanced(n) << '\n';
    }
    return 0;
}
```

### 复杂度

单次新询问至多新增 $O(\log n)$ 状态；哈希查表平均常数，总空间等于已缓存的不同状态数。

### 易错点

单纯不带记忆化递归会重复计算同样规模。n=0 和 n=1 都不需要合并，不能对零继续递归。
