## Graph Coloring I

### 题意

输出图的二染色或任意简单奇环。

### 思路

BFS用深度奇偶染色，同时保存父节点。若每条边两端异色，直接输出染色。否则找到同色边(u,v)，在BFS树中把u、v分别沿父链上移到公共祖先，合并成树上简单路径，再用原边闭合。两端同色意味着树路径长度为偶数，加闭合边形成奇环。公共祖先只放一次，保证简单。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<vector<int>> edge(n);
    while (m--) {
        int u, v;
        cin >> u >> v;
        u--;
        v--;
        edge[u].push_back(v);
        edge[v].push_back(u);
    }
    vector<int> color(n, -1), parent(n, -1), depth(n);
    vector<int> queue = {0};
    color[0] = 0;
    int a = -1, b = -1;
    for (size_t h = 0; h < queue.size() && a < 0; h++) {
        int u = queue[h];
        for (int v : edge[u]) {
            if (color[v] < 0) {
                color[v] = color[u] ^ 1;
                parent[v] = u;
                depth[v] = depth[u] + 1;
                queue.push_back(v);
            } else if (color[v] == color[u]) {
                a = u;
                b = v;
                break;
            }
        }
    }
    if (a < 0) {
        cout << 0 << '\n';
        for (int i = 0; i < n; i++)
            cout << color[i] << (i + 1 == n ? '\n' : ' ');
        return 0;
    }
    vector<int> left, right;
    while (a != b) {
        if (depth[a] >= depth[b]) {
            left.push_back(a);
            a = parent[a];
        } else {
            right.push_back(b);
            b = parent[b];
        }
    }
    left.push_back(a);
    reverse(right.begin(), right.end());
    left.insert(left.end(), right.begin(), right.end());
    cout << left.size() << '\n';
    for (int i = 0; i < (int)left.size(); i++)
        cout << left[i] + 1 << (i + 1 == (int)left.size() ? '\n' : ' ');
    return 0;
}
```

### 复杂度

时间、空间均 $O(n+m)$。

### 易错点

同色边加树路径是奇环，不应输出整个DFS访问序列。图保证连通，二分图与有奇环恰好二选一。
