## 月月查华华的手机

### 题意

预处理一个长串，多次判断给定字符串是否为其子序列。

### 思路

分别保存每种字母在 s 中出现的所有下标。匹配一个查询时，维护已匹配到的位置 previous；对查询的每个字母，在它的下标列表里二分找第一个大于 previous 的位置。找不到就失败。每次尽量用最早位置，只会给后续留下更多空间，因此贪心匹配充分且必要。相比每次扫描完整 s，查询只处理自身字符。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    vector<int> positions[26];
    for (int i = 0; i < (int)s.size(); i++)
        positions[s[i] - 'a'].push_back(i);
    int q;
    cin >> q;
    while (q--) {
        string t;
        cin >> t;
        int previous = -1;
        bool valid = true;
        for (char c : t) {
            const auto &v = positions[c - 'a'];
            auto it = upper_bound(v.begin(), v.end(), previous);
            if (it == v.end()) {
                valid = false;
                break;
            }
            previous = *it;
        }
        cout << (valid ? "Yes\n" : "No\n");
    }
    return 0;
}
```

### 复杂度

设查询总长度为 $Q$，时间 $O(|s|+Q\log |s|)$，额外索引空间 $O(|s|)$。

### 易错点

下一位置必须严格大于上一位置，重复字母不能复用同一下标。每条查询都要从 previous=-1 重新开始。
