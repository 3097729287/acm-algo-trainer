## 红球进黑洞

### 题意

区间异或、区间和，数值和异或掩码至10^5。

### 思路

每个节点按二进制位记录1的个数。第b位异或1时，计数变成区间长度−原计数，其他位不变；懒标记按异或合并。数值小于2^17，记录17位即可。区间和是Σ count[b]*2^b。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<array<int, 17>> count(4 * n + 4);
    vector<int> tag(4 * n + 4);
    auto pull = [&](int u) {
        for (int b = 0; b < 17; b++)
            count[u][b] = count[u * 2][b] + count[u * 2 + 1][b];
    };
    auto build = [&](auto &&self, int u, int l, int r) -> void {
        if (l == r) {
            int x;
            cin >> x;
            for (int b = 0; b < 17; b++)
                count[u][b] = x >> b & 1;
            return;
        }
        int mid = (l + r) / 2;
        self(self, u * 2, l, mid);
        self(self, u * 2 + 1, mid + 1, r);
        pull(u);
    };
    build(build, 1, 1, n);
    auto apply = [&](int u, int l, int r, int x) {
        for (int b = 0; b < 17; b++)
            if (x >> b & 1)
                count[u][b] = r - l + 1 - count[u][b];
        tag[u] ^= x;
    };
    auto push = [&](int u, int l, int r) {
        if (tag[u]) {
            int mid = (l + r) / 2;
            apply(u * 2, l, mid, tag[u]);
            apply(u * 2 + 1, mid + 1, r, tag[u]);
            tag[u] = 0;
        }
    };
    auto update = [&](auto &&self, int u, int l, int r, int ql, int qr, int x) -> void {
        if (ql <= l && r <= qr) {
            apply(u, l, r, x);
            return;
        }
        push(u, l, r);
        int mid = (l + r) / 2;
        if (ql <= mid)
            self(self, u * 2, l, mid, ql, qr, x);
        if (qr > mid)
            self(self, u * 2 + 1, mid + 1, r, ql, qr, x);
        pull(u);
    };
    auto query = [&](auto &&self, int u, int l, int r, int ql, int qr) -> long long {
        if (ql <= l && r <= qr) {
            long long result = 0;
            for (int b = 0; b < 17; b++)
                result += 1LL * count[u][b] * (1 << b);
            return result;
        }
        push(u, l, r);
        int mid = (l + r) / 2;
        long long result = 0;
        if (ql <= mid)
            result += self(self, u * 2, l, mid, ql, qr);
        if (qr > mid)
            result += self(self, u * 2 + 1, mid + 1, r, ql, qr);
        return result;
    };
    while (m--) {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 2) {
            int k;
            cin >> k;
            update(update, 1, 1, n, l, r, k);
        } else
            cout << query(query, 1, 1, n, l, r) << '\n';
    }
    return 0;
}
```

### 复杂度

每次操作 $O(17\log n)$，空间 $O(17n)$。

### 易错点

异或两次同一掩码应抵消，所以懒标记用xor。不要只记录区间异或值，它无法恢复区间和。
