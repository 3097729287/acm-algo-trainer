## 保护那些花

### 题意

每次赶回一头牛，其他牛在往返时间内吃花，最小化总损失。

### 思路

两头牛 A、B 相邻时，先 A 后 B 会额外让 B 等待 2tA，反序则让 A 等待 2tB；其他牛的等待总时长不变。所以 A 放前更好当且仅当 tA*dB<=tB*dA。按该交叉乘积规则排序，维护之前已用的总时间 elapsed，当前牛贡献 elapsed*d，随后时间增加 2t。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<long long, long long>> cows(n);
    for (auto &[t, d] : cows)
        cin >> t >> d;
    sort(cows.begin(), cows.end(),
         [](const auto &a, const auto &b) { return a.first * b.second < b.first * a.second; });
    long long elapsed = 0, answer = 0;
    for (auto [t, d] : cows) {
        answer += elapsed * d;
        elapsed += 2 * t;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

当前正在被赶走的牛不再吃花，所以它只贡献此前等待时间。不要用浮点除法比较比值。
