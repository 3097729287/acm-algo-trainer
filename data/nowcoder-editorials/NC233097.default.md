## 0的个数

### 题意

多组求[m,n]的十进制0总数，包含数字0自身。

### 思路

先求正整数1..n中0的次数。枚举十进制位place，拆成高位high、当前位current、低位low。高位为0时该位不能出现有效0；否则完整高位周期贡献(high−1)*place，再按当前位补low+1（current=0）或place（current>0）。减掉的一个周期正是非法前导零。

数字0自身有一个0，故F(n)=正数计数+1（n≥0）；最后用F(n)−F(m−1)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long countDigit(long long n, int digit) {
    if (n <= 0)
        return 0;
    long long answer = 0;
    for (long long place = 1; place <= n;) {
        long long high = n / place / 10, current = n / place % 10, low = n % place;
        if (digit) {
            answer += high * place;
            if (current > digit)
                answer += place;
            else if (current == digit)
                answer += low + 1;
        } else if (high) {
            answer += (high - 1) * place;
            answer += current == 0 ? low + 1 : place;
        }
        if (place > n / 10)
            break;
        place *= 10;
    }
    return answer;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long m, n;
    auto prefix = [&](long long x) { return x < 0 ? 0LL : countDigit(x, 0) + 1; };
    while (cin >> m >> n && m >= 0 && n >= 0)
        cout << prefix(n) - prefix(m - 1) << '\n';
    return 0;
}
```

### 复杂度

每组时间 $O(\log n)$，空间 $O(1)$。

### 易错点

不能把0当成没有数位；负输入对是结束标记。高位为0的最高补零不能计数。
