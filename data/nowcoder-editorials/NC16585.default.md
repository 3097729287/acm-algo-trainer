## [NOIP2011]统计单词数

### 题意

忽略大小写查找完整单词，输出出现次数及第一次的零起始字符位置。

### 思路

把目标与文章都转小写，但不改变空格与字符位置。沿文章依次找到由空格分隔的每个单词区间，仅当长度与内容均等于目标时计数，并记下第一次的起点。重复空格直接跳过。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string word, text;
    getline(cin, word);
    getline(cin, text);
    for (char &c : word)
        c = tolower(static_cast<unsigned char>(c));
    for (char &c : text)
        c = tolower(static_cast<unsigned char>(c));
    int count = 0, first = -1;
    size_t i = 0;
    while (i < text.size()) {
        if (text[i] == ' ') {
            i++;
            continue;
        }
        size_t start = i;
        while (i < text.size() && text[i] != ' ')
            i++;
        if (i - start == word.size() && text.compare(start, word.size(), word) == 0) {
            if (first == -1)
                first = start;
            count++;
        }
    }
    if (count == 0)
        cout << -1;
    else
        cout << count << ' ' << first;
    return 0;
}
```

### 复杂度

时间与输入空间均为 $O(|文章|+|单词|)$。

### 易错点

目标是独立单词，不能把 Ottoman 中间的 to 当作命中。位置必须包含原文章开头及中间空格占用的字符。
