## [HEOI2014]南园满地堆轻絮

### 题意

将生成序列改为不下降，最小化单个音符的最大改变量。

### 思路

若 i<j 且 A[i]>A[j]，两端各最多改 d 后仍要不下降，必须有 A[i]-A[j]<=2d。因此最大前后下降量 drop 给出下界 ceil(drop/2)。它也充分：令 B[i]=max(1,所有 j<=i 的 A[j]-d)，这样 B 单调不降；当 d 已覆盖最大下降量时，B[i] 不超过 A[i]+d，也不低于 A[i]-d。初始音符为正，后续若生成零，最大下降量已经保证 d 至少为一，所以正整数下界也能满足。

只需流式生成序列、维护此前最大值与 drop，无须存五百万项或反复二分。多项式用秦九韶形式逐步取模，每个乘积都在 64 位范围内。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long n, sa, sb, sc, sd, first, mod;
    cin >> n >> sa >> sb >> sc >> sd >> first >> mod;
    auto f = [&](long long x) { return (((sa * x + sb) % mod * x + sc) % mod * x + sd) % mod; };
    long long previousPrevious = 0, previous = first, maximum = first, drop = 0;
    for (long long i = 2; i <= n; i++) {
        long long current = (f(previous) + f(previousPrevious)) % mod;
        drop = max(drop, maximum - current);
        maximum = max(maximum, current);
        previousPrevious = previous;
        previous = current;
    }
    cout << (drop + 1) / 2;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

输入实际有七个数，题面“六个数”是笔误。给定的 A[1] 就是初始项，之后从 A[0]=0、A[1] 按递推生成。
