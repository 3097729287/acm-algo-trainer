## 矩阵消除游戏

### 题意

用 k 次整行或整列清零，最大化覆盖到的矩阵权值和，每格只计一次。

### 思路

枚举选中的行集合。已选行的权值直接加入，剩下各列的新增收益，就是这列中未选行的总和；再选收益最大的 k-已选行数 列即可。任何行列方案都会对应某个枚举行集合，所以不会漏最优解。若 k 已至少为行数，直接选全部行便能获得总和，后续回合可重复清零，不会扣分。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, k;
    cin >> n >> m >> k;
    vector<vector<long long>> a(n, vector<long long>(m));
    long long total = 0;
    for (auto &row : a)
        for (auto &x : row) {
            cin >> x;
            total += x;
        }
    if (k >= min(n, m)) {
        cout << total;
        return 0;
    }
    long long answer = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        int used = __builtin_popcount((unsigned)mask);
        if (used > k)
            continue;
        vector<long long> columns(m);
        long long score = 0;
        for (int r = 0; r < n; r++)
            for (int c = 0; c < m; c++) {
                if (mask >> r & 1)
                    score += a[r][c];
                else
                    columns[c] += a[r][c];
            }
        sort(columns.begin(), columns.end(), greater<long long>());
        for (int c = 0; c < min(m, k - used); c++)
            score += columns[c];
        answer = max(answer, score);
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(2^n(nm+m\log m))$，空间 $O(nm+m)$。

### 易错点

不能每轮贪心选当前最大行列，两个选择会重叠。固定行集合后，列之间没有交集，此时取最大若干列才是安全的贪心。
