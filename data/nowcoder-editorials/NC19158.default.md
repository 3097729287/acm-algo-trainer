## 失衡天平

### 题意

每次可拿走天平两侧差不超过m的武器，允许多次操作，最大化带走总重量。

### 思路

多次操作不比一次更强：每组的重量差绝对值≤m，把下一组较重侧朝向目前较轻侧合并，总差变成两个差的绝对值，仍≤m。因此可把所有拿走的武器放在一次称量中。

用dp[d]记录当前左右重量差绝对值为d时，能选出的最大总重。每件武器有不选、放较重侧、放较轻侧三种选择，差分别为d、d+x、|d−x|，后两者总重加x。用新数组转移保证每件一次。最后在0到m的差值中取最大总重。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<int> a(n);
    int sum = 0;
    for (int &x : a) {
        cin >> x;
        sum += x;
    }
    vector<int> dp(sum + 1, -1);
    dp[0] = 0;
    int processed = 0;
    for (int x : a) {
        vector<int> next = dp;
        for (int d = 0; d <= processed; d++)
            if (dp[d] >= 0) {
                next[d + x] = max(next[d + x], dp[d] + x);
                next[abs(d - x)] = max(next[abs(d - x)], dp[d] + x);
            }
        processed += x;
        dp.swap(next);
    }
    cout << *max_element(dp.begin(), dp.begin() + min(sum, m) + 1);
    return 0;
}
```

### 复杂度

总重量 $S\le10000$，时间 $O(nS)$，空间 $O(S)$。

### 易错点

m不是背包容量，是两侧重量差上限。必须允许武器暂不选择；同一件不可从本轮新状态再用一次。
