## Balanced Lineup

### 题意

静态身高数组，多次查询闭区间最高与最低差。

### 思路

建立两棵区间最大值树：第一棵放原身高，第二棵放相反数。区间最小值就是相反数最大值的负数，因此答案为maxHeight+maxNegative。查询时把输入闭区间[A,B]转为零下标半开区间[A−1,B)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct RangeMaximum {
    int size = 1;
    vector<long long> tree;
    RangeMaximum(int n) {
        while (size < n)
            size <<= 1;
        tree.assign(size * 2, LLONG_MIN);
    }
    void setValue(int p, long long value) {
        p += size;
        tree[p] = value;
        for (p >>= 1; p; p >>= 1)
            tree[p] = max(tree[p * 2], tree[p * 2 + 1]);
    }
    long long query(int l, int r) {
        long long result = LLONG_MIN;
        for (l += size, r += size; l < r; l >>= 1, r >>= 1) {
            if (l & 1)
                result = max(result, tree[l++]);
            if (r & 1)
                result = max(result, tree[--r]);
        }
        return result;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    cin >> n >> q;
    RangeMaximum high(n), negative(n);
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        high.setValue(i, x);
        negative.setValue(i, -x);
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << high.query(l - 1, r) + negative.query(l - 1, r) << '\n';
    }
    return 0;
}
```

### 复杂度

构建 $O(n\log n)$，每问 $O(\log n)$，空间 $O(n)$。

### 易错点

只有一个元素时差为0；两棵树必须查询相同区间。
