## 两个人的星座

### 题意

每个三角形含三色，统计彼此完全不相交的无序三角形对。

### 思路

两个不相交凸三角形恰有两条内公切线，每条线各经过两个三角形的一个顶点，且两个三角形位于其两侧。固定有向线P→Q，先令P所属三角形其余两顶点在左侧、Q所属三角形其余两顶点在右侧；按颜色计数，方案数是左侧除P颜色外两种数量之积，乘右侧除Q颜色外两种数量之积。再加上左右互换的另一种情况。

对每个P极角排序Q，用半周双指针维护严格左侧三色数量，右侧由总数减去左侧和P、Q得到。累计有向线两侧方案后除4：每对三角形有两条内公切线，每条又被两个方向各统计一次。无三点共线保证切线不重合、其余点不会落在线上。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using Wide = __int128_t;
struct IPoint {
    long long x = 0, y = 0;
    IPoint operator+(IPoint b) const { return {x + b.x, y + b.y}; }
    IPoint operator-(IPoint b) const { return {x - b.x, y - b.y}; }
};
Wide cross(IPoint a, IPoint b) { return (Wide)a.x * b.y - (Wide)a.y * b.x; }
Wide dot(IPoint a, IPoint b) { return (Wide)a.x * b.x + (Wide)a.y * b.y; }
Wide absolute(Wide x) { return x < 0 ? -x : x; }
void printWide(Wide value) {
    if (value < 0) {
        cout << '-';
        value = -value;
    }
    string text;
    do {
        text.push_back('0' + value % 10);
        value /= 10;
    } while (value);
    reverse(text.begin(), text.end());
    cout << text;
}
bool angleLess(IPoint a, IPoint b) {
    auto half = [](IPoint p) { return p.y < 0 || (p.y == 0 && p.x < 0); };
    if (half(a) != half(b))
        return half(a) < half(b);
    return cross(a, b) > 0;
}
vector<IPoint> integerHull(vector<IPoint> point) {
    sort(point.begin(), point.end(),
         [](auto a, auto b) { return a.x != b.x ? a.x < b.x : a.y < b.y; });
    point.erase(
        unique(point.begin(), point.end(), [](auto a, auto b) { return a.x == b.x && a.y == b.y; }),
        point.end());
    if (point.size() < 2)
        return point;
    vector<IPoint> hull;
    for (auto p : point) {
        while (hull.size() >= 2 && cross(hull.back() - hull[hull.size() - 2], p - hull.back()) <= 0)
            hull.pop_back();
        hull.push_back(p);
    }
    size_t lower = hull.size();
    for (int i = (int)point.size() - 2; i >= 0; i--) {
        auto p = point[i];
        while (hull.size() > lower &&
               cross(hull.back() - hull[hull.size() - 2], p - hull.back()) <= 0)
            hull.pop_back();
        hull.push_back(p);
    }
    hull.pop_back();
    return hull;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<IPoint> p(n);
    vector<int> color(n);
    array<long long, 3> total = {};
    for (int i = 0; i < n; i++) {
        cin >> p[i].x >> p[i].y >> color[i];
        total[color[i]]++;
    }
    Wide answer = 0;
    for (int origin = 0; origin < n; origin++) {
        struct V {
            IPoint direction;
            int color;
        };
        vector<V> v;
        for (int i = 0; i < n; i++)
            if (i != origin)
                v.push_back({p[i] - p[origin], color[i]});
        sort(v.begin(), v.end(),
             [](auto a, auto b) { return angleLess(a.direction, b.direction); });
        int m = v.size();
        for (int i = 0; i < m; i++)
            v.push_back(v[i]);
        array<long long, 3> left = {};
        int right = 1;
        for (int i = 0; i < m; i++) {
            right = max(right, i + 1);
            while (right < i + m && cross(v[i].direction, v[right].direction) > 0) {
                left[v[right].color]++;
                right++;
            }
            auto other = total;
            other[color[origin]]--;
            other[v[i].color]--;
            for (int c = 0; c < 3; c++)
                other[c] -= left[c];
            Wide ways = 1, reverseWays = 1;
            for (int c = 0; c < 3; c++) {
                if (c != color[origin]) {
                    ways *= left[c];
                    reverseWays *= other[c];
                }
                if (c != v[i].color) {
                    ways *= other[c];
                    reverseWays *= left[c];
                }
            }
            answer += ways + reverseWays;
            if (i + 1 < right)
                left[v[i + 1].color]--;
        }
    }
    printWide(answer / 4);
    return 0;
}
```

### 复杂度

时间 $O(n²\log n)$，空间 $O(n)$。

### 易错点

两个三角形的6个点必须互不相同，P、Q都从左右计数中扣除。这里统计分离公切线，交叉或包含的三角形不会贡献。
