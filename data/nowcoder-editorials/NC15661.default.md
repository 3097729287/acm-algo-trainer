## String

### 题意

在固定六乘六字符表中，找出同时处于最高频行与最高频列的所有字符。

### 思路

先将数字与大写字母依次编号零到三十五，行号为编号整除六、列号为编号模六。每个字符为对应行列各贡献一次。求行频率最大值与列频率最大值，再按编号递增输出两个条件都满足的字符。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    const string alphabet = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    while (t--) {
        string s;
        cin >> s;
        int row[6] = {}, col[6] = {};
        for (char c : s) {
            int id = c <= '9' ? c - '0' : c - 'A' + 10;
            row[id / 6]++;
            col[id % 6]++;
        }
        int bestRow = *max_element(row, row + 6), bestCol = *max_element(col, col + 6);
        for (int id = 0; id < 36; id++)
            if (row[id / 6] == bestRow && col[id % 6] == bestCol)
                cout << alphabet[id];
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

每组时间 $O(|S|+36)$，除输入字符串外额外空间 $O(1)$。

### 易错点

找的是所有最大频率行与列的交点，某个交点字符即使没在原串中出现，也可能需要输出。
