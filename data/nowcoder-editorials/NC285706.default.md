## 【模板】01分数规划

### 题意

恰好选 k 件，最大化总价值除以总体积。

### 思路

对于候选比值 x，要求 sum(v)/sum(w)>=x，等价于 sum(v-xw)>=0。给每件物品打分 v-xw，选得分最大的 k 件就是该 x 下的最优选择。若这 k 项之和非负，x 可行，否则不可行。可行性随 x 增大而减弱，二分零到最大的单件价值体积比。每轮用 nth_element 选出前 k 大，不必完整排序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<long double> weight(n), value(n), score(n);
    long double low = 0, high = 0;
    for (int i = 0; i < n; i++) {
        cin >> weight[i] >> value[i];
        high = max(high, value[i] / weight[i]);
    }
    for (int iteration = 0; iteration < 65; iteration++) {
        long double mid = (low + high) / 2;
        for (int i = 0; i < n; i++)
            score[i] = value[i] - mid * weight[i];
        if (k < n)
            nth_element(score.begin(), score.begin() + k, score.end(), greater<long double>());
        long double sum = accumulate(score.begin(), score.begin() + k, 0.0L);
        if (sum >= 0)
            low = mid;
        else
            high = mid;
    }
    cout << fixed << setprecision(12) << low;
    return 0;
}
```

### 复杂度

每轮快速选择平均 $O(n)$，固定迭代 $K=65$ 次，平均总时间 $O(Kn)$，空间 $O(n)$。

### 易错点

必须比较总价值除总体积，按单件比值直接选前 k 个通常错误。k=n 时无需调用分割迭代器在末尾的 nth_element。
