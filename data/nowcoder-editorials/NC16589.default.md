## 机器翻译

### 题意

模拟先进先出的单词缓存，统计缓存未命中次数。

### 思路

队列保存单词进入缓存的顺序，布尔表记录是否在缓存中。命中时什么都不做；未命中时答案加一，若队列已满先移除队首并清掉标记，再把新单词入队。队列与布尔表始终表示同一批单词。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int capacity, n;
    cin >> capacity >> n;
    queue<int> cache;
    bool present[1001] = {};
    int answer = 0;
    while (n--) {
        int word;
        cin >> word;
        if (present[word])
            continue;
        answer++;
        if ((int)cache.size() == capacity) {
            present[cache.front()] = false;
            cache.pop();
        }
        cache.push(word);
        present[word] = true;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，队列空间 $O(m)$，编号表固定大小。

### 易错点

命中不会刷新进入时间，不能按最近使用时间淘汰。单词编号包含零。
