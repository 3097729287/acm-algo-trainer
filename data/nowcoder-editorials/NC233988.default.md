## 矩形面积并

### 题意

求有重叠轴平行矩形的并面积。

### 思路

按x扫描左右边界，每次对y区间覆盖次数加1或减1。将y端点离散化，树叶代表相邻端点之间的真实长度；节点覆盖次数>0时全段覆盖，否则覆盖长度由子节点相加。前后事件之间覆盖总长不变，面积增加x差乘根节点覆盖长度。输入上下角坐标先统一为升序。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct CoverTree {
    vector<long long> coordinate, length;
    vector<int> count;
    CoverTree(vector<long long> x)
        : coordinate(move(x)), length(coordinate.size() * 4 + 4), count(length.size()) {}
    void change(int u, int l, int r, int ql, int qr, int delta) {
        if (ql <= l && r <= qr)
            count[u] += delta;
        else {
            int mid = (l + r) / 2;
            if (ql <= mid)
                change(u * 2, l, mid, ql, qr, delta);
            if (qr > mid)
                change(u * 2 + 1, mid + 1, r, ql, qr, delta);
        }
        if (count[u])
            length[u] = coordinate[r + 1] - coordinate[l];
        else
            length[u] = l == r ? 0 : length[u * 2] + length[u * 2 + 1];
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    struct Event {
        long long x, low, high;
        int delta;
    };
    vector<Event> event;
    vector<long long> y;
    for (int i = 0; i < n; i++) {
        long long x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        if (x1 > x2)
            swap(x1, x2);
        if (y1 > y2)
            swap(y1, y2);
        if (x1 == x2 || y1 == y2)
            continue;
        event.push_back({x1, y1, y2, 1});
        event.push_back({x2, y1, y2, -1});
        y.push_back(y1);
        y.push_back(y2);
    }
    if (event.empty()) {
        cout << 0;
        return 0;
    }
    sort(y.begin(), y.end());
    y.erase(unique(y.begin(), y.end()), y.end());
    sort(event.begin(), event.end(), [](auto a, auto b) { return a.x < b.x; });
    CoverTree tree(y);
    long long area = 0, previous = event[0].x;
    for (auto e : event) {
        area += (e.x - previous) * tree.length[1];
        previous = e.x;
        int l = lower_bound(y.begin(), y.end(), e.low) - y.begin();
        int r = lower_bound(y.begin(), y.end(), e.high) - y.begin() - 1;
        tree.change(1, 0, (int)y.size() - 2, l, r, e.delta);
    }
    cout << area;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

离散下标距离不是几何长度，长度必须用原坐标相减。区间按半开[y1,y2)维护，对应叶下标到rank(y2)−1。
