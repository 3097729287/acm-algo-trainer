## [USACO 2006 Ope B]Cows on a Leash

### 题意

用最少竖直切线，使每个横向长条的内部都被切到。

### 思路

把开始位置 x 与长度 len 转成开区间 (x,x+len)。按右端点升序排序；若当前长条尚未被前一刀覆盖，就在它右端点左侧紧挨着的位置切一刀。这个位置在当前条内部，又尽量靠右，能覆盖最多后续长条。只需保存该刀右侧的整数边界 end；后续长条左端严格小于 end 才能被这刀切到，等于 end 则必须再切。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<pair<long long, long long>> intervals(n);
    for (auto &[right, left] : intervals) {
        long long length;
        cin >> left >> length;
        right = left + length;
    }
    sort(intervals.begin(), intervals.end());
    long long boundary = LLONG_MIN;
    int answer = 0;
    for (auto [right, left] : intervals)
        if (left >= boundary) {
            answer++;
            boundary = right;
        }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n\log n)$，空间 $O(n)$。

### 易错点

第二个输入数是长度，不是右端点。切在端点不能把条切开，所以共享端点的两条需要分别处理。
