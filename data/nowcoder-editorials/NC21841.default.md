## 牛牛玩平板

### 题意

任意合并两个图形 x、y，得到 x+y 并获分 xy，求最大总分。

### 思路

一个图形合并后大小是其包含的原始大小之和，合并两组时 xy 正好等于两组之间所有原始元素乘积的和。每对原始元素只在它们第一次进入同组时计分一次，因此无论合并顺序如何，总分始终是所有 i<j 的 a[i]a[j] 之和。读入 x 时，令它与前面所有元素的和 prefix 相乘加入答案，再把 x 加入 prefix。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long prefix = 0, answer = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        answer += prefix * x;
        prefix += x;
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n)$，额外空间 $O(1)$。

### 易错点

不需要枚举合并顺序，也不需要优先队列。最后的总大小不是总分，需累加每对元素的乘积。
