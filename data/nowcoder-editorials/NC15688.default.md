## Operating System

### 题意

完整访问序列已知，容量 N 的页面缓存最少发生多少次缺页。

### 思路

先倒序预处理每次访问之后，这个页面下一次会在哪个时刻被用到；不再访问则记为无穷。缓存满且缺页时，淘汰下一次访问最晚的页面。交换论证：若某最优方案反而淘汰更早要用的页面，在那个较早时刻之前保留它、换掉较晚页面，不会多缺页；到较早时刻再使两方案缓存一致即可。

用大根堆保存 (下次访问时刻,页面)。页面命中后更新时间并再入堆，旧记录延迟删除；淘汰时跳过已经不在缓存或记录时间过期的堆顶。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int capacity, pages, q;
    while (cin >> capacity >> pages >> q) {
        vector<int> request(q), next(q), last(pages + 1, q), current(pages + 1, -1);
        for (int &x : request)
            cin >> x;
        for (int i = q - 1; i >= 0; i--) {
            next[i] = last[request[i]];
            last[request[i]] = i;
        }
        vector<bool> present(pages + 1);
        priority_queue<pair<int, int>> heap;
        int size = 0, misses = 0;
        for (int i = 0; i < q; i++) {
            int page = request[i];
            if (!present[page]) {
                misses++;
                if (size == capacity) {
                    while (!heap.empty() && (!present[heap.top().second] ||
                                             current[heap.top().second] != heap.top().first))
                        heap.pop();
                    int removed = heap.top().second;
                    heap.pop();
                    present[removed] = false;
                    size--;
                }
                present[page] = true;
                size++;
            }
            current[page] = next[i];
            heap.push({next[i], page});
        }
        cout << misses << '\n';
    }
    return 0;
}
```

### 复杂度

时间 $O(Q\log Q+M)$，空间 $O(Q+M)$；堆包含待清理的旧记录。

### 易错点

这是已知未来的离线最优置换，命中也必须更新下一访问时刻。多组输入直到文件结束，每组清空缓存。
