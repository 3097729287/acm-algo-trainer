## Ocean Currents

### 题意

顺当前格的洋流方向移动耗能0，其他七方向耗能1，多次求最少能量。

### 思路

八邻接边权只有0或1，使用01BFS：松弛0边放队首，1边放队尾，队列按待确定距离保持非递减。每个点首次出队时确定最短距离，之后重复记录跳过，目标确定后即可停止。为配合原题满数据时限，用数组实现循环双端队列，避免通用堆的对数因子和频繁节点分配。每条边至多成功入队一次的上界为8V，加初始结点后队列容量8V+2足够。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    while (cin >> n >> m) {
        vector<string> grid(n);
        for (auto &row : grid)
            cin >> row;
        int queries;
        cin >> queries;
        int size = n * m, capacity = 8 * size + 2;
        vector<int> queue(capacity), distance(size);
        vector<unsigned char> done(size);
        int dr[] = {-1, -1, 0, 1, 1, 1, 0, -1}, dc[] = {0, 1, 1, 1, 0, -1, -1, -1};
        while (queries--) {
            int a, b, c, d;
            cin >> a >> b >> c >> d;
            int start = (a - 1) * m + b - 1, target = (c - 1) * m + d - 1;
            fill(distance.begin(), distance.end(), 1000000000);
            fill(done.begin(), done.end(), 0);
            int head = 0, tail = 1;
            queue[0] = start;
            distance[start] = 0;
            while (head != tail) {
                int u = queue[head];
                if (++head == capacity)
                    head = 0;
                if (done[u])
                    continue;
                done[u] = 1;
                if (u == target)
                    break;
                int r = u / m, col = u % m, direction = grid[r][col] - '0';
                for (int k = 0; k < 8; k++) {
                    int rr = r + dr[k], cc = col + dc[k];
                    if (rr < 0 || rr >= n || cc < 0 || cc >= m)
                        continue;
                    int v = rr * m + cc, w = k != direction;
                    if (!done[v] && distance[v] > distance[u] + w) {
                        distance[v] = distance[u] + w;
                        if (w == 0) {
                            if (--head < 0)
                                head = capacity - 1;
                            queue[head] = v;
                        } else {
                            queue[tail] = v;
                            if (++tail == capacity)
                                tail = 0;
                        }
                    }
                }
            }
            cout << distance[target] << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每次询问时间、空间均为 $O(nm)$，方向数8为常数。

### 易错点

边权由出发格的方向决定。输入坐标从1开始；0号方向是北，之后顺时针。起终点相同耗能0。
