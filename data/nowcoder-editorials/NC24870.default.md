## [USACO 2009 Dec G]Video Game Troubles

### 题意

买游戏必须先买其专属主机，主机和游戏各至多一个，求预算内最大产奶价值。

### 思路

按主机分组处理。全局dp[c]表示预算c的最优价值。当前组先设temporary[c]=dp[c−主机价格]，表示已经付过当前主机的钱；不足主机价格的状态不可达。再将本组每个游戏在temporary上倒序做01背包。全部游戏处理完后，将temporary与原dp逐预算取最大，表示买本主机或不买。这样主机钱恰付一次，又允许任意游戏子集，避免枚举至多2^10种组合再和全部预算卷积。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, budget;
    cin >> n >> budget;
    const long long neg = -(1LL << 60);
    vector<long long> dp(budget + 1);
    while (n--) {
        int consolePrice, games;
        cin >> consolePrice >> games;
        vector<long long> temporary(budget + 1, neg);
        for (int c = consolePrice; c <= budget; c++)
            temporary[c] = dp[c - consolePrice];
        while (games--) {
            int price, value;
            cin >> price >> value;
            for (int c = budget; c >= price; c--)
                if (temporary[c - price] != neg)
                    temporary[c] = max(temporary[c], temporary[c - price] + value);
        }
        for (int c = 0; c <= budget; c++)
            dp[c] = max(dp[c], temporary[c]);
    }
    cout << dp[budget];
    return 0;
}
```

### 复杂度

总游戏数 $G\le500$，时间 $O((n+G)V)$，空间 $O(V)$。

### 易错点

不能让游戏从全局dp直接转移，否则会不付主机钱。处理一个主机组期间保持原dp不变。
