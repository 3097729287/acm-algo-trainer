## 马踏棋盘

### 题意

马只允许四种x增大的日字移动，求角到角路径数。

### 思路

四种允许移动都使横坐标x严格增加，因此按列从1到m计算是拓扑顺序。dp[x][y]为到此的路径数，将它加到四种不越界的下一位置。dp[1][1]=1，最后取dp[m][n]，即第m列第n行。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int rows, columns;
    cin >> rows >> columns;
    long long dp[16][16] = {};
    dp[1][1] = 1;
    const int dx[] = {1, 1, 2, 2}, dy[] = {2, -2, 1, -1};
    for (int x = 1; x <= columns; x++)
        for (int y = 1; y <= rows; y++)
            for (int d = 0; d < 4; d++) {
                int xx = x + dx[d], yy = y + dy[d];
                if (xx <= columns && yy >= 1 && yy <= rows)
                    dp[xx][yy] += dp[x][y];
            }
    cout << dp[columns][rows];
    return 0;
}
```

### 复杂度

时间、空间均 $O(nm)$。

### 易错点

原题坐标终点文字与“n行m列、不能向左”及样例不一致。按行列含义，横坐标x取1..m，纵坐标y取1..n，目标为(m,n)；样例4行5列仅有一条向右路线。只用列出的四种移动。1×1有一条空路径。
