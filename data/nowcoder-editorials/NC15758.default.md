## 火车上的2连座

### 题意

多组车厢中选择最前一排、同排最左的一组相邻空座，把它们标成加号。

### 思路

按输入顺序扫描每排，先检查左侧两座，再检查右侧两座。只有尚未选中时才改写恰好一对。读完后，有方案则输出 YES 和全部座位，否则只输出 NO。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    while (cin >> n) {
        vector<string> a(n);
        bool found = false;
        for (string &s : a) {
            cin >> s;
            if (!found && s[0] == 'O' && s[1] == 'O') {
                s[0] = s[1] = '+';
                found = true;
            } else if (!found && s[3] == 'O' && s[4] == 'O') {
                s[3] = s[4] = '+';
                found = true;
            }
        }
        if (!found)
            cout << "NO\n";
        else {
            cout << "YES\n";
            for (string s : a)
                cout << s << '\n';
        }
    }
    return 0;
}
```

### 复杂度

每组时间与座位数组空间均为 $O(n)$。

### 易错点

不能跨过道选择中间两座。原题样例包含多组输入，需读到文件结束。
