## [NOI1998]免费馅饼

### 题意

玩家每秒左右最多两格，只能在整秒末接到落下的馅饼，最大化得分并输出每秒移动。

### 思路

馅饼初始在高度H的格子，玩家所在底格高度1，下降距离为H−1。只有(H−1)能被速度整除时，馅饼才在整秒恰好落入玩家格，接取时刻为初始时刻+(H−1)/速度。将同一时刻同一位置的分数相加。

设dp[t][x]为t秒末站在x的最大得分，从上一秒x−2到x+2的五个位置转移，再加当前馅饼分数。初始只有正中央可达，时刻0的该处馅饼也计分。记录每个状态的前驱位置，所有时刻中取得最高分的最早状态即为结束位置，逆向恢复逐秒移动；选最早时刻可避免收完最后一块后多输出动作。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int w, h;
    cin >> w >> h;
    vector<tuple<int, int, int>> pies;
    int startTime, x, speed, score, endTime = 0;
    while (cin >> startTime >> x >> speed >> score)
        if ((h - 1) % speed == 0) {
            int t = startTime + (h - 1) / speed;
            pies.push_back({t, x, score});
            endTime = max(endTime, t);
        }
    vector<vector<long long>> reward(endTime + 1, vector<long long>(w + 1));
    for (auto [t, p, s] : pies)
        reward[t][p] += s;
    const long long neg = -(1LL << 60);
    vector<vector<long long>> dp(endTime + 1, vector<long long>(w + 1, neg));
    vector<vector<int>> parent(endTime + 1, vector<int>(w + 1, -1));
    int center = (w + 1) / 2;
    dp[0][center] = reward[0][center];
    long long best = dp[0][center];
    int bestTime = 0, bestPosition = center;
    for (int t = 1; t <= endTime; t++)
        for (int p = 1; p <= w; p++) {
            for (int previous = max(1, p - 2); previous <= min(w, p + 2); previous++)
                if (dp[t - 1][previous] != neg && dp[t - 1][previous] + reward[t][p] > dp[t][p]) {
                    dp[t][p] = dp[t - 1][previous] + reward[t][p];
                    parent[t][p] = previous;
                }
            if (dp[t][p] > best) {
                best = dp[t][p];
                bestTime = t;
                bestPosition = p;
            }
        }
    vector<int> moves;
    for (int t = bestTime, p = bestPosition; t > 0; t--) {
        int previous = parent[t][p];
        moves.push_back(p - previous);
        p = previous;
    }
    reverse(moves.begin(), moves.end());
    cout << best << '\n';
    for (int step : moves)
        cout << step << '\n';
    return 0;
}
```

### 复杂度

最后可接时刻 $T\le1099$，馅饼数 $P$，时间 $O(P+5TW)$，空间 $O(TW+P)$。

### 易错点

下降距离是H−1，不能将到达时刻向下或向上取整。不同合法最优移动串均可，校验会模拟每个动作和得分。
