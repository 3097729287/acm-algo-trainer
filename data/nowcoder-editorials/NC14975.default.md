## 方块与收纳盒

### 题意

用长度为一或二的方块铺满长度 n 的盒子，统计铺法。

### 思路

按最后一块分类：它长一，前面有 f[n-1] 种；它长二，前面有 f[n-2] 种。两类互不重叠，所以 f[n]=f[n-1]+f[n-2]。令 f[0]=1，表示空前缀只有一种铺法，f[1]=1。一次预处理到八十，再回答各组询问。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long f[81] = {1, 1};
    for (int i = 2; i <= 80; i++)
        f[i] = f[i - 1] + f[i - 2];
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        cout << f[n] << '\n';
    }
    return 0;
}
```

### 复杂度

预处理时间与空间 $O(80)$，每个询问 $O(1)$。

### 易错点

铺法区分方块的排列顺序。f[80]=37889062373143906，需要 long long，但不需要取模或高精度。
