## 珂学送分

### 题意

非负数组随机选择合法下一段，求段数期望。

### 思路

若某元素>x，该元素无法被任何合法段覆盖，直接无解。否则对每个起点i，用双指针求最远合法右端R[i]；反复均匀随机右端直到合法，相当于在i..R[i]中均匀选一个。

E[i]=1+Σ(j=i..R[i])E[j+1]/(R[i]−i+1)，E[n+1]=0。倒序维护E的后缀和，把转移和化为常数时间。每问重新跑双指针和线性DP即可。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> a(n + 1);
    long long maximum = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        maximum = max(maximum, a[i]);
    }
    cout << fixed << setprecision(2);
    while (m--) {
        long long x;
        cin >> x;
        if (x < maximum) {
            cout << "YNOI is good OI!\n";
            continue;
        }
        vector<int> right(n + 1);
        int r = 0;
        long long sum = 0;
        for (int l = 1; l <= n; l++) {
            while (r < n && sum + a[r + 1] <= x)
                sum += a[++r];
            right[l] = r;
            sum -= a[l];
        }
        vector<long double> suffix(n + 3);
        long double answer = 0;
        for (int i = n; i >= 1; i--) {
            answer = 1 + (suffix[i + 1] - suffix[right[i] + 2]) / (right[i] - i + 1);
            suffix[i] = suffix[i + 1] + answer;
        }
        cout << answer << '\n';
    }
    return 0;
}
```

### 复杂度

每次询问 $O(n)$，总 $O(nm)$，空间 $O(n)$。

### 易错点

数组允许0，双指针条件仍是≤x。随机失败只是重新选，不增加段数。
