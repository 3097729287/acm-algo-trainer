## 时间转换

### 题意

把总秒数拆成小时、分钟和秒。

### 思路

整除 3600 得到小时数。剩余秒数除六十得到分钟，再对六十取余得到秒。小时不限制在一天以内。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int s;
    cin >> s;
    cout << s / 3600 << ' ' << s % 3600 / 60 << ' ' << s % 60;
    return 0;
}
```

### 复杂度

时间与额外空间均为 $O(1)$。

### 易错点

本题输出三个空格分隔的整数，没有冒号，也不需要补零。
