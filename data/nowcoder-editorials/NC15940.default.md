## 译码

### 题意

每五位十进制编号对应一个三字母小写串，依次译出。

### 思路

从 aaa 的零号开始，三个字母的序号构成二十六进制数。每次截取五位转成整数 v，三位依次是 v/676、v/26%26、v%26，各加上字符 a 后输出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int length;
        string s;
        cin >> length >> s;
        for (int i = 0; i < length; i += 5) {
            int v = stoi(s.substr(i, 5));
            cout << char('a' + v / 676) << char('a' + v / 26 % 26) << char('a' + v % 26);
        }
        cout << '\n';
    }
    return 0;
}
```

### 复杂度

时间与输入字符串空间均为 $O(length)$。

### 易错点

aaa 对应 00000，按题目后文的明确映射与样例从零编号，不要错误减一。数字串必须保留前导零后再按五位分组。
