## 孙悟空救师傅

### 题意

按顺序拿钥匙，蛇首次经过多耗一分钟，最短救师时间。

### 思路

状态(position,keys,mask)中keys是已集齐的连续钥匙种数，mask是已击败蛇的集合（最多5只）。走到数字keys+1时keys加1；提前路过更大数字不会取得钥匙。经过尚未击败的蛇，费用2并设置其位，之后再经过费用1。所有边权1或2，用Dijkstra。取到全部钥匙并到达T的状态首次出堆时即最优。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    for (auto &s : grid)
        cin >> s;
    int cells = n * n, start = 0, target = 0, snakes = 0;
    vector<int> snake(cells, -1);
    for (int u = 0; u < cells; u++) {
        char c = grid[u / n][u % n];
        if (c == 'K')
            start = u;
        if (c == 'T')
            target = u;
        if (c == 'S')
            snake[u] = snakes++;
    }
    int masks = 1 << snakes;
    auto encode = [&](int u, int keys, int mask) { return (keys * masks + mask) * cells + u; };
    const int inf = 1000000000;
    vector<int> distance((m + 1) * masks * cells, inf);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> heap;
    int initial = encode(start, 0, 0);
    distance[initial] = 0;
    heap.push({0, initial});
    const int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
    while (!heap.empty()) {
        auto [d, state] = heap.top();
        heap.pop();
        if (d != distance[state])
            continue;
        int u = state % cells, temporary = state / cells, mask = temporary % masks,
            keys = temporary / masks;
        if (u == target && keys == m) {
            cout << d;
            return 0;
        }
        for (int direction = 0; direction < 4; direction++) {
            int r = u / n + dr[direction], c = u % n + dc[direction];
            if (r < 0 || r >= n || c < 0 || c >= n || grid[r][c] == '#')
                continue;
            int v = r * n + c, nextKeys = keys, nextMask = mask, cost = 1;
            if (grid[r][c] >= '1' && grid[r][c] <= '9' && grid[r][c] - '0' == keys + 1)
                nextKeys++;
            if (snake[v] >= 0 && !(mask >> snake[v] & 1)) {
                nextMask |= 1 << snake[v];
                cost++;
            }
            int next = encode(v, nextKeys, nextMask);
            if (d + cost < distance[next]) {
                distance[next] = d + cost;
                heap.push({d + cost, next});
            }
        }
    }
    cout << "impossible";
    return 0;
}
```

### 复杂度

状态数V=n²(m+1)2^S，时间 $O(V\log V)$，空间 $O(V)$。

### 易错点

同一坐标但钥匙进度或蛇状态不同，不能合并。T也可以提前经过，只在keys=m时完成。
