## 金币

> 原题：[P2669](https://www.luogu.com.cn/problem/P2669)
> 解法：按工资段累加 · C++17

### 题意

第一个工资段每天一枚、持续一天；第二段每天两枚、持续两天，依此类推，求前 $k$ 天收入。



### 思路

前六天为一、二、二、三、三、三枚，总计十四枚。若只问前四天，前两段完整计算一枚与四枚，第三段只能计一天三枚，合计八枚。

remaining 表示还没有计入的天数。金额为 pay 的一段原应持续 pay 天，实际取 $days=\min(remaining,pay)$ 天；本段贡献是 $days\times pay$，扣掉这些天后继续。每一天恰好落在一个工资段中，最后的不完整段也按实际天数处理。

工资段数为 $O(\sqrt{k})$，时间 $O(\sqrt{k})$、额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int remaining;
    cin >> remaining;
    long long answer = 0;
    for (int pay = 1; remaining > 0; pay++) {
        int days = min(remaining, pay);
        answer += 1LL * days * pay;
        remaining -= days;
    }
    cout << answer << '\n';
    return 0;
}
```

### 易错点

最后一段可能只发一部分天数，不能直接加 pay 的平方。
