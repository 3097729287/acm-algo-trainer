## The Intriguing Obsession

### 题意

三类岛屿，同色两岛不能距离1或2，统计合法桥集合。

### 思路

同色岛之间不能直接连边。对任意两种颜色，其跨色边必须是匹配：若同一岛连接两个另一色岛，它们就距离2；反过来，距离2同色冲突也必然来自这种结构。因此三对颜色的匹配互相独立。

a、b两类选k条匹配，先各选k个端点，再任意双射，数量C(a,k)C(b,k)k!。定义F(a,b)为k=0..min(a,b)的和，答案F(a,b)*F(a,c)*F(b,c)。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long long mod = 998244353;
long long power(long long a, long long b) {
    long long result = 1;
    while (b) {
        if (b & 1)
            result = result * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return result;
}
struct Combinations {
    vector<long long> factorial, inverse;
    Combinations(int n) : factorial(n + 1, 1), inverse(n + 1) {
        for (int i = 1; i <= n; i++)
            factorial[i] = factorial[i - 1] * i % mod;
        inverse[n] = power(factorial[n], mod - 2);
        for (int i = n; i >= 1; i--)
            inverse[i - 1] = inverse[i] * i % mod;
    }
    long long choose(int n, int k) const {
        if (k < 0 || k > n)
            return 0;
        return factorial[n] * inverse[k] % mod * inverse[n - k] % mod;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int a, b, c;
    cin >> a >> b >> c;
    Combinations comb(max({a, b, c}));
    auto match = [&](int x, int y) {
        long long sum = 0;
        for (int k = 0; k <= min(x, y); k++)
            sum = (sum + comb.choose(x, k) * comb.choose(y, k) % mod * comb.factorial[k]) % mod;
        return sum;
    };
    cout << match(a, b) * match(a, c) % mod * match(b, c) % mod;
    return 0;
}
```

### 复杂度

时间 $O(a+b+c+\log P)$，空间 $O(\max(a,b,c))$。

### 易错点

允许距离3或更长的同色路径，因此不应强行让整个连通块只有一种或两种颜色。
