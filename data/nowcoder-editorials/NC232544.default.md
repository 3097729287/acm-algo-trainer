## [2020WF]Ley Lines

### 题意

固定宽度无限条带最多覆盖点数，n至3000。

### 思路

最优条带可平移到一侧边界经过某点P。用朝条带内部的单位法向量方向θ描述，其他点相对向量长度r、极角φ，入带条件为0≤r*cos(θ−φ)≤t。

r≤t时允许θ区间为[φ−π/2,φ+π/2]；r>t时分成[φ−π/2,φ−acos(t/r)]与[φ+acos(t/r),φ+π/2]。将跨2π区间拆开，扫描所有进入、离开事件取最大覆盖数，再加P。端点闭合，进入先于离开。t=0且无三点共线时直接答案2。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

constexpr long double EPS = 1e-12L;
struct Point {
    long double x = 0, y = 0;
    Point operator+(Point b) const { return {x + b.x, y + b.y}; }
    Point operator-(Point b) const { return {x - b.x, y - b.y}; }
    Point operator*(long double t) const { return {x * t, y * t}; }
    Point operator/(long double t) const { return {x / t, y / t}; }
};
long double cross(Point a, Point b) { return a.x * b.y - a.y * b.x; }
long double dot(Point a, Point b) { return a.x * b.x + a.y * b.y; }
long double norm(Point a) { return sqrtl(dot(a, a)); }
long double distance(Point a, Point b) { return norm(a - b); }
Point rotate90(Point a) { return {-a.y, a.x}; }

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long double width;
    cin >> n >> width;
    vector<Point> p(n);
    for (auto &a : p)
        cin >> a.x >> a.y;
    if (width == 0) {
        cout << 2;
        return 0;
    }
    const long double pi = acosl(-1.0L), period = 2 * pi;
    int answer = 2;
    for (int origin = 0; origin < n; origin++) {
        vector<pair<long double, int>> event;
        auto add = [&](long double l, long double r) {
            while (l < 0) {
                l += period;
                r += period;
            }
            while (l >= period) {
                l -= period;
                r -= period;
            }
            if (r <= period) {
                event.push_back({l, 1});
                event.push_back({r, -1});
            } else {
                event.push_back({l, 1});
                event.push_back({period, -1});
                event.push_back({0, 1});
                event.push_back({r - period, -1});
            }
        };
        for (int i = 0; i < n; i++)
            if (i != origin) {
                Point v = p[i] - p[origin];
                long double r = norm(v), a = atan2l(v.y, v.x);
                if (r <= width)
                    add(a - pi / 2, a + pi / 2);
                else {
                    long double offset = acosl(min(1.0L, width / r));
                    add(a - pi / 2, a - offset);
                    add(a + offset, a + pi / 2);
                }
            }
        sort(event.begin(), event.end(), [](auto a, auto b) {
            return a.first != b.first ? a.first < b.first : a.second > b.second;
        });
        int current = 1;
        for (auto [angle, delta] : event) {
            current += delta;
            answer = max(answer, current);
        }
    }
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(n²\log n)$，空间 $O(n)$。

### 易错点

t是整个条带宽，不是半径，不能误用2t。题目保证宽度增减0.01不改变答案，可使用long double区间端点。
