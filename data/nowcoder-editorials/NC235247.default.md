## Sramoc问题

### 题意

只用0..K−1数字组成能被M整除的最小正整数。

### 思路

按位追加数字时只需记录当前余数，转移为(10*r+d)%M。BFS按长度递增，并按数字升序扩展，就先得到最短、同长度字典序最小的数字。首位只枚举1..K−1，避免0这个无意义答案。每个余数只访问一次，保存父余数与末位，首次找到余数0后沿父链还原。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int k, m;
    cin >> k >> m;
    vector<int> parent(m, -2), digit(m);
    queue<int> queue;
    for (int d = 1; d < k; d++) {
        int r = d % m;
        if (parent[r] == -2) {
            parent[r] = -1;
            digit[r] = d;
            queue.push(r);
        }
    }
    while (parent[0] == -2 && !queue.empty()) {
        int r = queue.front();
        queue.pop();
        for (int d = 0; d < k; d++) {
            int next = (r * 10 + d) % m;
            if (parent[next] == -2) {
                parent[next] = r;
                digit[next] = d;
                queue.push(next);
            }
        }
    }
    string answer;
    for (int r = 0; r != -1; r = parent[r])
        answer.push_back('0' + digit[r]);
    reverse(answer.begin(), answer.end());
    cout << answer;
    return 0;
}
```

### 复杂度

时间 $O(KM)$，空间 $O(M)$。

### 易错点

K是允许数码的上界，不是数制，构造的仍是十进制数。不能用普通整数保存可能很长的答案。
