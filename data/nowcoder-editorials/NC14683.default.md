## 储物点的距离

### 题意

查询将区间 [l,r] 的带权货物运到指定点 x 的距离费用，答案取模。

### 思路

先由相邻距离得到各点坐标 p[i]，预处理重量前缀 B 与坐标乘重量前缀 W。把查询在 x 处分成两半：左侧费用为 p[x]*重量和-坐标重量和，右侧为坐标重量和-p[x]*重量和。区间端点取与 [l,r] 的交，x 在区间外时一侧为空即可。只做加减乘且最终取模，坐标和两个前缀都可边算边取模，避免真实加权总量溢出。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    const long long mod = 1000000007;
    int n, m;
    cin >> n >> m;
    vector<long long> p(n + 1), b(n + 1), w(n + 1);
    for (int i = 2; i <= n; i++) {
        long long distance;
        cin >> distance;
        p[i] = (p[i - 1] + distance) % mod;
    }
    for (int i = 1; i <= n; i++) {
        long long weight;
        cin >> weight;
        weight %= mod;
        b[i] = (b[i - 1] + weight) % mod;
        w[i] = (w[i - 1] + p[i] * weight) % mod;
    }
    auto sum = [&](const vector<long long> &prefix, int l, int r) {
        return l > r ? 0LL : (prefix[r] - prefix[l - 1] + mod) % mod;
    };
    while (m--) {
        int x, l, r;
        cin >> x >> l >> r;
        long long answer = 0;
        int end = min(r, x), start = max(l, x + 1);
        if (l <= end)
            answer = (p[x] * sum(b, l, end) - sum(w, l, end)) % mod;
        if (start <= r)
            answer = (answer + sum(w, start, r) - p[x] * sum(b, start, r)) % mod;
        cout << (answer + mod) % mod << '\n';
    }
    return 0;
}
```

### 复杂度

预处理 $O(n)$，每次询问 $O(1)$，空间 $O(n)$。

### 易错点

真实坐标乘重量会超出 long long，不能先求完整费用再取模。分左右依据原下标，不能比较已取模的坐标。
