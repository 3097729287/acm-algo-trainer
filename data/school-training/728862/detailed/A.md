## A. Beautiful Year

### 题意

给定年份 $1000\le y\le9000$，找严格大于 $y$ 且四位数字互不相同的最小年份。

### 从零讲：整数拆位与布尔数组

**十进制拆位。** 对非负整数，`value % 10;` 返回个位，`value / 10;` 的整数除法去掉个位。`bool seen[10] = {}` 创建十个初始为假的位置，用数字作为下标。数组有效下标为零到九；访问前由取余保证范围。数组查表和改值均为常数时间。

### 思路

先看 $2013$：它已经满足数字不同，但答案必须严格更大，所以从 $2014$ 检查，而不是把 $2013$ 再输出一次。

对一个候选年份，依次执行“取个位、删个位”。例如 $2014$ 的取数顺序为 $4,1,0,2$。每次取到数字 $d$，检查 `seen[d]`；已经出现说明不合法，否则把它标记为出现。零也是真实的一位，不能跳过。

为何不用寻找下一个年份的特殊规律？合法候选非常少、检查也只有四位，直接枚举既短又能避免进位时遗漏。对所有 $1000\le y\le9000$，合法年份 $9012$ 都在搜索终点之前或正好是终点，枚举一定结束。

正确性分两部分：判定函数恰在某个数字重复时拒绝，所以通过的年份数字确实互异；外层从 $y+1$ 递增检查，所以输出之前所有更小的合法范围候选均已被排除。时间 $O(10^4)$，额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

bool distinctDigits(int year) {
    bool seen[10] = {};
    while (year > 0) {
        int digit = year % 10;
        if (seen[digit]) return false;
        seen[digit] = true;
        year /= 10;
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int y;
    cin >> y;
    // 从下一年开始，首个合法年份就是最小答案。
    do { ++y; } while (!distinctDigits(y));
    cout << y << '\n';
}
```

### 易错点

必须严格大于输入；数字零也要参与去重。
