## L. Books

### 题意

有 $n\le10^5$ 本书，每本阅读时间为正数。选一个起点连续向后读，不能跳书，总时间不超过 $t\le10^9$，求最多能完整读几本。

### 从零讲：vector 下标与边界

**数组下标与空窗口。** `std::vector<int> a(n)` 的下标为零至 $n-1$。窗口闭区间的元素个数为 $right-left+1$；当左端恰好越过右端一位时，这个值是零，表示空窗口。代码在 `while (sum > t)` 时取走当前左端元素，由所有用时为正且预算为正保证访问仍在已加入部分内。

### 思路

答案必须是一段连续的书，不能跳过中间读得慢的一本。比如 $[3,1,2,1]$、$t=5$，从第二本开始读 $1+2+1=4$，能读三本。

![加入第三本后超时，删除最左一本](assets/l-books.svg)

从左往右加入书：前两本总用时 $3+1=4$；加入第三本后为 $6$，超出限制，于是移走第一本的 $3$，窗口变成第二、三本，总用时 $3$；再加入第四本，用时为 $4$，长度更新为 $3$。

为什么左端不需要往回走？当某个起点使窗口总时间超过 $t$，之后右端再扩展只会加入正数，这个起点永远不可能重新变合法。因此可以永久丢弃它。对固定右端点，不断移动左端直到首次合法，此时左端是仍可能使用的最靠左位置，对应最长合法区间。

需要用 `while` 收缩：一次加入一本很慢的书，可能需要移走多本，甚至把刚加入的书也移走，才能得到空窗口。例如单本用时 $10$、预算 $3$，最后左端来到右端后一位，窗口长度恰为零，不会误读这本书。

总复杂度并不是两个循环相乘：右端共走 $n$ 次，左端在所有收缩循环中合计至多走 $n$ 次，每本书最多入窗、出窗各一次，所以时间 $O(n)$。保存输入需要 $O(n)$ 空间。这个证明依赖用时为正；若数组允许负数，移动方向就不能这样判断。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    long long t;
    cin >> n >> t;
    vector<int> a(n);
    for (int &v : a) cin >> v;
    long long sum = 0;
    int left = 0, answer = 0;
    for (int right = 0; right < n; ++right) {
        sum += a[right];
        while (sum > t) {
            sum -= a[left];
            ++left;
        }
        // 对这个右端点，left 已是最靠左的合法起点。
        answer = max(answer, right - left + 1);
    }
    cout << answer << '\n';
}
```

### 易错点

一次可能要收缩多次；单本超时可得到空窗口；限制是连续阅读。
