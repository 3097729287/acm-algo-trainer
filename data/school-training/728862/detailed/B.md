## B. Raising Bacteria

### 题意

空盒中每天早上可放入细菌，晚上全部翻倍。要在某一时刻恰有 $1\le x\le10^9$ 个细菌，求亲手放入的最少个数。

### 从零讲：整数除法与余数

**整数除法与余数。** 对非负整数，`x % 2;` 只能为零或一，`x / 2;` 向下取整。比如十三除以二，商为六、余一；重复取余便从低位到高位读出二进制。这与小数除法不同，变量用 `int` 就不会保留小数部分。

### 思路

例如 $13=8+4+1$。在目标时刻之前三晚加入一个细菌，贡献 $8$；之前两晚加入一个，贡献 $4$；目标当天早上再加入一个，贡献 $1$。总共只加入三个。

这里统计的是“亲手放入的个数”，每晚翻倍得到的后代不再计费。反过来看，每个亲手放入的细菌，在观察时已经历非负整数次翻倍，因此它对最终数量的贡献一定为 $1,2,4,8,\ldots$ 中的一种。

如果某个方案有两项相同的 $2^j$，用一项 $2^{j+1}$ 代替即可少放一个。不断合并之后，每种幂只剩零项或一项；二进制表示的唯一性说明，剩下的项数正是二进制中 $1$ 的个数。原方案只会有更多项，上面的构造又能达到这个项数，所以它是最优值。

代码没有依赖内建位函数：整数除法 `x / 2;` 删除最低二进制位，`x % 2;` 取出最低位。例如 $13\to6\to3\to1\to0$，余数为 $1,0,1,1$，相加得到 $3$。时间 $O(\log x)$，空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int x, answer = 0;
    cin >> x;
    while (x > 0) {
        // 除以二前的余数正是当前二进制最低位。
        answer += x % 2;
        x /= 2;
    }
    cout << answer << '\n';
}
```

### 易错点

统计放入的细菌总数，不是翻倍次数，也不是最高位位置。
