## C. Fence

### 题意

给定 $n$ 块木板高度，找总高度最小的连续 $k$ 块，输出其左端编号。$1\le k\le n\le150000$，高度在 $1$ 到 $100$ 之间。

### 从零讲：vector：长度可变的连续数组

**动态数组 `vector`。** `std::vector<int> a(n)` 创建含有 $n$ 个整数的连续数组，有效下标为零至 $n-1$；下标访问为 $O(1)$。`for (int &v : a)` 中的引用让输入直接写进原数组。不要访问 `a[n]`；容器中途增容可能使旧引用、指针或迭代器失效，本题读入后不增容。

### 思路

若对每个起点都重新相加 $k$ 块木板，总工作量为 $O(nk)$。但相邻窗口只有首尾不同，重复求公共部分没有必要。

![两个窗口中的保留、移出与移入木板](assets/c-window.svg)

以 $[1,2,6,1,1,7,1]$、$k=3$ 为例，首个窗口和为 $9$。窗口右移时移出第 $1$ 块的 $1$，移入第 $4$ 块的 $1$，新和仍为 $9$；再右移，移出第 $2$ 块的 $2$、移入第 $5$ 块的 $1$，得到 $8$，对应起点 $3$。

维护的不变量是：完成一次右移后，`sum` 恰好等于当前连续 $k$ 块的和。初始化直接求出第一段；之后只删除不再属于窗口的一个元素、加入刚属于窗口的一个元素，不变量继续成立。枚举所有右端点就覆盖了全部 $n-k+1$ 个合法窗口。

代码数组从零编号。新右端下标为 $r$ 时，左端下标为 $r-k+1$；题目要求从一编号，所以输出 $r-k+2$。只在严格更小时更新，会保留并列最优中最靠左的一段，也符合“任意一段”的要求。时间 $O(n)$，空间 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, k;
    cin >> n >> k;
    vector<int> h(n);
    for (int &v : h) cin >> v;
    int sum = 0;
    for (int i = 0; i < k; ++i) sum += h[i];
    int best = sum, answer = 1;
    for (int r = k; r < n; ++r) {
        // 窗口右移：去掉最左木板，加入新右端木板。
        sum += h[r] - h[r - k];
        if (sum < best) {
            best = sum;
            answer = r - k + 2;  // 转为从一开始的左端点。
        }
    }
    cout << answer << '\n';
}
```

### 易错点

输出从一开始的左端点；窗口不能绕过数组末尾；并列最优可任选。
