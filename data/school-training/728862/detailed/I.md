## I. Ice Skating

### 题意

有最多 $100$ 个整数坐标雪堆，只能沿横向或纵向滑到其他雪堆。求最少新增几堆，才能使所有雪堆互相可达。

### 从零讲：queue 的基本用法

**队列 `std::queue`。** 队列先进先出：`q.push(v);` 在尾部加入，`q.front();` 读取头部，`q.pop();` 移除头部且不返回元素。`q.front();`、`q.pop();` 都要求队列非空，所以外层先检查 `q.empty();`。这些操作均为 $O(1)$；BFS 把已经发现的点入队、入队时标记，避免重复扩展。

### 思路

先把滑行关系看成一张图：雪堆是顶点，同一行或同一列的雪堆可相互到达。即使它们之间还有雪堆挡住，也可以在中间雪堆继续出发，最终到达。因此为了判断连通性，可以把同一行、同一列的任意两点视为连边。

![两块之间增加转弯位置](assets/i-bridge.svg)

图中原有 $(1,1)$ 与 $(3,3)$ 不连通，在 $(1,3)$ 增加一堆后，可以先竖向滑，再横向滑。一般地，在不同连通块中选 $(x_1,y_1)$ 与 $(x_2,y_2)$，加入 $(x_1,y_2)$ 即可合并它们。这个位置不可能已有雪堆：若已有，它已经把两块连接起来，与“两块不同”矛盾。所以总能用一堆减少一块，反复执行给出 $c-1$ 的可行方案。

还要证明不会有一次合并三块的捷径。考虑任意时刻加入的新雪堆：同一行的所有现有雪堆本来就在一个连通块，同一列的所有现有雪堆也在一个连通块；其他雪堆无法与新点直接滑行。所以它最多合并两个已有连通块。这个论证同样包含此前新增的雪堆，故任何构造都至少要加 $c-1$ 堆。

代码使用 BFS：从未访问的点出发，用队列维护已经发现、还未扫描邻居的点；取队首后检查所有点，把同一行或列的未访问点加入队尾。入队时立即标记，每点只会入队一次。一次 BFS 结束时恰好访问一个连通块；重新选择起点的次数就是 $c$。每点扫描 $n$ 个候选邻居，时间 $O(n^2)$，空间 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> x(n), y(n);
    for (int i = 0; i < n; ++i) cin >> x[i] >> y[i];
    vector<bool> seen(n, false);
    int components = 0;
    for (int s = 0; s < n; ++s) {
        if (seen[s]) continue;
        ++components;
        queue<int> q;
        q.push(s);
        seen[s] = true;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v = 0; v < n; ++v) {
                if (!seen[v] && (x[u] == x[v] || y[u] == y[v])) {
                    seen[v] = true;  // 入队时标记，避免重复加入。
                    q.push(v);
                }
            }
        }
    }
    cout << components - 1 << '\n';
}
```

### 易错点

同一行或列不必相邻编号；原本只有一个连通块时答案为零。
