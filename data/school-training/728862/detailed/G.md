## G. String Task

### 题意

给定长度不超过 $100$ 的英文字符串，删除元音 `AOYEUI`，每个辅音前加点号，并把辅音改为小写。题面保证结果非空。

### 从零讲：char 与 string

**字符和字符串。** `char` 保存一个字符，`string` 保存字符序列；单引号如 `'.'` 是字符，双引号如 `"abc"` 是字符串。范围循环按顺序读取每个字符。`ch-'A'+'a'` 只用于已确认是大写英文字母的字符，不能用于任意文字。

### 思路

以 `aBAcAba` 为例，小写化后得到 `"abacaba"`，去掉所有 `'a'` 后剩下 `"bcb"`，最终输出 `".b.c.b"`。

实现时不必真的修改字符串三遍。依次读取一个字符：若在 `'A'` 到 `'Z'` 之间，用它相对 `'A'` 的偏移加到 `'a'` 上，得到对应小写字母；与六个元音比较；只有辅音才输出 `'.'` 和自身。这个次序保证大小写元音都能被删除。

代码中的 `char` 保存一个字符，单引号写字符，如 `'.'`；`string` 保存字符序列，范围循环 `for (char ch : s)` 依次取出序列中的每个字符。本题输入只含英文字母，按英文字母连续编码做大小写转换适用；不要把这段转换当成任意 Unicode 文本的大小写处理。

扫描过程中，已经输出的部分恰好等于已经处理的原串前缀的目标结果；加入下一个辅音的两字符结果，或忽略下一个元音，都保持这一性质。因此扫描结束时得到完整答案。长度为 $m$ 时，时间 $O(m)$，除输入外额外空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    for (char ch : s) {
        if ('A' <= ch && ch <= 'Z') ch = char(ch - 'A' + 'a');
        bool vowel = ch == 'a' || ch == 'o' || ch == 'y'
                  || ch == 'e' || ch == 'u' || ch == 'i';
        // 只为保留的辅音输出点号，原字符顺序不变。
        if (!vowel) cout << '.' << ch;
    }
    cout << '\n';
}
```

### 易错点

元音包含 `'y'`；先统一大小写；元音前也不输出点号。
