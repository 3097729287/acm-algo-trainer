## H. Cut Ribbon

### 题意

把长度为 $n$ 的带子恰好切成若干段，每段长度只能为 $a,b,c$，求最多段数。所有参数不超过 $4000$，保证有解。

### 从零讲：vector 的创建与初值

**用数组表示状态。** `std::vector<int> dp(n+1, -1000000)` 创建下标零至 $n$ 的状态表，并设置统一初值。负值表示不可达，零表示可达且段数为零，二者不能混用。`std::max(old,candidate)` 只选数值较大者，状态是否合法须先由条件判断保证。

### 思路

长度必须恰好用完，不能只追求当前多切几段。例如 $n=7$，允许长度为 $2,5,5$，一直切长度 $2$ 会剩下一单位无法处理；正确方案为 $2+5$。

定义 $dp[len]$ 时要同时包含“恰好”与“最多”：它回答一个长度恰为 $len$ 的完整带子最多能切几段，不允许留下未使用的部分。空带子可以切成零段，所以 $dp[0]=0$；其他长度先设为负数，表示还没有合法方案。

![计算长度七时可使用的三个来源](assets/h-dp.svg)

图中允许长度为 $2,3,5$，计算 $dp[7]$：最后一段切 $2$，前面必须恰好用掉 $5$；最后一段切 $3$，前面必须恰好用掉 $4$；最后一段切 $5$，前面必须恰好用掉 $2$。相应段数为 $dp[5]+1=3$、$dp[4]+1=3$、$dp[2]+1=2$，所以答案为 $3$。

为什么最优值可由更小长度的最优值得到？删去最优方案的最后一段后，余下部分也必须最优，否则可换成段数更多的方案，再把最后一段加回去，得到更优答案。三个可能的最后长度都尝试，便覆盖所有方案。

循环从小长度走向大长度，因为 $cut$ 为正，来源 $len-cut$ 总已经算完。同一长度可以重复使用，这符合题目允许无限段的条件。参考代码用 `dp[len-cut] >= 0` 检查可达性，避免把“不可达”加一误当成可行答案。时间 $O(n)$，空间 $O(n)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, a, b, c;
    cin >> n >> a >> b >> c;
    vector<int> dp(n + 1, -1000000);
    dp[0] = 0;  // 长度零恰好切成零段，其余长度起初不可达。
    for (int len = 1; len <= n; ++len) {
        for (int cut : {a, b, c}) {
            if (len >= cut && dp[len - cut] >= 0) {
                dp[len] = max(dp[len], dp[len - cut] + 1);
            }
        }
    }
    cout << dp[n] << '\n';
}
```

### 易错点

必须恰好用完；不可达状态不能初始化为零；长度重复不影响转移。
