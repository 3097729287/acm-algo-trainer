## F. Twins

### 题意

给定至多 $100$ 枚正面值硬币，取尽量少的硬币，使已取总面值严格大于剩余总面值。

### 从零讲：sort 与迭代器范围

**排序范围。** `std::sort(first,last)` 对左闭右开区间原地升序排序，要求随机访问迭代器；`vector` 的 `begin()` 与 `end()` 正好指定全部元素。`end()` 不能解引用。排序一般花 $O(n\log n)$ 次比较；本题从末尾往前取值，不需要自定义比较器。

### 思路

目标是最少枚数，不是尽量少拿钱。比如硬币为 $[1,2,2]$，总额为 $5$：拿一枚最大硬币只得到 $2$，对方还有 $3$，不够；拿两枚最大硬币得到 $4$，对方只有 $1$，答案为 $2$。

设已拿总额为 $S$、全部硬币总额为 $T$，应满足 $S>T-S$。由于要求严格大于，相等时也必须继续拿。例如 $[3,3]$，拿一枚得到双方各 $3$，答案是两枚。

固定拿 $k$ 枚时，按面值从大到小取能使 $S$ 最大。证明可以直接交换：若一个方案遗漏了某枚更大硬币，却选了一枚更小硬币，把两者交换，枚数不变，总额不会减少；反复交换就得到最大的 $k$ 枚。所以只需依次检查这些前缀，最早超过一半的前缀长度就是最小可行枚数。

代码用 `sort(a.begin(), a.end())` 升序排序，再从数组末尾向前走。`begin()` 指向首元素，`end()` 指向末元素之后，排序处理左闭右开的整个范围。排序会改变容器内元素的顺序；本题不需要保留硬币原编号，所以可以直接修改。时间 $O(n\log n)$，存储硬币需要 $O(n)$ 空间。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, total = 0;
    cin >> n;
    vector<int> a(n);
    for (int &v : a) { cin >> v; total += v; }
    sort(a.begin(), a.end());
    int chosen = 0, answer = 0;
    // 固定枚数时，取最大的这些硬币能得到最大总额。
    for (int i = n - 1; i >= 0 && chosen <= total - chosen; --i) {
        chosen += a[i];
        ++answer;
    }
    cout << answer << '\n';
}
```

### 易错点

相等时仍不满足要求；先取最大面值，排序后从末尾扫描。
