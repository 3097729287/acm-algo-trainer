## B. Raising Bacteria

### 题意

空盒中每天早上可放入细菌，晚上全部翻倍。要在某一时刻恰有 $1\le x\le10^9$ 个细菌，求亲手放入的最少个数。

### 从零讲：整数除法与余数

**整数除法与余数。** 对非负整数，`x % 2;` 只能为零或一，`x / 2;` 向下取整。比如十三除以二，商为六、余一；重复取余便从低位到高位读出二进制。这与小数除法不同，变量用 `int` 就不会保留小数部分。

### 思路

答案等于 $x$ 的二进制中 $1$ 的个数。每加入一个细菌，它在若干次翻倍后贡献一个 $2$ 的幂；把 $x$ 拆成这些幂，最少的项数就是二进制位数中 $1$ 的数量。

若两个贡献都是 $2^j$，可合并为 $2^{j+1}$，项数减少。因此最少项的表示中每个幂至多出现一次，恰为二进制展开。逐次取 $x\bmod2$ 并整除二，累加余数即可。时间 $O(\log x)$，空间 $O(1)$。

### 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int x, answer = 0;
    cin >> x;
    while (x > 0) {
        // 除以二前的余数正是当前二进制最低位。
        answer += x % 2;
        x /= 2;
    }
    cout << answer << '\n';
}
```

### 易错点

统计放入的细菌总数，不是翻倍次数，也不是最高位位置。
